# 存储周期见顶或反转场景卡

## 决胜分歧

见顶通常先表现为价格斜率、订单能见度与分项扩散转弱。DRAM/NAND/HBM/企业级 SSD 与现货/合约/实现价必须分开。供给侧须拆**生产者纪律**：减产执行、产品组合迁移、capex 纪律、技术节点 bit 自然增长、HBM 对通用 DRAM 挤占——不能只看需求与库存。另须标明**周期属性**：仍是周期定价 / 长协仅改变再平衡节奏 / 可切换成长叙事（后两者只作 EG/VA 输入，本卡不推估值）。

## 1. 本场景相对于主框架增加什么

相对 IF-SC-01，本卡增加：

1. 分产品与多价格口径；
2. 斜率转弱 vs 全面反转；
3. 供给释放拆解：晶圆投入 × 节点 bit 增长 × 产品组合 × 良率 × 原厂资本纪律；
4. 周期属性门：现货/合约 vs LTA·SCA 锁量锁价是否改变再平衡（不在本卡内估值）。

## 2. 调用路由

| 项目 | 内容 |
|---|---|
| 默认主框架 | IF-SC-01 |
| 条件辅助框架 | HBM 挤占→SCN-MEM-HBM；晶圆/组合细节→IF-FAB |
| 默认排除 | APP/DES/EQP 除非已转向公司兑现 |
| 不适用问题 | 非存储品类；纯 HBM 供需用 SCN-MEM-HBM |

## 3. 场景特有判断脊柱

```text
分产品终端/bit demand
→ 多层库存与订单能见度
→ 生产者纪律：减产/组合/capex/节点bit增长
→ 分价格口径与斜率
→ 周期属性（周期定价 / 长协改节奏 / 成长叙事候选）
→ 见顶/反转与改判信号
```

## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |
|---|---|---|---|
| 分产品价格 | 分项涨价扩散一致 | 均价掩盖分化 | 分产品三价口径 |
| 多层库存 | 两层以上同向 | 只看单一口径 | 原厂+渠道/客户 |
| 生产者纪律 | 减产/组合/capex一致收缩 | 口头减产投片未降 | 投片+组合+capex |
| 拐点阶段 | 斜率转弱先行 | 全面反转已确认 | 斜率+合约重定价 |
| 周期属性 | 现货/合约仍主导再平衡 | LTA·SCA 锁量锁价改变节奏 | 长协覆盖率+重定价条款 |

## 5. 对 02 和 03 的增量交接

```yaml
scenario_additions:
  required_splits:
    - DRAM / NAND / HBM / 企业级SSD
    - 现货 / 合约 / 报价 / 实现价
    - 斜率转弱 / 全面反转
    - 晶圆投入 / 节点bit增长 / 组合 / 良率 / 资本纪律
    - 周期定价 / 长协改节奏 / 成长叙事候选
  mandatory_evidence:
    - 分产品需求库存价格
    - 至少两层库存
    - 减产执行与capex/组合证据
  counter_evidence:
    - 涨价来自补库
    - 口头减产未执行
    - 节点bit增长抵消减产
    - 长协口头锁量无重定价约束
  stop_if:
    - 不能拆分存储产品
    - 价格口径混用
    - 供给侧只看需求不论生产者纪律
```
