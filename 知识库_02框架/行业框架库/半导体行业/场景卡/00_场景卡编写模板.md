# 场景卡编写模板

场景卡是**场景差异适配器**，不是缩小版主框架。只写相对默认主框架的增量；未使用场景卡不必解释。

## Front matter（必填）

```yaml
---
document_type: semiconductor_scenario_card
scenario_id: SCN-XXX
name: 场景名称
scenario_kind: product_tech | external_event | special_judgment
default_framework_id: IF-XXX-01
scenario_type: product_application | event_problem
version: 1.0.0
status: scenario
updated_at: YYYY-MM-DD
---
```

## 正文五段（800—1200 字）

### 标题下：决胜分歧（非编号节）

1—2 段，写本场景相对主框架的核心矛盾与最易跳步误判。

### ## 1. 本场景相对于主框架增加什么

- 特殊对象
- 特殊时钟
- 最易跳步误判点（相对 `default_framework_id`）

### ## 2. 调用路由

| 项目 | 内容 |
|---|---|
| 默认主框架 | 仅 1 个 |
| 条件辅助框架 | 0—2 个，写明触发条件 |
| 默认排除 | 相关但通常不展开的框架 |
| 不适用问题 | 不应调用本卡的问题 |

### ## 3. 场景特有判断脊柱

4—6 节点，禁止产业链百科。

### ## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |

### ## 5. 对 02 和 03 的增量交接

```yaml
scenario_additions:
  required_splits: []
  mandatory_evidence: []
  counter_evidence: []
  stop_if: []
```

## 禁止

- 九段完整框架结构
- 默认并列 3 个以上主框架
- 「最低证据」与「输出到 03」双清单重复
- 复述主框架已有阶段门与变量
