# SiC渗透与供给场景卡

适用问题：SiC 渗透与四级供给是否加速，成本与可用性是否支持放量。

## 决胜分歧

SiC 渗透由系统 TCO 决定，不由材料性能单点决定。供给须衬底→外延→器件→模块逐级折算。每次任务只选一个互斥主判断模式，避免把场景卡做成小型全产业链框架。

## 1. 本场景相对于主框架增加什么

相对 IF-APP-01，本卡增加：

1. 系统 TCO（器件溢价 vs 效率/续航/热管理节省）；
2. 衬底—外延—器件—模组逐级折算；
3. **互斥主判断模式**：终端渗透 / 系统TCO / 合格供给 / 公司份额与利润准备度。

## 2. 和哪个主框架一起用

| 项目 | 内容 |
|---|---|
| 默认主框架 | IF-APP-01 |
| 条件辅助框架 | 衬底外延缺陷→IF-MAT；器件良率→IF-FAB；模组认证定点→IF-DES |
| 默认排除 | 未选模式前不并联 MAT+FAB+DES；SC/LOC/PKG 除非必要 |
| 不适用问题 | 纯 Si 基功率、无系统经济性的材料参数比较 |

## 3. 场景特有判断脊柱

```text
选定主判断模式
→ TCO或终端规格（若渗透/TCO模式）
→ 或衬底/外延/器件/模组折算（若供给模式）
→ 或认证/定点/装车/份额（若公司模式）
```

## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |
|---|---|---|---|
| 系统TCO | 全生命周期节省覆盖溢价 | 收益不足覆盖溢价 | 电气规格+TCO |
| 合格供给 | 器件良率+认证同步 | 衬底扩产器件受限 | 四级供给折算 |
| 装车兑现 | 平台量产复购 | 定点≠装车 | 定点+装车 |
| 份额渗透 | 公司份额随渗透升 | 终端渗透≠公司份额 | 渗透与份额分开 |

## 5. 对 02 和 03 的增量交接

以下为系统登记，研究员可不读。

```yaml
scenario_additions:
  required_splits:
    - 主判断模式四选一
    - 终端渗透率 / 公司份额
    - 衬底 / 外延 / 器件 / 模组
  mandatory_evidence:
    - 模式选定记录
    - 与模式对应的TCO或四级供给或装车证据
  counter_evidence:
    - 系统收益不足
    - 硅基继续竞价
    - 降价放量不增利
  stop_if:
    - 未选定互斥主判断模式
    - 只比材料参数无TCO
```
