# 地缘政治冲击影响半导体场景卡

## 决胜分歧

地缘事件必须拆为规则范围、真实暴露、库存/合同缓冲、替代能力和结果变量。舆论强度不等于执行强度，国家贸易额不等于公司暴露，概念国产替代不等于可量产替代。

先确认产品分类、实体/最终用途、许可和生效期，再看企业供应/客户关系及库存，最后看订单、交期、价格和财务结果。若关键产品不在范围、许可证可获或库存覆盖判断窗口，主路径应显著降级。

## 1. 适用问题

用于判断战争、制裁、出口管制、航运中断、能源价格、区域安全风险和外交冲突如何影响半导体需求、供给、设备材料、库存、价格、国产替代和风险偏好。适用于美伊冲突、台海风险、红海/霍尔木兹航运冲击、出口管制升级等问题。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 横向约束 | IF-LOC-01 外部约束、国产替代与供应链韧性 | 解析政策、管制、地缘和供应链韧性 |
| 横向状态 | IF-SC-01 半导体周期与库存 | 判断库存、价格、订单和周期扰动 |
| 材料框架 | IF-MAT-01 半导体材料需求、认证与放量 | 判断化学品、气体、衬底、物流和原料约束 |
| 设备框架 | IF-EQP-01 半导体设备需求、验证与放量 | 判断设备、零部件、交付和服务约束 |

## 3. 最小判断链

```text
地缘事件性质和影响范围
→ 能源、航运、金融、政策、出口管制和风险偏好
→ 半导体材料、设备、制造、封测、终端需求的暴露
→ 库存、替代供应、合同机制和客户行为缓冲
→ 价格、交期、订单和产能扰动
→ 公司暴露、业绩兑现和改判信号
```

## 4. 关键变量

- 事件性质、地域范围、持续时间和政策反应
- 能源价格、航运路径、保险、汇率和风险偏好
- 材料、设备、零部件、备件、软件和服务暴露
- 客户库存、供应商库存、替代供应和合同条款
- 受影响产品、地域收入、客户和供应商集中度

## 5. 最低证据

- 正式政策、制裁、出口管制、航运和能源市场证据
- 目标环节的供应商、客户、地域和产品暴露证据
- 库存、替代供应、合同和安全库存证据
- 价格、交期、订单、取消单和产能运行证据
- 公司披露中的供应链、客户和地区收入暴露

## 6. 主要反证与阻断

- 事件停留在情绪层面，没有实物流和政策约束
- 库存和替代供应吸收短期冲击
- 受影响地区或材料并非目标产业链关键节点
- 合同、长协和保险机制缓冲价格影响
- 终端需求下修抵消供应紧张

## 7. 停止条件

- 无法确认事件影响路径和产业链暴露
- 只有市场情绪，没有供应、需求或政策证据
- 无法区分一次性冲击和持续约束
- 公司暴露、客户地域和供应商依赖无法穿透

## 8. 常见误判

- 地缘事件直接推导半导体全面涨价
- 把风险偏好变化当作产业供需变化
- 只看新闻标题，不核正式政策和实际执行
- 忽略库存、替代供应和合同机制
- 把供应链冲击直接推导为公司盈利提升

## 9. 输出到 03 的证据要求

- 列事件—政策—物流—能源—供应链暴露证据链
- 按材料/设备/制造/封测/终端拆影响矩阵
- 补库存、替代供应、合同和客户行为证据
- 公司层面必须穿透地域收入、供应商和客户暴露
