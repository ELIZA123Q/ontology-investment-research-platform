# 财务报表与盈利质量框架

## 研究员先看什么

财务质量研究不是扫描一组异常指标，也不是用“经营现金流低于净利润”直接定性。它首先要区分当前分歧属于哪一种：

1. **报表可信与口径可比**：披露、审计、政策与附注是否足以让报告数字成为可用事实基础；
2. **利润来源与正常化基线**：报告利润由核心经营、周期、会计估计、并购与一次性项目中哪些因素形成；
3. **现金转换与营运资本**：利润是否经真实回款转为经营现金，还是依赖预收、延付或一次性释放；
4. **资产负债与持续性**：资产能否回收，义务是否完整，当前利润与现金是否足以支持持续经营。

单次任务应选择一条主路线，最多保留一条主要竞争路线。报表数字已披露不等于反映经济现实；经营恶化不等于会计操纵；经营现金流低于净利润不等于盈利质量差；扣非或调整后利润不自动等于正常化利润；红旗不等于已确认问题。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断某一明确报告主体在给定期间与口径下：

- 报表主体、合并范围、币种、准则与分部是否可比，审计与重述是否限制使用；
- 会计政策与估计是否稳定，收入、成本、资本化、减值与税务是否与业务实质一致；
- 报告利润来自核心经营、周期、并购、会计时点还是一次性项目，正常化基线如何形成；
- 净利润与经营现金流差异由哪些营运资本与非现金项目形成，是否可在业务时钟内解释；
- 资产可回收性、债务与表外义务是否完整，历史基线能否作为预测入口。

本框架不直接判断长期商业模式、短中期行业兑现、未来经营预测、治理定性、违约概率，以及预期差、估值或交易结论。财务质量回答“历史数字是否可信、可比、可持续并可作为基线”；未来数字交 `BF-FS-01`；短中期兑现交 `BF-EE-01`；流动性压力交 `BF-RS-01`。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 已报告事实 vs. 经济实质 | 数字可准确摘录，却可能受确认、估计、分类与合并范围影响 |
| 报告质量 vs. 经济结果质量 | 公司可如实报告差经营，也可能以低质量表达呈现尚可经营 |
| 法定 / 扣非 / 调整后 / 正常化利润 | 排除项、税务与现金影响不同，不能互相替代 |
| 经常发生 vs. 经济上可持续 | 每年出现不等于应纳入核心盈利；周期项目也可能是业务常态 |
| 会计利润 vs. 经营现金流 vs. 自由现金流 | 应计、营运资本与 Capex 会造成时点与口径差异 |
| 现金转换差 vs. 现金质量差 | 真实增长、季节性与合同机制也会占用现金 |
| 应收/库存增加 vs. 收入虚增或需求恶化 | 须结合业务规模、账龄、订单与减值，不能机械定性 |
| 财务红旗 vs. 已确认问题 | 红旗只是核查入口，需直接事实与竞争解释才能升级 |

### 1.3 禁止跳步

- 不能从审计标准意见直接推出报表完全可信；
- 不能从单个异常指标直接形成舞弊、利润失真或违约定性；
- 不能把公司“调整后利润”或扣非利润直接当作正常化利润；
- 不能从 OCF 低于/高于净利润直接推出操纵或现金质量优秀；
- 不能从应收、库存或资本化上升直接推出收入虚增或费用少计；
- 不能将减值、重组等反复项目长期全部剔除；
- 不能只看债务总额而忽略期限、契约、受限现金与表外义务；
- 不能以财务比率阈值跨行业机械比较；
- 不能从财务质量判断直接生成精确预测、估值或交易建议。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 报表主体、合并范围、期间、币种或准则无法确认 | 正式跨期比较与完整 `reported_fact` 基线 |
| 缺少完整三表、关键附注或审计材料，且缺口影响核心科目 | 高置信报表可信度与后续正常化 |
| 审计否定/无法表示意见，或重大保留直接影响核心信息 | 将相关报表作为高置信预测基线 |
| 并购、处置或合并范围变化无法拆分 | 内生增长、正常化盈利与历史可比性 |
| 重大调整项没有来源、税务、现金与跨期记录 | `normalized_baseline` |
| 利润与现金长期背离，但无法取得营运资本与业务解释 | 高质量盈利与现金转换结论 |
| 重大义务、受限现金或表外安排无法核实 | 完整负债与持续性判断 |
| 只有财务比率，没有原始报表、附注与业务事实 | 正式 `earnings_quality` |

高级输出停止时，可保留已核实局部事实与明确限制，但不得用“整体看起来合理”覆盖关键缺口。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。报表可信门是所有高阶路线的共同前置，但不要求每次完整扫描全部科目。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 报表可信与口径可比** | 数字能否作为事实基线，差异来自经营还是口径 | 新覆盖、重述、审计异常、政策或合并范围变化 | 审计意见、关键事项、监管问询、重述、政策/估计变更、合并分部桥 | 真实经营变化 vs. 准则、重分类、汇率、并购或估计变化 | 无法恢复可比口径时，止于局部已报告事实 |
| **B 利润来源与正常化基线** | 哪些利润来自核心经营，哪些来自周期、会计与一次性 | 利润高增、扣非差异大、调整项多、并购或处置 | 量价成本桥、分部利润、非经常项目、资本化、减值、补助、税率 | 核心改善 vs. 周期高点、会计时点、并购、成本递延 | 调整项无法验证或业务驱动无法对账时，不形成 `normalized_baseline` |
| **C 现金转换与营运资本** | 利润为何未转成现金，背离是时滞还是质量恶化 | 利润与 OCF 背离；应收/合同资产/库存增长 | 回款、账龄、合同资产转应收、库存周转、应付预收、订单交付 | 增长/季节性占用 vs. 确认激进、回款恶化、渠道压力 | 缺少营运资本明细与业务时钟时，止于现金差异描述 |
| **D 资产负债与持续性** | 资产能否回收、义务是否完整、缓冲是否够 | 商誉/无形高、减值争议、短债、担保或持续经营风险 | 资产利用与现金流、减值假设、债务期限、契约、受限现金、承诺 | 真实投资期 vs. 资本错配、减值延迟、义务遗漏 | 压力情景交 `BF-RS-01`；缺少关键义务时不形成稳定判断 |

### 路线选择要求

02 调用本框架时必须说明：目标输出；主路线与竞争路线；可比期间与口径；哪 2—3 个关键判断与 3—5 个决定性变量；哪些红旗仅作监测；哪些模块裁剪；哪些问题转交商业模式、业绩弹性、治理、资本配置、预测或风险框架。四条路线全部展开，通常说明问题未收敛。

## 3. 模块菜单

模块是可裁剪能力，不是默认必做清单。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| FQ-C1 报告范围与审计可用性 | 核心 | 使用任何财务高阶输出前 | 上游已可靠确认时可简写，不能省略 | 主体、口径、审计与数据版本基准 |
| FQ-C2 三表附注与业务对账 | 核心 | 解释利润、现金或资产负债 | 仅提取单一已报告事实时可缩短 | 关键科目与业务活动桥接 |
| FQ-M1 收入成本与利润确认 | 条件 | 收入或利润变化是核心分歧 | 不涉及利润形成 | 确认时点、成本配比与利润来源 |
| FQ-M2 非经常周期与正常化 | 条件 | 需要历史可持续基线 | 只确认报告事实 | 调整项台账与正常化区间 |
| FQ-M3 应收库存与现金转换 | 条件 | 现金背离、收入质量或营运资本争议 | 现金不是本次问题 | 收入—营运资本—现金桥 |
| FQ-M4 资本化减值与资产质量 | 条件 | 资本化、商誉、在建或减值争议 | 资产风险与本次无关 | 费用/资产化与可回收性 |
| FQ-M5 债务受限现金与承诺 | 条件 | 流动性、杠杆或持续经营问题 | 偿付不是本次问题 | 完整义务与可用缓冲 |
| FQ-M6 调整口径与关联交易 | 条件 | 大量非公认指标或重大关联安排 | 无重大调整/关联 | 法定与调整口径桥；交易实质 |
| FQ-E1 治理/压力/行业专用交接 | 扩展 | 报告动机、流动性压力或特殊行业 | 无对应问题 | 交 `BF-CG-01`、`BF-RS-01` 或领域框架 |

单次任务通常只启用 1—3 个条件模块；不会改变输出门槛或竞争解释的模块应裁剪。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 报告可用性 | 前提与停止变量 | 只看意见类型不够，须看影响范围 |
| 口径一致性 | 趋势是否可比 | 直接用同比可能被口径制造 |
| 利润来源与正常化 | 可持续基线 | 机械采用扣非或公司调整值 |
| 现金转换 | 质量与时点 | 单期 OCF/净利润不能定性 |
| 资产与负债质量 | 持续性与缓冲 | 账面现金/资产负债率可能误导 |

02 通常只保留 3—5 个决定性变量。变量多于 8 个时，通常说明任务未裁剪。正常化不是机械剔除：须判断项目是否与核心经营相关、是否重复、是否有现金影响、是否仅确认时点不同、税务与跨期如何处理。

### 4.2 代理与红旗要求

红旗只提高核查优先级。升级为削弱或阻断信号，至少满足：多项目同向；跨周期持续未反转；业务事实不支持报表；或审计/监管/重述提供独立支持。单一红旗通常不能定性。

### 4.3 关键时钟

只选择本次相关时钟，不得混用：

`业务发生 → 收入确认 → 回款 → 库存采购 → 费用/资本化 → 资产回报 → 债务到期 → 审计与重述`

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 利润增长快于收入 | 经营杠杆与结构改善 | 费用递延、资本化或一次性收益 | 成本结构、资本化、现金与后续费用 | 不直接认定核心改善 |
| OCF 低于净利润 | 增长与营运资本投入 | 回款恶化、库存积压或确认问题 | 业务增长、账龄、库存、后续反转 | 切换现金质量削弱或保留时点解释 |
| OCF 高于净利润 | 强现金模式 | 延付、预收或营运资本释放 | 应付预收、履约义务与可重复性 | 不升级为高质量盈利 |
| 应收/合同资产更快增长 | 客户结构与账期 | 回款质量下降或条件未满足 | 账龄、转应收速度、取消退货 | 削弱收入质量判断 |
| 资本化比例上升 | 真实长期投入 | 当期费用低估 | 项目进度、未来收益、失败样本 | 调整正常化利润 |
| 调整后利润显著更高 | 法定口径受低频扰动 | 核心成本被反复剔除 | 调整频率、现金影响、重复性 | 停止作一次性剔除 |
| 账面现金高 | 流动性充足 | 受限、境外或短债约束 | 受限现金、到期、担保与承诺 | 不形成可用流动性结论 |

### 降级规则

- 口径无法恢复：只输出原始披露，不做趋势比较；
- 调整项无法验证：保留报告口径并标注缺口；
- 现金背离未完成反转验证：写成“现金转换待验证”，不立即定性；
- 反复“一次性”项目：纳入正常成本或给区间；
- 报表可信门失败：同步降级依赖该基线的预测、预期差与估值；
- 资产负债复合压力：转 `BF-RS-01`，本框架只提供基线。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-FQ-01.reported_fact` | 主体、期间、准则与数据版本明确；数字可追溯；重大口径与审计限制已记录 | 只保留不受缺口影响的局部事实，或停止作为事实基线 |
| `BF-FQ-01.normalized_baseline` | `reported_fact` 可用；业务驱动与三表可对账；重大调整项有来源/现金/税务/跨期；明确只是历史还原 | 保留报告口径并标注缺口，或输出区间/多周期情景 |
| `BF-FQ-01.earnings_quality` | 所需 `reported_fact` 与 `normalized_baseline` 已满足；利润现金差异有业务时钟解释；重大资产义务已识别；竞争解释已检查 | 降级为受限质量判断或基线不可用，阻断精确预测/估值 |

高层门槛失败，不抹去已确认的低层事实。精确依赖以登记表为准。

### 6.2 组合与交接

- 商业模式与收入机制：`BF-BM-01`；
- 短中期业绩兑现：`BF-EE-01`；
- 资本配置与减值反馈：`BF-CA-01`；
- 治理与报告动机：`BF-CG-01`；
- 经营预测：`BF-FS-01`；
- 流动性压力：`BF-RS-01`；
- 预期差与估值：`BF-EG-01` / `BF-VA-01`。

报表可信度不足时，下游只能降级，不能用模型假设填补缺失事实。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 关键数字可追溯到原始报表、附注、审计或监管材料；
- 重大利润变化须连接业务驱动；正常化调整须记录来源、现金、税务与跨期；
- 利润与现金差异须连接营运资本与业务时钟；
- 重大资产有使用与可回收依据；重大义务、受限现金与表外承诺须检查；
- 每项进入任务的红旗至少有一个合理竞争解释与区分信号。

具体来源与验收由知识库_03取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的公司、分部、合同、财务相关对象、状态变量、观测、事件与信号。银行、保险、地产等行业专用资产质量问题优先进入领域框架或场景卡。“正常化基线”“现金转换质量”等属框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务验证 |
| 优先样本 | 利润现金背离、资本化争议、周期高点基线、高现金短债等 |
| 重点检查 | 是否只选一条主路线；正常化是否避免机械采用公司调整值；可信门失败是否阻断下游 |
| 经验沉淀 | 行业专用会计问题进场景卡；跨任务重复且有反例边界的规则才写回稳定内核 |

框架更新不以增加指标数量为目标。

## 8. 验收检查

- [ ] 明确本次目标是已报告事实、正常化基线还是盈利质量；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 报告质量与经济结果质量已分开；
- [ ] 法定、扣非、调整后与正常化利润已区分；
- [ ] 经营现金流与自由现金流已区分；
- [ ] 红旗只作为核查入口，没有自动定性；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 报表可信门失败时，没有继续输出精确预测或估值；
- [ ] 财务质量与未来预测、治理、风险和估值职责没有混写。
