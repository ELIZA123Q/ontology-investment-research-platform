# 政策影响框架

## 研究员先看什么

政策研究的重点不是解释文件说了什么，而是先判断当前分歧落在哪一层：

1. **政策是否已经构成可执行约束**：正式文本、权限、适用范围、生效条件和例外是否清楚；
2. **执行是否真正发生**：细则、预算、许可、执法、采购或问责是否把文本转成现实约束；
3. **目标主体是否改变行为**：企业、消费者、金融机构或地方政府是接受、提前、延后、替代、规避还是套利；
4. **行为变化是否改变产业状态**：供需、成本、准入、竞争、技术路线或供应链是否发生可验证变化。

单次任务不应默认把政策文本、执行、产业链、公司业绩、市场预期和估值全部展开。应选择一条主要研究路线，最多保留一条主要竞争路线，并在必要节点失败时停止向后推导。

政策支持方向正确，不等于执行充分；执行充分，不等于目标主体按政策设计响应；主体行为改变，也不等于所有行业和公司同向受益。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断一项政策是否已经形成可执行工具，执行到什么程度，是否改变目标主体行为，以及这种行为变化是否进一步改变目标行业的供需、成本、准入、竞争、技术路线或风险状态。

本框架可以形成：

- 政策事实与适用范围；
- 执行状态及其强弱、时点和覆盖；
- 政策到产业状态之间的候选影响路径。

本框架不直接形成公司收入、利润和现金结论，不判断政策是否形成市场预期差，也不形成估值或资产方向。公司兑现由 BF-EE-01 承接，宏观金融条件由 BF-MF-01 承接，产业链扩散由 BF-VT-01 承接，预期与估值由相应市场定价框架承接。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 政策目标 vs. 可执行工具 | 方向性表述未必包含预算、许可、处罚、采购或其他现实手段 |
| 发布 vs. 生效 vs. 执行 | 三者时间不同，现实主体可能提前或延后反应 |
| 名义适用对象 vs. 实际覆盖对象 | 豁免、绕行、地方差异和执行能力会改变真实覆盖 |
| 执行动作 vs. 主体行为变化 | 有拨付、审批或执法，不代表目标主体一定按设计响应 |
| 行为变化 vs. 产业净影响 | 同期周期、其他政策、技术演进和替代可能产生相同结果 |
| 直接影响 vs. 产业链再分配 | 政策可能只改变利益分配、地域流向或供应链结构，而非总量 |
| 短期抢跑 vs. 持续政策效果 | 生效前提前采购、投资或迁移可能造成阶段性反向波动 |

### 1.3 禁止跳步

- 不能从政策发布直接推出政策已经执行；
- 不能从政策目标或支持性措辞直接推出需求增长或公司受益；
- 不能从补贴、许可或限制存在直接推出主体一定改变行为；
- 不能从主体行为变化直接推出产业净影响，必须考虑替代、规避、转移和同期变量；
- 不能从行业受益直接推出某家公司能够获得订单、收入或利润；
- 不能从政策方向符合市场叙事直接推出形成预期差或资产价格上涨；
- 不能把中央文本、地方执行和企业实际行为视为同一业务时间。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 无法确认正式文本、主管权限、适用对象、生效时间或例外 | `policy_fact` |
| 政策仍停留在倡议、征求意见或无明确工具的方向表述 | `execution_state` 和产业效果 |
| 执行依赖细则、预算、许可或执法，但这些条件无法确认 | 确认性执行判断 |
| 目标主体的行为不可观察，且没有合理代理或反事实 | 行为归因和 `industry_effect` |
| 产业结果与政策的时间、对象或机制无法对齐 | 政策产业归因 |
| 主要对象可通过豁免、规避、替代或地域转移绕开约束，但覆盖无法判断 | 统一方向性产业结论 |
| 同期政策、宏观周期或技术变化足以解释结果，但无法区分 | 净政策影响判断 |

高级输出停止时，已确认的政策事实和执行事实仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 执行兑现** | 政策已经落地，还是仍停留在文本、准备或局部试行 | 市场依据政策标题形成强判断；执行时点、预算、许可或执法存在争议 | 细则、生效条款、预算拨付、名单、许可、采购、处罚、地方配套 | 强执行 vs. 延迟、局部或象征性执行 | 无直接执行证据时，最多确认政策事实和待执行条件 |
| **B 主体响应** | 目标主体会按政策设计改变行为，还是提前、延后、规避、替代或套利 | 执行动作已出现，但产业数据尚未变化；不同主体反应明显分化 | 申报、采购、投资、融资、产能迁移、合规调整、退出与替代 | 真实行为改变 vs. 形式合规或短期抢跑 | 无法观察行为时，不把执行动作外推为产业效果 |
| **C 产业再分配** | 政策改变行业总量，还是只改变地域、主体、产品和链条间的分配 | 政策影响对象多、产业链长，或“谁受益/谁受损”是主要争议 | 订单、价格、产能、份额、贸易流、替代进度、供应链迁移 | 总量变化 vs. 结构迁移、成本转嫁或路径改道 | 不能识别传导边和承接对象时，只保留直接政策影响 |
| **D 政策抵消与持续性** | 政策效果能够持续，还是被退坡、反制、配套不足或其他政策抵消 | 多政策叠加、国际反制、地方执行差异或政策稳定性是关键变量 | 修订、续期、退坡、反制、司法结果、跨地区差异、预算持续性 | 持续效果 vs. 短期冲击、政策抵消或方向逆转 | 交互关系无法区分时，不形成单一政策净影响结论 |

### 路线选择要求

02 调用本框架时必须说明：

1. 本次真正争议的是政策事实、执行、主体行为还是产业净影响；
2. 选择哪条主路线，为什么其他路线不是当前首先要解决的问题；
3. 保留的竞争路线会产生什么不同的可观察结果；
4. 哪些信号能够区分主路线与竞争路线；
5. 某一前置节点失败后，哪些后续分析必须停止；
6. 本次分析止于政策执行、产业效果，还是需要交接其他框架。

四条路线全部展开，通常意味着研究问题没有收敛，或把政策专题误写成完整行业与公司研究。

## 3. 模块菜单

模块是可裁剪能力，不是必须按顺序全部执行的目录。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| PI-C1 政策身份与边界 | 核心 | 每次调用 | 01 已完整固定且无政策版本、地域或对象歧义时可简写 | 政策工具、权限、对象、地域、时点和例外是什么 |
| PI-C2 执行条件 | 核心 | 需要形成 `execution_state` 或更高输出 | 仅确认已生效的简单规则，且执行不依赖预算、许可或地方配套时可简写 | 文本如何成为现实约束 |
| PI-R1 主体行为响应 | 条件 | 需要判断政策是否真正改变行为 | 政策直接机械改变税率、价格或法律状态，且行为中介不是研究重点 | 主体接受、规避、提前、延后还是替代 |
| PI-R2 产业链扩散 | 条件 | 影响跨越多个行业节点、地域或产品 | 政策只影响直接对象，且任务只问直接效果 | 影响在哪些环节被吸收、放大、延迟或改道 |
| PI-R3 覆盖、豁免与绕行 | 条件 | 存在豁免、替代、转口、规避或地方差异 | 覆盖对象和执行范围高度明确且不存在现实绕行 | 名义范围与实际覆盖是否一致 |
| PI-R4 政策交互与反事实 | 条件 | 同期存在其他政策、周期或技术变化；需要做净影响归因 | 任务只确认政策事实或执行状态 | 观察结果是否真正由目标政策导致 |
| PI-E1 公司承接 | 扩展/交接 | 用户要求具体公司影响，且已有产业效果候选 | 任务止于政策或行业层 | 识别需要交给 BF-EE-01 的暴露、资格和承接问题 |
| PI-E2 预期与估值 | 扩展/交接 | 用户明确要求市场预期或估值影响，且上游路径成立 | 任务不涉及资产定价 | 只生成后续研究需求，不在本框架内裁决 |

单次任务必须记录启用与排除模块。模块存在于框架中，不代表自动生成对应取证任务。

## 4. 候选变量、信号与政策时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 法律效力与政策工具 | 政策事实和执行前提 | 政策名称和宣传口径不能代替真实工具 |
| 执行资源 | 执行方向或强度变量 | 预算获批不等于拨付，名单发布不等于完成执行 |
| 适用范围与覆盖 | 前提、分支或强度变量 | 豁免、地方差异、转口和规避可能改变真实覆盖 |
| 主体行为 | 路线区分和中介变量 | 宣布意向、申报和真实投入必须区分 |
| 合规与替代成本 | 强度、分化或反证变量 | 成本可能被价格、补贴、库存或供应商吸收 |
| 产业状态 | 结果或传导验证变量 | 必须与政策对象、时间和反事实对齐 |
| 政策持续性 | 阶段、情景和停止变量 | 任期、预算周期、司法审查和国际反制会改变持续期 |

基础框架不设置跨政策类型的固定权重。02 应从中选择本次真正有判别力的变量，通常不超过 3—5 个。

### 4.2 不同政策工具的候选观察重点

下表只用于帮助选择变量，不构成固定模板。

| 工具类型 | 通常优先观察 | 不足以单独证明效果的信号 |
|---|---|---|
| 补贴、税收、财政支持 | 资格、预算、拨付、申报、实际投资和增量行为 | 政策目标金额、签约或意向 |
| 准入、监管、标准 | 生效范围、审批、检查、处罚、合规调整和退出 | 单次会议、行业倡议或未执行标准 |
| 政府采购 | 采购规则、预算、招标、中标、交付和回款 | 采购口号、入围名单或测试资格 |
| 贸易、关税、出口管制 | 商品与主体范围、许可、豁免、执法、贸易流和替代 | 公告本身、名义税率或未验证的绕行传闻 |
| 货币、信用和金融政策 | 政策工具、市场金融条件、贷款条件和实体融资行为 | 单一政策利率或流动性投放 |
| 价格、配额和行政限制 | 执行价格/配额、实际成交、供给反应、替代和黑市/绕行 | 指导价、名义配额或行政目标 |

货币与信用政策形成行业影响时，应与 BF-MF-01 组合，不由本框架独立完成金融条件传导。

### 4.3 代理变量要求

直接行为或产业结果无法获得时可以使用代理，但必须说明：

- 代理与目标变量之间的政策和业务机制；
- 代理覆盖的对象、地域和业务时间；
- 主体是否可能为了申报、合规或宣传而改变表面数据；
- 代理失效、替代或绕行条件；
- 使用代理后如何降低判断强度；
- 是否有第二类独立证据交叉验证。

政策表态、专家解读、企业口号和新闻转述默认不能作为执行或产业效果的直接代理。

### 4.4 关键政策时钟

只选择本次相关时钟，但不得混用：

`提出/征求意见 → 正式发布 → 生效 → 细则/预算/名单 → 审批/执法/拨付 → 主体决策 → 投资/采购/迁移 → 产业状态 → 公司交付与财务确认 → 修订/退坡/续期`

主体可能在正式生效前抢跑，也可能在执行后长期观望。02 应指出本次最可能造成误判的时间差。

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 政策发布后投资增加 | 政策激励生效 | 原有扩产计划、周期改善或抢跑 | 决策时间、项目增量、资格与拨付、反事实对象 | 不把全部投资归因于政策 |
| 获批、入围或申报增加 | 主体真实响应 | 低成本申报、形式合规或等待套利 | 实际投入、采购、产能、交付和退出成本 | 停止外推为产业需求 |
| 受限产品进口下降 | 政策约束有效 | 需求下降、库存消化、转口或统计迁移 | 最终使用、替代来源、贸易流和库存 | 不直接确认国产替代或供给缺口 |
| 国内订单增加 | 政策推动替代 | 原有周期、价格优势或客户分散采购 | 认证、复购、份额、合同与政策适用对象 | 只保留订单事实，交给行业和公司框架验证 |
| 行业价格上涨 | 政策减少供给或增加需求 | 成本、周期、结构错配或投机 | 成交、供需、库存、覆盖范围和时点 | 不用价格单独证明政策效果 |
| 补贴预算较大 | 执行强度高 | 拨付慢、资格窄、地方配套不足 | 实际拨付、覆盖主体、申报成功率和增量行为 | 降级为政策资源准备状态 |
| 企业完成合规调整 | 政策改变长期行为 | 临时规避、供应链转移或成本转嫁 | 持续投资、合同迁移、退出难度和后续执法 | 不确认长期产业重构 |

### 降级规则

- 只确认正式文本：输出 `policy_fact`，不判断执行；
- 有执行动作但没有主体行为：可判断执行准备或局部执行，不判断产业效果；
- 有主体行为但缺少反事实：形成条件式影响，不做净归因；
- 产业分化明显但无法拆分：分对象列示，不形成统一受益或受损结论；
- 主要证据来自代理、解读或意向：降低强度，并写明代理失效条件；
- 主解释与同期周期、其他政策或技术变化不可区分：03 优先收集区分证据，不继续扩展公司和估值模块；
- 政策存在高概率修订、退坡或反制：只形成期限明确的条件判断。

## 6. 输出门槛、组合与任务裁剪

### 6.1 输出门槛

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-PI-01.policy_fact` | 正式来源可追溯；工具、权限、对象、地域、生效时间和主要例外清楚 | 只记录政策线索或待确认事项，不形成政策事实 |
| `BF-PI-01.execution_state` | 已确认执行所需条件；至少有细则、预算、许可、采购、执法、拨付或其他直接执行证据；区分发布、生效与执行时间 | 只描述执行前提和缺口，不写“政策已落地” |
| `BF-PI-01.industry_effect` | 执行状态可用；至少识别一类目标主体行为变化；有产业状态或受影响主体交叉验证；比较至少一条竞争解释或反事实 | 只保留政策事实、执行状态或主体行为，不形成产业净影响 |

高层门槛失败，不抹去已经成立的低层输出。精确依赖、质量门槛和下游解锁以登记表为准。

### 6.2 组合与交接

- 宏观、货币、信用和金融条件：组合 BF-MF-01；
- 跨节点、跨地域和替代传导：组合 BF-VT-01；
- 供需、价格、竞争和行业结构变化：分别交给 BF-SD-01、BF-PC-01、BF-IC-01；
- 具体公司资格、产能、订单、收入、利润和现金：交给 BF-EE-01；
- 条件预测与政策情景：交给 BF-FS-01；
- 事前预期差：先接 BF-EG-01；
- 估值输入变化：全部必要前提满足后接 BF-VA-01。

单次任务可以止于 `policy_fact` 或 `execution_state`，不要求为了完整而自动进入产业和公司层。

出现以下情况应返工：

- 用政策态度或标题代替行为和产业证据。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 政策事实优先使用正式文本、主管机构说明和法规数据库；
- 执行状态至少需要一类直接执行证据，不得只依赖政策解读；
- 主体行为应尽量使用采购、投资、申报、迁移、合规、退出或交易等现实动作；
- 产业效果至少需要产业数据或多个受影响主体的独立交叉验证；
- 净影响判断必须比较反事实、同期政策、周期和技术变化；
- 关键结论必须记录发布、生效、执行、行为和产业观测的不同业务时间；
- 研究员观点、媒体解读和公司宣传不得冒充政策执行或产业结果。

具体来源、证据组合和验收由知识库_03取证管理。

### 7.2 本体边界

正式任务优先引用一级本体中已有的政策工具、组织、地区、事件、对象、关系、状态变量、观测、假设、信号、情景、判断和推理留痕。

行业专用的许可、配额、认证、替代、合规、贸易流和政策覆盖变量，只有在领域本体正式定义时才作为领域扩展引用。

“执行强度”“实际覆盖”“主体响应”“合规摩擦”“绕行能力”“政策持续性”等属于框架概念或候选状态变量，不因写入本文件自动成为正式本体定义。具体任务仍需完成正式映射、候选记录或缺口登记。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 产业补贴、采购政策、准入监管、出口管制、税收变化等不同工具任务 |
| 重点检查 | 是否明确止于政策事实、执行或产业效果；是否只选一条主路线；是否在主体未响应时停止后续推导 |
| 经验沉淀 | 特定政策工具和行业机制优先进入场景卡或行业框架；跨任务重复且有反例边界的规则才写回稳定内核 |

复盘应记录实际启用路线、长期未使用模块、错误的政策归因、遗漏的规避与替代、执行时钟误判和越界到公司或资产结论的位置。框架更新不以增加篇幅为目标。

## 8. 验收检查

- [ ] 明确本次目标输出是政策事实、执行状态还是产业效果；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 政策目标、可执行工具、发布、生效和执行已经区分；
- [ ] 名义适用对象、实际覆盖、豁免和绕行达到本次判断所需的最小清晰度；
- [ ] 至少验证一个现实执行动作；形成产业效果时，至少验证一个目标主体行为变化；
- [ ] 主解释与周期、其他政策、技术演进或原有计划会产生不同的可观察预测；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 主体未响应或产业结果不可归因时，没有继续推导公司业绩；
- [ ] 涉及公司、预期和估值时，已明确交接其他框架，而不是在本框架内越界完成。
