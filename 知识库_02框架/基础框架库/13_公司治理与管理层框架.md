# 公司治理与管理层框架

## 研究员先看什么

治理研究不是检查董事人数、独立董事比例、委员会设置和制度文本是否齐全，而是回答四个更接近经营现实的问题：

1. **谁拥有真实控制与关键决策权**；
2. **谁从决策中受益并承担风险**；
3. **管理层的重大决策是否能够被重复验证**；
4. **监督与信息机制能否在错误发生前后形成约束和修复**。

最有辨识力的材料通常不是管理层简历或治理承诺，而是重大资本配置、关联交易、激励安排、战略转向、业绩指引、风险处置、关键人变动和治理修复的完整记录。

优先避免五类误判：名义持股不等于真实控制；制度形式齐全不等于监督有效；股权激励不等于长期利益一致；公司业绩好不等于管理层能力强；单次治理事件不等于稳定治理质量。

本框架不预设任何控制结构天然更优。治理优劣必须结合公司阶段、业务复杂度、资本需求、风险承担和历史行为判断。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 真实控制关系、关键决策权、监督权、信息权和利益冲突位置；
- 管理层、控制人、董事和其他资本提供者在收益、期限、损失和风险承担上是否基本一致；
- 通过可追溯重大决策记录，管理层是否展现相对可重复的判断、执行、纠错和资本纪律；
- 治理缺陷如何经激励、信息、监督进入经营、资本、现金或风险结果。

本框架不直接回答：未来收入利润是多少、是否存在具体会计错报、某项资本配置的精确经济价值、风险情景下具体损失，以及治理改善是否必然带来估值或股价提升。这些问题分别由业绩弹性、财务质量、资本配置、风险、预期差和估值框架承接。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 名义所有权 vs. 实际控制 | 持股、投票权、协议控制、提名权、否决权和关键资源控制可能不一致 |
| 结构独立 vs. 行为独立 | 独立董事比例和制度文件只能说明形式；行为独立看信息、异议、否决和整改 |
| 激励金额 vs. 激励方向 | 高薪或持股不自动等于利益一致；须看指标、期限、回拨与下行损失 |
| 管理层结果 vs. 管理层能力 | 业绩可能来自周期、价格、低基数、政策或并购；能力需决策记录验证 |
| 承诺兑现 vs. 可控结果 | 未达目标不等于能力差；达目标也可能因目标过低或行业顺风 |
| 单次事件 vs. 稳定模式 | 一次决策、关联交易或整改通常只能形成事件信号 |
| 治理修复声明 vs. 行为修复 | 换董事、改制度只是起点；须看权限、交易、激励和重复问题是否改变 |

### 1.3 禁止跳步

- 不能从独立董事比例高、创始人持股高或实施股权激励直接推出监督有效或利益一致；
- 不能从履历优秀、业绩优秀或一次承诺兑现直接推出长期能力与可信；
- 不能从出现关联交易直接推出利益输送，也不能因程序合规就排除利益冲突；
- 不能从无监管处罚直接推出内控和信息质量可靠；
- 不能从治理整改公告直接推出风险已解除；
- 不能从治理优劣直接跳到估值、资产价格或交易结论。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 实际控制、投票安排或关键决策权无法识别 | 完整 `governance_structure` |
| 重大交易、激励或决策材料缺失；或只有公司自述 | `incentive_alignment` / `execution_quality` |
| 财务、审计或披露可信度受重大质疑 | 依赖这些数据的执行与资本纪律判断 |
| 单次结果高度受外部因素影响，无法分离；或无法建立事前假设—动作—结果链 | 管理层能力归因 / 可重复决策质量 |
| 只有一次孤立治理事件，没有持续模式 | 稳定治理质量升级 |
| 关联交易缺少定价、独立审批或替代方案信息 | 公平性和利益冲突结论 |
| 治理修复只有制度文本，没有后续行为变化 | 治理风险解除判断 |

高级输出停止时，已确认的结构事实与事件信号仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 控制权与关键决策** | 谁真正拥有控制、否决、任免和资源配置权 | 控制权变化、创始人/国企治理、股权分散、重大交易 | 投票与协议、提名任免、否决权、关联网络、真实决策样本 | 名义控股清晰 vs. 关联方/资源控制者主导 | 无法识别投票、提名与否决时，不形成完整控制判断 |
| **B 激励、利益冲突与资本提供者保护** | 收益、期限和风险是否一致，谁承担下行 | 股权激励、关联交易、质押、稀释、分红、减持 | 考核指标与期限、归属回拨、质押减持、关联交易定价与审批 | 长期绑定 vs. 低门槛套现/实质不公平 | 缺少条款或经济结果时，不做激励一致性升级 |
| **C 管理层决策与执行质量** | 好结果来自能力还是外部顺风，决策是否可重复 | 战略转型、扩产并购、产品路线、指引兑现、危机处置 | 事前假设、投入与进度、指引记录、纠错退出、外部贡献拆分 | 能力强 vs. 行业顺风/目标保守/口径变化 | 无事前与事后记录时，不做能力归因 |
| **D 监督、信息、继任与治理修复** | 制度是否真正约束行为，组织能否持续运行 | 审计内控、董事会有效性、关键人离任、继任、治理整改 | 异议与问责、内控整改、重复问题、继任交接、修复后行为变化 | 真实修复 vs. 形式合规；关键人风险 vs. 团队可延续 | 修复无行为验证或继任信息不可得时，不解除风险 |

### 路线选择要求

02 调用本框架时必须说明：本次主要治理分歧对应哪条路线；为什么其他路线不是当前主线；保留的竞争路线会产生什么不同预测；哪些信号能区分两条路线。若真正问题是财务错报、资本回报、流动性或估值，应转交相应框架。四条路线全部展开，通常说明问题范围过宽。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| CG-M1 实际控制与关键决策权 | 核心 | 每次调用 | 已有可信控制图且本次不涉及控制变化时可简化 | 谁能决定和阻止关键事项 |
| CG-M2 关键决策样本与历史记录 | 核心 | 评价管理层或治理有效性 | 只做静态结构描述时可不启动完整记录 | 连接治理安排与真实行为及结果 |
| CG-M3 董事会、监督和信息获取 | 条件 | 重大交易、利益冲突、危机或监督问题 | 监督与本次关键决策无关 | 形式安排是否改变行为 |
| CG-M4 激励与真实风险承担 | 条件 | 股权激励、短期考核、质押、减持或激励错配疑问 | 激励不会改变本次决策或风险承担 | 收益、期限和损失是否一致 |
| CG-M5 关联交易与资本提供者保护 | 条件 | 关联交易、担保、资金占用、稀释或资产转移 | 无利益冲突或交易不重大 | 公平性、程序和经济结果 |
| CG-M6 披露、审计和内部控制 | 条件 | 信息可信度、会计或风险报告受质疑 | 已由 BF-FQ-01 完整承接时可只引用 | 信息和监督基础是否可靠 |
| CG-M7 管理层能力与执行 | 条件 | 研究战略、资本配置、产品路线或指引兑现 | 缺少事前和事后记录 | 区分能力、运气、顺风和执行偏差 |
| CG-M8 继任、关键人与治理修复 | 条件 | 关键人集中、管理层变动、处罚整改或制度修订 | 关键人不构成关键能力，或无历史问题需验证 | 持续经营、交接与真实修复 |

单次任务通常选择 1—3 项最能体现真实决策权、激励、监督和纠错能力的决策样本，不做治理全景扫描。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 控制与权力 | 谁真实控制关键决策 | 只看第一大股东持股比例会漏协议与资源控制 |
| 监督与信息 | 监督是否具有独立判断和行动能力 | 只看独立董事比例 |
| 激励与风险 | 奖励方向和下行风险承担 | 只看激励金额或持股数量 |
| 利益冲突 | 谁受益、谁承担风险、是否有替代方案 | 出现关联交易就自动定性 |
| 决策与执行 | 判断和执行是否可重复 | 用公司结果直接替代决策归因 |
| 信息质量 | 决策依赖的信息是否可靠 | 无处罚就判断透明度高 |
| 组织继任与修复 | 关键能力能否持续；缺陷是否真实改善 | 披露继任计划或整改公告即视为完成 |

02 应从中选择本次真正有判别力的变量，通常不超过 3—5 个。

### 4.2 代理变量要求

制度文本、治理评分、媒体评价和管理层声誉默认不是监督有效或执行质量的无条件代理。使用代理时必须说明机制、失效条件与强度降级。

### 4.3 关键时钟

只选择本次相关的时钟：

`控制权变化 → 激励授予/归属/减持 → 战略决策与投入 → 财务确认与现金影响 → 监督整改与验证 → 继任交接 → 风险处置与复盘`

尤其要区分“制度建立”“行为改变”和“结果验证”三个时间点。

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 公司长期高增长 / 指引连续兑现 | 战略与执行优秀 / 计划能力强 | 行业顺风、并购、低基数 / 目标保守、口径变化 | 外部贡献拆分、事前难度、可控部分 | 停止能力升级 |
| 创始人长期控制 / 独董比例高 | 长期主义与快速决策 / 监督有效 | 利益冲突与接班风险 / 信息受限、形式独立 | 否决与异议记录、信息获取、冲突交易 | 切换到制衡不足或形式监督 |
| 股权激励规模大 | 利益一致 | 低门槛、短期限、稀释、质押减持削弱 | 指标期限、回拨、真实损失 | 切换到真实风险承担路径 |
| 关联交易增加 / 大额回购分红 | 利益输送风险 / 股东导向 | 正常协同或市场化交易 / 缺投资机会、借债返还、抵消稀释 | 定价替代方案、审批、经济结果；融资与稀释 | 按实质公平性或返还质量判断 |
| 治理整改完成 / 危机后恢复较快 | 风险已解除 / 风险管理有效 | 形式合规、问题未验证 / 外部救助或行业共振 | 权限激励交易是否改变；救助与资源来源 | 不解除风险或降低能力归因 |
| 管理层频繁调整 | 组织不稳定 | 正常升级、问责或继任推进 | 变动原因、继任与后续执行 | 按原因分支，不直接定性 |

### 降级规则

- 只有股权比例：降级为名义所有权事实；
- 缺少协议、任免和真实决策：不得形成实际控制完整判断；
- 缺少信息和监督行为：不得形成治理有效性判断；
- 业绩无法分离外部顺风：只保留结果事实，不做能力归因；
- 修复无行为变化：只保留修复动作及待验证节点；
- 主解释与竞争解释暂不可区分：03 只优先收集区分信号。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-CG-01.governance_structure` | 主要所有权与投票安排；任免与重大事项权限；关键协议/关联方/特殊权利；至少一项真实决策验证；信息与监督安排 | 只保留名义股权和公开制度事实 |
| `BF-CG-01.incentive_alignment` | 完整激励条款、指标、期限与归属；真实受益与下行损失；重大冲突交易或资本动作的程序与经济结果 | 只描述激励事实，不做一致性升级 |
| `BF-CG-01.execution_quality` | 1—3 项决策样本含事前假设、动作与事后结果；外部贡献可分离或明确不可分离；纠错/退出/问责记录可观察 | 只保留事件级观察，不做可重复能力判断 |

更高一层写不出来时，已经成立的更弱结论仍可保留。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 6.2 组合与交接

- 报表、审计与内控可信度：交 BF-FQ-01；
- 短中期收入利润现金兑现：交 BF-EE-01；
- 扩产并购回购分红是否创造价值：交 BF-CA-01；
- 关键人、流动性或治理冲击压力：交 BF-RS-01；
- 治理变化进入经营路径：交 BF-FS-01；预期差与估值：交 BF-EG-01、BF-VA-01。

本框架不以“管理层优秀”替代经营预测，不以“治理改善”替代资本回报验证，也不从治理事件直接推出资产价格。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 控制至少连接股权/投票与任免、否决或真实决策中的一层；
- 激励至少核对条款与真实兑现/损失路径；
- 执行质量必须有事前假设与事后结果，不能只有结局叙事；
- 修复判断必须观察行为变化，不能只看公告；
- 公司自评、治理评分和媒体评价不得冒充行为证据。

具体来源与验收由知识库_03取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的公司、事件、状态变量、观测、假设、信号和情景。“实际控制”“激励一致性”“执行质量”等属于框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 创始人控制争议、指引兑现归因、关联交易、治理整改验证、关键人继任 |
| 重点检查 | 是否只选一条主路线；是否用制度合规替代行为验证；是否越界到估值 |
| 经验沉淀 | 行业特殊治理机制优先进入行业框架或场景卡；跨任务重复且有失效边界的机制才写回稳定内核 |

## 8. 验收检查

- [ ] 明确本次要判断的是治理结构、激励一致性还是执行质量；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 名义所有权与实际控制、结构独立与行为独立已经区分；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 至少有 1—3 项关键决策样本，或明确为何只需结构描述；
- [ ] 主解释和竞争解释会产生不同的可观察预测；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 没有用制度文本、声誉或短期业绩替代治理有效性证据；
- [ ] 没有从治理直接推出估值或交易结论；
- [ ] 特殊行业机制优先放入行业框架或场景卡，而不是写成跨行业固定规则。
