# 错误产物校准集（建设中）

本目录测的是**评分机制**，不是生产能力。

> 若人为构造的错误产物仍大量被评为「通过」，问题在评分器/评分标准，不在生产方法。

## 建议至少 6 份构造物

| ID | 错误类型 | 预期评分结果 |
|---|---|---|
| ERR-01 | 终点正确，但核心证据不存在 | 不通过（证据失败/硬失败） |
| ERR-02 | 文章好看，但结论方向错误 | 不通过（走错终点或轮廓外） |
| ERR-03 | 证据正确，但判断强度越级 | 不通过或至少明显问题→不通过 |
| ERR-04 | 主路径成立，但遗漏决定性反证 | 不通过（反证硬失败） |
| ERR-05 | 历史回放混入截止日后信息 | 不通过（截止日穿越） |
| ERR-06 | 冲突证据下强行单边结论 | 不通过（应争议却确认） |

## 用法

1. 评分者只拿产物 + 对应任务的「任务输入」与「评审参考」（或本校准题专用卡）。  
2. 不得提前告知“这是错误产物”。  
3. 若 ERR 组仍高比例“通过”，先修 `02_指标定义.yaml` 与记分纪律，再谈生产改进。
