# 盲测集（建设中）

本目录用于**真正盲测**，与 `01_标准任务卡/` 回归集分开。

## 目的

测量方法在**未参与开发、未从优秀产物反推**的新任务上的表现。  
回归集（尤其 T01/T02）的通过率**不能**当作盲测准确率。

## 规则

1. 生产阶段只提供「任务输入」。  
2. 评分结束后才打开「评审参考」。  
3. 运行记录须能证明生产者未接触：预期终点、必须出现的关键证据、禁止表达、参考结论。  
4. 评分须 `independence_status=independent`（或至少独立于生产者）。  

## 建议规模

先做 **6—8** 张新题，覆盖：成立/条件成立/争议/阻断或暂不可判断/01退回 中的多数终点。
