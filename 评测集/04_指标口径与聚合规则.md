# 04 指标口径与聚合规则

## 1. 总体输出纪律

正式报告分别输出 `R`、`U`、`delta`、`S`、`C`，不合成综合分。硬错误、任务表现、评测分歧和支持频率分别报告。

## 2. R：研究判断可靠性

### 2.1 等级定义

| 等级 | 定义 |
|---|---|
| `R0` | 核心事实错误、无证据主结论、时间穿越、主结论强度越级，或应争议/弃答却强行确认 |
| `R1` | 证据或推理路径明显不足，只能作为待验证假设 |
| `R2` | 方向得到支持，但量化、范围、独立来源或反证仍有限制 |
| `R3` | 核心事实、最低证据组合、推理路径和反证均通过，表达不超过证据上限 |

### 2.2 硬错误门槛

以下任一问题出现时，该次判断强制为 `R0`：

- 核心事实错误；
- 无来源核心判断；
- 主结论强度越级；
- 使用信息截止日之后的材料；
- 应保留争议或弃答却写成确定结论；
- 明确决定性反证被忽略。

### 2.3 从判断到案例

对每个评测模型与种子的组合：

1. 仅选 `criticality: primary` 的核心判断；
2. 对每条判断应用硬错误门槛；
3. 该次案例 `R` 取所有主要判断的最低等级。

### 2.4 六次聚合

两个评测模型各运行三次，得到六个案例等级。案例最终 `R` 取保守中位数（偶数样本取较低中位数）。

### 2.5 案例级：裁决支持频率

```text
裁决支持频率 = 六次裁决中 R>=R2 的次数 ÷ 6
```

亦称 `R通过频率` / `跨评测运行支持率`。

**禁止**称为“代理可靠概率”或“可靠概率”。这六次共享同一产物、同一证据包与基本相同标准，主要测量评测器一致支持程度，与 `S` 存在重叠；不是该研究判断在现实中可靠的概率。

案例级**不报告** Wilson 区间，避免伪精确性。

只有整体和两个评测模型分别达到 `C2` 时才展示该频率。

### 2.6 案例集级：代理可靠率

```text
代理可靠率 = 某分层中最终R达到R2以上的案例数 ÷ 该层有效案例数
```

同时报告 R 等级分布。案例数不足约 20—30、或案例差异性不足时，只报告比例与分布，不报告区间。四题试点不得把分层比例外推为“系统研究可靠率”。

## 3. U：任务有用性

### 3.1 四项任务阈值（pilot_threshold）

| 任务 | 试点阈值 | 附加要求 |
|---|---:|---|
| 核心判断复述 | 0.85 | 明显误读率低于 10% |
| 五项跟踪计划 | 0.80 | 对象、指标、来源、频率和改判含义齐全 |
| 新信息更新 | 0.75 | 更新方向与密封场景一致 |
| 调研问题设计 | 0.80 | 可执行且能区分竞争解释 |

这些数值是**试点阈值**，仅用于方案比较和运行阻断。不得把 0.79 / 0.80 解释为已经过试验验证的硬分界。积累分布后再确定正式阈值。

得分来自独立下游评分模型，不接受执行模型自评分。

### 3.2 等级聚合

| 等级 | 规则 |
|---|---|
| `U3` | 四项任务均通过，且无致命误读 |
| `U2` | 三项任务通过，且无致命误读 |
| `U1` | 一至两项任务通过 |
| `U0` | 无任务稳定通过，或出现致命/明显误导 |

案例 `U` 以 D 组平均任务表现计算。A/B/C/E 用于基线与诊断。

## 4. delta：相对增益

`delta` 不转换为单一等级。主证据是 D 相对同证据基线的表现。

### 4.1 任务得分变化

```text
任务增益（百分点） = D 组四项任务平均分 - 对照上下文四项任务平均分
```

分别报告：

- 相对同证据直接生成（上下文 C，主对比）；
- 相对原始材料（上下文 B，诊断）；
- 相对仅问题（上下文 A，弱基线）。

### 4.2 错误降低率

```text
错误降低率 = (基线错误均值 - D 组错误均值) ÷ 基线错误均值
```

主对比至少报告 D 相对同证据直接生成（C）的错误降低。基线错误为零时记为 0 并在诊断中解释。

摘要稿以盲评胜率为主对比；若未单独设置摘要下游上下文，不得把原始材料组错误降低误标为“相对摘要稿”。

### 4.3 成对盲评胜率

每个主对比基线进行六次盲化比较：

```text
D 胜率 = (D 获胜次数 + 0.5 × 平局次数) ÷ 有效比较次数
```

胜率可附 Wilson 90% 区间，但须理解为重复评测频率，不是独立案例抽样。

### 4.4 首版增益门槛（pilot_threshold）

- D 相对同证据直接生成稿胜率至少 55%；
- D 相对证据摘要稿胜率至少 55%；
- D 相对同证据直接生成的任务净增益为正；
- D 相对同证据直接生成的总错误率没有上升。

这些门槛分别显示通过与否，不汇总为“delta 分数”。问题直答胜率/增益不得写入主证据门槛。

## 5. S：稳定性

| 指标 | 计算 |
|---|---|
| R 等级一致率 | 六次案例 R 中占比最高等级的频率 |
| 下游任务通过一致率 | 四项任务在六次评分中的通过/不通过众数比例均值 |
| 候选顺序效应 | D 在前与 D 在后时的平均胜率差，两个主基线取均值 |
| R 最大跨度 | 六次 R 的最高等级减最低等级 |

| 等级 | 规则 |
|---|---|
| `S3` | R 与下游主要一致率均至少 80%，顺序效应不高于 10%，R 跨度不超过一级 |
| `S2` | R 一致率至少 65%，下游一致率至少 70%，顺序效应不高于 20%，且不存在 R0/R3 对立 |
| `S1` | 未达到 S2，存在明显模型、提示或顺序敏感性 |
| `S0` | R 跨度达到三级，或 R 与下游结果都接近不可复现 |

S 不是研究质量分。`R2/S1` 表示方向性支持但稳定性不足。

## 6. C：评测可信度

### 6.1 基础指标

严重缺陷召回率、正常版错杀率、排序准确率、缺陷定位准确率、严重度准确率、裁决一致率、扰动敏感率。

### 6.2 等级规则（pilot_threshold）

| 等级 | 规则 |
|---|---|
| `C3` | 召回≥90%，错杀≤10%，排序≥90%，定位/严重度/一致性/敏感率均≥80% |
| `C2` | 召回≥80%，错杀≤20%，排序≥80%，定位/严重度/一致性/敏感率均≥70% |
| `C1` | 召回和敏感率至少 60%，但不足以支持正式案例集层解释 |
| `C0` | 低于 C1，或评测隔离失效 |

分界为试点阈值。任一模型或整体低于 C2，正式流程阻断。

## 7. 诊断项

可靠性诊断、有用性诊断、流程诊断、输出诊断（最弱核心判断、最强反证、主要分歧、密封独立性、适用边界）不独立形成总分。

## 8. 固定报告结构

每个案例至少输出：

```text
研究判断可靠性：R0—R3
裁决支持频率：点估计（非可靠概率），或因C不足而抑制
任务有用性：U0—U3（pilot_threshold）
相对同证据直接生成稿：任务增益、错误降低率、盲评胜率
相对证据摘要稿：盲评胜率
相对仅问题弱基线：任务增益（诊断）
稳定性：S0—S3
评测可信度：C0—C3
密封契约独立性、硬错误、最弱核心判断、最强反证、主要分歧、适用边界
```

分层汇总另输出：R/U 分布、案例集层代理可靠率（仅比例）、主基线胜率均值。
