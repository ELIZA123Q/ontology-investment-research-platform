# 04 指标口径与聚合规则

## 1. 总体输出纪律

正式报告分别输出 `R`、`U`、`delta`、`S`、`C`，不合成综合分。硬错误、任务表现、评测分歧和置信区间分别报告。

## 2. R：研究判断可靠性

### 2.1 等级定义

| 等级 | 定义 |
|---|---|
| `R0` | 核心事实错误、无证据主结论、时间穿越、主结论强度越级，或应争议/弃答却强行确认 |
| `R1` | 证据或推理路径明显不足，只能作为待验证假设 |
| `R2` | 方向得到支持，但量化、范围、独立来源或反证仍有限制 |
| `R3` | 核心事实、最低证据组合、推理路径和反证均通过，表达不超过证据上限 |

### 2.2 硬错误门槛

以下任一问题出现时，该次判断强制为 `R0`，不允许被其他优点抵消：

- 核心事实错误；
- 无来源核心判断；
- 主结论强度越级；
- 使用信息截止日之后的材料；
- 应保留争议或弃答却写成确定结论；
- 明确决定性反证被忽略。

### 2.3 从判断到案例

对每个评测模型与种子的组合：

1. 仅选 `criticality: primary` 的核心判断；
2. 对每条判断应用硬错误门槛；
3. 该次案例 `R` 取所有主要判断的最低等级。

因此，一份报告不能用多个容易判断的次要观点掩盖一个不可靠的主结论。

### 2.4 六次聚合

两个评测模型各运行三次，得到六个案例等级。案例最终 `R` 取保守中位数：

- 将等级映射为 `R0=0`、`R1=1`、`R2=2`、`R3=3`；
- 从小到大排序；
- 六个值取第三个值，即偶数样本的较低中位数。

### 2.5 代理可靠概率

定义成功为单次案例裁决 `R>=R2`：

```text
代理可靠概率点估计 = 六次裁决中 R>=R2 的次数 ÷ 6
```

同时报告 Wilson 90% 区间。设成功数为 `x`、总次数为 `n`、90% 双侧临界值为 `z=1.64485`：

```text
p = x / n
center = (p + z²/(2n)) / (1 + z²/n)
margin = z × sqrt((p(1-p) + z²/(4n))/n) / (1 + z²/n)
区间 = [center - margin, center + margin]
```

只有整体和两个评测模型分别达到 `C2` 时才展示该概率。名称必须写“代理可靠概率”，不得写“正确率”。

## 3. U：任务有用性

### 3.1 四项任务阈值

| 任务 | 通过阈值 | 附加要求 |
|---|---:|---|
| 核心判断复述 | 0.85 | 明显误读率低于 10% |
| 五项跟踪计划 | 0.80 | 对象、指标、来源、频率和改判含义齐全 |
| 新信息更新 | 0.75 | 更新方向与密封场景一致 |
| 调研问题设计 | 0.80 | 可执行且能区分竞争解释 |

得分来自独立下游评分模型，不接受执行模型自评分。

### 3.2 等级聚合

| 等级 | 规则 |
|---|---|
| `U3` | 四项任务均通过，且无致命误读 |
| `U2` | 三项任务通过，且无致命误读 |
| `U1` | 一至两项任务通过 |
| `U0` | 无任务稳定通过，或出现致命/明显误导 |

案例 `U` 以 D 组，即“问题与系统最终允许产物”的平均任务表现计算。A/B/C/E 只用于基线和诊断。

## 4. delta：相对增益

`delta` 不转换为单一等级，分别报告三类结果。

### 4.1 任务得分变化

```text
任务增益（百分点） = D 组四项任务平均分 - 基线组四项任务平均分
```

分别计算 D 相对 A、B、C 的百分点变化。

### 4.2 错误降低率

评分模型分别记录事实错误、推理错误和错误外推，并计算总错误：

```text
错误降低率 = (基线错误均值 - D 组错误均值) ÷ 基线错误均值
```

分别报告 D 相对 B 和 C 的事实、推理、外推及总错误降低率。基线错误为零时不制造无穷增益，结果记为 0 并在诊断中解释。

### 4.3 成对盲评胜率

每个基线进行六次盲化比较：

```text
D 胜率 = (D 获胜次数 + 0.5 × 平局次数) ÷ 有效比较次数
```

胜率同时报告 Wilson 90% 区间。

### 4.4 首版增益门槛

- D 相对直接生成稿胜率至少 60%；
- D 相对证据摘要稿胜率至少 55%；
- D 相对直接生成稿的任务净增益为正；
- D 相对 B/C 的总错误率没有上升。

这些门槛分别显示通过与否，不汇总为“delta 分数”。

## 5. S：稳定性

S 使用四个侧面指标：

| 指标 | 计算 |
|---|---|
| R 等级一致率 | 六次案例 R 中占比最高等级的频率 |
| 下游任务通过一致率 | 四项任务在六次评分中的通过/不通过众数比例均值 |
| 候选顺序效应 | D 在前与 D 在后时的平均胜率差，两个基线取均值 |
| R 最大跨度 | 六次 R 的最高等级减最低等级 |

### 5.1 等级规则

| 等级 | 规则 |
|---|---|
| `S3` | R 与下游主要一致率均至少 80%，顺序效应不高于 10%，R 跨度不超过一级 |
| `S2` | R 一致率至少 65%，下游一致率至少 70%，顺序效应不高于 20%，且不存在 R0/R3 对立 |
| `S1` | 未达到 S2，存在明显模型、提示或顺序敏感性 |
| `S0` | R 跨度达到三级，或 R 与下游结果都接近不可复现 |

S 不是研究质量分。`R2/S1` 表示方向性支持但稳定性不足，不能被写成高置信结论。

## 6. C：评测可信度

### 6.1 基础指标

| 指标 | 定义 |
|---|---|
| 严重缺陷召回率 | critical 缺陷中，正确识别且类别正确的比例 |
| 正常版错杀率 | 无缺陷正常版本被判为严重失败的比例 |
| 排序准确率 | 正常版被排在对应缺陷版之前的比例 |
| 缺陷定位准确率 | 返回位置与预设注入位置一致的比例 |
| 严重度准确率 | 返回严重度与预设严重度一致的比例 |
| 裁决一致率 | 同一缺陷重复运行时，识别、类别、位置、严重度和排序结果的一致率 |
| 扰动敏感率 | 评测器更新动作与预设扰动方向一致的比例 |

### 6.2 等级规则

| 等级 | 规则 |
|---|---|
| `C3` | 召回≥90%，错杀≤10%，排序≥90%，定位/严重度/一致性/敏感率均≥80% |
| `C2` | 召回≥80%，错杀≤20%，排序≥80%，定位/严重度/一致性/敏感率均≥70% |
| `C1` | 召回和敏感率至少 60%，但不足以支持正式概率解释 |
| `C0` | 低于 C1，或评测隔离失效 |

每个评测模型单独计算 C，整体再计算一次。任一模型或整体低于 C2，正式流程阻断。

## 7. 诊断项

以下内容不独立形成总分：

- 可靠性诊断：事实准确、证据支撑、来源独立、推理成立、反证处理、判断强度；
- 有用性诊断：问题保持、信息压缩、跟踪可执行、新信息更新、调研问题质量；
- 流程诊断：终点命中、截止日遵守、模型角色隔离、盲化完整性；
- 输出诊断：最弱核心判断、最强反证、主要分歧、适用边界。

## 8. 固定报告结构

每个案例至少输出：

```text
研究判断可靠性：R0—R3
代理可靠概率：点估计 + Wilson 90%区间，或因C不足而抑制
任务有用性：U0—U3
相对直接生成稿：任务增益、错误降低率、盲评胜率及区间
相对证据摘要稿：任务增益、错误降低率、盲评胜率及区间
稳定性：S0—S3
评测可信度：C0—C3
硬错误、最弱核心判断、最强反证、主要分歧、适用边界
```

报告必须注明运行模式。`development/mock` 结果只能用于验证框架，不得作为真实系统表现发布。
