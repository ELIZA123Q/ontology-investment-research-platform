# A01 状态判断

## 方法定位

> **一句话哲学：状态判断不是寻找数据，而是确定对象当前真实处于哪个状态。**

A01 回答：在指定时点、对象、范围和口径下，目标变量相对于适当基线处于高、低、紧、松、正常、异常还是结构分化状态。

状态判断不是复述一个数值，也不回答：

- 该状态是否会持续——进入 A02；
- 对象处于哪个阶段——进入 A03；
- 状态为什么形成——进入 A05；
- 状态会产生什么经营或投资影响——进入 A08—A10。

使用本方法前，除 A00 共用材料外，02 还必须事先定好状态变量、比较基线、状态门槛、覆盖与聚合规则；若用代理指标，须说明用什么代理、能说明到哪。

## 判断模型与停止点

A01 的判断思路是“基线—测量—聚合”：

```text
固定状态命题
→ 选择回答该命题的基线
→ 对齐真实变量与观测口径
→ 判断观测支持到哪一层
→ 汇总总体、局部与分化
→ 写出当前状态及其边界
```

状态不是绝对属性。相同库存水平相对于历史正常区间可能偏低，相对于安全线可能正常，相对于同行又可能偏高。基线不同，回答的是不同问题，不能混用。

A01 停在当前或历史截面的状态及结构，不外推趋势、原因、阶段和结果。

## 方法特有判断原则

本方法重点防范：[CE02](A00-附录4_通用认知错误与误用索引.md#ce02-相邻判断类型偷换)、[CE03](A00-附录4_通用认知错误与误用索引.md#ce03-代理替代真实变量)、[CE04](A00-附录4_通用认知错误与误用索引.md#ce04-未观测替代零或未发生)、[CE05](A00-附录4_通用认知错误与误用索引.md#ce05-单点局部或幸存样本外推总体)。

### 1. 先固定状态命题

状态命题必须明确：

```text
对象 + 时点 + 范围 + 状态变量 + 比较基线 + 待判断状态
```

“行业景气较好”不可判断；“截至某时点，中国渠道 DRAM 库存相对过去三年同季正常区间是否偏低”才是合格命题。

### 2. 基线必须匹配问题

可用基线包括历史正常区间、业务安全线、同类对象、计划/产能基线或事件前基线。02 必须说明基线为何适用。

若多个合理基线给出不同状态，应分别报告，不得选择最有利者。例如：

> 相对历史区间偏高，但相对当前订单覆盖的安全库存线仍偏低。

### 3. 区分真实变量、直接观测和代理

| 观测层 | 允许怎么说 |
|---|---|
| 真实变量被直接、同口径观测 | 可判断目标状态 |
| 直接业务变量覆盖目标状态的主要部分 | 可形成有限范围状态判断 |
| 代理对应关系清楚且经过验证 | 只能在代理边界内表达 |
| 弱代理、单点或口径不清 | 只报告观测或保留 J0/J1 |

数据未披露记未知，不得记零或“没有发生”。

### 4. 复合状态变量不得临时加权

一个状态由多个指标联合构成时，02 必须事先定义：

- 组成指标及其真实含义；
- 必要项与支持项；
- 怎么汇总、权重或优先级；
- 冲突、缺失和不可比时如何处理；
- 什么条件支持总体状态，什么条件只能支持结构分化。

A01 只按规定执行。必要指标冲突、汇总规则缺失或合理权重导致标签反转时，应输出“结构分化”或“暂不可判断”，不得事后平均或重设权重。

### 5. 总体结论受覆盖和分化约束

总体状态成立前，须检查产品、地区、客户、渠道、主体和数据覆盖。总体、局部、结构分化是不同结论：

- 主要分项同向且覆盖充分，才可形成总体状态；
- 变化集中在少数分项，只能形成局部状态；
- 关键分项方向相反，优先输出结构分化；
- 样本无法代表总体时，限定样本范围。

本方法特有误判：把价格上涨当作供给紧张状态。价格可能受成本、预期或渠道行为影响，不能替代库存、交期和订单等目标状态变量。

## 判断流程

1. 固定对象、时点、范围、状态变量、基线和状态词；
2. 核对单位、业务时间、数据版本、样本和分母；
3. 判断材料是目标变量、直接观测还是代理，并应用其上限；
4. 按 02 规则处理复合变量的必要项、支持项、汇总和冲突；
5. 检查总体覆盖、局部异常、未知值和结构分化；
6. 用最强反向观测检验状态标签、范围或把握是否需要收窄；
7. 形成总体、局部、结构分化、仅报告观测或暂不可判断结论。

## 裁决与输出增量

| 证据与结构 | 状态结论 | 这句话最多能说到哪 |
|---|---|---|
| 目标变量直接观测、基线匹配、覆盖充分 | 总体状态 | 可确认当前/历史状态本身 |
| 只有部分对象或环节满足 | 局部状态 | 限定对象和范围 |
| 关键分项方向相反 | 结构分化 | 分项表达，不给单一总体标签 |
| 代理有效但覆盖有限 | 代理支持的状态 | 明示代理和使用边界 |
| 只有单点、弱代理或基线不稳 | 仅报告观测 | 不贴强状态标签 |
| 必要指标冲突或汇总规则缺失 | 暂不可判断 | J0/J1，列区分信号 |

除 A00 七项通用输出外，A01 还要额外写清：

| 额外要写清 | 内容 |
|---|---|
| 状态命题 | 状态变量、基线和待判断状态 |
| 测量层级 | 真实变量、直接观测或代理 |
| 汇总结果 | 总体、局部、结构分化或不可汇总 |
| 复合变量记录 | 必要项、冲突项及所用汇总规则 |
| 覆盖说明 | 已覆盖范围、未知范围与不可外推部分 |

## 边界与退回

- A01 最高可到 J4，但只确认当前/历史状态本身，不因此自动支持趋势、阶段、因果或前瞻。
- 若待回答的是持续方向，进入 A02；阶段位置进入 A03；原因进入 A05；经营或财务意义进入 A08。
- 状态变量、基线、门槛、复合指标或汇总规则未定义，按 A00 退回框架（02）。
- 序列或样本口径不可比、代理未经确认可用、关键分项可补，退回取证（03）。
- 多个合理基线或复合指标持续冲突且无法按既定规则处理，保留分化或 J0/J1，不强行收口。

## 例与误判

**合格例：** 截至季度末，渠道库存低于过去三年同季正常区间，原厂库存仍在正常范围，主要地区覆盖完整。结论为“下游渠道库存偏低、上游库存正常的结构分化状态”，不外推为全行业供给紧张或上涨趋势。

**高迷惑性反例：** “价格连续上涨，所以行业库存很低。”

问题在于价格是结果变量，不能直接代理库存；同时把趋势信号偷换成状态，并从价格局部观测外推全行业，分别触发 CE03、CE02 和 CE05。
