# 半导体周期与库存框架

## 研究员先看什么：先找时钟错位，再用组合表定解释

```text
真实消耗 → 订单/取消单 → 分层库存 → 现货/合约/实现价
→ 稼动与投片 → 资本开支 → 合格供给释放
```

DRAM、NAND、HBM、逻辑、模拟、功率、代工、封测不得用同一总量阶段。负责：分项周期、驱动与切换候选。不负责：内容量来源、公司业绩。终端来源不清先读 IF-APP-01。

## 1. 适用边界与核心分歧

必须固定产品规格、客户层级、库存位置、价格口径、地域与时间窗。核心分歧：哪只时钟先转；订单性质；领先信号是否足以切换。候选：`segmented_cycle_state` 去库后段 / 早期复苏 / 主动补库 / 广泛扩张 / 高位分化 / 下行切换 / 暂不可判断；`phase_driver`、`phase_switch` 详见登记表对应输出层。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

## 2. 特有机制、关键环节与关键时钟

| 关键环节 | 必须回答 | 典型错位 |
|---|---|---|
| 分项状态 | 同口径产品/客户 | 高端强写成全面复苏 |
| 消耗与订单 | 真实消耗 vs 补库/抢货 | 订单领先但取消单升 |
| 分层库存 | 原厂/渠道/客户是否同向 | 原厂去库渠道累库 |
| 价格确认 | 现货—合约—实现价扩散 | 现货涨合约不动 |
| 生产与供给 | 稼动是否转合格供给 | 扩产公告早于供给 |

## 3. 洞见层：阶段切换对照

| 信号组合 | 更可能解释 | 暂不能说明 |
|---|---|---|
| 订单↑库存↓合约价↑消耗↑ | 真实复苏 | 是否已入供给扩张后段 |
| 订单↑现货↑渠道库存↑合约不动 | 抢货/重复下单 | 全面复苏 |
| 稼动↑价格弱库存↑ | 备货或低价抢单 | 需求改善 |
| 价格斜率↓库存仍低消耗稳定 | 高位放缓 | 已经反转 |
| 投片↑良率↑订单能见度↓ | 供给提前释放 | 需求立即下行 |
| 消耗稳、合约坚、现货回落 | 结构性分化或库存再平衡 | 周期全面结束 |

领先：取消单、分层库存拐点、现货斜率；同步：合约/实现价；滞后：稼动、合格供给。利润池：涨价段原厂/产品组合主导者；跌价段库存高、技术落后产线先受损。反常：现货与合约持续背离、两层库存反向。

最低证据：同口径消耗；订单取消交叉；两层库存；分价格口径；投片/合格供给代理。

## 4. 竞争解释、候选反证与停止条件

| 解释 | 区分预测 | 主要候选反证 |
|---|---|---|
| 主解释：真实消耗驱动复苏 | 消耗订单库存价格依次改善 | 终端不动渠道库存升 |
| 竞争解释：抢货/重复下单 | 订单现货先、合约库存不确认 | 合约跟随且库存降 |
| 竞争解释：被动累库误作补库 | 出货在、消耗弱、天数升 | 消耗恢复库存健康 |
| 竞争解释：供给收缩推价 | 价升订单利用不扩散 | 消耗订单同步增强 |

口径混杂、缺库存层、订单与消耗不可分时停止。裁决由 04。
