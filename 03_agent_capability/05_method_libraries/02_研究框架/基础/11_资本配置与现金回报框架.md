# 资本配置与现金回报框架

## 研究员先看什么

资本配置研究不是统计公司花了多少 Capex、做了多少并购、分了多少红利，而是先判断当前分歧属于哪一种：

1. **资本来源与真实再投资**：公司真正可支配的资本来自哪里，维持经营需要多少经济再投资；
2. **内生投资与扩产回报**：新增一元资本能否产生高于资本成本的增量现金回报；
3. **并购、组合与退出纪律**：外延交易与资产调整是否创造超出对价与整合成本的价值，失败时是否退出；
4. **资本结构与现金返还**：分红回购是否来自可持续剩余现金，是否与投资机会、债务约束和净稀释匹配。

单次任务应选择一条主路线，最多保留一条主要竞争路线。历史高 ROIC 不等于新增资本回报高；项目投产不等于创造价值；EPS 增厚不等于并购成功；回购公告不等于实际净股东回报；高分红不等于配置纪律良好。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断某一明确分析单位在给定决策与验证窗口内：

- 公司产生了多少可支配资本，资金来自经营现金、债务、股权、处置还是其他安排；
- 维持现有能力需要多少经济再投资，超出部分投向增长、研发、并购、偿债、分红或回购；
- 新增项目、研发、扩产或并购是否形成可归因的增量现金回报，是否高于风险一致的资本成本；
- 项目未达目标时，公司是否减速、暂停、处置、减值或重新配置；
- 债务结构与流动性如何约束投资与返还；分红回购是否来自可持续剩余现金，是否形成净股数下降。

本框架不重新审计历史财务数字；不直接完成行业机制判断、完整经营预测、治理最终定性，以及估值或交易建议。历史基线先由 `BF-FQ-01` 提供；商业模式由 `BF-BM-01` 提供；项目兑现交 `BF-EE-01` / `BF-FS-01`；治理交 `BF-CG-01`；压力交 `BF-RS-01`；估值交 `BF-VA-01`。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 可支配现金 vs. 账面现金 / 经营现金流 | 受限、维持投入、税息与必要偿债会改变可自由使用余额 |
| 维持性投入 vs. 增长性投入 | 前者维持现有能力，后者才应带来新增规模或效率 |
| 会计 Capex vs. 经济再投资 | 研发、获客、营运资本、租赁与承诺采购也可能是再投资 |
| 存量回报 vs. 增量回报 | 历史资产与低折旧基数可抬高平均 ROIC，不证明新投资有效 |
| 投产完成 vs. 商业成功 / 价值创造 | 产能建成后仍可能缺认证、利用率、价格与现金回报 |
| EPS 增厚 / 并表增长 vs. 并购价值创造 | 低融资成本与会计结构可制造增厚，交易仍可能低于资本成本 |
| 回购公告 vs. 实际执行 vs. 净股东回报 | 授权、执行、价格与净稀释必须分开 |
| 事前合理性 vs. 事后兑现 | 不能只用事后结果否定当时决策，也不能因叙事合理忽略长期未兑现 |

### 1.3 禁止跳步

- 不能从历史 ROE/ROIC 高直接推出新增配置优秀；
- 不能从 Capex 增加或投产直接推出增长与价值创造；
- 不能把管理层 IRR/NPV/协同目标直接采用为项目价值判断；
- 不能把会计 Capex 直接视为全部再投资或全部增长投入；
- 不能从并购规模或 EPS 增厚直接推出交易创造价值；
- 不能用商誉未减值替代并购事后审计；
- 不能从账面现金充足直接推出分红回购空间充足；
- 不能从回购金额直接推出净股东回报，必须扣除新增稀释；
- 不能用单年回报或事后股价倒推长期配置能力；
- 不能在没有预测与资本成本前提时直接跳到估值。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 资本来源、用途与期末变化无法与三表及附注对账 | 正式 `capital_action` |
| 维持性与增长性投入无法拆分，且差异会改变可支配现金 | 自由现金流、再投资率与返还覆盖 |
| 项目投入、时间、业务对象与结果无法建立稳定对应 | 项目 `value_creation` |
| 无法建立资本成本或最低机会成本的合理口径 | “创造经济价值”判断 |
| 并购对价、融资、商誉、整合成本与被收购结果无法拆分 | 并购价值创造与事后审计 |
| 债务期限、契约与流动性无法识别 | 资本结构韧性与返还持续性 |
| 分红回购依赖借款、处置或临时营运资金释放且无法还原 | 可持续现金返还判断 |
| 回购实际执行、平均价格与净股本变化不可得 | 回购质量与净股东回报 |

高级输出停止时，可保留已核实资本动作与项目事实，但不得用“总体配置优秀”覆盖无法验证的回报。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 资本来源与真实再投资** | 真正支配多少资本，资金被什么占用 | FCF 争议；Capex/研发/营运资本或融资变化大 | 经营现金、维持投入、增长投入、受限现金、债务股权、处置、承诺 | 真实剩余现金 vs. 临时营运资金释放、低维护投入、融资或处置 | 无法对账或拆分维持性投入时，只输出局部资本动作 |
| **B 内生投资与扩产回报** | 新增资本是否形成高于资本成本的增量现金回报 | 大额扩产、研发、门店、产线或新业务 | 原始预算、投产、利用率、销量、实现价、单位成本、增量 ROIC | 高回报投资 vs. 周期顺风、低基数、产能闲置、需求透支 | 无法建立投入—经营—现金桥时，不形成项目价值创造 |
| **C 并购、组合与退出纪律** | 并购与组合调整是否创造超出对价的价值 | 重大并购、频繁收购、协同、减值或重组 | 对价、融资、协同假设、整合成本、独立业务现金、商誉减值、处置 | 真实协同 vs. 并表、低成本融资、周期顺风、成本延后 | 被收购业务无法独立跟踪或原始假设缺失时，只描述交易事实 |
| **D 资本结构与现金返还** | 应继续投资、还债还是返还，返还是否可持续 | 高现金/高杠杆、分红回购、融资或流动性争议 | 可支配 FCF、债务期限、契约、投资机会、分红覆盖、回购执行、净股数 | 真实剩余返还 vs. 举债分红、抵消稀释、缺乏机会或控制权安排 | 缺少债务约束、实际执行或净稀释时，不形成返还持续性 |

### 路线选择要求

02 调用本框架时必须说明：目标输出；主路线与竞争路线；分析单位（公司/板块/项目/并购/返还动作）；决策时间与验证窗口；哪 2—3 个关键判断与 3—5 个决定性变量；哪些用途裁剪；哪些问题转交财务质量、商业模式、业绩弹性、治理、风险或预测框架。四条路线全部展开，通常说明问题未收敛。

## 3. 模块菜单

模块是可裁剪能力，不是必须全部启用的清单。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| CA-C1 资本来源与用途对账 | 核心 | 使用本框架时通常必须 | 单一已知项目且资金来源不改变结论时可简化 | 资本从哪来、投向哪、期末如何对账 |
| CA-C2 维持性再投资 | 核心/条件 | 判断 FCF、返还、资本轻重或新增投资空间 | 只描述已发生动作、不评价剩余现金时可简化 | 维持经营需要多少经济再投资 |
| CA-R1 内生增长与研发项目 | 条件 | 扩产、研发、门店、产线或新业务投入较大 | 规模很小且不改变回报或风险 | 项目投入、里程碑、有效产出与现金回报 |
| CA-R2 并购与资产组合 | 条件 | 重大并购、商誉、处置或重组 | 无重大外延交易 | 对价、协同、整合、被收购结果与退出纪律 |
| CA-R3 资本结构与流动性 | 条件 | 杠杆、到期、契约或缓冲影响用途 | 净现金充足且债务不限制决策（须说明） | 边际债务成本、期限、再融资与资金可用性 |
| CA-R4 分红回购与净返还 | 条件 | 研究股东回报或每股价值 | 不涉及现金返还 | 返还来源、实际执行、净稀释与持续性 |
| CA-R5 项目事后审计 | 条件 | 评价配置能力或重大项目兑现 | 尚未到可验证窗口时改为监测 | 原目标与实际投入、时点、经营和现金差异 |
| CA-E1 治理公平性与组合优先序 | 扩展 | 关联交易、控制权、多项目互斥 | 无治理冲突或单一项目 | 交 `BF-CG-01`；或多项目机会成本 |

判断现金返还须启用维持性投入与资本结构相关模块；判断项目价值须有事后兑现要求。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 资本来源与维持需求 | 前提与剩余现金 | 临时营运资金释放会伪装成 FCF |
| 增长投入与项目产出 | 方向与上限 | 投产不等于有效产能与现金 |
| 项目/并购回报 | 价值创造归因 | 周期、并表与会计会掩盖增量回报 |
| 资本结构 | 约束与机会成本 | 只看净债务不够 |
| 现金返还与净稀释 | 持续性与每股价值 | 公告不等于执行，回购可能只抵消稀释 |
| 配置纪律 | 继续/退出决策 | 合理试错与沉没成本升级需区分 |

02 通常只保留 3—5 个决定性变量。评价返还前须估计维持性经济再投资；不能机械用“折旧≈维持性 Capex”。增量回报优先使用税后增量现金流，不以分摊后会计利润代替。

### 4.2 代理变量要求

直接项目回报或维持性投入无法获得时可用代理，但须说明投入边界、覆盖范围、失效条件与强度降级。管理层目标、行业平均回报与事后股价默认不是项目价值的无条件代理。

### 4.3 关键时钟

只选择本次相关时钟，不得混用：

`决策批准 → 实际支出 → 建设转固 → 认证爬坡 → 收入确认 → 现金回收 → 周期位置 → 债务约束 → 返还执行 → 事后审计`

资本配置研究须按业务时间保存当时可见信息，避免用事后修订数据重写原决策条件。

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| ROIC / FCF 改善 | 资本效率与现金创造增强 | 周期价格、低投入、延付、库存释放或处置 | 维持性投入、营运资本、周期与处置 | 降级为暂时释放或周期回报 |
| Capex / 投产增加 | 高回报增长 | 超支、周期高点扩产、利用率不足 | 投入对象、利用率、正常化价格与现金 | 不确认价值创造 |
| 并购后收入/EPS 增长 | 协同与价值创造 | 并表、低融资成本、周期顺风 | 独立业务现金、协同兑现、投入资本回报 | 切换并表或金融工程增厚 |
| 商誉未减值 | 交易价值仍在 | 测试宽松或目标后移 | 业务目标下调、现金与追加投入 | 进入协同未兑现监测 |
| 分红/回购提高 | 剩余现金增加 | 举债、处置、周期高点或抵消稀释 | 资金来源、净股数、维持投入与债务 | 降级为不可持续或稀释抵消 |
| 项目持续追加 | 战略选择权增强 | 沉没成本与目标漂移 | 原目标对照、退出动作、追加理由 | 切换退出纪律/治理路径 |

### 降级规则

- 无法对账：只描述局部资本动作；
- 只能观察会计利润：不得写经济价值创造；
- 项目尚未进入稳定期：输出条件判断与监测节点；
- 回报主要受周期驱动：给周期调整后范围，不提高长期增量回报假设；
- 并购无法独立跟踪：只描述交易事实；
- 返还依赖外部融资或临时现金：不形成可持续返还；
- 研究窗口不足：不得提前判定成功或失败。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-CA-01.capital_action` | 对象期间口径明确；三表/附注/公告可交叉验证；重大动作区分批准、承诺与支付；受限资金与表外承诺已识别 | 只输出计划/授权或汇总变化，不形成可支配现金结论 |
| `BF-CA-01.value_creation` | 投入边界稳定；有原始目标或可重建基线；经济再投资完整；产出与现金可桥接；资本成本可合理确定；至少一个竞争解释 | 降级为条件式假设、会计回报描述或尚未可判断 |
| `BF-CA-01.cash_return_sustainability` | 正常化经营现金与维持性再投资可估计；债务/承诺/流动性已识别；实际执行与净稀释已核实；至少一个下行情景 | 不形成可持续返还，或降级为结构优先/稀释抵消/外部融资返还 |

高层门槛失败，不抹去已确认的低层资本动作与项目事实。精确依赖以登记表为准。

### 6.2 组合与交接

- 历史财务基线：`BF-FQ-01`；
- 商业模式与资本强度：`BF-BM-01`；
- 外部机制支持项目假设：供需/政策/价格等上游框架；
- 项目兑现到公司业绩：`BF-EE-01` / `BF-FS-01`；
- 治理与公平性：`BF-CG-01`；
- 压力与违约：`BF-RS-01`；
- 预期差与估值：`BF-EG-01` / `BF-VA-01`。

不以股价表现评价回购与并购；战略价值与财务回报不得混成单一分数。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 资本来源用途须与现金流量表、资产负债表、附注和公告对账；
- 项目须保存决策基线、实际投入、里程碑、经营兑现与现金回报；
- 并购须能独立观察被收购业务与可验证协同，不能只用并表增长；
- 返还须核实实际执行、资金来源、净股数变化与债务约束；
- 管理层材料与事后股价不得单独确认或推翻配置质量。

具体来源与验收由03_agent_capability/05_method_libraries/03_取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的公司、项目、并购、合同、资本与财务相关对象，以及状态变量、观测、事件、假设、信号与情景。“维持性再投资”“增量回报”“退出纪律”等属框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 周期高点扩产、大额并购事后审计、高现金回购、研发密集型再投资 |
| 重点检查 | 是否只选一条主路线；是否拆分维持性投入；是否区分投产与价值创造；是否用股价倒推 |
| 经验沉淀 | 行业特有资本类型优先进入行业框架或场景卡；跨任务重复且有失效边界的机制才写回稳定内核 |

框架更新不以增加固定回报阈值或估值公式为目标。

## 8. 验收检查

- [ ] 明确本次目标是资本动作、价值创造还是现金返还持续性；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 可支配现金、维持性投入与增长性投入已区分；
- [ ] 存量回报与增量回报、投产与价值创造已区分；
- [ ] 并购已区分并表/EPS 增厚与真实协同；
- [ ] 回购已区分公告、执行与净稀释；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 没有用事后股价评价资本配置；
- [ ] 未形成价值创造或返还判断时，没有直接跳到估值。
