# 行业结构与竞争格局框架

## 研究员先看什么

行业研究的第一步不是计算集中度，也不是把“五力”逐项填完，而是确认：**哪些产品和参与者真正争夺同一客户预算，客户在什么条件下能够切换，经济利润为什么停留在某个环节，以及这种结构是否正在改变。**

研究至少要过三道门：

1. **边界门**：对象是否满足相近客户任务，产品、技术路线、地域、认证和渠道差异是否允许它们相互替代；
2. **结构门**：参与者数量、份额、进入退出、产能承诺和议价关系是否形成稳定结构，而不是一段时间的供给短缺或统计口径结果；
3. **利润门**：高份额、集中度或毛利是否真正转化为跨周期的经济利润，价值由谁获得、为何能够保留。

最容易混淆的是：行业分类相同不等于处于同一个竞争市场；产品功能相似不等于客户能够现实切换；高集中度不自动等于竞争温和或盈利能力强；高市场份额不自动等于具备定价权或护城河；行业增长快不自动等于行业有吸引力；当前高毛利不自动等于利润池能够长期保留；份额上升可能来自低价、并购、产能投放或分母变化；龙头表现优秀可能来自行业顺风、周期短缺或历史资产。

单次任务不应默认同时研究行业规模、生命周期、五力、PESTLE、利润池、公司护城河和估值。应先明确本次要形成的是竞争市场边界、结构状态还是利润池归因，再选择一条主路线，最多保留一条主要竞争路线。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 哪些产品、服务、技术路线和参与者构成同一竞争市场；
- 市场边界应按客户任务、可替代性、地域、认证、渠道和业务时间如何划分；
- 当前行业结构是分散、集中、整合、受约束竞争，还是正在被新进入、产能扩张或替代技术重塑；
- 集中度、进入壁垒、供给纪律、客户和供应商议价如何共同影响竞争强度；
- 价值和经济利润停留在哪个产业环节，主要由哪种稀缺能力、关系或约束支撑；
- 份额、利润率和资本回报差异来自行业结构，还是公司特有能力、周期位置、会计口径或短期供需；
- 哪些技术、政策、客户行为、资本投入或替代路径会迫使行业边界、可比组和利润池重新定义。

本框架可以形成市场边界、结构状态和利润池归因，但不直接完成产品供需和价格周期、单家公司完整商业模式、公司业绩预测、财务质量和资本配置、预期差、估值与交易结论。行业结构只为这些后续判断提供边界、竞争约束和价值分配前提。

最小逻辑依赖为：客户任务与购买边界 → 可替代产品和真实参与者 → 进入退出、产能和竞争行为 → 客户/供应商/平台议价 → 价格、利润和资本回报如何分配 → 哪个变化会重建边界或利润池。任务可止于任一层；不要求每次机械完成五力五模块。

竞争市场至少说明：客户任务与决策主体、产品与规格、现实可替代性、供给能力、地域与渠道、价格和合同比较、业务时间、纳入与排除对象。只有同时具备需求侧和供给侧竞争证据，才能形成正式市场边界。

利润池不是各环节毛利率排序，必须回到：哪种稀缺能力 → 通过什么合同或价格获得收入 → 谁承担库存、资本、研发和失败风险 → 能否转化为跨周期现金和资本回报 → 哪种进入、替代或议价变化会侵蚀该回报。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 行业分类 vs. 竞争市场 | 分类体系按统计或管理目的划分，竞争市场由客户任务和现实替代关系决定 |
| 产品相似 vs. 可替代 | 技术或功能相近，不代表客户能在质量、认证、成本、风险和时间上完成切换 |
| 市场份额 vs. 竞争优势 | 份额可能来自低价、短缺配额、并购、补贴、产能或统计口径，而非持续优势 |
| 集中度 vs. 供给纪律 | 参与者少不代表不会扩产、降价、抢份额或发生技术替代 |
| 进入壁垒 vs. 当前进入较少 | 进入少可能只是需求低迷、资本市场收缩或时间窗口短，不能证明稳定壁垒 |
| 高毛利 vs. 经济利润 | 高毛利可能伴随高研发、资本开支、库存、获客或失败成本，未必产生超额资本回报 |
| 当前利润 vs. 可持续利润池 | 周期短缺、一次性政策、汇率、补贴或低折旧阶段可能制造暂时高利润 |
| 结构变化 vs. 周期波动 | 价格、利润和份额的短期变化，未必改变行业边界、参与者能力和长期价值分配 |

### 1.3 禁止跳步

- 不能从标准行业分类直接推出竞争市场边界；
- 不能从产品功能接近直接推出客户可以切换；
- 不能在市场边界未稳定前计算和比较市场份额；
- 不能把来自不同产品、地域、客户或期间的份额数据直接合并；
- 不能从高集中度直接推出竞争温和、提价能力或稳定高回报；
- 不能从高市场份额直接推出护城河、定价权或长期优势；
- 不能从行业快速增长直接推出行业盈利能力和资本回报改善；
- 不能从当前参与者少直接推出进入壁垒高；
- 不能从价格上涨或高毛利直接推出利润池结构性改善；
- 不能用“五力”文字描述替代价格、合同、进入退出、客户切换和资本回报证据；
- 不能把短期供给不足造成的高利润写成稳定供给纪律；
- 不能从公司份额上升直接推出竞争力增强，必须排除低价、并购、产能和分母变化；
- 不能把行业结构优势直接等同于单家公司能够兑现收入、利润和现金；
- 不能在技术路线、监管或客户采购方式已改变市场边界后继续使用旧份额和旧可比组；
- 不能从结构判断直接生成估值倍数、资产价格或交易建议。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 无法说明客户购买所解决的任务，或不同产品服务的任务并不相同 | `competitive_market_scope` |
| 只有行业分类、企业自报口径或数据库标签，没有客户替代和供给竞争证据 | 正式竞争市场边界 |
| 产品在规格、地域、认证、交付、渠道或风险上不可现实替代 | 将其放入同一竞争市场和同一份额分母 |
| 市场规模、份额分母、产品范围、地域或业务时间不可比 | 份额、集中度和竞争格局比较 |
| 公司横跨多个不同竞争市场，但数据无法拆分 | 公司相对位置和份额结论 |
| 只有静态集中度，没有进入退出、产能、价格或份额行为 | `structure_state` 中的供给纪律和竞争强度判断 |
| 当前高利润主要由短期短缺、周期价格、补贴、汇率或低折旧造成，无法区分 | 结构性利润池归因 |
| 只有会计毛利或净利，没有资本投入、现金和风险调整 | 可持续经济利润和行业吸引力判断 |
| 所谓进入壁垒没有潜在进入者、进入成本、失败案例或时间证据 | 稳定进入壁垒判断 |
| 所谓转换成本没有客户选择、迁移成本、合同、认证或实际切换证据 | 稳定客户锁定判断 |
| 替代技术只停留在路线图、样品或概念阶段 | 已形成竞争约束或边界重构结论 |
| 技术、监管、渠道或客户采购方式已使原竞争市场失效 | 继续使用旧市场边界、份额和利润池结论 |
| 无法区分行业共同顺风与公司特有能力 | 公司竞争优势归因 |

高级输出停止时，可以保留已经确认的产品分类、参与者、规模资料和结构线索，但不得以“暂按同一市场处理”掩盖边界缺口。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 竞争市场边界与可替代性** | 哪些产品和参与者真正争夺同一客户预算，市场应怎样拆分 | 初始行业研究；份额来源差异大；出现新技术、跨界竞争或可比组争议 | 客户任务、招投标重合、实际替换、交叉价格弹性、认证与切换时间、地域和渠道可达性 | 同一市场 vs. 相邻但不可替代的子市场；现实替代 vs. 理论替代 | 无法证明现实可替代时，止于候选边界，不计算正式份额和集中度 |
| **B 结构状态、进入退出与供给纪律** | 当前集中度是否形成稳定竞争结构，还是暂时短缺、扩产前夜或统计结果 | 用户询问竞争是否缓和、龙头格局、行业出清、价格战或集中度变化 | 进入退出、产能承诺、价格行为、份额稳定性、资本开支、利用率、订单纪律、并购 | 稳定供给纪律 vs. 周期短缺、低价抢份额、即将扩产、新进入或监管约束 | 只有集中度和静态份额时，只描述结构表象，不判断竞争纪律 |
| **C 利润池、议价权与价值分配** | 经济利润为何停留在某个环节，客户、供应商和平台谁拥有议价权 | 产业链不同环节利润差异大；高毛利是否可持续；利润池是否迁移 | 价格—成本差、合同条款、客户与供应商集中、切换成本、毛利与 ROIC、现金转换、风险承担 | 稳定稀缺和议价权 vs. 周期价格、会计口径、资本低估、补贴或风险外包 | 无法连接结构机制、合同行为与跨周期经济回报时，不形成利润池归因 |
| **D 结构迁移与优势持续性** | 技术、监管、客户行为、资本投入或商业模式是否正在重构边界和利润池 | 出现新技术、替代、并购、标准变化、平台迁移、渠道变化或龙头优势争议 | 替代渗透、客户迁移、资格取得、成本曲线、标准和许可、产能重配、份额与回报持续性 | 结构性重构 vs. 周期性份额波动、一次性事件、低价扩张或旧市场增长 | 没有产生不同客户选择、成本位置、进入退出或资本回报预测时，不升级为结构变化 |

### 路线选择要求

02 调用本框架时必须说明：

1. 本次目标是界定竞争市场、判断结构状态，还是解释利润池；
2. 主路线和主要竞争路线分别是什么；
3. 哪 2—3 个关键判断决定最终输出；
4. 哪 3—5 个变量或行为信号最能区分不同解释；
5. 本次竞争市场的产品、客户、地域、渠道和时间边界；
6. 哪些参与者、产品或相邻市场被排除，为什么；
7. 哪些模块不启用，为什么不会改变本次边界、结构或利润池判断；
8. 哪些后续问题应转交供需、商业模式、业绩、预期或估值框架。

四条路线全部展开，通常说明研究目标尚未收敛，或把本框架误用成完整行业研究报告目录。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的报告模板。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| IC-C1 研究对象与目标输出 | 核心 | 每次调用 | 不得裁剪 | 本次要形成市场边界、结构状态还是利润池归因 |
| IC-C2 客户任务与竞争单元 | 核心 | 每次调用 | 01 已完整定义时可简写 | 谁在争夺同一客户预算，产品和客户如何分层 |
| IC-C3 现实可替代性 | 核心 | 形成 `competitive_market_scope` | 任务只登记行业分类且明确不形成竞争判断 | 客户能否在性能、成本、认证、时间和风险上切换 |
| IC-R1 市场规模与份额口径 | 条件/核心 | 需要计算份额、集中度或比较参与者 | 任务仅做定性边界，且规模不影响判断 | 分母、地域、产品、渠道和时间是否一致 |
| IC-R2 进入退出与资本行为 | 条件 | 研究结构稳定性、出清、整合或竞争加剧 | 任务只做边界判断 | 进入壁垒、退出机制、产能和资本开支是否改变竞争 |
| IC-R3 价格与供给纪律 | 条件 | 高集中度是否形成盈利、是否存在价格战或扩产竞争 | 任务不涉及结构质量 | 参与者如何通过价格、产能、配额和合同竞争 |
| IC-R4 客户议价与转换成本 | 条件 | 客户集中、长协、认证、平台控制或客户锁定重要 | 客户高度分散且不影响本次结构判断 | 谁拥有选择权，客户切换的经济和组织成本是什么 |
| IC-R5 供应商与关键资源约束 | 条件 | 上游资源、技术、许可、人才或平台构成关键约束 | 上游可充分替代且不影响价值分配 | 上游是否截取利润或限制参与者能力 |
| IC-R6 替代技术与跨界竞争 | 条件 | 出现新技术、新商业模式或相邻行业进入 | 没有现实采用、认证和成本可行性 | 原边界是否被新方案重构 |
| IC-R7 利润池与经济回报 | 条件/核心 | 形成 `profit_pool_attribution` | 任务止于市场边界或结构状态 | 价值由谁获取，是否形成正常化现金和资本回报 |
| IC-R8 公司相对位置 | 条件 | 需要比较公司在同一市场中的成本、差异化、客户和资源位置 | 市场边界未稳定或任务不涉及公司比较 | 公司差异来自行业结构还是特有能力 |
| IC-R9 结构变化触发 | 条件 | 研究结构迁移、份额重估或框架更新 | 任务只做当前静态边界 | 哪种技术、政策、资本或客户行为会使旧结论失效 |
| IC-E1 生命周期与长期行业史 | 扩展 | 深度行业研究或需要解释多年结构演化 | 当前任务只需解决一个具体分歧 | 渗透、参与者、盈利和资本行为如何演化 |
| IC-E2 宏观、政策与社会环境 | 扩展/交接 | 外部环境明确改变准入、需求、成本或替代关系 | 只是一般背景 | 转交 BF-MF-01、BF-PI-01，不在本框架内铺开 PESTLE |
| IC-E3 商业模式、公司兑现与估值 | 扩展/交接 | 需要深入判断公司收入、利润、现金或价值 | 本框架任何情况下均不直接完成 | 分别交给 BF-BM-01、BF-EE-01、BF-FQ-01、BF-VA-01 |

单次任务必须记录启用和排除模块。模块存在于框架中，不代表 03 必须对所有模块平均取证。

## 4. 候选变量、信号与结构时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 客户任务、预算与转换成本 | 界定需求侧竞争边界和锁定 | 客户表述宽泛；未切换可能只是缺少触发，不代表成本高 |
| 产品功能、认证、交付与服务 | 判断技术可替代范围和供给侧真实竞争 | 规格接近不等于经济可替代；名义能力不等于同地域、同时间可交付 |
| 市场规模、份额与集中度 | 形成份额分母和结构表象 | 分母方法、渠道加价和上下游重复计算常见；集中度不能替代竞争行为 |
| 进入退出、资本开支与产能承诺 | 判断壁垒、出清、未来供给纪律和竞争强度 | 进入少可能源于低回报；公告产能不等于有效投产 |
| 价格、折扣与价格—成本差 | 观察竞争、议价和价值获取 | 需与产品结构、合同、成本和周期对齐 |
| 客户/供应商集中与合同行为 | 判断需求侧与上游议价 | 集中度与实际议价方向可能不一致；替代、库存和合同可削弱集中度影响 |
| 毛利率、ROIC、现金转换 | 观察利润分配和经济回报 | 毛利不等于经济利润；需正常化商誉、租赁、研发和周期 |
| 技术替代、监管许可与并购 | 判断边界是否变化及份额变化来源 | 路线图和样品不等于商业采用；政策文本不等于实际执行；份额变化可能只是分母重组 |

基础框架不设置跨行业固定集中度阈值、合理毛利或护城河公式。02 应从中选择本次真正决定边界、结构或利润池的 3—5 个变量。

### 4.2 代理变量要求

无法获得直接数据时，可以使用代理，但必须说明代理对应哪项机制以及何时失效。招投标重合不能证明最终可完全替代；毛利率差异不能排除会计、结构和周期；专利数量不能证明商业壁垒；多年未进入可能因为回报低而非高壁垒；份额稳定可能来自配额或供给不足；客户留存需排除缺少替代和合同强制。不得将单个代理直接升级为市场边界、竞争优势或利润池结论。

### 4.3 关键结构时钟

只选择本次相关时钟，但不得混用：

`客户采用 → 产能与资本 → 技术替代 → 合同与价格 → 监管与标准 → 盈利与资本回报 → 份额统计`

份额信号回答谁获得更多销量或收入；价格和合同信号回答竞争与议价怎样发生；客户切换信号回答替代是否真实；利润和现金信号回答价值是否被保留；资本和进入信号回答结构能否持续；技术和监管信号回答边界是否需要重建。只出现一个层级的变化，不足以替代其他层级。

## 5. 竞争解释、反证与降级

| 表面现象 | 主解释 | 主要竞争解释 | 区分信号 | 命中竞争解释后的动作 |
|---|---|---|---|---|
| 市场份额上升 | 公司竞争优势增强 | 低价换量、并购、产能投放、客户集中、分母缩小或统计变化 | 同口径份额、价格、毛利、客户留存、并购和产能数据 | 切换到低价扩张、低质量份额或短期抢占 |
| 集中度提高 | 行业整合和供给纪律增强 | 周期退出、地域样本收缩、监管限制、并购口径、短期短缺 | 进入退出、产能计划、价格行为、跨周期份额和 ROIC | 降级为暂时集中，关注未来竞争加剧 |
| 行业/龙头毛利较高 | 稀缺能力、议价权或差异化 | 周期价格、低折旧、补贴、会计分类、产品/客户结构或产能利用率 | 正常化利润、现金、资本投入、同产品同客户比较 | 停止高质量利润池或优势归因 |
| 客户长期未切换 / 新进入者少 | 转换成本高 / 进入壁垒高 | 缺少现实替代、合同未到期；或市场小、回报低、资本环境差 | 客户评估、招标、迁移成本、实际切换；潜在进入者、失败案例、投资回报 | 不判断锁定或高壁垒 |
| 价格稳定 / 行业增长快 | 供给纪律强 / 行业吸引力高 | 长协锁定、产品差异、监管；或资本投入过多、竞争加剧、低回报扩张 | 合同重置、折扣、产能、订单；增量 ROIC、进入、资本开支和现金转换 | 不形成纪律增强或吸引力结论 |
| 替代渗透上升 / 利润池迁移 | 旧边界被重构 / 结构性议价增强 | 局部试用、补充方案、经济性不足；或周期错位、会计口径、资本开支滞后 | 实际采购、复购、成本、性能、规模采用；跨周期价格、合同、现金和风险承担 | 降级为潜在替代监测，或拆分周期与会计因素 |

### 降级规则

- 产品满足不同客户任务或现实上不可替代：拆成不同竞争市场，重算参与者和分母；
- 技术、监管或渠道改变客户选择集合：切换到边界重建，暂停旧份额比较；
- 集中度提高但资本开支和新增产能激进：降级“供给纪律增强”；
- 龙头高利润只在短缺期出现：切换到供需或价格周期框架；
- 高毛利但资本回报和现金不高：切换到资本强度、会计和现金消耗解释；
- 客户集中上升但供应商产品不可替代：转向双边依赖、关键稀缺和合同约束分析；
- 并购导致份额和集中度上升：先检查整合、客户流失、产能纪律和经济回报；
- 政策或标准决定准入但执行不清：切换到 BF-PI-01 执行兑现路线；
- 公司表现优于同行但行业普遍改善：分离行业红利与公司特有能力，转 BF-BM-01。

合格反证应能够改变市场边界和可比组、份额分母、竞争强度和供给纪律、议价方向、利润池所在环节、结构持续期、公司相对位置或后续框架是否允许启动中的至少一项。“竞争激烈”“存在替代风险”只是一般风险提示，应写成可观察条件。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- **边界**：客户任务、采购比较、真实替换、招投标、认证、交付和地域可达性；
- **份额**：分母、产品、地域、渠道、币种、业务时间和估算方法一致；
- **结构**：进入退出、并购、产能、资本开支、价格和客户行为；
- **议价**：合同、折扣、客户集中、供应替代、切换成本和风险承担；
- **利润池**：同口径正常化利润、现金、资本投入和增量回报；
- **迁移**：替代采用、标准变化、许可执行、客户迁移、成本曲线和规模复购；
- **反证**：低价换份额、周期短缺、会计口径、补贴、并购分母和技术替代。

单一咨询市场规模、公司自报份额、行业分类代码或静态毛利表，均不足以独立支撑正式结构判断。具体来源、证据组合和验收由03_agent_capability/05_method_libraries/03_取证管理。

### 7.2 本体边界

正式任务优先引用一级本体中的行业、环节、公司、产品、应用、客户、地区、事件、关系、状态变量、观测、假设、信号、情景和判断。竞争市场边界、客户任务、可替代性、转换成本、进入退出、议价关系、利润池和经济回报、结构变化触发属于框架概念或任务候选，不因写入本文件自动成为正式本体定义。

若正式本体只能用“行业、竞争、优势、壁垒”等泛化概念承接，却不能指导 03 收集替代、切换、进入退出、议价和资本回报证据，应标记为 `upper_cover` 或 `weak_cover`。五力、生命周期和利润池分析可作为方法论来源，但不能替代现实证据；具体行业份额来源、认证规则和历史案例应进入行业主框架或场景卡。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 市场边界争议、集中度与价格战、利润池迁移、技术替代重构边界等不同机制任务 |
| 重点检查 | 是否先界定客户任务和现实替代；是否区分集中度与供给纪律；是否回到经济回报；是否越界到公司业绩和估值 |
| 经验沉淀 | 行业特有份额口径、进入壁垒和替代路径优先进入行业框架或场景卡；跨任务重复且有反例边界的机制才写回稳定内核 |

以下内容不得因单次案例直接写入稳定内核：某个行业固定合理集中度、某个份额阈值对应护城河、某个毛利率水平对应利润池、某种技术必然替代原路线、某类企业永久拥有最高议价权、固定生命周期年限或渗透率阈值。框架更新不以增加篇幅为目标。
