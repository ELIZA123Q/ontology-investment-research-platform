# 表达与模板

研究交付使用的可复用表达资产：语气/边界标准，以及各类研报模板。Research Lead 通过 `research-writing` Skill 按需加载，不绑定旧「05 阶段」流水线。

## 给谁看

- **研究员：** 写报告、对照表达标准与模板
- **维护者：** 标准与模板版本、审计字段

## 材料从哪来

| 编号 | 目录 | 内容 |
|------|------|------|
| 01 | [`01_标准`](01_标准) / [`standards/`](standards/README.md) | 表达标准（语气、边界、禁止事项） |
| 02 | [`02_模板`](02_模板) | 05A—05E 五类研报模板 + 审计模板 |

上游事实与判断必须来自取证与裁决结果；本库不生产新证据。

## 怎么用

1. 先确认 03/04 已审过的事实与判断。
2. 按交付类型选 05A–05E 模板（见 [`standards/README.md`](standards/README.md) 速览表）。
3. 按表达标准自检；不得新增未经 03、04 确认的事实或判断。

## 怎么维护

- 改标准/模板时同步审计 YAML schema 与 Runtime 表达校验（若有）。
- 不在本目录复制 Runtime 合同全文。
- 质量门槛以 `05_投研表达标准.md` §9 为准。
