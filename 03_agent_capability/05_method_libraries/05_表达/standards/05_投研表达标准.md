# 05_投研表达标准

## 研究员先看什么

05 回答：**怎样把 04 已批准的判断，写成可读、可讨论、可跟踪，并对投资判断真正有用的研究成果。**

| 你要交什么 | 业务说法 |
|---|---|
| 最终研究稿 | 按 01 指定原型（事件点评 / 行业动态点评 / 行业周期判断 / 公司业绩点评 / 主题深度研究等）写成正式研究语言 |
| 表达审计 | 机器侧核对是否越权表达、判断强度是否漂移、关键条件是否丢失（研究员可不深读） |

04→05 交付一致性检查属于 **05 确认门**：系统在确认本稿时核对是否新增主张、抬高强度、扩大范围、丢失关键条件或改判信号。检查通过后即可进入发布侧复验（见 [`05_control_evaluation/03_校验/README.md`](../../05_control_evaluation/03_校验/README.md)）。

**05 的核心任务不是“更谨慎地复述 04”，而是在 04 已批准边界内，把能成立的判断说到位。**

一份合格的 05，读者应能快速回答：

1. 当前到底怎么看；
2. 哪些判断最确定，哪些仍有不确定性；
3. 决定结论的主导矛盾和关键变量是什么；
4. 相对原判断、常见叙事或关键未知，本次研究增加了什么；
5. 结论如何传导到行业、公司、收入、利润或估值逻辑；
6. 后续最值得跟踪什么；
7. 哪些事实出现后需要改判。

**常见失败：**

- 把 04 判断简报逐段扩写；
- 用“不能判断、仍待验证、证据不足”构成主要叙事；
- 把多个子问题并列罗列，却没有形成面向研究问题的综合结论；
- Research Edge 只是“订单不等于收入”“政策不等于业绩”等研究常识；
- 为了体现严谨，在首页和正文反复重复同一限制条件；
- 为了形成鲜明观点，新增 04 未批准的事实、因果、预测或投资主张。

质量见第 9 章与 [`00A`](../../05_control_evaluation/03_校验/00A_高质量产出判别标准.md)。正文语言继承 [`00` §9.3](../../05_control_evaluation/01_架构/00_项目定位与边界.md)。

## 1. 文档定位

05 是正式表达层：接收 04 已定稿判断与表达许可，在不重新研究、不新增事实、不改变判断强度的前提下，形成面向研究员、投资经理或指定读者的最终研究成果。

05 的职责是：

- 把 04 已批准判断组织成清晰的综合结论；
- 明确判断强弱、主次关系和剩余关键未知；
- 将证据、机制、对象分化和投资含义组织成连续论证；
- 将 04 的边界与条件改写成自然研究语言；
- 形成可持续更新和改判的跟踪框架；
- 完成 04→05 的表达一致性确认。

05 不负责：

- 重新搜索、重新取证；
- 新增 03 没有的事实、图表或数据；
- 新增 04 没有的 Judgment、因果解释或投资主张；
- 为了让报告“更完整”而擅自补齐上游缺口；
- 因为证据不足而把报告退化为审计说明或资料汇编。

### 1.1 05 的基本原则：最大有效判断

05 应遵循：

> **不越过 04 的判断边界，但应把 04 已允许成立的判断完整、清楚、有效地表达出来。**

因此：

- 04 已批准“较高确定性”的判断，05 不得降格写成泛泛的“仍需观察”；
- 04 只允许条件式判断，05 不得改写为确定预测；
- 04 对不同子问题给出不同强度，05 应明确主次和层级，而不是全部处理成同等谨慎；
- 04 尚未解决的问题可以保留未知，但未知必须集中到真正决定后续判断的关键变量上，而不是平均撒在全文。

05 的目标不是“尽可能安全”，而是“在已批准范围内实现最大研究价值”。

## 2. 05 的核心产出

一份高质量 05 应形成以下五层结果：

### 2.1 综合主判断

必须直接回答 01 的核心研究问题，而不是只罗列各子问题结论。

原则上应形成：

- **1 个综合主结论；**
- **2—4 个支撑主结论的分项判断；**
- **1—2 个真正决定后续判断升级或下调的关键未知。**

综合主结论必须来自 04 已批准判断的组合，不得在 05 新增推理。

示例：

```text
当前可以确认国产替代仍在推进，2025 年订单与收入具备较强前端支撑；
但这一确定性尚不能完整外推至 2026 年，远期增长斜率主要取决于晶圆厂资本开支
与现有订单的交付、验收和盈利兑现。
```

不推荐：

```text
国产替代需要验证。
资本开支需要验证。
订单需要验证。
利润需要验证。
```

前者形成了综合判断；后者只是把多个未决项并列。

### 2.2 判断强弱与主次

05 必须让读者看出：

- 哪些已经相对确定；
- 哪些是中等确定性；
- 哪些只是方向性判断；
- 哪些仍是主要未知。

可以使用“高 / 中高 / 中等 / 中低 / 低”等研究语言，也可以使用自然语言表达，不强制固定标签。

判断强弱只能继承 04，不得自行升级。

### 2.3 主导矛盾与关键变量

05 不得平均描述所有因素，应明确：

> **现在最决定结论的矛盾是什么。**

例如：

```text
核心矛盾已从“产品能否进入客户产线”，逐步转向“份额提升能否穿越下游资本开支波动”。
```

主导矛盾必须能够由 04 已有判断支持；若 04 尚未形成该层判断，应退回 04，而不是由 05 临时创造。

### 2.4 Research Edge

05 应说明本次研究到底新增了什么，而不仅是证明“我们没有乱推断”。

有效 Research Edge 应优先来自：

- 阶段变化；
- 主导变量变化；
- 对象分化；
- 时间窗口变化；
- 传导机制变化；
- 市场或内部原判断混淆了不同层级；
- 一个关键未知被缩小或重新定位。

### 2.5 可跟踪的改判框架

05 应把未来观察项收敛成：

- 看什么指标；
- 为什么看；
- 哪个变化会增强判断；
- 哪个变化会削弱判断；
- 会改变哪一个具体结论。

不得只写“关注政策”“关注需求”“关注风险”等泛化表述。

## 2.6 五类报告怎么选

| 报告类型 | 适用问题 | 正文重点 |
|---|---|---|
| 事件点评 | 新政策、公告、事故或供应链扰动有什么影响 | 事件增量、预期差、传导、对象分化、持续时间 |
| 行业动态点评 | 最近一个阶段行业发生了什么变化 | 增量变化、关键数据、主导变量、产业链影响 |
| 行业周期判断 | 当前处于什么阶段，何时可能转向 | 供需库存价格、阶段位置、拐点条件、强弱分化 |
| 公司业绩点评 | 业绩和指引是否改变原判断 | 超预期来源、经营变化、传导、盈利与估值含义 |
| 主题深度研究 | 新技术、新赛道或长期产业变化如何演进 | 空间、产业链、壁垒、商业化、对象分化与验证 |

报告类型由 01 确认。05 不得为了套模板临时改变报告类型。

## 3. 基本写作原则

### 3.1 结论先于背景

标题、投资要点、核心结论和正文开头都应先给判断，再解释背景和依据。

不得以以下方式开篇：

- 从行业定义和发展历史开始；
- 大段复述政策或事件经过；
- 先罗列资料，文末才给观点；
- 用“空间广阔、前景可期”替代具体判断；
- 用“证据不足、仍待观察”代替当前已能成立的判断。

### 3.2 先回答“知道什么”，再回答“不知道什么”

每个核心观点原则上按以下顺序表达：

```text
当前成立的判断
→ 为什么成立
→ 最关键的限制或未知
→ 什么事实会改变判断
```

不推荐：

```text
缺少 A
→ 缺少 B
→ 缺少 C
→ 所以暂时不能判断
```

05 的审慎来自判断边界清楚，不来自大量否定句。

### 3.3 限制条件不得压过主判断

限制因素用于界定结论边界，不得成为报告的主要叙事。

同一限制条件原则上：

- 首页只保留最关键影响；
- 正文在最相关章节解释一次；
- 风险与跟踪部分转化为可观察的改判信号；
- 不得在投资要点、核心结论、多个章节和风险提示中重复同一套否定表达。

一个观点如果已经能成立，应优先表达成立的部分，再说明外推边界。

例如：

```text
好：现有订单和合同负债支持近端交付基础仍较充足，远期斜率主要取决于后续新增订单和验收节奏。

差：订单不能代表收入，合同负债不能代表订单，存货不能代表交付，因此 2025—2026 年仍存在较大不确定性。
```

### 3.4 不确定性必须分层，而不是平均分布

05 应区分：

- **已基本确认；**
- **方向可判断，但幅度或时点仍未知；**
- **证据不足，保留开放；**
- **当前最关键未知。**

不得因为部分变量证据不足，就把整篇报告都写成“低确定性”。

如果一个问题的核心事实已经成立，而远期外推仍不确定，应明确：

> 当前判断成立到哪里；不确定性从哪里开始。

### 3.5 把剩余未知集中到 1—2 个关键变量

首页和结论部分应尽可能回答：

> **真正还不知道的是什么？**

关键未知必须满足：

1. 目前确实没有被 04 解决；
2. 它会实质影响主结论；
3. 后续存在可观察的数据或事件；
4. 一旦变化，可以升级、下调或改写当前判断。

不得把所有证据缺口都列为“关键未知”。

### 3.6 结构服从研究问题，不服从固定目录

正文由核心论点决定，不由资料类别决定。

推荐使用判断型标题：

- “国产替代仍在推进，下一阶段看份额深度而非是否进入”；
- “2025 年交付具备支撑，2026 年斜率取决于下游资本开支”；
- “订单增长已形成收入基础，利润弹性仍取决于结构与验收”。

不推荐：

- 行业概况；
- 资本开支；
- 订单情况；
- 财务分析；
- 风险提示。

后者只有资料分类，没有研究论点。

### 3.7 事实、解释、判断和前瞻分开表达

正文应自然区分：

- **事实：** 已发生并可复核；
- **解释：** 为什么这些事实重要；
- **判断：** 当前综合看法；
- **前瞻：** 在明确条件下对未来的推演；
- **风险：** 哪些因素会削弱结论。

不要求机械加标签，但语言必须让读者分辨清楚。

### 3.8 从产业事实穿透到投资含义

05 不能停留在“政策重要、产业空间大、国产替代加速”。

应继续回答：

```text
变化发生在哪里
→ 哪个经营变量受到影响
→ 哪类对象最先体现
→ 对收入、利润、竞争位置或估值逻辑意味着什么
→ 这一变化是否已经被充分认识
```

若 01 明确不涉及评级或交易建议，仍应保留行业、类别、公司特征和经营含义。

### 3.9 继承上游结论，并独立完成正式表达

05 不重新取证或推理，不突破 04 的：

- 结论方向；
- 判断等级；
- 研究范围；
- 前提条件；
- 失效条件；
- `handoff_to_05` 表达许可。

05 可以：

- 合并重复观点；
- 调整叙述顺序；
- 将多个已批准判断综合成一个更清晰的研究表达；
- 形成标题、投资要点、章节结构和图表组织；
- 将边界、反证和不确定性改写成自然研究语言。

05 不可以：

- 新增因果；
- 新增预测；
- 新增事实；
- 新增市场共识；
- 新增未经 04 批准的“核心矛盾”；
- 把多个低强度判断组合成一个更高强度的综合结论。

## 4. 整体结构：稳定首页 + 弹性正文

### 4.1 首页必须稳定

首页原则上包括：

1. 判断型标题；
2. 判断时点、前瞻窗口、研究对象和范围；
3. 投资要点；
4. 综合主判断；
5. 分项判断强弱；
6. Research Edge；
7. 1—2 个关键未知；
8. 催化与验证信号；
9. 风险提示。

首页目标是：

> **投资经理不阅读全文，也能知道当前怎么看、为什么、哪里最确定、哪里最不确定、后面看什么。**

### 4.2 正文必须弹性

正文一般由 **2—5 个核心论点章节**构成。

每章围绕一个能够独立成立的判断展开，形成：

```text
结论
→ 关键证据
→ 作用机制
→ 投资含义
→ 最关键限制 / 改判条件
```

正文模块可按需选择：

| 可选模块 | 适合回答的问题 |
|---|---|
| 变化与驱动 | 为什么现在需要重新研究 |
| 核心矛盾与传导 | 什么变量真正决定结果 |
| 需求、供给与周期 | 当前处于什么阶段 |
| 市场空间与兑现 | 理论空间如何转成订单与收入 |
| 产业链与价值分配 | 哪些环节最受益 |
| 技术路线与产品演进 | 技术变化如何改变竞争位置 |
| 商业模式与单位经济 | 盈利路径是否成立 |
| 竞争格局与壁垒 | 谁能拿到份额，为什么 |
| 类别或公司比较 | 哪些对象兑现更强 |
| 海外经验或历史复盘 | 有什么可以类比，什么不能类比 |
| 财务影响与估值 | 如何传导到收入、利润、现金流与定价 |
| 市场预期与分歧 | 市场在定价什么，本次增量在哪里 |
| 情景推演 | 不同变量组合下结果如何变化 |
| 催化、验证与风险 | 什么时候看什么，什么会改判 |

模块库不是目录库。

## 5. 首页写作要求

### 5.1 标题

标题应表达最重要的研究判断，而不是表达“我们有多谨慎”。

推荐：

```text
<主结论>，<核心分化>
<阶段判断>：<下一阶段主导变量>
<增长已确认到哪里>，<远期取决于什么>
```

例如：

```text
国产替代仍在推进，2026 年增长斜率转向下游资本开支验证
```

不推荐：

```text
国产替代进度可确认，远期订单与业绩仍待验证
```

若“仍待验证”确实是主结论，可以保留；但不得默认用不确定性构成标题。

### 5.2 投资要点

原则上 4—6 条。

建议覆盖：

1. 当前综合主判断；
2. 最确定的变化；
3. 当前主导矛盾；
4. 对订单、收入、利润或行业格局的传导；
5. Research Edge；
6. 关键未知、催化或主要风险。

投资要点应“结论化”，不得写成：

- 正文目录；
- 数据摘录；
- 证据缺口清单；
- 04 审计摘要。

### 5.3 核心结论概览

核心结论概览应优先呈现“判断强弱”，而不是“证据缺什么”。

推荐结构：

| 研究环节 | 当前判断 | 判断强度 | 对主结论的作用 |
|---|---|---|---|

若确有必要，可增加“关键未知”，但不得让“尚缺什么”成为表格主体。

### 5.4 市场认知差 / Research Edge

除纯事实型且无可比较基准的交付外，05 必须说明本次研究增量。

Research Edge 至少包含：

1. **参考认识：** 市场可验证共识、常见叙事、内部原判断或明确关键未知；
2. **差异化判断：** 本研究在哪个变量、机制、对象、幅度或时间窗口上不同；
3. **被低估的机制：** 为什么旧叙事会失真；
4. **可证伪信号：** 什么事实出现后该认知差不再成立；
5. **证据边界：** 哪部分是已验证，哪部分仍是条件判断。

#### Research Edge 质量门槛

以下内容**不能单独构成有效 Research Edge**：

- 订单不等于收入；
- 收入不等于利润；
- 合同负债不等于在手订单；
- 政策发生不等于业绩受益；
- 相关性不等于因果；
- 单一公司不能代表全行业；
- “仍需持续跟踪”。

这些属于基本研究纪律。

有效 Research Edge 应进一步回答：

- 哪个阶段发生了变化；
- 哪个变量的权重发生了变化；
- 市场把哪些对象混在一起了；
- 哪个时间窗口被错误外推；
- 哪条传导链真正决定结果；
- 原来不知道的问题，现在被缩小到什么范围。

若没有可靠市场一致预期，应写“常见叙事”“内部原判断”或“关键未知”，不得虚构市场共识。

### 5.5 关键未知 / Remaining Uncertainty

首页原则上只保留 **1—2 个**。

写法应是：

```text
当前最关键未知：
2026 年增长斜率能否延续，主要取决于国内晶圆厂资本开支和订单验收节奏。
```

不推荐：

```text
尚缺：
市场份额、客户数据、Capex、ASP、毛利率、取消率、交付周期、存货质量……
```

后者属于证据缺口清单，不属于最终研究表达。

### 5.6 受益方向和资产映射

根据 01 的交付边界决定深度：

- 行业级：受益环节、对象特征、代表样本；
- 公司级：经营变量、财务影响、关键假设；
- 估值影响任务：估值参数、区间或敏感性；
- 核心平台统一不提供评级、目标价、收益承诺、仓位和交易建议。

不得用公司名单替代分析。

## 6. 正文论证要求

### 6.1 每章必须先有“章首判断”

正文每章第一段应回答：

> 本章到底证明什么？

之后再展开证据、机制和限制。

不得先用大量事实铺垫，再让读者自己总结。

### 6.2 每章只保留一个主判断

一章可以有多个证据，但应服务于同一个核心观点。

如果一个章节同时讨论：

- 产品进展；
- 行业 Capex；
- 管制；
- 订单；
- 毛利率；

通常意味着论点组织失败。

### 6.3 数据必须产生解释

每个关键数据应回答：

- 相较历史或预期发生了什么；
- 支持哪一个判断；
- 为什么重要；
- 能推到哪里，不能推到哪里。

不得长篇罗列数字后只写“保持增长”。

### 6.4 证据不足时，优先缩小判断范围

证据不足不等于必须写“无法判断”。

优先选择：

1. 缩短时间窗口；
2. 缩小对象范围；
3. 降低判断强度；
4. 把幅度判断改为方向判断；
5. 把确定预测改为条件式判断。

只有在以上处理后仍无法形成有效结论，才保留“当前不足判断”。

### 6.5 不得重复证明同一件事

同一组数据不得在多个章节中反复作为主要证据。

如果一组订单、合同负债、存货数据同时影响“订单可见性”和“业绩兑现”，应分别说明：

- 在前一章节支持什么；
- 在后一章节只讨论新增的传导问题。

不得整组数字原样重复。

### 6.6 机制分析必须服务于“为什么”

竞争解释、反证和限制因素不是为了展示完整性，而是为了回答：

> 为什么当前结论只到这个强度？

正文原则上只保留最影响判断的 1—2 个竞争解释。

完整竞争解释列表保留在 04 推理审计，不要求全部进入 05。

### 6.7 投资含义必须落到经营变量

每章应尽量回答：

- 对订单意味着什么；
- 对收入确认意味着什么；
- 对利润率意味着什么；
- 对竞争位置意味着什么；
- 对估值逻辑意味着什么；
- 对后续研究优先级意味着什么。

不得以“值得关注”“长期受益”结束一个章节。

### 6.8 前瞻必须有时间窗口和验证信号

未来判断应尽量包含：

- 时间窗口；
- 指标或事件；
- 当前基线；
- 增强条件；
- 削弱条件；
- 影响哪项结论。

## 7. 常见报告组装方式

以下为组装参考，不是固定目录。

### 7.1 产业趋势型

```text
投资要点
→ 当前阶段与增量变化
→ 主导变量与市场空间
→ 产业链价值分配
→ 对象分化与竞争格局
→ 关键未知、催化与风险
```

### 7.2 政策或事件驱动型

```text
投资要点
→ 事件真正改变了什么
→ 哪条传导路径成立
→ 哪些对象受影响最明显
→ 持续时间与下一阶段变量
→ 催化、验证与风险
```

### 7.3 周期与供需型

```text
投资要点
→ 当前周期位置
→ 决定阶段的核心变量
→ 价格、库存与盈利传导
→ 对象分化
→ 拐点条件与风险
```

### 7.4 技术与产品变革型

```text
投资要点
→ 技术变化解决了什么问题
→ 商业化目前到什么阶段
→ 份额和产业链如何重构
→ 哪些对象真正兑现
→ 下一阶段验证与风险
```

### 7.5 国产替代或供应链重构型

```text
投资要点
→ 国产替代目前进行到哪一阶段
→ 当前增长主要由什么驱动
→ 需求与订单能否持续
→ 收入和利润如何兑现
→ 下一阶段关键未知、验证与风险
```

重点不是把“外部约束、供给缺口、国产进展、订单、利润”全部写齐，而是围绕本次问题形成一条主线。

## 8. 来源、风险与合规

### 8.1 来源

关键事实、测算和图表必须可追溯到 03 已冻结且获准展示的素材。

正文可以使用：

- 脚注；
- 尾注；
- 图表来源；
- 关键事实后的来源注释。

不得只在文末列出大量来源，而无法对应核心观点。

### 8.2 风险提示

风险必须与主逻辑对应。

优先写：

- 哪个关键假设可能不成立；
- 哪个传导环节可能中断；
- 哪个经营指标可能偏离；
- 哪种竞争、技术或政策变化会改变判断。

风险部分不得机械重复正文所有限制条件。

### 8.3 “未检索到”表达

“未检索到反向事实”只能表示当前证据范围内未取得对应材料。

05 不得将其表达为：

- 风险不存在；
- 事件不会发生；
- 没有下调；
- 没有取消；
- 没有延期。

若该表述不影响主结论，原则上无需在高可见位置出现。

### 8.4 估值与投资建议边界

在 01 授权且 03—04 支撑充分时，可以讨论：

1. 哪个经营或财务假设变化；
2. 如何进入估值参数或敏感性；
3. 当前定价隐含什么可验证假设；
4. 什么条件会使估值影响失效。

核心平台统一禁止：

- 评级；
- 目标价；
- 收益率预测；
- 仓位建议；
- 直接交易建议。

禁止目标价不等于禁止投资含义和估值分析。

## 9. 质量门槛与返工规则

本节是 05 阶段质量要求和返工条件的唯一权威。

### 9.1 最低完整条件

05 至少满足：

1. 交付形态与 01 指定报告类型一致；
2. 已读取本次 01—04 正式交付物；
3. 判断时点、对象、范围和前瞻窗口与上游一致；
4. 首页有明确综合主判断；
5. 首页能区分主要判断强弱；
6. 首页仅突出 1—2 个关键未知；
7. Research Edge 可说明真实研究增量；
8. 正文由 2—5 个核心论点组织；
9. 每章包含结论、证据、机制、投资含义和最关键限制；
10. 图表、表格、来源只来自 03 冻结素材；
11. 表达审计可逐项追溯至 04 已批准 Claim；
12. 05 未新增事实、判断、强度、范围或投资主张。

满足最低完整条件只代表结构完整，不代表高质量。

### 9.2 高质量门槛

达到 `high_quality_pass`，必须同时满足。

> 标注说明：`[机器可检查]` 表示 Runtime 可从 Artifact 和来源引用机械判定；`[依赖LLM判断]` 表示需要模型或人工 Eval。确定性检查与 `06_runtime/src/governance/verifiers.ts` 保持一致。

1. **前 1—2 页即可回答“当前怎么看”；** `[机器可检查]`（首页结构检查：是否含综合主判断、关键未知与风险）
2. **综合主结论不是子问题简单并列；** `[依赖LLM判断]`（需 LLM 判断综合程度）
3. **不同子判断的确定性和主次清楚；** `[依赖LLM判断]`（需 LLM 判断主次表达）
4. **当前最关键未知已经被收敛，而不是形成长缺口清单；** `[依赖LLM判断]`（需 LLM 判断收敛度）
5. **限制条件没有压过主判断；** `[依赖LLM判断]`（需 LLM 判断主次权重）
6. **正文没有反复使用“不能判断、尚待验证、证据不足”等表达制造审慎感；** `[机器可检查]`（审计腔正则检查）
7. **Research Edge 不只是研究常识或合规纪律；** `[机器可检查]`（Research Edge 占位/真实性检查）
8. **每章完成“结论—证据—机制—投资含义—限制 / 改判条件”；** `[机器可检查]`（密度检查：每章 ≥500 字且含完整论证链）
9. **同一事实和数字没有在多章无效重复；** `[依赖LLM判断]`（需 LLM 判断重复是否“无效”）
10. **重要数据都产生了解释；** `[依赖LLM判断]`（需 LLM 判断数据—解释的对应）
11. **跟踪指标可观察，并能对应具体结论；** `[依赖LLM判断]`（需 LLM 判断可观察性与对应）
12. **判断方向、强度、范围、条件和状态与 04 一致；** `[机器可检查]`（`semantic_strength_review` / `conditions_preserved` 一致性检查）
13. **没有新增未经 03/04 支撑的事实、来源、数值或判断；** `[依赖LLM判断]`（需 LLM 对照冻结素材自律）
14. **正文使用自然研究语言，不出现任务编号、系统状态或审计登记腔；** `[机器可检查]`（审计登记腔禁令检查）
15. **没有越过评级、目标价、收益承诺和交易建议边界。** `[机器可检查]`（越界/交易建议检查）

### 9.3 审慎性过载检查

出现以下情况，应判定 05 返工：

- 首页超过一半要点主要在讲“为什么不能判断”；
- 同一限制条件在三个以上高可见位置重复；
- 多个章节以“证据不足”“无法判断”“仍需验证”作为主要结论；
- 报告无法明确指出最确定的 1—2 项判断；
- 报告无法指出真正决定后续变化的 1—2 个关键未知；
- 读完全文只知道“存在不确定性”，但不知道当前应如何判断。

### 9.4 Research Edge 失败检查

出现以下情况，应返工 05：

- Research Edge 只是基本研究纪律；
- 虚构市场一致预期；
- 只有“不同”，没有解释机制；
- 无法给出可证伪信号；
- 与主结论没有关系；
- 只是重新描述证据缺口。

### 9.5 不得正式发布的情况

出现任一情况，不得正式发布：

1. 首页不能独立传达主结论、关键未知和风险；
2. 正文仍按固定栏目或资料类别拼接；
3. 观点超过 04 判断强度；
4. Research Edge 不成立或虚构共识；
5. 关键跟踪项不可观察；
6. 使用 03 未冻结素材；
7. 正文与表达审计不一致；
8. 存在未经允许的评级、目标价、收益率、仓位或交易建议；
9. 上游 `delivery_readiness` 未达到可交付要求且未降级表达；
10. 标题、投资要点、结论概览仍使用明显审计登记腔；
11. 规则校验未通过。

### 9.6 返工去向

| 问题表现 | 处理 |
|---|---|
| 主结论不清、结构松散、重复、审慎性过载、Research Edge 太弱 | 返工 05 |
| 所需事实、图表、数据或来源不足 | 退回 03 |
| 需要改变判断强度、因果、范围、反证或改判条件 | 退回 04 |
| 主判断轴、关键变量或对象关系本身不合理 | 退回 02 |
| 研究问题、用途、对象或时间窗口发生变化 | 退回 01 |

返工后必须重新运行 05 规则校验。

## 10. 与 01—04 的关系

```text
01 明确研究问题、对象、边界和交付用途
→ 02 确定主判断轴、核心矛盾、关键变量和对象分化
→ 03 准备事实、数据、图表和来源
→ 04 形成判断、判断强度、反证、条件与表达许可
→ 05 在既有边界内形成综合主判断、正式论证、Research Edge 与跟踪框架
```

05 不是：

- 04 的扩写版；
- 03 的资料汇编版；
- “哪些事情还不能说”的审计报告。

05 是：

> **在不改变已审计判断的前提下，把研究结果压缩成有主次、有强弱、有增量、有投资含义、可持续验证的最终研究成果。**
