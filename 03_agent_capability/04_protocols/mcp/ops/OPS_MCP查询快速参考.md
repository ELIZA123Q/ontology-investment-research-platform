# OPS MCP查询快速参考

复核日期：2026-07-23。适用范围：通过 MCP 协议获取金融数据的操作参考。本文件与 [OPS_通用真实来源查询与回退手册](../../../02_skills/evidence_research/references/OPS_通用真实来源查询与回退手册.md) 平行，使用 `QP-MCP-*` 查询编号体系。

## 0. 前提

1. 所有 MCP 调用适用 [B00 准入规则](../../../02_skills/evidence_research/references/B00_来源选择与使用边界.md)：MCP 是获取通道，不是来源生产者。材料质量仍由上游来源（巨潮、通联、华泰研究所等）决定。
2. MCP credentials/config 由 Runtime / Harness 环境提供，项目仓库不保存凭证。
3. 每次调用必须按 [03附录2第5节](../../../02_skills/evidence_research/references/OPS_证据获取留痕手册.md) 记录留痕。
4. 查询前先写清：要证明的主张、对象、业务时间、指标/单位、权限范围、回退顺序（依据 [OPS通用手册第2节](../../../02_skills/evidence_research/references/OPS_通用真实来源查询与回退手册.md)）。

## 1. A股法定公告（QP-MCP-01）—— cninfo

| 项目 | 内容 |
|------|------|
| MCP名称 | `cninfo` |
| 类型 | stdio（npx `@youhaozhao/cninfo-mcp`） |
| 来源生产者 | 巨潮资讯网（cninfo.com.cn） |
| 主要能力 | 查询A股公司公告列表、获取公告分类信息 |
| 典型查询 | 按证券代码 + 公告类别 + 日期范围获取公告 |
| 输入参数 | 证券代码（如 000001）、公告类别、起止日期 |
| 取得后记下 | 证券代码、公告ID、公告标题、发布日期、公告类别、链接 |
| 留痕字段 | 证券代码、公告ID、公告标题、发布日期、查询参数、原始响应位置 |
| 口径边界 | 公告列表不含全文内容；需进一步获取PDF原文 |
| 回退 | cninfo MCP不可用 → [巨潮官网](http://www.cninfo.com.cn) → 通用查询手册 公司披露 |
| 取不到时 | 标注"cninfo MCP无此公告"，记录查询参数和时间 |

## 整体回退链

当 MCP 通道出现故障时，按以下优先级降级：

```text
MCP通道正常
  → 通过MCP获取 → 完整留痕 → 正常完备度评价
  ↓ 故障
同源换通道（如通联MCP → 通联Web/API直连）
  → 记录通道切换原因 → 完备度通常不变（降级需单独评估）
  ↓ 仍不可用
跨源回退（见各卡片"回退"字段 → OPS通用手册QP-*条目 → Web搜索）
  → 完备度可能降为受限/观察
  ↓ 仍不可用
代理指标（A09）+ 完备度降级
  → 最高受限，无交叉验证时为观察
  ↓ 完全不可得
记录为证据缺口（GAP-*）→ 相应核心判断 evidence_grade = unusable
```

MCP 可用性问题不属于来源权威性问题——通道故障不改写上游生产者身份，但需在证据评估中记录获取路径变更及对完备度的影响。
