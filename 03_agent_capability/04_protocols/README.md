# 协议与数据通道

这里配置「数据怎么进来、Agent 之间如何协作」的协议层材料。最常用的是 **MCP 金融/披露数据通道**。

## 给谁看

- **研究员：** MCP 通道清单与 OPS 操作卡（取数时查阅）
- **维护者：** 通道注册、路由与边界文档

## 材料从哪来

| 子目录 | 白话含义 |
|---|---|
| [`mcp/`](mcp/README.md) | MCP 通道注册、来源路由、B03、OPS 查询卡 |
| [`a2a/`](a2a/README.md) | Agent-to-Agent 协议边界（目前多为未实现壳） |

**关键原则：MCP 是获取通道，不是来源生产者。** 公告质量由巨潮等上游决定，行情/财务由通联等上游决定；通道故障时按 OPS 回退，禁止用模型记忆编造数据。

取证方法与完备度判断见 [`../05_method_libraries/03_取证/`](../05_method_libraries/03_取证/README.md)。

## 怎么用

1. 先想清楚「要证明什么」→ 取证方法库。
2. 再映射到通道 → [`mcp/B03_MCP通道注册.md`](mcp/B03_MCP通道注册.md)。
3. 按 [`mcp/OPS_MCP查询快速参考.md`](mcp/OPS_MCP查询快速参考.md) 操作并留痕。

## 怎么维护

- 新增/变更通道：更新 mcp 注册表、B03、OPS，并保持「通道 ≠ 生产者」表述。
- A2A 无经验证实现前保持 shell，不写假协议。
- 与 Runtime 本地网关/工具对接时，改代码在 `06_runtime`，配置权威仍在本目录。
