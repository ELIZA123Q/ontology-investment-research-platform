# judgment-reasoning · references

本目录是 [`judgment-reasoning`](../SKILL.md) Skill 的按需加载资源：裁决方法卡与附录协议。

在已有合格证据下，回答怎样形成、削弱、打断或修改判断——结论能说到多强（J4/J3/J2/J1/J0/不可判断），什么情况下要改判。

**定位：** 受约束的推理方法与裁决协议，不是现实世界因果规则真相库。必须区分事实/推断/假设，提出竞争解释并扫描反证，识别传导中间环节，说明改判条件；证据不足时输出「暂不可判断」。

文档写得完整，**不能证明**这些方法一定提高结论质量。下一阶段重点是对照案例验证（方法有效性验证），而不是继续扩写方法说明。

## 怎么用

按下列步骤选用方法（细节见各 A 方法卡与四份附录）。每张 A 方法说明统一为七部分。

1. 确认对象、时间、范围和版本一致；任务级先固定主研究命题。
2. 按判断单元从 A00 各选一个主方法，并沿用 `evidence-research` 给出的证据上限。
3. 需要看路径时，按 [附录：路径与阻断](A00-附录1_路径与阻断协议.md)；传导用 A06（机制问题用 A04）。
4. 按 [附录：反证与竞争解释](A00-附录2_反证与竞争解释协议.md) 与 [附录：通用认知错误](A00-附录4_通用认知错误与误用索引.md) 处理。
5. 形成方向、等级、把握、范围与局限；投资观点再做 A10；改判按 [附录：改判与版本](A00-附录3_改判与版本协议.md)。

简单任务不必用全套。共用规则见 [A00](A00_裁决总则.md) 及四份附录。

## 与相邻 Skill 的边界

| Skill | 负责 |
|---|---|
| [`research-design`](../../research_design/SKILL.md) | 判断什么、路径和变量是什么 |
| [`evidence-research`](../../evidence_research/SKILL.md) | 哪些证据能用、最多支持到多强 |
| **本 Skill** | 合格证据对命题的支持状态 |
| [`research-delivery`](../../research_delivery/SKILL.md) | 把已审过的判断准确写成交付物 |

冻结边界：只在已有合格证据上形成/削弱/打断判断，**不重新设计问题、不新增判断路径、不补充证据**。

## 从哪组方法进入

一个任务先定主研究命题，再按判断单元选用方法。

### 方法怎么分层看

| 层级 | 方法 | 作用 |
|---|---|---|
| 总则 | A00 + 四份附录 | 统一输入/输出/等级/退回/版本 |
| 判断类型主方法 | A01 状态 · A02 趋势 · A03 阶段 · A04 机制 · A05 归因 · A06 传导 · A07 分化 · A08 影响 · A09 预期差 | 每个判断单元选一个主方法 |
