# 表达标准

可复用表达规则以 [`05_投研表达标准.md`](05_投研表达标准.md) 为准。Research Lead 通过 `research-delivery` Skill 按需加载标准与模板。

## 给谁看

写交付物的研究员；维护表达门槛的工程师。

## 材料从哪来

| 文件 | 内容 |
|---|---|
| `05_投研表达标准.md` | 交付形态、结构、表达审计、质量门槛 |
| [`../../templates/`](../../templates/) | 五类交付模板与审计模板 |
| 本 README | 导览 |

本目录不复制 Runtime 合同。

## 怎么用

### 五类交付报告（模板见 `../../templates/`）

| 模板 | 报告类型 | 适用场景 | 核心要点 |
|---|---|---|---|
| `05A` | 事件点评 | 单点事件/公告/数据 | 事件→机制→影响→跟踪信号 |
| `05B` | 行业动态点评 | 政策/供需/价格等边际变化 | 变化点→路径→确定性→验证指标 |
| `05C` | 行业周期判断 | 景气/周期位置 | 核心论点、论证链、拐点条件 |
| `05D` | 公司业绩点评 | 财报/经营数据 | 业绩 vs 预期→驱动→可持续性 |
| `05E` | 主题深度研究 | 跨周期、跨标的主题 | Research Edge、可证伪信号、投资含义 |

### 表达审计与质量门槛（速览）

- 表达审计：`../../templates/05_表达审计模板.yaml`（须可追溯至已批准 Claim）
- 独立语义审查：`../../templates/05_独立语义审查模板.yaml`
- 高质量门槛见 `05_投研表达标准.md`
