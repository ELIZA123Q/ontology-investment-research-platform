# 半导体行业框架 — 8 个主框架与场景卡选择

> 上级：[`research-design` references](../../README.md) | 根目录：[`README.md`](../../../../../../../README.md)

做半导体相关研究的主入口。先选 **1 个主框架**回答核心机制；有产品/技术/事件特有增量时再挂 **0-1 张场景卡**。

## 研究员最短路径

1. 用一句话写清本次问题的产品、环节、客户、地区和时间
2. 判断核心分歧属于周期、国产替代、应用需求、设计商业化、制造、封装、设备还是材料
3. 选 1 个主框架；有明确场景增量时再选 0-1 张场景卡
4. 输出主路径、竞争解释、什么事实会推翻它，以及任务执行所需的决胜证据与约束

## 半导体的五个共同规律

1. **多时钟**：终端、订单、库存、价格、投片、良率、产能和收入确认不同步
2. **强分层**：产品、节点、晶圆尺寸、客户和地域混在一起时，总量结论经常失真
3. **有效供给小于名义供给**：认证、良率、关键工序、设备材料和系统配套会折损
4. **技术成功不等于商业成功**：样品、验证、design win、量产、复购和现金是不同阶段
5. **产业受益不等于公司兑现**：产品暴露、客户结构、产能、成本、合同和财务确认决定最终弹性

## 怎么维护

- **暂不新增主框架**；新机制优先场景卡且须真实任务触发
- 场景卡正文写在 [`02_scenario_task/02_scenarios/semiconductor/`](../../../../../../../02_scenario_task/02_scenarios/semiconductor/)
- 每主框架至少：1 个成立案例 + 1 个高迷惑性失败案例，方可记为已通过两次真实任务验证

### 禁止

- 把部署利用当全应用必经环节
- 把备份设备当主工艺突破
- 把无口径国产份额当韧性
- 把模块收入当芯片价值
- 在地缘场景卡内直接推股价
- 从行业供需跳估值
- 存储长协叙事直接当估值切换
