# A04 路径分段取证

路径分段取证：把「A 怎样影响 B」拆成一段段可核对的材料，而不是一次讲完故事。

## 1. 什么时候使用

用于为「A 怎样影响 B」或「已观察变化主要由什么造成」准备**路径分段材料**：起点、中介、暴露承接与结果。财务落点精细测算再接 A06。若起点事实未定，先做事实确认（A01）。这类问题通常还要做完整反向检索。

## 2. 取证逻辑

按边取证，不按完整故事拼材料：

```text
N0 起点事实／状态
→ E01 行为变化（方向、时滞、必要条件）
→ N1 中介状态
→ E12 暴露对象怎样承接
→ N2 经营／市场结果
```

每条关键边记录：谁改变了什么行为、预计多久、用什么信号观察、什么条件可能卡住。优先补最脆弱边的材料。

机制材料从弱到强：概念可行、时间一致、中介被观测、暴露差异、反事实／自然对照、跨对象或时期重复。两端同时变化而中间节点缺失时，材料只能支撑「相关或条件路径」的裁决输入，不能在此写成路径已经得到正式确认。

对主路径与最强竞争路径，分别收集它们对时间顺序、对象差异、中介、可能卡住的样本和分项的不同预测材料。

## 3. 最少必须取得什么

| 这份材料起什么作用 | 最低要求 |
|---|---|
| 主证据 | 起点由 A01／A02 覆盖；结果变量与业务窗口匹配 |
| 机制或承接 | 核心中介、关键边、真实暴露和合理时滞材料 |
| 独立交叉验证 | 中介行为、暴露差异或反事实中的至少一项 |
| 反证与限制 | 替代供应、库存缓冲、合同锁价、豁免、弱执行或竞争解释材料 |

取数前先核对：对象、业务时间、定义、单位、版本匹配。

## 4. 优先来源

起点用责任主体原文或合格直接测量；中介和结果用行业数据、公司行为、合同机制、客户／供应商披露和一手经营记录；暴露用收入、产能、客户、采购、地区或产品结构，不用产业链标签代替。

## 5. 完备度怎样受限

- 起点材料未覆盖：整条路径材料不可用或需先补 A01。
- 关键中介只有逻辑推演、无观测材料：完备度最高观察／受限。
- 暴露关系来自推测图谱：不得当作公司／资产级暴露证据。
- 结果时间早于起点的材料：必须归档，供 04 处理归因。
- 缓冲／替代／豁免材料足以质疑传导：必须进入反证角色，完备度相应降级。
- 两条路径无可区分预测材料：返回 02 改写，或并列移交。

## 6. 交给 04 什么

```text
路径草图：N0 → E01 → N1 → E12 → N2
各边已有／缺失材料清单（本方法不贴路径支持状态标签）
关键时滞与必要条件材料
暴露对象及证据定位
最强可能卡住的条件与竞争解释材料
证据完备度：充分／受限／观察／不可用
待裁决问题：各边与整条路径的命题支持状态（由 04 裁决；本方法不输出「路径已成立」）
```
