# 研究 Skill 入口

此目录放研究代理的可复用工作流，不存放第二份行业知识或正式证据。

| Skill | 何时使用 |
|---|---|
| [`touyan-gongkai-zhengju-diaoyan`](touyan-gongkai-zhengju-diaoyan/SKILL.md) | 跨行业执行公开来源查询、原文核验、反证扫描和结构化证据交接；不形成判断 |
| [`touyan-zhanlue-yanjiu-zongkong`](touyan-zhanlue-yanjiu-zongkong/SKILL.md) | 非 A 股权益或资产类别未明确的广义战略研究入口分流；明确 A 股权益完整研究优先交给权益总控 |
| [`touyan-yanjiu-sheji-pingshen`](touyan-yanjiu-sheji-pingshen/SKILL.md) | 取证前评审研究问题、对象范围、竞争假设、证据方案、反证和停止条件，并可输出可校验合同 |
| [`touyan-lunzheng-yuyan-bianji`](touyan-lunzheng-yuyan-bianji/SKILL.md) | 最终表达前检查事实、推断、判断和建议是否分离，语言是否清晰且不越界，并可输出可校验合同 |
| [`touyan-quanyi-yanjiu-zongkong`](touyan-quanyi-yanjiu-zongkong/SKILL.md) | 明确标记为 A 股权益的完整研究或研究更新；组织从问题到投资命题的流程 |
| [`touyan-quanyi-hongguan-yanpan`](touyan-quanyi-hongguan-yanpan/SKILL.md) | 明确标记为 A 股权益的宏观三问筛查与必要的深度研判 |
| [`touyan-quanyi-juece-bijiao`](touyan-quanyi-juece-bijiao/SKILL.md) | A10 投资命题后比较 ETF、个股选择或混合研究载体；不形成交易执行建议 |
| [`touyan-yinguo-shibie`](touyan-yinguo-shibie/SKILL.md) | 机制、归因、传导和影响兑现中的因果识别；区分正向、反向、共同原因和双向关系 |

Skill 负责入口与纪律；方法正文在[研究方法](../../研究方法/README.md)，机器规则在[研究规则](../../研究规则/README.md)。仓库里的 Skill 可作为 Codex 支持的项目级 Skill 使用，具体启用方式以使用者的 Codex 环境为准；不使用 Codex 时仍可阅读方法文件和运行 Python CLI。
