# 宏观三问研判协议

## 一、先确定筛查还是深挖

`screen` 的目的不是写宏观报告，而是判断三条轴线是否会改变权益结论。每条轴线只选择能够改变目标判断的少数证据，给出方向、置信度、竞争解释和目标相关性。

满足任一条件时升级到 `deep`：

- 用户明确询问经济、政策、信用、流动性或市场资金；
- 一条轴线可能改变核心假设的方向、强度、时点或风险；
- 三条轴线相互背离，无法用正常时滞解释；
- 目标属于强周期、政策驱动、利率/信用敏感、外需/汇率敏感或高久期风格；
- 现有结论依赖“流动性改善”“政策托底”或“经济复苏”等未经单独验证的前提。

若三轴均为低相关性，输出 `screen` 结果和停止理由，不继续取无关数据。

## 二、经济走向

经济走向回答目标研究期限内经济活动的边际方向，不把单一同比指标当成周期。

至少区分：水平与方向、总量与结构、环比与同比、名义与实际、扩散与局部、初值与修订。根据任务从增长、通胀、就业、信用和外需中选择至少两个有机制意义的状态轴，并记录主要竞争解释。

只有单一 GDP、PMI、CPI、社融或高频代理时，最多形成分轴信号；信号分化且无法解释时输出 `mixed` 或 `unknown`。

## 三、政策立场

按以下链条分层：

`政策目标/表态 → 正式工具 → 资源和执行 → 市场条件 → 主体行为`

政策结论描述的是对当前研究目标的有效立场，不是文件语气。只有表态时不得越过 `policy_fact`；只有降息、降准、预算或监管动作时，也必须检查实施范围、资源、约束和主体响应。财政、货币、产业、房地产和资本市场政策可能方向不同，应输出 `mixed`，不得用单一标签覆盖。

## 四、资金松紧采用双层口径

### 实体信用与融资条件

分别检查资金价格、数量、可得性、主体分布和用途。社融、信贷或货币总量增长不能单独证明企业投资和居民消费融资变宽；需要贷款标准、利差、审批、需求、资金用途或主体行为交叉验证。

### A股权益市场边际资金

从资金来源、资金用途与权益供给三面建立净图谱：

- 资金来源可包括公募/ETF、保险与长期资金、杠杆资金、外资、私募和居民配置；只选择当前目标真正相关的渠道。
- 资金用途需区分增量配置、存量换手、赎回应对、套利和短期交易。
- 权益供给需考虑 IPO、再融资、减持、解禁、分红和回购等净融资压力。
- 成交、换手、涨跌和单一渠道流入只能作为交叉验证，不能替代资金余额或净供需。

市场资金宽松不等于所有行业受益，也不等于风险偏好、盈利预期和估值同时改善。

## 五、行业与风格映射

映射必须写明传导机制、暴露方向、预期时滞和当前确认信号。经济、政策、实体融资和市场资金对同一目标可能相互抵消；先报告背离，再说明哪些信号能够区分路径。

行业/风格映射止于条件性暴露：周期/防御、价值/成长、大小盘、利率久期、信用敏感、外需/汇率敏感等。公司层必须另行验证收入结构、成本、资产负债表、交付和现金，不得由风格映射直接生成个股结论。

## 六、最小反例

- 只有政策表态：不得判断有效政策立场已经转向。
- 只有社融增长：不得判断实体资金全面宽松。
- 只有成交额或 ETF 流入：不得判断 A 股资金全面宽松。
- 三轴冲突：输出背离或不确定，不得强行合成单向宏观结论。
- 只有历史相关性：不得输出当前行业暴露；还需机制与当前微观确认。
