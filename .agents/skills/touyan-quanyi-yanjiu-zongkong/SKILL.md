# A股权益研究总控

## 职责

把一项完整权益研究编排成可追溯、可改判的投资命题。只负责研究设计、最小方法选择、跨层交接和结论表达；事实、机制和判断等级仍由仓库既有取证、框架、推理方法与人工发布门槛裁决。

## 进入与设计

- 仅对明确声明 `asset_class: equity`、`market_scope: A_share` 且 `mode: full_research | research_update` 的请求启用总控。自然语言已经明确市场和资产类别时可以在受理阶段补齐结构化字段；规划器不得凭标题关键词猜测。
- 先固定问题、对象、决策用途、信息截面和验证期限，再写一条当前最重要的矛盾与至少一条能区分的竞争假设。信息不足时记录缺口并停止，不填造观点。
- 在取证前形成结构化研究设计：假设的可观察预测和反证、最短证据方案、相关框架及选择理由、停止条件和监测触发点。运行合同见[研究设计与报告协议](references/research-design-protocol.md)。
- `judgment_types` 包含机制验证、因果归因、传导路径或影响兑现时，同时调用[通用因果识别 Skill](../touyan-yinguo-shibie/SKILL.md)生成 `CausalDesign`；缺少反向因果、共同原因或反事实设计时不得取证。证据完成后须先形成 `CausalAssessment`，正式判断通过独立的因果判断能力并回指该评估。
- 研究设计通过后，把 `evidence_plan`、信息截面、对象范围、业务时间、判断类型、取证方法和领域声明交给[公开证据调研 Skill](../touyan-gongkai-zhengju-diaoyan/SKILL.md)。收到通过结构校验的 `evidence_handoff` 后，才进入假设评价、推理和报告；完整研究不得从设计直接跳到观点。
- 只加载能够改变研究问题的框架。宏观三问调用现有[权益宏观研判 Skill](../touyan-quanyi-hongguan-yanpan/SKILL.md)，先筛查、按相关性深挖；不得从宏观或行业状态直接推断公司利润。

## 跨层交接

按需检验：宏观经济、政策与双层资金 → 产业供需、竞争和传导 → 公司盈利、现金与治理 → 市场预期、资金和定价 → [A10 投资命题裁决](../../../研究方法/推理/A10_投资命题裁决.md)。各层只在其已登记 output gate 内说话；保留背离与竞争解释，不把多条弱信号相加为强结论。

消费证据交接时，先检查每个核心任务的角色覆盖、来源独立性、冲突、反证查询和缺口影响。任何必要角色为 `partial` 或 `missing` 时，必须按 `completeness` 降级、转为观察或停止；不得由总控补写未取得的材料。纯 `evidence_refresh` 任务直接使用公开证据调研 Skill，不启动本总控。

个人原则只从[原则档案](../../../研究方法/个人方法论/principles.yaml)读取已确认且适用的条目；候选仅供用户逐条审阅，不影响规划或判断。[分析师视角](../../../研究方法/分析师视角/README.md)仅能提出候选解释和监测信号，不能作为当前事实、独立验证或投票权重。

## 停止与输出

研究止于“市场当前隐含什么、关键差异是什么、什么证据能促使修订、何时验证、何时失效”的可证伪投资命题。若预期基线、计价状态、上下行边界或验证窗口不足，依 A10 输出观察、不形成或阻断，而非勉强看多/看空。完整报告呈现最短证据链与决定性反证，不给买卖、仓位、目标价、择时或收益承诺；正式发布仍需人工批准。
