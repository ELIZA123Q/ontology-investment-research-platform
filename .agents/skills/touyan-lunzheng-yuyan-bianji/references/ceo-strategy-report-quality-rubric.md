# CEO 战略报告质量 Rubric

本文件用于 05 成稿和语言编辑。它不是新增研究结论的授权，只用于检查 04 已批准判断是否被写成 CEO 可决策的战略报告。

## 一票否决项

出现以下情况必须返回 02、03 或 04，不得靠写作补齐：

- 正文主章节在展示研究过程、口径边界、取证方法或免责；
- 摘要没有直接回答 CEO 应该怎么看、优先做什么、为什么现在做；
- 关键观点只有现象，没有原因、机制、结果和失效条件；
- 使用“导致、驱动、证明、源于、决定、必然、形成壁垒”等强因果词，但上游没有批准对应因果链；
- 优势只列规模、排名、牌照、品牌，没有拆到活动系统和可持续机制；
- 劣势只列短板，没有写成成因、后果、改善路径和观察指标；
- 战略举措只有口号，没有动作、资源、责任、指标和失败信号。

## 正文结构标准

CEO 报告的正文必须是结论组织，而不是过程组织：

| 位置 | 合格写法 | 不合格写法 |
|---|---|---|
| 标题 | 对象 + 核心矛盾 + 取舍 | 对象 + 研究报告 |
| 摘要 | 结论、证据、行动、改判信号 | 背景、方法、来源介绍 |
| 正文章节 | 判断句或强观点短句 | SWOT、背景、研究问题、资料整理 |
| 段首句 | 观点句 | “本文认为”“首先”“从某角度看” |
| 附录 | 口径、过程、来源、方法 | 正文主线需要的关键判断 |

## 因果表达标准

每个关键段落至少要能被还原为：

```text
因为 <事实/约束>，
通过 <机制/传导路径>，
所以 <业务结果/竞争结果>；
这意味着 <战略含义/行动取舍>，
除非 <失效条件/改判信号>。
```

写作时不必机械使用这五句话，但逻辑必须完整。尤其要区分：

- 事实：已经发生或可核验的材料；
- 推断：基于事实和机制得到的解释；
- 判断：04 已批准、允许进入报告的结论；
- 建议：在判断边界内提出的行动。

## 强因果词替代表达

当上游证据不足以支持强因果时，必须降级表达：

| 不允许 | 可使用 |
|---|---|
| A 导致 B | A 与 B 同期出现，可能通过某机制相关 |
| A 证明 B | A 支持 B 的一种解释，但仍需排除其他解释 |
| A 决定 B | A 是影响 B 的关键变量之一 |
| A 必然形成壁垒 | A 可能形成壁垒，前提是能力和管理系统持续成立 |
| 公司将受益 | 公司受益取决于客户转化、产品供给和费率结构 |

## 完稿前自检

交付前逐章检查：

- 只读摘要，CEO 是否已经知道核心判断和优先动作；
- 只读章节标题，是否能串成完整战略论证；
- 每段首句是否是观点句，后文是否解释机制和证据；
- 每个优势是否有来源、机制、可持续性和失效条件；
- 每个劣势是否有成因、后果、改善路径和观察指标；
- 每个举措是否有“为什么现在做”和“如何判断失败”；
- 附录是否承接了过程、口径和来源，而不是替代正文判断。
