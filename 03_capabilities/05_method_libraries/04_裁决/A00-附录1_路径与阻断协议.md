# A00-附录1 路径与阻断

本附录供 A04 和 A06 共用：统一记下每一段路径走到哪、中间有没有接上、时滞是否合理、哪里被打断，以及多条路径怎样一起看。A04 据此判断机制是否在运行，A06 据此判断影响到了哪里；本附录本身不形成行业、经营、财务或投资结论。

所有路径、节点、关系、必要性、时滞和多路径关系必须来自 02。04 可以判断既定路径当前走到哪，不能新增或改写路径。

## 每一段先问这六个问题

1. 起点在本次对象、范围和窗口内是否真的发生；
2. 这段作用关系为何适用于当前情形；
3. 预期主体行为或中间状态是否出现；
4. 当前是否进入 02 事先定好的合理观察窗口；
5. 是否被削弱、吸收、替代或阻断；
6. 当前证据最多支持到下一节点，还是已经支持到结果节点。

起点和终点同时变化，不能跳过中间六问；终点尚未出现，也不能在窗口未到时直接判失败。

## 节点与路径角色

02 应事先说明节点或路径承担的角色；04 只读取并检验。

| 角色 | 判断含义 |
|---|---|
| 必要节点/路径 | 失败即关闭对应下游 |
| 决定方向路径 | 其状态变化可能改变总体方向 |
| 放大路径 | 改变幅度或持续性，不单独决定方向 |
| 缓冲或吸收节点 | 延迟、缩小或终止影响 |
| 分流或分化节点 | 使影响进入不同对象或结果 |
| 反馈路径 | 下游结果反过来影响上游；仅在 02 已定义时使用 |
| 替代路径 | 可绕过原瓶颈；仅在 02 已定义并有独立承接时使用 |

若 02 未定义必要性、决定性或多路径关系，04 不得根据结果倒推这些角色，应退回框架（02）。

## 中间有没有真正接上

| 承接层 | 常见观测 | 说明什么 |
|---|---|---|
| 主体行为 | 采购、定价、排产、投资、审批、验证、客户切换 | 主体是否真正响应起点 |
| 中间状态 | 库存、订单、交期、稼动、良率、份额、产能 | 系统约束是否发生变化 |
| 结果节点 | 行业结果、经营、财务、现金流或风险 | 影响是否到达目标层 |

行为、状态和结果需要符合 02 预期的顺序。中介早于起点、结果早于行为，均削弱目标路径，除非 02 已明确反向或反馈关系。

## 这一段路径走到哪一步

下表用中文状态推规则。记录或对表时，可对照审计字段 `path_result_status`。不得在 A04、A06 或案例中另造同义状态。

| 研究员用语 | 审计记录用词 | 含义 | 下游怎么处理 |
|---|---|---|---|
| 成立 | `established` | 前提、作用关系和承接满足 | 可继续下一段 |
| 部分成立 | `partially_established` | 主方向在，但范围、幅度或对象受限 | 可继续，但要带着限制往下走 |
| 受到削弱 | `weakened` | 反证削弱路径但未打掉决定性前提 | 降强度或缩小范围后继续 |
| 被阻断 | `blocked` | 决定性前提或必要关系失败 | 关闭对应全部下游 |
| 证据不足 | `insufficient_evidence` | 当前无法判断该段是否发生 | 停止方向性下游，不等于没发生 |
| 存在争议 | `contested` | 支持与反证冲突且未消解 | 停止方向性下游，设置区分信号 |
| 不适用 | `not_applicable` | 本段不在当前对象或范围内 | 排除本段，不计支持或反证 |

“条件成立”不是路径状态。方向已有但范围受限记“部分成立”；尚未观察到且无法判断记“证据不足”。

## 承接、时滞与阻断

必须区分：

| 情况 | 处理 |
|---|---|
| 尚未进入合理窗口 | 停在当前节点，后续只作条件表达 |
| 已进入窗口但数据尚未披露 | 记“尚未观测”，不等于结果未发生 |
| 已超过窗口仍无必要中介 | 削弱或阻断对应路径 |
| 中介出现但被缓冲吸收 | 确认到达中介，限制结果层级 |
| 为维持结论必须不断延长窗口 | 退回框架（02），不允许事后改规则 |

常见打断点包括库存缓冲、长协与对冲、替代供应、政策豁免、认证或产能不足、客户延迟、执行走样和成本抵消。必须标出打断位置及受影响下游，不能只写“存在风险”。

## 什么时候可以往下推

1. **成立** 可无额外降级地进入下一段；
2. **部分成立** 或 **受到削弱** 可继续，但下游不得超过已留下的范围和强度；
3. **证据不足** 或 **存在争议** 在当前时点停止方向性下游判断；
4. **被阻断** 关闭对应全部下游；
5. **不适用** 只排除该段；
6. 下游等级不得高于决定性路径中最弱的一段。

## 多路径输入边界

多路径怎么合成，由 A06 完成；本附录只规定哪些路径可以进入合成：

- 每条路径均由 02 事先定义，并分别完成逐段状态；
- 标明路径是并行、串联、放大、抵消、分对象还是分时间关系；
- 标明是否共享同一中介或同一证据，避免重复计数；
- 反馈和替代路径未在 02 定义时不得临时纳入；
- 无法比较相对作用时，A06 必须保留净效应不确定，不能按路径数量投票。

## 至少写清这五件事

```text
每一段走到哪一步（成立 / 部分成立 / 受到削弱 / 被阻断 / 证据不足 / 存在争议 / 不适用）
→ 最后一个已核实节点
→ 第一条未通过路径及原因
→ 还缺什么才能继续
→ 因此当前不能推出的下游结果
```

这五项构成 A04、A06 共用的路径材料；各方法说明不再重复本附录内容。
