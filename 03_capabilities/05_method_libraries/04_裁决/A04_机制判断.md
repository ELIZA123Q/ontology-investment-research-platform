# A04 机制判断

## 方法定位

> **一句话哲学：机制不是相关关系，而是主体行为改变系统约束。**

A04 回答：一个由 02 事先定义的作用机制，在本次对象、情境和时间窗口中是否真实启动并运行。

理论上说得通不等于机制已经发生；起点和结果同时出现也不等于因果成立。A04 要看到主体为何响应、采取了什么行为、改变了什么资源或约束、出现了什么机制特有中介，以及什么信号会证伪该机制。

A04 不回答目标机制是不是主因、影响传到了哪个终点或公司盈利是否改善。这些问题分别进入 A05、A06 和 A08。

使用本方法前，除 A00 共用材料外，02 必须事先定好起点、主体、行为、必要中介、结果、适用与排除条件、典型时滞、阻断和可证伪条件。

## 判断模型与停止点

```text
适用条件
→ 主体感知变化
→ 主体改变行为
→ 行为改变资源、约束或激励
→ 机制特有中介出现
→ 在反证与替代解释下判断机制状态
```

真正有辨识力的机制证据通常同时具备：特异性、合理时序、对象分化、现实承接和可证伪性。

A04 读取附录1的路径结果和附录2的竞争解释比较，最终停在“机制是否运行、运行到哪个中介、适用于哪些对象”。它不重新维护逐段状态，也不做完整下游传导判断。

## 方法特有判断原则

本方法重点防范：[CE01](A00-附录4_通用认知错误与误用索引.md#ce01-相关替代因果)、[CE02](A00-附录4_通用认知错误与误用索引.md#ce02-相邻判断类型偷换)、[CE07](A00-附录4_通用认知错误与误用索引.md#ce07-遗漏共同驱动和最强竞争解释)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)。

### 1. 主体响应必须改变系统约束

机制不是“政策支持”“价格上涨”或“需求改善”这些压缩标签。必须说清：

1. 谁感知到什么变化；
2. 为什么会响应；
3. 采取了什么可观测行为；
4. 该行为改变了什么资源、约束或激励；
5. 哪个中间状态因此出现。

没有现实行为承接时，只能保留理论可能或“与机制一致”。

### 2. 机制特有中介优于一般结果

判断中介是否有识别力，应检查：其他机制是否也会产生同样信号、高暴露对象是否更明显、出现时间是否符合机制窗口、没有目标机制时该信号是否仍容易发生。

“价格上涨”通常缺少特异性；“受影响客户审批周期延长、采购提前、替代验证加速”更能识别具体机制。

### 3. 必要条件不能由多个支持条件补票

适用条件决定能否使用机制；必要条件缺失即不能认定运行；支持条件只增强判断；结果条件不能倒推前面机制成立。

逐段必要性、时滞和阻断状态完全按附录1用中文状态记录，A04 不另造状态；“证据不足”只表示当前无法判断该段，不等于该段未发生。

### 4. 时序、分化和可证伪条件共同约束

- 中介早于起点或结果早于行为，削弱目标机制；
- 尚未到窗口，保留条件判断；超过窗口无必要中介，削弱或阻断；
- 高暴露与低暴露对象没有预期差异，优先检查共同驱动；
- 每个机制判断必须给出至少一个会使其削弱或失效的可观测信号。

### 5. 替代解释进入判断主体

最强替代机制按附录2对称比较。若替代机制在特有中介、时序或对象分化上更强，应改写目标机制状态，不能只把它放进风险提示。

本方法特有误判：看到政策发布与行业价格同期上涨，就直接写“政策导致供给收缩”。

## 判断流程

1. 固定 02 的机制版本、适用范围、主体、必要中介和证伪条件；
2. 先检查适用条件，再读取附录1的逐段路径状态；
3. 识别最具特异性的主体行为和中介；
4. 检查起点、行为、中介的时序与高低暴露对象分化；
5. 读取附录2对最强替代机制和共同驱动的比较结果；
6. 判断理论可能、与机制一致、部分运作、实际运作、被削弱、争议、未验证或被阻断。

## 裁决与输出增量

| 证据结构 | 机制结论 | 这句话最多能说到哪 |
|---|---|---|
| 只有理论关系 | 理论可能 | 不写现实运行 |
| 起点和结果方向一致，缺特有中介 | 与机制一致 | 不写机制成立 |
| 部分行为或中介出现，范围受限 | 部分运作 | 限定对象、环节和窗口 |
| 主体行为、特有中介、时序和分化基本符合 | 实际运作 | 可形成机制判断 |
| 中介弱、时序异常或替代机制增强 | 被削弱/争议 | 降级或改写 |
| 行为未变或必要中介缺失 | 未验证 | J0/J1 |
| 决定性前提或必要路径失败 | 被阻断 | 关闭相应下游 |

除 A00 七项通用输出外，A04 还要额外写清：

- 主体响应及其改变的系统约束；
- 最具特异性的行为或中介；
- 最后已验证中介和第一条未通过路径；
- 高低暴露对象的分化结果；
- 最强替代机制的相对解释力；
- 可证伪条件及当前命中状态。

## 边界与退回

- A04 属于因果判断，通常最高 J3；满足公共路由表全部 J4 升级条件后可以形成范围内确认判断。
- 判断主因进入 A05；判断到达节点进入 A06；判断经营或财务影响进入 A08。
- 路径、时滞和阻断只使用附录1；竞争解释只使用附录2，不在 A04 另搞一套路径或比较规则。
- 主体、必要中介、适用/排除或证伪条件未定义，退回框架（02）。
- 现实中介或替代机制证据可补，退回取证（03）；只有理论故事时保留 J0/J1。
- 若必须修改机制结构或延长窗口才能符合结果，退回框架（02），不事后改规则。

## 例与误判

**合格例：** 政策生效后，受影响客户审批周期先延长，随后采购提前和替代供应商验证加速；低暴露客户没有同等变化。结论为“采购与验证环节的替代机制正在运行”，但批量订单尚未出现，因此不判断主因，也不写收入受益。

**高迷惑性反例：** “政策发布后行业价格上涨，因此政策导致供给收缩。”

该表述只有起点和结果，没有主体行为、特有中介或替代解释比较，触发 CE01、CE07 和 CE09。
