# 预期差判断框架

## 研究员先看什么

预期差不是“研究员比市场更乐观或悲观”，而是：**一项新的、可验证的判断，相对某个事件发生前已经存在且可追溯的预期基线，在哪个对象、指标、期间、情景或风险维度上形成了有经济意义的差异。**

研究首先要过三道硬门：

1. **基线门**：能否还原事件前谁在预期什么，时间戳、样本、口径和关键假设是否清楚；
2. **信息门**：新信息是否真的新增、可靠并与基线可比，而不是已公开事实、口径变化或事后修订；
3. **意义门**：差异是否足以改变收入、利润、现金流、持续期、风险或情景权重，而不仅是一个统计上的偏差。

只有前三项成立，才有必要继续研究市场是否已经修订、差异通过什么节点收敛，以及哪些风险或定价因素会抵消。

最容易混淆的是：实际值高于一致预期不自动等于可持续预期差；研究判断与共识不同不自动说明研究更正确；股价未涨不自动说明尚未计价，股价已涨也不能单独证明基线已充分修订；共识均值稳定不代表分布、样本和关键假设没有变化；正向基本面差异可能被持续期缩短、风险溢价上升或资本占用抵消。

没有事件前可追溯的预期基线时，必须停止使用“超预期”“低于预期”“市场没看到”“尚未计价”等表述。单次任务不应默认同时完成基线重建、经营预测、估值、价格反应和交易判断。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 事件前是否存在可追溯、可比较的预期基线；
- 一项新事实、研究判断或条件预测，相对该基线在哪些维度形成差异；
- 差异来自方向、幅度、时点、持续期、风险还是情景概率；
- 差异是否足以改变经营预测、价值输入或风险判断；
- 市场预期是否已经发生修订，修订的广度、速度和分歧如何；
- 哪个后续事实会使差异收敛、扩大或被证伪；
- 在证据允许时，形成“差异已确认但未充分修订”“差异已基本计价”“差异仍无法判断”等条件判断。

本框架不负责重新完成行业机制、公司业绩预测、财务质量或估值分析。独立研究判断应由相应上游框架先形成；本框架只比较该判断与事前市场基线。

本框架不输出股价方向、目标价、交易时点、仓位或确定性回报。即使预期差成立，也只能说明存在潜在的预期修订路径，不能证明资产价格必然按同方向变化。

最小逻辑依赖为：事件前基线 → 新信息或独立研究判断 → 同口径差异分解 → 经营/价值/风险含义 → 修订与计价状态 → 下一验证、收敛或证伪节点。任务可止于任一层。

有效基线至少包含：预期主体、对象、指标定义、预测期间、情景与前提、截面时间、样本与分布、来源与保存方式、有效性窗口。“市场认为”“大家预期”不构成有效基线。

差异至少按方向、幅度、时点、持续期、风险与情景拆解；只有改变收入、成本、利润、现金、资本投入、持续期、风险或情景权重中至少一项时，才具有进一步研究价值。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 预期主体 vs. “市场整体” | 卖方一致预期、公司指引、买方内部、价格隐含和用户给定基线不是同一主体 |
| 事件前基线 vs. 事后修订值 | 事后数据库往往覆盖历史快照，会制造虚假的“早已预期”或“超预期” |
| 共识均值 vs. 预期分布 | 均值可能不变，但离散度、尾部情景和样本构成已经变化 |
| 新事实 vs. 新解释 | 同一事实可能早已公开，只是研究者给出不同机制解释；两者证据要求不同 |
| 信息差 vs. 有经济意义的预期差 | 有新信息不代表该信息足以改变市场关键假设 |
| 预期修订 vs. 资产价格反应 | 预测和关键假设已经修订，价格仍可能因流动性、风格或风险偏好反向波动 |
| 未修订 vs. 未计价 | 分析师预测未变不代表资金没有提前交易；价格上涨也不代表所有差异均已吸收 |
| 催化事件 vs. 收敛机制 | 只有能够改变市场关键假设的事件才是收敛节点，普通新闻不自动构成催化 |

### 1.3 禁止跳步

- 不能从“实际值高于一致预期”直接推出存在可持续正向预期差；
- 不能用事件后的最新一致预期替代事件前基线；
- 不能用研究员自己的旧观点、主观印象或“市场普遍认为”替代可追溯预期；
- 不能只比较数字，不核对对象、指标定义、期间、币种、范围和情景；
- 不能把公司指引与市场预期、研究员预测和价格隐含预期混成一个基线；
- 不能从新信息“看起来重要”直接推出它会改变收入、利润、现金、持续期或风险；
- 不能用股价涨跌单独反推市场原先预期或计价程度；
- 不能从盈利预测尚未修订直接推出市场尚未计价，也不能从股价提前上涨直接推出差异已经充分计价；
- 不能从单期超预期直接提高长期增长、持续期或合理估值；
- 不能把风险溢价、利率、风格和资金流造成的价格变化归因于预期差；
- 不能把“有催化”写成价格一定收敛，必须说明催化改变哪项关键假设；
- 不能从预期差直接生成交易建议或确定性资产影响。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 找不到事件前、带业务时间的预期记录 | `prior_expectation_baseline` 及后续预期差判断 |
| 预期主体、样本、指标、期间或情景无法还原 | 可比较预期基线 |
| 只能取得事件后的最新一致预期，无法恢复历史快照 | 事前预期差判断 |
| 研究判断与基线对象、口径、范围或时间不一致 | `expectation_gap` |
| 新信息早已公开或已进入原基线，不能证明其新增性 | 信息增量与预期差归因 |
| 新信息只是未经验证的传闻、单一观点或口径不明估算 | 强预期差判断 |
| 差异不能改变任何经营驱动、现金流、持续期、风险或情景权重 | 有经济意义的预期差 |
| 只有单期实际偏差，无法区分一次性、时点错位和持续性 | 中长期预期差及收敛路径 |
| 只有价格反应，没有预测、假设、估值或行为侧交叉证据 | “已计价”或“未计价”判断 |
| 市场价格主要由宏观、风格、流动性或风险溢价主导，且无法分离 | 单向计价结论 |
| 无法指出后续什么事实会改变双方判断 | `convergence_path` |
| 上游研究判断自身缺少最低证据或可证伪条件 | 用该判断与市场形成高强度预期差 |

高级输出停止时，可以保留已经确认的预期来源、历史快照、信息事实和口径缺口。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 事前预期基线重建** | 事件前谁在预期什么，基线是否真实、有效且可比较 | 用户使用“超预期、低于预期、市场没看到、共识”等表述；历史数据库可能被覆盖 | 带时间戳一致预期、公司指引、卖方报告快照、价格隐含假设、样本和分布 | 真正事前基线 vs. 事后修订、样本变化、公开均值不代表交易基线 | 基线无法恢复时止于材料缺口，不进入预期差判断 |
| **B 信息增量与差异分解** | 新信息究竟新增了什么，差异发生在方向、幅度、时点、持续期还是风险 | 已有基线，出现财报、数据、政策、产品、调研或独立研究判断 | 原始新事实、可比预测、假设变化、驱动桥、情景概率 | 真正信息增量 vs. 旧信息重述、口径变化、一次性或非经济性偏差 | 无法证明新增性或经济意义时，只保留信息事实 |
| **C 预期修订与计价状态** | 市场是否已经修改关键假设，差异是未修订、部分修订还是已基本吸收 | 差异已经具备经济意义，用户询问“是否计价、为什么价格不动、是否仍有差异” | 盈利预测修订、目标假设变化、修订广度与速度、估值输入、价格和持仓反应 | 未计价 vs. 已提前计价、风险溢价抵消、市场关注不同时间窗口 | 缺少两个以上独立维度时，不形成已计价/未计价结论 |
| **D 收敛、扩大与证伪路径** | 哪个后续事件会改变市场或研究判断，差异何时、如何收敛 | 已确认存在分歧，需要定义下一验证点和改判条件 | 财报、订单、价格、产品验证、政策执行、现金流、风险事件、预测修订 | 差异将收敛 vs. 验证延后、研究判断错误、风险因素压过基本面 | 没有可观察验证节点时，只记录静态分歧，不写催化或收敛 |

### 路线选择要求

02 调用本框架时必须说明：

1. 本次目标止于基线重建、差异确认、计价状态，还是收敛路径；
2. 哪一条路线是主路线，哪一条竞争路线可能产生不同结论；
3. 哪 2—3 个关键判断单元决定最终输出；
4. 哪 3—5 个预期变量、经营输入或市场信号真正具有判别力；
5. 使用的是哪一种预期主体，为什么它与本次问题相关；
6. 本次不使用哪些预期来源、价格信号、估值指标或事件，以及为什么；
7. 上游独立研究判断来自哪个框架，下游哪些资产定价问题不在本框架内完成。

四条路线全部展开，通常意味着把预期差框架误用成完整公司研究、估值报告和市场交易分析。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的报告模板。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| EG-C1 对象、主体与业务时间 | 核心 | 每次调用 | 01 已完整定义时可简写 | 谁对什么对象、指标、期间和情景形成预期 |
| EG-C2 事前基线有效性 | 核心 | 每次调用 | 不得裁剪，只能止于不通过 | 基线是否为事件前真实快照，样本和假设是否可追溯 |
| EG-R1 多源基线重建 | 条件 | 单一数据库可能被覆盖，或正式共识不能代表真实交易基线 | 已有可靠、完整的原始快照 | 一致预期、指引、卖方、隐含预期和低语预期如何分层 |
| EG-R2 信息类型与新增性 | 核心 | 需要形成 `expectation_gap` | 任务只恢复历史基线 | 新信息是事实、估算、指引、预测还是观点，是否真的新增 |
| EG-R3 同口径差异分解 | 核心 | 需要形成 `expectation_gap` | 任务只检查信息事实 | 差异发生在方向、幅度、时点、持续期还是风险 |
| EG-R4 经营与价值含义 | 条件/核心 | 需要判断差异是否重要 | 任务仅记录统计偏差且明确不影响经营 | 差异改变了哪些业务驱动、现金流、持续期或风险输入 |
| EG-R5 修订广度与速度 | 条件 | 用户关心市场是否开始修订、谁先修订 | 任务止于静态预期差 | 预测、假设和情景是否扩散，修订是局部还是系统性 |
| EG-R6 计价状态交叉验证 | 条件 | 用户提出“已计价、未计价、股价为何不动” | 不涉及市场价格或缺少可靠市场数据 | 预测、估值、价格、持仓和风险因素共同说明什么 |
| EG-R7 收敛与证伪节点 | 条件/核心 | 需要形成 `convergence_path` | 任务只确认当前差异 | 什么事实会使市场修订、研究判断改判或差异继续扩大 |
| EG-E1 估值影响 | 扩展/交接 | 差异已经改变价值输入，需要进一步分析 | 价值输入未识别或任务不涉及估值 | 交给 BF-VA-01，不在本框架内重复建模 |
| EG-E2 资产价格与交易 | 扩展/交接 | 用户进一步询问价格、催化、交易或收益 | 本框架任何情况下均不直接完成 | 交给后续资产影响或表达环节，并继承全部限制 |

单次任务必须记录启用与排除模块。存在于框架中的基线、价格、持仓和估值信号，不代表自动进入取证或结论。

## 4. 候选变量、信号与预期时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 一致预期均值、中位数与分布 | 正式公开基线和分歧度量 | 可能掩盖样本变化和非正式交易预期；样本少或极端值会失真 |
| 公司指引 / 卖方单家 / 买方或用户基线 | 公司自身、假设还原或特定决策主体预期 | 指引可能保守或策略性；单家不能代表全市场；主体和版本必须明确 |
| 价格隐含预期 | 反推增长、风险或情景概率 | 高度依赖估值模型、风险溢价和其他参数 |
| 新事实、实际值与研究员条件预测 | 与基线比较的现实输入和独立判断 | 单点偏差可能一次性或口径错位；研究判断须由上游证据支撑 |
| 预测修订幅度、广度、速度与关键假设 | 判断市场是否改变数值基线或机制理解 | 修订滞后、样本变化或公开数字不变但假设已变会造成错觉 |
| 估值输入、价格成交、持仓与风险溢价 | 计价状态辅助信号和抵消因素 | 受宏观、风格、流动性影响，不能单独定性；与预期差方向可能相反 |
| 下一验证事件 | 收敛与证伪变量 | 必须能改变关键假设，而非普通信息发布 |

基础框架不设置固定“超预期幅度”、统一事件窗口、价格反应阈值或修订扩散比例。02 应从中选择本次真正决定基线、差异、计价或收敛的 3—5 个变量。

### 4.2 代理变量要求

直接事前预期、关键假设或真实交易基线不可得时，可以使用代理，但必须说明：代理对应哪一种预期主体和指标；在事件前是否真实可见；与目标预期之间的机制；样本、模型、风险溢价和市场结构如何影响代理；失效条件；使用后如何降级预期差和计价判断；是否有公司指引、预测修订、价格隐含、经营事实或市场行为侧第二类交叉验证。

股价涨跌、历史估值分位、新闻情绪、搜索热度和单家报告默认不能无条件替代事前市场预期。

### 4.3 关键预期时钟

只选择本次相关时钟，但不得混用：

`基线形成 → 信息公开 → 研究识别 → 预测修订 → 基本面兑现 → 市场计价 → 收敛验证`

所有基线、信息和价格证据必须标注业务时间与可见时间。不能把同一天下载的数据默认视为同一信息截面。

## 5. 竞争解释、反证与降级

| 观察现象 | 主解释 | 主要竞争解释 | 区分信号 | 命中竞争解释后的动作 |
|---|---|---|---|---|
| 实际值高于一致预期 | 正向信息增量 | 一次性、会计口径、低基数、确认时点或样本均值失真 | 同口径驱动桥、现金、持续性、分布 | 只保留单期偏差 |
| 公司指引高于共识 / 研究预测高于共识 | 管理层或研究提供正向增量 | 指引口径不同、期间错位、更高低语预期；或研究假设过乐观 | 指引定义、历史兑现、事件前分布；上游机制证据与反证 | 无法对齐或证据不足时不形成正式/高强度预期差 |
| 一致预期均值未变 | 市场尚未修订 | 样本增删抵消、分布变化、关键假设已变但数字未变 | 中位数、离散度、样本、模型假设 | 切换到分布和假设分析 |
| 盈利上修但股价不涨 / 事件前股价上涨 | 尚未计价 / 市场提前计价 | 已提前交易、持续期短、风险溢价上升；或风格、流动性、空头回补 | 事件前价格、估值、风险、修订时点、相对反应 | 缺少交叉证据时不判断未计价/已吸收 |
| 利好公布后股价下跌 | 预期已过高或低于低语预期 | 风险溢价、市场共振、获利了结、结构性卖盘 | 正式与非正式基线、预测修订、相对反应 | 价格反向不自动证伪基本面判断 |
| 差异长期不收敛 | 市场忽视关键信息 | 验证节点不足、研究判断错误、期限错位或风险抵消 | 事实兑现、预测修订、现金、风险 | 切换到证伪或时钟错位分析 |

### 降级规则

- 只能取得事件后共识：停止差异判断，只登记待补基线；
- 新信息在事件前已公开并进入原模型：不再称为新信息预期差；
- 数字差异来自期间、币种、范围或会计口径：调整后再比较；
- 单期偏差无法影响全年、持续期或风险：降级为单期偏差，不进入计价路径；
- 预测修订已广泛发生且关键假设接近研究判断：转入剩余差异与持续期分析；
- 价格反应主要由风险、利率或风格解释：不形成单向未计价或已计价判断；
- 后续事实向市场原基线靠拢：下调或取消预期差，记录改判原因；
- 没有任何事件能改变关键假设：删除催化表述，只保留监测条件。

合格反证必须能够改变基线有效性、信息新增性、同口径经济意义、差异维度、修订/计价状态、收敛节点或研究判断维持/降级/证伪中的至少一项。“市场可能不认可”“股价可能波动”不构成合格反证。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-EG-01.prior_expectation_baseline` | 预期主体、对象、指标、期间和情景清楚；截面时间早于新信息可证明；样本、均值、中位数、分布和关键假设可还原；来源可回到原始快照；有效窗口和已知限制明确 | 只登记材料缺口，不进入预期差比较 |
| `BF-EG-01.expectation_gap` | 比较双方口径一致；新信息类型、可靠性和新增性清楚；差异维度及方向明确；差异影响的经营、现金、持续期、风险或情景输入可指认；有主要竞争解释、反证和当前判断限制 | 不能改变任何关键经营或价值输入的偏差，不应通过该门槛 |
| `BF-EG-01.convergence_path` | 当前市场修订和计价状态清楚；下一验证事件及业务时间明确；该事件会改变哪项关键假设；收敛、维持、扩大和证伪有区分信号；风险、流动性等其他解释已考虑；未按预期收敛时有改判动作 | “有财报”“有政策”“有发布会”不自动构成收敛路径 |

更高一层写不出来时，不抹去已经确认的预期来源、历史快照、信息事实和口径缺口。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 6.2 组合与交接

- 行业状态、政策、价格或产业链变化：由 BF-SD-01、BF-PI-01、BF-PC-01、BF-VT-01 等先形成独立事实与机制判断；
- 公司业绩和现金判断：由 BF-EE-01、BF-FS-01 提供独立条件预测，本框架只与事前基线比较；
- 历史数字是否可信：由 BF-FQ-01 判断，财务基线不可靠时预期比较强度必须受限；
- 价值输入和估值范围：交给 BF-VA-01，预期差可提供事前基线和计价约束，但不替代估值分析；
- 风险溢价和压力情景：交给 BF-RS-01；
- 资产价格、催化与表达：交给后续资产影响或 05 表达环节，只能继承条件和限制。

不涉及市场预期、事前基线或信息修订的问题，不应启用本框架。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- **建立基线**：带时间戳的一致预期快照及样本说明；公司历史指引与关键假设；事件前卖方报告或可追溯预测；价格隐含预期的模型与参数；用户明确给定并版本化的内部基线；
- **确认信息增量**：原始公告、财报、政策、数据或产品事实；可比口径的独立研究预测；对收入、利润、现金、持续期或风险的驱动桥；信息首次公开时间和市场可见时间；
- **判断修订和计价**：预测修订幅度、广度、速度和关键假设；公司指引与市场模型变化；相对价格、估值、成交和风险溢价；必要时的持仓或期权隐含信息；宏观、行业和风格等其他可能解释；
- **形成收敛路径**：可观察的下一验证事件；该事件与关键假设之间的机制；支持、削弱和证伪条件；明确的时间窗口和改判动作。

新闻转述、事后数据库、无时间戳目标价和单一股价反应只能作为线索，不能单独承担正式预期差判断。具体来源、证据组合和验收由03_capabilities/05_method_libraries/03_取证管理。

### 7.2 本体边界

正式任务优先引用 `Judgment`、`MarketExpectation`、`ExpectationGap`、`Scenario`、`Signal`、`AssetImpact`、`ReasoningTrace` 及正式定义的证据、时间和来源对象。行业专用一致预期指标、事件窗口和隐含假设模型，只有在领域本体正式定义时引用。

预期分布、样本稳定性、修订广度与速度、信息新增性、差异维度、经济意义输入、计价程度、收敛速度和验证事件属于框架概念或任务候选，不因写入本文件自动成为正式本体定义。具体数据库字段、共识算法和事件研究公式属于研究工具。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 财报超预期、新产品验证、政策落地、研究判断领先共识、价格提前计价等不同机制任务 |
| 重点检查 | 是否先恢复事件前基线；是否证明信息新增和经济意义；是否用交叉证据判断计价；是否写出可观察收敛节点 |
| 经验沉淀 | 事件窗口、修订频率和隐含模型优先进入场景卡或案例复盘；跨任务重复且有失效边界的机制才写回稳定内核 |

复盘应记录：哪类事前预期最难恢复；哪些数据库会用事后修订覆盖历史值；哪些“超预期”最终只是口径、一次性或时点错位；哪些研究判断正确但市场早已计价；哪些价格反应被误归因于基本面预期差。框架更新不以增加篇幅为目标。
