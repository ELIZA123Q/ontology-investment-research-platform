# 研究概念字典（本体）

这里定义"研究世界里有什么、它们怎么关联"——就像一本字典，确保所有人对同一个概念的理解一致。

**这里面存的是稳定定义**（对象类型、关系类型、状态类型、约束规则），**不存某一次研究的具体事实或结论**。某次研究用了什么证据、得出什么判断，那些在 `instances/` 里。

## 三层结构

| 层 | 目录 | 存放 |
|----|------|------|
| 通用概念 | [`01_通用`](01_通用) | 跨行业通用的对象、关系、证据与判断规范 |
| 行业扩展 | [`02_领域`](02_领域) | 行业特定概念；目前主要是半导体（存储周期、管制、国产替代等） |
| 迁移记录 | [`03_迁移`](03_迁移) | 概念定义的历史变更记录（追溯用，不是当前定义的入口） |

研究员日常**很少需要改这里**。做 02 阶段搭分析框架时，如果规范提到某个类型或变量，可以来这里查它的稳定定义。
