# 房地产与地产链语义结构域说明

## 1. 对象身份

城市、项目、房企、政策、销售、库存和信用状态必须分开。销售改善不等于开工改善，政策放松不等于需求恢复。

## 2. 关键属性口径

- 销售需区分面积、金额、均价和城市范围。
- 库存需区分可售库存、广义库存和去化周期。
- 开工、施工、竣工是不同阶段。
- 房企现金流需区分销售回款、融资、债务到期和受限资金。

## 3. 稳定关系

| 关系组 | 业务关系 | 通用承接 |
|---|---|---|
| 政策与需求 | 政策影响购房约束 | `Event` → `StateVariable` |
| 销售与库存 | 销售影响去化周期 | `Metric` → `Observation` |
| 销售与开工 | 销售和资金影响开工 | `StateVariable` 传导 |
| 房企与信用 | 现金流和债务影响信用风险 | `RiskExposure` / `JudgmentUnit` |

## 4. 与通用模型连接

政策、城市、房企、销售、库存、开工和信用指标进入研究范围后，通过通用证据和判断链处理。

## 5. 禁止用法

- 不把政策出台直接写成销售改善。
- 不把单城成交外推全国。
- 不把销售金额改善等同面积改善。
- 不把竣工改善直接写成新开工恢复。
