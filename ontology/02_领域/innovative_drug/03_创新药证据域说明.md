# 创新药证据域说明

## 1. 证据链

创新药证据复用通用 `SourceDocument → EvidenceClaim → EvidenceFact → EvidenceAssessment / EvidenceBasket`。临床、审批、支付和销售证据必须先支撑 Observation、Signal 或 Hypothesis，不得直接生成最终 Judgment。

## 2. 领域证据画像

第一批证据画像包括：

| 画像 | 主要用途 | 最低材料 |
|---|---|---|
| clinical_evidence | 判断临床证据质量 | 试验设计、终点、样本、安全性、对照 |
| regulatory_status | 判断审批阶段 | 监管公告、审评状态、获批文件或标签 |
| reimbursement_access | 判断支付与准入 | 医保目录、支付限制、价格、执行时间 |
| commercialization | 判断销售兑现 | 销售额、处方量、准入医院、公司披露 |
| competitive_context | 判断竞争解释 | 竞品标签、疗效、安全性、价格和渠道 |

## 3. 代理指标

| 代理 | 目标状态 | 主要限制 |
|---|---|---|
| 处方量 | 放量趋势 | 样本渠道有限，可能滞后 |
| 医院准入数量 | 可及性 | 进院不等于真实处方 |
| 医保纳入 | 支付改善 | 价格和限制可能抵消收入弹性 |
| 学术指南推荐 | 治疗地位 | 指南不等于支付或销售 |
| 生产批次/供应 | 供给准备 | 供应充足不代表需求成立 |

## 4. 时间与范围

- 临床证据区分读出、发表、监管采纳和标签写入。
- 审批证据区分受理、审评、获批和上市后要求。
- 医保证据区分谈判、目录生效、地方执行和医院采购。
- 销售证据区分发货、处方、终端销售和收入确认。

## 5. 冲突与降级

若临床疗效、安全性、支付限制、竞品或销售证据冲突，必须保留冲突并降低判断强度。缺少销售或准入证据时，可以判断审批阶段变化，但不得判断商业化兑现。

## 6. 二轮证据质量补充

| 场景 | 主证据 | 反证/竞争解释 | 质量下限与代理误用 |
|---|---|---|---|
| 临床读出到审批概率 | 完整临床终点、安全性、适应症范围 | 对照不可比、安全性风险、标签范围收窄 | 最低 Q2；新闻稿不得替代试验材料 |
| 医保谈判降价后量价兑现 | 医保限制、价格、处方或销售验证 | 竞品更优、降价吞噬收入弹性、进院慢 | 最低 Q3；进医保和进院数量不得替代处方收入 |
