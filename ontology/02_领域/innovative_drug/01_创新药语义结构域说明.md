# 创新药语义结构域说明

## 1. 对象身份

创新药研究中必须区分六类对象：

- 公司是经营主体，不等于药品或管线；
- 药品是产品，适应症是应用范围；
- 临床试验是证据来源和事件，不是商业化结果；
- 注册、受理、获批和上市是不同阶段事件；
- 医保、进院和处方限制是支付与准入状态；
- 销售额、处方量和患者数是指标，不是产品身份。

## 2. 关键属性口径

- 药品必须说明通用名、商品名、靶点/机制、剂型和适应症范围。
- 适应症必须说明患者范围、治疗线数、联合用药和排除条件。
- 临床证据必须说明试验阶段、终点、对照、样本、随访和安全性。
- 审批事件必须区分申报、受理、优先审评、获批和上市后要求。
- 医保准入必须记录目录状态、支付限制、价格和执行时间。
- 销售兑现必须区分发货、处方、终端销售和公司确认收入。

## 3. 稳定关系

| 关系组 | 业务关系 | 通用承接 |
|---|---|---|
| 公司与产品 | 公司拥有、授权或商业化某药品 | `Company` 与 `Product` 的任务关系 |
| 产品与适应症 | 药品用于某适应症和患者范围 | `Product` → `Application` |
| 产品与事件 | 临床、申报、获批、医保等事件作用于药品 | `Event` 绑定主体和范围 |
| 证据与指标 | 临床终点、处方量、销售额支撑状态变量 | `EvidenceFact` → `Observation` |
| 支付与兑现 | 医保、进院和价格影响销售兑现 | `StateVariable` 传导 |

这些关系先作为任务本体视图中的对象和边，不新增正式关系类型。

## 4. 与通用模型连接

创新药对象可进入 `ResearchScope`；药品、适应症、审批事件和销售指标可绑定 `StateVariable`、`Observation`、`Event`、`EvidenceFact` 和 `JudgmentUnit`。最终判断仍通过通用判断模型完成。

## 5. 禁止用法

- 不把临床成功写成商业化成功。
- 不把受理、优先审评或突破性疗法认定写成获批。
- 不把医保纳入写成收入确认。
- 不把潜在适应症市场写成已获批市场。
- 不用单季度收入直接外推全年放量。
