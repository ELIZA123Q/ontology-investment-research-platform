# 保险语义结构域说明

## 1. 对象身份

保险公司、保单、产品、保费、新业务价值、赔付、准备金、投资资产和偿付能力必须分开。保费增长不等于价值增长，投资收益不等于承保改善。

## 2. 关键属性口径

- 保费需区分新单、续期、规模保费和价值保费。
- 新业务价值需说明假设、渠道和产品结构。
- 财险需区分赔付率、费用率和综合成本率。
- 投资收益需区分总投资收益、净投资收益和公允价值变动。
- 偿付能力需区分核心和综合偿付能力。

## 3. 稳定关系

| 关系组 | 业务关系 | 通用承接 |
|---|---|---|
| 产品与价值 | 产品结构影响新业务价值 | `StateVariable` |
| 赔付与利润 | 赔付率和费用率影响承保利润 | `Metric` |
| 投资与利润 | 利率和市场影响投资收益 | `Metric` 传导 |
| 资本与增长 | 偿付能力影响业务扩张 | `BlockingFactor` |

## 4. 与通用模型连接

保险指标进入研究范围后，通过通用证据和判断链处理。

## 5. 禁止用法

- 不把保费增长写成价值改善。
- 不把投资收益改善写成承保改善。
- 不混用寿险和财险指标。
- 不输出交易建议。
