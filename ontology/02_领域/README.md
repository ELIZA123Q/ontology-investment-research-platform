# 领域本体包

本目录保存行业或领域特定的稳定语义、状态变量、证据口径和判断连接方式。通用对象、证据链和判断链仍以 [`../01_通用`](../01_通用) 为唯一基础；领域包不得重定义通用五模型。

## 包结构

除半导体已具备正式扩展外，新领域先采用同一阅读结构，并统一视为 `draft domain seed`。该状态表示“可用于案例验证的领域参数种子”，不表示行业框架成熟，也不表示允许新增正式本体类型。

| 文件 | 作用 |
|---|---|
| `00_*领域本体概述.md` | 唯一权威、领域边界、能力和冻结条件 |
| `01_*语义结构域说明.md` | 对象身份、属性口径、稳定关系和禁止用法 |
| `02_*判断推理域说明.md` | 状态变量、事件、传导模板和更新失效 |
| `03_*证据域说明.md` | 证据画像、代理指标、时间范围和降级规则 |
| `business_instances.yaml` | 领域业务参数草案，当前不等同正式本体 extension |

## 沉淀原则

1. 先用通用五模型承接领域对象和判断链；
2. 领域包只保存稳定结构，不保存单次事实、结论和报告；
3. 同一领域跑过多个案例并出现重复缺口后，再评估是否新增正式 extension；
4. 正式扩展必须满足半导体包同等级的冻结条件。
