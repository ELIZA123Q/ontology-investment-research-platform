# 公用事业与电力运营语义结构域说明

## 1. 对象身份

公司、电厂、机组、装机容量、发电量、电价、燃料成本和利润必须分开。装机不是发电量，发电量不是收入，煤价现货不是公司燃料成本。

## 2. 关键属性口径

- 发电量需区分发电量、上网电量和售电量。
- 电价需区分上网电价、市场化交易价、容量电价和补贴。
- 燃料成本需区分现货、长协、库存和公司实际采购。
- 利润需剔除一次性投资收益、补贴和减值影响。

## 3. 稳定关系

| 关系组 | 业务关系 | 通用承接 |
|---|---|---|
| 机组与电量 | 机组利用小时影响电量 | `StateVariable` |
| 成本与利润 | 燃料成本影响毛利 | `Metric` 传导 |
| 电价与收入 | 电价机制影响收入质量 | `Event` / `Metric` |
| 区域与分化 | 区域供需和交易规则影响公司分化 | `ResearchScope` |

## 4. 与通用模型连接

公司、电厂、机组、电价、燃料成本、发电量和利润指标进入研究范围后，通过通用证据和判断链处理。

## 5. 禁止用法

- 不把煤价下行直接写成利润改善。
- 不把装机增长直接写成发电增长。
- 不混用计划电价、市场化电价和容量补偿。
- 不把一次性投资收益写成经营改善。
