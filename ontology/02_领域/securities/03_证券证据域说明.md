# 证券证据域说明

## 1. 证据链

证券证据复用通用证据链。市场数据、监管文件和公司披露必须先形成 EvidenceFact 或 Observation，再进入 Signal、Hypothesis 和 Judgment。

## 2. 领域证据画像

| 画像 | 主要用途 | 最低材料 |
|---|---|---|
| market_activity | 判断市场活跃状态 | 成交额、换手率、时间序列 |
| margin_financing | 判断两融业务 | 两融余额、利差、风险指标 |
| underwriting_cycle | 判断投行业务 | IPO/再融资/债券规模和费率 |
| business_mix | 判断公司分化 | 分部收入、成本、资本和风险 |
| profit_realization | 判断利润兑现 | 收入、费用、自营、减值和净利 |

## 3. 代理指标

| 代理 | 目标状态 | 主要限制 |
|---|---|---|
| 成交额 | 经纪业务活跃度 | 受佣金率和产品结构影响 |
| 两融余额 | 信用业务活跃度 | 需同时看利差和风险 |
| IPO 家数 | 投行业务线索 | 项目数量不等于收入 |
| 市场指数 | 风险偏好背景 | 不能替代经营事实 |
| 基金发行 | 财富管理景气 | 需看费率和渠道结构 |

## 4. 时间与范围

- 市场数据可高频更新，但财务兑现通常按季度。
- 政策证据区分发布、生效和实际执行。
- 自营收益需要与市场波动和持仓结构对齐。
- 行业总量和公司分部必须分开。

## 5. 冲突与降级

若成交改善与佣金率下行、自营亏损、投行下滑或成本上升冲突，必须降低利润弹性判断。缺少公司分部数据时，只能形成行业线索，不得写成公司业绩判断。

## 6. 二轮证据质量补充

| 场景 | 主证据 | 反证/竞争解释 | 质量下限与代理误用 |
|---|---|---|---|
| 投行业务周期修复 | 发行完成规模、费率、收入确认 | 审核收紧、费率下降、项目集中度过高 | 最低 Q3；受理或过会不得替代发行收入 |
| 自营收益扰动与经营质量分离 | 分部收入、自营敞口、公允价值和减值 | 一次性收益、自营亏损、费用刚性 | 最低 Q2；净利润不得替代主业质量 |
