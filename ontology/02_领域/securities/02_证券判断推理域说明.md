# 证券状态与判断连接说明

## 1. 定位

本文件说明证券业务参数如何进入通用五模型，不定义新的推理动作或 A01—A10 方法。状态变量和传导模板的轻量权威是 `business_instances.yaml`。

## 2. 领域状态变量

证券第一批状态变量按市场活跃度、经纪收入、两融收入、投行周期、自营暴露、成本费用和利润兑现分类。它们定义观察对象，不保存具体读数。

## 3. 领域事件

常见事件包括交易制度调整、资本市场政策、IPO/再融资节奏变化、利率变化、市场波动、监管处罚和公司业务调整。事件必须记录发生、公布、生效和研究截止时间。

## 4. 传导模板的边界

证券常见路径为：

```text
市场活跃度/政策事件 → 业务量或费率 → 分部收入 → 成本/风险调整 → 利润兑现
```

成交额改善只支持经纪业务线索；若缺少佣金率和成本证据，不得外推利润弹性。两融余额改善必须同时检查利差和风险。

## 5. 分化判断

证券公司分化通常来自业务结构、客户结构、资本实力、风险暴露和成本效率。不能用单一市场变量直接排序公司。

## 6. 更新与失效

若市场制度、费率、风险暴露或业务结构发生变化，应返回 02 重拆路径；仅新增成交、两融或财务读数时，从 03 局部重算。

## 7. 二轮场景与停判点

| 场景 | 必须停判点 | 不得外推 |
|---|---|---|
| 投行业务周期修复 | 缺发行完成规模、费率或项目归属 | 受理项目不得当作投行收入 |
| 自营收益扰动与经营质量分离 | 缺自营敞口、分部收入或减值成本 | 净利润改善不得直接推出主业改善 |

证券场景不用于短线交易、指数点位预测、个股买卖建议或仓位建议。
