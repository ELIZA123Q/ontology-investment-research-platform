# 证券领域本体概述

## 1. 唯一权威

证券领域当前采用“通用五模型 + 领域业务参数 + 方法资产”的轻量结构，暂不新增正式领域 extension：

- 正式对象、关系、证据链和判断链复用 [`../../01_通用`](../../01_通用)。
- 领域状态变量、证据画像、传导模板和代理指标：[`business_instances.yaml`](business_instances.yaml)。
- 取证与裁决方法：[`../../../methods`](../../../methods)。

本目录服务于证券公司经营和资本市场服务研究，不用于短线交易、指数点位预测、个股买卖建议或仓位建议。

## 2. 领域边界

纳入证券公司经纪、两融、投行、资管、自营、财富管理等业务，以及成交额、两融余额、发行融资、费率、成本和风险暴露。市场上涨本身不是经营改善，股价表现也不能反推基本面。

## 3. 正式新增对象

本阶段不新增正式对象类型。领域对象投影到通用模型：

| 领域对象 | 通用投影 | 说明 |
|---|---|---|
| 证券公司 | `Company` | 经营主体 |
| 成交额、两融、承销规模 | `Metric` | 市场与业务状态 |
| 政策和市场制度变化 | `Event` | 影响业务量、费率或风险 |
| 业务条线 | `BusinessSegment` / `ResearchScope` | 经纪、投行、资管、自营等 |
| 业绩弹性 | `StateVariable` | 收入和利润兑现状态 |

## 4. 领域能力

领域包支持以下问题：

- 市场活跃度是否改善；
- 活跃度是否传导到经纪和两融收入；
- IPO、再融资和债券承销节奏如何影响投行；
- 自营收益是否掩盖经营性业务趋势；
- 费率、成本和风险暴露是否削弱利润弹性。

## 5. 冻结条件

只有当多个证券研究案例证明通用对象不足以表达业务条线、费率、风险暴露或资本市场事件时，才考虑新增正式领域扩展。第一阶段只沉淀来源、变量和证据画像。
