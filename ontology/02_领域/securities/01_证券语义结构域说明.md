# 证券语义结构域说明

## 1. 对象身份

证券研究必须区分：

- 证券公司是经营主体；
- 经纪、投行、资管、自营和两融是业务条线；
- 成交额、两融余额、承销规模和佣金率是指标；
- 政策、制度调整和市场波动是事件；
- 收入、利润和 ROE 是财务兑现结果；
- 股价和估值不是经营事实。

## 2. 关键属性口径

- 成交额需说明市场范围、资产类别和时间窗口。
- 两融需区分余额、利差、担保风险和业务收入。
- 投行业务需区分 IPO、再融资、债券和财务顾问。
- 自营需区分权益、债券、衍生品和投资收益口径。
- 佣金率需区分毛佣金、净佣金和代销/席位等收入。

## 3. 稳定关系

| 关系组 | 业务关系 | 通用承接 |
|---|---|---|
| 公司与业务 | 公司拥有业务条线 | `Company` 与任务内业务范围 |
| 市场变量与收入 | 成交、两融、发行影响收入 | `StateVariable` 传导 |
| 政策与业务 | 政策改变发行、交易或融资约束 | `Event` → `StateVariable` |
| 风险与利润 | 自营和信用风险影响利润质量 | `RiskExposure` / `BlockingFactor` |

## 4. 与通用模型连接

证券领域对象可进入 `ResearchScope`；市场指标、政策事件、业务收入和财务指标可绑定 `StateVariable`、`Observation`、`EvidenceFact` 和 `JudgmentUnit`。

## 5. 禁止用法

- 不用指数涨跌替代成交活跃度。
- 不把成交额增长直接写成净利润增长。
- 不把行业数据直接外推单家公司。
- 不用股价表现反推经营改善。
- 不输出买卖建议、目标价或仓位。
