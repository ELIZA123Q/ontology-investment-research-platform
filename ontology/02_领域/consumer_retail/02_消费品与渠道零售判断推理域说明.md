# 消费品与渠道零售状态与判断连接说明

## 1. 定位

本文件说明消费品与渠道零售业务参数如何进入通用五模型。

## 2. 领域状态变量

状态变量按渠道库存、终端动销、价格体系、费用投放、经销商质量、收入质量和品牌分化分类。

## 3. 领域事件

常见事件包括提价、促销、渠道政策变化、新品发布、旺季动销、库存调整和公司经营披露。

## 4. 传导模板的边界

典型路径为：

```text
终端需求 → 动销 → 渠道库存 → 发货/回款 → 收入质量 → 利润兑现
价格政策 → 批价/折扣 → 毛利/费用 → 利润兑现
```

发货增长若缺少动销和库存验证，不得写成需求改善。

## 5. 分化判断

消费品分化通常来自品牌力、价格带、区域、渠道结构和费用效率。不能用单一收入同比排序公司。

## 6. 更新与失效

渠道政策或价格带变化时返回 02；仅新增动销、批价或财务读数时从 03 局部重算。

## 7. 二轮场景与停判点

| 场景 | 必须停判点 | 不得外推 |
|---|---|---|
| 渠道库存出清 | 缺渠道库存、折扣率、回款或退货 | 库存下降不得直接推出需求改善 |
| 提价是否损伤动销 | 缺成交价、销量复购、折扣和费用 | 标价提升不得直接推出品牌定价权 |

消费判断必须区分发货、动销、GMV、净收入和现金流质量。
