# 消费品与渠道零售语义结构域说明

## 1. 对象身份

品牌、产品、渠道、经销商、终端消费者、价格和库存必须分开。公司发货不是终端消费，提价公告不是成交价格，渠道库存不是公司存货。

## 2. 关键属性口径

- 渠道库存需说明层级、地区、价格带和库存月数。
- 动销需说明终端样本、时间窗口和渠道覆盖。
- 批价需区分建议价、成交价、批发价和促销价。
- 公司收入需结合合同负债、回款和费用投放。

## 3. 稳定关系

| 关系组 | 业务关系 | 通用承接 |
|---|---|---|
| 公司与品牌 | 公司经营品牌和产品 | `Company` → `Product` |
| 渠道与库存 | 渠道库存影响发货和价格 | `StateVariable` |
| 动销与兑现 | 终端动销影响收入质量 | `Observation` → `JudgmentUnit` |
| 价格与利润 | 批价、折扣和费用影响利润 | `Metric` 传导 |

## 4. 与通用模型连接

品牌、产品、渠道、价格、库存、动销和财务指标均可进入研究范围并绑定证据和判断单元。

## 5. 禁止用法

- 不把发货写成真实消费。
- 不把公司存货替代渠道库存。
- 不把建议零售价替代成交价。
- 不用社零数据直接判断单家公司。
