# 半导体判断推理域说明

## 研究员先看什么

把语义对象与有时间的证据转为**可验证、可反证、可分级**的判断。不保存原始材料，不输出买卖建议。

研究时用它：发生了什么事件、持续观察哪些变量、如何传导与竞争解释、形成什么判断与影响。

主线：事件/观测 → 状态变量 → 传导与竞争解释 → 假设 → 信号 → 判断 → 预期比较 → 资产影响/降级。

> 可复用变量与模板权威：`business_instances.yaml`；事件类型与约束：`reasoning.yaml`。

---

## 1. 事件类型（业务含义）

需求/预测、客户资本开支、订单出货、库存周期、价格交期、产能投资、良率工艺、产品路线图、认证量产、技术突破或受阻、供应中断恢复、竞争行为、产业政策、贸易出口管制、环境安全、标准认证、知识产权法律、市场预期重定价等。完整键名见 `reasoning.yaml`。

## 2. 关键变量（怎么用）

变量定义「持续判断什么」，观测记录「某时点读到什么」。目录按主题分组（商业化、供需库存、制造、技术替代、竞争、政策与预期等），完整键与说明见 `business_instances.yaml`。本文不平行维护 46 项长表。

选用原则：只纳入能改变本次路径或结论强度的变量；易得但不决定判断的材料不抢预算。

## 3. 禁止项

- 事件或指标直接跳到公司业绩/资产影响而不经变量与路径；
- 把单次观测写进变量定义；
- 在领域层改写一级推理对象语义。
