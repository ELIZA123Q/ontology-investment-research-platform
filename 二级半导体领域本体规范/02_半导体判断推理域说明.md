# 半导体判断推理域说明

## 1. 域定位

半导体判断推理域把语义对象和有时间的证据转化为可验证、可被反面证据推翻、可分级的研究判断。

本域关注：

- 发生了什么类型的事件；
- 哪些判断变量可能变化；
- 变量之间如何传导；
- 哪些条件支持、削弱或逻辑失效传导；
- 不同变量条件如何组合为通用情景；
- 基本面变化与市场预期之间是否存在差异。

本域不保存原始材料，不复制语义分类，不提供规则引擎阈值，也不输出买卖建议。

## 2. 半导体推理主线

```text
语义对象
  + 有来源、有业务时间的 Event / Observation
→ 判断型 StateVariable 变化
→ 变量传导和其他可能解释
→ Hypothesis
→ validation / tracking / weakening / blocking Signal
→ Judgment
→ MarketExpectation 比较
→ AssetImpact 或降级原因
```

事件只是触发器，不能直接产生资产影响。每一步都必须保留适用条件、滞后和反面证据。

## 3. 事件类型

`reasoning.yaml.event_type_taxonomy` 定义 18 类通用事件：

| 事件组 | 类型 |
|---|---|
| 需求与周期 | 需求预测、客户资本开支、订单出货、库存周期、价格交期 |
| 供给与制造 | 产能投资、良率工艺、供应中断与恢复 |
| 产品与技术 | 产品路线图、认证量产、技术突破或受阻 |
| 竞争 | 降价、扩产、并购、产品切换和客户争夺 |
| 政策与法律 | 产业政策、贸易与出口管制、环境安全、标准认证、知识产权与法律 |
| 市场预期 | 一致预期、估值和价格隐含预期重定价 |

Event 必须是已经发生或正在发生的具体事实，并具有业务时间和证据。事件类型本身不是 Event。

## 4. 关键变量设计原则

关键变量不是指标字段，而是可持续观察、可比较、可形成假设并能参与传导的判断维度。

合格变量应说明：

1. 定义和判断用途；
2. 可挂载的语义对象；
3. 观察口径；
4. 对应证据配置；
5. 典型反面证据。

具体收入、价格、库存数量、交期周数、良率和估值是 Observation。它们可以帮助判断关键变量，但不替代变量定义。

## 5. 关键变量体系

本体定义 46 个判断型关键变量，每个变量标注 `variable_role`（primary_judgment_variable、intermediate_variable、company_mapping_variable、market_variable 或 counter_variable）。

### 5.1 需求

| 变量键 | 中文名 | 判断用途 |
|---|---|---|
| `end_market_demand_strength` | 终端需求强度 | 判断产业链需求是否具备真实终端基础 |
| `customer_capex_intensity` | 客户资本开支强度 | 判断系统建设是否会转化为采购 |
| `order_visibility` | 订单能见度 | 区分询单、备货和可兑现订单 |
| `adoption_penetration` | 产品采用与渗透进展 | 区分概念验证、导入和主流采用 |

### 5.2 供给与产能

| 变量键 | 中文名 | 判断用途 |
|---|---|---|
| `supply_availability` | 供给可得性 | 判断目标时间和地域能否获得合格供给 |
| `capacity_tightness` | 产能紧张度 | 判断有效产能是否低于可兑现需求 |
| `capacity_expansion_progress` | 产能扩张进展 | 判断新增供给何时、以何种质量释放 |
| `supply_elasticity` | 供给响应弹性 | 判断供需缺口能否快速修复 |

### 5.3 制造

| 变量键 | 中文名 | 判断用途 |
|---|---|---|
| `yield_maturity` | 良率成熟度 | 判断名义产能能否成为有效供给 |
| `process_capability` | 制程能力 | 判断工艺能否稳定满足规格 |
| `production_cycle_pressure` | 生产与交付周期压力 | 判断排队、在制品和交付风险 |
| `quality_reliability` | 质量与可靠性水平 | 判断认证、量产和现场失效风险 |

### 5.4 库存与订单周期

| 变量键 | 中文名 | 判断用途 |
|---|---|---|

| `backlog_pressure` | 未交付订单压力 | 判断未来交付强度和取消风险 |

### 5.5 价格与经济性

| `profit_pool_shift` | 产业利润池迁移 | 判断利润在设计、制造、设备材料和系统间迁移 |

## 6. 传导模板

`reasoning.yaml` 定义 28 条跨场景业务传导。每条模板包含锚点对齐、结构化方向逻辑、证据 profile 引用和默认其他可能解释。

| 传导组 | 模板 |
|---|---|
| 需求 | 终端需求→订单、资本开支→半导体需求、采用→规模需求、订单→产能压力、需求→设备材料 |
| 库存周期 | 去库存→订单下行、补库存→订单上行、库存缓冲→冲击延后 |
| 供给制造 | 供给约束→价格交期、扩产→供给缓解、良率→有效供给与成本 |
| 工艺与技术 | 工艺复杂度→设备材料、微缩→良率成本、先进封装→基板设备测试、竞争力→替代 |
| 商业化 | 客户认证→量产、本地替代→供应链韧性 |
| 政策 | 产业政策→投资产能、出口管制→合规与供给 |
| 竞争与公司 | 竞争→定价利润池、公司暴露与执行→业绩 |
| 市场预期 | 基本面→预期差、预期差→定价反映 |

每条模板固定包含：

- 源变量、目标变量和中介变量；
- 业务方向映射；
- 时间滞后；
- 适用条件；
- 支持证据要求；
- 削弱条件；
- 判断不再成立的条件。

模板不是已经证实的因果事实。一次研究中是否命中，仍需 Observation、Signal、证据和其他可能解释。

## 7. 典型传导结构

### 7.1 需求链

```text
终端需求强度
→ 产品采用和客户资本开支
→ 订单能见度
→ 产能紧张与未交付订单
→ 制造、设备和材料需求
```

逻辑失效点包括客户库存、订单取消、产品未认证和架构变化。

### 7.2 供给瓶颈链

```text
供应中断或产能紧张
→ 供给可得性下降
→ 库存先行缓冲
→ 生产周期和交期压力
→ 产品价格压力
→ 定价权决定利润如何分配
```

替代供应、许可恢复、库存充足或需求下修均可削弱传导。

### 7.3 扩产与良率链

```text
产能扩张进展
+ 良率成熟度
+ 客户认证进展
→ 有效供给增加
→ 产能紧张缓解
→ 交期和价格压力变化
```

扩产公告本身不代表有效供给。

### 7.4 技术替代链

```text
技术综合竞争力
+ 技术成熟度
- 客户切换成本
→ 技术替代强度
→ 产品、工艺、设备和材料需求结构变化
→ 公司技术路线暴露
```

新旧路线可能互补，不能默认替代。

### 7.5 政策链

```text
政策或管制事件
→ 政策支持强度 / 出口管制强度
→ 合规摩擦、市场准入或资本开支变化
→ 供给可得性、替代进展和产业结构变化
→ 公司暴露与执行
```

必须检查正式原文、适用对象、生效时间、许可、豁免和执行情况。

### 7.6 公司与市场链

```text
产业变量变化
→ 公司价值链和技术路线暴露
→ 执行与交付能力
→ 业绩弹性
→ 与一致预期比较
→ 预期差
→ 市场反映程度
```

缺少公司暴露、执行、预期或反面证据时，不得形成高置信资产影响。

## 8. 信号和反面证据

领域本体继承平台的五类 Signal：

| 角色 | 作用 |
|---|---|
| validation | 支持假设或判断 |
| tracking | 持续观察进度 |
| catalyst | 催化判断兑现，不直接支持假设 |
| weakening | 降低假设或判断强度 |
| blocking | 命中核心前提并逻辑失效假设 |

削弱与逻辑失效必须区分：

- 削弱通常影响幅度、概率或时间；
- 逻辑失效直接否定不可缺失的核心前提；
- 同一反面证据是否构成逻辑失效，取决于它与假设条件的关系，不取决于措辞强弱。

## 9. 通用情景模板

四类情景直接保存在 `reasoning.yaml`：

| 情景 | 含义 |
|---|---|
| base | 当前可验证趋势按正常节奏推进 |
| upside | 需求、采用或政策强于基准，供给和执行未形成同等逻辑失效 |
| downside | 需求、订单或采用弱于基准，库存、竞争和成本压力增强 |
| stress | 供应中断、政策管制、质量事故或地域集中触发非线性冲击 |

场景模板只规定变量组合、验证点和证伪点。它不包含公司、产品、事件实例、数据加载或运行步骤，因此不需要独立场景文件。

## 10. 业务场景原型

除 base、upside、downside、stress 四类结果情境外，`business_scenario_tags` 定义九类业务场景标签：周期复苏、周期下行、供应冲击、扩产过剩、技术切换、国产替代、出口管制、先进封装瓶颈、库存修正。

## 11. 推理禁止项

- 需求增长直接等于行业或公司利润增长；
- 供给受限直接等于上游公司受益；
- 扩产公告直接等于有效产能释放；
- 技术指标领先直接等于客户采用；
- 客户认证直接等于收入确认；
- 政策支持直接等于公司受益；
- 出口管制直接等于国产替代成功；
- 公司属于热门产业链直接等于高业绩弹性；
- 基本面判断成立直接等于资产价格仍有空间。

## 12. 工程化边界

本文件和 `reasoning.yaml` 不定义：

- 规则 ID 和阈值表达式；
- 数据字段和接口；
- 对象或变量运行引用；
- 场景加载顺序；
- 模型调用和任务编排；
- 自动写回和输出契约。

这些属于后续工程化和运行包。
