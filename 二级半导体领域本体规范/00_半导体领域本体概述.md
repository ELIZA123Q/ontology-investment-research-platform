# 半导体领域本体概述

## 研究员先看什么

半导体领域本体是一级投研本体的**行业扩展**：补充半导体特有的稳定对象、分类、变量与证据配置，让存储周期、国产替代、先进封装等问题能落到同一套说法上。

研究时优先看：对象在产业里是什么、与什么稳定连接；判断时观察什么变量；如何传导、何时削弱；需要什么证据与反证。

**不是：** 公司/型号/工厂/指标/资讯库，也不承载单次任务运行配置。

---

## 1. 相对一级的增量

复用一级全部通用对象，不重定义。领域仅新增：

- **技术路线**：可复用的制程/器件/封装/集成路线
- **制造设施**：有独立位置与工艺能力的制造设施

需求来源复用「应用」，地域复用「地区」。独立命名空间，不得重定义一级类型。

## 2. 产业边界

**纳入**：设计—制造—封测链路；设备与材料；逻辑/存储/模拟/功率/光电/传感等器件；硅基与化合物等路线；需求、商业模式、竞争、供应链与政策暴露。

**相邻不展开**：显示、光伏、PCB、整机等仅作应用/产业连接。

**排除**：具体实例与时点读数、新闻事件、任务运行配置、买卖建议。

完整性 = 表达能力完整，不是样本穷举。

## 3. 文件权威

| 文件 | 作用 |
|---|---|
| `common.yaml` | 版本、依赖、边界与门槛 |
| `semantic.yaml` | 对象扩展、关系、受控分类 |
| `reasoning.yaml` | 事件类型、推理约束、实例图引用 |
| `evidence.yaml` | 质量维度、来源原则、商业化阶段、覆盖规则 |
| `business_instances.yaml` | 可复用变量、证据画像、传导/情景模板 |
| 本目录 `01/02/03_*.md` | 可读原则与概念速览 |

分类在 `semantic.yaml`；变量/画像/模板在 `business_instances.yaml`。

## 4. 推理与证据边界

禁止：事件/需求/政策/技术指标直接跳到资产影响或公司业绩。变量定义「持续判断什么」，观测记录「某时点读到什么」。

人工验收场景所需资源键见 `business_instances.yaml` 与评测用例，不在此展开矩阵。
