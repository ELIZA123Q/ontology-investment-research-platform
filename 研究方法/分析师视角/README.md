## 入库和晋升原则

1. 核对作者、原文、日期、具体位置和适用时钟。出版机构的原始研报或本人一手访谈可入库；媒体二次概括只能帮助发现线索，不替代原文。站点的抓取日期不能当作发表日期。
2. 一张卡只保存一个可证伪的主命题及其理论层次。每个理论组件都用 `source_refs` 指向具体原文；若多个原文只提供相邻议题，标明关系，不“拼”成作者从未提出的综合模型。
3. 卡片本身不得充当独立证据。原文是历史研究假说的出处；当前市场事实、机制是否有效以及竞争解释须另行检验。共享数据不得重复计票。
4. 进入通用宏观、产业或定价框架前，需要跨来源、跨任务的独立验证和失败案例审查。同一作者的两篇文章不是独立验证。本版不自动晋升任何人名视角。
