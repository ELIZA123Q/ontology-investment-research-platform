# 研究方法导览

本目录保存可追溯的研究方法，不是自动产生事实或正式判断的第二套规则。完整 A 股权益研究从[研究总控 Skill](../.agents/skills/touyan-quanyi-yanjiu-zongkong/SKILL.md)进入，再按问题选择最小必要框架。

| 子目录 | 作用 | 起点 |
|---|---|---|
| [框架](框架/) | 通用宏观、产业、公司、定价框架和行业框架 | [框架导览](框架/README.md) |
| [取证](取证/) | 来源、口径、证据上限与反证 | [取证导览](取证/README.md) |
| [推理](推理/) | 判断类型、裁决与失效条件 | [推理导览](推理/README.md) |
| [半导体](半导体/) | 半导体专用的研究目录与场景说明 | [领域导览](半导体/README.md) |
| [个人方法论](个人方法论/) | 候选个人原则与案例复盘；未确认原则不生效 | [原则治理](个人方法论/README.md) |
| [分析师视角](分析师视角/) | 有出处、可证伪的候选解释；不投票、不作事实 | [视角治理](分析师视角/README.md) |

通用顺序是“界定问题与期限 → 宏观筛查 → 产业与公司机制 → 预期和定价 → 可证伪投资命题”。何时深挖由问题相关性和证据门槛决定，不要求每个任务读完全部文件。
