# 取证方法库

本库回答要证明什么、使用哪种取证方法、最少需要哪些材料、优先从哪里获取，以及证据最多允许什么程度的表达。

- `A01`—`A09`：事实、状态、趋势、机制、分化、财务、市场预期、反证和代理指标方法。
- `B00`—`B02`：来源边界与速查。
- `OPS_*`：真实来源查询和回退手册。
- [方法登记](method-registry.yaml)：方法说明与计划器索引，不产生执行效果。

取证方法由 `LogicDefinition` 组合为任务 DAG，由 `CapabilityDefinition` 实际调用，证据准入和判断上限只由 `研究规则/rules.yaml` 中的机器条件决定。证据“充分”仅表示可做明确裁决，不表示原命题为真。
