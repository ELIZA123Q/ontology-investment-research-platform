# 推理方法库

本库回答在已有合格证据下，怎样形成、削弱、打断或修改判断。方法文档是 `LogicDefinition` 和推理能力的参考，不是本体，也不构成隐式执行顺序。

- `A01`—`A03`：状态、趋势与阶段判断。
- `A04`—`A08`：机制、归因、传导、分化与影响。
- `A09`—`A10`：预期差与投资命题。
- `A00` 及附录：共同裁决、路径阻断、反证、版本与误用约束。
- [方法登记](method-registry.yaml)：将任务判断类型映射到应读取的推理正文，不产生执行顺序。

任务可只调用一个方法，也可按数据依赖组合多个方法并行执行。是否调用、何时停止、是否补证或降级，由当次编译的 DAG 和机器规则决定，不由文档章节或步骤数决定。

图归档样例见 [存储周期](../../examples/memory-cycle/report.md) 和 [设备替代](../../examples/equipment-substitution/report.md)。
