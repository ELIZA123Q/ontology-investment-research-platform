# A03 阶段判断

## 方法定位

> **一句话哲学：阶段不是标签，而是一组共同成立的约束条件。**

A03 回答：行业、产品、技术、公司或周期对象当前符合哪个预定义阶段，是否正在迁移、回退、跳转、分化或处于过渡未决。

阶段不是一个看起来相似的名称，也不是对状态和趋势的简单汇总。它要求进入、维持、退出、排除和时序条件共同形成可复核的阶段位置。

使用本方法前，除 A00 共用材料外，02 必须事先定好阶段集合、进入/维持/退出/排除条件、必要与支持条件、领先/同步/滞后变量、允许迁移和分化汇总规则。

## 判断模型与停止点

```text
当前状态与趋势
+ 进入、维持、退出约束
+ 领先/同步/滞后顺序
+ 允许的迁移关系
+ 分项状态
= 当前阶段位置及迁移状态
```

阶段是一组约束：哪些状态变量处于什么区间、哪些趋势已形成、哪些滞后结果尚未出现仍合理、哪些退出条件一旦命中原阶段立即失效，以及对象允许进入哪些相邻状态。

A03 最有价值的输出不是阶段名称，而是：哪些约束已经松动、哪些仍未满足、原阶段是否结束、下一阶段是否已经确认。

停止点是当前阶段及迁移状态；成因进入 A05，经营或财务影响进入 A08。

## 方法特有判断原则

本方法重点防范：[CE02](A00-附录4_通用认知错误与误用索引.md#ce02-相邻判断类型偷换)、[CE05](A00-附录4_通用认知错误与误用索引.md#ce05-单点局部或幸存样本外推总体)、[CE08](A00-附录4_通用认知错误与误用索引.md#ce08-事后调整基线阈值窗口或阶段定义)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)。

### 1. 阶段定义必须先于数据

每个阶段至少有：

| 条件类型 | 作用 |
|---|---|
| 进入条件 | 何时开始考虑进入 |
| 维持条件 | 何时确认仍在阶段内 |
| 退出条件 | 哪些信号使原阶段失效 |
| 排除条件 | 哪些相似现象不属于该阶段 |

不能看完数据后修改阶段门槛；现实无法表达时退回框架（02）更新框架候选。

### 2. 四条优先级是硬规则

1. **退出条件优先于维持条件：** 决定性退出命中后，不得用一般维持信号保留原标签；
2. **必要条件优先于支持条件：** 缺少必要项不能靠多个支持项补票；
3. **同步条件优先于单一领先信号：** 领先信号只提示切换，不能单独确认新阶段；
4. **原阶段结束不等于下一阶段确认：** 两者之间允许存在过渡、空档或分化。

### 3. 按时序使用条件

```text
领先变量：提示可能切换
同步变量：确认当前状态变化
滞后变量：确认结果扩散或兑现
```

只有领先条件满足，最多写切换迹象；领先与同步条件满足可写切换中或新阶段早期；滞后结果也确认后才提高确认等级。超过合理窗口仍无同步承接，应削弱切换判断。

### 4. 迁移不必线性，但必须事先定好

可识别的迁移包括：

- 顺序迁移：进入相邻阶段；
- 失败回退：切换未承接，回到原阶段；
- 跳跃迁移：外部冲击跨过中间阶段；
- 分叉迁移：不同产品、地区或主体进入不同阶段。

A03 只识别 02 允许的迁移，不临时创造阶段或跳转关系。

### 5. 阶段分化优先于勉强总体化

总体阶段成立前，至少检查产品、地区、客户/渠道、龙头与长尾、领先与滞后环节。关键分项不同步时，应写“总体修复，但高端产品扩张、通用产品低迷”，而不是选择单一标签。

本方法特有误判：用价格上涨一个指标把行业贴为“上行周期”，或把原阶段退出直接写成已经进入下一阶段。

## 判断流程

1. 固定阶段定义版本、对象、窗口和允许迁移；
2. 列出进入、维持、退出、排除及必要/支持条件；
3. 标注领先、同步和滞后变量的当前状态；
4. 先检查原阶段退出，再检查原阶段维持；
5. 按必要条件和同步条件检查候选阶段；
6. 检查分项、回退、跳转、超时未承接和冲突；
7. 输出阶段内、切换迹象、切换中、新阶段确认、过渡未决、回退、跳转、分化或暂不可判断。

## 裁决与输出增量

| 条件结构 | 阶段结论 | 这句话最多能说到哪 |
|---|---|---|
| 进入与维持满足，退出未命中 | 阶段内 | 可按既定定义写出当前/历史阶段位置 |
| 下一阶段只有领先条件满足 | 切换迹象 | 不写新阶段成立 |
| 原阶段开始退出，下一阶段部分进入 | 切换中 | 明示仍缺条件 |
| 原阶段失效，下一阶段未建立 | 过渡未决 | 不强行贴标签 |
| 下一阶段必要与同步条件满足 | 新阶段确认 | 不保证未来持续；通常最高 J3，满足公共升级条件时例外 |
| 切换失败并重新满足原阶段 | 回退 | 停止沿候选阶段推导 |
| 关键分项处于不同阶段 | 阶段分化 | 分项表达 |
| 条件冲突或关键变量缺失 | 暂不可判断 | J0/J1，列区分信号 |

除 A00 七项通用输出外，A03 还要额外写清：

- 阶段定义版本和允许迁移；
- 进入、维持、退出、排除条件的满足状态；
- 必要项与支持项的区分；
- 领先、同步、滞后变量的时序位置；
- 当前迁移类型及尚未满足的关键约束；
- 阶段分化范围。

## 边界与退回

- A03 通常最高 J3；只有公共路由表的 J4 严格升级条件全部通过时才可升级，阶段标签本身不构成升级理由。
- 状态或趋势不足时先用 A01/A02；解释阶段成因进入 A05；判断影响进入 A08。
- 阶段集合、条件优先级、时序、迁移或分化规则未定义，退回框架（02）。
- 决定性条件未确认可用、时点错配或关键冲突可补，退回取证（03）。
- 现实反复出现无法表达的迁移，记下缺口并退回框架（02），不在 A03 临时命名新阶段。

## 例与误判

**合格例：** 库存下降、价格止跌和订单改善满足修复阶段的领先与同步条件，但稼动率和利润仍未回升，成熟制程也明显弱于先进制程。结论为“总体处于修复早期并存在产品分化”，尚不能确认全面扩张。

**高迷惑性反例：** “价格上涨，因此行业已经进入上行周期。”

该结论用单一趋势信号替代阶段条件组，也没有检查维持、退出和同步条件，并把局部信号外推总体，触发 CE02、CE05 和 CE08。
