# R00-CAUSAL 通用因果识别协议

## 适用范围

本协议统一约束 R04 机制、R05 归因、R06 传导和 R08 影响中的因果方向识别。纯事实、趋势和阶段测量不调用本协议。因果任务必须在 `judgment_types` 中显式声明，不能因标题或正文出现“导致”等词自动启用。

## 取证前设计

每个因果问题先形成 `CausalDesign`，冻结 A、B、分析单位、范围、业务时间、作用时滞、估计对象和反事实。候选结构至少包括：

1. A→B；
2. B→A；
3. C→A 且 C→B；
4. 存在理论依据时的 A↔B。

登记混杂变量、中介和碰撞变量。每种结构须有不同的可观察预测和证伪条件。没有反向因果候选、共同原因候选或反事实时，设计不合格，不能进入取证。

证据任务至少检查时序、必要中介、暴露差异、反向因果和共同原因。识别策略需要时再加入负向对照、安慰剂、事前趋势与稳健性检查。公开证据仍按通用取证协议取得，不新增“因果来源”角色。

## 关系裁决

`CausalAssessment` 只能从以下关系中选择：正向因果、反向因果、共同原因、双向关系、多重原因、仅相关、未决。

- 正向因果：A 在合理时滞上领先 B，机制或暴露差异成立，B→A 与主要共同原因受到削弱。
- 反向因果：B 在合理时滞上领先 A，B→A 的机制或暴露证据更强，主要共同原因受到削弱。
- 共同原因：C 对 A、B 均有独立时序和作用证据，A→B 的直接路径未获支持。结论须写明 A 与 B 相关，但当前不支持 A 直接导致 B。
- 双向关系：设计阶段已登记反馈，且两个方向分别具有合理时滞和中介证据。
- 仅相关：只观察到同期共变，或只有起点和结果而没有方向证据。
- 未决：反事实、时序或关键比较不可得，无法区分 A→B、B→A 和共同原因。

## 识别状态与表达

| 状态 | 最低门槛 | 允许表达 |
|---|---|---|
| `identified` | 随机或合格准实验；识别假设、时序、竞争结构和稳健性通过；有估计值、不确定区间、样本与可复现产物 | “A导致B” |
| `strongly_supported` | 时序及两项方向证据成立；至少两个独立来源组；竞争结构明显削弱 | “证据较强支持A对B存在因果作用” |
| `partially_supported` | 正向时序与至少一项方向证据成立；竞争结构仍未充分排除 | “A可能促成B” |
| `consistent_only` | 只有共变或方向一致 | “A与B相关/变化一致” |
| `not_identified` | 无法构造反事实或区分方向 | “无法区分A→B、B→A和共同原因” |
| `contradicted` | 结果先于原因、必要中介失败，或竞争结构证据更强 | 明确目标因果方向被反驳 |

代表公司样本、媒体叙事、同期趋势和理论机制均不能单独升级因果状态。最终 `Judgment` 必须引用同一研究包中的 `CausalAssessment`，并继承其关系、状态与表达级别。
