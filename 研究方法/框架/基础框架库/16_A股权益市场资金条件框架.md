# A股权益市场资金条件框架

## 研究员先看什么

A股资金研究回答的是：在明确的信息截面和研究期限内，权益市场可用资金相对权益供给是变松、变紧还是结构分化，以及这种变化通过什么机制影响行业与风格暴露。

它不把成交放大、指数上涨或单一渠道净流入直接解释成资金全面宽松，也不把实体货币信用条件等同于股市边际资金：

```text
货币或信用宽松 ≠ 资金进入权益市场
单一渠道流入 ≠ 全市场净增量资金
成交放大或价格上涨 ≠ 资金供需已经改善
市场资金改善 ≠ 所有行业、风格或公司同向受益
```

## 1. 判断权与边界

### 1.1 本框架能判断什么

- A股资金供需在当前截面是宽松、均衡、偏紧、分化还是无法判断；
- 改变来自增量配置、杠杆可得性、存量再配置，还是 IPO、再融资、减持、解禁等权益供给变化；
- 资金变化是否具有广度、持续性和可用性，还是单一渠道、套利或短期换手；
- 已确认的资金状态对行业与风格有哪些条件性暴露。

本框架不判断实体信用是否宽松，不直接输出指数涨跌、收益率、仓位、交易时点、个股业绩或目标价。实体融资交 `BF-MF-01`，预期差、风险与估值分别交 `BF-EG-01`、`BF-RS-01` 和 `BF-VA-01`。

### 1.2 必须区分

| 必须区分 | 原因 |
|---|---|
| 存量 vs. 流量 | 余额大不等于边际流入，单日流入也不等于可持续存量 |
| 总量 vs. 结构 | 市场净资金稳定时仍可能发生显著风格和行业再配置 |
| 毛流量 vs. 净供需 | 资金流入必须与赎回、融资、减持和解禁等权益供给对照 |
| 成交 vs. 可用资金 | 成交额包含双边换手，不能直接表示新增资金 |
| 价格反应 vs. 资金事实 | 价格受盈利预期、风险和供给冲击影响，不能反推唯一资金原因 |
| 配置 vs. 套利/被动申赎 | 短期套利和被动调整未必改变持续风险预算 |
| 市场平均 vs. 行业/风格暴露 | 不同久期、规模、估值和流动性暴露可能相反 |
| 境内资金 vs. 外部约束 | 外资与汇率是渠道之一，不代表A股全部边际资金 |

### 1.3 硬停止条件

| 停止情形 | 禁止输出 |
|---|---|
| 市场范围、研究期限或信息截面不明确 | 正式 `market_funding_state` |
| 只有成交、换手、价格或情绪 | 资金宽松/收紧判断 |
| 只有单一资金渠道，且未检查其他主要渠道与权益供给 | 全市场资金状态 |
| 资金流量与余额、用途或持续性无法区分 | 持续性资金方向 |
| 未核对 IPO、再融资、减持、解禁、分红和回购等相关供给 | 净资金供需判断 |
| 只有历史风格相关性，无当前资金分布和广度确认 | `industry_style_exposure` |
| 资金状态成立但盈利、预期或风险路径未验证 | 指数方向、个股方向或仓位建议 |

低层事实可以保留；高层输出必须停止或降级。

## 2. 研究路线与模块

| 路线 | 核心问题 | 最低判别信号 | 输出边界 |
|---|---|---|---|
| A 市场净资金供需 | 多渠道资金相对权益供给是否改善 | 至少两类相互独立的资金渠道、净权益供给、余额/流量交叉 | 渠道不足时只输出分项事实 |
| B 杠杆与风险预算 | 融资可得性或机构风险预算是否扩张 | 杠杆余额和成本、保证金或风险预算、持仓/广度 | 不从杠杆扩张直接推指数上涨 |
| C 结构性再配置 | 表面资金改善是否只是存量轮动 | 行业/风格流量、广度、集中度和持续性 | 无总量证据时只输出结构轮动 |
| D 权益供给压力 | 融资、减持与解禁是否吸收增量资金 | 融资与减持实际规模、解禁后行为、分红回购现金流 | 公告额度不等于实际供给 |

每次调用必须固定一条主路线；只有能够改变主结论时才保留一条竞争路线。

| 模块 | 类型 | 解决什么问题 |
|---|---|---|
| EF-C0 范围与截面 | 核心 | A股范围、研究期限、可见信息与数据口径 |
| EF-C1 资金来源与用途 | 核心 | 哪些渠道是真增量、存量换手、赎回应对或套利 |
| EF-C2 权益净供给 | 核心 | 融资、减持、解禁与分红回购形成的净压力 |
| EF-R1 长期与机构资金 | 条件 | 公募/ETF、保险等风险预算和持续性 |
| EF-R2 杠杆资金 | 条件 | 融资可得性、余额、成本和集中度 |
| EF-R3 外资与外部约束 | 条件 | 外资渠道、汇率和全球风险约束 |
| EF-R4 居民与私募配置 | 条件 | 申赎、发行、仓位或可验证配置变化 |
| EF-R5 成交广度验证 | 核心 | 资金变化是否扩散，而非少数资产换手 |
| EF-E1 行业与风格映射 | 条件 | 已验证资金状态如何形成条件性暴露 |

## 3. 证据与降级

### 3.1 最低证据纪律

- 资金状态至少覆盖两个相互独立的资金渠道，并核对相关权益净供给；
- 流量必须与余额、用途或持续性至少一项交叉验证；
- 成交、价格、情绪、单类排名和单一资金流属于软指标，只能交叉验证；
- 结构性流向不得冒充全市场增量资金；
- 行业与风格映射必须有当前横截面广度或持仓/流量确认。

### 3.2 常见降级

- ETF 流入但基金整体赎回、融资供给或减持压力不清：只保留 ETF 渠道改善；
- 成交放大但余额、申赎和净供给无改善：不得判断资金宽松；
- 融资余额上升但集中于少数高波动标的：降级为局部杠杆扩张；
- 外资流入但境内主要渠道收缩：输出渠道背离；
- 总量稳定、行业流量显著分化：输出结构轮动，不输出全面宽松；
- 数据时点不一致或渠道覆盖不足：输出 `unknown` 并建立补证项。

## 4. 输出门槛与交接

| 输出 | 最低条件 | 失败处理 |
|---|---|---|
| `BF-EF-01.market_funding_state` | 明确市场、期限和信息截面；至少两类独立渠道；资金来源/用途可解释；净权益供给已核对；成交或广度仅作交叉验证；有主要竞争解释 | 输出分渠道事实、`mixed` 或 `unknown` |
| `BF-EF-01.industry_style_exposure` | `market_funding_state` 可用；目标暴露机制明确；当前横截面流量、广度或持仓确认；说明时滞与失效条件 | 只保留待验证暴露候选 |

下游交接：预期修订和计价状态交 `BF-EG-01`，风险路径交 `BF-RS-01`，估值输入交 `BF-VA-01`。任何框架均不得把资金状态直接改写为买卖、仓位或择时结论。

## 6. 验收检查

- [ ] 没有把实体信用、市场资金、成交和价格混为一谈；
- [ ] 已区分存量/流量、总量/结构、毛流量/净供需；
- [ ] 至少两类独立资金渠道并核对权益净供给；
- [ ] 软指标没有单独提升判断等级；
- [ ] 三轴或多渠道背离时保留 `mixed` / `unknown`；
- [ ] 行业/风格映射有机制和当前横截面确认；
- [ ] 没有输出个股业绩、指数方向、仓位或交易时点。
