# 宏观周期与金融条件传导框架

## 研究员先看什么

宏观研究最容易出现的错误，不是少看了一个指标，而是把不同层级的概念直接连在一起：

```text
经济数据变化 ≠ 宏观状态已经切换 ≠ 政策立场已经改变
≠ 金融条件已经放松或收紧 ≠ 居民和企业行为已经响应
≠ 目标行业和公司一定同向受益
```

单次任务应先明确最终要回答的是哪一级问题，再选择最短充分路线。通常只有四类真正需要区分的分歧：

1. **宏观状态是否真的变化**：当前是水平高低、方向变化、扩散变化，还是基数和数据修订造成的表象；
2. **政策是否改变实际金融条件**：政策信号、工具操作、市场价格和实体融资可得性是否同向；
3. **金融条件是否改变主体行为**：家庭、企业和金融机构的资产负债表是否放大、吸收或阻断传导；
4. **目标行业和公司是否具有足够暴露**：历史相关性是否仍有机制基础，当前微观信号是否确认，个体差异是否足以改变结论。

本框架不固定跨国家、跨时期和跨行业的统一指标、固定阈值、固定时滞或唯一周期模型。单次 02 原则上只选择一条主路线，最多保留一条竞争路线。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 在明确地域、经济范围、业务时间和信息截面下，经济活动、通胀、就业、信用或金融条件处于什么状态，方向、扩散和持续性如何；
- 财政、货币、监管或外部冲击是否通过利率、信用、汇率、流动性和融资可得性改变家庭、企业与金融机构行为；
- 宏观与金融条件变化是否通过可验证机制影响目标行业的需求、价格、成本、库存、资本开支或融资，并识别公司之间的暴露与缓冲差异。

本框架不直接回答：某项政策一定有效无效、单一数据能否代表完整周期、行业供需价格的全部判断、某家公司一定实现业绩改善、资产价格方向、大类资产配置或交易时点，以及跨制度环境的统一宏观阈值。

宏观状态可以作为独立输出；金融条件传导和行业暴露必须逐级验证。研究目标若只到宏观状态，不要求继续推到行业和公司。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 经济期间 vs. 信息截面 | 数据反映期与发布日不同；初值、修订、季调、名义实际会改变当时可见信息 |
| 水平 / 方向 / 扩散 / 持续性 | 高位不等于仍在改善；同比回落不等于环比收缩；单点指标不能机械定周期 |
| 总量 vs. 结构 | 总量稳定可能掩盖部门、主体、品类或地域分化 |
| 政策信号 / 工具 vs. 实际政策立场 | 一次降息、预算或表态不自动构成全面宽松或收紧 |
| 市场金融条件 vs. 实体融资条件 | 市场利率改善不代表贷款审批、额度、抵押和主体融资同步改善 |
| 资金价格 vs. 资金可得性 | 成本下降但拿不到融资，或融资只用于借新还旧，都不等于投资意愿增强 |
| 宏观状态 vs. 主体行为 | 条件只有改变消费、投资、招聘、贷款标准等决策，才进入实体传导 |
| 平均主体 vs. 资产负债表异质性 | 利率/汇率/信用对净储蓄与净负债、固浮息、本外币主体影响可能相反 |
| 供给冲击 vs. 需求冲击 | 同为“放缓”或“通胀”，政策反应、行业结果和公司分化不同 |
| 历史相关性 vs. 当前传导机制 | 结构、制度、产品和融资体系变化后，历史敏感度不得成为固定常数 |
| 行业平均 vs. 公司个体 | 宏观影响行业，不代表所有公司同向；公司结论须交公司框架验证 |

### 1.3 禁止跳步

- 不能从单一 GDP、PMI、CPI、社融、利率或汇率指标直接判定完整周期；
- 不能从政策表态或一次工具操作直接推出实际政策立场已经改变；
- 不能从政策利率下降或银行间流动性宽松直接推出实体融资条件全面放松；
- 不能从信用总量增长直接推出居民消费或企业资本开支增强；
- 不能从宏观总量改善直接推出目标行业需求改善，也不能从历史相关性直接推出当前传导仍成立；
- 不能从行业宏观受益直接推出公司收入、利润或现金改善；
- 不能从利率或风险偏好变化直接推出资产价格方向；
- 不能用事后修订数据证明当时已能识别拐点，也不能把政策预期先行造成的市场变化当作实体效果；
- 不能把供给冲击、需求冲击和基数效应合并为同一宏观解释。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 地域、经济范围、数据期间或信息截面不明确；关键口径/修订无法还原 | 正式 `macro_state` / 高置信宏观趋势 |
| 宏观信号高度分化，且无法由结构、时滞或冲击来源解释 | 单一周期状态 |
| 只有政策表态，没有工具、资源或执行证据 | 实际政策立场已经改变 |
| 只有市场利率变化，没有信用价格、可得性或融资行为 | 完整 `financial_condition_transmission` |
| 政策或市场金融条件没有改变主体约束与行为 | 向实体需求或投资继续推导 |
| 目标行业缺少真实暴露机制；或只有历史相关性、无当前微观确认 | 正式 `industry_exposure` / 只能形成待验证敏感度候选 |
| 行业结构、政策制度或融资机制发生重大变化 | 原历史敏感度外推 |
| 公司暴露与行业平均明显不同且未单独验证 | 从行业结论外推公司 |
| 关键时滞超过本次研究窗口；全球与国内路径冲突且无法拆分 | 把尚未发生的传导写成当前状态；必须分地域或分渠道输出 |

高级输出停止时，已确认的低层事实与监测路径仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 宏观状态与周期识别** | 真实状态变化，还是基数、结构和修订表象 | 需判断增长、通胀、就业、信用或周期位置 | 多轴方向与扩散、修订轨迹、结构分项、持续性 | 广泛转折 vs. 基数/修订/局部冲击 | 截面不清或信号无法解释分化时，不形成统一周期状态 |
| **B 政策立场与金融条件** | 政策信号是否真正改变市场和实体融资约束 | 降息、财政、监管、流动性、汇率或信用政策变化 | 工具与资源、市场利率与利差、贷款标准与审批、融资量用途 | 表态宽松 vs. 信用仍紧；市场先行 vs. 实体未响应 | 只有表态或只有市场利率时，不形成完整传导 |
| **C 资产负债表与实体行为** | 金融条件是否改变家庭、企业和金融机构决策 | 市场条件已变，但消费、投资、信贷或库存响应不清 | 储蓄/提前还贷、贷款需求、资本开支、库存、招聘、银行风险偏好 | 条件改善 vs. 资产负债表修复；融资增加 vs. 借新还旧 | 主体行为未变时，停止向实体需求/投资推导 |
| **D 行业暴露与公司分化** | 宏观变化是否对目标行业和公司具有现实影响 | 研究目标是行业需求、成本、融资或公司差异 | 机制暴露、当前订单/库存/价格/融资微观确认、公司异质暴露 | 宏观受益 vs. 行业脱钩；行业改善 vs. 公司特有结构 | 无机制或无微观确认时，只保留敏感度候选；公司层交下游框架 |

### 路线选择要求

02 调用本框架时必须说明：最终需要哪一级输出；数据期间与信息截面；主路线与竞争路线；哪些宏观变量只是背景。若最终输出是 `macro_state`，可停在路线 A；若目标是金融条件传导，不必默认进入行业和公司；若目标是行业暴露，可引用已验证宏观状态，不必重做完整宏观全景。政策执行本身是核心问题时，应调用 BF-PI-01。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| MF-C0 研究范围与数据截面 | 核心 | 每次调用 | 不得裁剪 | 地域、窗口、发布修订、名义实际、季调 |
| MF-C1 目标输出与主分歧 | 核心 | 每次调用 | 不得裁剪 | 最终停在哪一级、主竞争路线 |
| MF-A1 活动、就业与通胀结构 | 条件 | 目标涉及增长、周期、需求、价格或实际利率 | 目标只涉及政策工具或汇率成本时可裁剪无关轴 | 状态轴的方向、扩散、持续性与冲击来源 |
| MF-B1 政策立场与市场金融条件 | 条件 | 政策是起点或主要竞争解释；需判断利率利差汇率流动性 | 已有 BF-PI-01 合格输出可直接引用；目标仅为活动状态时可裁剪市场侧 | 信号/工具/立场；市场价格是否变化 |
| MF-B2 实体信用价格与可得性 | 条件 | 需要判断企业或家庭融资响应 | 没有信用渠道或不在研究范围 | 贷款标准、审批、额度、用途与主体分布 |
| MF-C2 主体资产负债表与行为 | 条件 | 消费、住房、投资、库存、招聘或银行风险偏好为中介 | 目标不涉及对应部门 | 条件是否转化为真实决策 |
| MF-D1 外部周期与汇率 | 条件 | 目标具有出口、进口、美元融资或商品暴露 | 经济和行业高度内生 | 全球与国内路径是否同向或抵消 |
| MF-D2 行业宏观暴露 | 条件 | 最终目标为行业状态 | 研究止于宏观或金融条件 | 机制暴露 + 当前微观确认 |
| MF-D3 公司暴露候选 / 历史敏感度 | 扩展 | 明确要求比较公司差异；或使用历史弹性外推 | 目标止于行业；只做当前状态且无需外推 | 分化候选；结构断点检查 |
| MF-X1 资产定价环境 | 扩展 | 只作为预期差、风险或估值输入 | 未完成相应下游前置 | 交给 BF-EG-01、BF-RS-01、BF-VA-01 |

单次任务不得因数据容易取得而启动无关模块。同一问题若需要三个以上宏观条件模块，优先检查问题是否过宽。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 状态与方向 | 判断当前处于什么状态、往哪走 | 单指标、基数和修订可造成假转折 |
| 分支 | 区分竞争路径 | 库存、工资、能源、贷款标准、汇率等须对应机制节点 |
| 强度与时滞 | 调整传导幅度与到达时间 | 杠杆、久期、合同重定价、预算执行不可跨任务固定 |
| 暴露 | 决定行业和公司受影响程度 | 历史敏感度在结构断点后失效 |
| 监测 | 后续确认或改判 | 发布修订、政策操作、信贷审批、行业订单、公司现金 |

框架不预先规定哪个变量在所有任务中最高权重，也不维护百科式指标清单。02 只选择能改变本次路径、方向、强度或停止条件的少数变量，通常 3—5 个。

### 4.2 代理变量要求

每个进入核心证据的指标至少说明：对应哪个状态或路径节点；领先/同步/滞后；数量、价格还是可得性；直接观测还是代理；口径、基数、季节和修订风险；支持哪条解释、何种结果支持竞争解释；何时不再适用。

### 4.3 关键时钟

只选择本次相关的时钟，不得机械拼接：

`数据发布与修订 → 政策表态/工具/执行 → 市场价格 → 信用定价与可得性 → 主体行为 → 行业订单库存价格产能 → 公司合同确认回款融资`

历史回放必须使用当时可见信息。不得用事后修订结果证明当时已经能够识别周期拐点。

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 同比改善 / 初值强 | 宏观加速 | 基数、季节、后续修订下调 | 环比、扩散、修订轨迹 | 降级置信度或切换基数解释 |
| 总量稳定 | 周期平稳 | 关键部门/主体反向 | 结构分项 | 分结构输出，不形成统一状态 |
| 政策表态积极 / 市场利率下降 | 全面宽松已开始 | 工具资源未变；信用利差与贷款标准恶化 | 操作、利差、审批、融资用途 | 停止在政策信号或切换信用收缩 |
| 融资增加 / 家庭条件改善 | 投资与消费将扩张 | 借新还旧；储蓄和提前还贷上升 | 资金用途、贷款需求、资本开支 | 切换资产负债表修复 |
| 通胀上升同时活动走弱 | 需求过热 | 供给约束与政策两难 | 能源/产能/工资结构 | 区分冲击来源，不统一外推 |
| 国内宽松 | 行业全面受益 | 汇率与全球融资收紧抵消；行业特有库存产能主导 | 外需、汇率、行业微观 | 切换外部抵消或行业脱钩 |
| 历史关系稳定 / 行业改善 | 当前仍可外推 / 公司将兑现 | 结构断点；公司暴露与行业平均不同 | 制度/产品/融资变化；公司地域债务汇率客户 | 关闭旧敏感度；交 BF-EE-01 |

### 降级规则

- 宏观信号分化：暂不形成统一状态；
- 政策方向明确但金融条件未确认：停止在政策信号；
- 市场金融条件改善但实体信用仍受限：不向投资/消费继续推导；
- 实体行为仅局部响应：保留局部传导，不做全面实体结论；
- 行业有机制但缺微观确认：只保留待验证敏感度候选；
- 时滞尚未完成：只建立监测路径；
- 多条路径并存：输出条件分支，不强行合并。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-MF-01.macro_state` | 明确地域、范围、观察窗口和信息截面；至少两个有机制意义的状态轴；区分水平/方向/扩散/持续性；检查修订、季节、名义实际和基数；至少一个主要竞争解释 | 只保留分轴事实或“信号分化/不足” |
| `BF-MF-01.financial_condition_transmission` | 已有或同时形成可用宏观/政策起点；区分政策信号、市场金融条件与实体融资条件；至少一类主体约束或行为变化可验证；说明阻断或放大环节 | 停止在政策信号或市场条件，不形成完整实体传导 |
| `BF-MF-01.industry_exposure` | 目标行业有可验证暴露机制；当前微观信号确认或明确为何仍是候选；历史敏感度已做结构断点检查；公司外推须单独验证暴露 | 只保留机制候选或行业特有因素待查 |

更高一层写不出来时，已经成立的更弱结论仍可保留。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 6.2 组合与交接

- 政策事实、执行与主体响应：交 BF-PI-01；
- 目标产品有效供需、价格、产业链：交 BF-SD-01、BF-PC-01、BF-VT-01；
- 公司兑现：交 BF-EE-01；财务基线：交 BF-FQ-01；
- 条件预测：交 BF-FS-01；风险阈值与恢复：交 BF-RS-01；
- 预期差与估值：交 BF-EG-01、BF-VA-01。

本框架不得把宏观背景替代行业供需和价格事实，不得在公司暴露未验证时形成业绩结论，不得把利率下降直接写成估值提升，也不得形成大类资产配置和交易建议。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 宏观状态至少使用两个有机制意义的状态轴，并记录发布与修订；
- 金融条件至少区分市场价格与实体融资可得性；
- 实体传导至少观察到一类主体行为变化或明确阻断；
- 行业暴露必须同时有机制与当前微观确认，不能只靠历史回归；
- 政策预期、市场定价和机构观点不得冒充实体效果。

具体来源与验收由研究方法/取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的地域、行业、公司、状态变量、观测、事件、假设、信号和情景。“宏观状态”“金融条件”“行业宏观暴露”等属于框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 降息与耐用品/住房需求、汇率对出口制造、信用扩张与周期行业景气 |
| 重点检查 | 是否按层级停止；是否用指标堆砌替代路径选择；是否越界到公司业绩和资产配置 |
| 经验沉淀 | 国家/制度特殊机制优先进入行业或地域扩展；跨任务重复且有失效边界的传导才写回稳定内核 |

## 8. 验收检查

- [ ] 明确本次最终需要宏观状态、金融条件传导还是行业暴露；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 经济期间与信息截面、政策信号与实际金融条件、市场条件与主体行为已经区分；
- [ ] 决定性变量由单次任务选择，没有复制百科式指标清单；
- [ ] 供给冲击与需求冲击、历史相关与当前机制已经按需区分；
- [ ] 主解释和竞争解释会产生不同的可观察预测；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 没有从宏观直接推出公司业绩、估值或大类资产交易结论；
- [ ] 行业暴露同时具备机制与微观确认，或明确降级为候选；
- [ ] 特殊制度或行业机制优先放入扩展位置，而不是写成跨任务固定阈值。
