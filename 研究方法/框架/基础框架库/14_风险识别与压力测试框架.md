# 风险识别与压力测试框架

## 研究员先看什么

风险研究不是把政策、需求、供应、技术、财务、治理和合规风险逐项列全，而是识别：**哪一项关键假设可能被什么触发击穿，公司或行业实际暴露在哪里，现有缓冲能否覆盖冲击窗口，何时会跨过不可逆阈值，以及冲击后是否存在现实可执行的恢复路径。**

单次任务最有价值的通常不是风险数量，而是少数几条可能改变主结论的路径：

```text
风险源或脆弱点 → 可观察触发 → 真实暴露 → 经营或财务传导
→ 缓冲消耗 → 关键阈值 → 一阶结果与二阶影响 → 恢复、稀释、退出或原假设失效
```

优先避免六类误判：风险存在不等于目标对象有重大暴露；名义对冲/保险/授信不等于冲击时可用；盈利下滑不等于流动性压力；单一参数下调不等于内部一致压力测试；应急预案不等于可执行恢复能力；低概率无法精确估算，既不意味着可忽略，也不意味着可伪造概率。

单次任务应选择一条主风险路线，最多保留一条主要竞争路线或复合风险路线。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 风险源、触发、暴露、传导、缓冲、结果和恢复之间是否构成可执行风险链；
- 在内部一致的条件情景下，经营、现金、融资、契约、资本和持续经营约束可能如何变化；
- 哪些运营、流动性、契约、监管、客户或技术阈值一旦跨越，会使原判断失效、损失显著放大或恢复成本非线性上升。

本框架不直接回答：风险事件一定会不会发生、资产价格如何即时反应、应买入卖出或对冲多少、缺少业务财务基线时的精确损失数值、单一风险标签下的统一评级，以及未经机制验证的极端情景目标价。

没有作用对象和关键假设的风险，只能保留为外围监测事项。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 风险源 vs. 真实暴露 | 外部或内部风险存在，不代表目标对象必然受重大影响 |
| 潜在风险 vs. 触发状态 | 只有叙述、没有可观察触发时，不能形成高强度风险判断 |
| 固有风险 vs. 剩余风险 | 必须说明缓冲覆盖什么、多久、何时不可用、是否相关失效 |
| 缓冲存在 vs. 缓冲可用 | 账面现金、授信、保险和备用供应可能受限、需对手方履约或有时滞 |
| 波动 / 阶段性损失 vs. 结构性损伤 | 短期利润下降不等于长期价值毁损；现金充足也不等于损伤可逆 |
| 经营压力 vs. 财务压力 | 二者可独立发生，也可能相互放大形成反馈 |
| 可逆损失 vs. 不可逆阈值 | 阈值是跨过后恢复难度/成本/时间非线性上升的节点 |
| 单一风险 vs. 复合风险 | 同窗、同缓冲、同反馈时不能简单相加 |
| 压力情景 vs. 概率预测 | 可保留条件情景与结果范围，不得伪造精确概率 |
| 应急方案 vs. 可执行恢复 | 计划不等于拥有决策权、资金、时间、审批和历史执行记录 |

### 1.3 禁止跳步

- 不能从存在宏观/政策/行业风险直接推出目标公司受损；
- 不能从集中度高直接推出风险重大，必须验证替代性和合同结构；
- 不能从已投保、已对冲、有现金或授信直接推出风险已被覆盖；
- 不能只下调收入或利润一个参数就称为压力测试，也不能把历史最大跌幅直接当作未来压力参数；
- 不能把低概率当作忽略理由，也不能把不可量化风险写成确定会发生；
- 不能从短期现金覆盖直接推出无结构性经营风险，也不能从短期经营损失直接推出持续经营受威胁；
- 不能从管理层应急预案直接推出能够及时恢复；
- 不能从风险上升直接跳到估值、目标价或交易动作。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 风险无法绑定具体对象、关键假设或业务时间 | 正式 `risk_path` |
| 只知道风险源，无法确认真实暴露；或触发条件无法定义/不可观察 | 暴露强度、剩余风险或“已转为现实压力”判断 |
| 缓冲仅有名称，无法确认覆盖、期限和可用性 | 剩余风险和压力吸收判断 |
| 缺少经营或财务基线；压力参数彼此矛盾或未体现共同机制 | 正式 `stress_effect` |
| 无法识别现金、契约、运营、合规或客户阈值 | `irreversible_threshold` |
| 恢复方案依赖未确认融资、审批、认证或对手方行动 | 恢复能力升级 |
| 财务报告、合同或关键暴露数据可靠性受重大质疑 | 依赖该数据的压力量化 |

高级输出停止时，已确认的风险线索、局部路径和监测事项仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线或复合风险路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 暴露与触发** | 风险是否真正作用于目标对象，何时从潜在转为现实 | 客户/供应集中、政策合规、技术中断、需求或治理事件 | 暴露比例与不可替代性、触发条件、领先/同步确认信号 | 风险源存在但无实质暴露；信号来自情绪或市场共振 | 无真实暴露或触发不可观察时，不形成现实压力判断 |
| **B 传导与缓冲** | 冲击经何路径进入经营财务，在哪被吸收或放大 | 库存、合同、保险、对冲、冗余、定价权、替代能力争议 | 经营/财务中介变化、缓冲覆盖期限、相关失效条件 | 名义缓冲充分 vs. 压力时受限或相关失效 | 中介关系不清时，只保留局部路径 |
| **C 压力与不可逆阈值** | 内部一致压力下，何时触及现金、契约、运营或持续经营边界 | 周期下行、再融资、复合冲击、重大损失、资本约束 | 最低现金、契约余量、运营底线、资格/客户流失阈值 | 可管理波动 vs. 不可逆损伤；利润压力 vs. 财务危机 | 无基线或阈值不可识别时，不做正式压力结果 |
| **D 恢复、二阶效应与假设治理** | 冲击后能否恢复，恢复是否造成稀释、份额流失或长期损伤 | 供应中断、事故、监管整改、资产处置、重组和危机管理 | 替代认证、融资时间、复产、客户回流、整改与长期代价 | 快速恢复 vs. 结构性损伤；恢复来自应对 vs. 行业反转 | 恢复依赖未确认外部条件时，只保留条件恢复 |

### 路线选择要求

02 调用本框架时必须说明：本次风险影响哪一个核心判断；主路线与竞争/复合路线；原则上只保留 1—3 条可能改变主判断的重大风险路径；每条路径通常 3—6 个必要节点；决定性变量通常 3—5 个。多个风险消耗同一缓冲或形成反馈时，应合并为复合风险路线，而不是并列成清单。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| RS-M1 风险假设与作用对象 | 核心 | 每次调用 | 不得裁剪 | 风险影响哪个主假设、对象和时间窗口 |
| RS-M2 真实暴露与集中度 | 核心 | 风险源已识别 | 无真实关系时停止 | 暴露比例、依赖、不可替代性 |
| RS-M3 触发与领先信号 | 核心 | 风险可能由潜在转为现实 | 无可观察触发时降级 | 触发条件、监测变量和有效期 |
| RS-M4 传导路径 | 核心 | 风险可能改变经营或财务状态 | 关系不成立时停止后续 | 3—6 节点风险链 |
| RS-M5 缓冲与控制 | 条件 | 存在库存、合同、保险、对冲、冗余、现金或授信 | 无缓冲或与本风险无关 | 缓冲覆盖、期限和可用性 |
| RS-M6 经营 / 财务压力 | 条件 | 风险影响订单价格成本供应，或现金融资契约资本 | 只研究一侧且另一侧不会穿透时可裁剪对应侧 | 经营结果、流动性、杠杆与融资 |
| RS-M7 复合风险 | 条件 | 多风险同窗、消耗同一缓冲或互相放大 | 风险独立且无联动 | 反馈路径和联合阈值 |
| RS-M8 恢复与二阶效应 | 条件 | 冲击后存在修复、替代、重组或融资动作 | 研究只止于触发和暴露 | 恢复时间、成本、份额和资本影响 |
| RS-M9 预期和估值影响 | 扩展/交接 | 用户明确要求资产影响且前置结果具备 | 交给 BF-EG-01、BF-VA-01 | 风险输入变化需求 |

快速事件风险可以止于“暴露—触发—缓冲—短期结果”；若风险只影响某个局部假设，应止于该假设更新。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 暴露 | 判断风险是否重要 | 集中度高不等于不可替代 |
| 触发 | 判断风险是否转为现实 | 媒体/情绪信号可能无经营含义 |
| 传导 | 判断冲击如何穿透 | 利润损失不等于即时现金缺口 |
| 缓冲 | 判断剩余风险 | 名义缓冲可能相关失效或有时滞 |
| 阈值 | 判断何时非线性恶化 | 只看期末结果会漏中途违约 |
| 恢复 | 判断恢复能力和持续期 | 宣布恢复不等于经济恢复 |

02 应根据本次主风险选择 3—5 个决定性变量。

### 4.2 代理变量要求

使用代理时必须说明：支持哪个风险环节；是触发、暴露、缓冲消耗、阈值接近还是恢复信号；业务时间和有效期；替代解释；未命中时削弱哪一段路径。

### 4.3 关键时钟

只选择本次相关的时钟：

`风险形成 → 触发 → 经营传导 → 财务传导 → 缓冲消耗 → 阈值跨越 → 恢复 → 二阶影响`

不得把风险事件日等同经营结果日，也不得把宣布恢复等同经济恢复。

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 风险源存在 / 集中度高 | 重大暴露即将冲击 | 无实质暴露；可替代或合同保护充分 | 依赖关系、替代交付、合同条款 | 停止正式风险路径或降级监测 |
| 触发信号出现 | 经营已进入压力 | 情绪、市场共振、季节或一次性事件 | 订单、交付、成本、现金等经营中介 | 不升级为现实压力 |
| 利润下降 / 现金看似稳定 | 财务危机 / 风险已被吸收 | 可管理经营波动；现金来自延迟付款、削投入或卖资产 | 契约余量、再融资、投入与客户份额 | 降级为经营压力，或切换为代价型缓冲 |
| 名义缓冲充足 | 剩余风险低 | 压力时受限、对手方违约或相关失效 | 提款/赔付条件、时滞、复合压力 | 切换为复合风险 |
| 表面快速恢复 | 应对有效、风险解除 | 行业反转；客户份额/技术已受损；依赖未确认融资审批 | 客户回流、份额、认证、融资落实 | 切换为结构性损伤或条件恢复 |
| 跨过关键阈值 | 可逆压力仍可管理 | 不可逆损伤或需重组 | 客户永久切换、资格失效、交叉违约、被迫稀释 | 切换为不可逆/重组路径 |

### 降级规则

- 无真实暴露：只保留风险线索；
- 无触发条件：只保留潜在风险；
- 中介关系不清或竞争解释未排除：输出条件路径，不形成高强度结论；
- 无可靠基线：只保留方向性压力路径；
- 恢复依赖未确认外部条件：降级为条件恢复；
- 风险结果在合理区间内不改变主判断：停止继续精确化。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-RS-01.risk_path` | 明确主假设/作用对象；真实暴露证据；可观察触发或状态条件；至少一条主要传导；至少一个缓冲/替代/阻断条件；至少一个竞争解释 | 只保留风险线索、潜在风险或局部路径 |
| `BF-RS-01.stress_effect` | 可用经营或财务基线；围绕共同机制的内部一致压力；缓冲消耗与覆盖窗口可说明；结果对主判断有决策意义 | 只保留方向性压力，不做正式损失区间 |
| `BF-RS-01.irreversible_threshold` | 可识别现金/契约/运营/合规/客户等阈值；说明跨过后为何恢复难度非线性上升；有确认与监测信号 | 只保留一般风险上升判断 |

更高一层写不出来时，已经成立的更弱结论仍可保留。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 6.2 组合与交接

- 风险源属于供需、政策、价格、产业链或宏观机制：引用 BF-SD-01、BF-PI-01、BF-PC-01、BF-VT-01、BF-MF-01，不重复完成上游机制判断；
- 业务暴露与兑现：交 BF-BM-01、BF-EE-01；财务基线：交 BF-FQ-01；
- 管理层应对与资本配置：交 BF-CG-01、BF-CA-01；
- 风险如何进入预测：交 BF-FS-01；预期差与估值：交 BF-EG-01、BF-VA-01。

本框架不得输出交易动作、仓位或对冲指令。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 暴露至少说明真实依赖关系与足以改变判断的强度；
- 触发至少可观察，或明确为何只能保留潜在风险；
- 缓冲至少说明覆盖对象、期限与不可用条件；
- 压力路径必须经营与财务联动，不能只调一个利润参数；
- 阈值与恢复必须有可监测信号；情绪、媒体和泛化风险叙述不得冒充暴露证据。

具体来源与验收由研究方法/取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的公司、产品、事件、状态变量、观测、假设、信号和情景。“风险路径”“缓冲可用性”“不可逆阈值”等属于框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 关键供应商中断、周期下行叠加再融资、监管整改是否解除风险 |
| 重点检查 | 是否只保留改变主判断的路径；名义缓冲是否验证；是否越界到估值交易 |
| 经验沉淀 | 行业特殊风险机制优先进入行业框架或场景卡；跨任务重复且有失效边界的机制才写回稳定内核 |

## 8. 验收检查

- [ ] 明确本次风险作用于哪个主假设或关键输出；
- [ ] 只选择一条主路线，最多保留一条主要竞争/复合路线；
- [ ] 风险源与真实暴露、缓冲存在与缓冲可用已经区分；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 风险路径逐段可验证，不是风险标签清单；
- [ ] 主解释和竞争解释会产生不同的可观察预测；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 压力情景围绕共同机制，不是全参数同时变差；
- [ ] 没有从风险直接推出估值、目标价或交易动作；
- [ ] 特殊行业机制优先放入行业框架或场景卡，而不是写成跨行业固定损失率。
