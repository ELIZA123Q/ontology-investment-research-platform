# 分析框架库

本库保存可复用的分析框架：一类问题通常应判断什么、如何拆解、需要检查哪些机制和竞争解释。它是 `LogicDefinition` 和计划提案的方法输入，不是固定执行流程。

- [基础框架库](基础框架库/00_基础框架编写与验收标准.md)：供需、政策、产业链、价格、公司兑现、财务、预期和估值等通用框架。
- [半导体行业框架](行业框架库/半导体行业/README.md)：半导体主框架与高频场景卡。
- [框架依赖登记](00_framework_dependency_registry.yaml)：供计划器查询的进入条件和上下游能力提示；执行权威仍是 `研究能力/logics.yaml` 和 `研究规则/rules.yaml`。

使用时先写出核心待验证命题，再为每个判断单元选择一个直接框架；行业增强和场景卡按需加入。框架只提供可验证结构，不直接产生事实、判断或报告。

取证方法见 [取证库](../取证/README.md)，裁决方法见 [推理库](../推理/README.md)。
