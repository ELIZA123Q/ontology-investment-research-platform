# 银行业框架库

本库是 A 股银行研究的行业方法资产，不是当期事实库，也不是独立 Skill。它用一个综合主框架约束从资产负债表到盈利、资本、分红、估值和载体选择的传导。

## 研究员最短路径

1. 冻结银行类型、报表范围、业务时间、会计与监管口径；
2. 从息差、资产质量、资本与分红、区域／行业暴露、估值与投资载体中选 **1 条主路线**；
3. 最多保留 1 条能产生不同可观测预测的竞争路线；
4. 建立「原始状态 → 重定价／迁徙 → 利润与资本 → 股东回报」桥，不能跨节点外推；
5. 用[银行业来源速查](../../../取证/B03_银行业来源速查.md)安排主源、独立交叉源和反证，然后交给取证与推理能力裁决。

## 分类只是抽样起点

可按法定类型、控制权、经营地域与业务结构将样本暂分为国有大型、全国性股份制、城商行、农商行及其他具有特定定位的银行。正式比较不得从类型名称推导风险、增长或估值，而应重新核对：

- 资产、负债、客户、区域和表内外业务结构；
- 重定价时钟、资产质量迁徙和核销／处置方式；
- 风险加权资产消耗、内生资本和母公司可分配利润；
- 数据披露深度与可比性。

## 组合与交接

```text
利率／政策变化
→ 宏观与政策框架先定范围
→ IF-BANK-01 处理银行内部传导
→ 财务基线／预测框架处理精确测算
→ 预期差、估值和投资命题框架处理市场层
```

一个关键判断单元默认只保留 IF-BANK-01 中的一条主路线；不因「银行业都相关」而展开全部模块。公司或 ETF 对比仅在共同宏观假设、共同业务时间和统一计量口径下进行。

## 维护状态

IF-BANK-01 暂为 `candidate`，需要至少一个成立案例和一个高迷惑性失败案例才可升级为已验证。单次任务的固定阈值、当期结论和个股排名不得回写为框架规则。
