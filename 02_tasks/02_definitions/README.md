# 标准任务定义

这里登记「一类标准任务」长什么样：目标、默认角色、推荐工作流、需要哪些能力集合。它是任务说明书目录，不是某一次已经跑完的任务实例。

## 给谁看

- **研究员**：了解某类任务默认产出与边界
- **维护者**：从受理主任务类型与评测案例抽象登记

## 材料从哪来

- 登记表：[`registry.yaml`](./registry.yaml)
- 运行时真正创建的任务实例在 [`07_runtime/`](../../07_runtime/README.md) 数据库/事件中
- 评测案例可参考 [`05_governance/14_evals/`](../../05_governance/14_evals/README.md)

## 怎么用

1. 查某类任务的目标与默认配置 → 读 registry 与对应定义文件。
2. 实际开题做研究 → 在工作台创建会话；不必先手写一份定义文件。
3. 不要把单次 run 结果写回本目录冒充标准定义。

## 怎么维护

- 只登记可复用的标准 Task，不承载运行时产物。
- 新增定义后更新 `registry.yaml`，并与 Runtime node-catalog / 能力清单对齐。
- **status:** migrating
