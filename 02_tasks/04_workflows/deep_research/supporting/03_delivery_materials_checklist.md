# 03_交付素材检查场景参考

本附录保存按目标报告类型检查展示素材的场景参考。`delivery_readiness` 合同语义与状态枚举以 [`02_tasks/04_workflows/deep_research/stages/03_evidence.md`](03_数据与证据准备规范.md) 第 9 章及 [`03_附录1_证据要求与快照字段参考.md`](03_附录1_证据要求与快照字段参考.md) 第 7 节为准；本附录不构成统一硬门槛。

边界固定为：03 只判断素材有没有、是否可用、限制是什么；05 决定用不用、放在哪里、如何形成论证。本表不输出章节建议、故事线、标题或投资要点。

---

### 报告类型的素材检查

若 01 指定 `industry_cycle_report`，03 至少应检查以下素材单元：

| 素材单元 | 最低要求 | 可用性与限制 |
|---|---|---|
| 主结论证据 | 主方向至少有两类独立证据支撑，并完成反证检查 | 有/无独立支撑；缺口是否阻断主方向表达 |
| 价格证据 | 至少有同口径价格、现货价、合约价或公司实现价序列；需说明口径限制 | 序列是否齐备；口径能否跨期比较 |
| 需求证据 | AI/服务器需求与消费端需求必须分开，不得用单一需求指标替代 | 分层是否齐备；是否存在混用风险 |
| 供给证据 | 名义产能、有效供给、良率、认证、封装或晶圆分配至少拆开关键层级 | 关键层级是否拆开；缺失层级须显式限制 |
| 库存证据 | 原厂、渠道、客户至少说明覆盖层级和缺失层级 | 覆盖层级与缺失层级是否写清 |
| 订单证据 | 订单兑现、取消、延迟拉货、重复下单或客户锁单至少有可观察口径 | 是否有可观察口径；信号可靠性限制 |
| 分对象排序素材 | 强弱排序需绑定证据，不得只按直觉排序 | 排序是否有证据绑定；不得写成投资排序 |
| 预期差素材 | 市场常见理解、竞争解释或误读风险需有材料来源或研究问题来源 | 材料是否可追溯；缺材料则不可当作已证实预期差 |
| 图表素材 | 检查时间序列、横截面或排序素材是否存在且可制图；没有天然量化结构时可标记不适用并说明理由 | 仅影响 `delivery_readiness`，不影响证据质量和 03 `high_quality_pass` |
| 改判信号素材 | 至少三类关键变量具备可观察触发条件 | 触发条件是否可观察；缺项须写入限制 |
| 来源注释素材 | 关键数据可追溯到来源、发布时间、业务时间、口径和使用限制 | 正文可读注释是否齐备、可复核 |

单项素材状态可继续使用：

| 状态 | 含义 |
|---|---|
| `report_grade_ready` | 素材存在且可支撑目标 05 的高质量展示；这是交付素材状态，不是证据质量等级 |
| `usable_with_caveat` | 可用，但必须保留限制，05 不得放大 |
| `partial` | 有素材，但不足以支撑稳定展示 |
| `missing` | 缺失 |
| `not_applicable` | 不适用于本次 05 原型 |

不得把所有素材单元一律要求为 `report_grade_ready`。例如，目标报告不需要强弱排序时，排序表可不适用；目标是公告点评时，公告原文定位和来源注释可能比量化图表更关键。03 写清上述就绪度后即止；章节组织、论证顺序与投资要点由 05 决定。
