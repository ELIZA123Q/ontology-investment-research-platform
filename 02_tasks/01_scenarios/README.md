# 研究场景包

这里登记「这类研究问题常长什么样」的场景包（例如半导体 SCN-*），方便复用问题结构与场景卡，而不是从零描述行业背景。

## 给谁看

- **研究员**：选型场景、对照场景卡
- **维护者**：场景 catalog 与路径迁移

## 材料从哪来

- 场景卡正文目前多仍在方法库：[`03_capabilities/05_method_libraries/02_研究框架/行业/`](../../03_capabilities/05_method_libraries/02_研究框架/)
- 本体中的 scenario catalog（若已登记）见语义域
- 本目录 [`registry.yaml`](./registry.yaml) 先建立引用，不强制搬动原卡片文件
- 半导体落点说明见 [`semiconductor/`](semiconductor/README.md)

## 怎么用

1. 确定行业/问题类型 → 在 registry 或半导体子目录找到场景入口。
2. 打开对应场景卡，只取「与本次判断相关的增量约束」。
3. 场景卡是适配器，不是缩小版主框架；每个关键判断单元仍只留 1 个直接框架。

## 怎么维护

- 新增场景：先在方法库/行业目录写卡，再在本目录 registry 登记引用。
- 迁移完成前保留旧路径兼容，避免链接断裂。
- 不放通用本体定义、工具实现或单次 run 事实。
