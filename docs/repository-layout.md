# 仓库目录与权威边界

本仓库把定义权威、研究方法、可复现样例和历史研究运行分开；Python 实现与使用文档服务于这些资产。目录是否保留，不以“是否被 Python 直接导入”为唯一标准，而以是否在研究链中有明确消费者和审计用途为准。

| 目录 | 内容 | 实际消费者 | 是否产生执行效果 |
|---|---|---|---|
| `语义本体/` | 稳定实体、关系、词表、指标定义与语义约束 | `SemanticOntologyRegistry`、本体编译器、语义上下文能力 | 只约束允许表达什么，不负责推理流程 |
| `研究运行合同/` | 证据、判断、计划、审批、双时态和审计对象合同 | 本体映射、运行仓储、验证器和开发者 | 约束运行对象，不选择任务步骤 |
| `研究规则/` | 路由、激活、准入、等级上限、阻断、审批和完成规则 | `RuleRegistry`、规划器、编排器 | 是机器执行权威 |
| `研究能力/` | Capability、Logic、数据源与报告模板 | 规划器、计划编译器、编排器 | 定义可调用能力和候选 DAG |
| `研究方法/` | 取证、推理、通用框架与领域框架 | `ResearchMethodRegistry`、研究 Skill、研究员或模型 | 按请求声明或已登记的 A 股权益研究路由成为计划输入；不能越过规则形成事实或判断 |
| `.agents/skills/` | 研究代理的拆题、取证、对标和裁决纪律 | Codex 研究代理 | 约束模型如何使用研究方法 |
| `examples/` | 最小、稳定、可装载的验收样例 | 离线验证和回归测试 | 不作为新研究的数据权威 |
| `research_outputs/` | 动态投研运行、RDF 归档、报告与本地权威图 | 研究仓储、审阅者和历史复盘 | 是具体研究记录 |
| `outputs/` | 新生成交付的预留目录；当前不含稳定样例 | 研究者和审阅者 | 不作为规则、方法或证据权威 |
| `docs/` | 架构、使用与公开发布说明 | 新使用者和维护者 | 只解释权威，不替代权威配置 |
| `src/ir_platform/` | 规划、执行、运行图及 CLI 实现 | Python 运行环境 | 执行已登记的规则与能力 |
| `tests/` | 行为、边界和回归测试 | 维护者与 CI | 验证实现，不生成正式研究结论 |

## 一次研究如何使用这些目录

1. 任务声明研究目标，并可在 `methodology` 中声明判断类型、取证方法、框架和领域目录。明确标记为 A 股权益的完整研究会按已登记的路由启用研究设计；不按标题关键词猜测资产类别。
2. `ResearchMethodRegistry` 校验取证方法、推理方法和框架存在，把适用的稳定引用写入计划上下文；没有声明且不符合自动路由时记录为空，不通过关键词擅自套框架。
3. 规划器依据 `研究规则/rules.yaml` 选择 `研究能力/logics.yaml` 中的 Logic，并把声明的方法配置交给语义上下文节点。
4. 语义上下文只能引用 `语义本体/` 中存在的类型、关系和指标。
5. 能力节点取得材料、形成候选对象；机器规则决定证据能否准入、判断最高等级、是否阻断以及是否需要审批。
6. 运行对象进入 Oxigraph 并记录 provenance；方法文档、本体和报告 Markdown 都不取代运行图权威。

## 清理规则

- 删除生成缓存、编辑器元数据、临时会话和空兼容目录。
- 删除已被新权威覆盖、无人读取且带失效引用的指导副本；有效内容必须在删除前确认已存在于正式合同、规则或方法正文。
- 不删除 `.agents/`、`.codex/`、研究图运行目录或研究报告，它们都有明确消费者。
- 不保留 archive、deprecated stub 或第二套同义规则；历史只由 Git 保存。
