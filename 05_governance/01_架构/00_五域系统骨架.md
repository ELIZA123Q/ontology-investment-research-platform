# AI 原生投研判断工作台架构

## 核心原则

**确定性负责边界，Agent 负责路径。**

系统不是固定 Workflow，也不是自由 Agent。Research Lead 可以选择、跳过、并行或局部重跑节点，但只能组合 `Research Node Catalog` 中有类型、有前置条件、有输出 schema 和治理不变量的节点。

## 五域

五域只回答后台职责，不生成五个产品中心：

| 域 | 职责 | 运行入口 |
|---|---|---|
| Semantic | 世界模型、词典、证据语义、两类图 | `01_semantic/`、`07_runtime/src/semantic/` |
| Task | Intent、Task、typed TaskGraph、可选模板 | `02_tasks/`、`07_runtime/src/runtime/planner.ts` |
| Capability | Agent、Skill、Tool、方法资源、协议 | `03_capabilities/`、`07_runtime/src/capabilities/registry.ts` |
| Execution | Context、Memory、Event、Checkpoint、Worker | `04_execution/`、`07_runtime/src/runtime/` |
| Governance | 规则、权限、Verifier、Eval、审计 | `05_governance/`、`07_runtime/src/governance/` |

产品面登记在 `06_app/`，唯一实现位于 `07_runtime/app/`。

## 运行主链

```text
Conversation
  → Intent
  → Task / typed TaskGraph
  → Skill / Tool / Service / Policy / Verifier
  → Event + key Checkpoint
  → Artifact
  → trusted UI surface
```

- vNext.1 只有 Research Lead 活动。
- Deep Research 01—05 仅作为可选模板和历史评测基线。
- Message、Trace 从 Event 投影；ContextPackage 临时存在。
- 未经 Source Capture 不得形成 EvidenceFact；无合格 Evidence 时 Judgment 必须降级。
- Domain Semantic Graph 与 Research Provenance Graph 分开治理。

## 单一权威

- Agent/Skill/Tool manifest：`07_runtime/src/capabilities/registry.ts`
- Task Node 类型：`07_runtime/src/runtime/node-catalog.ts`
- 运行对象：`07_runtime/src/contracts.ts`
- Runtime 状态：`07_runtime/src/runtime/store.ts`
- 五域索引：`five_domain_authority.yaml`

禁止创建实现镜像、固定阶段 controller 或第二份 Skill 正文。
