## 保留与归档规则

- `active` / `in_progress` / `done-partial`：保留并从本页可达。
- `completed`：保留为决策与验收证据，不再继续在正文末尾追加无关工作。
- 被新账本替代时：旧文件文首或本页写明替代入口；不要直接删掉导致决策链断裂。
- 纯聊天记录、逐日工作记录和无引用临时清单不放这里；结论应收口到对应合同、README 或决策日志。
