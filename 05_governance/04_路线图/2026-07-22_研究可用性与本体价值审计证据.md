1. 当前项目已经是“本体约束的投研判断工作台”，不是只展示实体关系的知识图谱。正式本体对象、关系和规则通过公共合同、Runtime 确定性执行、实例图合同、方法应用、证据绑定和增量失效闭包进入工作流。
2. 工程基线已通过，真实研究增益尚未证明。不得把项目校验、mock 评测或单个黄金样例外推为平台级研究可靠率。
3. 当前正式样例的信息量足以形成边界清楚的半导体 J2 判断，并对统一周期结束日正确停在 J0；不足以支持跨领域泛化或普遍研究可靠性结论。

## 3. 正式本体执行覆盖

`05_governance/02_合同/rule_authority_registry.yaml` 当前登记 **14** 条正式本体规则（2026-07-28 再评估对齐）：

- **13** 条由 Runtime 语义执行面（`runtime_semantic_execution` + `blocking`）重算并挡门，对应 `REQUIRED_RULES`；
- **1** 条由实例图合同执行（`semantic_endpoint_compatibility`）；

因此当前 Runtime 的正式本体规则执行覆盖为 **14/14**。新增的状态时间一致性、代理披露、认证阶段、产能/良率范围，以及价值链传导、估值挂钩、风险阻断等规则都生成逐条件 `RuleEvaluation` 并参与挡门；代理证据、商业化阶段和产能/良率主张缺少结构化口径时会阻断，不按自由文本猜测后静默接受。历史 Runtime 2.0 样例仍按当时的五条确定性规则校验，不能冒充 3.0 留痕；所有新产物必须使用 Runtime 3.0 的 **13** 条语义规则。14/14 只衡量“登记规则是否有执行面”，不证明规则已经提高真实研究正确率；后者仍须通过真实研究评测验证。权威数字见 [`2026-07-28_本体支撑约束再评估与优化账本.md`](./2026-07-28_本体支撑约束再评估与优化账本.md)。

## 4. 本轮落地修复

证据覆盖页已经完成以下改进：

1. 每个判断单元显示最低证据组合、当前可核验事实、支持/反证、独立来源组、最薄弱环节和证据侧最大可达 J。
2. 只有 `usable + captured + quote_verified` 且不晚于研究截止时间的来源，才计入有效覆盖和独立来源组。
3. “结构要求检查反证”“已有反证事实”“反证缺口”不再混为同一状态。
4. 证据侧 J 上限使用与 Runtime `judgment_evidence_threshold` 一致的事实数、来源组、来源层级和直接性口径；Stage 04 仍可因竞争解释、冲突和路径状态下调。
5. 修正单条事实绑定多个独立来源组时错误停在 J0 的边界条件，使其至少可达到 J1；完整升级仍要求更多事实和合格来源组。
6. 来源卡使用单调研究状态链显示“线索—正文—引文—事实”；高阶状态必须满足前置条件，已确认 EvidenceFact 不会掩盖正文缺失或引文未核验。
7. 不同 URL 只要属于同一 `source_group`，仍只计一个独立来源组；显式回归测试证明两条同源事实不会把证据上限从 J1 错误抬到 J2。
8. 缺口按阻断、限制强度和补充完善分级并只突出前 3 项；证据变化通过实例图可达关系生成局部失效/重算范围，研究员界面显示受影响对象、命中条件与原因。
9. 知识库默认展示任务相关子图，不再把完整 182 节点网络作为研究员入口；完整网络保留为明确标注的高级治理视图。
10. 本体命中按“补全 / 限制 / 关联”解释实际生效的变量绑定、`task_local` 隔离、确定性规则结果和实例关系；没有本轮实例时明确显示“不能仅因类型存在就声称已用于研究”。
11. 数据库 v11 建立 `task_local` 治理队列：按名称、类别和变量类型的规范化键聚合跨 run 频次，保存专家确认、晋升/驳回状态与追加式历史。晋升记录不直接改写正式本体。
12. 跨 run 变量只有在正式语义对象、类别、类型、对象锚点、范围、地区、指标、单位和时间基准全部一致时生成可比键；差异返回不可直接比较，缺字段返回信息不足。
13. “证据影响哪些判断”使用与局部失效相同的正式方向追踪最短路径；台积电样例实际显示 EvidenceFact → Signal → Hypothesis → Judgment，并排除无关系稳定对象。“变量在哪些研究出现”同时覆盖正式本体变量和 `task_local` 候选。
14. 剩余 4 条正式规则已接入 Runtime 3.0：状态时间检查业务/公布/有效/截止时间顺序；代理指标强制披露滞后、范围和不可替代边界；商业化阶段禁止低阶段证据支持高阶段主张；产能/良率按设施、晶圆尺寸、制程/产品、批次、单位和业务时间六维对齐。正向、负向和缺陷注入测试覆盖关键词重叠误报（“量产良率”不等于“进入量产阶段”）。
