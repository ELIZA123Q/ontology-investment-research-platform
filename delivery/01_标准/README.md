# 表达标准

研究报告怎么写——这里定义所有产出的**写作规范、质量门槛和返工规则**。核心思想：把 04 已定稿的判断写成可读、可讨论、可跟踪的研究报告，不在写作环节新增或抬高结论。

## 主要规范

表达标准的完整内容见 [`05_投研表达标准.md`](05_投研表达标准.md)，核心要点如下：

### 五类报告

| 类型 | 适用场景 | 正文重点 |
|------|---------|---------|
| 事件点评 | 新政策、公告、事故或供应链扰动 | 事件事实、预期差、传导、影响对象 |
| 行业动态 | 近期行业发生了什么变化 | 增量变化、关键数据、产业链影响 |
| 周期判断 | 当前处于什么阶段，何时转向 | 供需库存、主导机制、强弱分化、结束条件 |
| 公司业绩 | 业绩和指引是否改变原判断 | 超预期来源、分业务表现、经营与估值含义 |
| 主题深度 | 新技术、赛道或产业变化如何演进 | 空间、产业链、竞争壁垒、商业化、对象分化 |

报告类型在 01 阶段与研究员确认，不能在写作阶段临时更换。

### 六大写作原则

1. **结论先于背景** — 标题和开头先给判断，不要从行业定义讲起
2. **结构服从问题** — 正文按论点组织，不套固定目录
3. **用带结论的章节标题** — "成熟制程供给并未归零"好过"产业链分析"
4. **事实、判断、前瞻分开** — 不让读者猜哪句是已发生、哪句是推演
5. **产业事实穿透到投资含义** — 不只写"空间很大"，还写谁受益、怎么传导
6. **继承上游、独立表达** — 不突破 04 判断的结论方向、等级、边界

### 关键禁忌

- 不要把 04 判断简报逐段扩写当成研报
- 不要新增未经 03/04 支撑的事实或更强主张
- 标题和投资要点不要用审计登记腔（"只能作为""不是确定结束"等），要改写成肯定的研究语言
- 不要虚构市场共识来衬托 Research Edge
