# 05_投研表达标准

## 研究员先看什么

05 回答：**怎样把 04 已定稿的判断写成可读、可讨论、可跟踪的研究报告。**

| 你要交什么 | 业务说法 |
|---|---|
| 最终研究稿 | 按 01 指定原型（事件点评 / 周期判断 / 主题深度等）写成研究语言 |
| 表达审计 | 机器侧核对是否越权表达（研究员可不深读） |

独立语义审查**不是**研究员交付物：由独立审阅者填写，登记在运行清单中，仅作发布闸门留痕（见 [`governance/03_校验/README.md`](../../governance/03_校验/README.md)）。

**怎样算完成：** 读者能回答——当前怎么看、相对原认识变了什么、主导矛盾是什么、如何传导、谁更受益、看什么信号、什么会改判。

**常见失败：** 把 04 简报逐段扩写；用章节堆砌冒充论证；把权限否定句抬成标题；新增未经 04 批准的更强主张。

质量见第 9 章与 [`00A`](../../governance/03_校验/00A_高质量产出判别标准.md)。正文语言继承 [`00` §9.3](../../governance/01_架构/00_项目定位与边界.md)。

## 1. 文档定位

05 是正式表达层：接收 04 已定稿判断与表达许可，写成可支持阅读、讨论与跟踪的研究成果。完整论证、章节结构、图表与研究语言均在本阶段完成。

研究员交付物：最终研究稿（01 指定原型）、表达审计。前 1—2 页结论化，正文论证化。五类主报告共用首页与论证原则，正文按问题选模块。独立语义审查属发布侧校验产物，不列入研究员交付清单。

## 2. 05 的核心产出

一份高质量 05 应使读者能够回答：

1. **当前到底怎么看；**
2. **与原有判断或市场普遍认识相比，发生了什么变化；**
3. **决定结论的核心矛盾和主导变量是什么；**
4. **结论如何传导到行业、环节、公司或资产；**
5. **哪些对象更受益、哪些对象兑现较弱，为什么；**
6. **未来看什么数据、事件或经营信号；**
7. **哪些风险会削弱结论，哪些事实出现后需要重新评估。**

05 的价值不以章节数量、篇幅或图表数量衡量，而以以下结果衡量：

> 结论鲜明，论证充分，结构服务于观点，对象分化有依据，投资含义清楚，后续可以持续验证。

04 的判断简报只回答“结论定到哪里、05 允许写什么”。05 必须据此独立完成：

- 标题与前页摘要；
- 正文论点和章节顺序；
- 从证据到机制再到投资含义的完整论证；
- 图表、表格和来源注释的选择与组织；
- 面向研究员和投资经理的最终研究语言。

05 不得把 04 判断简报逐段扩写，也不得为追求“增量”重新裁决判断。05 的增量来自正式表达、论证组织和阅读效率，而不是改变研究结论。

05 可以新增表达，不得新增未经批准的研究主张。允许调整叙事顺序、合并重复结论、转述结构化判断，并用 `source_rcs` 综合多个已获准观点；综合表达继承来源中的最低判断等级、全部条件和最窄共同范围。

## 2.1 五类报告怎么选

| 报告类型 | 适用问题 | 正文重点 |
|---|---|---|
| 事件点评 | 新政策、公告、事故或供应链扰动有什么影响 | 事件事实、预期差、传导、影响测算、受影响对象 |
| 行业动态点评 | 最近一个阶段行业发生了什么变化 | 增量变化、关键数据、产业链影响、后续演进 |
| 行业周期判断 | 当前处于什么阶段，何时可能转向 | 供需库存价格、主导机制、强弱分化、结束条件 |
| 公司业绩点评 | 业绩和指引是否改变原判断 | 超预期来源、分业务表现、预测假设、经营与估值含义 |
| 主题深度研究 | 新技术、新赛道或长期产业变化如何演进 | 空间、产业链、竞争壁垒、商业化路径、对象分化 |

报告类型由 01 与研究员确认。05 不能为了套模板临时改变报告类型。

## 3. 基本写作原则

### 3.1 结论先于背景

标题、投资要点和正文开头应先给结论，再解释背景和依据。

不得以以下方式开篇：

- 从行业定义和发展历史开始；
- 大段复述政策或事件经过；
- 先罗列资料，再到文末才给观点；
- 用“空间广阔、前景可期”替代具体判断。

### 3.2 结构服从研究问题，不服从固定目录

主题深度研究没有一套适用于所有问题的固定正文目录。

公开市场上的深度报告通常在首页集中呈现投资要点和风险，正文则根据研究主题分别采用产业趋势、市场空间、商业模式、竞争格局、技术路线、海外映射或公司比较等不同组织方式。05 应继承这种“首页相对稳定、正文按论点变化”的写法。

因此：

- 本规范规定**必须回答的内容功能**；
- 模板提供**可选择的研究模块**；
- 章节名称、顺序、数量和篇幅由本次核心问题决定；
- 不得为了满足模板而加入与结论无关的章节。

### 3.3 以核心论点组织正文

正文每一章都应是一个能够独立成立的研究论点，而不是一个资料类别。

推荐使用带结论的章节标题，例如：

- “成熟制程供给并未归零，政策影响将呈现类别分化”；
- “大市场仍在，但未来一年更依赖份额而非总量扩张”；
- “复购与跨线复制成为商业化分水岭”；
- “关键部件独立性决定第二轮分化”。

不推荐仅使用以下标题：

- 行业概况；
- 产业链分析；
- 竞争格局；
- 公司介绍；
- 未来展望。

上述内容可以存在，但标题和叙述必须服务于本次结论。

### 3.4 事实、判断和前瞻分开表达

正文应自然区分：

- **事实：** 已经发生并可复核；
- **解释：** 事实为什么重要；
- **判断：** 结合多项证据形成的当前看法；
- **前瞻：** 在明确条件下对未来的推演；
- **风险：** 可能使判断偏离的因素。

不要求在正文中机械标注“事实/判断/前瞻”，但语言必须让读者分辨清楚。

### 3.5 从产业事实穿透到投资含义

05 不能停留在“政策重要、产业空间大、技术有突破”。应继续回答：

```text
变化发生在哪里
→ 哪个经营变量受到影响
→ 哪类对象最先体现
→ 对收入、利润、竞争位置或估值逻辑意味着什么
→ 市场是否已经充分认识
```

若 01 明确不涉及估值、评级或个股建议，仍应说明行业和类别层面的投资含义、受益特征及跟踪方向；不得因合规边界而退化为纯行业科普。

### 3.6 继承上游结论，并独立完成正式表达

05 不重新取证或重新推理，不突破 04 的结论方向、判断等级、范围、条件、状态和 `handoff_to_05` 表达许可。

05 应为了研究可读性：

- 合并重复观点；
- 调整叙述顺序；
- 将机制、空间、竞争格局和公司样本重新组合成更清晰的论证；
- 用更符合研究员习惯的标题和图表表达上游结论；
- 把 04 的权限边界改写成研究语言，而不是把审计否定句抬成标题或投资要点。

#### 研究语言硬要求

标题、副标题、投资要点、核心结论概览和论点章节标题必须使用研究员可读的业务语言。边界与条件应写成**肯定条件句**或机制说明，例如：

```text
好：2027 下半年至 2028：先看新增供给能否真正放量
好：只有价格、库存、订单与合格供给共振转弱，才下调为正常化
坏：2027H2—2028 是供给验证窗口，不是确定结束日
坏：周期结束只能作为条件验证问题
```

下列审计登记腔不得出现在上述高可见位置：`只能作为`、`不得写成`/`不能写成`、`禁止给出`、`不是确定结束/拐点`、`条件式验证/缓解窗口`。这些语义约束留在 04 `handoff_to_05` 与表达审计 YAML；05 正文保留其含义，但必须改写措辞。`expression_text` 登记的是改写后的研报句，不是 04 Claim statement 原文。

04 不再提供标题候选、一页摘要要点、章节计划、叙事主线或图表表格方案。03 只提供报告级素材包及其有无、可用性与限制，不预写章节、故事线、标题或投资要点。05 应直接读取 03 素材包，并根据 04 已批准判断自主决定素材用不用、放在哪里、如何形成论证；每项选择仍须在表达审计中可追溯。

如正文需要关键的新事实或原结论无法支撑投资含义，应回到 03 或 04 补充，而不是在 05 中自行推断。

## 4. 整体结构：稳定首页 + 弹性正文

### 4.1 首页必须稳定

主题深度研究首页原则上包括：

1. 判断型标题；
2. 判断时点、前瞻窗口、研究对象和研究范围；
3. 投资要点；
4. 核心结论或主要变化；
5. 受益方向、重点观察对象或资产映射；
6. 催化与验证信号；
7. 风险提示。

首页的目标是让投资经理不阅读全文也能理解本次研究的核心价值。

### 4.2 正文必须弹性组织

正文一般由 **2—5 个核心论点章节**构成。每章围绕一个关键问题展开，并形成完整的“结论—证据—机制—含义”。

正文可以从下列模块中按需选择，不要求全部使用：

| 可选模块 | 适合回答的问题 |
|---|---|
| 变化与驱动 | 为什么现在需要重新研究，增量变化是什么 |
| 核心矛盾与传导 | 事件、政策、供需或技术如何影响经营结果 |
| 需求、供给与周期 | 总量、结构、库存、产能、价格处于什么阶段 |
| 市场空间与兑现 | 理论空间有多大，哪些部分可能形成订单和收入 |
| 产业链与价值分配 | 利润、议价权和受益环节如何分布 |
| 技术路线与产品演进 | 技术变化如何改变竞争位置和商业化节奏 |
| 商业模式与单位经济 | 收入来源、成本结构、盈利路径是否成立 |
| 竞争格局与壁垒 | 谁能获得份额，优势能否持续 |
| 类别或公司比较 | 不同对象的受益强弱、阶段和风险如何分化 |
| 海外经验或历史复盘 | 是否存在可比路径，哪些条件不可直接类比 |
| 财务影响与估值 | 变化如何进入收入、利润、现金流和估值 |
| 市场预期与分歧 | 当前市场在定价什么，研究结论的增量在哪里 |
| 情景推演 | 不同变量组合下结果如何变化 |
| 催化、验证与风险 | 未来什么时间看什么信号，什么会改变结论 |

模块选择应以核心问题为起点，不得把模块库当作目录库。

## 5. 首页写作要求

### 5.1 标题

标题应表达本次最重要的结论或变化，常用方式包括：

```text
<主结论>，<核心分化>
<行业变化>：<投资含义>
<核心矛盾>正在变化，<受益方向或阶段判断>
```

标题可以鲜明，但不得超过证据支持范围。

### 5.2 投资要点

投资要点原则上 4—6 条，每条包括一个清晰结论及必要依据。通常覆盖：

- 当前判断；
- 为什么现在；
- 核心矛盾或驱动；
- 主要受益方向和分化；
- 市场可能忽视的因素；
- 催化与风险。

不得把摘要写成正文目录，也不得简单复制 04 的结论段落。

### 5.3 市场认知差 / Research Edge

除纯事实型且无可比较基准的交付外，05 必须说明本次研究相较于可验证参考认识的增量。Research Edge 至少包含：

1. 参考认识：市场可验证共识、常见叙事、内部原判断或明确的关键未知；
2. 差异化判断：本研究与参考认识在哪个对象、变量、机制、幅度或时间窗口上不同；
3. 被低估的机制：为什么已有叙事可能遗漏、混同或错误外推；
4. 可证伪信号：什么事实出现后，该认知差不再成立；
5. 证据边界：哪些是可验证预期，哪些只是常见叙事或内部假设。

常见有效认知差例如：

- 市场把所有对象合并判断，但实际存在明显分化；
- 市场关注长期空间，但短期由验证和交付决定；
- 市场将增长归因于政策，实际还受到周期和扩产影响；
- 市场重视收入增速，但忽略利润质量或供应链限制。

若没有可靠的市场一致预期数据，应写“常见叙事”“普遍讨论”“内部原判断”或“关键未知”，不得虚构市场共识。若确实不存在可比参考，应明确写“本次研究边际在于解决关键未知”，不能省略 Research Edge。

### 5.4 受益方向和资产映射

应根据 01 的交付边界选择适当深度：

- **行业级任务：** 给出受益环节、对象特征和代表样本；
- **公司级任务：** 给出公司差异、财务影响和关键假设；
- **估值影响任务：** 可以说明哪些盈利、利润率、资本开支或折现假设发生变化，并给出估值区间和敏感性；
- **所有核心平台任务：** 不给评级、目标价、收益率预测、仓位或交易建议，但必须保留获准范围内的投资含义和关注方向。

不得用公司名单替代分析，也不得把代表样本写成未经论证的推荐组合。

## 6. 正文论证要求

### 6.1 每章应形成完整论证

每个正文核心章节至少包括：

1. **章首结论：** 本章要证明什么；
2. **关键证据：** 哪些数据和事实支持；
3. **作用机制：** 为什么这些证据能支持结论；
4. **投资含义：** 对行业、公司或资产意味着什么；
5. **限制因素：** 哪些因素可能削弱本章结论。

不要求以五个固定小标题呈现，但内容应完整。

### 6.2 数据必须产生解释

每个重要数据后都应回答“所以怎样”。

不应出现长篇数字罗列，却没有说明：

- 数据相较历史或预期发生了什么变化；
- 数据支持哪一个观点；
- 对未来变量有什么指示；
- 不同口径之间能否比较。

### 6.3 图表服务于论点

图表标题应尽量直接表达结论，例如：

- “中国设备需求维持高位，但增速已从扩张转向平台”；
- “已有复购类别的收入兑现明显领先于验证阶段类别”；
- “海外成熟制程供给仍在，替代紧迫性并非同步上升”。

每张图表应具备来源、时间、单位、口径和必要的样本说明。

图表数量由论证需要决定，不设置最低数量。不得为了“像研报”堆砌图表。

### 6.4 空间测算必须连接兑现条件

市场空间类章节应区分：

```text
总市场
→ 本次问题对应的有效需求
→ 可服务市场
→ 可替代或可获得份额
→ 订单、交付和收入确认
```

证据不足时可以采用区间、情景或结构性测算，不得输出缺乏依据的精确单一数字。

### 6.5 对象比较应说明比较口径

行业、类别和公司强弱比较必须说明基于什么：

- 需求弹性；
- 技术和产品成熟度；
- 客户验证和复购；
- 交付和服务能力；
- 收入和利润质量；
- 供应链独立性；
- 估值和市场预期。

“强、中、弱”不应单独出现，应写清楚是短期业绩、长期空间、竞争位置还是估值吸引力上的判断。

### 6.6 竞争格局不能只是公司罗列

竞争格局至少应解释：

- 谁在竞争；
- 竞争发生在哪个产品、客户或场景；
- 决定份额的关键能力是什么；
- 格局是集中、分散还是正在变化；
- 新进入者和替代路线如何影响现有格局；
- 格局变化最终如何影响收入和利润。

### 6.7 前瞻应有时间和验证信号

未来判断应尽量给出：

- 观察窗口；
- 领先指标；
- 数据或事件来源；
- 对结论的具体影响。

“持续关注政策变化”“需求不及预期”等泛化表达不足以构成研究跟踪。

## 7. 主题深度研究的常见组装方式

以下仅为组装参考，不是固定目录。

### 7.1 产业趋势型

```text
投资要点
→ 产业变化及核心驱动
→ 市场空间和渗透路径
→ 产业链价值分配
→ 竞争格局和受益方向
→ 催化与风险
```

### 7.2 政策或事件驱动型

```text
投资要点
→ 事件增量与真实边界
→ 主要传导路径
→ 行业和公司分化
→ 影响持续时间及情景
→ 催化、验证与风险
```

### 7.3 周期与供需型

```text
投资要点
→ 当前周期位置
→ 需求、库存和供给变化
→ 价格与盈利传导
→ 不同环节和公司的弹性
→ 拐点指标与风险
```

### 7.4 技术与产品变革型

```text
投资要点
→ 技术变化解决什么问题
→ 路线比较与产业化条件
→ 市场空间和商业模式
→ 产业链重构与竞争格局
→ 受益方向、催化与风险
```

### 7.5 国产替代或供应链重构型

```text
投资要点
→ 外部约束和真实供给缺口
→ 国内需求与验证进度
→ 各类别商业成熟度
→ 关键部件、交付和利润约束
→ 受益方向、验证与风险
```

实际成稿可以混合使用，但应保持一条清晰主线。

## 8. 来源、风险与合规

### 8.1 来源

关键事实、测算和图表应可追溯到正式规则、行业组织、公司法定披露、客户或供应商披露及其他可靠来源。

正文可采用脚注、尾注或图表来源，具体形式不强制，但不得只在文末列出大量来源而无法对应关键观点。

### 8.2 风险提示

风险应与主逻辑对应，优先写：

- 哪一项关键假设可能不成立；
- 哪一个传导环节可能中断；
- 哪一项经营指标可能偏离；
- 哪一种竞争、技术或政策变化可能改变格局；
- 哪些数据和样本存在局限。

### 8.3 估值分析与投资建议边界

05 可以在 01 授权且 03—04 证据充分时表达估值影响：

1. 哪个经营或财务假设发生变化；
2. 变化如何进入估值参数、区间或敏感性；
3. 当前定价隐含了哪些可验证假设；
4. 哪些条件会使该估值影响失效。

核心平台统一禁止评级、目标价、收益率预测、仓位和直接交易建议。禁止目标价不等于禁止估值分析；不具备估值基线和假设桥时，应停留在行业、类别、公司特征和投资含义层面。

## 9. 质量门槛与返工规则

本节是 05 阶段质量要求和返工条件的唯一权威。全局质量定义和正式发布规则见 `../governance/03_校验/00A_高质量产出判别标准.md`。

### 9.1 最低完整条件

05 至少满足以下条件，才可进入高质量检查：

1. 交付形态与 01《投研需求说明》记录的报告类型一致；
2. 已读取并引用本次 01—04 正式交付物；
3. 文首判断时点、前瞻窗口、研究对象和范围与上游一致；
4. 首页包含投资要点、核心结论概览和可证伪的 Research Edge；
5. 正文由 2—5 个核心论点组织，并包含投资含义、风险和跟踪内容；
6. 图表、表格和来源注释来自 03 已确认可用的素材，并由 05 自行选择与组织；
7. 表达审计能够把重要观点对应到 04 已审计判断，并逐项确认方向、等级、范围、条件和状态未漂移；
8. 正文结构、完整论证、标题摘要、图表组织和研究语言由 05 独立完成，未从 03/04 接收预写目录、故事线、投资要点或成段正文。

满足最低完整条件只表示结构完整，不代表可以正式发布。

### 9.2 高质量门槛

达到 `high_quality_pass`，还必须确认：

1. 阅读前 1—2 页即可理解当前结论、研究增量、对象分化、催化和主要风险；
2. 每章完成“结论—证据—机制—投资含义—限制因素”，不是资料汇编；
3. 数据口径可靠，图表和测算直接服务于论点；
4. 核心观点的方向、判断强度、范围、条件和状态与 04 一致；
5. 没有新增未经 03/04 支撑的事实、来源、数值或判断；
6. 跟踪信号可观察，并能说明会改变哪项结论；
7. 正文使用研究语言：没有任务编号、校验状态、路径编号，以及 `Q-/JU-/ER-/EV-/C-/RC-/EX-` 等跨阶段系统编号；这些编号只保留在表达审计 YAML（见 [`governance/02_合同/public_contract.yaml`](../../governance/02_合同/public_contract.yaml)）；同时，标题、投资要点、结论概览和章节标题不得粘贴 04 审计登记腔（见 §3.6），边界须改写成肯定条件句或机制说明；
8. 投资含义可讨论，但没有越过评级、目标价、收益承诺或交易建议边界；

### 9.3 不得正式发布的情况

出现以下任一情况，05 不得正式发布：

1. 首页不能独立传达核心结论和风险；
2. 正文仍按固定栏目拼接，缺少连续论证；
3. 观点超过 04 判断或 03 证据能够支持的强度；
4. Research Edge 虚构市场共识，或无法说明证伪信号和证据边界；
5. 跟踪内容不可观察，或无法对应具体结论；
6. 使用未在 03 快照登记的图表、表格、来源或数值；
7. 正文与表达审计不一致；
8. 存在未经允许的评级、目标价、收益率预测、仓位或交易建议；
9. 03 的 `delivery_readiness.status` 不是 `ready`，且 05 未按 `delivery_limit` 降级、删减相应表达或完成 `gap_action`；
10. 标题、投资要点、结论概览或论点章节标题使用审计登记腔，未改写成研究语言；
11. 规则校验未通过。

### 9.4 返工去向

| 问题表现 | 处理 |
|---|---|
| 报告形态、结构、语言或图表组织不合格 | 返工 05 |
| 需要表达的判断没有在 04 审计通过或未获表达许可 | 删除该表达或退回 04 |
| 观点超过 04 判断强度 | 降低表达强度或退回 04 |
| 所需数据、图表、表格或来源注释未在 03 准备 | 退回 03 或删除相关内容 |
| 研究对象、时间、范围或交付用途不一致 | 按最早发生偏差的位置退回 01—04 |

返工后必须重新运行 05 规则校验。

## 10. 与 01—04 的关系

```text
01 明确研究问题、对象、边界和交付用途
→ 02 确定核心矛盾、判断主线和对象分化
→ 03 准备事实、数据、图表和来源
→ 04 形成 2—4 页判断简报、推理审计和表达许可
→ 05 完成最终研究稿、完整论证与表达审计
```

05 不是 04 的扩写版，也不是 03 的资料汇编版，而是正式表达层：在不改变已审计判断的前提下，将上游研究转化为市场化、可阅读、可讨论、可持续跟踪的最终研究稿。
