# B00_来源画像总览

## 1. 定位

B 类文件定义取证来源相关的五个维度：

| 文件 | 维度 | 回答的问题 |
|---|---|---|
| B01 | SourceProfile | 谁生产或发布材料，权威性如何 |
| B02 | ContentDomain | 数据描述什么对象或变量 |
| B03 | AcquisitionChannel | 通过什么方式获取 |
| B04 | AccessScope | 能否使用、如何使用 |
| B05 | ArtifactType | 实际材料形态与留痕方式 |

## 2. 基本原则

不得把来源生产者、内容领域、获取方式、权限边界和材料形态混写。

```text
Wind = SourceProfile
金融市场数据 = ContentDomain
MCP Connector = AcquisitionChannel
licensed = AccessScope
API response / CSV = ArtifactType
```
