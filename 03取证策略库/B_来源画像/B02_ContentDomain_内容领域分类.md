# B02_ContentDomain_内容领域分类

## 1. 定位

`ContentDomain` 表示材料或数据描述的内容领域。它回答：

```text
这份数据讲的是什么领域；
适合支持哪类判断；
常见指标、口径和质量风险是什么；
应优先匹配哪些 SourceProfile 和 AcquisitionChannel。
```

`ContentDomain` 不是来源，也不是取数方式。例如“金融市场”是内容领域，不是来源；“MCP”是获取通道，不是内容领域。

## 2. 与其他维度的区别

| 概念 | 回答的问题 | 示例 |
|---|---|---|
| SourceProfile | 谁生产或发布 | Wind、交易所、公司、TrendForce、内部数仓 |
| ContentDomain | 数据描述什么 | 金融市场、公司财务、行业供需、政策监管 |
| AcquisitionChannel | 怎么取得 | Web、API、MCP、数据库终端、人工上传 |
| AccessScope | 能否使用 | public、licensed、internal、confidential |
| ArtifactType | 拿到什么形态 | PDF、CSV、API response、数据库字段 |

## 3. ContentDomain 标准字段

| 字段 | 说明 |
|---|---|
| `content_domain_id` | 稳定 ID |
| `domain_name` | 内容领域名称 |
| `typical_indicators` | 典型指标 |
| `typical_judgment_use` | 常用于哪些判断 |
| `preferred_source_profiles` | 首选来源画像 |
| `acceptable_source_profiles` | 可接受来源画像 |
| `common_quality_risks` | 常见质量风险 |
| `required_grain` | 常见粒度要求 |
| `freshness_requirement` | 时效性要求 |
| `traceability_requirement` | 留痕要求 |
| `proxy_policy` | 是否常需要代理指标 |
| `not_sufficient_for` | 不能单独支持什么 |

## 4. 主要内容领域

### 4.1 `CD_POLICY_REGULATION` 政策监管

| 项目 | 说明 |
|---|---|
| 典型内容 | 政策文本、监管规定、执行细则、处罚、豁免、清单、生效时间 |
| 常用判断 | 政策事实、政策冲击、适用范围、执行风险 |
| 首选来源 | 官方监管、政府部门、交易所、法院、海关、标准组织 |
| 质量风险 | 新闻转述替代原文；生效时间和发布时间混淆；适用范围外推 |
| 必需留痕 | 原文、发布者、发布时间、生效时间、条款、修订/失效检查 |
| 不足以支持 | 实际产业影响、公司业绩影响、市场预期 |

### 4.2 `CD_COMPANY_DISCLOSURE` 公司披露

| 项目 | 说明 |
|---|---|
| 典型内容 | 财报、公告、招股书、IR、投资者日、问询回复、业绩会 |
| 常用判断 | 公司事实、财务指标、项目进展、管理层指引、业务拆分 |
| 首选来源 | 交易所、公司官网、公司 IR、授权数据库回源字段 |
| 质量风险 | 披露选择性；指引与事实混淆；报告期和披露日混淆 |
| 必需留痕 | 文件版本、页码/表格、报告期、披露日、statement_type |
| 不足以支持 | 全行业事实、竞争对手未披露事实、真实市场需求 |

### 4.3 `CD_FINANCIAL_MARKET` 金融市场

| 项目 | 说明 |
|---|---|
| 典型内容 | 股价、成交量、估值、利率、汇率、商品价格、信用利差、一致预期 |
| 常用判断 | 市场定价、预期差、估值重估、相对收益、风险偏好 |
| 首选来源 | 交易所、授权金融数据库、行情 API、指数供应商 |
| 质量风险 | 复权口径、币种、交易日、样本、估值字段、预期样本不清 |
| 必需留痕 | 字段、交易日/窗口、复权方式、样本、数据截止时点、导出时间 |
| 不足以支持 | 基本面事实本身、产业链机制、公司未披露经营状态 |

### 4.4 `CD_FINANCIAL_STATEMENT` 财务报表

| 项目 | 说明 |
|---|---|
| 典型内容 | 收入、利润、成本、毛利率、费用、现金流、资产负债表 |
| 常用判断 | 业绩弹性、财务质量、经营预测、财务承接 |
| 首选来源 | 年报、季报、交易所披露、授权数据库追溯字段 |
| 质量风险 | 合并范围变化、会计政策变化、一次性项目、口径调整 |
| 必需留痕 | 报告期、币种、会计口径、字段来源、是否调整、版本 |
| 不足以支持 | 未来业绩必然变化、未披露业务线细节 |

### 4.5 `CD_INDUSTRY_SUPPLY_DEMAND` 行业供需

| 项目 | 说明 |
|---|---|
| 典型内容 | 出货、产能、库存、价格、利用率、市场规模、份额 |
| 常用判断 | 行业周期、景气阶段、供需缺口、价格趋势 |
| 首选来源 | 行业专业数据库、协会统计、公司披露交叉验证 |
| 质量风险 | 统计口径不透明；预测与事实混淆；样本覆盖不足 |
| 必需留痕 | 产品口径、统计期、地域、单位、方法说明、是否预测 |
| 不足以支持 | 单家公司未披露事实、客户关系、订单真实性 |

### 4.6 `CD_OPERATING_CHAIN` 经营与产业链

| 项目 | 说明 |
|---|---|
| 典型内容 | 订单、交期、客户、供应商、良率、认证、项目、产线、库存层级 |
| 常用判断 | 机制传导、供应链瓶颈、对象分化、业绩兑现 |
| 首选来源 | 公司披露、内部数据、一手调研、客户/供应商披露、项目文件 |
| 质量风险 | 样本偏差、非公开权限、关系推测、时间滞后、选择性披露 |
| 必需留痕 | 样本、主体、时间、权限、对象关系、可复核程度 |
| 不足以支持 | 全市场统计结论，除非样本覆盖和方法明确 |

### 4.7 `CD_MACRO` 宏观经济

| 项目 | 说明 |
|---|---|
| 典型内容 | GDP、CPI、PPI、PMI、利率、汇率、就业、贸易、社融 |
| 常用判断 | 宏观环境、需求背景、风险偏好、政策周期 |
| 首选来源 | 统计局、央行、财政、海关、国际组织、授权数据库 |
| 质量风险 | 初值修订、季调口径、国家间可比性、统计期错配 |
| 必需留痕 | 发布机构、统计期、修订版本、季调/非季调、单位 |
| 不足以支持 | 单家公司结论或具体产业链瓶颈 |

## 5. 质量影响

ContentDomain 会影响三个方面：

1. 必需字段不同：财务数据重报告期和会计口径，行业供需重产品/地域/统计方法，政策监管重原文和生效时间；
2. 时效要求不同：行情数据可能日频，财报季频，政策事件事件驱动，行业数据月度或季度；
3. 可支持判断不同：金融市场数据可以支持预期和定价，不直接证明基本面事实。

## 6. 输出到 03 快照

`source_profiles.csv`、`source_snapshot.csv`、`evidence_records.csv`、`evidence_readiness_assessments.csv` 中应保留 `content_domain_id` 或内容域标签，用于后续判断数据是否适合对应 judgment_type。

示例：

```csv
source_id,source_profile_id,content_domain_id,acquisition_channel_id,access_scope_id,artifact_type_id
SRC-001,SRC_WIND,CD_FINANCIAL_MARKET,CH_MCP,AS_LICENSED,AT_API_RESPONSE
```
