# B_取证来源

本包是 03 取证策略库中的 B 类“取证来源”目录，用于帮助 03 在取证前确定：

1. 某类证据优先去哪取；
2. 哪些来源可以作为主源，哪些只能作为交叉验证、替代来源或线索；
3. 行业专用变量和专题冲击变量应进入哪个来源文件；
4. 主源缺失时如何降级；
5. 取到材料后能否进入 04 推理和 05 表达。

## 快速使用

03 执行取证时建议按以下顺序使用：

```text
02 判断单元
→ A 类取证规则
→ 证据篮子
→ B02 通用来源
→ 如涉及行业变量，查 B03_行业专用来源/
→ 如涉及专题冲击，查 B04_专题来源/
→ B01 来源分层与使用边界
→ 执行取证并记录来源、口径、时间、权限、留痕和 04 使用上限
```

## 设计原则

- 不建设完整来源治理平台。
- SourceProfile、SourceDocument、AcquisitionChannel、AccessScope、ArtifactType 和 ContentDomain 由通用证据域定义，本包只给取证来源选择建议。
- 不把 MCP/API/网页/文件上传视为来源本身，它们只是获取方式。
- 不把新闻、研报、搜索结果、AI 摘要当作关键事实主源。
- 通用来源、行业来源、专题来源分开维护，避免 B02 被某个行业污染。
- 全球来源和中国来源都要覆盖；涉及中国资产、中国政策、中国贸易和 A/H 股公司时，必须检查中国侧主源。
- 来源清单不是封闭白名单，新来源可以使用，但必须说明来源生产者、口径、时间、权限、可复核路径和使用限制。
