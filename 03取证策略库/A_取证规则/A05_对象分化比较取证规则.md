# A05_对象分化比较取证规则

## 研究员排序前先统一三件事

1. 比较集合和排除规则；
2. 指标定义、期间、币种、分母与业务边界；
3. “暴露”与“能兑现收益/承受损失”的区别。

实用比较式为：`结果差异 = 暴露度 × 敏感度 × 承接/兑现能力 − 约束与对冲`。概念相关、产业链位置或收入占比只能说明暴露，不能单独支持排序。换一个合理口径就反转的排名，应降为分组描述。

## 1. 定位

对象分化比较取证规则用于判断不同公司、产品、环节、地区或资产在同一变量或机制下的相对受益、受损、强弱和约束差异。

它回答：

```text
谁真正暴露于该变量；
谁有更高弹性；
谁受到更多约束；
排序是否有证据支撑；
排序缺口和限制是什么。
```

A05 不直接进行财务测算；如涉及收入利润影响，应调用 A06。若涉及市场是否已经反映，应调用 A07。

## 2. 适用场景

| judgment_type | 示例 |
|---|---|
| `object_comparison` | 哪些公司更受益于价格上涨 |
| `winner_loser_ranking` | 产业链各环节谁强谁弱 |
| `exposure_ranking` | 谁对 AI 需求、政策限制或成本上涨暴露更高 |
| `constraint_comparison` | 哪些对象更受产能、认证、供应链约束 |
| `segment_differentiation` | HBM、DDR5、NAND 是否处于不同周期 |
| `regional_comparison` | 不同地区受政策或供需影响的差异 |

## 3. 不适用场景

| 问题 | 应转向 |
|---|---|
| 某个对象事实是否存在 | A01 |
| 单一变量状态 | A02 |
| 趋势或阶段 | A03 |
| 传导机制是否成立 | A04 |
| 业绩弹性测算 | A06 |
| 估值差异 | A07 |

## 4. 入口输入

| 字段 | 说明 |
|---|---|
| `comparison_set` | 纳入比较的对象集合 |
| `comparison_dimension` | 暴露度、弹性、约束、财务承接、估值等 |
| `required_scope` | 时间、地域、产品、业务范围 |
| `ranking_purpose` | 强弱排序、受益排序、风险排序或分层 |
| `minimum_comparable_fields` | 可比所需字段 |
| `counter_requirement` | 可能推翻排序的反证 |

## 5. 必需证据组合

| 必要证据组合 | 目的 | 最低要求 |
|---|---|---|
| `object_scope` 对象范围 | 明确谁参与比较 | 纳入和排除对象必须说明 |
| `exposure_evidence` 暴露度 | 证明对象与变量有关 | 收入、产能、产品、客户、地区、资产或供应链暴露 |
| `elasticity_evidence` 弹性 | 判断变量变化对对象影响强弱 | 价格、销量、成本、毛利率、经营杠杆或替代变量 |
| `constraint_evidence` 约束 | 识别受益无法兑现的条件 | 产能、良率、认证、客户限制、资本开支、政策约束 |
| `comparable_basis` 可比口径 | 保证横向比较有效 | 同时间、同指标、同业务口径或明确调整 |
| `counter_ranking_check` 排序反证 | 防止直觉排序 | 检查看似受益但受限、看似受损但对冲的情况 |

## 6. 来源优先级

| 证据类型 | 首选来源 | 辅助来源 |
|---|---|---|
| 暴露度 | 公司财报、业务拆分、招股书、客户/供应商披露、内部数据 | 产业链图谱、研报线索 |
| 弹性 | 历史量价、毛利率、成本结构、经营指标、敏感性披露 | 卖方模型假设需标注 |
| 约束 | 公司披露、项目文件、认证名单、调研、一手经营记录 | 新闻和行业媒体 |
| 可比指标 | 授权金融数据库、公司披露同口径字段 | 手工整理但需留痕 |

## 7. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 比较集合 | 必须说明纳入/排除标准 | 排序不可用 |
| 指标可比 | 排序指标必须同口径或说明调整 | 降为定性分层 |
| 暴露绑定 | 不能只按产业链位置排序 | 降级 |
| 弹性证据 | 强弱排序应至少有暴露+弹性或暴露+约束 | 只能描述暴露差异 |
| 约束检查 | 必须检查兑现约束 | 不得 high_quality_pass |
| 反证 | 必须检查排序可能反转的条件 | 降级 |

## 8. 降级规则

| 问题 | 03 处理 | 04 最多能形成的结论 |
|---|---|---|
| 只有对象名单 | 不形成排序 | background_only |
| 只有产业链位置 | 不得写强弱 | insufficient |
| 只有暴露无弹性 | 写暴露高低，不写受益强弱 | conditional_only |
| 口径不一致 | 分组或降级 | conditional_only |
| 排序反证未查 | 不得 high_quality_pass | directional_only_or_lower |
| 约束证据显示无法兑现 | 标记 contested 或反向排序 | contested |

## 9. 停止规则

对象比较可以停止的条件：

1. 对象集合和排除标准明确；
2. 至少一个主排序维度有可比证据；
3. 暴露、弹性和约束至少覆盖核心对象；
4. 排序反证已检查；
5. 可形成排序、分层或仅能描述差异的边界已明确。

## 11. 示例

问题：存储周期中哪些公司更受益。

最低证据：

```text
产品暴露度
+ 收入/产能/客户结构
+ 价格或销量弹性
+ 成本与产能约束
+ 同业可比口径
+ 排序反证：产能不足、客户限制、价格传导失败
```

## 12. 专项执行协议：可比性先于排序

比较前建立 `comparison contract`：

1. 固定比较目的：暴露、受益弹性、兑现能力、风险还是估值；
2. 定义总体与纳入/排除规则，避免事后挑选对象；
3. 统一时间、币种、会计口径、业务分部和产品范围；
4. 区分规模、比例和变化率，防止大公司天然排前；
5. 先比较暴露，再比较弹性和承接约束；
6. 缺失值不自动计零，单独标为 unknown；
7. 输出排序前做权重、口径和窗口敏感性检查。

## 13. 四层分化模型

| 层级 | 核心问题 | 典型指标 | 不足时允许表达 |
|---|---|---|---|
| Exposure | 是否与驱动变量真实相关 | 收入/产能/采购/客户/地域占比 | 只描述暴露高低 |
| Sensitivity | 驱动变化带来多大经营变化 | 量价、成本、经营杠杆、历史弹性 | 条件性受益/受损 |
| Capture | 是否有能力承接 | 产能、良率、认证、合同、渠道、资本 | 说明理论弹性受限 |
| Realization | 是否已进入财务或现金 | 订单、交付、收入、利润、回款 | 确认兑现阶段 |

任何“受益排序”至少覆盖前三层；只有 Exposure 时不得把“相关”写成“更受益”。

## 14. 排序方法与稳健性

- 维度较少且证据不齐时优先输出分层矩阵，不强造综合分数；
- 使用综合分数时必须公开指标、方向、标准化、权重和缺失处理；
- 极值、负数和分母接近零时禁止直接 min-max 标准化；
- 至少执行一次权重变化或指标剔除测试；前后名次大幅变化时标记 `ranking_unstable`；
- 定性标签必须绑定证据，不得将 analyst judgment 伪装成数据得分；
- 估值比较应另接 A07，不能把低估值直接计为经营受益。

## 15. 比较偏差与失败模式

| 偏差 | 示例 | 处理 |
|---|---|---|
| 选择偏差 | 只选已知受益公司 | 预设总体和排除理由 |
| 规模偏差 | 用绝对订单金额比较大小公司 | 同时看占比和增量贡献 |
| 分母偏差 | 小基数增速异常高 | 同时展示绝对值和基数 |
| 时间偏差 | 公司财年错位 | 转换到可比业务窗口 |
| 披露偏差 | 披露多的公司看似更强 | unknown 与 zero 分开 |
| 双重计算 | 收入暴露和产能暴露高度重叠 | 检查指标共线和重复权重 |
| 幸存者偏差 | 排除失败或退出对象 | 保留退出、延期和未兑现样本 |

## 16. 输出等级

| 证据状态 | 允许输出 |
|---|---|
| 仅对象和暴露 | 暴露分组 |
| 暴露 + 弹性 | 条件性影响分层 |
| 暴露 + 弹性 + 承接 | 方向性受益/受损排序 |
| 再加兑现证据和稳健性 | 可进入 05 的排序表 |

排序表必须附比较口径、数据截止点、unknown 项、反转条件和禁止用途。
