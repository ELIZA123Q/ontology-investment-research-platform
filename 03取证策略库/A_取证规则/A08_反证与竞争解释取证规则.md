# A08_反证与竞争解释取证规则

## 1. 定位

反证与竞争解释取证规则用于主动寻找可能削弱、阻断、推翻或重新解释主判断的证据。

它回答：

```text
主判断可能错在哪里；
是否存在方向相反的数据；
是否存在更能解释同一现象的机制；
哪些条件会阻断传导；
证据冲突如何限制 04。
```

A08 是所有方向性判断的必选规则。没有反证检查，不得标记为 high_quality_pass。

## 2. 适用场景

适用于所有 judgment_type，尤其是：

| judgment_type | 反证示例 |
|---|---|
| fact_confirmation | 撤回、修订、否认、失效、范围排除 |
| state_measurement | 反向指标、口径冲突、时间错配 |
| trend_or_phase | 趋势不持续、斜率放缓、阶段竞争解释 |
| mechanism_transmission | 阻断条件、替代路径、暴露不足 |
| object_comparison | 排序反转、兑现约束、指标不可比 |
| earnings_impact | 成本抵消、销量不足、价格传导失败 |
| valuation_expectation | 预期已反映、估值已高、风险溢价变化 |

## 3. 不适用场景

A08 不单独确认事实或测量变量。反证本身仍应按其性质调用 A01、A02、A03、A04、A05、A06 或 A07。

## 4. 入口输入

| 字段 | 说明 |
|---|---|
| `primary_judgment_unit_id` | 被反证检查的判断单元 |
| `primary_view_or_hypothesis` | 待检验的主观点或假设 |
| `supporting_baskets` | 已取得的支持证据篮子 |
| `required_counter_types` | 必须检查的反证类型 |
| `alternative_explanations` | 已知竞争解释 |
| `downgrade_rule` | 反证成立时的降级规则 |

## 5. 必需证据篮子

| 反证篮子 | 目的 | 最低要求 |
|---|---|---|
| `opposite_direction_evidence` 方向相反证据 | 检查变量是否反向 | 至少检查同变量或相邻变量的反方向来源 |
| `blocking_condition` 阻断条件 | 检查传导链是否中断 | 替代供应、库存缓冲、合同锁价、执行弱化等 |
| `alternative_explanation` 竞争解释 | 检查同一现象是否有其他机制 | 至少列出并取证一个主要竞争解释 |
| `scope_conflict` 范围冲突 | 检查对象、地区、产品、时间是否错配 | 记录与 02 范围不一致的证据 |
| `source_conflict` 来源冲突 | 检查来源之间是否矛盾 | 记录冲突类型、范围、是否可消解 |
| `quality_attack` 质量反证 | 检查支持证据自身是否不稳 | 来源不独立、口径不明、样本偏差、权限问题 |

## 6. 来源优先级

反证来源应优先使用与主证据独立的来源链。

| 反证类型 | 首选来源 |
|---|---|
| 方向相反数据 | 同变量独立数据库、公司披露、行业统计 |
| 阻断条件 | 公司公告、一手调研、供应商/客户披露、政策细则 |
| 竞争解释 | 历史数据、替代变量、卖方分歧观点、专家观点 |
| 来源冲突 | 原始来源、方法论说明、更新版本 |
| 质量攻击 | 字段定义、样本说明、权限说明、数据生成链路 |

## 7. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 主动性 | 必须主动查找，不得只记录碰巧出现的冲突 | 不得 high_quality_pass |
| 独立性 | 反证来源应尽量独立于主证据来源链 | 同源反证只作补充 |
| 对称性 | 反证口径应尽量与主证据可比 | 不可比时标注限制 |
| 强度判断 | 反证必须区分削弱、阻断、推翻或仅提示风险 | 不得混写 |
| 保留冲突 | 未消解冲突不得删除任一方 | 标记 contested |

## 8. 反证作用分类

| 类型 | 含义 | 04 影响 |
|---|---|---|
| `weakening` | 削弱主判断强度 | 降低置信度或限制范围 |
| `blocking` | 阻断关键路径 | 路径停止 |
| `invalidating` | 推翻事实或关键变量 | 不得方向性判断 |
| `competing` | 提供替代解释 | 条件判断或 contested |
| `scope_limiting` | 限制适用范围 | 缩小对象、时间或地域 |
| `quality_limiting` | 证据质量不足 | 降低证据等级 |

## 9. 降级规则

| 问题 | 03 处理 | 04 使用上限 |
|---|---|---|
| 未做反证检查 | 返工或降级 | directional_only_or_lower |
| 反证削弱主判断 | 降低置信度和范围 | conditional_only |
| 反证阻断路径 | 路径 blocked | none 或 path_stopped |
| 反证与支持证据冲突未消解 | 标记 contested | contested |
| 替代解释更强 | 主判断降级 | contested_or_insufficient |
| 反证只来自弱来源 | 记录但不直接推翻 | caveated_use |

## 10. 停止规则

反证检查可以停止的条件：

1. 每个方向性判断单元至少检查一个相反变量或竞争解释；
2. 每条核心路径至少检查一个阻断条件；
3. 反证来源、口径、时间和适用范围已记录；
4. 已明确反证对 04 的影响；
5. 继续补充不会改变准入状态，或已说明当前权限下不可得。

## 11. 输出到 03 快照

| 文件 | 关键字段 |
|---|---|
| `evidence_requirements.csv` | 主判断、反证类型、检查范围、来源计划、状态 |
| `evidence_records.csv` | effect_on_judgment=weaken/block/conflict/counter |
| `evidence_baskets.csv` | counter basket 状态 |
| `gaps_and_risks.csv` | 阻断、竞争解释、冲突和降级说明 |
| `evidence_readiness_assessments.csv` | 反证对判断单元状态的影响 |

## 12. 示例

主判断：存储价格上行由 AI/HBM 挤占供给主导。

反证检查：

```text
传统服务器或消费电子需求恢复是否也能解释价格上涨；
原厂库存是否已经回升；
新增供给是否快于预期；
HBM 产能扩张是否缓解挤占；
价格上涨是否只出现在部分规格；
卖方或行业机构是否有相反判断。
```
