# A02_状态变量测量取证规则

## 研究员先画一条测量链

```text
研究概念 → 可观察指标 → 数据生产过程 → 样本与覆盖 → 单位/分母 → 当前值与基准 → 误差边界
```

先问“这个指标是否真的测到了我要判断的状态”，再问数值高低。直接指标与代理指标要分开；缺失值、零值和未披露不能互换。当前状态至少要有一个可解释的基准：历史、同业、目标、正常区间或结构分项。

## 1. 定位

状态变量测量取证规则用于把 02 中的状态变量、观测要求和最低验证条件，转化为可取得、可比较、可追溯的数据需求。

它回答的是：

```text
某个变量当前是什么状态；
这个状态如何被观测；
观测值是否具备时间、对象、口径和来源约束；
该观测能否进入 04 推理。
```

A02 不直接判断趋势、周期阶段或机制含义。趋势和阶段判断交给 A03；机制传导交给 A04；财务影响交给 A06；市场预期交给 A07。

## 2. 适用场景

适用于以下 judgment_type：

| judgment_type | 示例 |
|---|---|
| `state_measurement` | DRAM 合约价当前处于什么水平 |
| `price_state` | 现货价、合约价、ASP、报价是否变化 |
| `demand_state` | 出货、订单、客户拉货、终端需求是否改善 |
| `supply_state` | 产能、产能利用率、良率、供给释放节奏是否变化 |
| `inventory_state` | 原厂、渠道、客户库存是否处于高位或低位 |
| `order_delivery_state` | 订单、交期、取消订单、重复下单是否变化 |
| `cost_state` | 原材料、制造成本、运费、能源成本是否变化 |
| `financial_metric_state` | 收入、毛利率、费用率、现金流等财务指标状态 |

## 3. 不适用场景

| 问题 | 应转向 |
|---|---|
| 某事件是否真实发生 | A01 事实确认 |
| 一个变量是否进入趋势或周期阶段 | A03 趋势与阶段判断 |
| 状态变量如何传导到另一个环节 | A04 机制传导验证 |
| 不同公司谁更受益 | A05 对象分化比较 |
| 状态变量如何影响收入利润 | A06 财务影响测算 |
| 市场是否已经反映变量变化 | A07 市场预期与定价 |
| 主变量不可得、只能找替代指标 | A09 代理指标使用 |

## 4. 入口输入

A02 调用前，03 应获得：

| 字段 | 说明 |
|---|---|
| `judgment_unit_id` | 绑定的 02 判断单元 |
| `state_variable_id` | 目标状态变量 |
| `anchor_object` | 变量锚定对象，例如公司、产品、环节、地区、资产 |
| `measurement_question` | 要测量的问题 |
| `required_scope` | 时间、对象、地域、产品、业务范围 |
| `required_grain` | 日度、周度、月度、季度、年度、事件点、截面 |
| `required_quality_level` | 最低证据等级 |
| `candidate_direct_indicators` | 候选直接指标 |
| `candidate_proxy_indicators` | 候选代理指标 |
| `counter_requirement` | 需要检查的反向变量或冲突来源 |

## 5. 必需证据组合

| 必要证据组合 | 目的 | 最低要求 |
|---|---|---|
| `direct_measure` 直接测量 | 获得目标变量的直接观测 | 至少有一个同口径、可追溯的直接指标或原始字段 |
| `business_time` 业务时间 | 明确变量对应的实际时间 | 必须区分业务时间、发布时间、获取时间和数据截止时点 |
| `measurement_scope` 测量范围 | 确认变量适用于哪个对象和范围 | 产品、地区、口径、公司或环节必须匹配 02 范围 |
| `unit_and_definition` 单位与定义 | 防止口径误用 | 指标定义、单位、币种、频率、统计方法必须可解释 |
| `cross_check` 交叉验证 | 防止单源误差 | 至少检查一个独立来源或相邻变量 |
| `counter_measure` 反向变量 | 识别削弱证据 | 检查是否存在方向相反或口径冲突的变量 |

进入 04 方向性使用的最低条件：

```text
direct_measure + business_time + measurement_scope + unit_and_definition + counter_measure
```

若只有代理指标，应同时调用 A09，并将 04 最多能形成的结论降为 `conditional_only` 或更低。

## 6. 来源优先级

| 变量类型 | 首选来源 | 可接受来源 | 辅助来源 |
|---|---|---|---|
| 金融市场价格 | 授权金融数据库、交易所行情、指数供应商 | 公司披露、基金/交易平台披露 | 新闻和研报仅作背景 |
| 公司财务指标 | 年报、季报、交易所文件、授权数据库原字段 | 公司 IR 材料 | 新闻和卖方研报不得替代原始财报 |
| 行业价格/供需 | 行业专业数据库、协会统计、公司披露交叉验证 | 产业研究机构、授权报告 | 新闻、研报作线索 |
| 库存/订单/交期 | 一手经营记录、公司披露、产业数据库 | 调研纪要、渠道反馈 | 单条传闻不得独立使用 |
| 产能/良率/认证 | 公司披露、项目文件、行业数据库、一手调研 | 客户/供应商披露 | 推测图谱不得当事实 |

## 7. 取数方式与留痕要求

| 通道 | 必须留痕 |
|---|---|
| 数据库终端 | 数据库、字段名、查询条件、导出时间、数据截止时点、字段解释 |
| API / MCP | connector 或 endpoint、参数、接口版本、响应时间、原始响应或 hash、字段血缘 |
| Web / 官网 | URL、标题、发布者、发布时间、获取时间、页码或段落定位 |
| 文件上传 | 文件名、来源、版本、上传时间、页码/表格/字段定位 |
| 人工调研 | 样本说明、记录时间、业务时间、问题口径、可复核程度、样本偏差 |

取数通道不提高来源权威性。MCP 只能增强查询可复现性和留痕完整性。

## 8. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 业务时间 | 动态变量必须有业务时间或统计期 | 降为背景或阻断方向性推理 |
| 指标定义 | 必须清楚指标含义、单位、口径 | 不得用于跨期或跨对象比较 |
| 对象锚定 | 必须绑定对象、产品、地区或环节 | 不得映射到状态变量 |
| 同口径可比 | 跨期、跨公司、跨来源比较必须口径一致 | 只能描述局部事实 |
| 直接性 | 首选直接指标；代理指标必须单独标识 | 调用 A09 并降级 |
| 独立性 | 交叉验证不得来自同一原始来源链 | 不计入独立验证 |
| 反向检查 | 必须检查反向指标或冲突来源 | 不得 high_quality_pass |

## 9. 降级规则

| 问题 | 03 处理 | 04 最多能形成的结论 |
|---|---|---|
| 无业务时间 | 标为时间不可用 | background_only |
| 只有单点数据 | 可描述当前状态 | conditional_only |
| 指标口径不明 | 不进入有效证据计数 | insufficient |
| 仅有代理指标 | 调用 A09，说明代理逻辑 | conditional_only |
| 交叉验证同源 | 不计独立验证 | directional_only_or_lower |
| 与反向指标冲突 | 标记 contested | contested |
| 来源权限不清 | 阻断 | none |

## 10. 停止规则

单项状态变量测量可以停止补充的条件：

1. 直接指标或合规代理指标已取得；
2. 业务时间、统计期、单位、对象和口径已明确；
3. 已完成至少一次独立交叉验证或说明不可得原因；
4. 已检查反向指标和冲突来源；
5. 04 最多能形成的结论已明确；
6. 继续补充不会改变变量状态或判断单元准入状态。

## 11. 输出到 03 快照

A02 至少更新：

| 文件 | 关键字段 |
|---|---|
| `evidence_requirements.csv` | `evidence_role=primary_support` 或 `cross_validation`，`required_evidence_category=state_measurement` |
| `reasoning_inputs.csv` | 状态观测、变量、对象、业务时间、数值和单位 |
| `evidence_records.csv` | 原始字段、主张、事实候选、来源、置信度 |
| `state_variable_coverage.csv` | 变量 × 锚点实例覆盖状态 |
| `evidence_readiness_assessments.csv` | 口径、时间、来源、独立性、反证检查结果和 04 最多能形成的结论 |
| `proxy_indicators.csv` | 若使用代理指标，必须登记 |

## 12. 示例

问题：判断服务器 DRAM 合约价是否处于上行状态。

最低证据：

```text
同口径合约价数据
+ 统计期和产品规格
+ 历史对比点
+ 来源字段或报告页码
+ 现货价、公司 ASP 或渠道报价交叉验证
+ 价格回落或需求弱化反证检查
```

## 13. 专项执行协议：Measurement Contract

每个状态变量在取数前必须建立测量合同：

| 合同项 | 必须固定的内容 |
|---|---|
| 构念 | 真正想观察的状态是什么，例如“有效供给”而非笼统“产能” |
| 指标 | 直接指标、计算指标或代理指标 |
| 对象与粒度 | 公司/产品/地区/环节，日/周/月/季 |
| 值域与单位 | 数值、比例、指数、状态标签；币种和换算基准 |
| 时间语义 | 期末、期间平均、累计、当期、发布日还是业务日 |
| 聚合规则 | 加总、加权平均、中位数、分位数或不允许聚合 |
| 转换规则 | 同比、环比、季调、价格换算、拆分或标准化公式 |
| 修订策略 | 使用首次值、最新修订值还是同时保留 vintage |
| 缺失与异常 | 缺失、零值、停报、异常值如何区分和处理 |
| 可比条件 | 产品规格、会计准则、样本、地域和方法变更条件 |

没有测量合同的数值只能作为候选材料，不能直接生成 `Observation`。

## 14. 数据处理与复算规则

1. 原始值和转换值同时保存，转换值必须有公式和输入 ID；
2. 不同币种统一时记录汇率类型、日期和是否平均汇率；
3. 累计值转单季值时保留复算公式，检查期初口径与重述；
4. 指数基期变化、公司分部重述、产品分类变化必须形成 series break；
5. 季调数据和未季调数据不得混接；
6. “未披露”“不可得”“不适用”和真实零值分别编码；
7. 异常值不得静默删除，应保留原值、异常理由和处理后值；
8. 数据修订时保留 vintage，避免用事后修订值评价当时可得判断。

## 15. 三角测量与最小样本

直接指标并不天然充分。按变量性质选择三角验证：

| 目标变量 | 主测量 | 互补测量 | 不能算独立验证的情况 |
|---|---|---|---|
| 需求 | 终端销量/实际消耗 | 订单、出货、客户资本开支 | 多家媒体转述同一公司指引 |
| 供给 | 有效产出/出货 | 产能、稼动、良率、交期 | 名义产能与项目公告相互验证 |
| 库存 | 同层库存量/天数 | 价格、订单取消、渠道反馈 | 不同研报引用同一数据库 |
| 价格 | 可成交同规格价格 | ASP、合约价、报价、公司披露 | 同一供应商的不同展示页面 |
| 公司经营 | 法定披露/内部实际值 | 客户、供应商、行业数据 | 公司年报与同公司 IR 材料 |

最低样本由问题决定，不机械规定“两个来源”。单一法定事实可由一个主源确认；方向性行业状态通常需要至少一个直接测量和一个真正独立或机制互补的验证。

## 16. 典型混杂因素与失败模式

| 风险 | 例子 | 必须处理 |
|---|---|---|
| 构念错配 | 用名义产能测有效供给 | 加入利用率、良率或交付约束 |
| 层级错配 | 用渠道库存代表原厂库存 | 分层建变量，不做无依据合并 |
| 分母漂移 | 市占率分母或样本公司改变 | 固定分母或重算可比序列 |
| 选择性披露 | 只披露高增长产品 | 补充总量、其他分项或范围限制 |
| 截止错配 | 财报季度与月度行业数据错位 | 对齐业务窗口并说明滞后 |
| 价格口径错配 | 报价、现货、合约、ASP 混用 | 分别建观测并说明传导关系 |
| 幸存者偏差 | 只观察仍披露的公司 | 记录退出、停报和样本变化 |

## 17. 高质量通过条件

`Q3_directional_ready` 不只要求“有数据”，还要求测量合同完整、转换可复算、关键序列无未解释断点、反向指标已检查。需要进入 `Q4_report_grade` 时，还必须具备可展示的原始/归一数据、来源注释、图表口径和修订说明。
