# A00_取证规则总览

> 研究员使用顺序：先从下表找到“正在回答的问题”，只打开一条主规则；再按需要补一条反证规则或代理规则。不要把九条规则全部跑一遍。

| 如果你在问 | 主规则 | 研究员最终要拿到的东西 |
|---|---|---|
| 事情到底发生没有 | A01 | 原文、主体、范围、生效时间与修订状态 |
| 当前值或状态是多少 | A02 | 同口径直接观测、基准与误差边界 |
| 是否形成趋势/进入新阶段 | A03 | 多点序列、切换条件与反向信号 |
| A 是否真的影响 B | A04 | 逐段机制、时滞、暴露、结果与阻断 |
| 谁更受益或受损 | A05 | 可比口径下的暴露、弹性和兑现约束 |
| 对收入利润现金影响多大 | A06 | 可复算的量价成本财务桥 |
| 市场是否已经反映 | A07 | 事前预期、修订、相对价格和估值输入 |
| 主判断可能错在哪里 | A08 | 最强竞争解释及其区分证据 |
| 主数据拿不到怎么办 | A09 | 代理逻辑、校准、失效条件和降级上限 |

## 1. 定位

A 类文件定义稳定复用的取证动作。它说明某类证据怎样取得、留痕、验收和降级；某个判断需要哪些证据组合，由 [Evidence Recipe](../C_Evidence_Recipe/00_证据配方使用说明.md) 负责。

## 2. 标准模板

每个 A 类规则应使用以下结构：

```text
1. 定位
2. 适用场景
3. 不适用场景
4. 入口输入
5. 必要证据组合
6. 来源优先级
7. 取数方式与留痕要求
8. 质量门槛
9. 代理指标规则
10. 反证要求
11. 降级规则
12. 停止规则
13. 输出到 03 快照的字段
14. 专项执行协议：测量、比较、验证或计算的可复现步骤
15. 典型混杂因素与失败模式
16. 最低通过、高质量通过和停止补证的明确区别
```

所有规则共同遵循：先固定口径，再执行；先保留原始材料，再抽取主张；来源可靠性与证据适用性分开；反证使用与主证据对称的口径；任何计算保留公式、输入、转换和版本。
