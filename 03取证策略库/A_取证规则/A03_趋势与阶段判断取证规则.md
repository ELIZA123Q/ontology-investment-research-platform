# A03_趋势与阶段判断取证规则

## 1. 定位

趋势与阶段判断取证规则用于判断状态变量是否形成持续变化、斜率变化、拐点、周期位置或阶段切换。

它回答：

```text
变量不是只在某个点发生变化，而是在一段时间内形成什么趋势；
该趋势是否足以支撑阶段判断；
阶段判断需要哪些证据篮子；
缺少哪些证据时必须降级。
```

A03 依赖 A02 的状态变量测量。没有合格的变量测量，不得直接进入趋势或阶段判断。

## 2. 适用场景

| judgment_type | 示例 |
|---|---|
| `trend_or_phase` | 价格是否从下行转为上行 |
| `cycle_phase` | 行业是否处于补库、上行、高位、下行或去库阶段 |
| `inflection_point` | 库存、订单、价格是否出现拐点 |
| `slope_change` | 涨价斜率是否边际放缓 |
| `normalization_phase` | 供需是否从紧缺走向正常化 |
| `stage_switch` | 驱动因素是否从需求转向供给或从价格转向量 |

## 3. 不适用场景

| 问题 | 应转向 |
|---|---|
| 某个变量当前值是多少 | A02 状态变量测量 |
| 一个政策或事件是否发生 | A01 事实确认 |
| 趋势如何传导到公司业绩 | A06 财务影响测算 |
| 市场是否已经反映该阶段 | A07 市场预期与定价 |
| 趋势是否有其他解释 | A08 反证与竞争解释 |

## 4. 入口输入

| 字段 | 说明 |
|---|---|
| `judgment_unit_id` | 绑定的 02 判断单元 |
| `phase_question` | 要判断的趋势或阶段问题 |
| `state_variable_ids` | 参与阶段判断的变量 |
| `time_window` | 判断窗口和对比基准 |
| `required_baskets` | 必需证据篮子 |
| `phase_definition` | 阶段定义或状态标签 |
| `counter_requirement` | 反证和竞争解释要求 |

## 5. 必需证据篮子

| 证据篮子 | 目的 | 最低要求 |
|---|---|---|
| `current_state` 当前状态 | 判断当前变量位置 | 至少来自 A02 合格测量 |
| `historical_comparison` 历史对比 | 判断方向和阶段 | 至少有前期、历史区间或周期对比基准 |
| `persistence` 持续性 | 排除一次性波动 | 至少覆盖多个时间点或多个独立观测 |
| `slope_or_momentum` 斜率/动量 | 判断边际变化 | 说明变化速度、幅度、连续性或边际放缓 |
| `multi_variable_confirmation` 多变量确认 | 防止单指标阶段误判 | 至少一个相邻变量验证，如价格+库存、需求+订单 |
| `counter_phase_check` 反阶段证据 | 检查阶段是否被反证 | 检查相反趋势、口径冲突或阶段竞争解释 |

周期判断类任务还应按问题加入：

```text
价格 + 需求 + 供给 + 库存/订单 + 反证
```

## 6. 来源优先级

A03 本身不新增来源，主要继承 A02 的合格状态变量来源，并补充历史序列、横向对比和反证来源。

| 证据类型 | 首选来源 | 辅助来源 |
|---|---|---|
| 时间序列 | 授权数据库、行业数据库、公司连续披露 | 新闻、研报只作解释线索 |
| 周期阶段 | 行业数据库、协会统计、公司披露、价格/库存/订单数据 | 卖方研报作市场理解和预期材料 |
| 横向阶段对比 | 同口径公司披露、数据库字段、行业统计 | 可比公司研报需回源 |
| 反证 | 反向变量、一手披露、冲突数据、竞争解释材料 | 观点材料可作为反证线索 |

## 7. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 非单点 | 不得用单个时间点判断趋势 | 只能写当前状态 |
| 同口径序列 | 时间序列必须同指标、同口径、同范围 | 不得判断斜率或阶段 |
| 持续性 | 趋势至少有连续或多点证据 | 降为观察 |
| 多变量验证 | 周期阶段不得只靠一个变量 | 降为条件判断 |
| 阶段定义 | 必须说明阶段标签的判断依据 | 不得使用“上行/见顶”等强标签 |
| 反证检查 | 必须检查相反变量和竞争解释 | 不得 high_quality_pass |

## 8. 降级规则

| 问题 | 03 处理 | 04 使用上限 |
|---|---|---|
| 只有当前值 | 转 A02，停止阶段判断 | background_or_state_only |
| 有价格趋势但无需求/供给/库存 | 限定为价格观察 | conditional_only |
| 多变量方向不一致 | 标记 contested | contested |
| 历史序列断裂 | 说明断点，限制比较 | conditional_only |
| 阶段定义来自模型推测 | 不得正式使用阶段标签 | insufficient |
| 反证未检查 | 不得 high_quality_pass | directional_only_or_lower |

## 9. 停止规则

趋势或阶段取证可以停止的条件：

1. 参与阶段判断的核心变量已通过 A02；
2. 当前状态、历史对比、持续性和斜率证据已满足最低门槛；
3. 至少有一个相邻变量或独立来源确认；
4. 已检查相反趋势和竞争解释；
5. 阶段标签的边界和 04 使用上限已明确。

## 10. 输出到 03 快照

| 文件 | 关键字段 |
|---|---|
| `evidence_requirements.csv` | `required_evidence_category=trend_or_phase`，并引用 A03 配方标签 |
| `evidence_baskets.csv` | 当前、历史、持续性、斜率、反证篮子状态 |
| `state_variable_coverage.csv` | 多变量覆盖状态 |
| `evidence_readiness_assessments.csv` | 阶段判断是否允许进入 04 |
| `gaps_and_risks.csv` | 阶段反证、口径断裂、缺失变量 |
| `display_data_candidates.csv` | 可展示时间序列或阶段对比素材 |

## 11. 示例

问题：存储芯片是否处于结构性景气高位延续。

最低证据：

```text
价格序列
+ 需求分层证据
+ 供给约束证据
+ 库存或订单证据
+ 历史区间对比
+ 涨价斜率或边际变化
+ 价格回落、库存回升、供给释放反证
```
