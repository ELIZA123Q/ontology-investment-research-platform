# A09_代理指标使用规则

## 1. 定位

代理指标使用规则用于处理直接指标不可得、滞后、权限受限或口径不完整时，是否可以使用相邻变量、替代数据或间接观测来支持有限判断。

它回答：

```text
代理指标代理的是什么原始变量；
代理逻辑是否成立；
在哪些条件下有效或失效；
代理指标能支持什么强度的判断；
是否必须降级。
```

A09 不能单独形成判断，必须绑定 A02—A08 中的某个取证规则。

## 2. 适用场景

| 场景 | 示例 |
|---|---|
| 主数据不可得 | HBM 实际成交价不可得，用公司 ASP、合约价或供应协议线索做代理 |
| 主数据滞后 | 官方库存季度披露滞后，用渠道交期、价格和订单变化观察边际 |
| 权限受限 | 无 Wind/Bloomberg 数据，用公开披露和行业报告替代 |
| 变量不可直接观测 | 客户真实需求不可得，用订单、出货、资本开支、交期代理 |
| 样本不足 | 单家公司数据不可代表行业，用同业或上下游数据交叉 |

## 3. 不适用场景

| 问题 | 处理 |
|---|---|
| 有直接指标但未查找 | 先查直接指标，不得直接用代理 |
| 代理逻辑无法解释 | 不得进入证据包 |
| 代理指标与目标变量方向不稳定 | 只能作为线索 |
| 代理完全来自模型推测 | 不得作为正式证据 |
| 核心判断完全依赖单一代理 | 04 不得方向性判断 |

## 4. 入口输入

| 字段 | 说明 |
|---|---|
| `target_variable` | 被代理的原始变量 |
| `proxy_indicator` | 拟使用的代理指标 |
| `proxy_reason` | 使用代理的原因 |
| `proxy_logic` | 代理逻辑 |
| `valid_conditions` | 代理有效条件 |
| `invalid_conditions` | 代理失效条件 |
| `cross_validation_plan` | 交叉验证计划 |
| `confidence_discount` | 置信度折扣 |

## 5. 必需证据篮子

| 证据篮子 | 目的 | 最低要求 |
|---|---|---|
| `proxy_need` 使用必要性 | 说明为什么需要代理 | 主数据不可得、滞后、权限受限或成本过高 |
| `proxy_logic` 代理逻辑 | 说明为什么能代理 | 必须有业务机制、历史关系或统计关系说明 |
| `validity_condition` 有效条件 | 限定适用范围 | 产品、时间、地区、对象、阶段和市场结构条件 |
| `invalidity_condition` 失效条件 | 防止越权 | 说明什么情况下代理不成立 |
| `cross_validation` 交叉验证 | 防止单一代理误导 | 至少一个独立相邻变量或来源验证 |
| `usage_limit` 使用上限 | 控制 04 强度 | 明确最高只能支持背景、条件或倾向判断 |

## 6. 来源优先级

代理指标的来源优先级取决于其绑定的主规则，但必须满足：

1. 代理指标来源自身可追溯；
2. 代理指标口径清楚；
3. 代理指标与目标变量的对应关系可解释；
4. 若代理来自二手观点，应回到原始数据或降级为线索；
5. 若代理来自 AI 摘要，必须回源校验。

## 7. 代理指标类型

| 类型 | 示例 | 常见限制 |
|---|---|---|
| 相邻变量代理 | 用交期代理供给紧张 | 可能受需求、物流、合同影响 |
| 上下游代理 | 用客户资本开支代理订单需求 | 传导存在滞后和预算偏差 |
| 价格代理 | 用现货价代理合约价 | 规格、市场、交易量可能不同 |
| 行为代理 | 用扩产公告代理供给释放 | 公告不等于实际投产 |
| 市场代理 | 用股价反应代理预期 | 股价受多因素影响 |
| 文本代理 | 用管理层表述代理经营状态 | 选择性披露和措辞偏差 |

## 8. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 必要性 | 必须说明为什么不用直接指标 | 退回直接取数 |
| 逻辑性 | 必须有业务或统计逻辑 | 不得使用 |
| 边界性 | 必须有有效/失效条件 | 降级 |
| 可验证性 | 至少有一个交叉验证 | 只能线索 |
| 标识清楚 | 不得把代理写成原始变量 | 退回修正 |
| 折扣明确 | 必须影响证据等级和 04 上限 | 不得 high_quality_pass |

## 9. 降级规则

| 问题 | 03 处理 | 04 使用上限 |
|---|---|---|
| 代理逻辑清楚且有交叉验证 | 可作为受限推理输入 | conditional_only 或 directional_only |
| 代理逻辑清楚但无交叉验证 | 只作线索或背景 | background_only |
| 代理边界不清 | 不进入正式证据计数 | insufficient |
| 核心判断完全依赖代理 | 标记 proxy_dependency_high | conditional_only |
| 代理与直接证据冲突 | 优先直接证据并记录冲突 | contested |
| 代理来自弱来源 | 降为线索 | background_only |

## 10. 停止规则

代理指标使用可以停止的条件：

1. 主数据不可得或不适用的原因已记录；
2. 代理逻辑、有效条件和失效条件已说明；
3. 代理来源可追溯；
4. 已完成至少一个交叉验证或说明无法验证；
5. 已明确置信度折扣和 04 使用上限。

## 11. 输出到 03 快照

| 文件 | 关键字段 |
|---|---|
| `proxy_indicators.csv` | 目标变量、代理指标、代理逻辑、有效/失效条件、折扣 |
| `evidence_readiness_assessments.csv` | 代理依赖程度、验证状态、降级结果 |
| `evidence_baskets.csv` | proxy basket 状态 |
| `gaps_and_risks.csv` | 代理限制和直接数据缺口 |
| `judgment_unit_readiness.csv` | 代理对 04 上限的影响 |

## 12. 示例

目标变量：HBM 实际供给紧张程度。

代理指标：

```text
原厂 HBM capex / 产能扩张指引；
客户长单或供应协议；
先进封装产能约束；
DDR5 交期和服务器 DRAM 合约价；
HBM 相关公司订单和收入指引。
```

使用限制：

```text
这些指标不能直接替代 HBM 实际成交量或实际成交价；
只能支持“供给紧张存在较强线索”或“结构性偏紧有条件成立”；
若缺少独立交叉验证，不能支撑强方向判断。
```
