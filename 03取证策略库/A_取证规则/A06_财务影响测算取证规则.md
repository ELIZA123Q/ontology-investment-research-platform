# A06_财务影响测算取证规则

## 1. 定位

财务影响测算取证规则用于验证某个变量、事件或机制如何传导到公司收入、利润、毛利率、现金流或资产负债表。

它回答：

```text
影响会落到哪个财务科目；
量、价、成本、费用和产能如何拆分；
哪些参数来自证据，哪些只是情景假设；
当前证据能支持方向判断还是测算。
```

A06 只负责准备测算依据和限制，不负责形成投资结论。

## 2. 适用场景

| judgment_type | 示例 |
|---|---|
| `earnings_impact` | 价格上涨对收入和利润影响 |
| `margin_sensitivity` | 成本下降对毛利率影响 |
| `volume_price_effect` | 销量和价格变化分别贡献多少 |
| `capacity_utilization_effect` | 产能利用率变化对利润弹性 |
| `cashflow_impact` | 资本开支、库存或回款对现金流影响 |
| `balance_sheet_effect` | 利率、汇率、减值、存货对资产负债表影响 |

## 3. 不适用场景

| 问题 | 应转向 |
|---|---|
| 某项财务数据是否披露 | A01 / A02 |
| 行业趋势是否成立 | A03 |
| 机制是否能传导到公司 | A04 |
| 谁更受益 | A05 |
| 估值是否重估 | A07 |

## 4. 入口输入

| 字段 | 说明 |
|---|---|
| `target_company_or_segment` | 公司或业务单元 |
| `financial_metric` | 收入、毛利、净利润、现金流、资产负债表项目 |
| `driver_variable` | 价格、销量、成本、产能、费用、汇率等驱动变量 |
| `calculation_purpose` | 方向判断、弹性估算、情景测算、研报图表 |
| `required_grain` | 年度、季度、产品、业务线、地区、客户 |
| `assumption_boundary` | 允许使用的假设范围 |

## 5. 必需证据篮子

| 证据篮子 | 目的 | 最低要求 |
|---|---|---|
| `revenue_split` 收入拆分 | 确认影响落点 | 产品、业务、地区或客户收入占比 |
| `volume_price` 量价证据 | 拆分收入驱动 | 至少说明销量、出货、价格或 ASP 中哪些可得 |
| `cost_structure` 成本结构 | 判断利润传导 | 原材料、制造费用、折旧、外包或其他成本口径 |
| `margin_baseline` 毛利率基准 | 测算利润弹性 | 历史毛利率、产品毛利或业务毛利口径 |
| `capacity_or_delivery` 兑现能力 | 判断能否放量 | 产能、利用率、良率、交付、认证或供应链约束 |
| `sensitivity_parameter` 敏感性参数 | 形成测算或情景 | 参数来源必须区分事实、估算、假设、模型 |
| `counter_financial_check` 财务反证 | 识别抵消项 | 成本上行、价格传导失败、费用增加、销量不达预期 |

## 6. 来源优先级

| 证据类型 | 首选来源 | 辅助来源 |
|---|---|---|
| 财务报表 | 年报、季报、交易所披露、授权数据库追溯字段 | 公司 IR 汇总 |
| 业务拆分 | 年报、招股书、投资者日、管理层披露 | 卖方拆分需标注假设 |
| 量价 | 公司披露、行业数据库、内部经营数据、客户/渠道数据 | 研报估算只能作假设 |
| 成本结构 | 公司披露、行业成本数据、内部成本系统 | 专家观点需降级 |
| 敏感性参数 | 公司披露、历史回归、可复算模型 | 纯模型假设必须标注 |

## 7. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 收入拆分 | 没有拆分不得精细测算 | 只能方向判断 |
| 量价拆分 | 不得把收入增长直接归因于价格或销量 | 降级 |
| 成本口径 | 利润测算必须有成本或毛利率口径 | 不得推利润弹性 |
| 产能兑现 | 放量测算必须检查产能和交付 | 降级 |
| 参数来源 | 事实、估算、假设必须区分 | 假设依赖过高则降级 |
| 期间匹配 | 财务期、业务期、数据期必须对齐 | 不得直接计算 |

## 8. 降级规则

| 问题 | 03 处理 | 04 使用上限 |
|---|---|---|
| 只有行业变量，无公司暴露 | 不得公司化测算 | background_only |
| 有收入拆分，无量价 | 只能收入方向判断 | conditional_only |
| 有量价，无成本毛利 | 不得利润弹性 | directional_revenue_only |
| 参数大多为假设 | 标记 scenario_only | conditional_only |
| 财务口径不匹配 | 不得复算 | insufficient |
| 财务反证未查 | 不得 high_quality_pass | directional_only_or_lower |

## 9. 停止规则

财务测算取证可以停止的条件：

1. 财务影响落点明确；
2. 收入、量价、成本、毛利率或现金流至少满足对应最低篮子；
3. 参数来源和假设边界已分开；
4. 反证和抵消项已检查；
5. 03 已说明可支持方向判断、情景测算还是精细测算。

## 10. 输出到 03 快照

| 文件 | 关键字段 |
|---|---|
| `reasoning_inputs.csv` | 财务变量、驱动变量、参数 |
| `evidence_records.csv` | 财务字段、来源、业务时间和口径 |
| `table_material_package.csv` | 敏感性表、拆分表、假设表候选 |
| `display_data_candidates.csv` | 可展示财务数据和图表候选 |
| `evidence_readiness_assessments.csv` | 参数质量、口径匹配、假设依赖和 04 使用上限 |
| `evidence_readiness_assessments.csv` | 财务影响判断准入 |

## 11. 示例

问题：DRAM 价格上涨对某公司利润弹性有多大。

最低证据：

```text
该公司 DRAM 或相关业务收入占比
+ 产品 ASP 或价格传导口径
+ 销量/产能/利用率约束
+ 成本和毛利率基准
+ 敏感性参数来源
+ 反证：成本上升、产能不足、客户降价
```
