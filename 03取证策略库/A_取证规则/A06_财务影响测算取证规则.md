# A06_财务影响测算取证规则

## 研究员先搭最短财务桥

```text
业务驱动 → 可销售量/交付 → 实现价与产品结构 → 收入确认
→ 变动成本/固定成本/利用率 → 利润率 → 营运资本/资本开支 → 现金
```

每个参数标注“事实、公司指引、外部预测、研究员假设”及来源日期。先做方向和敏感性，再决定是否值得做点估计。行业价格涨幅不能直接套到公司利润；必须检查产品暴露、合同重定价、良率、利用率、成本抵消、收入确认与回款。

## 1. 定位

财务影响测算取证规则用于验证某个变量、事件或机制如何传导到公司收入、利润、毛利率、现金流或资产负债表。

它回答：

```text
影响会落到哪个财务科目；
量、价、成本、费用和产能如何拆分；
哪些参数来自证据，哪些只是情景假设；
当前证据能支持方向判断还是测算。
```

A06 只负责准备测算依据和限制，不负责形成投资结论。

## 2. 适用场景

| judgment_type | 示例 |
|---|---|
| `earnings_impact` | 价格上涨对收入和利润影响 |
| `margin_sensitivity` | 成本下降对毛利率影响 |
| `volume_price_effect` | 销量和价格变化分别贡献多少 |
| `capacity_utilization_effect` | 产能利用率变化对利润弹性 |
| `cashflow_impact` | 资本开支、库存或回款对现金流影响 |
| `balance_sheet_effect` | 利率、汇率、减值、存货对资产负债表影响 |

## 3. 不适用场景

| 问题 | 应转向 |
|---|---|
| 某项财务数据是否披露 | A01 / A02 |
| 行业趋势是否成立 | A03 |
| 机制是否能传导到公司 | A04 |
| 谁更受益 | A05 |
| 估值是否重估 | A07 |

## 4. 入口输入

| 字段 | 说明 |
|---|---|
| `target_company_or_segment` | 公司或业务单元 |
| `financial_metric` | 收入、毛利、净利润、现金流、资产负债表项目 |
| `driver_variable` | 价格、销量、成本、产能、费用、汇率等驱动变量 |
| `calculation_purpose` | 方向判断、弹性估算、情景测算、研报图表 |
| `required_grain` | 年度、季度、产品、业务线、地区、客户 |
| `assumption_boundary` | 允许使用的假设范围 |

## 5. 必需证据组合

| 必要证据组合 | 目的 | 最低要求 |
|---|---|---|
| `FIN_EXPOSURE` 公司或分部暴露 | 确认影响落点 | 产品、业务、地区或客户收入占比 |
| `FIN_VOLUME_PRICE_MIX` 量价与产品结构 | 拆分收入驱动 | 说明销量、出货、实现价格和产品结构中哪些可得 |
| `FIN_COST_MARGIN` 成本与利润率基准 | 判断利润传导 | 原材料、制造费用、折旧、外包和历史利润率口径 |
| `FIN_CAPACITY_RECOGNITION` 产能、交付与确认 | 判断能否兑现 | 产能、利用率、良率、交付、验收、收入确认和供应链约束 |
| `FIN_PARAMETER_PROVENANCE` 参数来源 | 形成可审计测算 | 参数必须区分事实、公司指引、外部估算、模型和假设 |
| `FIN_COUNTER` 财务抵消与反证 | 识别抵消项 | 成本上行、价格传导失败、费用增加、销量不足、确认和回款风险 |

## 6. 来源优先级

| 证据类型 | 首选来源 | 辅助来源 |
|---|---|---|
| 财务报表 | 年报、季报、交易所披露、授权数据库追溯字段 | 公司 IR 汇总 |
| 业务拆分 | 年报、招股书、投资者日、管理层披露 | 卖方拆分需标注假设 |
| 量价 | 公司披露、行业数据库、内部经营数据、客户/渠道数据 | 研报估算只能作假设 |
| 成本结构 | 公司披露、行业成本数据、内部成本系统 | 专家观点需降级 |
| 敏感性参数 | 公司披露、历史回归、可复算模型 | 纯模型假设必须标注 |

## 7. 专项质量门槛

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 收入拆分 | 没有拆分不得精细测算 | 只能方向判断 |
| 量价拆分 | 不得把收入增长直接归因于价格或销量 | 降级 |
| 成本口径 | 利润测算必须有成本或毛利率口径 | 不得推利润弹性 |
| 产能兑现 | 放量测算必须检查产能和交付 | 降级 |
| 参数来源 | 事实、估算、假设必须区分 | 假设依赖过高则降级 |
| 期间匹配 | 财务期、业务期、数据期必须对齐 | 不得直接计算 |

## 8. 降级规则

| 问题 | 03 处理 | 04 最多能形成的结论 |
|---|---|---|
| 只有行业变量，无公司暴露 | 不得公司化测算 | background_only |
| 有收入拆分，无量价 | 只能收入方向判断 | conditional_only |
| 有量价，无成本毛利 | 不得利润弹性 | directional_revenue_only |
| 参数大多为假设 | 标记 scenario_only | conditional_only |
| 财务口径不匹配 | 不得复算 | insufficient |
| 财务反证未查 | 不得 high_quality_pass | directional_only_or_lower |

## 9. 停止规则

财务测算取证可以停止的条件：

1. 财务影响落点明确；
2. 收入、量价、成本、毛利率或现金流至少满足对应最低篮子；
3. 参数来源和假设边界已分开；
4. 反证和抵消项已检查；
5. 03 已说明可支持方向判断、情景测算还是精细测算。

## 11. 示例

问题：DRAM 价格上涨对某公司利润弹性有多大。

最低证据：

```text
该公司 DRAM 或相关业务收入占比
+ 产品 ASP 或价格传导口径
+ 销量/产能/利用率约束
+ 成本和毛利率基准
+ 敏感性参数来源
+ 反证：成本上升、产能不足、客户降价
```

## 12. 专项执行协议：财务桥

财务影响必须从业务驱动逐层桥接，不直接对净利润应用一个百分比：

```text
收入 = Σ(销量 × 实现价格 × 汇率) + 其他收入
毛利 = 收入 - 变动成本 - 固定制造成本 - 折旧/摊销
营业利润 = 毛利 - 期间费用 ± 其他经营项
税前利润 = 营业利润 ± 财务费用 ± 非经营项
净利润 = 税前利润 - 所得税 ± 少数股东/一次性项目
经营现金流 = 净利润 + 非现金项 - 营运资本增加
自由现金流 = 经营现金流 - 资本开支
```

按问题裁剪，不要求每次建完整三表；但从行业变量到目标财务科目之间的关键桥不能省略。

## 13. 参数证据等级

每个参数必须标记：

| 参数性质 | 例子 | 默认可支持结论上限 |
|---|---|---|
| reported_actual | 已披露收入、成本、产能 | 可作基准，仍检查口径 |
| management_guidance | 公司指引、目标 | 情景输入，不是实际值 |
| externally_estimated | 行业数据、卖方拆分 | 受限参数，需来源和方法 |
| model_derived | 由历史数据复算或回归 | 保留公式、样本和误差 |
| analyst_assumption | 渗透率、价格传导率 | 仅用于情景，不得伪装成证据 |

核心结果若由 analyst_assumption 主导，最高为 `scenario_only / conditional_only`。

## 14. 基准校准与复算

1. 模型基准期必须与最新已披露财务对账；
2. 分部收入之和与合并口径差异需解释抵消项；
3. 量价拆分必须与收入变化大体闭合，残差单列；
4. 毛利变化需区分价格、产品结构、原料、利用率、折旧和汇率；
5. 资本开支与产能释放之间保留建设、安装、验证、良率爬坡时滞；
6. 利润与现金分开，检查库存、应收、预付款和合同负债；
7. 一次性项目、会计重分类和并表变化不得作为持续经营弹性。

## 15. 情景与敏感性

- 基准、上行、下行情景只改变明确列出的关键参数；
- 每个情景说明触发条件，不用“乐观/悲观”空标签；
- 优先做单变量或少数关键变量敏感性，避免几十个假设不可审计；
- 价格与销量、价格与需求、产能与固定成本可能相关，不应默认独立变化；
- 输出区间而非伪精确单点，并说明结果对哪个参数最敏感；
- 若关键参数稍变就导致方向翻转，应标记模型脆弱，不输出强弹性结论。

## 16. 典型失败模式

| 失败模式 | 处理 |
|---|---|
| 行业涨价直接乘公司总收入 | 先确认产品暴露、实现价和销量 |
| 把名义产能当销量 | 加入利用率、良率、认证和需求约束 |
| 毛利率提升全部归因涨价 | 分解成本、结构、折旧和汇率 |
| 卖方模型参数无原始依据 | 标为 externally_estimated/assumption 并降级 |
| 忽略确认时点 | 区分订单、交付、验收、收入和回款 |
| 用净利润弹性代表现金弹性 | 单独检查营运资本和 capex |
| 结果无法与历史财务闭合 | 不进入正式测算，先修复模型 |
