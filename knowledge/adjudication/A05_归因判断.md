# A05 归因判断

## 方法定位

> **一句话哲学：归因不是寻找原因，而是分配解释权。**

A05 回答：一个已经发生且被明确测量的变化，主要由什么造成；多个原因分别解释方向、幅度、持续性和对象分化中的哪些部分。

归因不是原因清单，也不是证明某个机制存在。它要求在候选解释之间进行相对比较，并明确当前能否写“主要由”、只能写共同作用或必须保留不可区分。

使用本方法前，除 A00 共用材料外，被解释变化须先由 A01/A02 确认；02 必须事先定好候选原因、预期时序、中介、暴露对象、共同驱动、反事实和关键区分信号。

## 判断模型与停止点

```text
固定被解释变化
→ 拆分方向、幅度、持续性和分化
→ 建立候选解释集合
→ 对称比较区分信号
→ 检查共同驱动、重叠和剩余现象
→ 分配主因、次因与适用范围
```

解释权通常不是精确百分比，而是：谁决定方向、谁放大幅度、谁维持持续性、谁解释结构分化。

A05 停在可解释的主因结构。现有证据不支持精确贡献率时，不因业务需要强行量化。

## 方法特有判断原则

本方法重点防范：[CE01](A00-附录4_通用认知错误与误用索引.md#ce01-相关替代因果)、[CE06](A00-附录4_通用认知错误与误用索引.md#ce06-同源材料替代独立验证)、[CE07](A00-附录4_通用认知错误与误用索引.md#ce07-遗漏共同驱动和最强竞争解释)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)。

### 1. 先固定要解释的变化

归因命题必须明确对象、变量、方向、幅度、业务时间、比较基线和需要解释的维度。变化本身尚未确认时，先返回 A01/A02。

“解释订单增长”过宽；“解释第二季度中国渠道订单环比回升，区分补库、终端复苏和供给预期”才可执行。

### 2. 候选集合满足条件后停止扩展

候选集合至少覆盖：

1. 目标原因；
2. 能解释同一核心现象的最强替代解释；
3. 可能同时推动多个变量的共同驱动；
4. 数据、样本或口径变化因素。

四类均已覆盖，且没有新的、最能分清对错的反向事实时，可以停止扩展。明显的一次性因素或结构分项变化若能解释核心现象，应归入上述最强替代或数据/口径因素，而不是无限增加原因清单。

### 3. 使用同一套维度对称比较

候选解释统一按附录2比较覆盖、时序、特有中介、对象分化、反事实、假设负担和证据直接性。材料更多、媒体提及更多不等于解释力更强。

高价值区分信号包括：高暴露对象变化更明显、低暴露对象没有同等变化、机制启动前后存在断点、特有中介按顺序出现。

### 4. “主要由”必须同时满足两条硬规则

只有同时满足以下条件，才允许写“主要由”：

1. 目标解释至少在一项关键区分信号上明显优于竞争解释；
2. 目标解释没有被更强的共同驱动覆盖。

若多个原因各解释独立部分，应写主因＋次因、共同作用或分范围解释；缺少关键区分证据时保留不可区分。

### 5. 防止重复归因

共享同一上层驱动或同一中介的原因不能当作两个独立主因。“AI 需求增长”和“客户增加 AI 服务器采购”可能是同一因果链的不同层级，应合并或明确上下游关系。

### 6. 不同窗口可以有不同解释权

短期触发、中期维持和长期结构原因必须分开。例如短期价格上涨由补库触发，中期由供给约束维持，长期利润仍由产品结构和成本决定。

本方法特有误判：把最显眼的新闻事件直接选为唯一原因，或用“多因素共同作用”逃避相对比较。

## 判断流程

1. 引用 A01/A02，固定被解释变化、幅度、窗口和口径；
2. 建立覆盖四类要求的候选集合，并判断是否停止扩展；
3. 按附录2对所有候选解释进行对称比较；
4. 检查高低暴露、反向样本、特有中介和反事实；
5. 检查共同驱动、解释重叠、剩余现象和时间窗口；
6. 应用“主要由”两条硬规则；
7. 输出单一主因、主因＋次因、共同作用、分范围解释、不可区分或改写。

## 裁决与输出增量

| 比较结果 | 归因结论 | 这句话最多能说到哪 |
|---|---|---|
| 一个解释在关键区分信号上明显更强且无更强共同驱动 | 单一主因 | 可写“主要由” |
| 一个原因决定方向，其他改变幅度或持续性 | 主因＋次因 | 分别说明解释权 |
| 多个原因各解释独立部分 | 共同作用 | 不伪造精确权重 |
| 不同对象、阶段或窗口由不同原因主导 | 分范围解释 | 限定适用范围 |
| 只有相关性或缺关键区分信号 | 可能由/与……一致 | 不写“主要由” |
| 共同驱动或替代解释更强 | 原归因被改写 | 目标原因降为次要或排除 |
| 竞争解释无法区分 | 暂不可区分 | 保留争议和下一信号 |

除 A00 七项通用输出外，A05 还要额外写清：

- 被解释变化及待分配的解释维度；
- 候选集合及停止扩展理由；
- 各原因承担的方向、幅度、持续性或分化解释权；
- 支持“主要由”的关键区分信号；
- 共同驱动、重复归因和剩余未解释现象；
- 不支持精确权重时的明确限制。

## 边界与退回

- A05 属于因果判断，通常最高 J3；只有竞争解释已被高辨识力证据区分且公共 J4 条件全部通过时才可升级。
- 验证单个机制是否运行进入 A04；判断影响到达哪里进入 A06；判断经营/财务意义进入 A08。
- 候选原因、共同驱动、反事实或区分信号未定义，退回框架（02）。
- 候选解释未对称取证、低暴露样本或关键冲突可补，退回取证（03）。
- 被解释变化本身未确认，返回 A01/A02；无法区分时保留 J0/J1，不选择最显眼原因。

## 例与误判

**合格例：** 订单回升主要出现在低库存客户，高库存客户变化有限；终端销量尚未改善，而渠道库存下降和补库意愿上升。现有证据更支持“渠道补库”为短期主因，终端预期只影响持续性；不量化两者贡献比例。

**高迷惑性反例：** “出口管制发生后国产设备订单增长，因此订单增长主要由出口管制造成。”

该表述没有比较资本开支、产品升级和份额变化等解释，也没有高低暴露分化或共同驱动检查，触发 CE01、CE07 和 CE09。
