# 价格周期框架

## 研究员先看什么

价格研究的重点不是看到“涨价”或“降价”，而是先判断当前分歧落在哪一层：

1. **价格变化是否真实可比**：变化发生在目录价、报价、现货成交、合同价、结算价还是公司实现价；是否只是规格、地域、汇率、税费或产品组合变化；
2. **价格由什么驱动**：有效供需、库存、成本、竞争纪律、合同重定价或短期扰动，哪一种机制真正改变了边际成交；
3. **价格处于什么阶段**：只是价格水平变化，还是斜率、扩散度和持续期正在改变；上涨放缓不等于已经反转；
4. **边际价格能否进入合同和公司实现价**：现货信号可能领先，但若成交占比低、长协未重置或产品结构变化，不能直接外推到收入和利润。

单次任务不应同时把价格口径、全部驱动、完整周期、公司业绩、市场预期和估值全部展开。应先明确目标输出是价格状态、驱动归因还是实现价路径，再选择一条主要研究路线，最多保留一条主要竞争路线。

报价上涨但缺少成交、库存、交期或数量验证，只能称为报价信号；行业价格上涨但公司实现价未验证，不能推出公司盈利改善。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断某一明确产品、材料或服务在给定规格、地域、币种、合同和业务时间下：

- 当前可比价格处于上涨、下跌、稳定、分化还是暂不可判断；
- 价格变化是水平、斜率、扩散度还是持续期发生改变；
- 价格变化主要由供需、库存、成本、竞争、合同或结构因素中的哪类机制推动；
- 边际现货或报价变化是否具备传导至合同价、结算价和公司实现价的条件。

本框架可以独立判断价格状态。若要解释供需驱动，应读取 BF-SD-01 的供需平衡结果；跨产业链价格或成本传导由 BF-VT-01 承接；公司销量、利润和现金兑现由 BF-EE-01 承接；市场预期、估值和资产定价分别由 BF-EG-01 和 BF-VA-01 承接。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 目录价、报价 vs. 成交价 | 报价可能只是试探、限量、宣传或谈判锚点，不代表真实成交 |
| 现货价 vs. 合同价 | 交易主体、成交占比、重定价周期和交付条件可能完全不同 |
| 合同价、结算价 vs. 公司实现价 | 折扣、返利、产品结构、客户结构、币种和会计确认会改变最终 ASP |
| 同规格价格 vs. 产品组合变化 | 高端产品占比提升可能推高平均价格，但同一产品并未涨价 |
| 名义价格 vs. 同口径实际价格 | 汇率、税费、运费、规格升级和计量单位会产生表面变化 |
| 边际价格 vs. 平均价格 | 小比例现货成交可快速变化，但不一定代表大部分交易价格 |
| 价格水平 vs. 价格斜率 | 价格仍上涨时，涨幅收窄可能已进入减速阶段，但尚未反转 |
| 局部价格 vs. 广泛价格 | 单一规格、地区或客户紧张不能自动代表整个市场周期 |
| 成本转嫁 vs. 需求拉动 | 两者都可能造成涨价，但数量、利润、持续性和供给响应不同 |
| 产品价格 vs. 资产价格 | 产品价格变化不能直接证明盈利、预期差或估值方向 |

### 1.3 禁止跳步

- 不能从目录价或报价上涨直接确认市场价格已经上涨；
- 不能从单一现货成交直接推出合同价格或行业平均价格变化；
- 不能从价格上涨直接推出需求改善或供需紧张；
- 不能把平均销售价格上升直接解释为同规格价格上涨；
- 不能把价格仍在上涨但斜率放缓写成价格已经反转；
- 不能从局部高规格或特定地区涨价直接推出全市场价格周期；
- 不能从产品价格上涨直接推出公司收入、利润、现金或估值改善；
- 不能在规格、币种、税费、地域、合同和业务时间不可比时拼接价格序列。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 产品、规格、品质、地域、币种、税费、合同或业务时间无法对齐 | 可比 `price_state` |
| 只有目录价、报价或单方调价通知，没有成交、结算、配额、交期或订单验证 | 确认性价格状态，只能保留报价信号 |
| 平均价格变化无法排除产品、客户、地域或会计组合变化 | 同规格价格方向和价格驱动归因 |
| 价格样本来源、成交量或市场覆盖无法判断，且边际样本可能不具代表性 | 全市场或广泛价格结论 |
| 缺少供需、库存、成本、竞争或合同中的区分证据 | `driver_attribution` |
| 缺少连续序列、扩散度或供给响应与需求破坏时钟 | 价格阶段和拐点判断 |
| 现货或报价变化尚未进入合同重置、结算或公司 ASP | `realized_price_path` |
| 目标公司存在销量、结构、成本或汇率变化，但无法拆分 | 产品涨价到公司盈利的传导结论 |

高级输出停止时，已经确认的低层价格事实、报价变化或局部成交仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条主要竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 成交真实性** | 当前所谓涨跌是可比成交变化，还是报价、样本、结构或口径造成的表象 | 市场主要依据调价函、报价、价格指数或少量现货交易下结论；不同来源方向不一致 | 同规格成交/结算、成交量、折扣、订单、配额、交期、价差和样本覆盖 | 真实成交变化 vs. 报价无成交、产品组合、汇率税费或局部样本 | 无成交或结算验证时，止于报价/指数信号，不形成广泛价格状态 |
| **B 驱动归因** | 价格变化主要由供需、库存、成本、竞争纪律还是合同重定价推动 | 价格方向已基本确认，但持续性、数量和利润含义存在争议 | BF-SD-01 平衡状态、库存、订单、交期、成本、利用率、份额、折扣和合同条款 | 需求/供给驱动 vs. 成本转嫁、竞争减弱、库存扰动或结构变化 | 无法比较至少一条竞争解释时，只描述价格状态，不形成主导驱动 |
| **C 周期拐点** | 当前是加速、减速、分化还是反转；价格水平变化是否具有广度和持续性 | 用户询问价格趋势、顶部、底部或持续期；不同规格和市场节奏分化 | 价格斜率、扩散度、现货—合同价差、库存、取消单、交期、折扣、供给响应、需求破坏 | 周期拐点 vs. 季节性、局部规格扰动、合同滞后或短期补库 | 缺少连续序列和扩散度时，只判断当前价格方向，不判断阶段切换 |
| **D 合同与实现价** | 边际价格能否进入主流合同、结算和公司实现价，还是只停留在少量现货 | 行业价格已变化，但公司收入和利润反应不清；长协、返利、结构或确认时点重要 | 合同重签、定价公式、重置窗口、现货占比、折扣返利、实现 ASP、产品/客户结构 | 广泛重定价 vs. 现货局部变化、合同锁价、结构效应或会计时滞 | 没有合同与实现价证据时，止于行业价格状态，不外推公司兑现 |

### 路线选择要求

02 调用本框架时必须说明：

1. 本次目标是确认价格是否真实、解释驱动、判断拐点，还是验证实现价路径；
2. 主路线对应的核心分歧是什么；
3. 保留的竞争路线会产生哪些不同的数量、库存、价差、合同或实现价表现；
4. 本次采用哪一种价格口径，为什么能够代表研究对象；
5. 哪些价格层级、规格或地区因不会改变本次判断而被排除；
6. 前置条件失败后，分析止于哪一级输出。

四条路线全部展开，通常意味着研究问题没有收敛，或把价格框架误用成供需、公司与估值的完整研究目录。

## 3. 价格口径与最小判断结构

### 3.1 先建立价格层级，不默认一条直线传导

价格层级可包括：

```text
目录价/指导价
→ 报价或询价
→ 边际现货成交
→ 主流现货或渠道成交
→ 合同价/长协价
→ 结算价
→ 公司实现价（ASP）
→ 收入、利润和现金
```

这不是所有市场都必须完整存在的固定流程。某些行业直接按公式定价，某些服务没有现货市场，某些产品由招标或项目合同定价。单次任务只保留真实存在并会改变判断的价格层级。

上游价格层级的变化只有满足下列条件之一，才允许向下一级继续：

- 下一层交易主体接受了新的定价；
- 合同或公式已进入重置窗口；
- 折扣、返利或附加条件同步变化；
- 成交覆盖和数量足以代表目标市场；
- 产品与客户结构变化已经拆分；
- 对应的业务时间允许在当前窗口内完成传导。

### 3.2 价格状态至少拆成四个维度

| 维度 | 回答什么 | 常见误判 |
|---|---|---|
| 水平 | 当前价格相对历史、成本或可比市场处于什么位置 | 价格高位被误写成仍在加速上涨 |
| 方向与斜率 | 价格上涨/下跌，速度是在加快还是放缓 | 涨幅收窄被误写成价格已经下跌 |
| 扩散度 | 变化覆盖多少规格、地域、客户和合同 | 局部高端产品涨价被外推为全行业上涨 |
| 持续与兑现 | 变化能维持多久，是否进入合同和实现价 | 短期现货跳升被外推为长期盈利改善 |

单次任务只需选择会改变目标输出的维度，但不能用一个维度替代另一个维度。

### 3.3 边际定价者必须可识别

驱动归因或周期判断应尽量识别：

- 谁决定新增交易价格；
- 该交易占整体市场或目标公司的比例；
- 价格变化通过什么合同、平台、招标或谈判机制形成；
- 非边际交易是否仍被旧合同、旧库存或行政价格锁定；
- 边际价格变化是否会引发供给响应、替代或需求破坏。

无法识别边际定价者时，可以保留价格事实，但应降低对驱动和持续性的判断强度。

## 4. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| PC-C1 价格对象与口径 | 核心 | 每次调用 | 01 已固定且不存在规格、合同、地域、币种或税费歧义时可简写 | 哪一种价格能够代表本次研究对象 |
| PC-C2 成交与可比性验证 | 核心 | 需要形成 `price_state` | 直接获得权威同口径结算或实现价序列时可简写 | 价格变化是否真实、可比且具有代表性 |
| PC-R1 驱动分解 | 条件 | 需要形成 `driver_attribution` | 任务只确认价格事实，不解释原因 | 需求、供给、库存、成本、竞争和合同中谁改变边际价格 |
| PC-R2 广度与结构分化 | 条件 | 规格、地区、客户、合同或渠道方向不同 | 分项方向一致，拆分不会改变结论 | 价格变化是广泛周期还是局部结构性变化 |
| PC-R3 现货—合同—实现价 | 条件 | 需要判断合同、结算或公司 ASP | 研究对象本身就是最终结算价，且无额外合同或结构层级 | 边际信号能否进入主流交易和公司实现价 |
| PC-R4 周期响应与拐点 | 条件 | 用户要求趋势、顶部、底部或持续期 | 只研究当前价格状态；缺少连续序列和响应时钟 | 价格是加速、减速、分化还是反转 |
| PC-R5 数量、成本与结构桥 | 条件 | 价格变化的经营含义可能被销量、成本或组合抵消 | 任务止于纯价格事实 | 防止把单价变化直接写成收入或利润变化 |
| PC-E1 公司兑现 | 扩展/交接 | 用户要求具体公司订单、收入、利润或现金影响 | 任务止于行业或产品价格 | 生成交给 BF-EE-01 的实现价、销量、结构与成本问题 |
| PC-E2 预期与估值 | 扩展/交接 | 用户明确要求市场预期或估值，且价格与公司路径已具备 | 任务不涉及资产定价 | 只生成后续研究需求，不在本框架内裁决 |

单次任务必须记录启用与排除模块。模块存在于框架中，不代表自动生成对应取证任务。

## 5. 候选变量、信号与价格时钟

### 5.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 报价与调价 | 领先或情绪信号 | 可能无成交、限量、附带条件或只针对特定客户 |
| 成交价与结算价 | 状态和方向变量 | 样本、成交量、规格和渠道覆盖必须确认 |
| 合同价与定价公式 | 传导和时滞变量 | 重置窗口、回溯条款、折扣、返利和数量承诺会改变效果 |
| 公司实现价 | 公司兑现的前置或验证变量 | 产品、客户、币种和收入确认结构可能改变 ASP |
| 成交量与订单 | 价格真实性和需求承接信号 | 可能受补库、抢单、取消和会计口径影响 |
| 库存、交期和取消单 | 驱动、拐点和反证变量 | 需区分层级、规格、所有权和物流扰动 |
| 供给利用率、良率和释放 | 持续性、拐点和停止变量 | 名义产能和宣布扩产不能直接代表有效供给 |
| 成本、汇率、税费和运费 | 驱动或口径校正变量 | 成本上涨不等于能够转嫁，名义涨价不等于实际涨价 |
| 折扣、返利和价差 | 成交质量和竞争纪律变量 | 名义牌价稳定时，折扣变化可能才是真实价格变化 |
| 价格斜率与扩散度 | 阶段和结构变量 | 需要连续、同口径且足够覆盖的分项序列 |
| 替代与需求破坏 | 反证、停止和再平衡变量 | 需要技术、认证、价格弹性和业务时滞支持 |

基础框架不设置跨行业固定变量权重。02 应从中选择本次真正有判别力的变量，通常控制在 3—5 个，并说明其对应哪条路线、哪个价格层级和哪个输出门槛。

### 5.2 代理变量要求

直接成交、合同或实现价无法获得时可以使用代理，但必须说明：

- 代理对应哪一个价格层级；
- 代理与真实成交或实现价之间的业务机制；
- 代理覆盖的规格、地域、客户、渠道和业务时间；
- 样本选择、报价意愿、调价策略或统计权重可能造成的偏差；
- 代理在什么条件下失效；
- 使用代理后如何降低判断强度；
- 是否有成交量、库存、交期、折扣或公司披露中的第二类证据交叉验证。

调价函、媒体报价、专家口述、单一渠道价格和公司指引默认不能作为广泛成交价或实现价的无条件代理。

### 5.3 关键价格时钟

只选择本次相关时钟，但不得混用：

`供需或成本变化 → 报价/询价 → 边际现货成交 → 主流成交扩散 → 合同重置 → 结算 → 公司实现价 → 财务确认 → 供给响应/替代/需求破坏 → 再平衡`

不同价格层级可能跨越完全不同的时间窗口。现货可在数日内变化，长协和公司 ASP 可能在数月后才重置；扩产宣布可以即时影响预期，但形成有效供给可能需要数季甚至更久。

### 5.4 周期拐点不使用单一信号

判断加速、减速或反转时，优先从以下不同性质的信号中选择最小组合：

- **价格自身**：方向、斜率、价差、折扣、扩散度；
- **交易承接**：成交量、订单、配额、取消和交期；
- **缓冲状态**：库存、渠道行为、合同锁定；
- **响应机制**：供给释放、替代、需求破坏和客户降规格；
- **兑现状态**：合同重签、结算和实现 ASP。

基础框架不规定固定的“领先—同步—滞后”指标清单。02 应根据行业定价机制说明本次哪些信号领先、哪些同步、哪些滞后。

## 6. 竞争解释、反证与路径切换

| 表面现象 | 主解释 | 主要竞争解释 | 区分信号 | 命中竞争解释后的动作 |
|---|---|---|---|---|
| 报价上涨 | 市场价格正在上行 | 无成交调价、试探性报价、限量交易或宣传 | 成交量、折扣、配额、订单、交期和结算 | 只保留报价信号，不确认价格状态 |
| 平均售价上升 | 同规格价格上涨 | 高价产品、客户或地区占比提升 | 同规格价格、产品/客户结构和数量桥 | 切换为结构变化解释，不写价格周期 |
| 现货快速上涨 | 广泛供需紧张 | 小比例现货短缺、投机或临时物流扰动 | 现货占比、合同价、库存、交期和分项扩散 | 止于局部现货路径，不外推合同和行业平均价 |
| 价格上涨且销量下降 | 供给紧张推动涨价 | 需求破坏、主动提价保利润或退出低价订单 | 终端需求、订单质量、库存、客户流失和份额 | 不把涨价写成需求改善；检查可持续性 |
| 价格上涨、成本也上涨 | 需求拉动带来价格权 | 成本转嫁但单位利润未改善 | 单位成本、毛利、销量、合同和竞争份额 | 改为成本转嫁路径，交给 BF-EE-01 判断利润 |
| 价格仍上涨但涨幅收窄 | 上行周期延续 | 价格已进入减速，广度收窄或合同滞后 | 斜率、扩散度、折扣、库存、取消和价差 | 输出减速而非反转；启动拐点监测 |
| 局部规格涨价 | 全市场供给紧张 | 规格错配、认证壁垒或产线转换受限 | 分规格库存、交期、价差和转换能力 | 分对象输出，不形成广泛周期结论 |
| 公司 ASP 上升 | 行业价格传导到公司 | 产品/客户结构、汇率、确认节奏或并表变化 | 同产品实现价、合同、销量、结构和币种 | 不由本框架确认公司价格弹性，交给 BF-EE-01 |
| 库存下降且价格上涨 | 需求强、供给紧 | 减产、供给中断或渠道库存转移 | 终端、产量、出货、库存所有权和交期 | 不做单一需求归因，读取 BF-SD-01 |
| 供给扩张后价格未跌 | 需求强劲吸收供给 | 产能尚未有效释放、结构不匹配或合同滞后 | 良率、认证、利用率、交付、分规格价格 | 不认为价格韧性已经证明需求强劲 |

### 路径切换与降级规则

- 报价缺少成交验证：从“成交真实性”路线退回报价信号，不继续驱动和周期判断；
- 同规格价格稳定但平均价格上升：切换到产品/客户结构解释；
- 现货上涨但合同和主流成交未动：保留局部现货状态，不进入实现价路径；
- 价格上涨但数量、库存和交期不支持供需紧张：切换到成本、竞争、结构或短期扰动解释；
- 价格仍上涨但斜率和扩散度下降：输出“减速或分化”，不得直接写“反转”；
- 驱动解释暂时不可区分：03 优先收集区分证据，不扩展公司、预期和估值模块；
- 合同或实现价无法验证：止于产品价格，不形成公司业绩方向；
- 只有代理价格：降低强度，并写明代理失效条件和样本覆盖限制。

## 7. 可写到哪一层、组合与任务裁剪

### 7.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-PC-01.price_state` | 价格对象、规格、地域、币种、税费、合同和业务时间可比；有同口径序列；至少有成交/结算验证，并用成交量、价差、库存、交期或折扣中的一类独立信息交叉验证 | 只保留报价、指数或局部成交事实，不形成广泛可比价格状态 |
| `BF-PC-01.driver_attribution` | 已有可用 `price_state`；读取或明确 BF-SD-01 平衡状态；比较需求、供给、库存、成本、竞争、结构或合同中的至少一条竞争解释；有能够产生不同预测的区分信号 | 只描述价格状态、斜率和分化，不解释主要驱动 |
| `BF-PC-01.realized_price_path` | 已有可用 `price_state`；合同类型、重置机制和产品/客户结构清楚；至少有合同重签、折扣/返利、结算或公司实现 ASP 中的直接验证；说明现货或边际价格的覆盖比例和传导时滞 | 只保留产品或市场价格状态，不形成公司实现价路径 |

`price_state` 可以只判断当前价格方向，也可以在连续序列充分时包含加速、减速、分化或反转候选；不因缺少公司实现价而否定已确认的产品价格事实。更高一层写不出来时，已经成立的更弱结论仍可保留。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 7.2 组合与交接

- 价格驱动涉及供需平衡、库存与有效供给：读取或组合 BF-SD-01；
- 价格跨产业链向成本、数量或其他环节传导：组合 BF-VT-01；
- 行业结构、价格纪律和竞争行为是主因：组合 BF-IC-01；
- 公司实现价、销量、结构、成本、利润和现金：交给 BF-EE-01；
- 条件预测与未来价格区间：交给 BF-FS-01；
- 事件前预期、是否已经计价：先接 BF-EG-01；
- 估值输入变化：全部必要前提满足后接 BF-VA-01。

单次任务可以止于报价事实、成交价格状态或驱动判断，不要求为了完整而自动进入实现价、公司和资产层。

## 8. 证据、本体与维护边界

### 8.1 最低证据纪律

- 每条价格记录必须标明对象、规格、品质、地域、币种、税费、运费、合同类型和业务时间；
- 报价必须由成交、结算、配额、订单、交期或折扣中的至少一类信息验证；
- 平均价格必须拆分产品、客户、地域和币种结构，避免把组合变化误判为涨价；
- 驱动归因必须比较至少一条竞争解释，并读取必要的供需、库存、成本或竞争证据；
- 周期拐点必须依赖连续序列、斜率、扩散度和至少一类响应机制，不使用单一价格点；
- 现货到合同、结算和实现价必须分别验证，不能默认逐级传导；
- 公司实现价必须结合销量、产品结构、客户结构、币种、折扣和确认时点；
- 预测、公司指引、调价意向和机构观点不得冒充现实成交或结算。

具体来源、证据组合和验收由methods/03_取证管理。

### 8.2 本体边界

正式任务优先引用一级本体中已有的产品、材料、服务、环节、公司、交易或合同相关对象，以及状态变量、观测、事件、假设、信号、情景、判断和推理留痕。

行业正式定义的现货价、合同价、结算价、实现价、价差、折扣、成本曲线和库存变量，只有在领域本体正式存在时才作为领域扩展引用。

“价格真实性”“边际定价者”“价格扩散度”“合同重定价”“需求破坏阈值”“现货—合同传导”等属于框架概念、候选变量或候选规则，不因写入本文件自动成为正式本体定义。具体任务仍需完成正式映射、候选记录或缺口登记。

### 8.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 存储芯片现货与长协、原材料成本推动、消费品提价、项目型服务定价等不同机制任务 |
| 重点检查 | 是否明确价格层级和目标输出；是否只选一条主路线；是否区分斜率放缓与反转；是否在合同未重置时停止公司外推 |
| 经验沉淀 | 行业特有定价机制优先进入行业框架或场景卡；跨任务重复且存在反例边界的规则才写回稳定内核 |

复盘应记录实际启用路线、无代表性的价格样本、被误判的结构效应、合同传导时滞、错误的周期切换、长期未使用模块和越界到公司或估值结论的位置。框架更新不以增加篇幅为目标。
