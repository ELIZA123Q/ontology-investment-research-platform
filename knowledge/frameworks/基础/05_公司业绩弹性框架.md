# 公司业绩弹性框架

## 研究员先看什么

公司业绩弹性不是“行业景气变化 × 公司相关度”。真正需要判断的是，一项外部变化能否经过公司的真实暴露、商业化阶段、交付能力、实现价、产品结构、成本与费用、收入确认和现金回收，最终形成可持续的收入、利润和现金变化。

单次任务应先确认本次争议位于哪一段：

1. **暴露是否真实**：公司是否真的依赖或受益于目标产品、客户、地域和业务，而不是只有概念关联、潜在空间或管理层表述；
2. **机会能否转化为交付**：订单、送样、认证、产能规划或行业短缺，是否已经越过资格、良率、供应链、排产和客户接受等门槛；
3. **收入能否转化为利润**：销量、公司实现价、产品结构和汇率变化，是否被单位成本、固定成本、费用、折旧和原有业务变化抵消；
4. **利润能否转化为现金**：应收、存货、合同资产、预付款、资本开支和回款时点，是否使利润增长不能形成自由现金流；
5. **弹性是否具有非线性**：固定成本可能放大利润，也可能因产能、认证、客户集中、成本重定价和资本投入形成封顶、滞后或反向放大。

单次任务不应默认从行业变化一路推到估值。应先明确目标输出是业务暴露桥、收入利润桥还是现金桥，再选择一条主要研究路线，最多保留一条主要竞争路线。

行业受益不等于公司兑现；订单不等于可交付收入；收入不等于利润；利润不等于现金。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 行业、产品、客户、政策、价格或成本变化，与目标公司之间是否存在可验证的业务暴露；
- 该暴露是否已经进入能够形成交付、收入和利润的商业化阶段；
- 外部变化如何通过销量、公司实现价、产品结构、产能利用、良率、单位成本和费用进入收入与利润；
- 经营利润如何通过营运资本、资本开支、税费、融资和回款转化为现金；
- 不同公司为什么因暴露、合同、客户、产能、良率、成本、确认和现金占用不同而形成弹性分化。

本框架负责短中期经营与财务兑现，不重述长期商业模式。长期客户价值、收入模式、单位经济和资本强度由 BF-BM-01 承接；历史财务基线是否可信由 BF-FQ-01 判断；条件预测由 BF-FS-01 承接；市场预期和估值分别由 BF-EG-01、BF-VA-01 承接。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 主题或产业链相关 vs. 真实业务暴露 | 公司名称、概念标签或潜在市场不能证明已有收入、利润或客户暴露 |
| 潜在机会 vs. 当前商业化阶段 | 送样、测试、认证、定点、订单、量产、复购和规模采用具有不同兑现概率 |
| 订单 vs. 可交付收入 | 订单可能可取消、重复、提前、附带条件，且受产能、良率和验收限制 |
| 名义产能 vs. 可交付量 | 资格、良率、关键材料、排产、客户接受和供应链会折损名义产能 |
| 行业价格 vs. 公司实现价 | 合同、折扣、产品结构、客户结构、币种和确认时点会改变公司 ASP |
| 收入增长 vs. 增量利润 | 单位成本、固定成本、费用、折旧和原有业务变化可能抵消收入增量 |
| 平均利润率 vs. 增量利润率 | 存量业务的平均水平不能说明新增收入带来的边际贡献 |
| 报告利润 vs. 目标业务贡献 | 汇率、并表、一次性项目、会计估计和其他业务可能改变报表结果 |
| 利润增长 vs. 现金兑现 | 应收、存货、合同资产、预付款和资本开支可能吞噬利润 |
| 暴露大小 vs. 业绩弹性 | 高暴露公司若交付受限或成本高，弹性可能低于暴露较小但承接能力强的公司 |
| 上行弹性 vs. 下行弹性 | 固定成本、合同和库存会使上行、下行反应不对称 |
| 短期兑现 vs. 长期商业模式 | 短期景气改善不能自动证明长期单位经济和竞争优势增强 |

### 1.3 禁止跳步

- 不能从公司处于相关产业链位置直接推出其拥有实质业务暴露；
- 不能从送样、认证、设计导入、定点或产能规划直接推出收入兑现；
- 不能从订单增长直接推出可交付收入增长；
- 不能从行业产品涨价直接推出公司实现价和利润改善；
- 不能从名义产能扩张直接推出销量和收入增长；
- 不能从收入增长直接推出毛利、经营利润或现金同步改善；
- 不能把平均售价、毛利率或利润变化直接归因于目标业务，而不拆分产品结构、客户结构、汇率、并表和原有业务；
- 不能把净利润增长直接写成现金流和资本回报改善；
- 不能从公司业绩改善直接推出形成预期差、估值提升或资产价格上涨。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 上游行业、政策、价格或需求变化本身尚未形成可用机制判断 | 从外部变化到公司的兑现归因 |
| 目标业务、产品、客户、地域或报告分部无法识别，只有概念性关联 | `exposure_bridge` |
| 暴露规模、收入来源或成本暴露无法形成任何可核验边界 | 确认性业务暴露与公司比较 |
| 商业化阶段停留在意向、送样或测试，且下一门槛和业务时间不清 | 收入和利润兑现判断 |
| 订单可取消、重复或附带关键条件，但订单质量无法判断 | 订单到收入的确定性传导 |
| 资格、产能、良率、供应链、排产或客户验收中存在关键未决门槛 | 可交付量和收入桥 |
| 销量、公司实现价、产品结构、汇率或收入确认无法拆分 | `earnings_bridge` 中的收入归因 |
| 单位成本、固定成本、费用、折旧或原有业务变化无法识别，且可能抵消目标增量 | 增量利润和弹性判断 |
| 报表变化主要受并表、一次性项目、会计估计或口径变化影响，无法还原 | 目标业务业绩贡献 |
| 应收、存货、合同资产、资本开支或回款时点无法获得，且现金是目标输出 | `cash_bridge` |
| 行业变化、交付、财务确认和现金回收的业务时间明显不匹配 | 当前窗口已经完成兑现的判断 |

高级输出停止时，已经确认的业务暴露、商业化阶段、订单或局部财务事实仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条主要竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 暴露真实性** | 公司是否真正暴露于目标变化，还是只有概念、潜在空间或弱关联 | 用户问某公司是否受益/受损；业务披露模糊；同行相关度看似相同但表现分化 | 分部收入、产品出货、客户或合同、产能用途、采购成本暴露、目标业务毛利或订单占比 | 实质暴露 vs. 概念关联、潜在市场、非核心业务或可忽略占比 | 暴露无法达到可核验和重要性门槛时，止于主题相关，不进入收入利润桥 |
| **B 商业化与执行承接** | 机会能否越过资格、认证、产能、良率、供应链和客户接受，形成稳定交付 | 行业机会清楚，但公司仍处于送样、认证、定点、扩产或订单阶段 | 商业化阶段、下一门槛、订单质量、产能利用、良率、材料设备到位、排产、验收、复购 | 规模兑现 vs. 项目试点、双供备份、一次性订单、产能或良率受限 | 关键执行门槛未过时，只确认机会或阶段，不形成收入和利润方向 |
| **C 收入与利润捕获** | 外部变化能否通过销量、公司实现价和产品结构进入增量利润，还是被成本、费用和原有业务抵消 | 行业量价已变化，用户关心收入、毛利或利润弹性；公司指引和实际结果不一致 | 出货、实现 ASP、产品/客户结构、利用率、良率、单位成本、毛利桥、费用和折旧 | 目标业务兑现 vs. 结构、汇率、并表、低基数、成本下降或原有业务变化 | 无法还原量价结构和成本桥时，只描述报表变化，不形成目标业务利润归因 |
| **D 现金捕获与持续性** | 利润改善能否转成经营现金和资本回报，还是被营运资本、资本开支和回款占用 | 利润增长明显但现金弱；重资产扩产、项目制收入、渠道压货或回款周期重要 | 应收、存货、合同资产/负债、预付款、经营现金流、资本开支、自由现金流、回款和 ROIC | 可持续现金兑现 vs. 压货、延迟回款、资本开支前置、一次性收现或融资支持 | 缺少营运资本和资本开支证据时，止于利润桥，不形成现金和资本回报结论 |

### 路线选择要求

02 调用本框架时必须说明：

1. 本次目标输出是确认业务暴露、验证商业化与交付、解释利润弹性，还是判断现金兑现；
2. 主路线对应的核心分歧是什么；
3. 保留的竞争路线会产生哪些不同的订单、交付、实现价、成本、利润或现金表现；
4. 本次目标业务和公司整体之间如何分层，哪些原有业务可能抵消或掩盖增量；
5. 哪 2—3 个判断单元真正决定总体结论；
6. 哪些财务科目、业务模块或下游框架因不会改变本次判断而被排除。

四条路线全部展开，通常意味着研究目标没有收敛，或把公司业绩弹性框架误用成完整公司研究和估值模型。

## 3. 弹性桥与非线性结构

### 3.1 弹性不是一个固定系数

本框架中的“弹性”是条件式传导能力，不是跨公司、跨周期稳定不变的倍数。单次任务应说明外部变量变化通过哪些门槛和财务桥进入目标结果。

推荐的最小表达为：

```text
上游行业/产品/政策/成本变化
→ 目标业务真实暴露
→ 商业化阶段与订单质量
→ 可交付量、公司实现价和产品结构
→ 单位成本、利用率、固定成本和费用
→ 收入与增量利润
→ 营运资本、资本开支和现金回收
```

这不是所有任务必须完整执行的固定流程。目标若只是确认暴露，可以止于第二层；目标若只判断收入利润，不要求现金，则可以止于利润桥。

### 3.2 必须识别的非线性

| 非线性类型 | 典型来源 | 对判断的影响 |
|---|---|---|
| 阈值效应 | 认证通过、量产起点、最低产能利用率、盈亏平衡点 | 门槛未过时几乎无兑现，过门槛后收入或利润可能跳升 |
| 封顶效应 | 产能、良率、供应链、客户份额、合同上限 | 行业机会继续扩大，公司收入和利润仍可能受限 |
| 经营杠杆 | 固定制造成本、研发、销售和管理费用 | 收入变化可放大利润，也会在下行时反向放大亏损 |
| 时点错位 | 现货与合同、价格与成本、订单与收入、利润与现金 | 同一季度可能出现收入、利润和现金方向不一致 |
| 结构效应 | 高低毛利产品、客户、地域和渠道占比变化 | 平均售价和毛利变化不一定来自同产品价格或成本变化 |
| 抵消效应 | 原有业务下滑、成本上涨、费用投入、汇率和并表 | 目标业务改善可能未反映在公司总量结果中 |
| 非对称效应 | 长协锁价、库存、客户集中、减产和固定成本 | 上行和下行弹性不相等，不能用单一线性系数外推 |
| 现金稀释 | 应收、存货、预付款、扩产和资本开支 | 利润增量可能伴随更高资金占用和更低自由现金流 |

02 只需选择会改变本次判断的非线性，不得为了完整把所有非线性都列入主路径。

### 3.3 公司比较不能只比较暴露比例

比较公司弹性时至少需要统一：

- 目标产品、客户、地域和业务时间；
- 暴露口径是收入、出货、产能、成本还是利润；
- 商业化阶段和可交付能力；
- 合同、公司实现价和产品结构；
- 固定成本、单位成本和资本开支；
- 原有业务抵消和财务确认时点。

若比较对象在商业化阶段、会计口径或业务时间上不可比，不得仅按“相关业务占比”排序。

## 4. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| EE-C1 上游变化与目标输出 | 核心 | 每次调用 | 01 已明确且上游机制判断已有稳定引用时可简写 | 什么外部变化需要传到公司，目标止于暴露、利润还是现金 |
| EE-C2 业务暴露映射 | 核心 | 需要形成任一公司兑现输出 | 目标业务已经有清晰分部、合同和财务披露时可简写 | 公司在哪些产品、客户、地域、收入或成本上真实暴露 |
| EE-R1 商业化阶段 | 条件 | 目标业务处于技术导入、客户验证或新产品放量 | 成熟存量业务，无认证和采用门槛 | 当前处于送样、认证、订单、量产还是复购，下一门槛是什么 |
| EE-R2 执行与可交付量 | 条件 | 存在产能、良率、材料、排产、交付或验收约束 | 服务或轻资产业务且交付能力已被可靠验证 | 机会能否转化为实际销量和收入 |
| EE-R3 量价结构收入桥 | 条件/核心 | 需要形成 `earnings_bridge` | 任务只确认业务暴露或阶段 | 销量、公司实现价、产品结构、汇率和确认如何进入收入 |
| EE-R4 成本与经营杠杆 | 条件/核心 | 需要形成利润弹性 | 任务止于收入，不判断利润 | 单位成本、利用率、固定成本、费用和折旧如何放大或抵消收入 |
| EE-R5 报表归因与原有业务抵消 | 条件 | 公司整体结果与目标业务方向不一致，或存在并表、汇率、一次性项目 | 单一业务公司且口径稳定、目标贡献可直接识别 | 报表变化是否真正来自目标业务 |
| EE-R6 营运资本与现金 | 条件 | 需要形成 `cash_bridge`；项目制、重资产或渠道模式现金占用重要 | 任务明确止于经营利润 | 利润是否形成经营现金和自由现金流 |
| EE-R7 公司分化比较 | 条件 | 用户要求比较多家公司，或同行弹性明显不同 | 只研究单一公司 | 暴露、阶段、执行、合同、成本和现金差异如何形成分化 |
| EE-E1 财务基线与预测 | 扩展/交接 | 需要数量化历史基线或未来情景 | 任务只做方向性兑现判断 | 先交 BF-FQ-01 检查历史，再交 BF-FS-01 形成条件预测 |
| EE-E2 预期与估值 | 扩展/交接 | 用户明确要求预期差或估值，且业绩桥已经可用 | 任务不涉及资产定价 | 只生成后续研究需求，不在本框架内裁决 |

单次任务必须记录启用与排除模块。模块存在于框架中，不代表自动生成对应取证或预测任务。

## 5. 候选变量、信号与兑现时钟

### 5.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 业务暴露 | 前提、方向和公司比较变量 | 概念标签、潜在市场和笼统产品介绍不能代替实际收入、成本或客户暴露 |
| 商业化阶段 | 前置、阈值和停止变量 | 送样、认证、定点、订单、量产和复购不能混用 |
| 订单质量 | 收入领先和反证变量 | 订单可能可取消、重复、提前、附带验收或融资条件 |
| 可交付量 | 收入上限和阶段变量 | 名义产能需经利用率、良率、材料、排产、人员和客户接受折损 |
| 公司实现价 | 收入和利润变量 | 行业价格、报价和公司 ASP 之间存在合同、折扣、结构和币种差异 |
| 产品与客户结构 | 收入、毛利和分化变量 | 平均售价或毛利变化可能完全由结构变化造成 |
| 利用率与良率 | 经营杠杆、成本和封顶变量 | 不同产线、产品和成熟阶段不可直接平均 |
| 单位成本 | 利润方向和竞争解释变量 | 原材料、制造、外包、物流、折旧和良率损耗需分开 |
| 固定成本与费用 | 非线性和下行风险变量 | 费用前置、资本化和一次性调整会改变当期弹性 |
| 收入确认 | 时点和报表边界变量 | 发货、验收、履约、并表和会计政策可能使业务与财务时间不同 |
| 营运资本 | 现金和持续性变量 | 应收、存货、合同资产和预付款的变化需结合业务阶段解释 |
| 资本开支 | 现金稀释、产能和回报变量 | 扩产宣布、在建工程、转固和真正形成产能具有不同时间 |
| 原有业务与其他损益 | 抵消和归因变量 | 目标业务改善可能被旧业务下滑、汇率、并表或一次性项目掩盖 |

基础框架不设置跨行业固定变量权重。02 应从中选择本次真正决定暴露、利润或现金的变量，通常控制在 3—5 个，并说明其对应哪条路线和哪个输出门槛。

### 5.2 代理变量要求

直接业务暴露、订单、公司实现价或单位成本无法获得时可以使用代理，但必须说明：

- 代理对应哪一个业务环节和财务桥；
- 代理与目标变量之间的业务机制；
- 代理覆盖的产品、客户、地域、分部和业务时间；
- 公司选择性披露、渠道调研、行业均值或样本偏差可能造成的限制；
- 代理在哪些条件下失效；
- 使用代理后如何降低判断强度；
- 是否有第二类独立信息从财务、客户、供应商或交付端交叉验证。

行业均价、行业出货、名义产能、公司管理层定性表述和券商测算默认不能无条件替代公司实现价、实际出货和目标业务利润。

### 5.3 关键兑现时钟

只选择本次相关时钟，但不得混用：

`行业/政策/价格变化 → 客户决策 → 送样/认证/定点 → 订单形成 → 排产与采购 → 生产、良率与交付 → 客户验收 → 收入确认 → 成本和费用确认 → 回款与营运资本变化 → 资本开支和现金回报`

不同业务的兑现时钟可以完全不同。标准品可能先体现现货和出货，项目型业务可能以验收决定收入，设备和材料可能以认证、订单、交付和收入确认跨越多个季度。

### 5.4 订单、收入、利润和现金信号应分层

| 层级 | 常见信号 | 不能单独证明的结论 |
|---|---|---|
| 机会与商业化 | 送样、测试、认证、定点、客户导入 | 不能证明规模订单、收入和复购 |
| 订单与排产 | 在手订单、排产、预付款、合同负债 | 不能证明全部可交付、可确认或可回款 |
| 交付与收入 | 出货、验收、收入、公司实现价 | 不能证明增量利润和现金同步改善 |
| 利润 | 毛利、经营利润、增量贡献 | 不能证明来源是目标业务，也不能证明现金兑现 |
| 现金与回报 | 回款、经营现金流、自由现金流、ROIC | 需要结合资本开支、融资和业务周期判断持续性 |

## 6. 竞争解释、反证与路径切换

| 表面现象 | 主解释 | 主要竞争解释 | 区分信号 | 命中竞争解释后的动作 |
|---|---|---|---|---|
| 公司处于热门产业链 | 具备高业务暴露 | 只有概念、潜在产品或非核心业务 | 分部收入、产品出货、合同、客户和产能用途 | 止于主题相关，不形成 `exposure_bridge` |
| 送样、认证或定点 | 商业化即将兑现 | 试点、双供备份、议价工具或长期未转量产 | 下一门槛、订单、交付、复购和收入 | 只确认阶段，不形成收入利润方向 |
| 在手订单增长 | 收入即将增长 | 重复下单、提前备货、可取消订单、低毛利订单或交付受限 | 订单条款、取消、排产、交付、验收和回款 | 降级为订单信号，不确认可交付收入 |
| 名义产能扩张 | 公司能够承接行业机会 | 良率、材料、设备、人员、认证或客户需求不足 | 实际产出、利用率、良率、交付和客户接受 | 不把扩产规划写成收入上限已提升 |
| 公司 ASP 上升 | 行业涨价进入公司实现价 | 高价产品/客户占比、汇率、并表或收入确认变化 | 同产品实现价、销量、合同和结构桥 | 切换为结构或口径解释，不直接确认价格弹性 |
| 收入增长 | 目标业务量价兑现 | 并表、汇率、低基数、原有业务恢复或会计口径变化 | 分部、量价结构、同口径收入和业务时间 | 不做目标业务单一归因 |
| 毛利率上升 | 价格和规模带来利润弹性 | 原材料降价、一次性冲回、产品结构、补贴或费用重分类 | 单位价格、单位成本、利用率、结构和会计附注 | 切换到成本、结构或会计解释 |
| 利润增长快于收入 | 经营杠杆释放 | 一次性收益、汇兑、税率或费用延后 | 增量毛利、固定成本、费用、其他损益和税率 | 不直接认定核心经营弹性 |
| 利润增长但经营现金流下降 | 现金兑现滞后 | 应收、存货、合同资产、预付款或渠道压货 | 回款、账龄、库存、合同负债和订单质量 | 止于利润桥，启动现金捕获路线 |
| 同行业公司业绩差异大 | 暴露和执行能力不同 | 会计口径、并表、周期位置或一次性因素不同 | 同口径暴露、阶段、量价、成本和现金桥 | 先统一口径，再形成公司弹性比较 |
| 行业景气改善但公司利润下降 | 公司未能承接 | 原有业务恶化、价格成本错位、扩产费用、汇率或客户结构变化 | 业务分部、实现价、单位成本、费用和原有业务桥 | 拆分抵消项，不否定行业机制本身 |

### 路径切换与降级规则

- 暴露无法验证或重要性过低：止于主题相关，不进入商业化和财务桥；
- 商业化阶段未越过关键门槛：保留机会和监测条件，不形成收入方向；
- 订单质量无法判断：退回订单信号，不把订单总额直接转成收入；
- 可交付量受产能、良率或供应链限制：切换到执行约束路径，并形成收入上限；
- 公司实现价无法从行业价格或产品结构中拆出：止于行业价格或 ASP 事实，不形成价格弹性；
- 收入变化主要由结构、汇率、并表或原有业务造成：切换到对应归因，不形成目标业务收入桥；
- 成本和费用抵消增量：输出部分捕获或无利润捕获，不以收入增长替代利润判断；
- 利润未转成现金：保留利润桥，启动营运资本和资本开支路线；
- 公司比较口径不一致：停止排序，只保留各自条件式弹性描述。

## 7. 可写到哪一层、组合与任务裁剪

### 7.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-EE-01.exposure_bridge` | 上游变化和目标公司清楚；目标产品、客户、地域或成本暴露可识别；至少有一类直接业务证据和一类财务或交付交叉验证；暴露在研究窗口内具有重要性 | 只保留主题相关、潜在机会或弱暴露，不形成公司受益/受损判断 |
| `BF-EE-01.earnings_bridge` | 已有可用 `exposure_bridge`；商业化和执行门槛满足；销量、公司实现价、产品结构和收入确认至少能形成最小收入桥；单位成本、利用率、固定成本、费用和原有业务抵消可以比较；主要竞争解释被排查 | 止于暴露、阶段、订单或收入事实，不形成增量利润和弹性判断 |
| `BF-EE-01.cash_bridge` | 已有可用 `earnings_bridge`；应收、存货、合同资产/负债、预付款、经营现金流和资本开支中的关键现金变量可得；利润到现金的时滞、占用和回收机制清楚 | 只形成经营利润桥，不形成现金、自由现金流或资本回报结论 |

更高一层写不出来时，不抹去已经确认的低层暴露、阶段、订单、收入或利润事实。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 7.2 组合与交接

- 上游变化来自供需和周期：读取或组合 BF-SD-01；
- 上游变化来自政策或管制：组合 BF-PI-01；
- 上游变化需要逐边传导：组合 BF-VT-01；
- 上游变化是产品价格：读取 BF-PC-01 的价格状态和实现价前提；
- 长期收入模式、客户价值和单位经济：组合 BF-BM-01；
- 历史财务基线、报表可靠性和正常化：先交 BF-FQ-01；
- 未来条件预测和情景范围：交给 BF-FS-01；
- 风险穿透、流动性和不可逆阈值：组合 BF-RS-01；
- 事件前预期和是否已经计价：交给 BF-EG-01；
- 估值输入与区间：全部前提满足后交给 BF-VA-01。

单次任务可以止于 `exposure_bridge` 或 `earnings_bridge`，不要求为了完整而自动进入现金、预测、预期和估值。

## 8. 证据、本体与维护边界

### 8.1 最低证据纪律

- 业务暴露优先使用分部披露、产品收入、合同、客户、出货、采购和产能用途；概念表述只作弱信号；
- 商业化阶段必须同时说明当前里程碑、下一门槛、业务时间和未决条件；
- 订单至少检查可取消性、重复下单、履约条件、交付窗口和收入确认；
- 可交付量必须结合资格、产能、利用率、良率、供应链、排产和客户接受；
- 收入桥应尽量同时核对销量、公司实现价、产品/客户结构、汇率和确认时点；
- 利润桥应同时核对单位成本、利用率、固定成本、费用、折旧、其他损益和原有业务抵消；
- 报表归因应排除并表、一次性项目、会计估计和口径变化；
- 现金桥必须核对应收、存货、合同资产/负债、预付款、经营现金流和资本开支；
- 公司指引、机构预测和研究员假设不得冒充现实订单、出货、实现价或现金。

具体来源、证据组合和验收由methods/03_取证管理。

### 8.2 本体边界

正式任务优先引用一级本体中已有的公司、产品、客户、行业、环节、应用、设施、合同和财务相关对象，以及状态变量、观测、事件、假设、信号、情景、判断和推理留痕。

客户验证、设计导入、产能、良率、订单、公司实现价、单位成本、收入确认和营运资本等，只有在领域本体已有正式定义时才作为领域扩展引用。

“真实业务暴露”“商业化阶段”“可交付量”“订单质量”“增量利润率”“经营杠杆”“现金捕获率”等属于框架概念、候选变量或候选规则，不因写入本文件自动成为正式本体定义。具体任务仍需完成正式映射、候选记录或缺口登记。

### 8.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 行业涨价到公司利润、国产替代认证到收入、设备订单到确认、周期上行到现金、重资产扩产等不同兑现机制 |
| 重点检查 | 是否先验证暴露；是否区分商业化阶段；是否选择单一主路线；是否拆分订单、收入、利润和现金；是否识别非线性和抵消项 |
| 经验沉淀 | 行业特有认证、合同和确认机制优先进入行业框架或场景卡；跨任务重复且有反例边界的规则才写回稳定内核 |

复盘应记录实际启用路线、错误的暴露假设、长期未转化的商业化信号、订单到收入的折损、实现价与行业价格的偏差、成本和原有业务抵消、利润与现金背离，以及被长期裁掉的模块。框架更新不以增加篇幅为目标。
