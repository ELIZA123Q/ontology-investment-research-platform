### 1.2 方向观察链

- Run：`536a5f6f-84ed-423a-9a52-be3bd0b25291`
- 问题：截至 2025-01-16，台积电 2024 全年营收是否同比增长，且 Q4 同比增速是否高于全年。
- 事实：两条截止日内 SEC 原文逐字引文，分别披露全年同比 `33.9%` 和 Q4 同比 `38.8%`；两份文档属于同一 `TSMC` 来源组。
- 终态：两个 J1/low-confidence 方向观察；系统明确禁止把 `38.8% > 33.9%` 外推为“下半年持续加速”，也不支持增长质量、原因、持续性或预测。
- 生产失败留痕：Stage03 与 Stage04 的 DeepSeek 结构化生成分别超时；研究者随后通过受控事实/判断投影提交明确输入，Runtime 重算方法前置条件、证据上限、竞争解释和五项确定性规则，再经对象级人工批准。
- 独立审阅：`deepseek-v4-flash` 审阅 `human-controlled-judgment-projection`，verdict=`pass`，independence=`independent_model`。
- 同证据 A/B：运行验收评分明确标注为“非正式人类盲评”。系统方案在事实核验、无来源主张、边界和复盘性上优于直接基线；直接基线存在“下半年加速”推理跳跃和冻结引文外主张。
- 确定性指标：绑定来源数 `2`、supported claim ratio `1`、traceable claim ratio `1`、judgment-method trace ratio `1`、executed MethodApplication `6/6`。
- 导出：`90_compat/instances/00_本机运行/exports/536a5f6f-84ed-423a-9a52-be3bd0b25291`

## 2. 本次证明了什么

1. 模型失败不会迫使系统编造事实；失败分类、失败 artifact 和受控降级路径都可回放。
2. Source Registry、EvidenceFact、Judgment 和 Expression 之间存在事实级引用，而不是只保存 URL 或在 Markdown 中自证。
3. 同一来源组的多文档不会被误算为多个独立来源，判断强度被确定性限制在 J1。
4. Stage05 模型的过度表达会被已批准 Judgment 投影覆盖，报告不能新增方向结论。
5. 工作项逐对象批准、旧 attempt supersede、独立审阅、冻结基线、A/B 揭示锁定和工作台导出门都在真实数据库运行中发生。

## 3. 尚未证明什么

### 3.1 四案例研究增益尚未正式收集

`90_compat/evaluation/03_执行` 已具备真实 HTTP 模型适配器、冻结/盲化/校准/聚合/报告链和四案例合同。

**`pilot_light`（可立即跑）：** 使用 [`model_profiles.yaml`](../03_执行/model_profiles.yaml) 的 `run_mode: single_vendor`——只需 DeepSeek 两个互异 `model_id`（`deepseek-v4-pro` 生产 + `deepseek-v4-flash` 评测/下游）。评测与下游槽位可复用 flash；报告须注明单供应商限制，不得外推跨模型可靠率。

**`formal_full`（尚未跑）：** 仍要求 `run_mode: official` 下的五个互异 `model_id` 与评测/下游 `model_id` 不重合。单供应商两模型结果不能代替 formal_full 结论。

因此：

- 在跑通 `single_vendor` + `pilot_light` 之前，不发布 R、U、delta、S、C 的正式实测结论；
- 不把工作台两条运行的 A/B 验收分数外推为系统可靠率；
- 不把 mock 端到端测试结果表述为研究质量；
- `pilot_light` 通过后，若需 formal_full 级发布，须取得多 `model_id` 的 official 档案并开新运行目录。

### 3.2 研究价值结论仍受样本范围限制

当前真实方向链是发行人历史数值核查，不是复杂行业机制、归因或预测任务。它证明约束与回放有效，但不能单独证明本体方法链在高歧义研究问题上持续产生正增益。

## 4. 当前决策

- 架构层面：不再横向扩本体，继续用真实失败归因决定是否修改 ontology、methods 或 runtime。
- 产品层面：受控事实和判断投影已经进入证据台/判断台，不再是隐藏 API；模型超时时研究者仍能完成受审计的工作流。
- 降级路径：Stage05 已可在没有模型种子报告时由当前 Judgment/Evidence/Method 血缘确定性生成；独立审阅同时支持不同模型与有身份、hash、独立性声明的人类审阅，但禁止自审。
- 评测层面：下一硬门是跑通 `single_vendor` + `pilot_light`（见 `90_compat/evaluation/03_执行/model_profiles.yaml`），不是增加更多静态本体类。
