# A07 事前预期与定价取证

事前预期与定价取证：新信息相对「事件发生前可得的共识截面」差多少，价格是否已反映。

## 1. 什么时候使用

用于准备「新信息相对事前共识是否构成预期差、预期怎样修订、价格是否已反应、估值输入怎样变化」的材料。基本面输入须先由 A01—A06 覆盖到可用范围。没有事件发生前可得的共识截面（事前预期）时，不得形成预期差材料（完备度最高观察或不可用）。这类问题通常还要做完整反向检索。

## 2. 取证逻辑

把四类材料分开归档：

1. 已确认可用的基本面输入；
2. 信息公开前可得的市场预期截面（事前预期）；
3. 预期修订路径；
4. 相对价格反应与估值输入变化。

事前基线必须使用信息发生前可得的共识截面，记录信息时间、共识截点、样本数、指标和预测期、分布、修订路径及价格窗口。没有可追溯事前基线，不使用「超预期」措辞准备材料。

价格反应至少拆为资产收益、市场收益和行业／风格共同收益材料。股价涨跌材料不能单独充当基本面或「充分计价」证据。估值材料看盈利／现金流基准、增长持续期、资本强度、再投资回报、折现率和尾部风险输入，不把「低于历史均值」直接写成低估证据。

## 3. 最少必须取得什么

| 这份材料起什么作用 | 最低要求 |
|---|---|
| 主证据 | 已确认可用的基本面输入，以及事件前一致预期截面 |
| 比较基准 | 同样本预测修订、市场／行业相对收益、历史或同业估值输入 |
| 独立交叉验证 | 共识修订、价格反应和估值变化至少两类相互印证 |
| 反证与限制 | 提前交易、样本变化、市场共振、拥挤、风险溢价或预期已充分修订材料 |

取数前先核对：对象、业务时间、定义、单位、版本匹配；事前预期截面的时间戳必须早于事件信息时间。

## 4. 优先来源

一致预期使用 Wind、Bloomberg、FactSet、LSEG、Capital IQ、iFinD、Choice 等可保存事前截面的授权字段；价格使用交易所或授权行情；估值用行情和财务输入复算；卖方报告、电话会和新闻只用于观点分布与叙事。保存共识均值／中位数、区间、样本数和分歧度。

## 5. 完备度怎样受限

- 基本面输入不可用：停止预期差材料准备。
- 只有单篇研报、目标价或新闻热度：只能描述叙事材料。
- 只有股价涨跌，或价格窗口与信息时间不匹配：最高观察。
- 用事件后最新共识倒推事前预期：不可用。
- 共识样本变化未处理：受限。
- 同期宏观／行业事件无法分离：降低定价归因材料强度。
- 无事前预期截面：观察或不可用，不得评为充分。

## 6. 交给 04 什么

```text
已确认可用的基本面输入摘要
事前共识截面、样本与分布
同样本修订方向、幅度和速度材料
相对价格反应与事件窗口材料
估值输入变化及市场叙事材料
证据完备度：充分／受限／观察／不可用
待裁决问题：是否存在预期差及其强度（由 04 裁决；本方法不写「预期差成立」）
```
