# 产业链传导框架

## 研究员先看什么

产业链研究不是把上游、中游、下游全部画出来，而是确认一项变化是否能沿**最短充分链条**到达目标对象。优先判断四件事：

1. **依赖是否真实**：是否存在方向明确的供应、使用、生产、替代、合同或能力依赖；
2. **变化能否越过关键边**：库存、合同、议价、认证、冗余、监管和替代会吸收、延迟或阻断多少冲击；
3. **传导的是什么**：数量、价格、成本、交期、结构和风险通常不是同一条路径；
4. **目标对象能否承接**：产业链位置不等于业务暴露、执行能力和财务兑现。

单次任务围绕一条主路径，通常只保留 3—6 个必要节点和 1—2 条决定性边。需要铺开整条产业链才能说明问题，通常意味着目标尚未收敛。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 是否存在通向目标对象的真实传导路径；
- 冲击在哪一段被吸收、放大、延迟、阻断或改道；
- 传到目标的是数量、价格、成本、交期、结构还是风险；
- 不同对象为何因依赖、缓冲、替代和承接条件不同而分化。

可止于产品、环节或行业状态。公司订单/收入/利润/现金交给 BF-EE-01；长期商业模式暴露接 BF-BM-01；预期与估值分别接 BF-EG-01、BF-VA-01。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 稳定关系 vs. 动态变化 | 长期供应关系不能证明本次冲击已经传导 |
| 概念邻近 vs. 真实依赖 | 同属产业主题不等于采购、生产或收入关系 |
| 必要节点 vs. 增强节点 | 必要节点失败终止路径；增强节点只改变强度 |
| 数量/价格/成本/交期/结构路径 | 决策主体、合同和时滞通常不同 |
| 名义暴露 vs. 有效承接 | 位于受益环节不等于资格、产能、交付能力 |
| 缓冲吸收 vs. 路径阻断 | 缓冲可能只延迟；阻断使后续路径失效 |
| 替代意愿 vs. 替代可用 | 有动机不等于已完成兼容、认证和规模交付 |
| 同期相关 vs. 因果传导 | 同向变化可能来自共同宏观或行业因素 |

### 1.3 禁止跳步

- 不能从上游事件直接推出下游公司受益或受损；
- 不能用产业链图、行业分类或概念关联代替真实关系证据；
- 不能只验证起点与终点同向，就声称中间路径成立；
- 不能把价格、数量、成本、交期和利润合并为同一条传导链；
- 不能从替代意愿直接推出替代已经发生；
- 不能在必要节点失败后，仅降低措辞仍保留终点判断。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 起点对象、源关键变量或作用范围无法确认 | `path_structure` |
| 关键边只有概念邻近、常识或单方推测 | 该边及其后续路径 |
| 跨两级以上却无任何中间动态节点证据 | `segment_pass_through`、`terminal_effect` |
| 数量/价格/成本/交期口径混用 | 对应类型传导结论 |
| 关键缓冲状态无法判断 | 确认性穿透判断 |
| 目标对象暴露或承接能力无法确认 | 目标承接与分化判断 |
| 业务时间不匹配或时滞足以解释无变化 | 当前已完成传导的判断 |
| 共同因素无法区分 | 净传导归因 |

高级输出停止时，已确认的起点事实、稳定关系和局部中介变化仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 依赖真实性** | 目标是否真实依赖起点，还是只有概念关联 | 关系是整条判断的前提 | 合同、采购、BOM、披露、兼容、收入/成本暴露 | 真实依赖 vs. 概念邻近或可忽略暴露 | 依赖未确认则止于关系待验证 |
| **B 穿透与吸收** | 冲击会越过缓冲，还是被吸收/延迟 | 上游冲击能否传到下游是主争议 | 库存覆盖、长协、转嫁条款、冗余、交期 | 直接穿透 vs. 缓冲吸收 | 缓冲状态不清时只做条件式传导 |
| **C 瓶颈与放大** | 中间节点是否把局部变化放大成全链约束 | 总量冲击不大但交期/价格反应剧烈 | 瓶颈利用率、转换、认证、单点依赖 | 关键瓶颈 vs. 暂时排产/物流/规格错配 | 瓶颈可快速绕开时不外推全链 |
| **D 替代与改道** | 原路径延续，还是因替代而改道 | 管制、短缺或技术变化引发替代 | 兼容、认证阶段、切换成本、复购、份额 | 原路径延续 vs. 有效替代/转口/自产 | 仅有意愿或送样时不确认已改道 |

### 路线选择要求

必须说明：主路线与竞争路线、哪 1—2 条边决定路径、哪些节点因不改变路径被排除、分析止于哪个对象和哪类变量。四条以上路线全部展开，通常意味着终点未收敛。

单次路径表达骨架（可裁剪）：

```text
起点变化 → 关键依赖边 → 缓冲/瓶颈/替代中介 → 穿透或改道边 → 目标业务状态 →（条件满足时）交接公司兑现
```

节点进入主路径的条件：是后续成立的必要条件、承担关键缓冲、是放大/阻断/改道位置、决定某类状态变化、能区分竞争解释，或决定是否允许进入下游框架。

## 3. 模块菜单

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| VT-C1 起点与目标锚定 | 核心 | 每次调用 | 01 已无对象/变量/终点歧义时可简写 | 从哪里开始、传到哪里、判什么 |
| VT-C2 最短充分路径 | 核心 | 需要任一传导输出 | 单一直接关系时可简化为一条边 | 哪些节点和边真正决定结论 |
| VT-R1 稳定关系验证 | 条件 | 关键依赖尚未确认 | 关系有直接证据且无争议 | 防止概念邻近替代真实依赖 |
| VT-R2 缓冲与吸收 | 条件 | 存在库存、合同、冗余或转嫁 | 无现实缓冲的直接机械传导 | 冲击是否被延迟或局部吸收 |

| VT-R5 多变量与时滞 | 条件 | 数量/价格/成本/交期不同步 | 单一变量单一时钟 | 防止混路径 |
| VT-E1 公司兑现交接 | 扩展 | 目标涉及订单/收入/利润/现金 | 止于行业或产品状态 | 交给 BF-EE-01 |

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 可能作用 | 常见限制 |
|---|---|---|
| 依赖强度 | 前提或方向 | 名义采购不等于关键依赖 |
| 暴露比例 | 强度与分化 | 笼统“相关业务”不能代替真实暴露 |
| 库存与缓冲 | 吸收、时滞或停止 | 所有权、规格必须匹配 |
| 合同与议价 | 价格、成本、时滞 | 标价、合同价、实现价不能混用 |
| 产能与瓶颈 | 放大、上限 | 名义产能不等于可交付产能 |
| 认证与兼容 | 前置、阻断、改道 | 送样≠认证≠量产≠复购 |
| 替代准备度 | 路径切换 | 意愿≠可用性≠规模替代 |
| 目标承接能力 | 对象分化 | 需资格、产能、交付共同验证 |

单次通常选 3—5 个真正能改变路径的变量。

### 4.2 代理与时钟

代理须说明对应边、机制、失效条件和判断折扣。产业链图、行业分类、口头判断和单方宣传默认不能作为关键边直接代理。

相关时钟（不得混用）：

`事件 → 决策 → 库存 → 合同重定价 → 排产/转换 → 认证/替代 → 交付 → 客户产销 → 收入/现金`

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中 B 后的动作 |
|---|---|---|---|---|
| 上游短缺、下游涨价 | 短缺沿链传导 | 下游自身需求/成本/投机 | 中间库存、合同、数量时点 | 不做单一上游归因 |
| 上游停产、下游出货稳 | 冲击尚未到达 | 缓冲吸收或依赖本就有限 | 库存覆盖、替代、依赖占比 | 保留时滞或不传导，不提前确认 |
| 受限进口降、国内升 | 替代路径成立 | 需求降、库存消化、转口 | 最终使用、认证、复购、贸易流 | 停止从进口降推出国产替代 |
| 上游涨价、公司利润改善 | 成本/价格传导 | 结构、汇率或其他业务 | 实现价、单位成本、利润桥 | 交给 BF-EE-01 |
| 全链交期拉长 | 核心瓶颈放大 | 物流、抢单或规格错配 | 瓶颈利用率、分规格交期 | 不确认总量结构性短缺 |
| 替代送样或获认证 | 路径正在改道 | 测试、双供或议价工具 | 批量、复购、份额、稳定交付 | 只确认阶段，不确认规模迁移 |

### 降级规则

- 必要关系不存在：依赖该关系的下游路径停止；
- 缓冲覆盖研究窗口：当前终点效果停止，保留后续监测；
- 替代已可用且覆盖关键需求：原路径降级或切换；
- 目标暴露不足：停止目标对象影响，可保留上游行业路径；
- 时间窗口不匹配：调整观察窗，不把“尚未体现”写成“不会传导”；
- 共同因素无法排除：条件式传导，不做净因果归因。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-VT-01.path_structure` | 起点/目标/源变量清楚；关键关系可追溯；最短充分链明确；至少一条失效条件 | 只形成关系待验证或候选路径 |
| `BF-VT-01.segment_pass_through` | 路径可用；至少一条决定性边有动态变化；识别主要缓冲/瓶颈/替代；变量与时滞清楚 | 只确认局部关系或状态 |
| `BF-VT-01.terminal_effect` | 关键边未被阻断；中间动态与目标状态交叉验证；比较竞争解释；暴露与承接满足 | 止于环节或条件式终点 |

### 6.2 组合与交接

供需起点接 BF-SD-01；价格接 BF-PC-01；政策接 BF-PI-01；宏观接 BF-MF-01；结构/利润池接 BF-IC-01；公司兑现接 BF-EE-01；预测接 BF-FS-01；预期接 BF-EG-01；估值接 BF-VA-01。可合理止于 `path_structure` 或 `segment_pass_through`。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 决定性边至少有一个直接来源，或两个独立高质量来源；
- 跨两级以上至少验证一个中间动态节点；
- 目标与起点对象、业务时间可对齐；
- 替代路径验证兼容、认证、产能或规模交付中的相关门槛；
- 代理须写明机制、失效条件与判断折扣；
- 止于行业状态时，不为公司、预期、估值提前收全套证据。

具体来源与验收由90_compat/methods/03_取证管理。

### 7.2 本体边界

优先引用一级本体已定义的对象、稳定关系与动态能力。依赖强度、吸收能力、替代准备度、分路径传导等无正式定义时，在任务视图记为候选或缺口，不得仅用“相关、影响、受益”视为已覆盖。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 重点检查 | 是否裁出最短充分链；决定性边是否被误假定；公司兑现是否被过早写入 |
| 经验沉淀 | 行业特有节点优先进入行业框架或场景卡 |

框架更新目标是提高路径识别和裁剪能力，不是把产业链知识写全。

## 8. 验收检查

- [ ] 判断权与下游交接清楚；
- [ ] 只选一条主路线，最多一条竞争路线；
- [ ] 主路径通常 3—6 节点、1—2 条决定性边；
- [ ] 真实依赖与概念邻近、缓冲吸收与路径阻断已区分；
- [ ] 数量/价格/成本/交期未混成单一影响；
- [ ] 竞争解释会产生不同可观察预测；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 没有从概念邻近直接推出公司受益或估值结论。
