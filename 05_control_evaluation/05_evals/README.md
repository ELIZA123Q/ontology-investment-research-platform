# Evals

这里回答「结果到底好不好、有没有价值」。Eval 评价研究质量、遗漏、决策帮助和相对基线；它不处理 schema、来源存在性或可解析性等确定性问题。

| 区域 | 内容 |
|---|---|
| `protocols/` | 评测规则、聚合口径与验收手册 |
| `cases/` | 冻结的评测案例与消融材料 |
| `runners/` | 执行器、指标、校准与测试 |
| `reports/` | 评测产出与审计报告 |
| `decision_logs/` | 对外宣称前的硬门与决策记录 |
| `stress_tests/` | 第二领域压力测试 |
| `experience/` | 研究员体验基线 |
| `rubrics/` | 人类可读的研究质量标准 |

机器可判定的检查见 [`../04_verifiers/`](../04_verifiers/README.md)。未满足案例冻结、对照、独立裁决和样本门槛前，不得把预检或单次运行写成已证明的流程增益。
