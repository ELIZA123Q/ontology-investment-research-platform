# 研究质量 Rubric

Eval 回答「结果到底好不好、有没有价值」。它在冻结的案例、基线、评测协议和独立裁决条件下，评价研究质量、遗漏、决策帮助与相对价值；不是字段或 schema 校验。

研究员可用以下五项自检：

1. 问题有没有被偷换：对象、时间、范围与用途仍是原问题。
2. 有没有判断价值：识别关键分歧、主导机制与竞争解释，而非材料堆砌。
3. 证据有没有越权：重要观点不超过证据允许的强度，并处理反证与限制。
4. 读者能不能直接用：判断、依据、边界与下一步跟踪清楚可见。
5. 证据不足时有没有硬撑：清楚的「暂不可判断」可以是高质量结果。

这些项目必须结合案例、对照和评测协议解释；不能由 Verifier 的通过状态自动推出。

## Runtime 过程自检

以下原则可以在研究过程中提示返工，但不是硬性生成模板，也不产生综合分：

- **不偷换问题**：对象、时间、范围与用途始终对齐研究目标。
- **有判断价值**：说清分歧、主导机制和竞争解释，而不是材料堆砌。
- **证据不越权**：观点强度不超过 EvidenceFact 与反证能够支持的边界。
- **读者可使用**：无需阅读内部 YAML，也能理解判断、依据、限制和下一步。
- **不足时不硬撑**：证据不足时明确「暂不可判断」。

确定性发布条件见 [`../../04_verifiers/deterministic_release_standard.md`](../../04_verifiers/deterministic_release_standard.md)。运行时专业纪律诊断只用于定位缺口，不代表 R、U、delta、S、C 或研究增益已经通过。
