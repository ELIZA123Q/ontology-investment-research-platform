# 研究质量 Rubric

Eval 回答「结果到底好不好、有没有价值」。它在冻结的案例、基线、评测协议和独立裁决条件下，评价研究质量、遗漏、决策帮助与相对价值；不是字段或 schema 校验。

研究员可用以下五项自检：

1. 问题有没有被偷换：对象、时间、范围与用途仍是原问题。
2. 有没有判断价值：识别关键分歧、主导机制与竞争解释，而非材料堆砌。
3. 证据有没有越权：重要观点不超过证据允许的强度，并处理反证与限制。
4. 读者能不能直接用：判断、依据、边界与下一步跟踪清楚可见。
5. 证据不足时有没有硬撑：清楚的「暂不可判断」可以是高质量结果。

这些项目必须结合案例、对照和评测协议解释；不能由 Verifier 的通过状态自动推出。
