# 研究质量原则（参考自检，非生成约束）

研究质量是否成立仍须按 Eval 协议与案例评估；确定性发布条件见 [`../../04_verifiers/deterministic_release_standard.md`](../../04_verifiers/deterministic_release_standard.md)。本卡仅作研究过程中的参考原则，不是硬性生成约束。

## 五项原则

1. **不偷换问题** — 对象、时间、范围、用途对齐 01；研究过程中始终回答原问题。
2. **有判断价值** — 说清分歧、主导机制、竞争解释；言之有物，不是材料堆砌。
3. **证据不越权** — 观点强度不超过证据能支撑的档位；反证与限制如实处理。
4. **读者可使用** — 不读 YAML 也能看懂当前判断、依据、边界和下一步。
5. **不足时不硬撑** — "暂不可判断"但边界清楚可以是高质量；硬编方向不是。

人话强度参考：J0 缺口 / J1 观察 / J2 有条件方向 / J3 较强方向 / J4 范围内可确认。
