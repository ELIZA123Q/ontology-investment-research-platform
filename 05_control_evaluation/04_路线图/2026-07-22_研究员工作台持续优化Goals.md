日期：2026-07-22  
状态：active

## Goal 2：建立研究员默认主线

优先级：P0  
状态：completed（2026-07-22）
目标：研究员不进入高级编辑、不阅读 YAML/JSON，也能从问题走到结论、边界和下一步。

验收标准：

1. 每个研究只有一个突出主动作：继续当前阶段、处理待审、补证或查看交付；同屏不出现多个同优先级入口。
2. 概览首屏在常见桌面高度内显示：当前结论、结论强度、最关键依据/缺口、下一步动作。
3. `JU/ER/EV/MA/RC` 等内部 ID 默认收进“审计详情”，主视图使用研究语言。
4. 结构页默认按“核心问题—关键判断—必要证据—反证/竞争解释”分层，不一次铺开完整关系图。
5. 研究项目库支持搜索、状态筛选、最近更新排序、归档；删除不是主要管理动作。
6. 用 3 个真实任务做可用性走查：首次使用者无需口头指导即可完成范围确认、结构审阅和证据处置。

2026-07-26 持续优化里程碑：建立统一的五阶段研究旅程契约，逐页声明阶段输出与研究员确认问题；范围、结构、证据、判断和交付输出页均可在原位完成确认，不再要求返回编辑器。以持久库真实记录走查草稿、待确认、证据待审、已确认、任务阻断、生成失败和完整交付状态；修复历史失败任务覆盖新状态、同一研究重复计入待处理、失败入口指向无恢复信息页面等跨状态问题。默认页清理 `J0/J3`、`source_claim`、worker、HTTP/模型错误和对象 ID，结构必要证据与历史来源变化按研究语义去重、聚合。`research_journey.test.ts` 固化五阶段输出/确认契约，任务状态、研究员文案和阶段投影回归覆盖历史任务去重、错误恢复、结构信息去重与证据缺口优先级。

## Goal 3：把证据台变成日常研究驾驶舱

优先级：P0  
状态：completed（2026-07-22）
目标：研究员围绕“判断缺什么”工作，而不是围绕来源列表或系统对象工作。

验收标准：

1. 每个判断单元显示最低证据组合、当前覆盖、最薄弱环节、反证覆盖和可达到的最大 J。
2. 缺口按“阻断主判断 / 限制强度 / 仅补充”分级，默认先处理边际价值最高的 3 项。
3. 来源卡明确区分线索、已抓取正文、已核验引文、已形成 EvidenceFact 四个状态。
4. AI 可提出补证建议并执行公开来源取得，但任何事实进入判断前保留对象级人工确认。
5. 重复来源、同源转载和同一 source_group 不被误计为独立证据。
6. 证据更新能生成局部重算计划，并向研究员解释“哪些判断需要重看、为什么”。

验收证据：`source_coverage.test.ts` 覆盖未核验来源排除、同一 `source_group` 去重、反证缺口和来源四态前置条件；`evidence_review_assist.test.ts` 覆盖缺口优先级；`market_radar.test.ts` 与 `change_set.test.ts` 覆盖可达后代失效、局部 patch 边界和稳定对象不误失效。当前全量 45 个测试文件、200 项测试、类型检查和生产构建通过。

## Goal 4：让 AI 能持续、可恢复地执行

优先级：P0  
状态：completed（2026-07-22）
目标：长时间取证与分阶段生成不依赖单个 HTTP 请求或单个 Next.js 进程存活，失败后可从检查点恢复。

验收标准：

1. 用持久化 job 表记录任务、阶段、状态、租约、心跳、重试次数、预算、输入 artifact/hash 和输出 artifact。
2. 独立 worker 领取任务；进程重启后，过期租约可安全回收，旧 worker 不能覆盖新结果。
3. 每个阶段支持 `queued/running/waiting_for_review/waiting_for_input/retrying/blocked/completed/cancelled`，并提供研究员可读原因。
4. 自动执行只跨越确定性步骤；范围确认、证据事实批准、判断批准和发布保持人工门。
5. 每个 run 有最大轮数、最大来源数、最大 token/金额、硬超时和停止规则；达到上限时生成缺口说明，不无限循环。
6. 支持“继续到下一个人工门”的一键运行，而不是要求研究员逐阶段点击生成。
7. 有故障注入测试覆盖：模型超时、网络失败、进程重启、重复投递、取消与租约竞争。

建议状态机：

```text
研究问题
  → 自动形成范围草稿
  → [人工确认范围]
  → 自动生成结构 + 结构自检
  → [人工确认结构]
  → 多轮取证/覆盖评估/停止规则
  → [人工确认事实与缺口]
  → 自动裁决 + 确定性规则 + 独立审阅
  → [人工确认判断]
  → 自动生成研究稿与审计索引
  → [人工确认交付]
```
