# 研究能力与模板

| 文件或目录 | 用途 |
|---|---|
| [`capabilities.yaml`](capabilities.yaml) | 可调用能力及输入、输出约束 |
| [`logics.yaml`](logics.yaml) | 能力之间的候选依赖，供规划器编译任务 DAG |
| [`data_sources.yaml`](data_sources.yaml) | 数据源能力及使用边界 |
| [`报告模板/`](报告模板/) | 报告投影结构，不取代证据或审批 |

机器执行门槛由[研究规则](../研究规则/README.md)裁决；研究方法的选择与解释见[研究方法](../研究方法/README.md)。修改能力定义后运行根目录 [README](../README.md) 中的校验与测试。
