# 独立语义审查

## 触发条件

- 全部阶段（01-05）：作为独立审查者检查每个阶段的产出
- 每个阶段均有对应的审查清单
- 不要与 producer 使用同一模型

## 审查维度（按阶段）

### 阶段通用审查（5项）
1. **生产者−审查者分离：** 是否使用不同模型
2. **本体一致：** 主张是否违反本体的"必须为真"约束
3. **断言绑到来源：** 每条断言是否有 evidence_id 或 claim_id
4. **高宽门：** 格式/完整性是否满足最低门
5. **撤消完整性：** 是否可从当前状态独立重建

### Stage05 专项审查（10项）
1. **等级一致性：** 表达强度是否 ≤ J/J 许可范围
2. **逻辑一致性：** 内部无自相矛盾
3. **反证收束：** 反证有对应回应
4. **预测边界：** 预测声明了不确定性
5. **投资建议合规：** 无越界建议
6. **角色与资格合规：** 如适用，含执业资格交叉检查
7. **关系审计：** 判断单元间关系未断裂
8. **跳步检测：** 无中间缺失步骤
9. **定调审计：** 基调未偏向极端心理
10. **假设有效性：** 假设在合理范围内

## 核心约束

- **审查者不得与生产者使用同一模型**
- 审查报告绑定到具体判断单元和阶段
- 发现缺陷标记严重程度与建议修正方向
