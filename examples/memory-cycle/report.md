# 存储芯片周期研究

总体判断等级：J2

## 核心判断

- **J2**：存储行业仍受供给约束，但 HBM、服务器 DRAM 与 NAND 已进入内部高位分化，不能生成统一的高位消化阶段标签。
- **J2**：AI 服务器和 HBM 需求支持结构性偏紧方向
- **J1**：HBM 晶圆和封装挤占支持通用 DRAM 供给约束解释
- **J2**：企业级 SSD 支撑 NAND 上行但消费端形成削弱
- **J2**：服务器 DRAM 涨价斜率放缓且部分美国 CSP 库存累积，只支持服务器 DRAM 高位消化观察。
- **J1**：2027H2 至 2028 只能作为条件式缓解窗口
- **J0**：不能确认三类产品统一结束日
