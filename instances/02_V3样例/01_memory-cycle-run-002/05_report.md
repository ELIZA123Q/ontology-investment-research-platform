# 存储周期：库存去化延续，全面上行仍待价格确认

## 研究问题

1. 库存是否连续下降且口径可比？
2. 库存下降是否伴随价格企稳，而非仅由供给收缩造成？
3. 库存下降中需求修复贡献是否可确认？

## 主要判断

**库存状态（J3）**

多个独立口径共同指向库存持续去化。该判断仅回答“方向是否在改善”，不输出绝对库存水平。

**周期阶段（J2）**

行业已进入去库后段，但有三条边界同时存在：

- 合约价格跌幅虽收窄，尚未转正；
- 现货价格仍在下跌，与合约口径形成未解决冲突；
- 供给纪律仍能解释部分库存改善，竞争解释尚未排除。

因此现阶段不足以确认全面上行。

**需求归因（不可判断）**

现有证据只能确认供给端对库存下降可能有贡献。由于缺少与库存主体口径对齐的终端 OEM 出货或补库直接序列，**不能确认需求修复贡献**，也不应强行给出归因结论。

## 证据结构

- **支持**：厂商+渠道库存下降（EV-01）；合约价格跌幅收窄（EV-02）
- **反证**：供给纪律仍解释部分去化（EV-03）
- **冲突**：合约跌幅收窄 vs 现货继续下跌（EV-02 / EV-05，CF-01）
- **缺口**：终端 OEM 出货/补库序列缺失（EG-01，ER-06 unmet）

## 失效条件与增量更新

周期阶段判断（C-02）在以下情况失效或需重算：

- 合约价格跌幅重新扩大
- 库存重新累积
- 现货与合约同向确认全面上行

增量演练（`incremental_update.yaml`）：当 EV-04「7 月合约价格跌幅重新扩大」进入后，只需重算 JU-02 相关链（含 EA-02 评估失效 → RE-02 → C-02 → EX-02），**JU-01 库存判断与 JU-03 不可判断结论保持 current**，无需全量重跑。
