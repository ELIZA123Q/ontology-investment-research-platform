# 表达审计技能集

## 触发条件

- 处理 Stage05 表达与交付任务
- 检查研究报告是否符合表达规范
- 需要审计表达强度是否超出判断等级许可
- 关键词：表达审计、等级一致性、禁词、无支撑新观点、反证完整性

## 核心原则

**表达不超出判断的许可范围。** 05 是对 04 判断的叙述转化，不是新增判断。

## 组成文件

| 文件 | 职责 |
|------|------|
| `expression_audit.ts` | 表达审计主逻辑：EX→C 映射完整性、等级一致性（J0-J4 → 允可表达范围）、禁止措辞、反证完整性、11类校准缺陷分类 |
| `readable_markdown.ts` | 可读 Markdown 生成：结构化叙述格式化、内联审计详情剥离 |
| `text_quality.ts` | 文本质量检测：可读证据文本判定 |

## 等级→表达范围映射（来源：judgment_threshold_policy.yaml）

| 等级 | 允许 | 禁止 |
|------|------|------|
| J0 | 只说明缺口，不形成方向 | 方向性判断、预测、展望、建议 |
| J1 | 只作事实观察或线索 | 方向性判断、预测、趋势 |
| J2 | 保留条件的方向判断 | 确定性判断、确认、预测、建议 |
| J3 | 方向判断或高概率判断 | 目标价、评级、交易建议 |
| J4 | 在明确范围内形成确认判断 | 目标价、评级、交易建议 |

## 使用流程

1. 加载 04 判断简报与推理审计
2. 提取 05 研究报告中的主张（expression claims）
3. 执行 EX→C 映射（每个 expression 对应一个 04 claim）
4. 逐条检查等级一致性
5. 扫描禁止措辞与审计腔禁词
6. 检测无支撑新观点
7. 分类缺陷到 11 类校准维度

- 审计结果判定：pass / return_to_04 / return_to_05
