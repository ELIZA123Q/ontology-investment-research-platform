# 投研需求说明

## 1. 研究目标与核心判断问题

### 1.1 研究目标

识别全球存储芯片主要产品当前所处的供需、库存和价格周期阶段，并将“本轮周期什么时候结束”改写为可验证的条件式时间窗口，供行业跟踪和研究框架复盘使用。

### 1.2 核心判断问题

> 截至每次运行的数据截止时点，全球存储芯片中 HBM、非 HBM DRAM 与 NAND 分别处于什么供需与价格周期阶段；在未来 6—24 个月内，哪些需求、库存、有效供给、价格和产能信号将支持周期延续或表明周期转入见顶、正常化或下行？

HBM 属于 DRAM 内部的高端品类，但因其需求、晶圆占用、封装和合同机制显著不同，本次单独作为观察层；非 HBM DRAM 指除 HBM 外的 DRAM 产品线。

**研究类型：** 状态与趋势判断

## 2. 研究对象与判断起点

### 2.1 研究对象

| 对象 | 业务角色 | 与本次研究的关系 |
|---|---|---|
| HBM | AI 加速器高带宽内存 | 结构性需求、先进 DRAM 晶圆与封装瓶颈的主要来源；DRAM 内部高端品类，单独观察 |
| 非 HBM DRAM | 服务器、PC、手机等工作内存 | 观察 HBM 产能挤出、服务器需求和消费需求的综合周期 |
| NAND Flash | 企业级 SSD、客户端 SSD、手机存储等 | 观察 AI 存储需求、制程升级供给和消费需求的分化周期 |
| 存储芯片产业 | 产品集合与供需系统 | 形成总体判断时必须由三类产品分层汇总，不直接求平均 |

### 2.2 判断起点

从“当前状态与未来趋势”出发，核验最近可得的原厂经营数据、库存与价格变化、需求展望和新增供给时间表，不预设当前已经见顶或仍处早期。

## 3. 核心观察维度

| 观察维度 | 需要判断的变化 | 与核心问题的关系 |
|---|---|---|
| 终端需求 | AI 数据中心、通用服务器、PC、手机和汽车需求 | 区分结构性需求与消费需求走弱 |
| 订单与采购 | 长协、订单覆盖、提前采购、取消或延迟拉货 | 区分真实需求与重复下单/抢货 |
| 库存 | 原厂、渠道、OEM/客户库存及可用性 | 判断补库、去库和缓冲能力 |
| 有效供给 | 晶圆投入、产品组合、良率、先进封装、认证 | 判断名义产能何时转化为可交付供给 |
| 价格 | 合约价、成交/实现价格及涨幅斜率 | 定位涨价、放缓、见顶与下行阶段 |
| 资本开支与扩产 | 建设、设备搬入、试产、良率与量产时间 | 决定供给拐点和周期结束窗口 |

## 4. 初步关注线索

- HBM 对先进 DRAM 晶圆和封装产能的占用是否继续挤压非 HBM DRAM。
- AI 推理需求是否由 HBM 扩展到高容量 RDIMM 和企业级 SSD。
- 消费电子因价格上涨而下调配置和出货，是否足以形成需求破坏。
- 新厂与封装扩产的投产时间、良率和客户认证是否早于或晚于市场需求。
- “涨价幅度放缓”与“供需紧张结束”需要分开判断。

> 本节仅记录需求层面的初步线索，供 02 梳理判断结构时参考；不是正式判断路径、路径节点或本体映射。

## 5. 研究范围与边界

| 范围 | 本次约定 |
|---|---|
| 时间 | 每次运行回看最近六个完整季度，判断截至运行时点的状态；前瞻 6—24 个月 |
| 地域 | 全球供需；对 DRAM/HBM 重点观察主要 DRAM 原厂，对 NAND 补充主要 NAND 原厂及企业级 SSD 供应链；辅以主要云/服务器和消费终端 |
| 产业链 | 从终端需求、订单与库存，到晶圆制造、先进封装、产品供给和价格 |
| 对象 | HBM、非 HBM DRAM、NAND；必要时拆分服务器与消费应用 |

**不纳入本次研究：**

- 个股估值、股价是否已反映、买卖建议或目标价；
- NOR Flash 等利基存储的独立周期判断；
- 未经公开来源验证的客户订单和渠道传闻。

## 6. 初步线索：验证与反证关注点

| 类型 | 需求层面需关注的情况 | 说明 |
|---|---|---|
| 关注方向 | 原厂库存低、合约价和实现价上行、长协锁量、交期拉长 | 可能支持供给紧张和上行延续 |
| 关注方向 | HBM/服务器内存需求扩张并挤占非 HBM 产品产能 | 可能形成结构性而非单纯补库周期 |
| 关注方向 | 新增洁净室、晶圆产能和先进封装在 2027—2028 年转为合格供给 | 可能触发周期正常化 |
| 关注方向 | PC/手机配置下调、终端出货走弱、订单取消或库存上升 | 可能造成需求破坏并提前结束周期 |
| 关注方向 | HBM 多供格局、良率提升和代际切换 | 可能缓解单品紧缺，也可能因更大 die 与容量继续挤压 DRAM 产能 |

> 本节仅说明哪些信息方向可能影响判断，供 02 设计验证与反证框架时参考；不是证据规则、取数要求或证据准备清单。
