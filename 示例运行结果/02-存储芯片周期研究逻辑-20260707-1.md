# 存储芯片周期研究逻辑

> 本文档说明本次问题应该怎么分析、为什么这样拆解、需要什么证据，以及什么情况会削弱、阻断或替代主判断。正式本体 ID、路径节点、实例需求 ID 和证据要求 ID 保存在配对本体视图 YAML 中；正文不写成技术字段说明。

## 1. 研究问题与判断边界

### 1.1 核心问题

> 截至每次运行的数据截止时点，全球存储芯片中 HBM、非 HBM DRAM 与 NAND 分别处于什么供需与价格周期阶段；在未来 6—24 个月内，哪些需求、库存、有效供给、价格和产能信号将支持周期延续或表明周期转入见顶、正常化或下行？

### 1.2 判断落点

| 项目 | 本次取值 |
|------|----------|
| 判断落点 | 状态定位 / 阶段切换 |
| 主任务类型 | 状态与趋势判断 |
| 研究用途 | 行业跟踪、假设验证、进入 03/04 |
| 04 最终需要回答 | 分产品当前怎么看、为什么、下一步看什么，以及哪些信号触发改判 |

### 1.3 判断脊柱

本次需要区分 AI/HBM 拉动的结构性紧张、通用产品被动紧缺、消费端削弱和新增合格供给缓解窗口，而不是把存储芯片写成一个统一周期。

### 1.4 本次研究范围

| 维度 | 本次边界 | 是否来自 01 | 备注 |
|------|----------|-------------|------|
| 时间 | 回看最近六个完整季度，前瞻 6—24 个月 | 是 | 由 03 按执行日解析 |
| 地域 | 全球供需 | 是 | 公司披露只作证据来源，不做个股判断 |
| 对象 | HBM、非 HBM DRAM、NAND | 是 | 机制不同，必须分层 |
| 产业链 | 终端需求—订单库存—有效供给—价格 | 是 | 不延伸到证券定价 |
| 不判断事项 | 评级、目标价、收益率、仓位 | 是 | 04 合规约束 |

## 2. 最小问题树与分析顺序

### 2.1 总体拆解

```text
终端需求
→ 订单质量和库存缓冲
→ HBM / 非 HBM DRAM / NAND 有效供给
→ 价格与涨幅斜率
→ 新增合格供给或需求破坏
→ 高位正常化、见顶转弱或下行
```

### 2.2 最小问题树

| question_id | 子问题 | 与总判断的关系 | 判断顺序 | 失败后的处理 |
|-------------|--------|----------------|----------|--------------|
| Q-01 | AI/服务器和消费终端需求是否分化 | precondition | 1 | 保留竞争解释 |
| Q-02 | 订单和库存是否支持可兑现需求 | precondition | 2 | 降级或停止 |
| Q-03 | 有效供给和产能是否真实紧张 | parallel | 3 | 转入新增供给解释 |
| Q-04 | 价格事实和斜率对应哪个阶段 | outcome | 4 | 条件化表达 |
| Q-05 | 新增合格供给和需求破坏何时触发正常化 | competing | 5 | 只能输出窗口和闸门 |

## 3. 主路径、反证和竞争解释

### 3.1 主路径

```text
AI/HBM 与服务器需求增强
→ 长协、订单和有效供给紧张
→ HBM 挤占和通用 DRAM / NAND 分化
→ 价格上行或高位维持
→ 新增合格供给或需求破坏决定结束窗口
```

### 3.2 削弱、阻断和竞争解释

| 类型 | 内容 | 如何区分 | 对 04 的影响 |
|------|------|----------|--------------|
| 削弱条件 | 消费端出货和配置下调 | 终端销量、配置、渠道库存 | 降级为分化判断 |
| 阻断条件 | 多层库存累积、订单取消或可切换产能充足 | 库存天数、取消率、交期、实际供给 | 路径停止或暂不可判断 |
| 竞争解释 | 涨价来自产品组合、抢货或短期供给扰动 | 同口径价格、实际拉货、库存层级 | 降低置信度或条件化 |

| 对象/环节 | 为什么需要单独判断 | 关键变量 | 可合并判断吗 | 合并或拆分依据 |

| NAND | 企业级 SSD 与消费端方向可能相反 | 企业级需求、客户端需求、价格 | 否 | 应用结构不同 |
