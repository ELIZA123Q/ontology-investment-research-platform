# 存储芯片周期研究逻辑

> 本文档说明本次问题应该怎样分析、为什么这样拆解、需要什么证据，以及什么情况会削弱或推翻判断。正式本体 ID、路径节点、实例需求 ID 和证据要求 ID 保存在配对的本体视图 YAML 中。

## 1. 研究问题与判断边界

### 1.1 核心问题

> 截至每次运行的数据截止时点，全球存储芯片中 HBM、非 HBM DRAM 与 NAND 分别处于什么供需与价格周期阶段；在未来 6—24 个月内，哪些需求、库存、有效供给、价格和产能信号将支持周期延续或表明周期转入见顶、正常化或下行？

HBM 属于 DRAM 内部的高端品类，但因其需求、晶圆占用、封装和合同机制显著不同，本次单独作为观察层；非 HBM DRAM 指除 HBM 外的 DRAM 产品线。

### 1.2 本次真正要辨别的判断矛盾

同一时间内，HBM 可能因 AI 与先进封装约束保持结构性紧张，非 HBM DRAM 可能因 HBM 挤占晶圆投入而被动紧缺，NAND 则可能由企业级 SSD 拉动、但同时受消费需求走弱约束。因此，必须区分“终端真实需求还是抢货补库”“名义扩产还是合格有效供给”“涨价斜率放缓还是供需周期结束”“局部产品紧缺还是全行业同步紧缺”。

### 1.3 本次研究范围

| 维度 | 本次边界 |
|---|---|
| 时间 | 每次运行以数据截止时点为锚点，回看最近六个完整季度；前瞻未来 6—24 个月。若作为 2026-07-03 示例运行，则回看 2025Q1—2026Q2，前瞻至 2028H1。 |
| 地域 | 全球供需 |
| 对象 | HBM、非 HBM DRAM、NAND；对 DRAM/HBM 重点观察主要 DRAM 原厂（Samsung、SK hynix、Micron），对 NAND 补充主要 NAND 原厂（含 Kioxia、Western Digital、Solidigm、YMTC 等）及企业级 SSD 供应链；辅以云厂商/服务器客户和消费终端应用 |
| 产业链 | 终端需求—订单/库存—晶圆/封装有效供给—价格；不延伸到证券定价 |
| 不判断事项 | 个股收益、目标价、仓位；NOR 等利基产品的独立周期 |

## 2. 本问题的分析主线

### 2.1 总体拆解

先按产品拆分，再用同一组需求、订单库存、有效供给和价格信号定位当前阶段；随后核验新增供给、良率认证和需求破坏两类结束机制。周期结束必须由价格、库存、交期和供需条件共同确认，不能由单一涨幅放缓推断。

```text
AI/服务器与消费终端需求
→ 订单质量、补库行为与多层库存
→ HBM / 非 HBM DRAM / NAND 有效供给与产能挤出
→ 合约/实现价格及涨幅斜率
→ 新增合格供给或需求破坏
→ 高位正常化、见顶转弱或下行
```

### 2.2 判定顺序

1. 先确认产品、应用和价格口径，避免把 HBM 与非 HBM DRAM、合约价与现货价混为一谈；
2. 再验证需求是否由真实使用和长期采购支持，并检查提前采购、重复下单和库存；
3. 再比较有效供给、产能利用、良率、封装和新增产能时间；
4. 最后用价格斜率、库存回补、供给释放和需求破坏共同判断拐点窗口。

## 4. 关键判断

### 4.0 周期阶段判定口径

本次不直接判断“好”或“差”，而是将每个产品线归入以下阶段之一。本表是 04 对各产品线的阶段归类框架，不是 03 的证据清单。

| 阶段 | 基本含义 | 典型条件 |
|---|---|---|
| 紧缺上行 | 需求强于有效供给，价格和交期继续上行 | 需求强、库存低、交期拉长、价格持续上涨 |
| 加速上行后段 | 价格仍涨，但涨幅可能接近高点 | 价格涨幅高，但部分需求或采购开始承压 |
| 高位正常化 | 供需仍不宽松，但价格涨幅放缓、交期改善 | 价格继续高位但边际趋稳，库存开始修复 |
| 见顶转弱 | 需求或订单走弱，价格上行动能不足 | 库存回升、订单取消、价格涨幅明显收窄 |
| 下行 | 供给超过需求，价格和稼动率下行 | 库存累积、价格下跌、产能利用率下降 |
| 证据不足 | 关键证据缺失或互相矛盾 | 不能形成方向性判断 |

操作规则：

- 三类产品分别独立判定阶段，不得共用一个阶段标签。
- 阶段由需求、库存、有效供给、价格和交期等指标组合判定；单一价格或单一库存信号不足以定阶段。
- 判断一负责当前阶段归类；判断二主要识别「加速上行后段」与「高位正常化」的领先信号；判断三主要识别「见顶转弱」与「下行」及结束窗口。

### 判断一：三类产品当前处于什么周期阶段

- **要判断的小问题：** HBM、非 HBM DRAM、NAND 的需求、订单库存、有效供给和价格是否共同指向 4.0 所列阶段之一？
- **为什么重要：** 这是回答“目前处于什么周期”的直接前提。
- **分析逻辑：** 产品分层后，先看真实终端与服务器需求，再看订单和库存，再看有效供给，最后用合约/实现价格交叉确认，并按 4.0 归类。
- **关键变量：** 终端需求强度、订单能见度、库存周期位置、供给可得性、产能紧张度、产品价格压力。
- **支持条件：** 需求和订单有实际部署/交付支持，原厂库存低，产能/交期紧张，合约或实现价格持续上行。
- **削弱或阻断条件：** 订单主要来自抢货或重复下单；终端出货下修；库存快速累积；价格仅为报价而无成交兑现。
- **替代解释：** 产品组合升级或币种变化造成表观 ASP 上升；物流而非产能造成交期拉长。
- **前置判断：** 无。
- **最低证据需求：** 至少一条需求端、一条订单/交付、一条库存/替代供应、一条有效产能或交期、一条合约或实现价格证据，并明确业务时间。

### 判断二：涨价斜率何时先放缓

- **要判断的小问题：** 当前极高的季度价格涨幅是否已接近斜率峰值，即使绝对价格仍继续上涨？
- **为什么重要：** 涨幅放缓通常早于供需完全正常化，是周期从「紧缺上行」或「加速上行后段」转向「高位正常化」的领先信号。
- **分析逻辑：** 比较连续季度的合约/实现价格变化，结合长协价格机制、客户配置下调和采购行为判断边际变化。
- **关键变量：** 产品价格压力、定价权、订单能见度、库存缓冲能力。
- **支持条件：** 下一季度涨幅指引明显低于前季，采购量或配置因成本下降，价格仍涨但增速递减。
- **削弱或阻断条件：** 供给进一步收缩、HBM 挤占加剧、客户以长协锁量且接受更高价格。
- **替代解释：** 产品组合或年度合同重定价导致季度价格暂时失真。
- **前置判断：** 判断一中的价格与供给节点具备可用证据。
- **最低证据需求：** 连续两个以上价格时点、原厂实现价/ASP 变化或明确下一季指引，并有需求/供给证据解释。

### 判断三：供需紧张何时实质结束

- **要判断的小问题：** 未来 6—24 个月，新增合格供给是否会超过结构性需求增量，或需求破坏是否会使订单和库存先转弱？
- **为什么重要：** 这是回答“本轮周期什么时候结束”的核心，但只能给条件式窗口。
- **分析逻辑：** 将洁净室/晶圆和封装扩产的投产时间，依次经过设备、试产、良率和客户认证，再与 HBM/服务器/企业 SSD 需求及消费需求破坏比较；识别「见顶转弱」与「下行」的实质条件。
- **关键变量：** 产能扩张进展、良率成熟度、供给响应弹性、供给可得性、产能紧张度、终端需求强度、产品价格压力。
- **支持条件：** 新增供给在前瞻窗口内形成稳定量产，库存和交期同步正常化，价格由上涨转为平稳或下降。
- **削弱或阻断条件：** 扩产延迟、良率/认证失败、HBM 单位晶圆占用继续提升、AI 需求再上修。
- **替代解释：** 消费需求破坏可在新增供给到来前使非 HBM 产品先见顶转弱，但 HBM 仍保持独立上行。
- **前置判断：** 判断一确认当前确有供给紧张；判断二用于识别领先拐点。
- **最低证据需求：** 主要原厂扩产时间表、至少一项良率/量产验证、需求增量或订单证据、库存/交期和价格连续观测。

## 5. 主逻辑、反向逻辑与竞争解释

### 5.1 主逻辑路径

```text
AI 基础设施与服务器需求增强
→ HBM、高容量 DRAM、企业 SSD 订单增长
→ HBM 晶圆/封装及服务器产品优先分配挤压非 HBM 供给
→ 原厂库存低、供给可得性下降、产能紧张
→ 合约/实现价格上行且定价权增强
→ 直至新增合格供给释放或需求被高价破坏
```

### 5.2 削弱或阻断路径

```text
PC/手机出货与配置下调、订单取消或客户库存回升
→ 订单能见度下降
→ 产能紧张度缓解
→ 价格涨幅先放缓，随后绝对价格见顶转弱

新厂/封装扩产完成但良率或认证未通过
→ 名义产能不能转化为有效供给
→ 周期结束时间推迟
```

### 5.3 竞争解释

| 竞争解释 | 与主逻辑如何区分 | 需要的辨别证据 | 影响的关键判断 |
|---|---|---|---|
| 抢货/提前采购而非终端增长 | 订单强但终端使用、出货或部署不跟随，客户库存上升 | 终端部署、客户库存、取消单 | 判断一、三 |
| 产品组合升级造成 ASP 上涨 | 同规格合约价涨幅弱于公司 ASP | 同代际合约价与 bit shipment | 判断一、二 |
| 短期物流或事故造成紧张 | 设施产能和利用率并不紧，交期随事件快速恢复 | 产能、利用率、交期与恢复时间 | 判断一 |
| 消费需求破坏先于供给释放 | PC/手机出货、配置和采购先下降 | 终端出货、配置、订单和库存 | 判断二、三 |
| HBM 多供与良率改善缓解局部紧缺 | 通过认证的供应商增加，合格供给增速超过需求 | 认证、量产、良率和交付 | 判断三 |

## 6. 对象、时间与情景差异

| 拆分维度 | 为什么必须拆分 | 分组或阶段 | 对分析路径的影响 |
|---|---|---|---|
| 产品 | 需求、晶圆占用、封装、合同和客户不同 | HBM / 非 HBM DRAM / NAND | 分别判定周期，不做简单平均 |
| 应用 | AI/服务器强而消费电子可能受价格抑制 | 数据中心 / PC手机 / 汽车工业 | 决定需求是真实扩张还是被高价破坏 |
| 时间 | 价格斜率、供需状态和新增供给时点不同 | 近端 / 中端 / 远端前瞻窗口（相对数据截止时点；示例运行对应 2026H2 / 2027H1 / 2027H2—2028H1） | 先看斜率，再看供需实质反转 |
| 情景 | 扩产良率与 AI 需求存在较大不确定性 | base / upside / downside | 形成条件式结束窗口 |

## 7. 证据计划与判断作用

### 7.1 证据口径要求

1. **价格证据**必须区分合约价、现货价、原厂 ASP、第三方价格调查（如 TrendForce/DRAMeXchange）和实现价，不得直接混用。
2. **需求证据**必须区分终端出货、客户资本开支、订单锁量和提前采购。
3. **供给证据**必须区分名义产能、晶圆投入、良率、认证通过和实际交付。
4. **库存证据**必须区分原厂库存、渠道库存和客户库存。
5. 所有证据必须保留**业务时间**，不得只记录发布日期。

### 7.2 证据不足时的处理

- 若某一产品线缺少价格、库存、有效供给或需求中的关键证据，不得输出强方向性结论，只能输出「证据不足」或带明确限定的「倾向性判断」。
- 若证据只覆盖 HBM、非 HBM DRAM、NAND 中的一部分产品，不得外推为整个存储芯片周期。
- 若价格证据与库存/供给证据方向冲突，优先降级为「分化」或「待验证」，不得直接判定周期结束。

### 7.3 证据计划与判断作用

| 关键判断 | 最低必要证据 | 优先来源类型 | 关键反证 | 证据如何改变判断 |
|---|---|---|---|---|
| 当前周期阶段 | 原厂订单/出货、库存、有效供给/交期、合约或实现价格（口径见 7.1） | 原厂财报、行业价格调查 | 终端走弱、重复下单、库存上升 | 同向则增强；分化则按产品拆分或降级 |
| 涨价斜率 | 连续季度同口径价格和下一季价格指引 | 原厂经营数据、合约价调查 | 年度合同或产品组合失真 | 涨幅递减只支持「加速上行后段」或「高位正常化」，不直接判周期结束 |
| 供需结束窗口 | 新厂/封装扩产、良率认证、需求与库存/交期 | 原厂 10-Q/公告、行业调查 | 扩产延期、需求再上修 | 供给与库存价格共同正常化才支持「见顶转弱」或「下行」 |
