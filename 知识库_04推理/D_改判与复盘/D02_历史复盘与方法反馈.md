# D02 历史复盘与方法反馈

## 复盘定位

复盘先保留轻量框架，不急于沉淀普遍规律。没有足够历史样本时，只记录案例和候选改进，不修改稳定方法。

复盘必须先区分“结论后来是否命中”和“当时判断是否合规”。结果未命中不等于方法错误，结果命中也不能证明当时推理合规。

## 复盘六问

1. 当时基于可见信息预期什么；
2. 后来在哪些对象和时点实际发生什么；
3. 哪个信号有区分力，哪个只是噪声或滞后确认；
4. 错误来自结构、证据、口径、机制、时滞、外推还是竞争解释；
5. 应反馈到 02、03、04、正式本体还是 05；
6. 相同问题是否已在多个独立任务重复。

## 六类复盘结果

| 复盘类型 | 含义 | 默认反馈 |
|---|---|---|
| 合理未命中 | 当时输入、证据和裁决均合规，但随机结果未发生或外部条件后来改变 | 不改方法，记录条件变化与可校准性 |
| 过早确认 | 领先信号、条件路径或代理被写成已发生/已兑现结果 | 反馈 A/B 的路径验证和输出上限 |
| 关键变量遗漏 | 02 未定义决定性变量、必要中介、时滞或阻断点 | 返回 02；稳定重复后形成框架/本体候选 |
| 证据误用 | 来源、口径、代理、独立性、权限或时点不合格 | 返回 03 |
| 裁决错误 | 证据合格，但反证、时滞、路径状态或竞争解释处理错误 | 返回 04 对应 A/B/C/D 方法 |
| 表达放大 | 判断本身合规，但 05 删除条件、范围、等级或限制 | 返回 05 |

## 最低复盘记录

```text
原判断及当时版本
→ 当时可见证据与证据上限
→ 原判断在当时是否符合方法
→ 后来结果是否命中、何时命中
→ 错误或条件变化发生在哪个环节
→ 是否属于跨任务重复问题
→ 本次是否修改稳定方法及理由
```

不得用事后才出现的信息改写原判断的当时版本，也不得只按盈亏或方向命中率评价方法。

## 反馈去向

| 问题 | 返回位置 |
|---|---|
| 少了变量、路径或停止条件 | 02 |
| 来源、指标、证据组合或质量门槛有误 | 03 |
| 相同证据被反复错误处理，或路径/反证/竞争解释裁决有误 | 04 |
| 稳定对象、关系或正式规则缺失 | 本体候选 |
| 判断正确但表达误导 | 05 |

一次案例只形成候选；至少两个不同任务出现同类判断问题并通过研究员复核后，才修改稳定规则。重复标准按“同一错误机制”判断，不按题材、行业或结论方向表面相似判断。
