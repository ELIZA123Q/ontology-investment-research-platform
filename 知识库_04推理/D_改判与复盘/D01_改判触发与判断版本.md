# D01 改判触发与判断版本

## 改判是判断等级的状态迁移

每次判断都必须显式保留：

```text
上一版/初始 J 等级与置信度
→ 本次证据变化
→ 被命中的决定性前提、路径、反证、范围或窗口
→ 更新后 J 等级与置信度
→ 变化理由或维持理由
```

首次形成判断的初始等级记为 J0。03 给出新版证据的最高等级，04 只能在新上限内更新实际等级。新闻篇数、转载数量或同源材料增加不构成独立验证，不能自动升级。

## 改判与复盘的边界

改判回答“新信息出现后当前判断应变成什么”，不等于认定上一版推理错误。每次版本更新必须同时保留两个问题：

1. 当时可见信息下，原判断是否符合 01—04 的输入、证据和裁决规则；
2. 新信息是否改变了事实条件、证据上限、路径状态、竞争解释或投资窗口。

原判断在当时合规、后来因随机结果或条件变化未命中，属于 D02 的“合理未命中”，不自动修改方法；原判断当时已违反方法，才进入错误归因和方法反馈。

## 改判在首次形成判断时就写好

每个条件包含观察对象、变量、方向/门槛、时间窗口、优先来源和触发后的具体动作。“需求不及预期则下调”因没有基线、指标和窗口而不合格。

## 五种版本动作

| 动作 | 触发 | 版本处理 |
|---|---|---|
| 维持 | 决定性前提未变 | 更新依据与时点，不制造新观点 |
| 增强 | 中介和结果得到独立确认 | 提高强度，但不超过 03 新上限 |
| 削弱 | 幅度、持续性或部分对象受反证影响 | 降级或缩小范围 |
| 阻断 | 起点或必要条件失败 | 关闭相关路径和下游观点 |
| 改写 | 主因、阶段、对象或窗口实质变化 | 新建判断版本，说明替代关系 |

改判不能覆盖原判断。必须保留原时点可见证据、原结论、触发信号和变更理由，才能区分“条件后来变化”和“原推理本身错误”。

## 等级更新规则

| 证据变化 | 对等级的默认影响 |
|---|---|
| 新证据补齐决定性前提或关键中介，且来源独立 | 可升级，但不超过 03 上限 |
| 新证据只重复既有方向或属于同源转述 | 维持等级，可更新时点 |
| 新证据只影响幅度、持续性或部分对象 | 降低置信度，必要时降一级或缩小范围 |
| 反证命中决定性前提或必要路径 | 降至 J0/J1 或直接阻断，不得只写风险提示 |
| 支持与反证冲突且暂不可消解 | 状态记为 contested，强度上限为 J1 |

## 投资命题的双重更新

A10 输出需要同时监测两类变化：

1. **研究等级变化：** 基本面前提、传导、盈利影响或反证改变；
2. **投资性变化：** 即使研究判断不变，预期修订、价格与估值已反映、催化窗口过期或下行风险放大，也可使“形成投资命题”降为“观察”或“不形成”。

因此，“基本面判断继续成立”不等于“投资命题继续成立”。
