# A00-附录2 反证与竞争解释

凡要给出方向性判断，都按本附录处理反证、替代解释和材料冲突，并把结果写进「最强限制」。不要把反证全部塞进风险提示。

## 反证：先看打在哪，再决定怎么改

反证不一定推翻主判断。先看它打在：起点事实、决定性前提、中间传导、幅度或持续性、局部对象，还是背景解释。

| 打在哪里 | 默认怎么处理 |
|---|---|
| 起点事实或决定性前提 | 阻断 |
| 中间传导 | 降级，或改成有条件的判断 |
| 幅度或持续性 | 降低强度，或缩短窗口 |
| 局部对象 | 缩小范围，并保留分化 |
| 主因解释 | 改写，或与竞争解释并列 |
| 暂时分不清 | 保留争议 |

建议按五步走：它反驳的具体命题是什么 → 对象、时间、口径是否和主证据一致 → 03 允许用到多强 → 打掉的是必要条件还是只影响程度 → 处理后原判断具体改成什么。

“没找到支持材料”不是反证；真正相反、且质量合格的观测才是。

## 竞争解释：用同一张表比

多个原因都能解释同一现象时，对每个解释问同样的问题：

| 维度 | 要问什么 |
|---|---|
| 覆盖 | 能解释哪些核心现象，漏了什么 |
| 时序 | 原因是否先于结果，时滞是否合理 |
| 中介 | 有没有看到它特有的中间信号 |
| 分化 | 能不能解释高/低暴露对象的差异 |
| 反事实 | 原因变弱或不存在时，结果还会不会出现 |
| 假设负担 | 还要额外假设多少才能成立 |
| 证据直接性 | 关键前提有没有直接、独立支持 |

怎么收口：

- 区分信号明显更强：作为主解释；
- 不同解释各管不同对象或阶段：拆开适用范围；
- 多种机制共同作用：写清各自贡献方向，不伪造精确权重；
- 没有关键区分证据：保留争议，并给出下一观察窗口。

A05 归因、A04 替代机制比较，都用这张表。

## 材料看起来打架时

先分清是真冲突还是表面冲突：对象、产品/地区/客户、业务时间与发布日期、单位与分母、计划还是实际、总量还是结构、初值还是修订值、样本和来源是否独立。

| 情况 | 怎么处理 |
|---|---|
| 口径或对象不同 | 各自收窄适用范围，不要当成互相推翻 |
| 时间错位 | 按时序解释，保留领先/滞后关系 |
| 方法不同但可评估 | 比较样本与方法，按任务需要给权重 |
| 说不清的真实冲突 | 两边都留着，降低结论强度，写清区分信号 |

不要删掉“不合主线”的材料，也不要简单取平均。写明：冲突是什么、为何能或不能解释、当前结论因此卡在哪里、下一项最能分清对错的证据是什么。
