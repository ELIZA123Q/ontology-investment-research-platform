# A06 传导判断

## 要判断什么

读取 B01 的逐段路径验证结果，回答影响沿 02 既定路径实际到达了哪个节点、可形成什么业务层级的传导结论，以及哪些后续结果不得表达。A06 不重复给每条边定状态。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 事件/变化、目标对象、判断窗口和范围 |
| 02 | 已固定的起点、节点、关系、终点、时滞和阻断条件 |
| 03 | 路径各段的已准入证据、最高 J 等级、冲突和缺口 |
| 04 前置 | B01 的逐段状态、最后一个已验证节点、第一条未通过路径和禁止外推结果；必要时 B02/B03 结果 |

## 判断步骤

1. 先确认路径起点及关键中间前提对应的状态变化是否已成立；起点未确认时，不得直接写出终点利好或利空；
2. 读取 B01 的正式路径状态，不在 A06 重新标记或覆盖边状态；
3. 定位最后一个已验证节点、第一条未通过路径及其对下游的约束；
4. 合并 B02 的承接/时滞/阻断判断和 B03 的多路径合成结果（如适用）；
5. 把路径结果翻译为“已到达、条件可达、受削弱、暂不可判断或被阻断”的传导裁决；
6. 明确当前可表达的业务层级，以及尚未验证、不得表达的经营或财务结果；
7. 写入判断简报时，把“已确认状态变化”与“主路径传导到达节点”分开展示，不得揉成一句笼统利好/利空。

## 判断结果

- 全部关键边为 established：裁决为已到达终点；
- 中间边为 partially_established 或 weakened：只裁决到最后一个已验证节点，后续写明条件或削弱；
- 第一条未通过路径为 insufficient_evidence 或 contested：停止强结论并设置区分信号；
- 决定性边被阻断：停止全部下游推导；
- 仅起点成立：只确认事件，不写产业或公司影响。

## 必须输出

| 字段 | 内容 |
|---|---|
| 已确认状态变化 | 构成路径起点或决定性中间前提的对象变化、方向与是否已观测 |
| 当前判断 | 影响已到达何节点，以及属于已到达、条件可达、受削弱、未决或阻断 |
| 实际等级与置信度 | 不超过 03 上限；不得高于决定性路径中最弱的有效状态 |
| 适用范围 | 起点、目标对象、路径版本、判断窗口和范围 |
| 决定性依据 | 引用 B01 的最后已验证节点和关键边状态 |
| 最强限制 | 第一条未通过路径、阻断、时滞或竞争路径 |
| 改判条件 | 使未通过边转为成立、受到削弱或被阻断的信号、窗口和动作 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 哪些状态变化已确认；影响沿已验证路径实际到达哪里，后续可否条件表达 |
| 不能回答 | 重新定义边状态；起点未确认时写终点利好/利空；把到达经营变量自动升级为利润已兑现；越过未验证节点表达终点结果 |
| 最高允许等级 | J3；传导属于路径/因果判断，不得达到 J4 |
| 下一方法 | 需要把到达节点连接到行业、经营或财务结果时进入 A08 |

## 强制退回条件

- 事件、目标对象、窗口或范围未固定，返回 01；
- 02 没有既定路径、关键节点、时滞或阻断条件，返回 02；
- 关键边证据未准入或路径缺口可补，返回 03；
- 尚无 B01 结果时先调用 B01；第一条决定性边证据不足时保留 J0/J1，不自行判为成立。

## 例与误判

合格：管制范围确认且客户采购行为改变，但公司订单尚未变化，因此只确认暴露与条件性传导。

误判：管制发布后直接推出国产设备公司利润增长。
