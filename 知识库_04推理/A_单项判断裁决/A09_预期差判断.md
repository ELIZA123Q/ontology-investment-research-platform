# A09 预期差判断

## 要判断什么

回答已准入的新基本面信息相对事前市场预期产生了什么差异，以及该差异是否已通过修订或价格反应消化。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 对应资产、预期差问题、事件前基准时点、观察窗口和范围 |
| 02 | 事前预期基线定义、比较口径、定价输入、计价判断维度和排除条件 |
| 03 | 已准入的新基本面信息、事前预期样本、预测修订、价格/估值反应，最高 J 等级、冲突和缺口 |
| 04 前置 | 至少一条可引用的 A08 基本面影响判断 |

## 判断步骤

1. 固定事件前共识的时间戳、样本、分布和关键假设；
2. 明确新信息改变收入、利润、持续期、风险还是其他估值输入；
3. 比较预测修订而非只比较目标价；
4. 观察相对行业/市场的价格反应和事件窗口；
5. 排除样本变化、市场共振和风险溢价变化。

## 判断结果

- 事前基线明确、新信息有识别力且尚未充分修订：存在预期差；
- 共识已同步修订：预期差收敛；
- 只有价格变化：只描述市场表现；
- 无事前基线：禁止使用“超预期/低于预期”。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 预期差方向及未计价、部分计价、已计价或不可判断状态 |
| 实际等级与置信度 | 不超过 03 上限；无可追溯事前基线不得形成方向 |
| 适用范围 | 资产、基准时点、观察窗口、样本和口径 |
| 决定性依据 | A08 新信息与事前预期/修订/价格估值反应的关键差异 |
| 最强限制 | 基线代表性、样本变化、市场共振、风险溢价或数据缺口 |
| 改判条件 | 预期修订、价格/估值消化或基本面变化的信号与窗口 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 新基本面信息相对事前市场预期有何差异，以及计价反映程度 |
| 不能回答 | 仅凭股价涨跌判断市场预期；直接判断该差异值得成为投资观点 |
| 最高允许等级 | J3；预期差和计价属于综合/前瞻判断，不得达到 J4 |
| 下一方法 | 需要判断是否形成投资命题时进入 A10 |

## 强制退回条件

- 资产、基准时点、窗口或范围未固定，返回 01；
- 事前预期基线、比较口径或计价维度未定义，返回 02；
- 预期样本、修订或定价证据未准入/可补，返回 03；
- 无有效事前基线或只有股价变化时保留 J0，不使用“超预期/低于预期”。

## 例与误判

合格：公司订单改善超出事件前共识假设，盈利预测尚未修订且相对价格反应有限，形成待兑现预期差。

误判：股价下跌后声称“市场完全没有预期”。
