# A08 影响判断

## 要判断什么

回答一个已验证变化对行业、公司经营或财务意味着什么。必须区分暴露、可能影响、已发生经营影响和已兑现财务结果。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 已验证变化、影响对象、目标结果层级、判断窗口和范围 |
| 02 | 从变化到结果变量的既定路径、暴露口径、缓冲/抵消项和结果定义 |
| 03 | 暴露、传导、缓冲与结果变量的已准入证据，最高 J 等级、冲突和缺口 |
| 04 前置 | 必要时引用 A06/B01 的可达节点，以及 B02 的承接、时滞和阻断结果 |

## 判断步骤

1. 明确影响对象、方向、窗口和结果层级；
2. 评价暴露程度及传导效率；
3. 检查库存、合同、对冲、替代、能力和成本等缓冲；
4. 检查结果变量是否出现，以及是否被其他因素抵消；
5. 把方向、幅度、持续性和范围分别判断。

## 判断结果

- 暴露、传导与结果均确认：可写已发生影响；
- 暴露确认、结果未到窗口：写条件性影响；
- 缓冲吸收大部分冲击：缩小幅度或窗口；
- 只有概念关联：不得形成影响结论。

影响层级必须按下表逐级确认，不能跳级：

| 层级 | 最低成立条件 | 允许表述 |
|---|---|---|
| 暴露 | 对象与变化存在可核对的直接关联 | 存在暴露，不写结果方向 |
| 可能影响 | A06/B01 支持传导方向，但结果尚未到窗口 | 在明确条件下可能影响 |
| 经营兑现 | 订单、价格、份额、产量或成本等经营变量已出现 | 已发生经营影响 |
| 财务兑现 | 收入、利润、现金流或风险结果已出现，且主要抵消项已处理 | 已兑现财务影响 |

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 影响方向及其处于暴露、可能影响、经营兑现或财务兑现哪一层 |
| 实际等级与置信度 | 不超过 03 上限，并受可达节点和结果层级共同约束 |
| 适用范围 | 影响对象、窗口、业务/财务口径和结果层级 |
| 决定性依据 | 暴露、传导与结果变量中最后一个已验证环节 |
| 最强限制 | 缓冲、抵消、能力约束、未到窗口或结果缺口 |
| 改判条件 | 结果兑现、抵消放大或路径阻断的信号、门槛、窗口和动作 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 已验证变化对行业结果、公司经营、收入、利润、现金流或风险意味着什么 |
| 不能回答 | 把概念暴露写成已发生影响；把经营兑现写成利润兑现；判断市场是否已反映 |
| 最高允许等级 | J3；影响属于因果判断，不得达到 J4；已披露财务数值本身可由 A01 作为事实确认 |
| 下一方法 | 比较市场预期与计价进入 A09；形成投资命题进入 A10，但必须先完成 A09 |

## 强制退回条件

- 影响对象、目标结果层级、窗口或范围未固定，返回 01；
- 结果变量、既定路径、暴露口径或缓冲项未定义，返回 02；
- 暴露/传导/结果证据未准入或可补，返回 03；
- 只有概念关联或决定性路径未通过时保留 J0/J1，不写经营或财务影响。

## 例与误判

合格：行业价格上涨已进入公司合同重定价，但成本同步上升，因此只确认收入受益，利润弹性受限。

误判：公司处于受益产业链位置，所以业绩必然改善。
