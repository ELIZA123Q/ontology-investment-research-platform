# A01 状态判断

## 要判断什么

回答一个明确对象在判断时点或窗口内“现在是什么状态”。状态判断不自动推导未来，也不解释原因。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 对象、状态问题、判断时点或窗口、范围 |
| 02 | 状态变量、单位与口径、比较基线、异常或状态门槛 |
| 03 | 已准入的直接观测或代理、最高 J 等级、反向证据、口径冲突和覆盖缺口 |

## 判断步骤

1. 对齐对象、范围、单位、业务时间和数据版本；
2. 选择与研究问题匹配的基线：历史正常区间、同类对象、计划目标或结构分项；
3. 区分直接观测、估算和代理，不用平均数掩盖分化；
4. 检查至少一个反向指标或口径冲突；
5. 给出状态、范围、异常程度和测量误差。

## 判断结果

- 直接观测与基线匹配、反向指标无未解释冲突：可以确认状态；
- 只有代理或样本覆盖不足：只能条件描述；
- 分项方向相反：拆分对象，不给总体标签；
- 无合理基线：只报告观测值，不贴“高/低/紧/松”。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 对象在给定时点/窗口的状态；不能判断时写 J0 |
| 实际等级与置信度 | 不超过 03 上限；说明直接观测或代理限制 |
| 适用范围 | 对象、窗口、单位、口径与比较基线 |
| 决定性依据 | 形成状态标签的关键观测与门槛 |
| 最强限制 | 反向指标、分项分化、测量误差或覆盖缺口 |
| 改判条件 | 变量、门槛、观察窗口及触发后的状态变化 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 当前或历史时点是什么状态 |
| 不能回答 | 状态是否持续、为何发生、处于何阶段 |
| 最高允许等级 | J4；仅限直接确认的历史事实或当前状态，前瞻外推最高 J3 |
| 下一方法 | 判断持续方向进入 A02；判断阶段进入 A03；判断原因进入 A05 |

## 强制退回条件

- 对象、时点或范围未固定，返回 01；
- 状态变量、口径、基线或门槛未定义，返回 02；
- 决定性观测未准入或口径冲突可补，返回 03；
- 只能报告观测值、不能形成状态方向时保留 J0，不自行设定基线。

## 例与误判

合格：渠道与客户库存均低于各自正常区间，但原厂库存正常，因此只确认下游库存偏低。

误判：用单个渠道访谈确认“全行业库存处于历史低位”。
