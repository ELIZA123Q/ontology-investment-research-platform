# 04 推理方法知识库

本库回答：在已有合格证据下，怎样形成、削弱、打断或修改判断。单次报告怎么写，见 [`04_推理输出规范.md`](../04_推理/04_推理输出规范.md)。

**说明：** 文档写得完整，**不能证明**这些方法一定提高结论质量。下一阶段重点是对照案例验证，而不是继续扩写方法说明。

## 1. 怎么用

1. 确认 01—03 的对象、时间、范围和版本一致；任务级先固定主研究命题。
2. 按判断单元从 A00 各选一个主方法，并沿用 03 给出的最高等级（A01 最高 J4；A02—A10 最高 J3）。
3. 需要看路径时，按 [附录：路径与阻断](A00-附录1_路径与阻断协议.md) 一段段核实；再由 A06 做传导判断（机制问题用 A04，不要为了时滞去“跑一遍 A06”）。
4. 按 [附录：反证与竞争解释](A00-附录2_反证与竞争解释协议.md) 处理最强反证、竞争解释和未解决冲突。
5. 按 [附录：通用认知错误](A00-附录4_通用认知错误与误用索引.md) 定位常见误用，并执行方法说明里的特有硬规则。
6. 形成方向、实际等级、把握、范围、时点和局限。
7. 需要投资观点时再做 A10；按 [附录：改判与版本](A00-附录3_改判与版本协议.md) 写清改判条件并更新版本。

简单任务不必用全套方法。选最难判断、最可能改判的环节即可。

**和 02、03、05 的边界**

- [02 框架库](../知识库_02框架/README.md)决定判断什么、路径和变量是什么。
- [03 取证库](../知识库_03取证/README.md)决定哪些证据能用、最多支持到多强（完备度）。
- 本库决定合格证据对命题的支持状态。
- 05 只负责把已经审过的判断准确写成研究报告。

04 不重新设计问题、不增加路径、不补充证据、不规定报告目录。问题不清退回受理（01）；结构有误退回框架（02）；证据不够或口径有误退回取证（03）。

## 2. 从哪组方法进入

一个任务先定主研究命题，再按判断单元选用方法。下面四组是常用入口，不是必须全部做完的固定工序。

| 组别 | 方法关系 | 何时用 |
|---|---|---|
| 状态—趋势—阶段 | [A01](A01_状态判断.md) → [A02](A02_趋势判断.md) → [A03](A03_阶段判断.md) 可递进 | 现在怎样、方向有没有变、处在哪一阶段；可按需要停在任一层 |
| 因果判断组 | [A04](A04_机制判断.md)、[A05](A05_归因判断.md)、[A06](A06_传导判断.md) 按问题分别选用 | 机制是否运行、主因是什么、影响传到哪；共用附录1与附录2，非严格顺序 |
| 对象比较与兑现 | [A07](A07_分化判断.md) 与 [A08](A08_影响判断.md) | A07 可独立做暴露/能力分化；比较经营或财务兑现时，先分别完成 A08，再由 A07 综合比较 |
| 投资链 | [A08](A08_影响判断.md) → [A09](A09_预期差判断.md) → [A10](A10_投资命题裁决.md) | 相对市场预期差在哪、能否写成投资观点 |

补充约定：

- 一个任务可以包含多个判断单元，但每个判断单元只能有一个主方法；
- A05 不是每次都要做；A04 与 A06 可单独使用；
- A07 可直接服务公司比较，不必先经 A08；
- A10 不是普通任务的默认终点；
- 共用规则见 [A00](A00_裁决总则.md) 及四份附录。

### 常见判断单元怎么选卡

| 判断单元问题 | 主方法 | 常用辅助 |
|---|---|---|
| 当前供需是否紧张 | [A01 状态](A01_状态判断.md) | 必要时 A07 |
| 价格是否进入上涨趋势 | [A02 趋势](A02_趋势判断.md) | A01 |

| 变化主要由什么造成 | [A05 归因](A05_归因判断.md) | 附录2 |
| 事件影响传到了哪里 | [A06 传导](A06_传导判断.md) | 附录1 |
| 哪些公司受益更多（暴露/能力） | [A07 分化](A07_分化判断.md) | — |
| 哪些公司兑现更多（经营/财务） | [A07 分化](A07_分化判断.md) | 先分别完成 A08 |
| 对公司盈利有什么影响 | [A08 影响](A08_影响判断.md) | A06 |

| 是否形成投资观点 | [A10 投资命题](A10_投资命题裁决.md) | A08、A09 |

## 3. 方法怎么分层看

| 层级 | 方法 | 作用 |
|---|---|---|
| 基础判断纪律 | A01—A03 | 状态、趋势、阶段：防止单点、跳级贴标签 |
| 核心裁决能力 | A04—A08 | 机制、归因、传导、分化、影响：防止跨级推导和概念暴露写成业绩 |
| 投资综合裁决 | A09—A10 | 预期差与投资观点：防止基本面正确直接写成投资机会 |

[A00 裁决总则](A00_裁决总则.md) 统一约定开始前要固定什么、结论至少写清什么、等级怎么定、缺材料时退回哪里。各方法说明默认沿用这些约定，只维护本方法独有内容。细则拆在：

- [附录：路径与阻断](A00-附录1_路径与阻断协议.md)
- [附录：反证与竞争解释](A00-附录2_反证与竞争解释协议.md)
- [附录：改判与版本](A00-附录3_改判与版本协议.md)
- [附录：通用认知错误与误用索引](A00-附录4_通用认知错误与误用索引.md)

每张 A 方法说明统一为七部分：方法定位、判断模型与停止点、方法特有判断原则、5—7 步判断流程、裁决与输出增量、边界与退回、例与误判。

## 4. 每次判断至少留下什么

**所有判断必填**（与 [A00 统一输出规范](A00_裁决总则.md#统一输出规范) 一致）：

- 待判断命题及对象、时间、范围；主方法；
- 当前判断；
- 实际等级与把握；
- 适用范围；
- 决定性依据；
- 最强限制；
- 下一项高辨识力证据；
- 改判条件。

**有对应情形时还要写明：**

| 条件 | 还要写明 |
|---|---|
| 使用路径的判断 | 最后可达节点、第一条未通过路径 |
| 存在上一版本 | 证据变化、等级变化和本版相对上版做了什么 |
| 比较多个解释 | 最强竞争解释和区分信号 |
| 投资命题 | 事前预期、计价、验证与过期条件 |

等级标准见 [A00](A00_裁决总则.md#统一等级规则)。不要把路径终点或版本变化当成所有方法的必填项。

## 5. 证据打在不同位置时怎么处理

| 证据影响 | 处理 | 结果 |
|---|---|---|
| 只影响幅度或把握 | 降级 | 保留方向，降低强度 |
| 只影响部分对象或时间 | 缩小 | 收窄范围或窗口 |
| 打掉决定性前提 | 阻断 | 停止相关路径及后续推导 |
| 新解释更能说明事实 | 改写 | 更换主因、路径、阶段或对象表述 |
| 当前证据不能区分 | 保留争议 | 不强行选择，设置区分信号 |

细则见 [附录：反证与竞争解释](A00-附录2_反证与竞争解释协议.md)。

## 6. 质量与入库

新方法进入正式库前须满足：

1. 解决反复出现的判断问题，不保存单次结论；
2. 现有方法无法完整表达；
3. 至少在两个不同任务中出现并经研究员复核；
4. 使用统一七段写法，说明判断思路、特有原则、流程、结论、边界和误判；
5. 不复制 02 的判断结构、03 的证据规则或 05 的写作要求；
6. 单次经验先记为复盘候选，验证后再改稳定方法。

**当前冻结：** 暂不新增 A11 及以后方法说明；优先用对照案例验证现有方法是否真正改变结论。

### 复盘时先分清两件事

结论后来有没有命中，和当时判断是否站得住，不是一回事。

| 类型 | 默认反馈 |
|---|---|
| 合理未命中 | 不改方法，记下条件变化 |
| 过早确认 | 反馈路径核实与这句话最多能说到哪 |
| 关键变量遗漏 | 返回 02；稳定重复后形成框架/本体候选 |
| 证据误用 | 返回 03 |
| 裁决错误 | 返回 04 对应方法说明 |
| 表达放大 | 返回 05 |

## 8. 维护用校验与评测

```bash
python3 知识库_04推理/validate_methods.py
```

校验只检查文件是否齐全、七部分结构、等级上限、路径状态表、认知错误引用与链接。**结构合规 ≠ 方法有效。**

要验证方法是否真正改变判断质量，请使用 [研究价值评测体系](../评测集/README.md) 与 [指标口径和聚合规则](../评测集/04_指标口径与聚合规则.md)。对照案例时至少观察：选方法是否对、是否停在正确节点、证据不足时是否降级、反证是否进入主体、是否拒绝跨层结论。这就是本库的方法有效性验证。
