# 04 推理方法知识库

本库回答：在已有合格证据下，怎样形成、削弱、打断或修改判断。单次报告怎么写，见 [`04_推理输出规范.md`](../04_推理/04_推理输出规范.md)。

**说明：** 文档写得完整，**不能证明**这些方法一定提高结论质量。下一阶段重点是对照案例验证，而不是继续扩写方法说明。

## 1. 怎么用

1. 确认 01—03 的对象、时间、范围和版本一致；任务级先固定主研究命题。
2. 按判断单元从 A00 各选一个主方法，并沿用 03 给出的证据上限。
3. 需要看路径时，按 [附录：路径与阻断](A00-附录1_路径与阻断协议.md)；传导用 A06（机制问题用 A04）。
4. 按 [附录：反证与竞争解释](A00-附录2_反证与竞争解释协议.md) 与 [附录：通用认知错误](A00-附录4_通用认知错误与误用索引.md) 处理。
5. 形成方向、等级、把握、范围与局限；投资观点再做 A10；改判按 [附录：改判与版本](A00-附录3_改判与版本协议.md)。

简单任务不必用全套。共用规则见 [A00](A00_裁决总则.md) 及四份附录。每张 A 方法说明统一为七部分。

**和 02、03、05 的边界**

- [知识库_02框架](../知识库_02框架/README.md)决定判断什么、路径和变量是什么。
- [知识库_03取证](../知识库_03取证/README.md)决定哪些证据能用、最多支持到多强（完备度）。
- 本库决定合格证据对命题的支持状态。
- 05 只负责把已经审过的判断准确写成研究报告。

阶段执行边界见 [`04_推理输出规范.md`](../04_推理/04_推理输出规范.md)（不重新设计问题、不新增路径、不补充证据）。

## 2. 从哪组方法进入

一个任务先定主研究命题，再按判断单元选用方法。

| 组别 | 方法 | 何时用 |
|---|---|---|
| 状态—趋势—阶段 | [A01 状态](A01_状态判断.md)→[A02 趋势](A02_趋势判断.md)→[A03 阶段](A03_阶段判断.md) | 现在怎样、方向、阶段 |
| 因果 | [A04 机制](A04_机制判断.md)、[A05 归因](A05_归因判断.md)、[A06 传导](A06_传导判断.md) | 机制、主因、传导 |
| 分化与兑现 | [A07 分化](A07_分化判断.md)、[A08 影响](A08_影响判断.md) | 暴露/能力分化；经营兑现先 A08 再 A07 |
| 投资链 | A08→[A09 预期差](A09_预期差判断.md)→[A10 投资命题](A10_投资命题裁决.md) | 预期差与投资观点 |

每个判断单元只能有一个主方法。

## 3. 方法怎么分层看

| 层级 | 方法 | 作用 |
|---|---|---|
| 基础判断纪律 | A01—A03 | 状态、趋势、阶段 |
| 核心裁决能力 | A04—A08 | 机制、归因、传导、分化、影响 |
| 投资综合裁决 | A09—A10 | 预期差与投资观点 |

## 4. 每次判断至少留下什么

必填：命题与范围、主方法、当前判断、等级与把握、适用范围、决定性依据、最强限制、下一项证据、改判条件。路径/版本/竞争解释/投资命题有则另写。

| 证据影响 | 处理 |
|---|---|
| 只影响幅度或把握 | 降级 |
| 只影响部分对象或时间 | 缩小 |
| 打掉决定性前提 | 阻断 |
| 新解释更能说明事实 | 改写 |
| 当前不能区分 | 保留争议 |

## 5. 质量与入库

入库：反复出现的问题、现有方法无法表达、至少两任务验证、七部分写法、不复制 02/03/05。**当前冻结**新增 A11+。
