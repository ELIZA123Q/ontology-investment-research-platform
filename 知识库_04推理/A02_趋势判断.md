# A02 趋势判断

## 方法定位

> **一句话哲学：趋势判断不是观察连续变化，而是识别具有惯性的系统运动。**

A02 回答：一个变量或一组相关变量在指定窗口内是否形成持续方向、斜率变化或扩散，以及当前运动是否仍有延续基础。

它不回答当前水平高低、变化主因、周期阶段或未来必然结果。单点高低回 A01，阶段进入 A03，原因进入 A05。

使用本方法前，除 A00 共用材料外，02 必须事先定好同口径变量、频率、最少连续点数、持续/斜率/切换门槛、扩散规则、相邻验证变量和退出条件。

## 判断模型与停止点

```text
单点变化
→ 排除噪声与断点
→ 识别方向和斜率
→ 检查相邻变量是否接上
→ 判断扩散或收缩
→ 判断趋势惯性
→ 识别惯性失效
```

趋势的关键不是“连续”，而是当前运动是否具备继续发生的内部条件。连续上涨仍可能来自低基数、短期补库或一次性冲击；只有相邻状态按预期接上，方向才具有延续基础。

趋势惯性是当前延续基础，不是未来必然延续。A02 停在趋势迹象、形成、延续、加速、放缓、反转或分化，不预测下一阶段和最终结果。

## 方法特有判断原则

本方法重点防范：[CE02](A00-附录4_通用认知错误与误用索引.md#ce02-相邻判断类型偷换)、[CE05](A00-附录4_通用认知错误与误用索引.md#ce05-单点局部或幸存样本外推总体)、[CE08](A00-附录4_通用认知错误与误用索引.md#ce08-事后调整基线阈值窗口或阶段定义)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)。

### 1. 分开水平、方向、斜率和扩散

| 维度 | 要回答的问题 |
|---|---|
| 水平 | 当前处于高位还是低位；由 A01 回答 |
| 方向 | 变量正在上升、下降还是横向 |
| 斜率 | 变化速度在强化、稳定还是减弱 |
| 扩散 | 变化覆盖更多还是更少的分项与主体 |

“仍在上涨”不等于加速；“涨幅收窄”是上行放缓，不自动等于反转。

### 2. 先排除噪声，再谈持续性

至少检查季节性、基数、一次性事件、数据修订、样本构成、统计频率、序列断点和异常分项。无法排除时，只能写边际变化或观察信号。

观察窗口、连续点数和切换门槛必须来自 02，不能看到结果后挑选有利窗口。

### 3. 相邻变量确认优于同类转述

有效确认来自机制相邻但不完全同义的变量，例如价格、库存、交期按合理顺序共同变化；多篇报道重复同一价格信息不构成结构确认。

相邻变量须满足：业务关系已定义、时序合理、原始来源独立、没有更强反向结构信号。

### 4. 趋势惯性分三种状态

| 惯性状态 | 含义 | 怎么说 |
|---|---|---|
| 自我强化 | 相邻变量和扩散继续支持原方向 | 延续基础较强 |
| 外力维持 | 方向依赖一次性政策、补库或低基数 | 持续性受限 |
| 惯性衰减 | 方向未反转，但领先、斜率或扩散走弱 | 趋势仍在，失效风险上升 |

### 5. 趋势降级使用固定优先顺序

趋势尚未在同步结果上反转时，优先按以下信号降级：

1. 核心领先变量先转向；
2. 扩散范围持续收窄；
3. 相邻机制变量失去承接；
4. 最后才等待同步结果变量反转。

前三类信号可以先将“延续”降为“惯性衰减”或“外力维持”，但不能仅凭单一领先信号直接宣布反转。正式反转仍须命中 02 的退出和切换门槛。

### 6. 稳健性是趋势成立的一部分

至少执行一种事先约定的稳健性检查：替换合理窗口、比较月度与季度、剔除异常分项、检查地区/产品分项或比较修订前后序列。合理调整后方向频繁反转，应降为短期波动或局部趋势。

本方法特有误判：把降幅收窄写成已经转正，或把涨幅收窄写成趋势反转。

## 判断流程

1. 固定变量、窗口、频率、范围和待判断维度；
2. 对齐口径、季调、样本、修订与序列断点；
3. 排除基数、季节性、一次性事件和异常分项；
4. 按预设门槛判断方向、斜率和扩散；
5. 用至少一个相邻机制变量检查承接和时序；
6. 判断惯性状态并做稳健性检查；
7. 输出趋势类型、降级信号、停止位置和下一证据。

## 裁决与输出增量

| 证据结构 | 趋势结论 | 这句话最多能说到哪 |
|---|---|---|
| 方向改变但持续性或承接不足 | 趋势迹象 | 只写边际改善/恶化 |
| 多点持续、相邻变量确认 | 趋势形成 | 可作当前趋势判断 |
| 原趋势继续满足维持条件 | 趋势延续 | 同时声明惯性状态 |
| 方向未变但斜率或扩散减弱 | 趋势放缓/惯性衰减 | 不写反转 |
| 原趋势退出且新方向命中切换门槛 | 趋势反转 | 不外推下一阶段 |
| 主要分项方向相反 | 趋势分化 | 分项表达 |
| 单点、基数或断点无法处理 | 非趋势/暂不可比较 | 回到状态或 J0/J1 |

除 A00 七项通用输出外，A02 还要额外写清：

- 趋势结构：方向、斜率、扩散分别是什么状态；
- 惯性状态：自我强化、外力维持或惯性衰减；
- 降级信号：领先变量、扩散、相邻承接和同步结果处于哪一层；
- 稳健性结果：合理窗口、频率或样本变化后是否保持；
- 退出/切换门槛的当前命中情况。

## 边界与退回

- A02 最高 J3（含已形成的历史或当前趋势分类）；未来延续、加速或反转同为最高 J3。
- 只有单点时回 A01；需要阶段标签进入 A03；判断主因进入 A05；判断经营影响进入 A08。
- 连续点数、切换门槛、扩散或相邻验证变量未定义，退回框架（02）。
- 序列不可比、修订和断点未说明或关键数据可补，退回取证（03）。
- 多个合理窗口给出相反方向且无法解释，保留争议，不挑选有利窗口。

## 例与误判

**合格例：** DRAM 合约价连续三个季度上涨，渠道库存下降、交期延长，涨价从高端产品扩展到部分通用产品；但领先订单扩散开始收窄。结论为“上涨趋势延续但惯性开始衰减”，不写成趋势已反转或未来必然继续。

**高迷惑性反例：** “单月销售同比由负转正，因此需求趋势已经反转。”

该表述只有单点，可能受低基数影响，也没有相邻变量确认，并事后把一次变化上升为趋势反转，触发 CE05、CE08 和 CE02。
