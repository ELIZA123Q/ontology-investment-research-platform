# A00-附录3 改判与版本

每个重要判断首次形成时就写明可执行的改判条件；新证据出现后更新版本，不覆盖原判断。本附录统一说明：增强、削弱、阻断、改写、过期，以及复盘后怎么反馈到方法本身。

改判回答“新信息来了，当前判断应变成什么”，不等于认定原判断做错。必须同时区分：原判断在当时可见信息下是否站得住，以及后来条件是否发生变化。

## 改判是等级怎么跟着证据走

```text
上一版结论、等级与把握
→ 本次新增、变更或失效的证据
→ 命中的前提、路径、反证、范围或窗口
→ 更新后的结论、等级与把握
→ 这版相对上版做了什么，以及理由
→ 下一次观察信号
```

03 给出新证据下的最高上限；04 仍只能在上限内更新。同源转述、转载增加和方法步骤变多，不构成升级依据。

## 改判条件要写到能执行

每个条件必须包含：对象、变量、方向或门槛、时间窗口、优先来源、触发后的具体动作。

不合格：“需求不及预期则下调。”

合格：“若未来两个合同窗口的终端订单连续低于 02 预设维持门槛，且渠道库存重新上升，则将‘趋势延续’改为‘惯性衰减’，并关闭利润进一步改善的条件表达。”

## 七种版本动作：判断版本如何更新

| 动作 | 什么时候用 | 怎么处理 |
|---|---|---|
| 维持 | 决定性前提未变 | 更新依据与时点，不制造新观点 |
| 增强 | 新证据补齐关键中介或区分信号 | 提高强度但不超过新上限 |
| 削弱 | 幅度、持续性或部分对象被反证击中 | 降级、缩小范围或缩短窗口 |
| 阻断 | 起点或必要条件失败 | 关闭相关路径及下游结论 |
| 改写 | 主因、阶段、对象、资产或窗口实质变化 | 新建版本并说明替代关系 |
| 过期 | 原逻辑可能仍对，但验证或定价窗口已结束 | 移出当前投资主线，保留历史记录 |
| 终止跟踪 | 命题不再有研究价值或已由新命题完整替代 | 记下终止原因，不删除历史 |

## 等级默认怎么动

| 证据变化 | 默认影响 |
|---|---|
| 补齐决定性前提或关键中介，且来源独立 | 可升级，但不超过 03 和方法上限 |
| 只重复既有方向或同源转述 | 维持等级，可更新时点 |
| 只影响幅度、持续性或部分对象 | 降把握，必要时降级或缩小范围 |
| 打掉决定性前提或必要路径 | 降至 J0/J1 或阻断 |
| 支持与反证冲突且无法消解 | 记为争议，方向性强度最高 J1 |
| 预期已修订、价格已吸收或窗口结束 | 基本面可维持，A10 可过期或不形成 |

## 投资命题要盯两套变化

1. **研究侧：** 基本面前提、传导、盈利影响、反证是否变化；
2. **投资侧：** 预期修订、价格与估值吸收、下行边界、验证窗口是否变化。

“基本面仍成立”不等于“投资命题仍成立”。A10 可以在研究判断不变时过期、改写或转为不形成。

## 历史复盘与方法反馈

复盘先区分结果命中与当时判断质量：

| 复盘类型 | 默认反馈 |
|---|---|
| 合理未命中 | 方法不变，记下条件变化 |
| 过早确认 | 反馈路径核实、时滞或这句话最多能说到哪 |
| 关键变量遗漏 | 退回框架（02）；重复出现后再形成框架候选 |
| 证据误用 | 退回取证（03） |
| 裁决错误 | 返回对应 A 方法说明 |
| 表达放大 | 返回 05 |

只有同类裁决错误在至少两个不同任务中重复出现并经复核，才修改稳定方法；单次异常先进入复盘记录。
