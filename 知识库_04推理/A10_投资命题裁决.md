# A10 投资命题裁决

## 方法定位

> **一句话哲学：投资命题不是看多，而是等待重新定价的假设。**

A10 回答：已经完成的基本面和预期差判断，在明确资产、时间窗口和下行边界下，是否足以形成有边界、可验证、可失效的投资命题。

投资命题是一个当前价格尚未充分反映、未来可被新信息验证或证伪，并可能引发重新定价的假设。它不是基本面结论的摘要，也不是“景气改善＋估值低＋催化剂”的机械拼接。

A10 只用 A01—A09、附录1—3 和 03 已确认可用的结果，不再重做基本面、事前预期、定价、情景或催化材料。

本方法不构成投资建议，不输出买入/卖出、评级、仓位、目标价、收益率承诺或个人行动指令。

## 判断模型与停止点

```text
可用研究判断
× 剩余预期差
× 尚未充分计价
× 可比较的上行与下行边界
× 可验证窗口
－ 决定性反证
= 是否形成投资命题
```

所有结论依次回答五个研究问题，不再另设重复进入条件：

| 编号 | 研究问题 | 最低要求 |
|---|---|---|
| G1 | 基本面判断是否足以支撑命题 | 至少一条关键判断≥J2，决定性路径未阻断，A08已到可识别结果变量 |
| G2 | 市场原本怎么看，研究差异在哪里 | A09事前基线、期限、样本和关键假设可追溯 |
| G3 | 修订、价格、估值和风险是否已吸收 | 存在未计价或部分计价部分，且不是只看股价 |
| G4 | 上行能否与下行和不确定性同口径比较 | 同组敏感变量、方向、幅度区间、窗口和可逆性明确 |
| G5 | 何时、通过什么证据验证或证伪 | 至少一个可观测验证信号和合理时间窗口 |

投资命题的最小表达是：

```text
市场当前隐含什么
→ 研究认为哪个关键假设不同
→ 什么证据会促使预期修订
→ 在什么窗口验证
→ 若判断错误，哪个信号首先出现
```

A10 停在形成、条件性形成、观察、不形成、阻断、过期或改写，并规定 05 最多能写到哪。

## 方法特有判断原则

本方法重点防范：[CE02](A00-附录4_通用认知错误与误用索引.md#ce02-相邻判断类型偷换)、[CE06](A00-附录4_通用认知错误与误用索引.md#ce06-同源材料替代独立验证)、[CE08](A00-附录4_通用认知错误与误用索引.md#ce08-事后调整基线阈值窗口或阶段定义)、[CE10](A00-附录4_通用认知错误与误用索引.md#ce10-跨层跳跃)。

### 1. 研究正确不等于投资命题成立

先写一句不含市场、估值或价格表述的 A08 基本面判断，再依次检查预期、计价、边界和窗口。基本面强但已充分计价，可以形成高等级的“不形成投资命题”。

多个弱判断相加不能生成强命题；A10 等级与类型始终分开记录。

### 2. 命题差异必须具体且可验证

合格命题写成：

```text
市场认为：A
研究判断：B
当前尚未反映：C
验证窗口：D
失效条件：E
```

“行业景气向好”“公司是龙头”“长期看好”不能单独构成命题差异。真正差异通常位于方向、幅度、持续期、结果分布、下行风险或受益对象。

### 3. 上行与下行必须使用同一组敏感变量

基准、上行和下行情景必须使用同一资产、口径、时间尺度和核心敏感变量。对每个核心变量同时比较：

| 维度 | 必须回答 |
|---|---|
| 方向 | 对盈利、现金流、风险或定价向上还是向下 |
| 幅度区间 | 在现有证据下可支持的区间或有序档位 |
| 发生窗口 | 何时开始、何时验证、何时过期 |
| 可逆性 | 条件消失后能否恢复，损害是否不可逆 |

不能用一组变量描述上行、另一组变量描述下行；不能把三种互不相干的故事称为情景比较。

### 4. “收益风险比显著有利”有严格表达门槛

只有上行和下行的幅度区间能够在同口径下量化或形成可复核的有序区间，并同时处理发生概率、窗口和可逆性时，才允许写“收益风险比显著有利”。

若无法形成幅度区间：

- 不得写“收益风险比显著有利”或类似强结论；
- 只能写“下行边界更清楚”或“仍有未反映上行”；
- G4 只算部分通过，A10 最高输出条件性投资命题或观察命题；
- 若连方向、窗口或可逆性也无法比较，G4 未满足，判为观察或不形成。

### 5. 催化、验证、结果和市场收敛分开

| 类型 | 含义 |
|---|---|
| 催化信号 | 可能引起关注或预期修订 |
| 验证信号 | 能确认或否定关键假设 |
| 基本面结果 | 经营或财务最终兑现 |
| 市场收敛 | 预测、价格或估值开始吸收差异 |

有催化不等于命题成立；基本面长期正确但没有当前验证窗口，不能进入当前投资主线。

### 6. 最弱决定性环节约束等级和类型

A10 上限取 G1—G5、最强反证和 03 上限中的最低者。A08 为 J3、A09 为 J1 时，A10 不得按平均值提升，也通常不能形成正式投资主线。

决定性前提失败必须阻断；预期已修订、定价已吸收或窗口结束应判过期或不形成，不能只下调把握。

### 7. 七类结论互不混用

| 类型 | 含义 |
|---|---|
| 形成投资命题 | G1—G5 五个研究问题均满足，无决定性反证 |
| 条件性投资命题 | G1—G3 满足，G4/G5 仍依赖明确可观测条件 |
| 观察命题 | 研究方向有价值，但预期、计价、边界或窗口不足 |
| 不形成投资命题 | 已充分计价、上行不足、下行更强或无验证价值 |
| 命题被阻断 | 关键研究前提或必要路径失败 |
| 命题过期 | 原逻辑可能仍对，但定价或验证窗口已结束 |
| 命题改写 | 资产、主变量、期限或预期差发生实质变化 |

本方法特有误判：周期改善且估值低于历史均值，就直接写投资机会；或只写上行情景和催化，不写同口径下行边界。

## 判断流程

1. 引用 A08，写出不含市场表述的基础研究判断及等级；
2. 引用 A09，写出事前预期、计价程度和唯一或少数命题差异；
3. 依次检查 G1—G3，确认研究、预期和未充分计价同时成立；
4. 用同组敏感变量建立基准、上行和下行情景，比较方向、幅度区间、窗口和可逆性；
5. 区分催化、验证、基本面结果和市场收敛，并检查 G4—G5；
6. 用最强反证攻击命题，确定最弱决定性环节和等级上限；
7. 输出七类结论之一、改判/过期动作及对 05 这句话最多能说到哪。

## 裁决与输出增量

| 五个研究问题与反证结果 | A10 结论 | 对 05 最多能写到哪 |
|---|---|---|
| G1—G5 均满足，无决定性反证 | 形成投资命题 | 可进入投资主线，保留资产、窗口、情景和风险边界 |
| G1—G3 满足，G4或G5仍依赖明确条件 | 条件性投资命题 | 只能写条件观点，不删除前置条件 |
| 研究成立，但预期、计价、边界或窗口不足 | 观察命题 | 进入跟踪项，不写投资机会 |
| 已充分计价、上行不足、下行更强或无验证价值 | 不形成投资命题 | 保留研究结论，不进入投资主线 |
| 关键研究前提或必要路径失败 | 命题被阻断 | 停止全部下游投资表达 |
| 基本面仍成立，但修订/定价完成或窗口结束 | 命题过期 | 从投资主线移出并保留版本 |
| 资产、主变量、期限或预期差实质变化 | 命题改写 | 新建版本并说明替代关系 |

除 A00 七项通用输出外，A10 还要额外写清：

- A08基础研究判断及其等级；
- A09事前预期、代理覆盖层和计价状态；
- 市场假设与研究判断的具体命题差异；
- G1—G5 五个研究问题的回答及最弱决定性环节；
- 基准、上行、下行的同组敏感变量比较；
- 方向、幅度区间、窗口和可逆性；
- 催化、验证、基本面结果和市场收敛信号；
- 七类当前结论及对 05 的表达许可；
- 命题升级、降级、阻断、过期或改写条件。

推荐命题表达：

```text
基于【A08研究判断】，市场相对低估/高估的是【具体变量】；
当前【预测修订与定价】仅反映【程度】。
在【窗口】内，若【验证条件】成立，命题为【结论类型】；
若【失效条件】命中，则【降级/阻断/过期/改写】。
```

## 边界与退回

- A10 属于前瞻综合判断，最高 J3；命题类型不等于判断等级或收益概率。
- A08 未形成影响判断，返回 A08；A09 无有效事前比较，返回 A09。
- 资产、窗口、情景、敏感变量、失效或验证条件未定义，按 A00：问题不清退回受理（01），结构有误退回框架（02）。
- 事前预期、定价、情景或风险材料可补，退回取证（03）。
- 必须依靠叙事、目标价、股价没涨或历史估值均值才能补齐时，判观察或不形成。
- 决定性前提失败直接阻断；窗口结束或计价完成按附录3判过期，不覆盖历史版本。
- 无后续 A 方法；将结论交给 05，并保留这句话最多能说到哪。

## 例与误判

**合格例：** 存储价格、库存和合同重定价支持收入改善，但成本限制利润弹性。市场已预期涨价，尚未充分反映的是持续两个合同窗口的可能性。上行与下行均使用合同价、终端订单和成本三项变量比较；因幅度只能形成有序区间，结论为“持续期被低估的条件性投资命题”，只允许写“仍有未反映上行”，不写收益风险比显著有利。

**高迷惑性反例：** “行业周期改善，公司估值低于历史均值，因此存在投资机会。”

该表述从基本面跨越到投资结论，没有可追溯预期、同口径情景、下行边界或验证窗口，并把历史估值均值事后当作有效基线，触发 CE02、CE08 和 CE10。
