# A06 传导判断

## 方法定位

> **一句话哲学：传导不是箭头，而是受约束的影响网络。**

A06 回答：一个已确认事件、状态变化或机制，沿 02 事先定好的路径实际传到了哪个节点；第一处瓶颈在哪里；多条路径当前形成什么净结论；业务上这句话最多能说到哪一层。

A06 不重新验证路径状态定义，不新增节点、反馈或替代路径，也不把经营节点直接写成财务兑现。逐段状态、承接、时滞与阻断由附录1统一维护。

使用本方法前，除 A00 共用材料外，必须已有：附录1逐段状态、最后核实节点、第一条未通过路径，以及 02 对决定方向路径、多路径关系和目标结果层的定义。

## 判断模型与停止点

```text
读取既定路径状态
→ 确定最后可达节点
→ 找到第一条未通过路径
→ 识别决定方向的路径
→ 合成多路径当前净结论
→ 给出业务上最多能说到哪
```

A06 只保留五件必须写清的事：最后可达节点、第一条未通过路径、决定方向的路径、多路径净结论、当前业务表达上限。

现实可以是网络，但只有被 02 定义并经附录1记录的路径才进入判断。停止点是当前网络在既定约束下能到达哪里，不是画出一张完整箭头图。

## 方法特有判断原则

本方法重点防范：[CE01](A00-附录4_通用认知错误与误用索引.md#ce01-相关替代因果)、[CE06](A00-附录4_通用认知错误与误用索引.md#ce06-同源材料替代独立验证)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)、[CE10](A00-附录4_通用认知错误与误用索引.md#ce10-跨层跳跃)。

### 1. 路径状态只读取附录1

A06 不另造“条件成立”等状态，也不把“证据不足”解释为路径未发生。下游强度和范围必须跟着决定性路径最弱一段的限制走。

### 2. 先找最后可达节点和第一条未通过路径

传导结论必须按以下顺序形成：

```text
每一段走到哪一步（成立 / 部分成立 / 受到削弱 / 被阻断 / 证据不足 / 存在争议 / 不适用）
→ 最后一个已核实节点
→ 第一条未通过路径及原因
→ 对下游的限制
→ 当前最大表达层级
```

越过未通过节点表达终点，无论终点是否同期变化，都属于跨层跳跃。

### 3. 路径数量不决定方向

02 必须指定哪条路径决定方向，哪些只改变幅度、持续性、时点或对象范围。多条同向路径共享同一中介或证据时，不能重复增强；方向相反时不能按多数票决定。

### 4. 多路径合成只做当前净判断

按以下次序合成：

1. 读取决定方向路径的状态；
2. 叠加放大、缓冲、抵消和分化路径留下的限制；
3. 按短期、中期或 02 事先定好的窗口分别判断；
4. 决定性路径被阻断后重算整体方向；
5. 相对作用不可比较时，输出净效应不确定。

### 5. 反馈和替代路径不得临时补入

反馈、绕行或替代路径只有在 02 已定义、03 已确认可用、附录1已逐段记录时才能进入判断。为了使结果“讲得通”而临时补入，必须退回框架（02）。

### 6. 传导层级不等于结果兑现

“已传至客户验证”不等于订单形成；订单不等于收入；收入不等于利润。A06 只声明节点到达，经营、财务、现金流或风险净影响由 A08 继续判断。

本方法特有误判：事件一发生就直接写终点利好，或用起点与终点同时变化替代中间传导。

## 判断流程

1. 固定起点、目标对象、目标结果层、窗口和路径版本；
2. 读取附录1逐段状态，确认起点已经成立；
3. 标出最后可达节点和第一条未通过路径；
4. 读取 02 定义的决定方向路径及多路径关系；
5. 合成放大、缓冲、抵消、分化和分窗口限制；
6. 输出已到达、条件可达、受限、争议、未决、阻断或净效应不确定及业务上限。

## 裁决与输出增量

| 路径结果 | 传导结论 | 业务上最多能说到哪 |
|---|---|---|
| 起点、行为、中介和目标节点逐段成立 | 已到达 | 可表达至该节点 |
| 当前段成立，下一段尚未到窗口 | 条件可达 | 停在当前节点 |
| 中间段部分成立或被削弱 | 受限传导 | 缩小范围、幅度或窗口 |
| 决定性中介存在冲突 | 存在争议 | 不继续方向性下游 |
| 第一条决定性边证据不足 | 暂不可判断 | J0/J1，停在上一节点 |
| 必要路径被阻断 | 被阻断 | 关闭对应全部下游 |
| 多路径方向相反且无法比较 | 净效应不确定 | 分路径、分窗口表达 |
| 只看到起点和终点共现 | 未确认传导 | 不认定路径成立 |

除 A00 七项通用输出外，A06 还要额外写清：

- 已确认起点及其等级；
- 最后可达节点；
- 第一条未通过路径、该段走到哪一步及原因；
- 决定方向路径及决定性最弱环节；
- 多路径独立性、共享中介和分窗口净结论；
- 当前业务表达上限与明确禁止表达的下游结果。

## 边界与退回

- A06 属于路径/因果判断，通常最高 J3；只有关键路径逐段通过且公共 J4 条件全部满足时才可升级。
- 机制是否运行由 A04；经营、财务或风险净影响进入 A08。
- 逐段状态、节点角色、时滞和阻断全部沿用附录1，不在 A06 重复定义。
- 路径、决定方向关系、反馈或替代关系未定义，退回框架（02）。
- 关键段证据、披露状态或冲突可补，退回取证（03）。
- 还没有附录1记录时先完成逐段验证；第一条决定性边不足时保留 J0/J1。

## 例与误判

**合格例：** 管制范围和客户采购切换已确认，部分国产设备进入验证，但批量订单证据不足。结论为“影响已传至客户验证环节，第一条未通过路径为验证到批量订单”，当前只能表达替代路径启动，不能写收入或利润增长。

**高迷惑性反例：** “出口管制发布后国产设备公司股价上涨，因此利好已传到公司基本面。”

股价不是经营节点，且采购切换、验证、订单和收入均未核实；该表述触发 CE01、CE09 和 CE10。
