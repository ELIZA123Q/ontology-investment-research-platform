# A07 分化判断

## 方法定位

> **一句话哲学：分化不是排序，而是识别异质性。**

A07 回答：同一驱动、场景或变化作用下，为什么不同对象出现不同结果；这些差异是否足以支持分组、相对排序，或只能保留维度化比较。

分化判断不按概念相关度排列受益者，也不为了输出明确名次而机械加权。它首先解释差异来自哪里，其次才判断当前证据能否排序。

使用本方法前，除 A00 共用材料外，02 必须事先定好可比对象、排除规则、比较维度、基准、误差或最小业务差异门槛、分组/排序规则和稳健性要求。

## 判断模型与停止点

```text
共同驱动
× 对象暴露差异
× 敏感度差异
× 承接能力差异
－ 约束与抵消
× 时间和情景
= 异质结果
```

A07 使用“暴露—敏感—承接—约束—兑现”识别异质性：受到多少影响、对变化多敏感、有没有能力承接、哪些约束会抵消、最终是否出现经营或财务结果。

停止点优先是可解释的分组或相对位置。精确排名是证据、尺度、误差和情景均稳定时的少数例外，不是常规输出。

## 方法特有判断原则

本方法重点防范：[CE03](A00-附录4_通用认知错误与误用索引.md#ce03-代理替代真实变量)、[CE04](A00-附录4_通用认知错误与误用索引.md#ce04-未观测替代零或未发生)、[CE05](A00-附录4_通用认知错误与误用索引.md#ce05-单点局部或幸存样本外推总体)、[CE10](A00-附录4_通用认知错误与误用索引.md#ce10-跨层跳跃)。

### 1. 可比性先于比较

至少检查：对象层级、商业模式、口径与分母、币种与会计规则、业务时间、比较基线、生命周期和证据覆盖。

不可比时可以拆组、排除或做维度化比较，不能强行合成总分。

### 2. 差异沿结果链分解

| 维度 | 核心问题 |
|---|---|
| 暴露 | 多少业务与驱动直接相关 |
| 敏感 | 驱动变化一个单位，影响多大 |
| 承接 | 产品、认证、产能、客户和执行是否具备 |
| 约束 | 成本、合同、竞争、供应和政策是否抵消 |
| 兑现 | 经营或财务结果是否实际出现 |

只有暴露差异时，最多支持暴露分组；有承接和结果验证后，才讨论兑现分组或相对排序。

### 3. 业务差异必须超过误差下限

02 应给出测量误差、口径误差、估算误差或最小有意义业务差异的判断方式。

- 对象差异未超过误差下限，即使点估计顺序稳定，也必须放入同一组；
- 排序稳定不代表业务差异显著；
- 未知值不能按零处理，也不能因缺数据就自动排在末位；
- 误差下限未定义且无法从 02 规则推导时，只做维度化比较。

### 4. 输出层级逐级提高

| 输出 | 最低条件 |
|---|---|
| 不可比较 | 比较基础不一致 |
| 维度化比较 | 各维可比，但无法稳定合成 |
| 暴露分组 | 暴露可比，兑现不足 |
| 兑现分组 | 承接和结果存在超过误差的稳定差异 |
| 相对排序 | 多维方向一致，合理调整不反转且差异有业务意义 |
| 精确排名 | 尺度、误差、权重、窗口和情景均高度稳定 |

精确排名不因模型输出了分数而自动成立。

### 5. 稳健性检查不是寻找最稳定的权重

至少检查合理权重、窗口、基准、样本、绝对值/增量口径和情景变化。若合理调整导致反转，降为分组或维度化比较；不得事后选择使原排名稳定的权重。

### 6. 分化依赖情景和时间

短期库存、认证进度，中期产能和客户承接，长期成本与产品结构可能给出不同排序。每个分化结论必须声明情景、窗口和结果层级。

本方法特有误判：对象名称含有热门产业概念，就判断其受益最大；或把未知数据当零后形成精确排名。

## 判断流程

1. 固定比较问题、对象集合、情景、窗口和结果层级；
2. 建立可比组并执行拆组、排除和未知值规则；
3. 分解暴露、敏感、承接、约束和兑现差异；
4. 检查差异是否超过测量、口径和估算误差；
5. 优先形成分组，再判断是否满足相对排序条件；
6. 调整合理权重、窗口、基准、样本和情景做稳健性检查；
7. 输出不可比较、维度化比较、分组、相对排序或例外精确排名。

## 裁决与输出增量

| 证据结构 | 分化结论 | 这句话最多能说到哪 |
|---|---|---|
| 比较基础不一致 | 不可比较 | 拆组或排除 |
| 多维可比但无法稳定合成 | 维度化比较 | 不给总排序 |
| 只有暴露差异 | 暴露分组 | 不写经营或盈利排序 |
| 承接和结果差异超过误差 | 兑现分组 | 可形成高低分层 |
| 多维一致、差异有业务意义且稳健 | 相对排序 | 给相对位置 |
| 合理权重或窗口变化即反转 | 排序不稳健 | 降为分组 |
| 点估计有顺序但差异未超过误差 | 同组 | 不给精确名次 |
| 尺度和情景均高度稳定 | 精确排名例外 | 明示严格适用边界 |

除 A00 七项通用输出外，A07 还要额外写清：

- 比较对象、拆组与排除项；
- 暴露、敏感、承接、约束和兑现差异；
- 误差下限或最小业务差异及是否超过；
- 当前支持的是分组、相对排序还是精确排名；
- 权重、窗口、基准和情景变化后的稳健性结果；
- 最可能导致分组或排序反转的观测。

## 边界与退回

- A07 的分化解释和受益排序最高 J3；纯当前事实比较可用 A01。
- 需要验证经营或财务兑现，进入 A08；比较市场反映进入 A09/A10。
- 可比口径、排除规则、误差门槛、分组/排序或稳健性规则未定义，退回框架（02）。
- 各对象未对称取证、口径冲突或关键结果可补，退回取证（03）。
- 商业模式或生命周期不可比时拆组；合理调整频繁反转时不得给精确排序。

## 例与误判

**合格例：** 两家公司收入暴露相近，但甲已完成客户验证并具备交付产能，乙仍处送样阶段。差异超过认证进度的估算误差，支持“甲兑现能力更强”的分组；因成本口径不可比，不做利润弹性精确排名。

**高迷惑性反例：** “公司业务名称包含先进封装，所以先进封装景气上行时该公司受益最大。”

该表述用概念代理真实暴露，也没有承接、约束、误差和兑现证据，并跨层跳到受益排序，触发 CE03、CE05 和 CE10。
