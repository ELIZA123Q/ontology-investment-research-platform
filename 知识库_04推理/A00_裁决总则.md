本文件是 A01—A10 的共用约定。它统一规定：开始前要固定什么、结论至少写清什么、等级怎么定、缺材料时退回哪里、案例怎么写。各方法说明只保留本方法独有的思路、原则、结论类型和边界。

## 先选主问题，再选主方法

A01—A10 不是必须全部做完的固定工序。分两层选用：

- **任务级：** 确定一个主研究命题，控制整篇研究的方向；一个任务可以包含多个判断单元。
- **判断单元级：** 每个待判断命题只选择一个主方法；其他方法仅作为前置、辅助，或为回答主问题必须先弄清的子判断。

一个任务可以包含多个判断单元，但每个判断单元只能有一个主方法；任务同时指定一个主研究命题，其他判断作为前置、辅助或为回答主问题必须先弄清的子判断。这样既防止十张卡全部乱跑，也不把复杂报告压缩成一个方法。

| 判断单元级主问题 | 主方法 | 默认停在哪里 |
|---|---|---|
| 现在是什么状态 | A01 状态 | 当前或历史截面的状态与结构 |
| 变化是否形成持续方向 | A02 趋势 | 方向、斜率、扩散和惯性状态 |
| 处于哪个预定义阶段 | A03 阶段 | 阶段内、迁移、过渡或分化 |
| 某机制是否真实运行 | A04 机制 | 机制运行状态，不裁决主因 |
| 已发生变化主要由什么造成 | A05 归因 | 解释权分配，不伪造精确权重 |
| 影响沿路径传到了哪里 | A06 传导 | 最后可达节点和这句话最多能说到哪 |
| 不同对象为何出现差异 | A07 分化 | 分组或稳健相对排序 |
| 变化对经营或财务意味着什么 | A08 影响 | 已确认的基本面或风险结果层 |
| 相对市场事前预期差在哪里 | A09 预期差 | 预期修订和计价吸收程度 |
| 是否形成投资命题 | A10 投资命题 | 形成、观察、不形成或失效 |

A10 只用已有的基本面、预期差和反证结论，不再重做这些判断；也不输出买卖建议、仓位、目标价或收益承诺。

## 统一输入规范：每次判断开始前要固定什么

各方法默认沿用下面三层材料，不必在每张说明里重抄完整清单。

| 来自 | 必须提供 | 04 能做什么、不能做什么 |
|---|---|---|
| 01 受理 | 待判断命题、对象、判断时点或窗口、范围、交付边界 | 不改变问题和对象范围 |
| 02 框架 | 判断模型、变量与口径、门槛、路径、时滞、聚合或比较规则 | 不临时创造模型、阈值、路径或阶段 |
| 03 取证 | 已确认可用的证据、最高等级、冲突、反证、缺口、修订与适用边界 | 不搜索、补造或重新判定证据是否可用 |

进入任何方法前还须确认：

1. 01—03 的任务、对象、范围、业务时间和版本一致；
2. 待判断命题可以由所选方法回答，而不是相邻方法的问题；
3. 02 已定义本方法所需的特殊门槛或关系；
4. 03 已说明关键材料是否可用、能用到哪（完备度）；
5. 若确需依赖前序方法，其结论、等级和限制可追溯。

各方法说明里的“开始前还需要什么”，只写超出上述共用材料的特有要求。共用材料缺失时，不得由本方法自行补齐。

## 三组容易混的边界

### 状态、趋势、阶段

- A01 回答某一截面相对基线是高、低、紧、松、正常、异常还是分化。
- A02 回答多个可比时点上是否形成方向、斜率、扩散和延续基础。
- A03 回答多组进入、维持和退出条件共同定义的阶段位置。

单点变化不能直接成为趋势；趋势改善不能直接成为阶段切换。

### 机制、归因、传导

- A04、A05、A06 回答三个不同问题，可按需要单独使用，不是必经顺序。
- A04 判断目标机制有没有在现实中运行。
- A05 比较多个候选解释，并分配方向、幅度、持续性或分化的解释权。
- 附录1 是 A04 与 A06 共用的路径工具（记下每一段走到哪）；A06 据此判断影响到了哪里、还能说什么。附录1 不是“先跑一遍再做其他方法”的流水线。

机制成立不等于它是主因；主因成立不等于影响已到终点。

### 影响、预期差、投资命题

- A08 停在行业、经营、财务、现金流或风险结果。
- A09 停在相对事前预期的增量和计价吸收程度。
- A10 才判断给定资产、窗口和下行边界下是否形成投资命题。

基本面正确不等于市场未计价，也不等于投资命题成立。

## 统一输出规范：每次判断至少写清什么

每个正式判断都必须写清以下七项；各方法只在“裁决与输出增量”中补充本方法特有要写的内容。

| 必须写清 | 要求 |
|---|---|
| 当前判断 | 一句话直接回答命题；信息不足时明确写“暂不可判断” |
| 实际等级与把握 | 分别记下 J0—J4 和把握，不得互相替代 |
| 适用范围 | 对象、时间、地域、产品、口径及被排除范围 |
| 决定性依据 | 真正改变结论的条件、区分信号或最后核实节点 |
| 最强限制 | 最强反证、竞争解释、冲突、缺口或卡住位置 |
| 下一项高辨识力证据 | 最可能分清候选结论、或改变当前判断的下一观测 |
| 改判条件 | 变量、方向或门槛、窗口、优先来源，以及触发后怎么改 |

推荐写法：

```text
截至【时点】，在【范围与口径】下，【当前判断】（Jx，【把握】）。
决定性依据是【关键条件/区分信号】，但【最强限制】使结论不能扩展到【被排除结论】。
下一项高辨识力证据为【观测】；若【触发条件】出现，则【升级/削弱/阻断/改写/过期】。
```

材料多少、步骤是否写全、文字是否顺畅，都不能单独抬高等级。

## 统一等级规则

等级回答“证据和路径够不够支撑这句话”；把握回答“在这个等级下有多确信”。首次出现时的含义：

| 等级 | 研究含义 | 最低要求 |
|---|---|---|
| J0 暂不可判断 | 关键输入或区分证据不足 | 不给方向，写清缺口与下一证据 |
| J1 观察 | 存在信号，但决定性前提未满足 | 写明信号、噪声与验证点 |
| J2 条件/方向支持 | 关键条件已出现，可作有边界方向判断 | 至少一项直接支持，条件和失效点清楚 |
| J3 高概率 | 关键路径基本完整，主要反证已处理 | 多源独立验证，决定性环节无未解阻断 |
| J4 确认 | 在明确对象、时间与范围内，Q4 证据、关键方法门槛、两条独立证据链、竞争解释与反证检查均通过 | 写清范围、时点、失效条件与语义审核结果，不把范围内确认外推为无条件真理 |

03 给出每条判断的证据上限（完备度），04 只能维持或下调到命题支持状态。不同判断类型存在通常上限，但不按方法编号机械封顶：

| 判断情形 | 通常上限 | 升级规则 |
|---|---|---|
| 可直接确认的历史或当前状态 | J4 | 仍须满足 Q4、独立证据链、反证与范围要求 |
| 趋势、阶段、机制、归因、传导、分化、影响、预期与估值影响 | J3 | 满足公共路由表全部 J4 升级条件后可升至 J4 |

J4 升级条件只在公共路由表维护，包括 Q4、方法门槛通过、至少两条实质独立证据链、主要竞争解释已区分、无决定性反证、范围/时点/失效条件明确和语义审核通过。

最终等级取“03 上限、判断类型通常上限或已通过的升级门槛、决定性环节上限”中的最低者。材料变多、同源转述变多、用到的方法变多，都不会自动升级。

## 统一退回规则

| 缺口类型 | 去向 | 当前处理 |
|---|---|---|
| 命题、对象、窗口、范围或交付边界未固定 | 问题不清，退回受理（01） | 不选择有利范围继续判断 |
| 变量、口径、基线、阈值、路径、阶段或比较规则未定义 | 结构有误，退回框架（02） | 不在 04 临时创造结构 |
| 数据未确认可用、口径不清、版本冲突、关键样本或反证可补 | 证据不够，退回取证（03） | 不自行搜索或替换证据 |
| 结构完整但当前证据仍不能区分 | 留在 04 | 保留 J0/J1，写下一项高辨识力证据 |
| 决定性前提失败或必要路径被阻断 | 留在 04 | 阻断对应结论及其全部下游 |

各方法只补充本方法特有的停止和退回条件，不重复上表对应关系。

## 统一案例规范

每张方法说明只保留一组案例：

1. **合格例：** 明确命题、决定性依据、结论类型、这句话最多能说到哪、停在哪里；
2. **高迷惑性反例：** 结论表面合理但违反关键原则；
3. **误判说明：** 只指出本方法特有错误，并引用附录4 的 2—4 个通用错误编号；
4. 案例不重复讲解完整输入、等级、退回或输出约定；
5. 不用虚构材料把案例补成高等级结论。

## 版本与使用记录

首次判断从当时可见证据形成，不伪造“逐步升级”的过程。后续版本按附录3记下：上一版、证据变化、命中位置、新等级与把握、这版相对上版做了什么，以及下一观察信号。

方法编号 A00、A01—A10 保持稳定，便于跨版本对照；方法说明改写不改变编号含义。
