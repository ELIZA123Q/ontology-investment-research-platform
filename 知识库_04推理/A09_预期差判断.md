# A09 预期差判断

## 方法定位

> **一句话哲学：预期差不是结果更好，而是市场假设不同。**

A09 回答：新的基本面信息相对事件前可追溯市场预期改变了什么关键假设；预测和定价已经吸收多少；还剩什么未反映或可能过度反映。

市场预期本身不可直接观测，只能通过共识、关键假设、叙事、持仓和定价等代理推断。A09 必须声明本次实际覆盖了哪些代理层，不能把一个代理代表完整市场预期。

使用本方法前，除 A00 共用材料外，必须已有至少一条 A08 基本面影响判断；02 必须定义事件前基准、比较口径、期限、关键定价输入、计价维度和排除条件。

## 判断模型与停止点

```text
事件前可追溯预期
→ 新信息改变的关键假设
→ 预测修订程度
→ 价格、估值和风险吸收程度
→ 分期限剩余预期差
```

可使用的市场预期代理包括：

| 层面 | 常见代理 | 是否必需 |
|---|---|---|
| 共识/关键假设 | 一致预期、公司指引、可追溯模型假设 | 最低组合之一 |
| 预测修订 | 盈利、数量、价格、利润率、持续期调整 | 最低组合必需 |
| 定价反应 | 相对价格、估值、风险溢价 | 最低组合必需 |
| 叙事 | 研报、媒体和交流中的主线 | 可选增强或解释冲突 |
| 持仓 | 拥挤度、资金暴露的合格代理 | 可选增强或解释冲突 |

最低可用组合是“事前共识或关键假设＋预测修订＋定价反应”。叙事和持仓不是每次必须具备。

A09 停在未计价、部分计价、已计价、过度计价、分期限差异或不可判断，不裁决是否值得形成投资命题。

## 方法特有判断原则

本方法重点防范：[CE03](A00-附录4_通用认知错误与误用索引.md#ce03-代理替代真实变量)、[CE07](A00-附录4_通用认知错误与误用索引.md#ce07-遗漏共同驱动和最强竞争解释)、[CE08](A00-附录4_通用认知错误与误用索引.md#ce08-事后调整基线阈值窗口或阶段定义)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)。

### 1. 事前基线必须可追溯

至少记下：早于新信息公开的时间戳、样本或来源、均值/中位数/区间与分歧、关键假设、期限和代表性限制。

事件后评论不能重构事前预期；只有股价变化也不能反推出市场原本怎么想。

### 2. 新信息必须改变关键输入

新信息可能改变收入、数量、价格、利润率、持续期、结果分布、下行风险、现金流或估值方法。只重复已知事实、没有改变关键输入时，可能不存在方向性预期差。

应明确写成：

```text
原关键假设 → 新信息 → 被改变的输入 → 影响方向与期限
```

### 3. 每次声明实际覆盖层

若只有共识、修订和价格材料，只能判断“可观测共识与定价层的预期差”，不得声称已识别完整市场预期。叙事和持仓仅在证据可得时增强判断或解释代理冲突。

代理层互相冲突时，不简单平均：例如共识未上修但价格已经提前反映，应写明“共识层仍有差异、定价层已部分吸收”。

### 4. 区分超预期、修订和计价

| 概念 | 含义 |
|---|---|
| 基本面超预期 | 实际或新信息优于事件前基线 |
| 预期修订 | 模型、指引或关键假设已调整 |
| 价格反应 | 资产相对市场/行业发生变化 |
| 估值吸收 | 倍数或风险溢价发生调整 |
| 未计价 | 关键增量尚未充分进入预期和定价 |
| 过度计价 | 定价反应超过基本面可支持范围 |

基本面超预期不自动等于未计价，也不自动形成投资命题。

### 5. 定价反应按三个通道检查

1. 预期通道：盈利和关键假设是否修订，分歧是否变化；
2. 价格通道：相对行业/市场反应、事件窗口、提前交易和同期事件；
3. 估值与风险通道：倍数、风险溢价以及当前价格更接近哪个情景。

最低组合要求预测修订和定价反应可追溯；估值或风险材料不可得时，必须降低覆盖声明，不补造完整计价判断。

### 6. 分布与期限优先于单一均值

均值可能掩盖样本分歧、持续期和尾部风险。短期季度超预期、中期盈利不变、长期结构假设削弱可以同时成立，必须分期限输出。

本方法特有误判：业绩很好但股价没涨，就断言“市场完全没有预期”。

## 判断流程

1. 锁定新信息公开前的预期时间戳、样本、分布和期限；
2. 引用 A08，说明新信息改变的基本面或风险输入；
3. 声明本次使用的共识/假设、修订、定价、叙事和持仓覆盖层；
4. 比较盈利及关键假设修订，不用目标价替代；
5. 检查相对价格、估值、风险溢价及同期干扰；
6. 分短期、中期和长期判断剩余差异；
7. 输出未计价、部分计价、已计价、过度计价、收敛、分期限差异或不可判断。

## 裁决与输出增量

| 证据结构 | 预期差结论 | 这句话最多能说到哪 |
|---|---|---|
| 基线明确，新信息改变关键输入，尚未修订或计价 | 未计价预期差 | 可形成明确方向 |
| 预测或定价已反映部分变化 | 部分计价 | 说明剩余差异所在层与期限 |
| 关键假设和定价基本吸收 | 已计价/预期差收敛 | 不再写明显预期差 |
| 定价超过基本面可支持范围 | 可能过度计价 | 保留反向风险 |
| 代理层互相冲突 | 分层预期差 | 分层表达，不给单一标签 |
| 只有价格变化或事后评论 | 无有效基线 | J0，不使用超预期/未计价 |
| 短期与长期方向不同 | 分期限预期差 | 不合并为单一方向 |

除 A00 七项通用输出外，A09 还要额外写清：

- 事前预期的时间戳、样本、分布、关键假设和期限；
- 本次实际覆盖的预期代理层及代表性限制；
- A08 新信息改变的关键输入；
- 预测修订、相对价格、估值和风险吸收程度；
- 各代理层的冲突与分期限剩余差异；
- 哪项修订、经营结果或市场反应最可能改变计价状态。

## 边界与退回

- A09 属于综合/前瞻判断，通常最高 J3；无有效事前基线时为 J0，只有公共 J4 条件全部通过时才可升级。
- A08 尚未形成基本面影响判断时返回 A08；是否形成投资命题进入 A10。
- 事前基线、期限、比较口径或计价维度未定义，退回框架（02）。
- 预期样本、修订或定价材料可补，退回取证（03）。
- 只有价格变化、事后评论或必须事后重构预期时，禁止使用“超预期、低于预期、未计价”。

## 例与误判

**合格例：** 事件前共识已预期订单改善，但关键假设是只持续一个季度。新合同支持持续两个至三个季度，盈利预测只小幅上修，相对行业价格反应有限。覆盖共识、修订和定价三层后，结论为“持续期仍存在部分未计价预期差”。

**高迷惑性反例：** “公司业绩很好但股价没有上涨，因此市场完全没有预期。”

该结论没有事前基线，用价格代理完整市场预期，也未排除市场共振和风险溢价，触发 CE03、CE08 和 CE09。
