# A08 影响判断

## 方法定位

> **一句话哲学：影响不是关联，而是跨层兑现。**

A08 回答：一个已核实变化，对行业、公司经营、财务、现金流或风险状态究竟意味着什么；当前影响实际到达哪一层，净方向、幅度、持续性和覆盖能说到什么程度。

A08 不判断市场是否已反映，也不从产业概念直接写公司受益。市场预期进入 A09，投资命题进入 A10。

使用本方法前，除 A00 共用材料外，02 必须定义目标结果层、暴露口径、从变化到结果的既定路径、能力约束、缓冲/抵消项、业务与会计确认时点；必要时先完成 A06。

## 判断模型与停止点

```text
有效暴露
→ 路径可达
→ 经营承接
→ 毛影响
－ 缓冲、约束和抵消
→ 净经营结果
→ 净财务、现金流或风险结果
```

每跨一层都可能传递、变形或消失。行业涨价可以进入公司价格和收入，也可能被原材料、旧合同、产能、费用或回款周期抵消。

A08 要分清三件事：影响到达的层级、扣除抵消后的净额、一次性/周期性/结构性及可逆性。停止点是已确认的基本面或风险结果，不进入定价。

## 方法特有判断原则

本方法重点防范：[CE01](A00-附录4_通用认知错误与误用索引.md#ce01-相关替代因果)、[CE03](A00-附录4_通用认知错误与误用索引.md#ce03-代理替代真实变量)、[CE09](A00-附录4_通用认知错误与误用索引.md#ce09-时间窗口错配或顺序倒置)、[CE10](A00-附录4_通用认知错误与误用索引.md#ce10-跨层跳跃)。

### 1. 先确认有效暴露

| 暴露层 | 含义 | 可否继续 |
|---|---|---|
| 名义暴露 | 只有概念或名称相关 | 不形成方向影响 |
| 直接暴露 | 收入、成本、产能、客户或资产直接相关 | 仍须检查承接 |
| 有效暴露 | 直接暴露且产品、资质、产能或合同可承接 | 可继续影响判断 |
| 净暴露 | 扣除对冲、替代、合同和抵消后的真实基础 | 可判断净方向 |

### 2. 影响层级必须逐级确认

| 层级 | 最低成立条件 | 允许表达 |
|---|---|---|
| 暴露 | 对象与变化有可核对直接关联 | 存在暴露，不写结果方向 |
| 可能影响 | A06 支持路径方向，结果未到窗口 | 明确条件下可能影响 |
| 经营兑现 | 订单、价格、份额、产量、利用率或成本已变化 | 已发生经营影响 |
| 财务/风险兑现 | 收入、利润、现金流、资本占用或风险结果出现，主要抵消已处理 | 已发生相应影响 |
| 持续兑现 | 多个窗口维持且非一次性 | 可讨论持续性或结构性 |

经营兑现不能自动升格为财务兑现；已披露财务数值可由 A01 确认，但“由目标变化造成”仍需因果判断。

### 3. 毛影响和净影响分开

结果桥至少检查数量、价格、产品结构、合同与时滞、成本与费用、产能与执行、收入确认和回款。正向毛收入与同步成本上涨可以并存，净利润方向不能由单一环节决定。

### 4. 强制声明边际贡献还是总量结果

每次 A08 必须选择并写明判断口径：

- **边际贡献：** 目标变化相对于反事实给结果带来的增量；
- **总量结果：** 公司最终收入、利润、现金流或风险的整体变化。

目标事件提高利润 5%，但公司利润总量下降并不矛盾。未声明口径时，不得用“影响偏正/偏负”形成正式结论。

### 5. 财务结果出现不等于由目标变化造成

财务结果与目标变化同期出现时，必须引用 A05 的归因结果或按附录2处理最强竞争解释。缺少相对识别时，只能确认总量结果，不得反推目标变化的边际贡献。

### 6. 影响形态分开判断

方向、幅度、持续性、覆盖、经营/会计时点和可逆性分别判断。方向明确不代表幅度可量化；经营影响持续不代表利润弹性或现金流同步持续。

本方法特有误判：公司位于受益产业链，就直接写利润增长；或看到利润增长后倒推某事件产生正面影响。

## 判断流程

1. 固定影响对象、判断口径、目标结果层、窗口和范围；
2. 核对名义、直接、有效和净暴露；
3. 读取 A06 的最后可达节点与第一条未通过路径；
4. 建立从毛影响到净结果的结果桥并扣除缓冲、约束和抵消；
5. 分别检查经营、财务、现金流或风险结果及确认时点；
6. 引用 A05/附录2排除更强竞争解释；
7. 输出兑现层级、边际或总量口径、净方向和影响形态。

## 裁决与输出增量

| 证据结构 | 影响结论 | 这句话最多能说到哪 |
|---|---|---|
| 只有概念或名称关联 | 名义暴露 | 不形成方向影响 |
| 有效暴露和路径方向成立，结果未到窗口 | 可能影响 | 条件表达 |
| 经营变量已变化 | 经营兑现 | 不写财务兑现 |
| 财务结果出现且主要抵消和归因已处理 | 财务兑现 | 可写已发生财务影响 |
| 多窗口维持且非一次性 | 持续兑现 | 可讨论结构性 |
| 毛影响偏正但抵消显著 | 净影响受限 | 缩小幅度或范围 |
| 总量结果变化但边际归因不足 | 总量确认、边际未决 | 不归因于目标变化 |
| 决定性路径未通过 | 暂不可判断/阻断 | 不写经营或财务影响 |

除 A00 七项通用输出外，A08 还要额外写清：

- 判断口径：边际贡献或总量结果；
- 暴露层级：名义、直接、有效或净暴露；
- 最后已核实的影响层级；
- 毛影响、缓冲、约束、抵消和净结果桥；
- 方向、幅度、持续性、覆盖、时点和可逆性；
- A05 或附录2的归因/竞争解释引用。

## 边界与退回

- A08 属于因果影响判断，最高 J3；财务数字本身的事实确认不抬高因果等级。
- 路径未完成时返回 A06；比较市场预期进入 A09；形成投资命题进入 A10。
- 暴露口径、结果桥、缓冲/抵消或确认时点未定义，退回框架（02）。
- 暴露、传导、结果或归因证据可补，退回取证（03）。
- 只有名义暴露或决定性路径未通过时保留 J0/J1，不写经营或财务受益。

## 例与误判

**合格例：** 行业涨价已进入公司合同重定价，收入端开始兑现；原材料成本同步上升，部分客户仍执行旧合同。判断口径为边际贡献：收入影响偏正、利润边际贡献有限；公司利润总量仍可能因其他业务下降而走弱。

**高迷惑性反例：** “公司利润增长，所以先进封装景气改善已经给公司带来显著影响。”

该结论从总量结果反推目标事件，未检查有效暴露、路径、抵消和竞争解释，触发 CE01、CE03 和 CE10。
