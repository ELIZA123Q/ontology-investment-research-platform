# 示例1：存储芯片周期（2026-07-15）

本目录是按当前项目规范跑通的存储芯片周期样例，覆盖从需求到研报的完整流程（全链），展示“行业周期判断”如何从投研需求、任务本体视图和证据，落到可复核的推理与研报正文。

## 研究结论摘要

截至 2026 年 7 月 15 日，存储市场处于「供给短缺延续、涨价斜率放缓」的高位消化期：HBM 仍结构性扩张，通用 DRAM 仍由卖方定价但 3Q26 涨幅预计明显回落，NAND 由企业级 SSD 拉动而消费端承压。部分美国 CSP 库存累积是新增削弱信号，但成因包含 CPU 短缺和预防性备货，尚不足以确认见顶。新增供给要到 2027 下半年至 2028 才开始过检，当前不能给出统一周期结束日。

## 使用边界

- 可用于理解行业周期判断类任务的完整链路；

- 不应替代最新市场跟踪；如研究时点更新，应重新执行 03、04、05。
