# 示例1：存储芯片周期（当前可运行样例）

本目录保存存储芯片周期研究的现行 01—05 全链样例，并纳入根目录 `validate_project.py` 的项目级验收。它展示“行业周期判断”场景如何从用户需求、任务本体视图、证据实例、推理实例，最终落到研究员可阅读的研报正文。

## 研究结论摘要

本样例的研究判断是：存储芯片处在结构性上行后段，而非三类产品同步强景气的单一周期。价格上涨事实已经比较明确，但尚不能判断三类产品会在何时同步见顶或结束；后续重点跟踪价格斜率、客户库存、订单兑现、HBM 认证和新增合格供给。

## 使用边界

- 可以用于理解行业周期判断类任务的完整链路；
- 可以用于检查 02 跨三域任务本体视图、03 证据实例清单和 04 推理实例之间的引用关系；
- 可以用于验证 05 如何把 04 已批准观点写成真实研报表达；
- 不应替代最新市场跟踪；如研究时点更新，应重新执行 03、04、05。
