# 存储芯片周期投研需求说明

## 1. 研究需求确认

已与研究员确认以下三个问题：

| 确认项 | 问题 | 研究员回答 |
|----------|------------------|----------|
| 研究对象 | 看存储芯片整体，还是 HBM、非 HBM DRAM、NAND 分开看？ | 三类产品分开观察，行业整体只作背景 |
| 事件与时间 | 「当前周期」和「周期结束」分别怎么理解？ | 以每次运行数据截止日为锚点，回看近六个季度，前瞻 6—24 个月；结束时间用条件式窗口，不给确定日期 |
| 交付方式 | 做行业跟踪还是完整研究？要不要判断股价？ | 进入完整研究链路；只判断供需与价格周期，不判断股价、评级或仓位 |

## 2. 研究目标与核心问题

### 2.1 研究目标

识别全球存储芯片主要产品当前所处的供需、库存和价格周期阶段，并把「本轮周期什么时候结束」改写为可验证的条件式时间窗口，供行业跟踪和研究框架复盘使用。

### 2.2 核心问题

> 截至每次运行的数据截止时点，全球存储芯片中 HBM、非 HBM DRAM 与 NAND 分别处于什么供需与价格周期阶段；在未来 6—24 个月内，哪些需求、库存、有效供给、价格和产能信号将支持周期延续或表明周期转入见顶、正常化或下行？

### 2.3 要回答的问题类型

| 项目 | 说明 |
|------|------|
| 问题类型 | 状态定位 / 阶段切换 |
| 研究类型 | 状态与趋势判断 |
| 用途 | 进入完整研究链路 |
| 最终要弄清什么 | 分产品说明当前周期位置、延续条件、削弱信号和结束窗口，不给确定结束日 |

## 3. 研究对象

### 3.1 对象范围

| 对象 | 在研究中的角色 | 是否核心 | 说明 |
|------|----------------|----------|------|
| HBM | AI 加速器高带宽内存 | 是 | 结构性需求与先进封装瓶颈的主要来源 |
| 非 HBM DRAM | 服务器、PC、手机等工作内存 | 是 | 观察 HBM 挤出效应与服务器/消费需求 |
| NAND Flash | 企业级 SSD、客户端 SSD、手机存储 | 是 | 观察 AI 存储需求与消费端分化 |
| 存储芯片产业 | 产品集合 | 是 | 总体判断由三类产品分层汇总，不做简单平均 |

### 3.2 研究缘起

从研究员提出的「当前处于什么周期、何时结束」出发，核验最近可得的原厂经营数据、库存与价格变化、需求展望和新增供给时间表，不预设已经见顶或仍处早期。

| 缘起 | 具体内容 | 来源 |
|------|----------|------|
| 研究问题 | 存储芯片目前处于什么周期，本轮周期什么时候结束 | 研究员原话 |

## 4. 研究范围与边界

| 维度 | 怎么定 | 备注 |
|------|--------|------|
| 时间 | 每次运行回看最近六个完整季度，前瞻 6—24 个月 | 由后续运行在执行日解析实际起止日期 |
| 地域 | 全球供需 | DRAM/HBM 重点看 Samsung、SK hynix、Micron；NAND 补充主要原厂及企业级 SSD 供应链 |
| 产业链 | 终端需求、订单库存、制造、封装、供给、价格 | 不延伸到证券定价 |
| 对象 | HBM、非 HBM DRAM、NAND | 分产品判断，不用行业均值替代 |
| 不研究 | 个股收益、目标价、仓位、NOR 等利基产品独立周期 | 不得输出投资建议 |

## 5. 已澄清的问题

| 曾经不清楚的地方 | 现在怎么定 | 为什么重要 |
|------------------|------------|------------|
| HBM 是否并入 DRAM | HBM 属于 DRAM 但单独观察 | 影响对象拆分和供给分析 |
| 「周期结束」是否指确定日期 | 改写为条件式窗口和转折信号 | 结论只能条件化表达 |
| 是否判断股票 | 明确不判断股价、评级、目标价、仓位 | 约束合规边界 |

## 6. 重点看什么

| 观察什么 | 看什么变化 | 可能说明什么 |
|----------|------------|--------------|
| 终端需求 | AI 数据中心、服务器、PC、手机和汽车需求 | 结构性需求强还是消费端走弱 |
| 订单与采购 | 长协、订单覆盖、提前采购、取消或延迟拉货 | 真实需求还是重复下单 |
| 库存 | 原厂、渠道、OEM/客户库存 | 补库、去库和缓冲能力 |
| 有效供给 | 晶圆投入、产品组合、良率、封装、认证 | 名义产能何时变成可交付供给 |
| 价格 | 合约价、实现价及涨幅斜率 | 涨价、放缓、见顶或下行 |

## 7. 初步线索：支持、削弱与反面情形

| 类型 | 需关注的情况 | 为什么重要 |
|------|--------------|------------|
| 支持方向 | AI/HBM 订单和服务器 DRAM、企业级 SSD 需求继续强 | 支持结构性偏紧 |
| 削弱方向 | PC、手机配置下调或消费端出货走弱 | 削弱全行业同步景气判断 |
| 反面情形 | 多层库存累积、订单取消或新增供给提前兑现 | 可能推翻价格继续上行 |
| 其他可能 | 涨价来自产品组合或短期抢货，而非真实供需缺口 | 区分周期持续性 |

本次研究分 HBM、非 HBM DRAM、NAND 三类产品判断，不把「周期结束」写成确定日期，也不把三类产品的机制差异合并成单一周期结论。不判断股价、评级、目标价或仓位。
