# 美国管制与国产设备替代投研需求说明

## 1. 研究需求确认

已与研究员确认以下三个问题：

| 确认项 | 问题 | 研究员回答 |
|---|---|---|
| 研究对象 | 看行业整体、细分设备类别，还是特定公司？ | 中国半导体设备行业整体 |
| 事件与时间 | 管制升级按单次事件看，还是合并看迄今已生效规则？前瞻多久？ | 合并评估迄今已生效升级，前瞻未来十二个月 |
| 交付方式 | 最终交付什么形态？要不要按类别和公司拆分？ | 主题深度研究；按设备类别及代表公司拆分受益强弱 |

## 2. 研究目标与核心问题

### 2.1 研究目标

判断美国出口管制是否会推翻、强化或改写中国半导体设备国产替代的投资逻辑，并把「政策有多紧迫」与「订单和业绩能否落地」分开，供行业跟踪、假设更新和主题深度研究使用。

### 2.2 核心问题

> 截至2026年7月10日已经生效的美国对华半导体设备出口管制合并作用，在未来十二个月内是否会改变中国半导体设备行业国产替代逻辑的成立条件、兑现路径和类别受益结构？

### 2.3 要回答的问题类型

| 项目 | 说明 |
|---|---|
| 问题类型 | 假设验证与更新 |
| 研究类型 | 假设验证与更新判断；兼看政策传导与事件影响 |
| 用途 | 行业跟踪、假设更新、进入完整研究链路并产出主题深度研究 |
| 最终要弄清什么 | 主逻辑是否改变；哪些设备类别与代表公司更可能兑现；哪些信号会改变判断 |

## 3. 研究对象

### 3.1 对象范围

| 对象 | 在研究中的角色 | 是否核心 | 说明 |
|---|---|---|---|
| 中国半导体设备行业 | 行业整体 | 是 | 本次判断的主对象 |
| 美国现行对华设备管制 | 外部政策约束 | 是 | 研究起点 |
| 前道与先进封装设备类别 | 细分赛道 | 否 | 用于解释受益分化 |
| 北方华创、中微公司、拓荆科技、盛美上海、华海清科、芯源微等 | 代表公司样本 | 否 | 验证商业化阶段，不代表完整行业名单 |

### 3.2 研究缘起

研究从美国对华半导体设备出口管制持续升级出发，检验「管制越紧、国产设备越受益」这一常见推断是否成立，以及未来十二个月受益是否取决于验证、复购和业绩兑现。

| 缘起 | 具体内容 | 来源 |
|---|---|---|
| 政策事件 | 2022年以来已经生效的美国对华半导体设备限制及执行升级 | 研究员问题与正式规则 |
| 待检验判断 | 管制收紧不必然等于所有国产设备未来十二个月都能兑现业绩 | 研究问题本身 |

## 4. 研究范围与边界

| 维度 | 怎么定 | 备注 |
|---|---|---|
| 时间 | 2022-10-07 至 2026-07-10 为现行基线，前瞻至 2027-07-09 | 尚未生效条款只作未来跟踪 |
| 地域 | 美国规则对中国大陆设备采购和国产供给的影响 | 海外厂商披露用于核对供给是否归零 |
| 产业链 | 规则—海外供给—晶圆厂需求—验证复购—交付验收—收入利润 | 不展开芯片设计与终端需求全景 |
| 对象 | 行业整体、至少五类设备、六家代表公司 | 公司只作样本，不外推全行业 |
| 不研究 | 个股估值、目标价、交易建议、未证实技术传闻 | 只输出研究判断与跟踪变量 |

## 6. 重点看什么

| 观察什么 | 看什么变化 | 可能说明什么 |
|---|---|---|
| 规则与执行 | 设备、软件、实体、许可和处罚是否实质收紧 | 外部约束是否成立 |
| 海外供给 | 成熟制程设备、备件和服务是否仍可供货 | 管制是不是「全面断供」 |
| 中国设备需求 | 晶圆厂设备支出是否维持足够大的需求池 | 替代有没有市场窗口 |
| 验证与复购 | 是否从首台进入批量、复购和跨线复制 | 商业化是否成熟 |
| 经营质量 | 收入、毛利、研发、验收与服务是否同步改善 | 投资逻辑是主题还是业绩 |
| 上游独立性 | 关键部件、软件和服务是否反向受限 | 国产整机交付上限 |

## 7. 初步线索：支持、削弱与反面情形

| 类型 | 需关注的情况 | 为什么重要 |
|---|---|---|
| 支持方向 | 规则执行收紧、国产设备批量复购、跨线复制和收入兑现 | 说明政策窗口可能转化为经营结果 |
| 削弱方向 | 中国设备支出高位趋缓、毛利率和利润承压 | 战略必要性未必转化为近端业绩 |
| 反面情形 | 海外成熟制程设备继续供货，国产整机上游部件受限 | 打断「管制越紧、全面越受益」的简单推断 |
| 其他可能 | 增长主要由全球设备周期、AI/存储和国内扩产驱动 | 不能把全部增长都归因于政策 |
