# 示例2：美国管制与国产设备替代（当前可运行样例）

本目录是现行本体、01—05 阶段规范和校验器共同使用的正式可运行样例。它用于证明以下链路能够完整运行：

```text
01 用户需求合同
→ 02 跨三域任务本体视图
→ 03 语义域与证据域实例、冻结推理输入及证据准入
→ 04 推理域实例与判断留痕
→ 05 真实研报正文与表达审计
```

其中，02 只固定本次任务所需的本次需要的本体范围；03、04 只生成本次任务记录，不直接修改正式本体。03 的规范化证据链和证据质量准入共同约束 04 的判断强度，并继续约束 05 的文字表达。

## 校验方式

在项目根目录执行：

```bash
python3 validate_project.py
```

只校验本次运行时执行：

```bash
python3 输出模板/validate_publish.py 示例2
```

返回 `PUBLISHABLE` 表示 01—05 的结构、跨阶段引用、证据质量、判断强度和表达边界均通过规则校验。资料真实性、经济含义和观点增量仍须由研究员完成独立复核。
