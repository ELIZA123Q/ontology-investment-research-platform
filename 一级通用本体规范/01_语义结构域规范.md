# 01-语义结构域规范

## 研究员先看什么

语义域回答：**研究什么**——稳定对象、边界与相对稳定的业务关系，给证据和推理提供锚点。

研究时用它：统一「公司 / 产品 / 环节 / 政策」等叫法；区分稳定身份与时点变化；避免把材料全文或单次观测塞进对象定义。

不保存材料全文、单次观测、方向判断或报告模板。行业实例进领域扩展或任务记录。

> 机器权威：[`semantic.yaml`](semantic.yaml)。下文是概念速查；完整字段、枚举、端点与约束以 YAML 为准。

---

## 1. 字段设置原则

- 需独立身份/关系/生命周期 → 对象；仅描述 → 属性。
- 关系 = 稳定连接；条件结果 → 规则/流程；时点变化 → 推理对象。
- 正式写入须经动作授权范围。

## 2. 对象（概念速查）

中文名优先；括号内为系统类型名。

- **概念** (`Concept`)：术语定义与边界，不自动等同现实对象
- **产业 / 环节** (`Industry` / `Segment`)：产业分类与产业链稳定位置
- **组织 / 公司** (`Organization` / `Company`)：可识别主体；商业经营用公司
- **产品 / 材料 / 工序** (`Product` / `Material` / `ProcessStep`)
- **地区** (`Region`)：地理/经济/监管范围；不是临时政策事件
- **应用** (`Application`)：稳定下游用途或需求场景
- **政策工具 / 政策要求 / 技术约束** (`PolicyInstrument` / `PolicyRequirement` / `TechnicalConstraint`)
- **资产 / 金融工具** (`Asset` / `FinancialInstrument`)：标的与合约身份；价格与交易动作不进本对象
- **识别码 / 识别体系 / 交易场所 / 上市挂牌 / 角色承担** (`Identifier` / `IdentificationScheme` / `TradingVenue` / `Listing` / `RoleAssignment`)

## 3. 关系（概念速查）

关系表达稳定连接（归属、供应、替代、竞争、政策适用、资产暴露等）。完整端点名与约束只在 [`semantic.yaml`](semantic.yaml) 维护。

常见研究用法：公司归属产业/参与环节；产品用材料、用于应用；政策适用对象与地区；资产对业务对象暴露。时点占比、敏感度、订单强度进入推理域。

## 4. 与证据域、推理域的交界

| 内容 | 放哪 |
|---|---|
| 稳定身份与结构关系 | 语义域 |
| 来源说法、归一事实、够不够用 | 证据域 |
| 时点观测、信号、判断、影响 | 推理域 |
