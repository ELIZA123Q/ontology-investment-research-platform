# 国产材料放量场景卡

适用问题：国产材料是否完成认证并进入净耗用放量。

## 决胜分歧

放量须经送样、小批、单线、批量、复购、跨厂；批次一致性与原料依赖常比实验室性能更关键。须先固定材料族（衬底外延 / 化学品气体 / 靶材CMP / 封装材料）。互斥主判断模式：净消耗认证 / 批次稳定供应 / 份额与韧性（每次一个）。

## 1. 本场景相对于主框架增加什么

相对 IF-MAT-01，本卡增加：

1. 国产替代下的客户变更控制与披露稀缺（用量代理组合验证）；
2. 与 IF-LOC 分工：本卡主判认证放量，LOC 判约束加速与残存依赖；
3. 互斥主判断模式，防止一次性扫完全部材料链。

## 2. 和哪个主框架一起用

| 项目 | 内容 |
|---|---|
| 默认主框架 | IF-MAT-01 |
| 条件辅助框架 | 约束/韧性→IF-LOC；工艺或封装位置→IF-FAB / IF-PKG |
| 默认排除 | 未固定材料族前不展开；SC/DES/EQP 除非必要 |
| 不适用问题 | 无规格等级的泛化“国产材料行情” |

## 3. 场景特有判断脊柱

```text
选定材料族与主判断模式
→ 净消耗与规格适配
→ 产线认证与批次稳定
→ 合格供应与复购跨厂
→ （若问韧性）残存上游依赖交LOC
```

## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |
|---|---|---|---|
| 认证放量 | 批量复购跨厂同向 | 仅送样小批 | 分阶段客户证据 |
| 批次质量 | 多批稳定良率可控 | 小批过量产退货 | 多批质量/退货 |
| 份额来源 | 同工艺份额升 | 行业投片驱动耗用 | 份额vs行业耗用 |
| 上游依赖 | 原料双源 | 新单点原料风险 | 原料穿透 |
