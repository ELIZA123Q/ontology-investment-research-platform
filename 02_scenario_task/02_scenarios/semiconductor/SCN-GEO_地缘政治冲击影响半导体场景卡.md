# 地缘政治冲击影响半导体场景卡

适用问题：地缘政治或出口管制冲击如何落到半导体实物链路（市场情绪通道另交基础框架）。

## 决胜分歧

地缘事件必须拆为规则范围、真实暴露、缓冲、替代与结果。**先分流市场通道与实物通道**：市场通道不在本产业场景卡内推导股价；实物确认后再选产业链落点。舆论≠执行，贸易额≠公司暴露。

## 1. 本场景相对于主框架增加什么

相对 IF-LOC-01，本卡增加：

1. 双轨分流：市场通道 vs 实物通道；
2. 事件—暴露—缓冲—落点的顺序（不并联全产业链）；
3. 一次性冲击 vs 持续约束时钟。

## 2. 和哪个主框架一起用

| 项目 | 内容 |
|---|---|
| 默认主框架 | IF-LOC-01（仅实物通道） |
| 条件辅助框架 | 实物落点：材料→IF-MAT；设备→IF-EQP；制造→IF-FAB；周期→IF-SC |
| 市场通道交接 | 风险偏好/预期差/估值 → BF-EG-01 / BF-RS-01 / BF-VA-01（不得在本卡内直接推股价） |
| 默认排除 | 未确认实物影响前不展开 EQP/MAT/SC |
| 不适用问题 | 无地缘/政策/物流/能源暴露的纯产品问题 |

## 3. 场景特有判断脊柱

```text
事件性质与影响范围
→ 市场通道或实物通道确认（互斥优先）
→ 若实物：受限物项与暴露→缓冲→产业链落点
→ 若市场：交接基础市场/预期差/估值框架
→ 改判信号
```

## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |
|---|---|---|---|
| 通道选择 | 明确主通道后再展开 | 未分流就推产业与股价 | 通道判定记录 |
| 规则执行 | 正式政策/许可/生效期 | 仅舆论 | 正式文本与执行 |
| 真实暴露 | 关键节点供应商/客户暴露 | 暴露非关键 | 暴露矩阵 |
| 缓冲吸收 | 库存/合同/替代覆盖 | 缓冲耗尽扰动显现 | 库存+替代+合同 |
