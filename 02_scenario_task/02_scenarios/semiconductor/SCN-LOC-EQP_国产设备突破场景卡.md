# 国产设备突破场景卡

适用问题：国产设备是否进入主工艺、主供与复购，而非仅备份或样机验证。

## 决胜分歧

“突破”至少分为样机、验证、量产线、验收、**工艺位置（备份/非关键/主工艺）**、主供、复购与跨厂复制。能完成一次工艺≠改变客户工艺依赖。**整机进入主工艺仍可能被 BOM 关键件卡住**；关键件可得性须与工艺位置同级判断，结果回读 `IF-LOC.residual_dependency`。互斥主判断模式：验证验收 / 主工艺进入 / 复购复制（每次只主攻一个）。

## 1. 本场景相对于主框架增加什么

相对 IF-EQP-01，本卡增加：

1. 国产替代语境下的客户切换风险与核心部件（二阶）依赖；
2. 备份设备 vs 主工艺/关键层采用的辨识；
3. 与 IF-LOC 的分工：本卡主判设备阶段与工艺位置，并输出关键件残存依赖供 LOC 读取。

## 2. 和哪个主框架一起用

| 项目 | 内容 |
|---|---|
| 默认主框架 | IF-EQP-01 |
| 条件辅助框架 | 约束/韧性→IF-LOC-01；工艺环节约束→IF-FAB 或 IF-PKG |
| 默认排除 | 未定位前不展开 MAT/SC/DES |
| 不适用问题 | 非国产替代语境的纯海外设备 TAM、无具体设备类别 |

## 3. 场景特有判断脊柱

```text
选定主判断模式
→ Fab工艺需求与设备类别
→ 验证线位置与工艺结果
→ 备份/非关键/主工艺升级
→ BOM关键件可得性（与工艺位置同级）
→ 验收、复购、跨线与服务依赖
```

## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |
|---|---|---|---|
| 工艺位置 | 进入主工艺或关键层 | 仅备份/示范线 | 线位置+工艺结果 |
| 复购复制 | 重复订单与跨线 | 仅首台/政策单 | 首台后复购证据 |
| 关键件依赖 | 关键件可得且可维护 | 整机国产、部件仍卡脖子 | BOM关键件+供应路径 |
| 经济性 | 复购伴随可接受毛利 | 低价导入利润弱 | 价格/毛利代理 |

## 5. 对任务执行的增量约束

以下为系统登记，研究员可不读。

```yaml
scenario_constraints:
  required_splits:
    - 主判断模式三选一
    - 备份或非关键 / 主工艺 / 主供
    - 样机 / 验证 / 验收 / 复购 / 跨线
    - 整机工艺位置 / BOM关键件依赖
  mandatory_evidence:
    - 设备类别与工艺步骤
    - 线位置与多批工艺结果
    - 复购/跨线与核心部件服务
  counter_evidence:
    - 长期停留备份位
    - 无复购
    - 核心部件仍受限
  stop_if:
    - 未选定主判断模式
    - 只有进入客户名单无工艺位置
    - 主工艺叙事未核对BOM关键件
  recommended_methods:
    - IF-EQP-01
    - IF-LOC-01
```
