# 半导体场景卡 — 研究情境的增量约束

> 上级目录：[`02_scenarios/`](../README.md) | 根目录：[`README.md`](../../../README.md)

本目录是半导体 SCN-* 场景卡的**唯一权威正文**。场景卡是主框架的差异适配器——在已有研究框架上补充特定情境的额外约束。

## 怎么用

1. 先选 1 个主框架（在 [`research-design` Skill](../../../03_agent_capability/02_skills/research_design/SKILL.md) 里选）
2. 再按需挂 0-1 张场景卡——场景卡只补增量约束，不是缩小版主框架
3. 场景卡不用时不必解释为什么不用

> 登记见 [`registry.yaml`](registry.yaml)，模板见 [`../_scenario_card_template.md`](../_scenario_card_template.md)。
