# 光电子芯片与硅光场景卡

适用问题：光电子芯片与硅光路线的价值量、瓶颈与传导。

## 决胜分歧

网络带宽到光芯片收入须经交换架构、速率、端口、铜光边界、模块方案、良率与认证。模块整机收入≠半导体器件收入。每次任务只选一个互斥主判断模式，禁止单次任务做全产业链扫描。

## 1. 本场景相对于主框架增加什么

相对 IF-APP-01，本卡增加：

1. 端口/速率/距离/模块BOM→器件价值量传导；
2. InP/Si/SiGe/硅光路线与耦合封装约束；
3. **互斥主判断模式**：网络需求传导 / 技术路线替代 / 供应瓶颈 / 器件价值量与利润池。

## 2. 和哪个主框架一起用

| 项目 | 内容 |
|---|---|
| 默认主框架 | IF-APP-01 |
| 条件辅助框架 | 外延/硅光平台→IF-FAB；耦合封装/测试→IF-PKG；认证路线→IF-DES |
| 默认排除 | 未选模式前不并联 FAB+PKG+DES；IF-SC/LOC/EQP 除非已定位 |
| 不适用问题 | 纯光模块整机财务、无关网络架构的单点器件 |

## 3. 场景特有判断脊柱

```text
选定主判断模式
→ 网络架构/端口/速率/距离（若需求模式）
→ 或路线比较（若替代模式）
→ 或分工序约束（若瓶颈模式）
→ 或模块BOM vs 芯片价值（若利润池模式）
```

## 4. 场景增量变量与竞争解释

| 决胜变量 | 主解释成立时 | 竞争解释成立时 | 最低验证 |
|---|---|---|---|
| 器件价值量 | 端口升级带动芯片BOM | 模块ASP升芯片价值降 | 模块与芯片价值分开 |
| 路线替代 | 硅光份额持续升 | 路线分工互补非替代 | 份额+客户认证 |
| 耦合瓶颈 | 外延/晶圆是瓶颈 | 耦合封装/测试是瓶颈 | 分工序产能良率 |
| 客户认证 | 平台导入与复购 | 单客户样品外推 | 多客户量产 |
