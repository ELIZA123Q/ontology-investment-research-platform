# 管制约束上升，国产设备受益先看认证、再看采购

## 研究问题

1. 管制是否直接改变先进设备可得性？
2. 国产设备认证是否从评估推进到量产导入？

## 主要判断

**管制传导（J3）**

新规则提高部分先进设备的许可约束，设备可得性不确定性上升。该判断通过 `eventAffectsState` 将政策事件与样本晶圆厂约束关联，但不外推至全部厂商或全部设备品类。

**国产替代（J2）**

国产刻蚀设备在样本客户的验证机会增加，但当前证据只支持“认证推进”：

- 支持：设备商披露新增客户进入验证（EV-12）
- 反证：验收尚未转化为规模采购（EV-13）
- 缺口：跨客户批量采购直接序列仍缺失（EG-11，partially_met）

验证进展**不能直接外推**为全品类替代、规模采购或收入兑现。

## 失效条件与增量更新

国产替代判断（C-12）在以下情况失效：

- 关键验证失败
- 客户终止采购

增量演练（`incremental_update.yaml`）：当 EV-14「样本客户关键验证失败」进入后，EA-12 评估失效，只需重算 JU-02 链（RE-12 → C-12 → EX-12）。**JU-01 管制判断保持 current**，无需重跑 stage 02 或全量流程。
