# 工作区（Workspace）

这里存放「某次任务正在产生或已经留下」的运行产物与历史样例，用于回放、对照和回归，不是可复用方法真理库。

## 给谁看

- **研究员：** 查阅历史样例、了解某次研究留下了什么
- **维护者：** 回归夹具与导出治理

## 材料从哪来

| 子区域 | 含义 |
|---|---|
| [`03_回归/`](03_回归/README.md) | 已验收运行冻结的回归夹具 |
| `02_V3样例/` 等 | 历史样例快照（只读回放） |
| [`registry.yaml`](./registry.yaml) | 本目录登记 |

现行会话数据默认在 `07_runtime/.data/`；本目录多为导出/归档/兼容路径。

## 怎么用

1. 看现行研究 → 用工作台，不必先翻 Workspace。
2. 回放历史 → 打开对应样例目录的 README，按阅读顺序看产物。
3. 把内容当作「当时快照」，不要当成现行方法规范。

## 怎么维护

- 新正式方法/本体不要写进 Workspace。
- 刷新回归夹具前先通过工作台校验，再按 `03_回归` README 的脚本快照。
- **status:** migrating
