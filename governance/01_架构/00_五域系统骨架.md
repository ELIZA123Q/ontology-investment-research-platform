# 00_五域系统骨架

> 本文件定义 Agent-native 投研研究系统的一级职责域。与 [`00_项目定位与边界.md`](./00_项目定位与边界.md) 冲突时，以定位文档的产品边界为准；与目录布局冲突时，以本文件 + [`repo_layout.yaml`](./repo_layout.yaml) 为准。
>
> 迁移状态见 [`../04_路线图/2026-08-06_五域迁移资产账本.md`](../04_路线图/2026-08-06_五域迁移资产账本.md)。

## 1. 定调

本项目从「写死 01—05 的投研程序」转向 **Agent-native 研究系统**：

```text
User Intent → Task → Context → Agent → Skill / Tool / Knowledge → Workspace → Result
```

原 01—05 **不删除**，降级为 **Deep Research Workflow**（深度研究任务的一种推荐执行路径），挂在 `tasks/workflows/deep_research/`，不再充当仓库骨架。

组织原则：**按系统职责拆层，不按技术名词堆目录。** 只建评估通过的目录；壳目录必须有 README（回答什么 / 不放什么 / 当前权威在哪 / `status`）。

## 2. 五域 + App

| 一级域 | 核心问题 | 目标目录 |
|--------|----------|----------|
| **Semantic** 语义知识域 | Agent「理解什么」 | `semantic/` |
| **Task** 场景任务域 | Agent「要完成什么」 | `tasks/` |
| **Capability** 能力域 | Agent「靠什么完成」 | `capabilities/` |
| **Execution** 执行状态域 | Agent「这一次具体怎么工作」 | `execution/` |
| **Governance** 控制评估域 | Agent「什么能做、做到什么程度算对」 | `governance/`（内部分层目标壳） |
| **App**（波次 4） | 用户看见什么 | 现权威 `runtime/app/`；根级 `app/` 缓建 |

```text
semantic/          # 世界是什么（不写研究步骤）
├── ontology/
├── dictionary/
├── knowledge_graph/
└── evidence/

tasks/             # 要完成什么
├── scenarios/
├── definitions/
├── roles/
└── workflows/deep_research/

capabilities/      # 靠什么完成
├── agents/
├── skills/
├── tools/
└── protocols/{mcp,a2a}/

execution/         # 这次如何运行
├── context/
├── memory/
├── workspace/
└── runtime/

governance/        # 能做什么、什么算做好（与现有 01_架构 等并存过渡）
├── rules/
├── identity/
├── permissions/
├── evals/
└── verifiers/
```

## 3. 职责边界

| 域 | 可以放 | 禁止放 |
|----|--------|--------|
| Semantic | 稳定对象/关系/约束、概念口径、图合同、证据 provenance 与来源准入 | 研究步骤、阶段门、prompt、单次结论 |
| Task | 场景、标准 Task 定义、角色、推荐 workflow | 本体定义、工具实现、评测协议正文 |
| Capability | Agent 组织、Skill、Tool、MCP/A2A 协议 | 世界模型、单次 workspace 产物 |
| Execution | Context 装配、Memory、Workspace、Runtime 引擎 | 可复用方法正文、正式本体 YAML |
| Governance | Rules、Identity、Permission、Eval、Verifier | 业务对象定义、单次研究事实 |
| App | UI/API | 权威业务定义（只消费各域） |

### 3.1 Verifier ≠ Eval

- **Verifier**（确定性）：schema、来源存在、引用可回溯、结论是否绑证据、门槛字段 → 目标 `governance/verifiers/`（现权威 `governance/03_校验/`）。
- **Eval**（质量判断）：洞察、遗漏关键变量、决策价值、相对增益 → 目标 `governance/evals/`（现权威 `evaluation/`）。

### 3.2 Agent ≠ Skill ≠ Tool

- **Agent**：能力的组织与决策者（何时调什么）。
- **Skill**：怎么完成某类任务（可版本化程序/知识）。
- **Tool**：具体执行动作（含 MCP 暴露的外部能力）。
- **MCP / A2A**：连接协议；A2A 仅边界占位，未实现前禁止假协议代码。

### 3.3 Execution 四件套不是四种知识库

| 组件 | 含义 |
|------|------|
| Context | 这一刻模型看见什么（动态组装） |
| Memory | 跨任务保留什么 |
| Workspace | 这次任务正在产生什么 |
| Runtime | 谁负责真正跑起来 |

### 3.4 Workflow 的地位

以前：Workflow 决定系统怎么跑。  
以后：Task 决定目标；Agent 按 Context 调 Skill/Tool；**Workflow 只是某些 Task 的推荐路径**。

## 4. 过渡期权威（本轮边界）

“权威在哪”优先查：

1. [`five_domain_authority.yaml`](./five_domain_authority.yaml)
2. 各域 `registry.yaml`（`semantic/` `tasks/` `capabilities/` `execution/` + `governance/{rules,evals,verifiers,identity,permissions}/`）
3. [`repo_layout.yaml`](./repo_layout.yaml) / [`compat_policy.yaml`](./compat_policy.yaml)

| 能力 | 新增改动入口（write） | 默认读取（read_primary / 镜像） | compat 回放 |
|------|----------------------|--------------------------------|-------------|
| 正式本体 | `semantic/ontology/` 登记 | `ontology/` | `ontology/` |
| Deep Research 阶段规范 | `tasks/workflows/deep_research/` | `tasks/workflows/deep_research/` | `runtime/workflow/stage_specs/` |
| 上下文白名单 | `governance/01_架构/runtime_contexts.yaml` | 同上 | `governance/architecture/` |
| 覆盖矩阵 | `governance/03_校验/runtime_asset_coverage.yaml` | 同上 | `governance/validation/` |
| Agents / Skills 实现 | 暂不重写 | `runtime/agents/` `runtime/skills/` | 目标 `capabilities/` |
| 运行实例 | 不清洗 | `instances/` | 目标 `execution/workspace/` |
| 评测 | `governance/evals/` 契约 | `evaluation/` | `evaluation/` |
| 校验脚本 | `governance/verifiers/` 契约 | `governance/03_校验/` | `governance/validation/` |
| UI | 不改结构 | `runtime/app/` | 根级 `app/` 缓建 |

规则：

- **新增改动**写五域 write_entry；旧顶层不再作为新增入口。
- **旧路径保留可读**，供回放与未切消费侧使用；标 `README.compat.md`，`write_policy: deny_new_writes`。
- **不删除**旧目录、不清洗 `instances/` / `evaluation/`、不重写 `runtime/agents|skills` 核心逻辑、不改 `ontology/*.yaml` 语义。

壳目录 `status: shell` = 仅契约；`migrating` = 注册表可回答权威、物理迁移未完成；`active` = 可独立作为入口。

## 5. 明确不做（骨架阶段）

- 不重写本体业务语义，不扩第二行业。
- 不删除 Deep Research 01—05 能力。
- 不放宽 Eval；不宣称研究增益。
- 不建四套 `*-ui` 空目录；不建无账本支撑的空行业子树。
- **Memory / Identity / Permission**：仅契约与最小矩阵（wave5）；不实现完整存储与 RBAC。
- **A2A**：仅边界文档 + registry（wave5）；禁止假协议实现。

入口层（波次 0–5）封版说明见迁移账本。
