# 语义词典

这里统一「同一个概念在人话里怎么叫、怎么解释」，避免同一事物多种说法导致误解。

## 给谁看

- **研究员**：对齐口径（例如同一指标不同叫法）
- **维护者**：维护人类可读说明；机器唯一枚举仍以本体 YAML 为准

## 材料从哪来

- 人类可读说明多与 [`../01_ontology/`](../01_ontology/README.md) 中的概念对应
- 机器权威枚举在本体 YAML，不在本目录另建平行副本
- 迁移索引见 [`registry.yaml`](./registry.yaml)

## 怎么用

1. 遇到名称不一致 → 先查本目录词典说明，再对照本体正式名。
2. 写报告或任务时，优先使用词典与本体已对齐的叫法。
3. 不要把研究流程或单次结论写进词典。

## 怎么维护

- 只补充概念口径与可读说明；不把流程、单次结论、工具实现塞进来。
- 若新增正式枚举，先改本体，再补词典说明，并更新 `registry.yaml`。
- 当前 status 多为 migrating：改完走治理/语义校验。
