# 预期差判断框架

## 1. 适用问题与边界

用于判断新事实或研究判断相对市场既有预期是否形成可比差异，差异来自方向、幅度、时点、持续期还是风险，并分析其可能如何收敛。

没有明确预期主体、指标、对象、情景和观测时间，就不能声称存在预期差。资产价格变化也不能单独证明市场原先预期是什么。

## 2. 核心判断任务与关键口径

核心任务是对齐“同一对象、同一指标、同一时间和同一情景”下的研究判断与市场预期，并分开判断信息质量、差异大小、计价程度和收敛节点。

- **预期主体**：一致预期、公司指引、卖方、买方内部、价格隐含或用户提供预期必须区分。
- **预期截面**：预期形成或被记录的业务时间，不能用事后修订值代替当时基线。
- **差异维度**：方向、幅度、时点、持续期和风险并列记录，不压缩成“超预期/低于预期”。
- **计价程度**：需要盈利预测修订、估值和价格反应等证据组合，不由主观印象判断。

## 3. 核心问题树

1. 谁的预期、关于哪个对象和指标、对应什么期间与情景？
2. 基线在新信息出现前何时形成，是否仍然有效？
3. 新信息属于事实、估算、指引、预测、假设还是观点？
4. 研究判断与基线在方向、幅度、时点、持续期和风险上差多少？
5. 差异是否足以改变经营预测、估值输入或情景权重？
6. 资产价格、估值和盈利预测是否已经反映该差异？
7. 哪个后续事件会使差异收敛、扩大或被证伪？

## 4. 分析模块与传导机制

| 模块 | 核心变量与机制 | 主要信号 | 典型窗口 |
|---|---|---|---|
| EG-M1 基线建档 | 主体、指标、期间、情景和截面组成可比较预期 | 一致预期、指引、价格隐含数据 | 新信息前固定截面 |
| EG-M2 信息质量 | 事实/估算/预测/观点的可靠性和新鲜度决定权重 | 公告、财报、数据、调研、报道 | 信息有效期 |
| EG-M3 差异分解 | 判断 − 预期 → 方向/幅度/时点/持续期/风险差 | 可比预测、实际值、假设表 | 同指标同期间 |
| EG-M4 经营含义 | 差异是否改变收入、利润、现金流和资本回报路径 | 模型修订、关键驱动更新 | 预测期 |
| EG-M5 计价检查 | 预测修订、估值和价格反应共同反映计价程度 | 盈利修订、估值、事件窗口价格 | 事件前后及中期 |
| EG-M6 收敛机制 | 财报、订单、政策、产品或风险事件使差异收敛 | 催化、验证、削弱、阻断信号 | 明确下一验证点 |

## 5. 最低证据与交叉验证

- 必须同时有带业务时间的预期基线和口径一致的新信息或研究判断。
- 预期来源须注明主体、样本覆盖、统计方法和是否为事后修订。
- 新信息须区分事实、估算、指引、预测和观点，并记录原始位置。
- 判断计价程度至少结合预测修订、估值或价格反应中的两个维度。
- 价格反应分析需控制宏观、行业和资金等竞争解释。

## 6. 竞争解释、阻断与停止条件

竞争解释包括基线过时、样本偏差、指标口径不同、信息早已公开、价格由宏观或资金驱动、市场关注不同时间窗口、差异虽存在但不影响现金流。

关键阻断条件：找不到事前预期截面；判断与预期不在同一对象/指标/期间；新信息可靠性不足；差异不能改变任何经营或估值输入。任一命中时停止形成预期差结论，只保留待补证据。

## 7. 情景设置

- **差异收敛**：后续事实向研究判断靠拢，市场预测逐步修订。
- **差异维持**：验证节点延后，双方判断保持分歧。
- **研究判断被证伪**：关键事实向原市场基线靠拢或出现阻断信号。
- **已提前计价**：研究判断方向正确，但预测、估值或价格已经充分反映。

每个情景必须写明下一验证事件、时间窗口和需要更新的预期截面。

## 8. 本体映射

**一级正式本体**：研究判断使用 `Judgment`，预期基线使用 `MarketExpectation`，比较结果使用 `ExpectationGap`，对象连接使用 `expectationAbout`、`gapComparesJudgment` 和 `gapComparesExpectation`，资产影响另由 `AssetImpact` 承接；证据通过正式证据关系支撑预期或信号，不能直接支撑最终资产影响。

**领域扩展可选项**：行业专用一致预期指标、事件窗口和隐含预期算法仅在领域或系统规范已有定义时使用。

**任务候选或本体缺口**：预期分歧度、修订扩散度、隐含增长、计价程度等先作为候选状态变量或函数需求。

## 9. 组合与裁剪

- 公司经营判断来自 BF-EE-01/BF-FS-01，估值影响接 BF-VA-01。
- 政策或价格事件分别接 BF-PI-01/BF-PC-01，先完成基本面验证再比较预期。
- 不涉及资产或市场预期的研究可不启用本框架。
- 预期基线不可得时只记录待补材料，不用“市场可能认为”填充。

## 10. 权威依据卡

| 项目 | 内容 |
|---|---|
| 主要来源 | CFA Institute《Company Analysis: Forecasting》与分析师技能框架；Damodaran 估值和隐含假设方法；华泰证券催化与预期差框架（华泰智研MCP数据服务） |
| 采用内容 | 预测对象、基线、情景、差异分解、估值输入和市场反映 |
| 本地化改写 | 强制保存事前截面、预期主体和五维差异，并与一级本体对象直接对齐 |
| 未采用内容 | 不采用资金配置、交易时点、评级和单点资产价格表达 |
| 证据等级 | 多来源方法论候选；计价判断仍需按市场补充历史事件样本 |

## 11. 框架自检

- [ ] 预期主体、对象、指标、期间、情景和截面完整。
- [ ] 新信息的表述类型与可靠性已区分。
- [ ] 比较对象口径一致。
- [ ] 差异已拆成方向、幅度、时点、持续期和风险。
- [ ] 计价判断至少有两个维度的证据。
- [ ] 下一验证点、收敛路径和阻断条件可观察。
