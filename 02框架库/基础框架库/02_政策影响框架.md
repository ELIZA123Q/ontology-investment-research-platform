# 政策影响框架

## 1. 适用问题与边界

用于判断财政、货币、产业、税收、补贴、准入、监管、采购、贸易和出口管制等政策，是否通过约束、激励和资源配置改变主体行为及产业状态。

政策文本发布只是 `Event`，不等于执行、行为改变、行业受益、公司兑现或资产影响。本框架不评价政策立场本身，也不从政策标题直接推导受益对象。

禁止跳步：`政策发布 → 公司业绩`、`支持性措辞 → 需求增长`、`限制措施 → 国产替代兑现` 均是不完整路径。

## 2. 核心判断任务与关键口径

核心任务是把政策拆成可执行工具，并建立“法律效力—执行资源—主体行为—产业状态—公司兑现”的逐段验证链。

- **政策工具**：预算、税率、补贴、许可、标准、采购、信贷、价格、处罚或贸易限制等可执行手段。
- **法律与执行强度**：发布主体、约束力、细则、预算、执法和问责共同决定实际强度。
- **适用对象**：直接对象、间接受影响对象、豁免对象和可绕行对象必须分开。
- **反事实基线**：没有该政策时的行为和状态，用于识别政策的净影响而非同期共振。

## 3. 核心问题树

1. 政策工具、主管机构、法律效力、地域、对象和生效时间是什么？
2. 落地是否依赖细则、预算、许可、地方配套、执法或金融条件？
3. 政策直接改变成本、收入、准入、供给、需求、技术路线还是融资约束？
4. 各主体会接受、提前、延后、替代、规避还是套利？
5. 影响如何跨产业链传导，在哪些环节被吸收、放大或阻断？
6. 行业变化能否由公司暴露、承接能力和履约进度兑现？
7. 当前市场预期是否已经包含政策方向、力度和时点？

## 4. 分析模块与传导机制

| 模块 | 核心变量与机制 | 主要信号 | 典型窗口 |
|---|---|---|---|
| PI-M1 政策识别 | 文本 → 工具、对象、地域、效力、例外 | 正式文件、主管部门解释 | 发布至生效 |
| PI-M2 执行准备 | 工具 + 预算/细则/许可/执法 → 可执行强度 | 预算、细则、名单、处罚、拨付 | 数周至数年 |
| PI-M3 行为响应 | 激励或约束 → 企业、消费者、金融机构行为改变 | 申报、采购、投资、融资、合规动作 | 依主体决策周期 |
| PI-M4 产业影响 | 行为变化 → 供需、成本、准入、竞争和技术路线变化 | 订单、价格、产能、份额、替代 | 通常滞后行为变化 |
| PI-M5 公司兑现 | 产业状态 × 公司暴露 × 承接能力 → 订单/收入/成本 | 资格、认证、合同、交付、回款 | 依商业和会计确认周期 |
| PI-M6 预期与失效 | 预期基线 + 落地差异 → 预期修正；政策撤回或绕行削弱路径 | 一致预期、政策修订、执行偏差 | 贯穿全程 |

默认主路径：`政策发布 → 细则/预算/执法 → 主体行为变化 → 产业供需或竞争变化 → 公司商业兑现 → 财务影响 → 市场预期变化`。

## 5. 最低证据与交叉验证

- 政策身份和约束力优先使用正式文本、主管机构页面及法规数据库。
- 执行至少需要细则、预算、名单、许可、执法、拨付或实际行为中的一项直接证据。
- 行业影响至少用产业数据或多个受影响主体披露验证，不能只引用政策解读。
- 公司兑现需有资格、认证、订单、交付、回款或财务披露，概念关联只能作弱信号。
- 关键比较必须记录政策发布、生效、执行和观测的不同业务时间。

## 6. 竞争解释、阻断与停止条件

竞争解释包括同期经济周期、其他政策叠加、企业原有扩产计划、需求前置、地方执行差异、市场先行预期和技术自然迭代。

关键阻断条件：政策无强制力或无预算；细则长期缺失；豁免或绕行覆盖主要对象；受影响主体不改变行为；公司没有资格、产品、产能或交付能力。直接效应未出现时，停止向行业和公司层继续推导。

## 7. 情景设置

| 情景 | 执行强度 | 主体响应 | 研究重点 |
|---|---|---|---|
| 基准 | 按正式预算和既有执法能力落地 | 部分调整 | 验证直接对象和首个行为节点 |
| 强执行 | 细则、资金和问责同步强化 | 快速调整 | 检查供需、准入和利益分配变化 |
| 弱执行/受阻 | 预算、许可或地方执行不足 | 观望、规避或延后 | 停止把文本目标外推为产业结果 |
| 反向调整 | 政策修订、退坡、撤回或外部反制 | 路径逆转 | 重新建立反事实和受损对象 |

## 8. 本体映射

**一级正式本体**：稳定政策身份使用 `PolicyInstrument`，发布、修订、执行、延期和失效使用 `Event`；发布与管理主体使用 `Organization`，地域使用 `Region`，适用对象使用一级正式语义关系。动态影响使用 `StateVariable`、`Observation`、`Hypothesis`、`Signal`、`Scenario`、`Judgment` 和 `ReasoningTrace`。

**领域扩展可选项**：具体产业的准入、替代、合规或技术变量仅在领域本体已有定义时使用，并注明来源版本。

**任务候选或本体缺口**：执行强度、预算兑现率、合规摩擦、政策绕行能力、受益承接能力等先作为候选状态变量；稳定复用且正式本体缺失时再登记缺口。

## 9. 组合与裁剪

- 产业链分配接 BF-VT-01，供需影响接 BF-SD-01，公司兑现接 BF-EE-01。
- 涉及市场计价时接 BF-EG-01 或 BF-VA-01，不能从政策文本直跳资产影响。
- 纯政策执行研究可止于 PI-M4；公司问题必须保留 PI-M5。
- 宏观政策需同时接 BF-MF-01，区分政策工具、金融条件和实体传导。

## 10. 权威依据卡

| 项目 | 内容 |
|---|---|
| 主要来源 | OECD《G20/OECD Principles of Corporate Governance 2023》中的政策、治理与披露原则；Federal Reserve 货币政策传导说明；华泰证券政策与宏观研究框架（华泰智研MCP数据服务） |
| 采用内容 | 工具与执行区分、治理和披露、金融条件传导、政策落地时滞 |
| 本地化改写 | 增加主管机构—细则—预算—地方执行—公司承接的中国政策研究链条 |
| 未采用内容 | 不采用立场性政策评价、配置建议和交易表达 |
| 证据等级 | 多来源方法论候选；需要按政策类型补充历史执行与反例样本 |

## 11. 框架自检

- [ ] 已使用正式政策文本并区分发布、生效和执行时间。
- [ ] 政策工具、直接对象、豁免和绕行路径已明确。
- [ ] 至少验证一个真实行为变化，而非只解释文本。
- [ ] 行业影响与公司兑现之间没有跳步。
- [ ] 已建立无政策反事实或其他同期解释。
- [ ] 阻断条件可观察，政策弱执行时会停止后续推导。
