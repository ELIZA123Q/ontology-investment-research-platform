# 车规芯片认证与装车场景卡

## 决胜分歧

AEC/功能安全等资质、客户定点、PPAP/产线认证、车型 SOP、实际装车和跨车型平台复用是不同阶段。车规商业化常受车型周期、责任风险、长期供货、软件适配和供应保障约束。

最有辨识力的证据是具体平台/车型、SOP 时间、单车用量、实际采购/装车与后续复购；“通过认证”只证明进入候选，不证明收入兑现。还要检查车型销量不及预期和客户延迟量产两类竞争解释。

## 1. 适用问题

用于判断汽车芯片从样品、测试、Tier1验证、主机厂定点、SOP、实际装车到复购的兑现路径。适用于汽车 MCU、功率芯片、座舱/智驾芯片、电源管理、传感和安全芯片等问题。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 需求框架 | IF-APP-01 应用需求与半导体内容量 | 判断车型、平台、配置和单车芯片内容量 |
| 设计框架 | IF-DES-01 芯片设计、IP与产品商业化 | 判断产品开发、认证、Design Win 和量产复购 |
| 横向约束 | IF-LOC-01 外部约束、国产替代与供应链韧性 | 判断国产替代、供应安全和客户切换 |
| 横向状态 | IF-SC-01 半导体周期与库存 | 判断汽车芯片库存和供需周期 |

## 3. 最小判断链

```text
车型/平台产量与配置渗透
→ 单车芯片数量和价值量
→ 芯片功能、质量、可靠性和安全要求
→ Tier1验证与主机厂定点
→ SOP、实际装车和售后质量反馈
→ 复购、跨平台采用和收入利润兑现
```

## 4. 关键变量

- 车型/平台产量、配置渗透率和单车内容量
- 环境可靠性、EMC、功能安全、信息安全和长期供货
- Tier1验证、主机厂定点、SOP和实际装车
- 平台生命周期、年降、保修、召回和质量反馈
- 国产替代时的客户切换成本和供应韧性

## 5. 最低证据

- 车型/平台、SOP时间、采购份额和定点范围
- 芯片测试、Tier1验证、主机厂验证和整车匹配证据
- 实际装车、量产供货、售后质量和复购证据
- 价格年降、质量赔付、召回和保修条款
- 供应链稳定性、长期供货和变更控制证据

## 6. 主要反证与阻断

- 定点项目延期或取消
- SOP不等于实际装车和稳定供货
- 质量问题、召回或现场失效率上升
- 平台销量不及预期或配置渗透率下降
- 年降、保修和服务成本抵消放量收益

## 7. 停止条件

- 只有样品或单项认证，没有Tier1/主机厂验证
- 只有定点金额，没有平台、SOP和采购份额
- 无法证明实际装车和量产供货
- 未说明安全、可靠性和长期供货要求

## 8. 常见误判

- 汽车销量直接等同芯片需求
- 单项车规证书替代完整验证
- 定点金额等同收入
- 样品等同装车
- 忽略年降、质量和召回风险

## 9. 输出到 03 的证据要求

- 按车型/平台/SOP/采购份额整理证据
- 把样品、验证、定点、SOP、装车、复购分阶段列示
- 收集质量、召回、保修和年降条款证据
- 国产替代问题补客户切换和多供证据
