# 光电子芯片与硅光场景卡

## 决胜分歧

网络带宽需求到光芯片收入之间要经过交换架构、速率升级、端口数、铜光边界、模块方案、良率和客户认证。硅光技术优势不自动转化为份额，封装耦合、激光源、热管理和测试可能成为主要约束。

决胜证据应落到端口/速率结构、实际网络部署、模块 BOM、器件价值量、量产良率和客户平台导入。模块整机收入与半导体器件收入必须分开，避免产业链口径重复计算。

## 1. 适用问题

用于判断激光器、探测器、调制器、驱动/TIA、硅光、CPO/LPO 等光电子芯片需求、路线替代、供给瓶颈和价值分配。适用于光模块升级、AI网络架构、硅光替代、InP供给等问题。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 需求框架 | IF-APP-01 应用需求与半导体内容量 | 从端口、速率、距离和网络架构推导芯片需求 |
| 制造框架 | IF-FAB-01 晶圆制造、工艺平台与产能 | 判断外延、晶圆、硅光平台和良率 |
| 封装框架 | IF-PKG-01 封装测试与异构集成 | 判断耦合封装、测试和系统集成 |
| 设计框架 | IF-DES-01 芯片设计、IP与产品商业化 | 判断产品路线、客户认证和量产复购 |

## 3. 最小判断链

```text
网络架构、端口、速率和距离
→ 光模块形态和每模块芯片BOM
→ 激光器/探测器/调制器/驱动等需求
→ InP/Si/SiGe/硅光路线比较
→ 外延、晶圆、耦合封装、测试和认证
→ 芯片价值量与利润池变化
```

## 4. 关键变量

- 端口、速率、距离、通道数和光源方案
- 每模块光芯片和电芯片用量
- InP、Si、SiGe、硅光路线的性能、功耗和成本
- 外延、晶圆、耦合封装、测试和可靠性
- 客户认证、模块架构、CPO/LPO和利润池

## 5. 最低证据

- 下游端口、速率、距离、网络架构和模块规划
- 每模块芯片BOM和技术路线证据
- 外延、晶圆、耦合封装、测试、良率和可靠性证据
- 客户认证、量产出货和复购证据
- 模块ASP、芯片价值量和利润池分配分开

## 6. 主要反证与阻断

- 模块需求强但芯片价值量下降
- 硅光路线并非替代，而是与分立器件分工互补
- 耦合封装和测试成为实际瓶颈
- 客户自研或架构变化重塑利润池
- 单客户样品无法外推行业放量

## 7. 停止条件

- 只有模块速率，没有端口、距离和BOM
- 没有路线、良率、耦合封装和测试证据
- 模块ASP直接反推芯片价值
- 单客户样品缺少认证和量产出货证据

## 8. 常见误判

- 端口直接等同芯片数
- 模块ASP等同芯片价值
- 实验参数等同量产
- 只看晶圆不看耦合封装
- 把硅光简单理解为全面替代

## 9. 输出到 03 的证据要求

- 按端口/速率/距离/模块形态列需求证据
- 拆每模块芯片BOM和路线证据
- 补外延、晶圆、耦合封装、测试和认证证据
- 区分模块、芯片和公司收入口径
