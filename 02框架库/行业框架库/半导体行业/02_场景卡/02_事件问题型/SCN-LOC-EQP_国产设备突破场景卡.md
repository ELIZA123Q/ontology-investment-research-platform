# 国产设备突破场景卡

## 1. 适用问题

用于判断某国产半导体设备是否从样机、首台、验证进入复购、跨线复制、规模收入和真实国产替代。适用于刻蚀、薄膜、清洗、量测、测试、先进封装设备及核心零部件突破问题。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 主框架 | IF-EQP-01 半导体设备需求、验证与放量 | 判断设备需求、验证、订单、验收和收入 |
| 横向约束 | IF-LOC-01 外部约束、国产替代与供应链韧性 | 判断国产替代、客户切换和关键依赖 |
| 制造/封装补充 | IF-FAB-01 / IF-PKG-01 | 按设备所在工艺环节补充工艺和产能约束 |

## 3. 最小判断链

```text
Fab项目和工艺步骤需求
→ 设备类别、性能、稳定性和拥有成本
→ 客户验证、工艺结果和验收
→ 首台/首批/复购/跨线复制
→ 交付、安装、验收、收入和回款
→ 零部件、软件、备件和服务依赖
→ 国产份额、利润和韧性
```

## 4. 关键变量

- 目标工艺步骤、节点、晶圆尺寸和客户设施
- 设备性能、产能、稳定性、良率影响和拥有成本
- 样机、首台、客户验证、验收、复购和跨线复制
- 订单、交付、安装、验收、收入和回款
- 核心零部件、软件、备件和现场服务能力
- 国产份额、价格、毛利和服务成本

## 5. 最低证据

- Fab项目、招标、设备类别和工艺步骤证据
- 客户上线、工艺结果、多批次稳定性和验收证据
- 首台/首批与重复订单、跨线复制证据
- 合同、交付、安装、验收、收入和现金分开
- 关键零部件、软件、备件和服务能力证据

## 6. 主要反证与阻断

- 仅示范线或政策订单，无法跨线复制
- 工艺指标达标但稳定性、吞吐量或拥有成本不足
- 关键零部件、软件或服务仍被外部约束
- 低价导入导致份额提升但利润弱
- 订单到验收收入存在长时滞

## 7. 停止条件

- 不知道设备对应的工艺步骤和客户设施
- 只有样机、首台或新闻口径，没有客户验证和工艺结果
- 没有复购、跨线复制或验收证据
- 无法穿透关键零部件和服务依赖

## 8. 常见误判

- 样机等同量产
- 首台套等同份额提升
- 合同额等同收入
- 国产份额等同利润
- 整机国产等同供应链韧性

## 9. 输出到 03 的证据要求

- 按设备类别、工艺步骤、客户设施列证据
- 分阶段记录样机、验证、首台、验收、复购和跨线复制
- 订单、收入、回款和毛利分开取证
- 穿透关键零部件、软件、备件和服务依赖
