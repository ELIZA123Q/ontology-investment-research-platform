# 先进封装瓶颈场景卡

## 1. 适用问题

用于判断 AI、HBM、Chiplet、2.5D/3D、Fan-out、混合键合等需求是否形成先进封装瓶颈，以及瓶颈具体落在基板、中介层、TSV、bumping、键合、封装、测试、良率或客户认证。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 主框架 | IF-PKG-01 封装测试与异构集成 | 判断先进封装路线、良率、有效产能和利润池 |
| 需求框架 | IF-APP-01 应用需求与半导体内容量 | 判断 AI/HPC/系统配置对封装的需求 |
| 设备/材料补充 | IF-EQP-01 / IF-MAT-01 | 判断封装设备、基板、材料和耗材供给 |
| 制造补充 | IF-FAB-01 | 判断前道晶圆与已知良品对封装的约束 |

## 3. 最小判断链

```text
AI/HPC/Chiplet系统架构
→ 先进封装路线和工艺BOM
→ 基板/中介层/TSV/bumping/键合/封装/测试需求
→ 已知良品和组合良率
→ 分工序有效产能、客户认证和交期
→ 利润池迁移和公司收入利润兑现
```

## 4. 关键变量

- 产品架构、带宽、功耗、面积和良率目标
- 中介层、基板、TSV、bumping、键合、组装和测试工艺BOM
- 已知良品率、封装良率、组合良率和可靠性
- 分工序设备、材料、人员、治具和客户认证
- OSAT、晶圆厂、基板厂、设备材料厂的利润池分配
- 扩产、良率爬坡、交期和价格

## 5. 最低证据

- 目标产品架构和先进封装路线证据
- 关键工艺BOM、设备、材料和分工序产能证据
- 良率、可靠性、测试、认证和客户复购证据
- 基板/中介层/封装/测试交期和价格证据
- 公司客户、产能、资本开支、收入确认和毛利证据

## 6. 主要反证与阻断

- 真正瓶颈在HBM、前道晶圆、基板或系统交付，不在目标封装环节
- 扩产快于需求或客户自建导致溢价压缩
- 组合良率低于预期，成本上升抵消价值量
- 标准化、内制化或代工厂整合重塑利润池
- 客户认证延迟或产品路线变化

## 7. 停止条件

- 无产品架构和封装路线
- 无法拆分关键工序和有效产能
- 没有良率、可靠性和客户认证证据
- 价值量重复计算，无法判断利润池

## 8. 常见误判

- 把先进封装当作单一工序
- 用总封装产能判断先进封装供给
- 忽略已知良品和组合良率
- 设备订单直接推公司收入
- 晶圆、封装和系统价值重复相加

## 9. 输出到 03 的证据要求

- 按产品架构和封装路线建立BOM证据表
- 拆分基板、中介层、TSV、bumping、键合、组装、测试证据
- 收集良率、可靠性、认证和交期证据
- 公司兑现需补产能、客户、收入确认和毛利证据
