# 国产材料放量场景卡

## 1. 适用问题

用于判断国产半导体材料是否从送样、线下测试、产线验证进入批量供应、复购和跨厂复制。适用于硅片/衬底、光刻胶、电子气体、湿化学品、前驱体、靶材、CMP、封装材料等问题。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 主框架 | IF-MAT-01 半导体材料需求、认证与放量 | 判断材料耗用、规格、认证、供给和批量供应 |
| 横向约束 | IF-LOC-01 外部约束、国产替代与供应链韧性 | 判断国产替代、客户变更和共享上游依赖 |
| 制造/封装补充 | IF-FAB-01 / IF-PKG-01 | 按材料所在工艺或封装环节补充约束 |

## 3. 最小判断链

```text
目标工艺和材料用途
→ 投片、步骤数、单位耗用和规格要求
→ 送样、线下测试、产线验证和批量供应
→ 批次一致性、良率影响和客户变更控制
→ 复购、跨厂复制和份额提升
→ 原料、合格产能、物流和价格利润兑现
```

## 4. 关键变量

- 材料用途、节点、晶圆尺寸、封装路线和规格等级
- 投片、步骤数、单位耗用、回收率和良率影响
- 纯度、缺陷、批次一致性、包装运输和现场管理
- 送样、线下测试、产线验证、批量供应、复购和跨厂复制
- 原料来源、合格产能、库存、物流和客户集中度
- 国产份额、价格、毛利和长协条款

## 5. 最低证据

- 材料用途、工艺节点、规格等级和客户工艺证据
- 投片、步骤数、单位耗用或合理代理证据
- 测试、产线验证、良率影响和批量供应证据
- 复购、跨客户/跨厂复制和长期供货证据
- 原料、合格产能、库存、物流、价格和毛利证据

## 6. 主要反证与阻断

- 实验室指标达标但产线稳定性不足
- 送样多年无法进入批量供应
- 客户变更控制和认证周期过长
- 上游原料、包装、物流或质量控制成为瓶颈
- 低价导入导致份额提升但利润弱

## 7. 停止条件

- 不能说明材料用于何种工艺和规格等级
- 只有送样或实验室指标，没有产线验证
- 没有批量供应、复购或跨厂复制证据
- 无法区分名义产能和合格供给

## 8. 常见误判

- capex直接等同材料需求
- 送样等同导入
- 实验室参数等同产线能力
- 名义吨产能等同合格供给
- 单厂采用外推全行业

## 9. 输出到 03 的证据要求

- 按材料类型、工艺用途、规格等级整理证据
- 分阶段列送样、测试、产线验证、批量供应、复购
- 收集投片、单位耗用、价格和良率影响证据
- 穿透原料、合格产能、库存和物流证据
