# 存储周期见顶或反转场景卡

## 1. 适用问题

用于判断 DRAM、NAND、HBM、企业级 SSD 等存储产品的周期阶段、涨价持续性、价格斜率变化、见顶或反转风险。适用于存储周期是否见顶、涨价能否持续、复苏是否真实等问题。

## 2. 推荐主框架组合

| 角色 | 框架 | 用途 |
|---|---|---|
| 主框架 | IF-SC-01 半导体周期与库存 | 判断周期阶段、库存、订单、价格和供给释放 |
| 产品应用型场景 | SCN-MEM-HBM | 当问题涉及 HBM 和资源挤占时调用 |
| 制造/封装补充 | IF-FAB-01 / IF-PKG-01 | 判断晶圆、产品组合、封装和测试供给 |

## 3. 最小判断链

```text
终端/服务器/AI需求
→ 单机容量、bit demand和采购节奏
→ 原厂/渠道/模组/客户库存
→ 晶圆投入、减产/复产、技术迁移和HBM挤占
→ 现货、合约、报价和实现价
→ 公司量价利润兑现
→ 周期阶段、见顶/反转和改判信号
```

## 4. 关键变量

- DRAM、NAND、HBM、企业级SSD分产品口径
- 终端需求、服务器需求、单机容量和实际部署
- 原厂、渠道、模组、客户库存和backlog
- 晶圆投入、良率、die size、减产/复产和产品组合
- 现货、合约、报价、实现价和合同重定价节奏
- capex、扩产、库存和价格改判信号

## 5. 最低证据

- 分产品、代际、容量和客户的需求、库存、价格证据
- 至少两层库存证据，避免只看原厂或渠道单一口径
- 减产、复产、晶圆投入、产品组合和技术迁移证据
- 现货、合约和公司实现价分开
- 公司产品暴露、成本、库存和合同重定价证据

## 6. 主要反证与阻断

- 价格上涨主要来自补库而非终端需求
- 客户库存重新累积，订单能见度下降
- 原厂复产或新增产能释放快于预期
- HBM景气未能外溢到通用DRAM或NAND
- 现货价格回落但合约价仍滞后，误判时间点

## 7. 停止条件

- 不能拆分DRAM、NAND、HBM和企业级SSD
- 缺少两层以上库存证据
- 价格口径混用
- 只有单一领先指标，无法判断拐点

## 8. 常见误判

- 用存储均价替代分产品价格
- 现货涨价直接等同公司实现价
- 订单增加直接等同终端复苏
- HBM、DRAM、NAND求平均
- 减产公告直接等同供给收缩

## 9. 输出到 03 的证据要求

- 按产品/代际/客户拆分需求、库存和价格证据
- 至少两层库存和订单能见度证据
- 列减产、复产、晶圆投入和产品组合证据
- 公司兑现需补收入、毛利、库存和合同重定价
