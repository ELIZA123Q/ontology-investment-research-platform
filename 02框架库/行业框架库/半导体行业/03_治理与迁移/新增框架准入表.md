## 2. 主框架准入判断

只有拟新增“主框架”时才填写本节。

| 准入条件 | 判断问题 | 结果 | 说明 |
|---|---|---|---|
| 独立核心矛盾 | 是否不是已有框架简单换对象？ |  |  |
| 独立变量体系 | 是否存在稳定、可观察、可复用的关键变量？ |  |  |
| 独立传导机制 | 是否不能被现有主框架覆盖？ |  |  |
| 独立反证方式 | 是否有不同于其他框架的阻断和停止条件？ |  |  |
| 跨案例复用 | 是否至少可服务 3—5 个不同研究案例？ |  |  |
| 权威来源支撑 | 是否至少两个独立来源，且至少一个为中国官方/协会/标准/产业组织来源？ |  |  |
| 本体可映射 | 是否能映射到现有本体，或明确提出领域扩展缺口？ |  |  |

## 3. 场景卡准入判断

| 准入条件 | 判断问题 | 结果 | 说明 |
|---|---|---|---|
| 高频入口 | 是否是研究员会反复提出的问题？ |  |  |
| 组合价值 | 是否需要组合 1 个以上主框架？ |  |  |
| 特殊变量 | 是否有本场景特有变量或证据口径？ |  |  |
| 反证清晰 | 是否能说明主要误判和停止条件？ |  |  |
| 不保存事实 | 是否不保存当期数据、结论和公司预测？ |  |  |

## 4. 判定规则

| 结果 | 处理 |
|---|---|
| 满足主框架全部准入条件 | 可进入 candidate，待案例验证 |
| 不满足主框架但满足场景卡条件 | 新增场景卡 |
| 仅服务单一案例 | 作为案例复盘或证据模板 |
| 只是已有场景卡换名称 | 不新增，合并到已有场景卡 |
