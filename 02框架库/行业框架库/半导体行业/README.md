# 半导体行业框架库（场景卡版）

> 研究员先用场景卡快速定位特殊约束，再回到一个主框架深入机制。场景卡是“问题入口”，不是填表模板；主框架是“研究底盘”，不是必须全量执行的流程。

## 研究员最短路径

1. 用一句话写清本次半导体问题的产品、环节、客户、地区和时间；
2. 判断核心分歧属于周期、国产替代、应用需求、设计商业化、制造、封装、设备还是材料；
3. 有明确场景时选一张卡，只提取它特有的变量和误判；
4. 输出 3—6 节点主路径、最强竞争解释、改判信号和交给 03 的决胜证据。

## 1. 目录定位

本目录面向中国为主、兼顾全球供应链的半导体投研问题，提供可组合、可验证、可反证、可裁剪的行业分析框架。

框架库不保存当期事实、公司实例、预测数值或投资结论。它只帮助 02 阶段回答：

> 一类半导体问题通常应该如何定界、拆解、观察、验证、反证和停止推导。

## 2. 本版结构

本版取消“产品/应用适配卡”作为独立资产层，统一改为“场景卡”。

原因是：产品应用型问题本质上也是研究场景，只是它的触发入口来自产品、应用或技术族；事件问题型场景则来自地缘、政策、国产替代、周期拐点或产业链瓶颈。

最终结构：

```text
1 个总纲
8 个主框架：两横六纵
10 张场景卡：产品应用型 + 事件问题型
若干治理与迁移文件
```

## 3. 主框架：两横六纵

| 类型 | 框架 | 作用 |
|---|---|---|
| 横向状态 | IF-SC-01 半导体周期与库存框架 | 判断周期位置、库存、价格、稼动、资本开支和供给释放 |
| 横向约束 | IF-LOC-01 外部约束、国产替代与供应链韧性框架 | 判断政策、管制、地缘、替代、供应安全和韧性 |
| 应用牵引 | IF-APP-01 应用需求与半导体内容量框架 | 判断终端、系统和工作负载如何转化为半导体需求 |
| 设计商业化 | IF-DES-01 芯片设计、IP与产品商业化框架 | 判断产品定义、EDA/IP、流片、验证、Design Win、量产和复购 |
| 晶圆制造 | IF-FAB-01 晶圆制造、工艺平台与产能框架 | 判断制造能力、节点、工艺平台、良率、稼动、折旧和盈利 |
| 封装测试 | IF-PKG-01 封装测试与异构集成框架 | 判断传统封测、先进封装、测试、级联良率和利润池 |
| 设备支撑 | IF-EQP-01 半导体设备需求、验证与放量框架 | 判断设备需求、客户验证、复购、验收、收入和服务能力 |
| 材料支撑 | IF-MAT-01 半导体材料需求、认证与放量框架 | 判断材料耗用、规格、认证、量产、复购和跨厂复制 |

## 4. 场景卡分类

### 4.1 产品应用型

产品应用型场景卡用于承接高频产品、应用或技术族，不再作为“适配卡”单独管理。

| 场景卡 | 适用问题 |
|---|---|
| SCN-MEM-HBM_HBM供需与资源挤占场景卡 | HBM供需、DRAM晶圆挤占、先进封装和客户认证 |
| SCN-AI-AI计算芯片系统供给场景卡 | AI计算芯片、HBM、封装、网络、电力和软件生态 |
| SCN-AUTO_车规芯片认证与装车场景卡 | 车规芯片定点、SOP、装车、复购和质量跟踪记录 |
| SCN-PWR-SIC_SiC渗透与供给场景卡 | SiC渗透、衬底外延、器件良率、模组和系统经济性 |
| SCN-OPTO_光电子芯片与硅光场景卡 | 光芯片、硅光、CPO/LPO、耦合封装和光模块传导 |

### 4.2 事件问题型

事件问题型场景卡用于承接地缘、政策、国产替代、周期拐点和产业链瓶颈等问题。

| 场景卡 | 适用问题 |
|---|---|
| SCN-GEO_地缘政治冲击影响半导体场景卡 | 战争、制裁、出口管制、航运能源和风险偏好冲击 |
| SCN-LOC-EQP_国产设备突破场景卡 | 国产设备验证、复购、跨线复制、验收和收入兑现 |
| SCN-LOC-MAT_国产材料放量场景卡 | 国产材料送样、产线认证、批量供应、跨厂复制 |
| SCN-MEM-CYCLE_存储周期见顶或反转场景卡 | DRAM/NAND/HBM周期阶段、涨价持续性和改判信号 |
| SCN-PKG-BTL_先进封装瓶颈场景卡 | AI/HBM/Chiplet相关先进封装瓶颈、良率、产能和利润池 |

## 5. 快速选择规则

先判断问题入口，再选场景卡和主框架：

| 研究问题入口 | 优先使用 | 推荐主框架 |
|---|---|---|
| 行业周期到了哪里 | SCN-MEM-CYCLE 或 IF-SC-01 | IF-SC-01 |
| HBM 是否继续紧缺 | SCN-MEM-HBM | IF-SC-01、IF-PKG-01、IF-FAB-01 |
| AI算力如何传导到半导体 | SCN-AI-AI计算芯片系统供给 | IF-APP-01、IF-PKG-01、IF-FAB-01 |
| 先进封装是否成为瓶颈 | SCN-PKG-BTL | IF-PKG-01、IF-EQP-01、IF-MAT-01 |
| 国产设备是否真正突破 | SCN-LOC-EQP | IF-EQP-01、IF-LOC-01 |
| 国产材料是否放量 | SCN-LOC-MAT | IF-MAT-01、IF-LOC-01 |
| 车规芯片定点是否兑现 | SCN-AUTO | IF-DES-01、IF-APP-01、IF-LOC-01 |
| SiC渗透是否加速 | SCN-PWR-SIC | IF-APP-01、IF-FAB-01、IF-MAT-01 |
| 光模块升级如何传导到光芯片 | SCN-OPTO | IF-APP-01、IF-PKG-01、IF-FAB-01 |
| 美伊冲突、出口管制、地缘冲击 | SCN-GEO | IF-LOC-01、IF-SC-01、IF-MAT-01、IF-EQP-01 |

## 6. 调用规则

正式研究任务原则上最多选择：

```text
1 张场景卡
+ 1 个主框架
+ 0—1 个横向框架
+ 必要时补充 1 个产业链框架
```

如果需要同时调用多张场景卡，通常说明 01 研究问题没有收敛，应回到需求说明阶段重新限定对象、时间、地域和产业链边界。
