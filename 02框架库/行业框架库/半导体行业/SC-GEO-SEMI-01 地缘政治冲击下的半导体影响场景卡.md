# SC-GEO-SEMI-01 地缘政治冲击下的半导体影响场景卡

## 1. 场景定位

本场景卡用于分析战争、军事冲突、航道风险、制裁升级、外交对抗等地缘政治事件，是否会通过能源、物流、制裁、需求、风险偏好和供应链安全等路径，影响半导体行业及相关公司。

本场景卡不是正式框架，不替代基础框架或行业框架。它的作用是把一次具体外部冲击，组织成可以进入 02 研究逻辑、03 证据准备和 04 推理判断的分析路径。

本场景卡回答：

> 地缘政治冲击会不会影响半导体？
> 如果影响，是影响基本面、供应链、成本、需求、估值，还是只是短期市场预期？
> 哪些环节真正暴露，哪些只是概念联想？
> 哪些影响已经有证据，哪些只是待验证假设？

## 2. 适用问题

适用于以下问题：

* 美伊战争、霍尔木兹风险对半导体行业的影响；
* 台海风险对全球半导体供应链的影响；
* 中美科技冲突、出口管制升级对半导体设备、材料、EDA、AI 芯片的影响；
* 俄乌冲突、中东冲突等事件对半导体材料、能源、物流和需求的影响；
* 地缘风险上升是否会强化国产替代、供应链安全和自主可控投资逻辑；
* 外部冲击下半导体板块的基本面影响与估值影响如何区分。

## 3. 不适用问题

不适用于以下问题：

* 单纯判断半导体周期处于上行、下行还是见顶；
* 单纯判断某个产品是否供需紧张；
* 单纯判断某家公司业绩弹性；
* 单纯判断某项政策文本的执行影响；
* 没有明确冲击事件，只是泛泛讨论“地缘政治长期风险”。

如果问题没有具体事件、冲击主体、时间范围和观察对象，应先回到 01 研究需求阶段澄清，不应直接套用本场景卡。

## 4. 核心判断对象

本场景卡的核心判断对象不是“地缘政治事件本身”，而是事件能否形成可验证的半导体影响链。

判断对象包括：

| 判断对象 | 需要回答的问题                            |
| ---- | ---------------------------------- |
| 冲击性质 | 这是军事冲突、制裁升级、航道风险、能源冲击、金融冲击，还是多重叠加？ |
| 直接暴露 | 半导体哪些环节与事件存在直接暴露？                  |
| 传导路径 | 冲击通过什么中介变量传到行业或公司？                 |
| 影响强度 | 是短期扰动、阶段性压力，还是中期结构变化？              |
| 影响方向 | 是利好、利空、分化，还是更多体现为不确定性上升？           |
| 证据状态 | 影响已经发生、正在形成，还是只是市场预期？              |
| 反证条件 | 哪些信号出现后，应停止或下修该影响判断？               |

## 5. 标准分析顺序

### 5.1 第一步：识别冲击类型

先判断本次地缘政治事件属于哪几类冲击，不要直接跳到行业结论。

| 冲击类型    | 典型事件                   | 半导体相关性                  |
| ------- | ---------------------- | ----------------------- |
| 军事冲突    | 战争、空袭、导弹袭击、海峡封锁        | 影响风险偏好、航运、能源和供应链安全预期    |
| 航道风险    | 霍尔木兹、红海、台海、南海等通道风险     | 影响物流、交付周期、保险和安全库存       |
| 能源冲击    | 原油、天然气、电力价格大幅波动        | 影响制造成本、材料成本和宏观需求        |
| 制裁升级    | 出口管制、实体清单、金融制裁         | 影响设备、EDA、材料、先进芯片和客户行为   |
| 金融冲击    | 汇率、利率、风险偏好、流动性变化       | 影响估值、融资、资本开支和订单节奏       |
| 需求冲击    | 全球经济预期、企业 capex、消费需求变化 | 影响消费电子、汽车、工业、服务器和 AI 需求 |
| 供应链安全冲击 | 客户主动调整供应商、提高备货、推动本土化   | 影响国产替代、认证、复购和产能规划       |

一个事件可以同时命中多类冲击，但正式分析时必须区分主路径和次路径。

### 5.2 第二步：判断直接暴露

判断半导体是否真的暴露，不能只因为“地缘政治风险上升”就得出行业影响。

需要检查：

* 事件地点是否处在关键能源、航运或供应链节点；
* 事件主体是否涉及半导体设备、材料、晶圆、封测、终端客户或资本开支；
* 是否影响关键原材料、化工品、气体、晶圆、设备零部件或物流通道；
* 是否触发美国、欧洲、日本、韩国、中国台湾等关键地区政策变化；
* 是否影响客户采购、备货、认证、订单、交付或库存行为；
* 是否改变市场对半导体安全供应、国产替代和技术封锁的预期。

如果没有直接暴露，只能作为风险偏好或市场情绪影响处理，不能直接写成基本面影响。

### 5.3 第三步：拆解传导路径

本场景卡默认拆成六条路径。正式使用时只保留与本次问题相关的路径。

#### 路径一：能源与成本路径

```text
地缘冲突升级
→ 原油、天然气、电力、化工品或运输能源成本变化
→ 晶圆制造、材料、化工气体、物流成本变化
→ 半导体公司毛利率、报价、订单节奏变化
```

重点观察：

* 原油、天然气、电力价格是否显著上行；
* 半导体制造地区是否面临能源价格或供应压力；
* 晶圆厂、材料厂、化工气体厂是否披露成本压力；
* 公司是否具备成本转嫁能力；
* 下游客户是否接受涨价。

常见误判：

* 把油价上涨直接等同于晶圆厂利润下滑；
* 忽视半导体不同环节能源成本占比差异；
* 忽视长协、库存、成本转嫁和产品结构。

#### 路径二：物流与交付路径

```text
地缘冲突或航道风险
→ 海运、空运、保险、绕航、港口和通关不确定性上升
→ 设备、材料、零部件、晶圆、封测或整机交付延迟
→ 客户备货、安全库存和订单节奏变化
```

重点观察：

* 航运时间、保险费用、空运价格是否变化；
* 关键设备、材料或零部件是否出现交付延迟；
* 客户是否提高安全库存；
* 公司是否披露交付、安装、验收、收入确认延后；
* 是否影响产能爬坡或新产线建设。

常见误判：

* 把一般航运扰动放大成半导体供应链中断；
* 忽视高价值半导体产品可能使用空运；
* 忽视企业已有替代物流安排和库存缓冲。

#### 路径三：制裁与出口管制路径

```text
地缘冲突升级
→ 美国及盟友制裁、出口管制、实体清单或合规要求升级
→ 设备、EDA、材料、先进芯片、IP、制造服务流动受限
→ 中国及相关市场供应链重构、国产替代和客户行为变化
```

重点观察：

* 是否有新增制裁、出口管制或实体清单；
* 限制对象是国家、企业、产品、技术、软件，还是金融交易；
* 是否涉及先进制程、AI 芯片、设备、EDA、材料或制造服务；
* 第三方企业是否主动收缩交易；
* 国内客户是否加速国产验证和替代采购；
* 国产厂商是否从样机、送样进入认证、量产、复购和收入确认。

常见误判：

* 把制裁预期当成已落地政策；
* 把国产替代预期直接等同于国产公司业绩兑现；
* 忽视合规收缩可能同时压制需求和交付。

#### 路径四：终端需求路径

```text
地缘风险上升
→ 全球经济预期、企业资本开支、消费信心和终端订单变化
→ 消费电子、汽车、工业、服务器、AI、军工等需求分化
→ 半导体订单、库存、价格和稼动率变化
```

重点观察：

* 消费电子订单是否下修；
* 汽车和工业需求是否受宏观预期影响；
* 云厂商 AI capex 是否变化；
* 军工、安全、通信相关需求是否上升；
* 存储、模拟、功率、MCU、AI 芯片是否出现分化；
* 渠道库存和真实终端需求是否被混用。

常见误判：

* 把宏观风险直接等同于所有半导体需求下行；
* 把短期备货当成真实需求改善；
* 把 AI、服务器、消费电子、汽车芯片放在同一个周期里判断。

#### 路径五：风险偏好与估值路径

```text
地缘冲突升级
→ 全球风险偏好下降、无风险利率或风险溢价变化
→ 高估值科技股、半导体板块估值承压
→ 股价变化与基本面影响出现背离
```

重点观察：

* 半导体板块下跌是否来自基本面预期变化，还是风险偏好收缩；
* 高估值、长久期、AI 相关资产是否更敏感；
* 市场是否重新定价供应链风险、政策风险和需求风险；
* 分子端盈利预期与分母端估值变化是否分开讨论。

常见误判：

* 把股价下跌直接解释成基本面恶化；
* 把短期避险交易写成中期产业趋势；
* 不区分业绩影响、估值影响和预期差影响。

#### 路径六：供应链安全与国产替代路径

```text
地缘风险上升
→ 客户和政府提高供应链安全权重
→ 本土设备、材料、EDA、IP、制造、封装、设计公司获得更多验证机会
→ 认证、量产、复购、份额和收入兑现
```

重点观察：

* 客户是否调整供应商策略；
* 是否出现新增送样、认证、定点、订单、复购；
* 国产替代是否只是主题交易，还是已进入经营兑现；
* 替代环节是设备、材料、EDA、封装、制造、设计，还是终端系统；
* 是否存在良率、稳定性、产能、交付、成本和客户认证约束。

常见误判：

* 把“安全可控重要性上升”直接写成“国产替代全面加速”；
* 把首单、送样、验证等同于收入兑现；
* 忽视国产替代也可能受下游需求、资本开支和客户预算约束。

## 6. 半导体环节映射

正式分析时，应把影响映射到具体环节，不要笼统写“利好半导体”。

| 环节        | 可能受影响路径                | 重点变量                     |
| --------- | ---------------------- | ------------------------ |
| 晶圆制造      | 能源、材料、设备交付、客户订单、稼动率    | 投片、稼动率、良率、ASP、折旧、毛利率     |
| 先进制程      | 设备、EDA、先进封装、AI 需求、出口管制 | EUV/DUV、良率、产能、客户结构、技术限制  |
| 存储芯片      | 需求、库存、价格、HBM 资源分配      | DRAM、NAND、HBM、库存、合约价、现货价 |
| 先进封装      | AI 芯片、HBM、基板、设备、交付周期   | CoWoS、2.5D/3D、良率、产能、认证   |
| 传统封测      | 终端需求、库存、订单、价格          | 稼动率、订单能见度、封装结构、测试需求      |
| 半导体设备     | 晶圆厂 capex、出口管制、物流、验收   | 订单、交付、安装、验收、复购、收入确认      |
| 半导体材料     | 晶圆投片、认证、替代、物流、化工品      | 耗用量、认证、良率、复购、供应稳定性       |
| EDA/IP    | 出口管制、生态替代、先进制程限制       | 工艺覆盖、客户粘性、授权、版税、迁移成本     |
| AI 芯片     | 云 capex、出口管制、HBM、先进封装  | 订单、供应链、生态、部署利用率          |
| 汽车/工业芯片   | 宏观需求、终端订单、安全库存         | 定点、装车、库存、渠道订单、价格         |
| 功率/化合物半导体 | 能源转型、汽车需求、材料和产能        | SiC/GaN、衬底、良率、系统经济性      |
| 国产设备材料    | 供应链安全、认证、复购、客户导入       | 验证进度、产线导入、份额、收入兑现        |

## 7. 判断输出分层

本场景卡输出不应只有“利好/利空”，而应分成五类。

| 输出类型   | 含义                      | 表达方式                   |
| ------ | ----------------------- | ---------------------- |
| 无显著影响  | 暂无直接暴露或证据不足             | “目前只能作为风险偏好变量观察”       |
| 短期扰动   | 主要影响交易情绪、物流、成本或备货       | “短期扰动大于中期基本面影响”        |
| 结构分化   | 不同环节方向不同                | “对设备材料、国产替代和消费链影响方向不同” |
| 基本面重估  | 订单、价格、成本、产能或收入确认发生变化    | “已进入基本面验证阶段”           |
| 产业逻辑变化 | 供应链安全、政策工具或客户采购规则发生长期变化 | “可能改变中期产业配置逻辑”         |

## 8. 证据要求

### 8.1 必要证据

至少需要覆盖以下几类证据中的三类，才可形成方向性判断：

| 证据类型  | 例子                         |
| ----- | -------------------------- |
| 事件事实  | 军事冲突、航道中断、制裁文本、政策公告        |
| 市场变量  | 油价、航运价格、汇率、利率、半导体指数、风险资产表现 |
| 产业数据  | 订单、库存、价格、交期、稼动率、capex、设备交付 |
| 公司披露  | 公告、业绩会、年报、投资者交流、客户/供应商披露   |
| 第三方数据 | 行业协会、海关、航运、能源、研究机构数据       |
| 供应链信号 | 送样、认证、定点、复购、交付延迟、备货行为      |

### 8.2 证据分级

| 等级    | 标准                              |
| ----- | ------------------------------- |
| 强证据   | 已有政策文本、公司披露、订单变化、价格变化、交付变化或收入影响 |
| 中证据   | 有行业数据、供应链信号或多方一致观察，但尚未反映到财务结果   |
| 弱证据   | 主要是市场预期、媒体推测、主题交易或逻辑外推          |
| 不可用证据 | 来源不明、口径不清、无法验证或与本次对象无关          |

### 8.3 不能单独作为结论依据的材料

以下材料只能作为线索，不能单独支撑方向性判断：

* 市场传闻；
* 单日股价表现；
* 单篇情绪化媒体报道；
* 没有政策文本支持的制裁预期；
* 没有订单、认证或收入证据支持的国产替代叙事；
* 没有客户行为证据支持的安全库存判断。

## 9. 反证条件

出现以下情况，应下修或停止相关判断：

| 原判断         | 反证条件                     |
| ----------- | ------------------------ |
| 能源成本冲击半导体利润 | 油气价格回落，企业无成本压力披露，毛利率未受影响 |
| 航运风险影响交付    | 关键产品主要空运或已有替代路径，交付周期未变化  |
| 制裁升级影响供应链   | 未出现新增政策，企业合规行为未变化        |
| 国产替代加速      | 只有主题关注，没有认证、订单、复购和收入证据   |
| 需求受压        | 终端订单、云 capex、汽车/工业需求未下修  |
| 估值承压来自基本面   | 盈利预期未变，主要由风险偏好和流动性解释     |
| 半导体整体受益     | 不同环节分化明显，缺乏全行业共同受益机制     |

## 10. 常见误判

本场景最常见的错误包括：

1. 把“战争风险”直接写成“半导体利好”；
2. 把“油价上涨”直接写成“晶圆厂成本大幅上升”；
3. 把“制裁风险”直接写成“国产替代全面加速”；
4. 把“国产替代主题交易”直接写成“国产公司业绩兑现”；
5. 把“股价下跌”直接写成“基本面恶化”；
6. 把“短期备货”直接写成“真实需求改善”；
7. 把“AI、存储、消费电子、汽车芯片”放在同一个周期阶段里判断；
8. 把“政策可能性”当成“政策已经发生”；
9. 把“行业影响”跳写成“公司利润影响”，中间不验证暴露、订单、价格、成本和收入确认；
10. 把“地缘政治长期不确定性”当成某一次事件的确定结论。

## 13. 示例：美伊战争对半导体行业影响

### 13.1 初始判断

“美伊战争对半导体影响”不应直接写成“利好国产替代”或“利空全球半导体”，而应先判断冲击是否经过以下路径传导：

```text
美伊冲突升级
→ 中东能源与航道风险上升
→ 全球风险偏好下降、油价和物流不确定性上升
→ 半导体板块估值承压，部分供应链安全主题升温
→ 是否进入基本面影响，取决于能源成本、物流交付、制裁政策、终端需求和客户采购行为是否发生可验证变化
```

### 13.2 推荐主路径

如果研究目标是“行业整体影响”，主路径建议为：

```text
美伊冲突
→ 能源、航运、风险偏好和制裁预期变化
→ 半导体成本、物流、需求、估值和供应链安全预期分化
→ 短期更多体现为风险偏好和预期交易
→ 中期是否影响基本面，取决于政策升级、客户订单、供应链交付和公司披露
```

### 13.3 需要避免的结论

不能直接得出：

* “战争利好半导体”；
* “战争利空所有半导体公司”；
* “油价上涨必然压制晶圆厂利润”；
* “地缘风险上升必然加速国产替代兑现”；
* “半导体股价下跌说明基本面恶化”。

### 13.4 更合适的表达

更合适的初步表达是：

```text
美伊冲突对半导体的影响不宜按单一利好或利空处理。短期主要影响风险偏好、能源与航运预期，以及供应链安全主题；中期是否形成基本面影响，需要继续验证油价和物流扰动是否进入制造成本和交付周期，制裁或出口管制是否升级，终端客户是否调整订单和备货，以及国产设备材料是否获得新的认证、订单和复购证据。
```

## 14. 升级、合并与废弃规则

本场景卡为候选场景卡，不自动升级为正式框架。

只有满足以下条件，才考虑升级为正式基础框架或行业框架：

1. 至少被 3 个以上独立案例复用；
2. 每次复用都能稳定产出有效研究逻辑；
3. 形成了稳定的状态变量、证据要求和反证条件；
4. 能明显补足现有 BF-RS、BF-VT、BF-PI、BF-MF 的不足；
5. 经过复盘证明，该场景卡不是简单组合模板，而是一类独立判断机制。

如果后续发现其只是 BF-RS、BF-VT、BF-PI 和 IF-SC 的组合应用，应继续保留为场景卡，不升级为正式框架。
