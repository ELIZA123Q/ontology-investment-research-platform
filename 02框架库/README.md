# 02 框架库使用说明

## 1. 定位

本目录为 02 提供可复用的分析参考。框架回答“一类问题通常有哪些机制、变量、证据、竞争解释和阻断条件”，用于帮助研究者更快搭建并检查本次研究逻辑，但不代替独立判断。

02 应先根据 01 的研究需求识别真正需要辨别的核心矛盾，再参考本目录检查遗漏、补充视角，最后形成属于当前任务的研究框架并映射正式本体。库中框架不是现实事实、正式本体、研究结论或必须照填的报告模板。

```text
01 研究需求
→ 识别核心矛盾并独立搭建基本问题树
→ 查找基础框架和行业框架补充机制、证据与反证
→ 按本次对象、范围和时间裁剪组合
→ 匹配正式本体并形成任务本体视图
→ 03 准备现实实例、观测和证据
```

基础框架的固定结构、证据等级、本体映射和验收要求见[基础框架编写与验收标准](基础框架库/00_基础框架编写与验收标准.md)。半导体行业的覆盖矩阵、中国权威来源和跨行业边界见[半导体行业框架总览与来源索引](行业框架库/半导体/00_半导体行业框架总览与来源索引.md)。

## 4. 框架选择矩阵

| 判断起点 | 首选框架 | 常见补充 | 最容易误判的跳步 |
|---|---|---|---|
| 行业是什么、好坏由什么决定 | BF-IC-01 | BF-SD-01、BF-PC-01 | 分类代码直接当竞争市场 |
| 产品是否紧缺或过剩 | BF-SD-01 | BF-PC-01、BF-VT-01 | 订单等同终端需求；产能等同供给 |
| 涨价能否持续 | BF-PC-01 | BF-SD-01、BF-EE-01 | 报价等同成交和公司实现价 |
| 政策是否产生实际影响 | BF-PI-01 | BF-VT-01、BF-EE-01 | 文本直接跳行业或公司结果 |
| 冲击如何跨产业链传导 | BF-VT-01 | BF-SD-01、BF-RS-01 | 概念邻近当稳定供应关系 |
| 公司靠什么挣钱 | BF-BM-01 | BF-IC-01、BF-FQ-01 | 收入增长不检查单位经济和现金 |
| 行业改善能否变成公司利润 | BF-EE-01 | BF-BM-01、BF-FQ-01 | 认证、订单、收入和现金混用 |
| 财报改善是否真实可持续 | BF-FQ-01 | BF-BM-01、BF-CA-01 | 单指标红旗直接定性 |
| 管理层是否有效配置资本 | BF-CA-01 | BF-FQ-01、BF-CG-01 | ROE高等同增量回报高 |
| 如何预测未来经营 | BF-FS-01 | BF-EE-01、BF-RS-01 | 指引等同事实；单情景线性外推 |
| 治理是否影响长期结果 | BF-CG-01 | BF-FQ-01、BF-CA-01 | 形式合规等同治理有效 |
| 公司能否承受冲击 | BF-RS-01 | BF-FQ-01、BF-CA-01 | 风险清单替代现金与传导测试 |
| 宏观变化如何落到行业 | BF-MF-01 | BF-PI-01、BF-SD-01 | 政策工具直接等同金融或实体条件 |
| 基本面如何改变估值输入 | BF-VA-01 | BF-FS-01、BF-EG-01 | 倍数低等同价值被低估 |
| 新事实是否形成预期差 | BF-EG-01 | BF-FS-01、BF-VA-01 | 没有事前预期基线也声称存在差异 |

## 5. 常用组合链路

```text
→ BF-FS-01 可持续经营预测
```



```text
IF-AI-01 工作负载、系统配置与部署利用
```

组合链路不是固定流水线。若某一前置节点与本次问题无关，可以裁剪；但会改变方向、强度或停止条件的中介不能删除。

## 6. 使用方法

### 6.1 先独立形成核心矛盾

根据当前问题建立基本问题树，说明前置条件、并列问题、竞争解释和停止节点。不要从标题或关键词直接套框架。

### 6.2 再用框架检查遗漏

重点检查：对象和口径是否一致；状态变量是否可观察；是否跳过商业化、履约或财务环节；是否缺少业务时间、竞争解释、阻断条件和下一验证点。

### 6.3 按任务边界裁剪组合

只保留能影响本次判断的模块。框架库不能扩大 01 已确定的对象、时间、地域和产业链范围，也不能为追求完整而编造变量或信号。

### 6.4 最后匹配本体

先查一级通用本体，再查领域本体。正式定义、领域扩展和任务候选必须分开记录。框架中列出的候选变量不会自动成为正式 `StateVariable`。

## 7. 最小使用记录

研究逻辑只需记录：

- 本次研究的核心矛盾和独立形成的问题树；
- 参考了哪些基础或行业框架；
- 框架补充、纠正或排除了什么；
- 最终结构为何与参考框架不同；
- 哪些路径因证据、本体或边界不足被降级或停止。
