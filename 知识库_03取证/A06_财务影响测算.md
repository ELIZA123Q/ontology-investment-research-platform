# A06 财务测算取证

财务测算取证：把行业变量或事件，落到公司收入、利润或现金可复算的桥上。

## 1. 什么时候使用

用于准备行业变量、事件或机制落到公司收入、利润率、净利润、现金流或资产负债表所需的**财务桥输入与测算材料**。目标涉及收入、利润或现金流时，通常还要补本方法。先有 A04 传导与公司暴露材料；只需要方向时不必建完整模型。这类问题通常还要做完整反向检索。

## 2. 取证逻辑

先搭最短财务桥，不把行业变化直接乘公司利润：

```text
业务驱动 → 可销售量／交付 → 实现价与产品结构 → 收入确认
→ 变动／固定成本与利用率 → 利润率
→ 营运资本／资本开支 → 现金
```

按问题裁剪，但行业变量到目标财务科目之间的关键桥不能省略。每个参数标记：已披露实际值、管理层指引、外部估算、模型推算或研究员假设，并保存来源日期、公式和输入。

模型先与最新披露基准期对账，再做量价、成本、利用率、汇率和确认时点拆分。优先准备区间和敏感性材料。利润与现金材料分开。一次性项目、并表、重分类不能当作持续经营弹性材料。

## 3. 最少必须取得什么

| 这份材料起什么作用 | 最低要求 |
|---|---|
| 主证据 | 公司／分部暴露、收入和目标财务科目的实际基准 |
| 机制或承接 | 销量、实现价、产品结构、成本、产能、良率、交付和收入确认中的关键桥 |
| 比较基准 | 最新已披露财务、历史量价／利润率或可复算同业基准 |
| 反证与限制 | 成本抵消、价格传导失败、销量不足、费用增加、确认／回款风险材料 |

取数前先核对：财务期、业务期、产品／分部、币种、会计和确认口径匹配。缺财务基准或关键财务桥时，完备度不得评为充分。

## 4. 优先来源

财务基准和业务拆分优先年报、季报、交易所披露、招股书和可回源数据库；量价和产能用公司披露、行业数据或内部经营数据；成本用公司披露、行业成本数据和供应商信息；卖方模型只作外部估算。公司指引是情景输入，不是实际结果。

## 5. 完备度怎样受限

- 只有行业变量、没有公司暴露：不能形成公司化测算材料。
- 有收入拆分但无量价：只能移交收入方向材料。
- 有量价但无成本／利润率：不能移交利润弹性测算材料。
- 名义产能替代销量，或忽略良率、认证和需求：测算材料不可用。
- 订单、交付、验收、收入和回款混在一起：退回拆桥。
- 核心结果由研究员假设主导：只能作情景材料，完备度通常观察／受限。
- 量价拆分与财务基准不能闭合：先修复，不进入正式测算。

## 6. 交给 04 什么

```text
最短财务桥及目标科目
基准期与对账结果
关键参数、性质、来源日期和公式
基准／上行／下行情景材料及触发条件
最敏感参数、抵消项与现金差异材料
证据完备度：充分／受限／观察／不可用
待裁决问题：财务影响方向、区间与可复算程度（由 04 裁决）
```
