# A03 趋势与阶段取证

趋势与阶段取证：准备「是否持续、是否拐弯、可能处在哪一段」所需的序列与相邻变量材料。

## 1. 什么时候使用

用于准备「是否形成持续趋势、斜率变化、拐点、周期位置或阶段切换」所需的**序列与相邻变量材料**。必须建立在合格的 A02 测量上；只有当前值时，退回 A02。这类问题通常还要做完整反向检索。

## 2. 取证逻辑

取数前先写清可检验判据，再取材料：观察窗口、频率、最少连续点数、累计幅度、扩散要求和阶段切换候选条件。至少区分单点波动、斜率改变、方向反转、扩散确认和阶段切换的材料需求。

排错材料顺序：

```text
季节性 → 基数 → 口径／样本变化 → 一次性扰动 → 候选趋势材料
```

最小趋势材料应预先写成：

```text
在窗口 W 内，指标 X 的连续观测与累计变化材料；
相邻变量 Y 的同窗材料；季节性／基数／断点检查材料。
```

N 和 T 由行业频率与历史噪声决定。优先同时保留首次发布值与最新修订值。周期问题要覆盖需求、供给、库存／订单和价格中与阶段区分有关的变量；分项材料冲突时，分别归档，不在此贴统一阶段标签。

## 3. 最少必须取得什么

| 这份材料起什么作用 | 最低要求 |
|---|---|
| 主证据 | 同对象、同口径、覆盖预设窗口的连续序列 |
| 比较基准 | 前期、历史区间或可比周期材料 |
| 独立交叉验证 | 至少一个领先／同步相邻变量或独立来源 |
| 反证与限制 | 季节性、基数、序列断点、相反变量和竞争阶段解释材料 |

取数前先核对：对象、业务时间、定义、单位、版本匹配。无合格 A02 测量不得启动本方法。

## 4. 优先来源

使用 A02 已确认可用的连续数据库、行业统计和公司披露；补充历史区间、分项扩散和相邻变量。研报可提供阶段假设线索，关键序列应回到原始来源。

## 5. 完备度怎样受限

- 只有单点或同比转正材料：最高观察。
- 同比与环比材料方向冲突：分别归档，完备度通常受限。
- 总量与分项材料冲突：检查集中度／扩散材料是否齐备。
- 历史序列断裂或窗口事后挑选：受限。
- 多变量方向冲突且缺领先滞后材料：受限或不可用。
- 未完成完整反向检索：不得评为充分。

## 6. 交给 04 什么

```text
预设判据材料：窗口／连续点数／幅度／阶段切换候选条件
实际序列结果：方向、幅度、持续性、扩散度材料摘要
首次值与修订值差异
相邻验证与主要反向材料
证据完备度：充分／受限／观察／不可用
待裁决问题：是否构成趋势／阶段切换及候选标签（由 04 贴标签；本方法不输出「阶段已确认」）
```
