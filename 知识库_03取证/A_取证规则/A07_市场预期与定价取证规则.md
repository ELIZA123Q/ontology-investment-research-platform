# A07_市场预期与定价取证规则

## 研究员把四件事分开

- 基本面事实发生了什么；
- 事件前市场预期是什么、样本和时间戳是什么；
- 预期如何修订；
- 价格相对行业/市场如何反应，估值输入改变了什么。

没有可追溯的事前基线，不使用“超预期”；只有股价表现，不使用“已充分计价”。单篇研报、目标价、新闻热度或管理层口径都不能代表完整市场共识。

## 1. 定位

市场预期与定价取证规则用于判断市场是否已经反映某个基本面变化，是否存在预期差、估值重估、交易拥挤或定价错配。

它回答：

```text
市场原本怎么看；
盈利预期是否变化；
价格和估值是否已经反应；
当前观点与市场共识的差异在哪里；
利好或利空是否还有未定价部分。
```

A07 不直接证明基本面事实；基本面事实、变量、机制和财务影响需先由 A01—A06 准备。

## 2. 适用场景

| judgment_type | 示例 |
|---|---|
| `valuation_expectation` | 利好是否已经被估值反映 |
| `expectation_gap` | 市场对供需改善是否低估 |
| `consensus_revision` | 一致预期是否上修或下修 |
| `price_reaction` | 股价是否充分反应事件 |
| `relative_valuation` | 同业估值差异是否合理 |
| `narrative_divergence` | 市场主流叙事与证据是否不一致 |

## 3. 不适用场景

| 问题 | 应转向 |
|---|---|
| 政策或事件是否发生 | A01 |
| 基本面状态是否改善 | A02/A03 |
| 机制是否成立 | A04 |
| 公司受益差异 | A05 |
| 盈利影响测算 | A06 |

## 4. 入口输入

| 字段 | 中文释义 |
|---|---|
| `asset_or_company` | 股票、债券、行业指数、公司或资产 |
| `market_question` | 预期差、估值、价格反应或相对定价问题 |
| `fundamental_input_refs` | 来自 A01—A06 的事实和变量输入 |
| `market_window` | 事件前后、财报前后、周期窗口或观察区间 |
| `benchmark` | 指数、同业、历史估值、目标价或共识基准 |
| `required_quality_level` | 最低证据等级 |

## 5. 必需证据组合

| 必要证据组合 | 目的 | 最低要求 |
|---|---|---|
| `EXPECT_ADMITTED_FUNDAMENTAL_INPUT` 已确认可用的基本面输入 | 确保不是脱离事实谈预期 | 来自 A01—A06，且已通过相应证据检查 |
| `EXPECT_PRIOR_CONSENSUS` 事前一致预期 | 固定事件前基线 | 保存预测 vintage、样本、分布和关键假设 |
| `EXPECT_ESTIMATE_REVISION` 预测修订 | 观察预期如何改变 | 收入、利润、EPS 或关键假设的同样本修订 |
| `EXPECT_PRICE_REACTION` 相对价格反应 | 观察市场定价 | 相对市场/行业收益、成交量、波动率或信用利差 |
| `EXPECT_VALUATION_INPUTS` 估值输入 | 识别估值变化来源 | 盈利基准、增长持续期、资本强度和风险溢价 |
| `EXPECT_COUNTER` 反向定价检查 | 检查是否已充分反映 | 提前交易、样本变化、市场共振、拥挤和风险溢价变化 |

## 6. 来源优先级

| 证据类型 | 首选来源 | 辅助来源 |
|---|---|---|
| 一致预期 | Wind、Bloomberg、FactSet、Refinitiv、iFinD 等授权数据库 | 卖方汇总需标注范围 |
| 价格反应 | 交易所、授权金融数据库、行情 API | 新闻报道不可替代行情 |
| 估值区间 | 授权数据库、公司财务和市场价格复算 | 卖方图表需回源 |
| 市场叙事 | 卖方研报、电话会问答、投资者交流、新闻 | 模型摘要仅作线索 |
| 风险溢价 | 市场利率、信用利差、行业指数、波动率 | 观点材料作解释 |

## 7. 专项质量要求

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 基本面基础 | 预期差必须绑定已确认可用的基本面证据 | 不能形成预期差判断 |
| 预期来源 | 一致预期需说明样本、时间和字段 | 降级 |
| 价格窗口 | 事件窗口和价格窗口必须匹配 | 不能判断反应充分性 |
| 相对基准 | 估值比较必须有同业或历史基准 | 只能描述绝对估值 |
| 叙事分离 | 卖方观点、新闻叙事、市场定价不能混为一类 | 降级 |
| 反证检查 | 必须检查是否已被价格或预期反映 | 不能高质量通过（`high_quality_pass`） |

## 8. 降级规则

| 问题 | 03 处理 | 04 最多能形成的结论 |
|---|---|---|
| 没有已确认可用的基本面输入 | 停止预期差判断 | none |
| 只有卖方观点 | 只作市场叙事 | background_only |
| 只有股价上涨/下跌 | 不能判断预期差 | conditional_only |
| 一致预期口径不清 | 降级 | conditional_only |
| 价格窗口不匹配 | 不能判断定价充分 | insufficient |
| 已充分反映的反证强 | 标记 contested（争议未决）或无预期差 | contested |

## 9. 停止规则

市场预期取证可以停止，当且仅当：

1. 基本面输入来自已确认可用的证据；
2. 一致预期、价格反应和估值背景至少满足两个核心篮子；
3. 市场叙事与价格/预期数据分开；
4. 已检查“预期已反映”的反证；
5. 可明确 04 是能判断预期差、只能观察定价，还是不能判断。

## 10. 输出到本次证据归档

| 文件 | 回写什么 |
|---|---|
| `reasoning_inputs.csv` | 市场预期、价格反应、估值变量 |
| `evidence_records.csv` | 一致预期、行情、估值、叙事来源 |
| `display_data_candidates.csv` | 股价、估值、一致预期图表候选 |
| `table_material_package.csv` | 同业估值表、预期变化表 |
| `evidence_readiness_assessments.csv` | 该预期差核心判断证据是否够用 |
| `gaps_and_risks.csv` | 预期已反映、样本限制、定价冲突 |

## 11. 示例

问题：存储周期景气是否还存在预期差。

最低证据：

```text
03 已确认可用的周期和财务证据
+ 一致预期是否上修
+ 股价和估值是否已经反映
+ 同业和历史估值对比
+ 卖方/市场主流叙事
+ 反证：预期已充分上修、估值已高、风险溢价上升
```

## 12. 专项执行约定：固定事前预期

预期差必须使用信息发生前可得的预期基线（vintage），不能拿事件后的最新一致预期倒推“市场原本怎么看”。至少记录：

| 字段 | 要求 |
|---|---|
| `information_time` | 新信息首次公开时间和时区 |
| `consensus_cutoff` | 事件前最后可用一致预期截点 |
| `sample_size` | 覆盖机构数及样本变化 |
| `metric_and_period` | 收入/EPS/利润/关键假设及预测期 |
| `distribution` | 中位数、均值、区间和分歧度；不能只看平均值 |
| `revision_path` | 事件后预测修订的方向、幅度和速度 |
| `price_window` | 事件前、事件日和后续窗口 |
| `benchmark` | 市场、行业、风格或可比资产基准 |

没有事前 vintage，只能描述当前共识，不能正式声称存在预期差。

## 13. 定价反应拆解

价格变化至少拆成：

```text
资产收益
- 市场基准收益
- 行业/风格共同收益
= 受限的相对或异常表现
```

事件窗口需要处理：盘前/盘后发布、交易日、停牌、跨市场时区、同期宏观事件和泄露/提前交易。短窗适合观察即时反应，长窗更易混入其他信息；两者不能互相替代。

股价不动可能表示已计价、信息不重要、正负信息抵消、流动性不足或市场尚未理解，不能单独证明“已反映”。股价上涨也不能单独证明基本面判断正确。

## 14. 估值输入而非倍数标签

估值判断至少区分：

- 盈利/现金流基准是否改变；
- 增长率和持续期是否改变；
- 资本强度与再投资回报是否改变；
- 折现率、风险溢价和尾部风险是否改变；
- 会计周期和一次性项目是否扭曲倍数；
- 同业差异是否由业务结构、增长、盈利质量或治理解释。

“估值低于历史均值”不等于低估；“股价已上涨”不等于充分计价。

## 15. 市场叙事取证

叙事材料用于回答市场关注什么，而非证明事实。应记录样本范围、发布日期和观点分布，并区分：

| 材料 | 可支持 | 不可支持 |
|---|---|---|
| 一致预期数据库 | 可量化共识与修订 | 关键假设未必透明 |
| 单篇卖方报告 | 一个观点和模型假设 | 市场整体共识 |
| 多篇同源报告 | 观点扩散 | 独立证据数量 |
| 电话会问答 | 投资者关注点 | 全市场定价程度 |
| 新闻/社媒 | 叙事热度线索 | 正式预期基线 |

## 16. 典型失败模式

| 失败模式 | 处理 |
|---|---|
| 事件后共识当事前基线 | 回取 vintage；不可得则禁止预期差判断 |
| 单篇研报等同一致预期 | 仅作 narrative_evidence（叙事证据） |
| 只看绝对涨跌 | 加入市场/行业基准和同期事件 |
| PE 低即低估 | 回到盈利质量、增长、风险和资本强度 |
| 目标价数量投票 | 不作为独立验证，检查模型假设分布 |
| 预期样本变化未处理 | 同时展示可比样本和全样本结果 |
| 基本面证据不足先谈定价 | 路径停止，返回 A01—A06 |
