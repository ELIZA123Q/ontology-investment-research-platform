# A09_代理指标使用规则

## 代理指标必须过四问

1. 它通过什么稳定机制代表目标变量？
2. 在什么对象、窗口和状态下关系成立？
3. 历史领先滞后、方向一致性和结构断点如何？
4. 什么情况会让代理失效，届时用什么交叉验证？

代理适合缩小搜索、判断方向或触发更新，不适合填补关键直接证据后把结论升级为“已确认”。多个来源复制同一个代理，不构成独立验证。

## 1. 定位

代理指标使用规则用于处理直接指标不可得、滞后、权限受限或口径不完整时，是否可以使用相邻变量、替代数据或间接观测来支持有限判断。

它回答：

```text
代理指标代理的是什么原始变量；
代理逻辑是否成立；
在哪些条件下有效或失效；
代理指标能支持什么强度的判断；
是否必须降级。
```

A09 不能单独形成判断，必须绑定 A02—A08 中的某个取证规则。

## 2. 适用场景

| 场景 | 示例 |
|---|---|
| 主数据不可得 | HBM 实际成交价不可得，用公司 ASP、合约价或供应协议线索做代理 |
| 主数据滞后 | 官方库存季度披露滞后，用渠道交期、价格和订单变化观察边际 |
| 权限受限 | 无 Wind/Bloomberg 数据，用公开披露和行业报告替代 |
| 变量不可直接观测 | 客户真实需求不可得，用订单、出货、资本开支、交期代理 |
| 样本不足 | 单家公司数据不可代表行业，用同业或上下游数据交叉 |

## 3. 不适用场景

| 问题 | 处理 |
|---|---|
| 有直接指标但未查找 | 先查直接指标，不能直接用代理 |
| 代理逻辑无法解释 | 不能进入证据包 |
| 代理指标与目标变量方向不稳定 | 只能作为线索 |
| 代理完全来自模型推测 | 不能作为正式证据 |
| 核心待验证命题完全依赖单一代理 | 04 不能做方向性判断 |

## 4. 入口输入

| 字段 | 中文释义 |
|---|---|
| `target_variable` | 被代理的原始变量 |
| `proxy_indicator` | 拟使用的代理指标 |
| `proxy_reason` | 使用代理的原因 |
| `proxy_logic` | 代理逻辑 |
| `valid_conditions` | 代理有效条件 |
| `invalid_conditions` | 代理失效条件 |
| `cross_validation_plan` | 交叉验证计划 |
| `confidence_discount` | 置信度折扣 |

## 5. 必需证据组合

| 必要证据组合 | 目的 | 最低要求 |
|---|---|---|
| `PROXY_LOGIC` 代理逻辑 | 说明为什么需要且能够代理 | 主数据不可得，并有业务机制、历史关系或统计关系说明 |
| `PROXY_VALID_CONDITION` 有效条件 | 限定适用范围 | 产品、时间、地区、对象、阶段和市场结构条件 |
| `PROXY_INVALID_CONDITION` 失效条件 | 防止越权 | 说明什么情况下代理关系不成立 |
| `PROXY_CROSS_CHECK` 交叉验证 | 防止单一代理误导 | 至少一个独立相邻变量或来源验证 |
| `PROXY_CONFIDENCE_DISCOUNT` 置信度折扣 | 控制 04 强度 | 明确最高只能支持背景、条件或倾向判断 |

## 6. 来源优先级

代理指标的来源优先级取决于其绑定的主规则，但必须满足：

1. 代理指标来源自身可追溯；
2. 代理指标口径清楚；
3. 代理指标与目标变量的对应关系可解释；
4. 若代理来自二手观点，应回到原始数据或降级为线索；
5. 若代理来自 AI 摘要，必须回源校验。

## 7. 代理指标类型

| 类型 | 示例 | 常见限制 |
|---|---|---|
| 相邻变量代理 | 用交期代理供给紧张 | 可能受需求、物流、合同影响 |
| 上下游代理 | 用客户资本开支代理订单需求 | 传导存在滞后和预算偏差 |
| 价格代理 | 用现货价代理合约价 | 规格、市场、交易量可能不同 |
| 行为代理 | 用扩产公告代理供给释放 | 公告不等于实际投产 |
| 市场代理 | 用股价反应代理预期 | 股价受多因素影响 |
| 文本代理 | 用管理层表述代理经营状态 | 选择性披露和措辞偏差 |

## 8. 专项质量要求

| 质量项 | 要求 | 不满足时处理 |
|---|---|---|
| 必要性 | 必须说明为什么不用直接指标 | 退回直接取数 |
| 逻辑性 | 必须有业务或统计逻辑 | 不能使用 |
| 边界性 | 必须有有效/失效条件 | 降级 |
| 可验证性 | 至少有一个交叉验证 | 只能线索 |
| 标识清楚 | 不能把代理写成原始变量 | 退回修正 |
| 折扣明确 | 必须影响证据等级和 04 上限 | 不能高质量通过（`high_quality_pass`） |

## 9. 降级规则

| 问题 | 03 处理 | 04 最多能形成的结论 |
|---|---|---|
| 代理逻辑清楚且有交叉验证 | 可作为受限推理输入 | conditional_only 或 directional_only |
| 代理逻辑清楚但无交叉验证 | 只作线索或背景 | background_only |
| 代理边界不清 | 不进入正式证据计数 | insufficient |
| 核心待验证命题完全依赖代理 | 标记 proxy_dependency_high（代理依赖高） | conditional_only |
| 代理与直接证据冲突 | 优先直接证据并记录冲突 | contested |
| 代理来自弱来源 | 降为线索 | background_only |

## 10. 停止规则

代理指标使用可以停止，当且仅当：

1. 主数据不可得或不适用的原因已记录；
2. 代理逻辑、有效条件和失效条件已说明；
3. 代理来源可追溯；
4. 已完成至少一个交叉验证或说明无法验证；
5. 已明确置信度折扣和 04 最多能形成的结论。

## 11. 输出到本次证据归档

| 文件 | 回写什么 |
|---|---|
| `proxy_indicators.csv` | 目标变量、代理指标、代理逻辑、有效/失效条件、折扣 |
| `evidence_readiness_assessments.csv` | 代理依赖程度、验证状态、降级结果 |
| `evidence_baskets.csv` | 代理篮子（proxy basket）状态 |
| `gaps_and_risks.csv` | 代理限制和直接数据缺口 |
| `reasoning_inputs.csv` | 代理观测、目标变量、领先滞后和适用窗口 |

## 12. 示例

目标变量：HBM 实际供给紧张程度。

代理指标：

```text
原厂 HBM capex / 产能扩张指引；
客户长单或供应协议；
先进封装产能约束；
DDR5 交期和服务器 DRAM 合约价；
HBM 相关公司订单和收入指引。
```

使用限制：

```text
这些指标不能直接替代 HBM 实际成交量或实际成交价；
只能支持“供给紧张存在较强线索”或“结构性偏紧有条件成立”；
若缺少独立交叉验证，不能支撑强方向判断。
```

## 13. 专项执行约定：代理验证卡

代理指标必须建立验证卡：

| 字段 | 要求 |
|---|---|
| 构念对应 | 目标变量的哪一部分被代理，哪一部分没有 |
| 业务机制 | 为什么代理变化应领先、同步或滞后目标变量 |
| 方向与时滞 | 正/负关系和合理时滞区间（lag range） |
| 历史稳定性 | 至少覆盖正常、紧张或转折等不同阶段 |
| 样本与结构 | 产品、地区、公司和市场结构是否改变 |
| 独立验证 | 另一个不同生成机制的代理或滞后主数据 |
| 失效监控 | 哪些信号出现后应停用代理 |
| 退休条件 | 直接数据恢复后如何回测、替换和关闭 |

“业务上似乎相关”只能作为候选代理；进入正式推理至少需要机制说明和一次独立验证。

## 14. 代理组合规则

- 多个高度同源代理不构成三角验证，例如多篇报告引用同一报价；
- 优先组合不同生成机制的代理，例如价格 + 交期 + 客户行为；
- 代理方向冲突时不能求平均，应检查时滞、范围和失效条件；
- 文本代理与行为代理冲突时，优先核查实际行为，但保留文本作为预期或叙事证据；
- 主数据恢复后，应比较代理此前的方向、时滞和误差，形成复盘；系统性失效的代理应标记 retired（已停用）。

## 15. 统计关系的使用边界

如使用相关、回归或领先关系验证代理：

1. 保留样本窗口、频率、变换和缺失处理；
2. 检查趋势共线、季节性和结构断点，不能只报告相关系数；
3. 样本外或滚动窗口稳定性优于单一全样本拟合；
4. 统计关系不能替代业务机制；
5. 代理与目标的历史关系不保证事件冲击期仍成立；
6. 不把模型拟合优度转换为判断置信概率。

## 16. 置信折扣与上限

| 代理状态 | 04 最多能形成的结论 |
|---|---|
| 机制清晰、历史稳定、双重独立验证 | 可作为受限方向输入，但不能替代配方禁止替代项 |
| 机制清晰、仅一次交叉验证 | conditional_only |
| 只有统计相关或单一文本代理 | background_only |
| 与主数据或其他代理重大冲突 | contested |
| 失效条件已出现 | 不能使用，标记 invalidated/retired（失效/已停用） |

## 17. 典型失败模式

| 失败模式 | 处理 |
|---|---|
| 用扩产公告代理实际供给 | 只证明意图，补建设、良率和出货 |
| 用股价代理市场预期 | 需控制市场因素并补共识/叙事 |
| 用订单代理终端需求 | 检查重复下单、取消、库存和交付 |
| 用现货价代理合约价 | 限定规格、市场和成交量 |
| 直接数据存在却偏好代理 | 返回主数据，代理只作交叉验证 |
| 代理长期不复盘 | 定期与迟到主数据对照并更新状态 |
