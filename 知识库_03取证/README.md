# 03 取证库

本库只回答：要证明什么、用哪一种取证方法、最少要拿到什么、优先去哪里找、完备度最高到哪一级。单次归档与阶段门槛见 [`03_数据与证据准备规范`](../03_数据与证据/03_数据与证据准备规范.md)。

## 和 02、04 的边界

- [`知识库_02框架`](../知识库_02框架/README.md) 决定判断什么、按什么结构验证。
- 本库决定需要什么证据、去哪里找、怎样验收、**证据完备度**最高到哪一级。
- [`知识库_04推理`](../知识库_04推理/README.md) 决定合格证据怎样形成、削弱、打断或修改判断（**命题支持状态**）。

| 轴 | 责任方 | 示例 |
|---|---|---|
| 证据完备度 | 03 | 充分／受限／观察／不可用 |
| 命题支持状态 | 04 | 支持／部分支持／削弱／争议未决／阻断／推翻／暂不可判断 |

“充分”= 材料齐到可做明确裁决（含明确否定），不是“原命题已被证明为真”。本库不输出路径成立、公司最受益、预期差成立等裁决结论。

## 动线与选方法

```text
02 待验证判断 → 取证任务卡 → 1 主方法 + 1 来源速查 → 完备度收口 → 待裁决问题交 04
```

| 正在回答的问题 | 用哪个方法 |
|---|---|
| 当前是什么状态 | [A02](A02_状态变量测量.md) |
| 趋势或阶段切换 / 周期位置 | [A03](A03_趋势与阶段判断.md)（先有合格 A02） |
| 主因 / A 如何影响 B / 改判信号 | [A04](A04_机制传导验证.md)（起点未定先 A01） |
| 谁更受益或敏感 | [A05](A05_对象分化比较.md) |
| 新信息是否已被市场反映 | [A07](A07_市场预期与定价.md)（无事前截面不做预期差材料） |

按需：[A01](A01_事实确认.md)、[A06](A06_财务影响测算.md)、[A08](A08_反证与竞争解释.md)、[A09](A09_代理指标.md)。系统对照见 [`03_registry.yaml`](03_registry.yaml)。

材料作用：主证据、比较基准、机制或承接、独立交叉验证、反证与限制。取数前核对可追溯、权限、对象、业务时间、定义单位、版本。
