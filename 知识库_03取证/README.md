# 03 取证库

本库只回答五个问题：这次要证明什么、用哪一种取证方法、最少要拿到什么、优先去哪里找、证据齐不齐（完备度最高到哪一级）。

默认动线：

```text
02 里已经写清的待验证判断
→ 填一张取证任务卡
→ 打开 1 个主方法 + 1 张来源速查表
→ 用「证据质量与结论上限」收口：只谈完备度，并把待裁决问题交给 04
```

## 和 02、04 的边界

- [`知识库_02框架`](../知识库_02框架/README.md) 决定判断什么、按什么结构验证。
- 本库决定需要什么证据、去哪里找、怎样验收、**证据完备度**最高到哪一级。
- [`知识库_04推理`](../知识库_04推理/README.md) 决定合格证据怎样形成、削弱、打断或修改判断（**命题支持状态**）。

03 输出停在：取得了什么、覆盖哪个对象／时间／口径、哪些关键条件已有／仍缺或冲突、完备度、交给 04 的待裁决问题。

03 **不**直接输出：阶段已确认、路径已成立、某公司最受益、判断被阻断、预期差成立。

两条轴：

| 轴 | 责任方 | 示例 |
|---|---|---|
| 证据完备度 | 03 | 充分／受限／观察／不可用 |
| 命题支持状态 | 04 | 支持／部分支持／削弱／争议未决／阻断／推翻／暂不可判断 |

“充分”表示材料已经齐到可以做一次明确裁决，**包括明确支持与明确否定**；不是“原命题已被证明为真”。

## 一次取证怎样开始

1. 从 02 复制一句待验证判断，以及对象、时间和范围。
2. 按下表选一个主方法。若起点事实未定，通常先补事实确认；涉及收入／利润／现金流时，通常还要补财务测算材料；直接数据拿不到时才用代理指标。
3. 在 [`00_取证任务卡.md`](00_取证任务卡.md) 里写清主证据、比较基准、交叉验证和反证计划；取数前先核对对象、时间、定义、单位、版本。
4. 从 [`B00 来源选择与使用边界`](B00_来源选择与使用边界.md) 选主源、独立交叉源和反证来源。
5. 用 [`00_证据质量与结论上限.md`](00_证据质量与结论上限.md) 写出完备度、限制、待裁决问题，以及升级还缺什么。

## 选方法：正在回答的问题 → 用哪个方法

| 正在回答的问题 | 用哪个方法 |
|---|---|
| 当前是什么状态 | [A02 状态测量取证](A02_状态变量测量.md) |
| 是否形成趋势或阶段切换 | [A03 趋势与阶段取证](A03_趋势与阶段判断.md)（先要有合格的 A02） |
| 周期处于哪一段 | [A03 趋势与阶段取证](A03_趋势与阶段判断.md)（先要有合格的 A02） |
| 已观察变化主要由什么造成 | [A04 路径分段取证](A04_机制传导验证.md)（起点事实未定先补 A01） |
| A 怎样影响 B | [A04 路径分段取证](A04_机制传导验证.md)（起点事实未定先补 A01） |
| 谁更受益、受损或更敏感 | [A05 可比性与暴露取证](A05_对象分化比较.md)（口径未统一不排序） |
| 新信息是否已被市场反映 | [A07 事前预期与定价取证](A07_市场预期与定价.md)（没有事前预期截面，不做预期差材料） |
| 哪个信号会触发改判 | [A04 路径分段取证](A04_机制传导验证.md)（起点事实未定先补 A01） |

> 系统对照见 [`03_registry.yaml`](03_registry.yaml)。

四个按需方法：

- [A01 事实状态取证](A01_事实确认.md)：若起点事实未定，先做事实确认；做轻量反向检查即可（修订／撤回／否认）。
- [A06 财务测算取证](A06_财务影响测算.md)：目标涉及收入、利润或现金流时，通常还要补财务桥与测算材料。
- [A08 反向证据扫描](A08_反证与竞争解释.md)：A03—A07 这类问题通常还要做完整反向检索；A01／A02 做轻量反向检查即可。
- [A09 代理指标校准](A09_代理指标.md)：只有直接数据不可得时使用；作核心替代时完备度最高「受限」。

## 取数前先核对；材料在判断里起什么作用

所有材料取数前先核对：可追溯、权限合法、对象匹配、业务时间匹配、定义与单位匹配、版本明确。任务卡上的「范围与口径」就是这份核对摘要。

| 这份材料在判断里起什么作用 | 回答什么 |
|---|---|
| 主证据 | 是否直接回答当前问题 |
| 比较基准 | 相对前期、历史、同业或正常区间处于哪里 |
| 机制或承接 | 变化怎样传导，谁能承接，哪里可能卡住 |
| 独立交叉验证 | 不同生产链的材料是否给出相容结果 |
| 反证与限制 | 哪些反向、可能卡住的条件或竞争解释需要交给 04 |

代理指标不是第六种作用，而是某个作用的降级取得方式。
