# B04-TOPIC-GEOPOLITICAL_地缘冲击取证来源清单

## 第一部分：来源清单与使用边界

### 地缘取证按四层推进

1. **规则事实**：正式文本、主体、产品/实体/用途范围、生效与豁免；
2. **真实暴露**：产品分类、客户/供应关系、地域收入或采购、许可依赖；
3. **缓冲与替代**：库存、合同、本地化、替代供应、执行弹性；
4. **结果确认**：贸易流、交期、价格、订单、产量与公司财务。

只完成第一层时，只能确认事件；完成前两层可写条件性暴露；没有第三、四层，不应直接写“显著利好/利空”。新闻和专家解读可帮助理解规则，但关键范围必须回到正式文本与可核验业务数据。

### 1. 定位

本文是 03 取证策略库中 B04 专题来源的第一份样板文件，用于处理“地缘冲击”类投研问题的来源选择。

它不替代 B02 通用来源，也不替代 B03 行业专用来源。

- B02 解决跨行业通用证据去哪取：政策、监管、公司披露、金融市场、宏观、贸易、商品、新闻、研报等。
- B03 解决特定行业变量去哪取：行业供需、价格、库存、产能、份额、下游需求、行业口径等。
- B04 解决跨行业专题冲击去哪取：地缘冲突、制裁管制、航道扰动、能源冲击、贸易限制、供应链暴露、金融制裁、国家风险等。

本文的目标不是列“地缘政治资料大全”，而是让 03 在做地缘冲击取证时，能够快速回答：

1. 冲击事实是否真实发生；
2. 冲击是否已经进入正式政策、制裁、管制或军事行动；
3. 冲击通过哪条传导链影响资产、行业或公司；
4. 哪些来源能支撑方向判断，哪些只能作为线索；
5. 主源缺失时如何降级；
6. 反证应该去哪里找。

本文件负责来源选择和专题边界；BIS/OFAC/中国出口管制、贸易、航运和能源的具体查询字段与失败回退见 [B04-TOPIC-GEOPOLITICAL-OPS 查询手册](B04-TOPIC-GEOPOLITICAL-OPS_地缘规则与冲击查询手册.md)。

### 2. 适用问题

本文适用于以下问题类型：

| 问题类型 | 示例 |
|---|---|
| 军事冲突和战争升级 | 中东冲突、俄乌冲突、印巴冲突、朝鲜半岛风险、台海风险 |
| 航道和海运扰动 | 霍尔木兹海峡、红海、苏伊士运河、黑海、马六甲海峡、巴拿马运河 |
| 制裁与出口管制 | OFAC 制裁、BIS Entity List、欧盟制裁、中国出口管制、技术封锁 |
| 贸易摩擦与关税 | Section 301、反倾销、反补贴、报复性关税、进口限制 |
| 能源和商品地缘风险 | 原油、天然气、LNG、煤炭、铀、粮食、化肥、关键金属 |
| 国家风险和政策突变 | 政变、选举、政权更替、资本管制、外汇管制、国有化 |
| 金融制裁和支付体系风险 | SWIFT、二级制裁、银行清算限制、外汇固定、主权债风险 |
| 供应链安全和关键基础设施 | 港口、管道、炼厂、电网、数据中心、海缆、关键矿产 |

不适用：

1. 单纯行业周期问题，应先用 B03 行业来源；
2. 单纯公司业绩测算，应先用 B02 公司披露和金融数据库；
3. 单纯宏观数据跟踪，应先用 B02 宏观来源；
4. 无明确冲击机制的泛泛“国际形势分析”。

### 3. 使用顺序

03 做地缘冲击取证时，应按以下顺序使用来源：

```text
02 判断单元
→ 识别是否属于地缘冲击
→ B04 确认冲击事实、政策动作、冲击通道和反证来源
→ B02 补公司披露、市场行情、宏观、贸易、商品等通用来源
→ B03 补行业专用变量
→ 形成必要证据组合
→ 判断 04 最多能形成的结论
```

原则：

1. 先确认“事件是否发生”和“正式动作是否落地”，再讨论影响。
2. 军事、制裁、航道、能源、贸易、金融市场必须分开取证。
3. 新闻只能做线索；关键事实必须尽量回到官方、监管、交易所、数据库或专业来源。
4. 地缘冲击天然容易被叙事放大，必须主动查反证。
5. 地缘事件影响不能直接外推到行业或公司，必须经过暴露度、传导路径和财务敏感性验证。
6. 涉及中国、A/H 股、中资企业、中国供应链、中国贸易或中国政策回应时，必须同时检查中国外交、商务、海关、海事、交易所、公司披露和中文权威新闻来源。


### 3.1 全球/中国双侧取证原则

地缘冲击取证不能只看国际新闻，也不能只看中国单方表态。应按以下规则配对：

| 问题 | 全球侧主源 | 中国侧主源 | 使用边界 |
|---|---|---|---|
| 冲突事实 | 当事国政府、联合国、ACLED、Reuters/Bloomberg/AP | 外交部、国防部、国台办、新华社/人民日报 | 官方表态代表立场，事实确认需多源交叉 |
| 制裁/出口管制 | OFAC、BIS、Federal Register、EU Official Journal、UK OFSI | 商务部、中国出口管制信息网、海关总署、外交部、国务院、市场监管总局 | 必须区分制裁事实、管制物项、许可要求和反制措施 |
| 贸易暴露 | UN Comtrade、USITC、WTO、ITC Trade Map、Eurostat | 海关总署统计查询平台、商务部数据中心、税委会 | HS code、数量单位、币种、报告期必须一致 |
| 航道物流 | EIA chokepoints、Drewry、Freightos、Baltic Exchange、Clarksons、UKMTO | 上海航运交易所、中华航运网、中国海事局、主要港口公告 | 航运指数和公司交付影响要分开 |
| 能源商品 | EIA、IEA、OPEC、ICE、CME、LME、Argus、Platts | 国家能源局、上期所/INE、大商所、郑商所、SMM、Mysteel、百川、隆众 | 国际价格和中国到岸/现货/期货口径不能混用 |
| 公司影响 | SEC EDGAR、HKEXnews、DART、EDINET、公司 IR | 巨潮资讯、上交所、深交所、北交所、HKEXnews、A/H 股公司公告 | 风险披露、收入地区、供应链关系和实际损益要分开 |
| 市场反应 | Bloomberg、LSEG、FactSet、交易所、CME/ICE | Wind、iFinD、Choice、中证指数、交易所、外汇交易中心、中债 | 市场反应只能说明定价，不等于基本面事实 |

### 4. 地缘冲击的核心必要证据组合

| Basket ID / 专题子项 | 回答的问题 | 首选来源方向 |
|---|---|---|
| `TRANS_START_FACT` / 冲突事实 | 事件是否真实发生，发生在何时何地，涉及哪些主体 | 官方声明、国际组织、冲突数据库、权威新闻 |
| `TRANS_START_FACT` / 升级强度 | 是口头威胁、局部冲突、制裁落地，还是实际军事行动 | 官方军事/外交声明、ACLED、CFR、ICG、Reuters/Bloomberg/AP |
| `TRANS_START_FACT` / 制裁管制 | 是否有正式制裁、实体清单、出口管制、投资限制 | OFAC、BIS、Federal Register、CSL、EU Official Journal、UK OFSI、中国商务部等 |
| `TRANS_START_FACT` / 贸易限制 | 是否有关税、禁运、许可证、海关限制、原产地规则变化 | USTR、CBP、USITC、WTO、海关、UN Comtrade、ITC Trade Map |
| `TRANS_INTERMEDIATE_NODE` / 航道物流 | 是否影响港口、航道、保险、运价、船舶绕行、交付时间 | Drewry、Freightos、Baltic Exchange、Clarksons、UKMTO、JMIC、EIA chokepoints |
| `TRANS_INTERMEDIATE_NODE` / 能源商品 | 是否影响原油、天然气、LNG、电力、金属、粮食、化肥 | EIA、IEA、OPEC、JODI、ICE、CME、LME、S&P Global Commodity Insights、Argus |
| `TRANS_EXPOSED_SUBJECT` / 供应链暴露 | 哪些国家、公司、产品、HS code、客户或供应商暴露 | 公司披露、海关、UN Comtrade、USITC DataWeb、Panjiva/ImportGenius、FactSet/Bloomberg 供应链数据 |
| `TRANS_OUTCOME_VARIABLE` / 金融市场反应 | 油价、汇率、利率、股价、信用、波动率如何反应 | Wind、Bloomberg、Refinitiv/LSEG、FactSet、Capital IQ、交易所、CME、ICE |
| `TRANS_OUTCOME_VARIABLE` / 公司经营影响 | 公司收入、成本、客户、供应商、物流、存货是否受影响 | 年报、季报、公告、IR、业绩会、风险因素、管理层指引 |
| `TRANS_BLOCKER_COUNTER` / 反证和缓冲 | 是否有库存、替代路线、豁免、过渡期、战略储备、停火或影响有限证据 | 同层级反向来源、公司披露、库存数据、航运数据、能源储备、官方豁免文件 |

### 5. 来源优先级总表

| 取证任务 | 主源 | 交叉验证 | 替代或线索 | 04 最多能形成的结论 |
|---|---|---|---|---|
| 确认军事/安全事件 | 当事国官方声明、国际组织、UN OCHA/ReliefWeb、ACLED | Reuters、Bloomberg、AP、CFR、ICG、CSIS | 社媒、论坛、OSINT 账号 | 主源可复核才可进入事实确认；社媒只能作线索 |
| 确认制裁/出口管制 | OFAC、BIS、Federal Register、CSL、EU Official Journal、UK OFSI、各国主管部门 | 公司公告、律师事务所简报、权威媒体 | 新闻标题、研报摘要 | 必须回到正式清单或规则文本 |
| 判断贸易暴露 | UN Comtrade、USITC DataWeb、IMF trade data、海关、ITC Trade Map | 公司披露、行业协会、WTO、OECD TiVA | 新闻、研报图表 | 能支撑贸易暴露，但不能自动推出盈利影响 |
| 判断航道扰动 | Drewry、Freightos、Baltic Exchange、Clarksons、UKMTO、JMIC、EIA chokepoints | 公司物流表述、港口公告、船公司公告、保险费率 | 新闻、行业媒体 | 可支持物流压力，需结合行业库存和公司交付周期 |
| 判断能源冲击 | EIA、IEA、OPEC、JODI、ICE、CME、EEX、LME | Wind/Bloomberg、公司成本披露、商品研究机构 | 新闻油价描述 | 可支持成本/通胀/风险偏好变化，不能直接推公司利润 |
| 判断金融市场反应 | 交易所、Wind、Bloomberg、Refinitiv/LSEG、FactSet、Capital IQ | ETF、期货、期权、CDS、VIX、MOVE | 新闻叙事 | 可支持市场反应和预期变化，不等于基本面确认 |
| 判断公司暴露 | SEC EDGAR、HKEXnews、巨潮、交易所公告、公司 IR | 供应链数据库、海关、客户/供应商披露 | 卖方研报、专家纪要 | 公司披露是主源；供应链和调研需说明口径 |
| 判断反证 | 与主证据同层级的反向来源 | 库存、替代路线、豁免、停火、价格回落、公司无影响表述 | 市场传闻 | 没有反证检查，不能给高强度方向判断 |

### 6. 具体来源清单

### 6.1 冲突事实、军事行动和安全事件

适合支持：

1. 事件是否发生；
2. 事件时间、地点、参与方；
3. 冲突强度变化；
4. 是否存在升级、停火、谈判或外溢风险；
5. 是否涉及关键港口、航道、管道、能源设施、通信基础设施。

首选来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| 当事国政府、外交部、国防部、军方通报 | 确认官方立场、军事行动、外交回应 | 官方立场可能有偏向，不能单独确认全部事实 |
| UN Security Council / UN OCHA / ReliefWeb | 冲突、人道、撤离、停火、国际组织信息 | 更适合确认局势和人道影响，不直接支持金融影响 |
| ACLED | 冲突事件数据库、暴力事件、地点、参与方、伤亡等结构化跟踪 | 存在报告延迟和来源限制，适合趋势和空间分布，不宜作为唯一事实主源 |
| International Crisis Group / CrisisWatch | 冲突升级、降级、政治背景、风险解释 | 属于分析和预警来源，不替代官方事实 |
| CFR Global Conflict Tracker | 全球冲突状态和背景 | 适合做背景和风险等级，不替代实时事件确认 |
| CSIS / IISS / Chatham House / Brookings / MERICS | 地缘机制、军事能力、区域安全解释 | 适合机制和背景，不作为硬事实唯一来源 |
| Reuters / Bloomberg / AP / FT / WSJ / Nikkei Asia | 事件线索、时间线、市场反应、官方表态转述 | 关键事实需回到官方或原始文件 |


中国侧补充来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| 外交部 | 外交表态、记者会、声明公报、涉外制裁/反制立场 | 代表中国官方立场，不能单独确认全部冲突事实 |
| 国防部 | 军事声明、演训信息、国防政策、安全表态 | 需与其他官方和第三方来源交叉 |
| 国台办 | 台海相关政策表态、两岸事件回应 | 适合台海场景，不能替代军事或贸易数据 |
| 中国海事局 / 地方海事局 | 航行警告、航行通告、海上安全事件、禁航区 | 适合确认中国周边海域管制和航行安全 |
| 新华社 / 人民日报 | 官方新闻、重要会议、权威发布 | 更适合时间线和官方叙事，不替代原始公告 |
| 中国驻外使领馆 | 撤侨、旅行提醒、当地安全通报 | 适合确认中国企业和人员安全风险线索 |

禁止用法：

1. 不得用社媒截图直接确认军事行动；
2. 不得用单一匿名消息源确认关键事实；
3. 不得把智库判断写成已发生事实；
4. 不得把一方官方声明直接等同于客观事实；
5. 不得只确认“冲突发生”，不确认地点、强度、持续性和外溢通道。

### 6.2 制裁、出口管制、实体清单和投资限制

适合支持：

1. 哪个主体被制裁或限制；
2. 哪类产品、技术、服务、资金流受限制；
3. 生效日期、豁免、过渡期、许可证要求；
4. 是否有二级制裁、长臂管辖、再出口限制；
5. 公司或行业是否暴露于限制对象。

首选来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| OFAC Sanctions List Search / OFAC Sanctions List Service | 美国制裁对象、SDN、非 SDN 清单 | 必须核对实体名称、别名、国家、清单类型、更新日期 |
| BIS Entity List / Denied Persons List / Unverified List | 美国出口管制、实体清单、许可要求 | 必须核对 EAR、ECCN、license requirement、license review policy |
| Federal Register | 美国正式规则、出口管制修订、制裁和关税规则文本 | 必须核对 rule、effective date、comment period、修订版本 |
| Consolidated Screening List | 美国多部门限制清单聚合检索 | 适合筛查，但关键判断仍应回到主管部门原始清单 |
| USTR / CBP / USITC | Section 301、关税、海关执行、进口统计 | 适合贸易限制和关税事实确认 |
| EU Official Journal / EU Sanctions Map | 欧盟制裁法规、限制对象、适用范围 | 必须核对法规编号和成员国执行口径 |
| UK OFSI / UK Export Control Joint Unit | 英国金融制裁和出口管制 | 适合英国相关制裁和管制事实 |
| 中国商务部、海关总署、国务院、外交部、工信部、市场监管总局 | 中国出口管制、不可靠实体清单、反制措施、贸易管理 | 需核对公告原文、生效日、适用品类和企业名单 |
| 日本 METI / MOF，韩国 MOTIE，台湾经济部/国际贸易署 | 日韩台出口管制、贸易限制、产业政策 | 适合东亚产业链和半导体、材料、设备限制确认 |


中国侧补充来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| 商务部 / 中国出口管制信息网 | 两用物项出口管制、出口管制清单、许可、相关公告 | 管制物项以正式清单和公告为准，数据库仅辅助检索 |
| 国务院 / 中国政府网 | 行政法规、出口管制条例、反外国制裁相关法规 | 需核对法律/法规/规章层级和生效时间 |
| 外交部 | 反制裁声明、外交回应、涉外立场 | 表态不能替代商务部或法规清单 |
| 海关总署 | 海关监管、禁限进出口、商品归类、执行口径 | 执行层面仍需核对海关公告和 HS 归类 |
| 市场监管总局 | 反垄断、经营者集中、行政处罚 | 适合中国市场竞争和合规影响 |
| 发改委 / 工信部 | 产业安全、关键产业政策、供应保障 | 适合产业政策背景，不直接证明公司影响 |

降级规则：

1. 只找到新闻转述，未找到正式清单或公告：只能作为线索；
2. 找到规则但未核对生效日期、过渡期、豁免：只能作条件判断；
3. 只确认“被列入清单”，未确认产品和交易限制范围：不能推导公司影响；
4. 使用律师事务所简报或咨询报告：可作解释辅助，但不能替代原文；
5. 对出口管制类问题，未核对产品分类、最终用户、最终用途、再出口规则：不能给高强度判断。

### 6.3 贸易、关税、海关和跨境暴露

适合支持：

1. 哪些产品依赖特定国家或地区；
2. 某国出口/进口在全球贸易中的份额；
3. 公司或行业是否暴露于关税、禁运、许可证或原产地规则；
4. 替代供应来源是否存在；
5. 冲击是否可能通过贸易链扩散。

| WTO / WTO Tariff Download Facility | 贸易规则、关税、争端、成员通知 | 适合规则和关税口径，不替代企业实际采购 |
| ITC Trade Map | 贸易流、市场份额、贸易伙伴 | 多数高级功能有权限限制 |

| Panjiva / ImportGenius / Altana / Sayari | 企业级贸易和供应链关系 | 通常为授权数据，不能无口径引用 |

|---|---|---|
| 海关总署统计查询平台 | 中国进出口金额、数量、国别、商品、HS code | 必须记录 HS code、数量单位、币种和统计期 |

常见错误：

1. 用国家贸易额直接推公司收入暴露；
2. 用 HS code 大类推细分产品暴露；
3. 只看进口金额，不看数量、价格和替代来源；
4. 不区分直接贸易和转口贸易；
5. 不考虑库存、合同、长期协议和本地化产能。

### 6.4 能源、商品和关键原材料

1. 地缘冲突是否影响能源供给；
2. 原油、天然气、LNG、成品油、煤炭、电力价格是否变化；
3. 关键金属、粮食、化肥、化工品是否受影响；
4. 是否存在战略储备、替代产能、增产空间；
5. 冲击是价格扰动还是实际断供。

首选来源：

|---|---|---|
| EIA | 美国和全球能源统计、库存、产量、油气价格、世界油运 chokepoints | 适合能源事实和结构背景；金融市场价格仍需交易所或数据库 |

| ICE / CME / NYMEX | Brent、WTI、天然气、成品油等期货价格 | 适合市场价格和预期变化 |

| 国家能源局 | 电力、煤炭、油气、能源供需和政策 | 适合中国能源供需事实，不等同企业采购价格 |

降级规则：

1. 新闻称“油价大涨”，但未引用具体价格源：只能作线索；
2. 只看价格，不看库存、产量、战略储备和替代供应：不能判断持续性；
3. 用期货价格直接替代企业采购成本：只能作方向参考；
4. 商品价格没有规格、交割地、币种、税费和周期：不得进入硬证据；
5. 地缘冲击下，必须查“供给受损”和“市场风险溢价”是否可区分。

### 6.5 航道、港口、海运和物流

适合支持：

1. 航道是否受阻；
2. 船舶是否绕行；
3. 运价、保险费率、交期是否上升；
4. 港口吞吐、拥堵、罢工、军事风险是否影响供应链；
5. 物流冲击是否足以传导到库存和交付。

首选来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| EIA World Oil Transit Chokepoints | 霍尔木兹、马六甲、苏伊士、曼德海峡等能源航道重要性 | 适合结构性背景，不是实时航运数据 |
| Drewry World Container Index | 集装箱运价和主要航线价格 | 适合运价趋势，需注意航线覆盖 |
| Freightos Baltic Index | 全球集装箱现货运价、主要航线 | 适合高频运价跟踪 |
| Baltic Exchange | 干散货、油轮、海运市场指数 | 适合航运市场和运价变化 |
| Clarksons Research / Shipping Intelligence Network | 船队、航运、海运贸易、船舶位置和行业数据 | 授权数据，适合专业航运分析 |
| UKMTO / JMIC / IMO / Maritime authorities | 商船安全事件、航行警告、海上风险 | 适合确认海上安全事件 |
| 主要港口、运河和船公司公告 | 港口关闭、拥堵、绕行、服务调整 | 适合确认实际运营变化 |
| Lloyd’s List / TradeWinds / gCaptain / Splash247 | 航运新闻和线索 | 关键事实需回到公告、航运数据或官方通报 |

| 来源 | 用途 | 使用边界 |
|---|---|---|
| 上海航运交易所 | SCFI、CCFI、中国出口集装箱运价、沿海运价指数 | 航线、箱型、币种、指数构成必须记录 |

常见错误：

1. 用“航道紧张”直接推导公司断供；
2. 只看运价，不看库存天数、运输时滞和替代路线；
3. 把绕行导致的时间成本等同于产能损失；
4. 用单一航线运价推全球物流压力；
5. 不区分油轮、LNG、干散货、集装箱和空运。

### 6.6 金融市场、风险偏好和预期变化

适合支持：

1. 市场是否已经定价地缘冲击；
2. 资产价格、波动率、信用利差、汇率、利率是否反应；
3. 冲击是局部行业冲击还是宏观风险偏好冲击；
4. 预期差是否存在；
5. 市场反应是否与基本面证据一致。

首选来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| Wind / Bloomberg / Refinitiv/LSEG / FactSet / Capital IQ / iFinD | 股价、指数、估值、成交、财务、一致预期 | 授权数据，需记录字段、时间和口径 |
| 交易所行情 | 股价、期货、期权、成交量 | 适合价格事实确认 |
| CME / ICE / Cboe | 原油、天然气、利率、汇率、波动率、期权 | 适合市场预期和风险溢价 |
| FRED / US Treasury / central banks | 利率、汇率、信用、宏观金融变量 | 适合宏观金融背景 |
| CDS 数据供应商 / ICE Data / Markit | 主权和公司信用风险 | 通常为授权数据 |
| ETF 和行业指数 | 国防、能源、航运、半导体、黄金、区域市场 | 适合市场叙事和板块反应 |

| 来源 | 用途 | 使用边界 |
|---|---|---|
| Wind / iFinD / Choice | A/H 股、债券、期货、商品、估值、一致预期 | 授权数据，需记录字段、口径和导出时间 |
| 上交所 / 深交所 / 北交所 / 港交所 | 交易行情、停复牌、公告、市场规则 | 官方行情适合事实确认，复权和估值需说明口径 |
| 中证指数 / 国证指数 / 恒生指数公司 | 中国资产指数、行业指数、成分和权重 | 指数调整日和行业分类需记录 |
| 中国外汇交易中心 / 中国货币网 | 人民币汇率、银行间市场、LPR、SHIBOR | 汇率中间价、即期价、离岸价不能混用 |

使用边界：

1. 市场反应只能说明市场定价，不能说明基本面已经发生；
2. 股价上涨不等于公司受益；
3. 一致预期变化要看样本和更新时间；
4. 地缘冲击下应同时观察避险资产、受益资产和受损资产；
5. 金融市场证据不能替代冲击事实和公司暴露证据。

### 6.7 公司暴露、供应链暴露和经营影响

适合支持：

1. 公司收入是否来自冲击地区；
2. 供应商、客户、工厂、港口、物流是否暴露；
3. 成本端是否暴露于能源、材料、运费；
4. 公司是否披露制裁、出口管制、地缘风险；
5. 公司是否有库存、替代供应、长期合同、保险或对冲。

首选来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| SEC EDGAR | 10-K、10-Q、8-K、20-F、S-1、风险因素、区域收入 | 适合美股和海外公司正式披露 |
| HKEXnews | 港股公告、年报、中报、招股书 | 适合港股公司披露 |
| 巨潮资讯、上交所、深交所、北交所 | A 股公告、定期报告、问询回复 | 适合 A 股公司披露 |
| 台湾 MOPS、韩国 DART、日本 EDINET/TDnet | 东亚公司披露 | 适合半导体、电子、汽车、材料、设备公司 |
| 公司 IR、业绩会、投资者日 | 管理层对风险、订单、交期、客户和成本的表述 | 必须区分事实、指引、计划和观点 |
| FactSet GeoRev / Revere / Bloomberg SPLC / Capital IQ supply chain | 地区收入、供应链关系、客户供应商 | 授权来源，需记录模型口径 |
| Panjiva / ImportGenius / Altana / Sayari | 贸易记录、客户供应商、跨境物流关系 | 授权来源，适合供应链暴露验证 |
| 一手调研、内部经营数据、渠道反馈 | 订单、库存、交期、客户需求边际变化 | 必须说明样本、时间、权限和可表达边界 |

禁止用法：

1. 不得把“公司有某地区业务”直接写成“公司受损严重”；
2. 不得用供应链数据库的推断关系替代公司披露；
3. 不得忽略库存和替代供应；
4. 不得把管理层安抚性表述当作反证唯一来源；
5. 不得无量化暴露比例就给高强度财务影响判断。

### 6.8 国家风险、政治风险和专题研究

适合支持：

1. 地缘冲击的背景机制；
2. 冲突升级或缓和的可能路径；
3. 国家风险、政权稳定、政策连续性；
4. 地缘事件对行业和资产的潜在传导；
5. 情景分析和替代解释。

可用来源：

| 来源 | 用途 | 使用边界 |
|---|---|---|
| International Crisis Group | 冲突背景、预警、升级/降级路径 | 分析来源，不替代事实主源 |
| CFR Global Conflict Tracker | 全球冲突跟踪和背景 | 适合背景和事件定位 |
| CSIS / ChinaPower / AMTI | 安全、军事、区域、科技竞争研究 | 适合机制和专题解释 |
| IISS | 军事能力、地区安全、军事平衡 | 适合军事背景和能力分析 |
| Chatham House / Brookings / Carnegie / MERICS / Rhodium Group / PIIE | 国际关系、政策、贸易、制裁、产业政策研究 | 适合解释和框架，不替代硬数据 |
| Economist Intelligence Unit / Control Risks / RANE / Eurasia Group | 国家风险、政治风险、商业风险 | 多为授权或咨询来源，适合风险评分和情景 |
| IMF / World Bank / OECD country reports | 国家宏观、财政、外债、国际收支 | 适合宏观脆弱性背景 |

使用边界：

1. 智库、咨询和研究机构适合解释“为什么”，不适合单独证明“已经发生”；
2. 风险评分需要说明模型和更新时间；
3. 专题研究不能替代贸易、能源、公司、市场等实证证据；
4. 多家智库观点一致不等于事实交叉验证；
5. 必须区分“冲突背景”“升级概率”“资产影响”。

### 6.9 新闻、行业媒体和社媒线索

适合支持：

1. 快速发现事件；
2. 整理时间线；
3. 获取官方表态线索；
4. 识别市场叙事和关注点；
5. 发现需要回溯的原始来源。

可用来源：

| 类型 | 来源 | 使用边界 |
|---|---|---|
| 国际新闻 | Reuters、Bloomberg、AP、AFP、FT、WSJ、Nikkei Asia | 可作高质量线索，但关键事实仍需回到原始来源 |
| 区域新闻 | Al Jazeera、Times of Israel、Kyodo、Yonhap、中央社等 | 适合区域事件跟踪，注意立场和语言口径 |
| 财经新闻 | 财新、第一财经、证券时报、经济观察报等 | 适合中文市场叙事和公司反应 |
| 行业媒体 | 航运、能源、半导体、汽车、化工等行业媒体 | 适合行业线索，需回到专业数据或公司披露 |
| OSINT / 社媒 | 官方账号、航运预警账号、卫星图像账号、专业 OSINT 社群 | 只能作线索，除非可回到原始图像、官方通报或权威数据库 |

禁止用法：

1. 不得用社媒热度替代事实确认；
2. 不得用新闻标题替代政策原文；
3. 不得把多家转载同一消息当作独立验证；
4. 不得用匿名消息源支撑关键判断；
5. 不得把媒体的“可能、据称、预计”写成已发生事实。

### 8. 推荐检索路径

### 8.1 事件冲击路径

```text
事件是否发生
→ 发生时间、地点、参与方
→ 是否影响关键通道、资产、国家或公司
→ 是否已有官方动作或政策落地
→ 是否影响价格、运价、贸易、供应链或金融市场
→ 是否有公司披露或行业变量跟随
→ 是否有反证或缓冲
```

### 8.2 制裁管制路径

```text
官方清单 / 规则原文
→ 被限制主体
→ 被限制产品 / 技术 / 服务 / 资金流
→ 生效时间 / 豁免 / 过渡期 / 许可证
→ 公司客户、供应商、收入、成本、产品暴露
→ 行业替代供给和竞争格局
→ 市场定价和一致预期变化
→ 反证：豁免、许可、替代、低暴露、已预期
```

### 8.3 航道物流路径

```text
安全事件 / 航道限制
→ 船舶绕行 / 港口拥堵 / 航线取消
→ 运价、保险、交期变化
→ 公司库存和交付周期
→ 行业供需和价格传导
→ 财务影响
→ 反证：运价回落、服务恢复、库存充足、替代路线
```

### 8.4 能源商品路径

```text
冲击事件
→ 供给受损还是风险溢价
→ 产量、库存、战略储备、替代供应
→ 现货/期货价格变化
→ 企业成本、需求和利润弹性
→ 货币、通胀、利率和风险偏好
→ 反证：增产、库存释放、需求走弱、价格回落
```

### 9. 取证输出时的最低留痕要求

地缘冲击取证至少记录：

1. 事件发生时间和取证时间；
2. 来源发布时间和更新状态；
3. 主体、地点、产品、航道、国家或公司；
4. 事实、预测、观点、假设、估算的区分；
5. 原始来源和二手来源的区分；
6. 是否存在生效日期、豁免、过渡期、许可证、例外条款；
7. 是否完成反证检索；
8. 对 04 最多能形成的结论。


中国相关地缘问题还需额外记录：

1. 中国官方原文来源：外交部、商务部、海关、海事、交易所、公司公告等具体入口；
2. 中国侧数据口径：HS code、商品规格、币种、指数、交易所、统计期；
3. A/H 股披露口径：公告日期、报告期、公司风险因素、收入/成本/供应链暴露；
4. 全球来源与中国来源是否一致；若不一致，必须说明差异和采用理由。

### 10. 04 最多能形成的结论

| 证据完成度 | 04 可使用强度 |
|---|---|
| 只有新闻线索，未找到原始来源 | 只能作为背景或待验证线索 |
| 有官方事件确认，但无传导数据 | 可确认事件事实，不能推导资产影响 |
| 有政策/制裁/管制原文，但无暴露度 | 可确认规则变化，不能推导公司财务影响 |
| 有贸易/能源/航运/市场数据，但无公司或行业暴露 | 可做宏观或行业条件判断 |
| 有公司暴露、行业变量、市场反应和反证检查 | 可进入方向性判断 |
| 有量价成本拆分、情景测算和改判条件 | 可进入财务影响测算和可执行跟踪 |

### 11. 常见错误

1. 用新闻替代原文；
2. 用地缘叙事替代数据；
3. 用冲突发生替代影响发生；
4. 用油价上涨替代公司成本上升；
5. 用运价上涨替代供应链断裂；
6. 用制裁对象存在替代公司暴露；
7. 用贸易额替代公司营收暴露；
8. 用市场上涨替代基本面验证；
9. 只查支持证据，不查反证；
10. 不区分短期风险溢价和长期供需变化。

### 12. 一句话原则

> 地缘冲击取证不能从“新闻叙事”直接跳到“投资结论”，必须先确认事实，再确认正式动作，再确认传导通道，再确认行业或公司暴露，最后用市场反应和反证校验判断强度。

## 第二部分：专题取证附录

> 本部分只提供地缘场景的取证提示，不是正式判断结构。传导路径与研究问题以 02 场景卡为准，最低证据组合、反证、降级与停止条件以 `ER-TRANS-01` 和 A04/A08 为准；出现冲突时不得以本附录覆盖正式合同。

### 13. 地缘事件状态机

地缘材料必须区分：

```text
rumor / report
→ officially_confirmed_event
→ formal_policy_or_operational_action
→ actual_flow_disruption
→ industry_or_company_outcome
→ recovery / escalation / supersession
```

媒体报道可发现事件；正式制裁、管制、航行警告或公司公告确认动作；贸易量、船舶轨迹、港口、库存、价格和交付确认实际扰动。任何一层未成立，不得直接使用后层结论。

### 14. 暴露测量矩阵

| 暴露类型 | 优先测量 | 常见错误 |
|---|---|---|
| 贸易 | HS code、国别、数量/金额、替代来源 | 用全国贸易额推单家公司 |
| 能源/商品 | 实物来源、合同、库存、运输和对冲 | 用油价变化等同公司成本变化 |
| 航运 | 航线、船型、港口、绕行、保险、交期 | 用运价上涨等同供应中断 |
| 政策/制裁 | 清单对象、产品、最终用途、许可和豁免 | 只看实体名称，不看适用规则 |
| 公司 | 收入、采购、资产、产能、客户和供应商地域 | 用注册地址代替经营暴露 |
| 金融 | 币种、利率、流动性、信用和对冲 | 用短期股价代替基本面损失 |

### 15. 冲击分解与时间窗口

地缘冲击至少分开：

1. **事实冲击**：物理中断或正式规则是否发生；
2. **风险溢价**：市场因不确定性先行定价；
3. **库存缓冲**：短期是否被安全库存、在途和长协吸收；
4. **替代与绕行**：供应、航线、支付、技术或客户是否迁移；
5. **需求反馈**：高价格、延迟和不确定性是否破坏需求；
6. **二阶政策**：储备释放、补贴、反制、监管和货币财政响应；
7. **恢复路径**：恢复速度、积压消化和价格回落。

短期价格跳升不能自动外推长期供需；长期结构变化也不能用事件日行情证明。

### 16. 双侧与多侧取证

- 冲突事实尽量检查涉事各方、国际组织和独立观测，不以单方表述自动定案；
- 政策事实以制定和执行司法辖区的正式文本为主，同时检查受影响方回应；
- 中国资产影响同时检查海外原文、中国主管部门/海关/公司披露和全球行业数据；
- 各方表述不可比时保留其“来源主张”身份，不归一成共同事实；
- 安全敏感、实时性强的信息明确截止时点，过期材料不得继续支撑当前状态。

### 17. 地缘冲击反证包

每个方向性判断至少检查：

```text
event_not_confirmed_or_scope_narrower
formal_action_not_enforced
inventory_or_contract_buffer
alternative_supplier_or_route
license_exemption_or_transition
physical_flow_not_reduced
price_or_lead_time_normalized
company_exposure_lower_than_assumed
market_move_explained_by_other_macro_factors
```

### 18. 停止与更新规则

地缘事件是高频变化对象。单次运行必须固定截止时点；出现升级、停火、修订、豁免、恢复或新制裁时生成新版本，不覆盖旧快照。当前信息只够确认事件而不足以证明实际流量和公司结果时，停止在事实层并输出后续监测指标。
