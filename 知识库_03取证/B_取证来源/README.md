# B_取证来源

> 研究员不要从“我能访问哪些网站”开始，而应从“哪类主体最接近这项事实”开始。推荐顺序通常是：原始责任方/直接数据 → 独立观测 → 专业解释 → 市场预期。来源知名度不能替代任务适配。

## 三步找来源

1. 用 B02 按证据类型找通用来源角色；
2. 半导体专业变量进入 B03，地缘与跨境规则进入 B04；
3. 用对应 OPS 手册固定查询参数、数据口径和失败回退；
4. 用 B01 检查每个来源能证明什么、不能证明什么，并记录更新频率、修订和样本偏差。

本目录帮助 03 在取证前确定：

1. 某类证据优先去哪取；
2. 哪些来源可以作为主源，哪些只能作为交叉验证、替代来源或线索；
3. 行业专用变量和专题冲击变量应进入哪个来源文件；
4. 主源缺失时如何降级；
5. 取到材料后能否进入 04 推理和 05 表达。

## 快速使用

03 执行取证时建议按以下顺序使用：

```text
02 判断单元
→ C 类最低证据组合
→ 必要证据类别
→ A 类取证执行说明
→ B02 通用来源
→ 如涉及行业变量，查 B03_行业专用来源/
→ 如涉及专题冲击，查 B04_专题来源/
→ B01 来源分层与使用边界
→ 执行取证并记录来源、口径、时间、权限、留痕和 04 最多能形成的结论
```

## 设计原则

- 不建设完整来源治理平台。
- 来源画像、来源文档、获取渠道、访问范围、材料类型和内容领域由通用证据域定义，本目录只给取证来源选择建议。
- 不把 MCP/API/网页/文件上传视为来源本身，它们只是获取方式。
- 不把新闻、研报、搜索结果、AI 摘要当作关键事实主源。
- 通用来源、行业来源、专题来源分开维护，避免 B02 被某个行业污染。
- 全球来源和中国来源都要覆盖；涉及中国资产、中国政策、中国贸易和 A/H 股公司时，必须检查中国侧主源。
- 来源清单不是封闭白名单，新来源可以使用，但必须说明来源生产者、口径、时间、权限、可复核路径和使用限制。
- 每个必需、交叉和反证类别都要建立来源计划、独立来源组和失败回退顺序。
- 来源层级不等于通用权威分；按当前主张的直接性、口径、方法和权限选择来源。
