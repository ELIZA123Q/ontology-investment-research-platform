# 商业模式与收入驱动框架

## 研究员先看什么

商业模式研究不是贴“订阅、平台、制造、项目制”标签，也不是填完商业模式画布，而是先判断当前分歧属于哪一种：

1. **客户价值与支付意愿**：谁在为什么任务付费，价值是否足以使客户选择、续约或增加采购；
2. **收入引擎与收入质量**：客户行为如何转化为数量、价格、费率、结构与留存，增长是否内生；
3. **单位经济与可扩展性**：每新增一个客户、订单、项目或使用单位，能否形成可持续增量利润；
4. **资本、现金与优势持续性**：增长需要多少营运资本与再投资，利润能否转为现金与增量回报，优势能否在竞争下维持。

单次任务应选择一条主路线，最多保留一条主要竞争路线。客户有需求不等于愿意付费；收入增长不等于模式增强；高毛利不等于单位经济健康；高留存不等于转换成本或网络效应。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断某一明确业务单元在给定客户、产品和业务时间内：

- 谁使用、谁决策、谁付费，客户为何购买、续约或接受更高价格；
- 收入应拆成什么最小业务单元，数量、价格、结构、留存与并购口径如何作用；
- 收入增长是来自真实客户价值，还是折扣、压货、并购、会计确认或低基数；
- 每新增一个经济单元的增量收入、增量成本与资本占用如何变化，规模是改善还是恶化经济性；
- 增长需要多少营运资本与再投资，利润能否转为现金与增量资本回报；
- 定价权、留存、转换成本或网络效应是否得到客户行为与经济结果验证，何种变化会使其衰减。

本框架不直接判断行业供需与价格周期、短中期业绩预测、财务报告真实性、完整资本配置评价，以及预期差、估值或交易结论。长期模式由本框架回答；短中期兑现交 `BF-EE-01` / `BF-FS-01`；财务基线交 `BF-FQ-01`；资本配置交 `BF-CA-01`。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 使用者 / 采购者 / 付款者 / 决策者 | 主体不同会改变价值证据、预算与切换条件 |
| 收入模式标签 vs. 收入驱动 | “订阅/平台”不能代替数量、价格、留存与结构桥 |
| 合同收入 / 经常性收入 vs. 可预测现金 | 取消权、账期、服务义务与资本投入会改变现金质量 |
| 价格上涨 vs. 实现价改善 | 结构、套餐与客户迁移可能不等于同产品真实提价 |
| 毛利率 vs. 单位经济 | 毛利常未计入获客、部署、售后、失败与资本占用 |
| 规模扩大 vs. 规模经济 | 只有单位成本、获客效率或资产利用随规模改善才构成规模经济 |
| 资产轻 vs. 资本轻 | 不持有固定资产仍可能占用应收、补贴、研发与承诺采购 |
| 历史高回报 vs. 增量回报 | 存量优势抬高历史 ROIC，不证明新增增长仍创造价值 |

### 1.3 禁止跳步

- 不能从公司叙事直接推出客户愿意付费；
- 不能从使用量增长直接推出收入与利润同比例增长；
- 不能从合同或在手订单直接推出收入确认与现金流；
- 不能从收入增长直接推出商业模式增强；
- 不能把并购、汇率、低基数、会计重分类与渠道压货当作内生驱动；
- 不能从“订阅/平台/软件”标签直接推出高质量或轻资产；
- 不能从高留存直接推出转换成本、网络效应或护城河；
- 不能从高毛利或单一成功样本直接推出整体单位经济健康；
- 不能从商业模式判断直接生成季度业绩、估值或交易建议。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 无法识别客户任务、付款主体与预算来源 | 正式客户价值与 `revenue_model` |
| 收入无法拆到可解释业务单元，或不同模式混科目且无法分拆 | `revenue_model` 与收入驱动归因 |
| 增长主要来自并购、汇率、会计变更或一次性项目且无法还原 | 内生增长与模式增强判断 |
| 缺少客户/产品/订单层面的收入与成本对应 | `unit_economics` |
| 单位经济口径未含关键获客、履约、服务、失败或资本成本 | 健康单位经济与规模经济判断 |
| 应收、库存、Capex、研发与融资需求无法识别 | `business_model_quality` |
| 所谓优势无客户行为与经济结果支持 | 稳定竞争优势判断 |
| 多商业模式关键业务无法拆分 | 公司整体模式质量结论 |

高级输出停止时，可保留客户结构、收费方式与收入拆分线索，但不得用“模式总体良好”覆盖关键缺口。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 客户价值与支付意愿** | 客户为何选择并持续使用，价值是否足以付费 | 新产品/新公司；高使用低付费；流失、提价或替代争议 | 客户任务、采购原因、使用深度、续约/复购、提价接受、替代切换 | 真实价值 vs. 补贴、短缺、关系销售、合规强制或捆绑 | 无法识别付款主体与真实选择行为时，止于候选价值主张 |
| **B 收入引擎与收入质量** | 收入由哪些驱动，增长是否内生可持续 | 高增长、结构迁移、并购或合同复杂 | 数量、实现价、折扣、结构、续约复购、订单转化、回款 | 内生增长 vs. 并购、低价换量、压货、提前确认、一次性大单 | 无法与运营驱动和财务口径对账时，不形成 `revenue_model` |
| **C 单位经济与可扩展性** | 新增单元是否创造增量利润，规模改善还是恶化 | 高增长亏损；毛利高费用高；扩张争议 | 分群贡献利润、获客/部署/服务成本、留存扩张、边际毛利、失败率 | 健康单位经济 vs. 成熟样本偏差、成本外置、服务义务低估 | 无法定义经济单元或匹配完整增量成本时，不形成 `unit_economics` |
| **D 资本、现金与优势持续性** | 增长资本与现金约束，优势会否被侵蚀 | 利润与现金背离；高融资；护城河争议 | 营运资本、Capex、现金转换、增量 ROIC、提价留存、进入替代 | 价值创造 vs. 资本吞噬、账期换增长、历史资产红利、暂时保护 | 缺少资本现金或优势反证时，不形成 `business_model_quality` |

### 路线选择要求

02 调用本框架时必须说明：本次目标输出；主路线与竞争路线；收入单元与（如需要）经济单元；哪 2—3 个关键判断与 3—5 个决定性变量；哪些模块不启用；哪些问题转交行业结构、业绩弹性、财务质量、资本配置或预测框架。四条路线全部展开，通常说明目标未收敛。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| BM-C1 研究对象与目标输出 | 核心 | 每次调用 | 不得裁剪 | 本次形成收入模型、单位经济还是模式质量 |
| BM-C2 业务单元与客户角色 | 核心 | 每次调用 | 01 已完整定义时可简写 | 谁使用/决策/付费，哪些业务必须拆开 |
| BM-C3 收费与收入单元 | 核心 | 形成 `revenue_model` | 只做客户价值候选且明确不判断收入 | 收入如何由客户行为与合同生成 |
| BM-R1 客户任务与价值验证 | 条件 | 价值、采用、留存、提价或替代是核心分歧 | 已有可靠客户证据且本次只做收入拆解 | 价值是否真实、持续且足以付费 |
| BM-R2 数量价格结构留存桥 | 条件 | 解释收入变化或形成 `revenue_model` | 收入桥已冻结且任务只评单位经济 | 报告收入变化来自哪些经营/非经营因素 |
| BM-R3 合同订单与收入质量 | 条件 | 长协、订单、项目制、渠道或集中度重要 | 即时交易且无重大合同风险 | 订单如何转收入，取消/折扣/账期如何影响质量 |
| BM-R4 获客履约与单位经济 | 条件 | 形成 `unit_economics`；高增长盈利不清 | 任务止于收入模型 | 增量成本、分群经济性与规模效应 |
| BM-R5 营运资本再投资与优势 | 条件 | 形成 `business_model_quality` | 本次只解释收入机制 | 资本现金约束、增量回报与优势衰减 |
| BM-E1 业绩/财务/资本/估值交接 | 扩展 | 需要预测、财务真实性、资本配置或估值 | 本次只判断模式机制 | 分别交 `BF-EE-01`/`BF-FS-01`、`BF-FQ-01`、`BF-CA-01`、`BF-VA-01` |

单次任务必须记录启用与排除模块。模块存在不代表自动生成对应取证任务。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 客户价值 | 前提与路线区分 | 需求认可不等于支付意愿 |
| 数量与价格 | 方向与归因 | 易受结构、折扣、补贴与口径影响 |
| 留存与扩张 | 质量与持续性 | 合同未到期可伪装成黏性 |
| 单位经济 | 增量利润与可扩展性 | 成功样本偏差、成本外置 |
| 资本与现金 | 模式质量与反证 | 轻资产表象可能掩盖占用 |
| 增量回报与优势 | 长期质量与衰减 | 历史 ROIC 不能代理增量回报 |

02 通常只保留 3—5 个有判别力的变量。收入单元应贴近客户购买与公司交付决策，不机械套财务科目；重大收入变化须区分数量、真实价格、结构、留存与并购/汇率/口径影响。

### 4.2 代理变量要求

直接变量无法获得时可用代理，但须说明业务机制、覆盖范围、失效条件、强度降级与交叉验证。管理层叙事、标价 ARPU、GMV 与机构预测默认不是付费价值或单位经济的无条件代理。

### 4.3 关键时钟

只选择本次相关时钟，不得机械拼接：

`客户认知 → 采购/合同 → 获客 → 使用采用 → 续约复购 → 交付服务 → 收入确认 → 回款 → 再投资 → 优势衰减`

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 客户快速增长 | 产品价值增强 | 补贴、低价、渠道扩张或强制采购 | 使用深度、付费率、续约与回款 | 降级为低质量数量增长 |
| ARPU/ASP 上升 | 定价权增强 | 结构、套餐或客户层级迁移 | 同产品同客户实现价与折扣 | 不确认真实提价 |
| 高续约率 | 黏性强 | 合同未到期、替代暂缺 | 使用趋势、提价接受、迁移窗口 | 不升级为转换成本 |
| 收入高增长 | 内生引擎增强 | 并购、压货、提前确认、一次性大单 | 运营驱动桥、订单转化、应收退货 | 不评价模式增强 |
| 毛利率提高 | 价值或规模经济 | 成本外置、结构、资本化 | 获客服务成本、现金与分群 | 回到完整单位经济 |
| 利润改善但现金恶化 | 模式现金质量增强 | 账期、库存、Capex 或融资换增长 | 营运资本、融资与增量 ROIC | 切换资本吞噬路径 |
| 份额上升 | 优势增强 | 低价、并购、短缺配额 | 价格、单位经济与现金 | 不确认模式质量提升 |

### 降级规则

- 无法区分真实价值与补贴/短缺：止于条件式价值主张；
- 收入无法与运营驱动对账：降级为候选收入结构；
- 单位经济样本或成本不完整：只保留局部线索；
- 缺少资本现金或优势反证：止于收入模型或单位经济，不形成模式质量；
- 主解释与竞争解释暂不可区分：03 只优先收集区分信号。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 客户价值须有采用、使用、续约、复购或支付证据，不得仅靠管理层叙事；
- 收入驱动须与至少一个运营指标和财务口径交叉验证；
- 单位经济须包含业务相关的完整增量成本与资本占用，并核对公司总账；
- 模式质量须连接利润、现金与增量回报，并保留优势衰减条件；
- 预测、指引与机构观点不得冒充客户行为或单位经济观测。

具体来源与验收由methods/03_取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的公司、产品、客户、合同、状态变量、观测、事件、假设、信号与情景。“收入单元”“单位经济”“优势衰减”等属框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 订阅、制造销售、项目制、平台等不同收入机制 |
| 重点检查 | 是否只选一条主路线；是否区分收入单元与经济单元；是否越界到预测/估值 |
| 经验沉淀 | 行业特有收入单元优先进入行业框架或场景卡；跨任务重复且有失效边界的机制才写回稳定内核 |

框架更新不以增加篇幅为目标。

## 8. 验收检查

- [ ] 明确本次目标是收入模型、单位经济还是商业模式质量；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 使用者、采购者、付款者与决策者已区分；
- [ ] 收入增长已区分经营驱动与并购、汇率、口径和一次性因素；
- [ ] 订单、合同、交付、确认与回款未被混为一谈；
- [ ] 毛利、单位经济、公司利润与现金未被混为一谈；
- [ ] 规模扩大与规模经济已区分；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 未形成模式质量时，没有直接推导估值或交易建议。
