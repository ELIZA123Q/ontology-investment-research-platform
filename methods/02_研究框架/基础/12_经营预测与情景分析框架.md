# 经营预测与情景分析框架

## 研究员先看什么

经营预测不是把历史增长率延长，也不是先填满三张表再寻找解释。真正需要回答的是四个彼此约束的问题：

1. **基线门**：历史数字和业务口径是否足以作为预测起点，哪些异常、周期、并购和会计因素必须先还原；
2. **驱动门**：未来结果真正由哪 2—3 个业务变量决定，这些变量怎样经过产能、交付、确认、成本和现金形成财务结果；
3. **闭合门**：数量、价格、结构、成本、费用、营运资本、资本开支和融资是否在同一时间逻辑下相互一致；
4. **更新门**：什么现实信号会使基准路径继续、切换、降级或失效，历史误差将怎样反向校准模型。

单次任务不应默认展开完整收入、成本、费用、三张表和四套情景。应先明确本次要形成的是条件式经营路径、关键结果区间，还是较高精度的点预测；再选择一条主路线，最多保留一条主要竞争路线。

历史增长率、公司指引和一致预期，均不能单独构成预测基线。

## 1. 判断权、边界与稳定内核

### 1.1 本框架能判断什么

本框架用于判断：

- 现有历史业务和财务数据能否形成可解释的预测基线；
- 哪些业务驱动真正决定未来收入、利润和现金；
- 驱动如何经过数量、价格、结构、产能、交付、确认、成本和费用进入财务结果；
- 基准路径为何在当前证据下最一致；哪些不确定性需要条件情景，哪些只需局部敏感性；
- 收入、利润、营运资本、资本开支、融资和现金是否在时间上闭合；
- 预测可停留在方向、区间、条件路径，还是能形成较高精度点估计。

本框架不直接完成：历史报表可信度裁决、行业机制现实判断、长期商业模式终裁、事前预期差、完整风险压力测试，以及估值区间或交易建议。

历史基线由 BF-FQ-01 提供；行业机制由供需、价格、政策等框架提供；单位经济可由 BF-BM-01 提供；行业到公司兑现由 BF-EE-01 提供；资本与融资约束由 BF-CA-01 提供；宏观假设由 BF-MF-01 提供；风险压力由 BF-RS-01 提供；预期与估值分别由 BF-EG-01、BF-VA-01 承接。

### 1.2 必须区分的稳定概念

| 必须区分 | 不能混为一谈的原因 |
|---|---|
| 历史实际 vs. 正常化基线 | 一次性项目、周期高低点、并购和口径变化可能使历史不可直接外推 |
| 历史基准率 vs. 未来业务驱动 | 历史均值只能提供边界，不能替代订单、产能、价格和执行判断 |
| 管理层指引 / 一致预期 vs. 研究员预测 | 指引与一致预期是沟通或市场假设，不等于经营事实基线 |
| 订单/合同 vs. 可确认收入 | 取消、交付、验收、价格调整和确认时点会形成差异 |
| 名义产能 vs. 有效产出 | 稼动、良率、认证、材料和瓶颈决定可交付量 |
| 报价 vs. 实现价 | 合同重置、折扣、产品与客户结构会改变公司实际价格 |
| 收入增长 vs. 利润 / 现金增长 | 成本、费用、营运资本、Capex 和融资会改变兑现 |
| 基准路径 vs. 中间情景 | 基准是证据下最一致路径，不是上下行数值的机械中点 |
| 情景分析 vs. 敏感性分析 | 情景要求相关假设内部一致；敏感性只观察少数参数 |
| 点估计 vs. 预测质量 | 精确数字可能掩盖数据缺失；质量取决于基线、驱动和闭合 |

### 1.3 禁止跳步

- 不能从历史增长率、指引或一致预期直接采用为基准预测；
- 不能从订单、合同、送样或名义产能直接推出收入；
- 不能从行业价格直接推出公司实现价，也不能从收入直接推出利润和现金同比例增长；
- 不能只预测利润表而不检查对判断有影响的营运资本、Capex 和融资；
- 不能把所有变量同向上下调来构造情景，或用单一敏感性表替代内部一致情景；
- 不能在基线不可信或关键驱动不可观察时输出精确点预测；
- 不能把季节性、低基数、并购、汇率和会计口径变化写成内生经营趋势；
- 不能在没有事前预期基线时判断“高于/低于预期”，也不能把预测范围直接解释成投资回报。

### 1.4 硬停止条件

| 停止情形 | 禁止形成的输出 |
|---|---|
| 对象、地域、产品、期间和确认口径未定义，或历史口径无法对齐 | 任何正式经营预测 / `precise_point_estimate` |
| 财务报表可信度不足，关键正常化无法完成 | 精确经营预测 |
| 关键收入驱动无法识别或不可观察且无可靠代理 | `conditional_forecast` 方向归因 / 基于该驱动的定量预测 |
| 订单、产能、交付或确认之间无法建立时间桥 | 收入点预测和季度路径 |
| 单位成本、固定成本或利用率关系无法建立 | 利润率与利润弹性预测 |
| 重大营运资本、Capex 或融资需求无法识别，或三表无法解释不一致 | 自由现金流、高阶 `scenario_range` 和点预测 |
| 情景没有进入/退出条件或可观察切换信号；或只是全参数同向调整 | 正式 `scenario_range` |

高级输出停止时，已确认的低层事实与条件路径仍可保留。

## 2. 常见研究路线

以下路线是选择菜单，不是固定流程。单次 02 原则上选择一条主路线，最多保留一条竞争路线。

| 路线 | 核心分歧 | 何时启动 | 最有判别力的候选信号 | 主要竞争解释 | 停止或输出边界 |
|---|---|---|---|---|---|
| **A 基线可信度与可预测性** | 历史数据能否代表未来起点，对象是否有足够可见性 | 新覆盖；并购/口径变化；周期高低点；财务质量争议 | 正常化历史、分部桥、合同可见性、历史指引与预测误差 | 真实趋势 vs. 低基数、并购、汇率、一次性与会计影响 | 基线无法正常化时，只输出条件框架和缺口 |
| **B 关键业务驱动与经营路径** | 未来结果由哪少数驱动决定，如何进入收入利润 | 需要收入/利润/经营趋势预测；行业变化映射到公司 | 终端、订单、销量、份额、产能、利用率、实现价、结构、单位成本 | 真实增长 vs. 补库、低价换量、并表、压货或确认提前 | 驱动无法解释历史或不能观察更新时，不做高精度预测 |
| **C 财务闭合与时间错位** | 经营路径能否在利润、营运资本、Capex、融资和现金中闭合 | 收入与现金分歧；重资产扩张；确认周期长；债务重要 | 收入确认、应收、库存、合同负债、折旧、Capex、债务期限、现金转换 | 真实增长 vs. 提前确认、积压、延迟付款、资本化或融资填补 | 重大项目无法闭合时，只输出局部经营结果 |
| **D 情景切换、误差复盘与模型更新** | 哪些不确定性改变整条路径，什么信号触发切换 | 不确定性高；多条竞争路径；历史预测频繁偏差 | 里程碑、订单转换、指引变化、价格重置、回款、融资余量、误差桥 | 模型错误 vs. 时点、口径、外部冲击或执行延迟 | 无法定义情景差异或切换信号时，只列不确定性 |

### 路线选择要求

02 调用本框架时必须说明：本次最终需要条件式判断、结果区间还是点估计；主路线与竞争路线；预测对象与期限；哪 2—3 个关键判断决定总体预测；哪 3—5 个变量区分主路径与竞争解释；哪些财务模块必须闭合。四条路线全部展开，通常说明问题尚未收敛。

## 3. 模块菜单

模块是可裁剪能力，不是必须依次执行的工作流。

| 模块 | 类型 | 启动条件 | 裁剪条件 | 解决什么问题 |
|---|---|---|---|---|
| FS-M1 历史基线与口径 | 核心 | 每次调用 | BF-FQ-01 已提供可靠基线时可只引用 | 正常化起点与主要异常 |
| FS-M2 关键驱动模型 | 核心 | 需要条件式预测 | 只能识别结果、不能识别驱动时停止定量归因 | 2—3 个主驱动、约束和结果桥 |
| FS-M3 收入与确认桥 | 条件 | 输出涉及收入或增长 | 任务只预测非收入结果且收入不改变判断 | 数量、价格、结构、交付与确认 |
| FS-M4 成本费用与利润桥 | 条件 | 输出涉及利润或经营杠杆 | 任务止于收入方向 | 单位成本、固定成本、费用与利润弹性 |
| FS-M5 营运资本与现金 | 条件 | 涉及现金、FCF、流动性或收入质量 | 短期收入任务且现金不影响输出 | 应收、库存、应付、预收与现金桥 |
| FS-M6 Capex 折旧与融资 | 条件 | 重资产、扩产、债务或估值任务 | 轻资产且资本不改变结果 | Capex、产能时点、折旧、债务与资金缺口 |
| FS-M7 情景与切换规则 | 条件 | 多条可区分路径或关键不确定性 | 单一路径且不确定性不改变输出时可只做敏感性 | 情景差异、进入/退出与监测信号 |
| FS-M8 误差复盘与更新 | 条件 | 已有历史预测或需持续跟踪 | 首次覆盖时建立未来复盘计划 | 误差桥与更新规则 |
| FS-M9 完整三表 / 预期估值对接 | 扩展 | 现金融资估值要求明确；或需比较预期 | 仅需业务方向时默认不启用；预期差与估值交 BF-EG-01、BF-VA-01 | 内部一致三表或下游输入 |

单次任务必须记录启用与排除模块。

## 4. 候选变量、信号与时钟

### 4.1 候选变量不是默认必选项

| 变量族 | 在单次任务中可能承担的作用 | 常见限制 |
|---|---|---|
| 基线 | 预测起点与历史可比性 | 口径、并购、周期高低点可能使历史不可外推 |
| 需求与数量 | 方向或强度驱动 | 订单可能被补库、抢单和取消放大 |
| 供给与执行约束 | 决定需求能否转化为交付 | 名义产能不能直接代理有效产出 |
| 价格与结构 | 收入与毛利差异 | 报价不能替代实现价 |
| 成本与利润 | 利润桥与经营杠杆 | 一次性冲回、资本化会扭曲 |
| 现金与资本 | 现金与资金闭合 | 增长占用与收入质量恶化需区分 |
| 情景切换与校准 | 路径继续、切换、失效；识别模型问题 | 不得因短期噪声频繁改写长期假设 |

基础框架不设置跨行业固定权重。02 应选择本次真正有判别力的变量，通常不超过 3—5 个。

### 4.2 代理变量要求

直接变量无法获得时可以使用代理，但必须说明业务机制、覆盖范围、失效条件、强度降级，以及是否有第二类独立证据交叉验证。指引、一致预期和机构预测默认不是经营事实的无条件代理。

### 4.3 关键时钟

只选择本次相关的时钟，不得将不同期间信号机械拼接：

`订单/合同 → 交付与验收 → 收入确认 → 实现价与成本重置 → 营运资本与回款 → 产能爬坡/认证 → Capex 与债务 → 情景切换与误差复盘`

预测应按近期可见、中期执行、远期条件分段；远期信息不足时降低精度，而不是延长短期参数。

## 5. 竞争解释、反证与降级

| 表面现象 | 解释 A | 解释 B | 区分信号 | 命中解释 B 后的动作 |
|---|---|---|---|---|
| 订单快速增长 | 终端需求改善 | 补库、抢单、压货 | 终端消耗、库存、取消率、交付和回款 | 不再按持续需求外推 |
| 收入加速 | 数量和价格改善 | 并购、汇率、低基数、提前确认 | 同口径内生收入、现金和合同负债 | 切换为口径贡献路径 |
| ASP 上升 | 同产品实现价上涨 | 结构升级、汇率、会计分类 | 同规格价格、合同重置、结构桥 | 停止实现价上修 |
| 毛利率提升 | 价格、利用率或成本改善 | 一次性冲回、资本化、结构、补贴 | 单位成本、固定成本和现金 | 不把毛利写成单位经济改善 |
| 经营现金流下降 | 增长占用营运资本 | 收入质量恶化、积压、回款困难 | 应收、库存、订单质量 | 切换到财务质量/资金压力 |
| Capex 增加 | 高回报扩张 | 周期高点扩产、被动替换 | 需求、利用率、增量回报 | 不自动写入增长情景 |
| 指引上调 / 预测持续偏差 | 经营路径改善 / 业务超预期 | 保守基线、一次性贡献 / 时点错位或模型错误 | 原指引口径、误差桥、驱动持续性 | 改模型结构或降级可预测性 |

### 降级规则

- 基线不可用：只列缺口和条件，不形成定量预测；
- 驱动可解释但数据不足：只保留条件式方向判断；
- 重大财务项目无法闭合：只输出局部经营结果；
- 情景差异或切换信号不清：只列不确定性，不形成正式情景范围；
- 点预测任一关键条件不足：降级为区间或条件式预测；
- 主解释与竞争解释暂不可区分：03 只优先收集区分信号。

## 6. 可写到哪一层、组合与任务裁剪

### 6.1 可写到哪一层（系统对照）

| 输出 | 最低条件 | 条件失败后的处理 |
|---|---|---|
| `BF-FS-01.conditional_forecast` | 对象/单位/时间清楚；基线至少局部可用；至少一个主驱动与结果路径可解释；明确约束、竞争解释和失效条件 | 只保留驱动清单或方向性条件判断 |
| `BF-FS-01.scenario_range` | 已有可用条件预测；情景有真实机制差异与进入/退出条件；相关变量内部一致；对判断有影响的财务项目已闭合 | 只做局部敏感性，不标记正式情景范围 |
| `BF-FS-01.precise_point_estimate` | 基线可信；驱动可观察且近端有锚点；转化率/实现价/成本/确认有证据；重大三表项目闭合；主要竞争解释已削弱；误差已复盘 | 降级为区间或条件式预测 |

更高一层写不出来时，已经成立的更弱结论仍可保留。需要核对进入条件与可写到哪一层时，见根目录依赖说明。

### 6.2 组合与交接

- 报表可信度：先接 BF-FQ-01；
- 商业模式与单位经济：接 BF-BM-01；
- 行业到公司兑现：接 BF-EE-01；
- 行业机制输入：接 BF-SD-01 / BF-PC-01 / BF-PI-01 等；
- 资本与融资约束：接 BF-CA-01；宏观与风险：接 BF-MF-01、BF-RS-01；
- 预期差与估值：交给 BF-EG-01、BF-VA-01。

### 6.3 单次 02 必须形成的裁剪结果

```yaml

  competing_route: <零或一条>
  target_output_gates: [conditional_forecast | scenario_range | precise_point_estimate]
  critical_judgment_units: [<2—3 个>]
  decisive_variable_refs: [<通常 3—5 个>]
  activated_modules: []
  excluded_modules:
    - module_ref: <模块>
```

出现以下情况应返工：四条路线全部展开；所有候选变量都被列为关键变量；没说明主路线为什么优先；竞争解释不会产生不同预测；为填满三表而隐藏不确定性。

## 7. 证据、本体与维护边界

### 7.1 最低证据纪律

- 基线至少说明正常化项目与口径边界；
- 驱动至少能解释历史主要结果，并能被现实证据更新；
- 收入路径至少连接数量/价格/结构与确认或交付中的一层；
- 利润与现金路径至少检查对本次判断有影响的成本、营运资本或 Capex；
- 情景必须有可观察切换信号；预测、指引和机构观点不得冒充现实观测。

具体来源与验收由methods/03_取证管理。

### 7.2 本体边界

正式任务优先引用一级本体已定义的公司、产品、状态变量、观测、事件、假设、信号和情景。“预测基线”“驱动桥”“情景切换”等属于框架概念，不因写入本文件自动成为正式本体定义。

### 7.3 实践验证与维护

| 项目 | 当前要求 |
|---|---|
| 验证状态 | 结构性重写后，需通过真实任务或历史回放验证 |
| 优先样本 | 周期盈利预测、新产品放量、重资产扩张、高增长现金预测 |
| 重点检查 | 是否只选一条主路线；是否从指引跳到基准；是否用敏感性冒充情景；是否越界到估值 |
| 经验沉淀 | 行业特殊驱动优先进入行业框架或场景卡；跨任务重复且有失效边界的机制才写回稳定内核 |

## 8. 验收检查

- [ ] 明确本次要形成的是条件式预测、情景范围还是点估计；
- [ ] 只选择一条主路线，最多保留一条主要竞争路线；
- [ ] 历史实际与正常化基线、指引与研究员预测已经区分；
- [ ] 决定性变量由单次任务选择，没有复制全部候选变量；
- [ ] 订单/产能到收入、收入到利润现金的关键桥已按本次输出需要展开；
- [ ] 主解释和竞争解释会产生不同的可观察预测；
- [ ] 至少有一个可执行停止条件，并说明禁止哪一级输出；
- [ ] 情景有进入/退出条件，不是全参数同向上下调整；
- [ ] 没有从预测直接推出预期差、估值或交易结论；
- [ ] 特殊行业机制优先放入行业框架或场景卡，而不是写成跨行业固定公式。
