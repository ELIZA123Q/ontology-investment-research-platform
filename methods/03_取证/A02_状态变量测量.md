# A02 状态测量取证

状态测量取证：把「当前是什么水平」测清楚，并记下比较基准。

## 1. 什么时候使用

用于取得价格、需求、供给、库存、订单、成本、财务或经营变量的**当前状态测量材料**。若问题是趋势／阶段，主方法转 A03，但 A03 依赖本方法的合格测量。只能取得间接指标时同时调用 A09。

## 2. 取证逻辑

先固定测量链，再取数值：

```text
研究概念 → 可观察指标 → 数据生产过程 → 样本与覆盖
→ 单位／分母 → 当前值与基准 → 误差边界
```

取数前先核对并写清：构念、直接指标、对象与粒度、单位与分母、时间语义、聚合／转换、修订策略和缺失处理。原始值与转换值同时保留；缺失、未披露、不适用和真实零值不能互换。

行业方向通常需要一个直接测量，加一个来源链独立或生成机制互补的验证。派生指标必须保留原始输入和公式。

做轻量反向检查即可：反向指标、样本变化、口径冲突。不必因此单独做完整反向检索。

## 3. 最少必须取得什么

| 这份材料起什么作用 | 最低要求 |
|---|---|
| 主证据 | 至少一个可追溯的直接指标或原始字段 |
| 比较基准 | 前期、历史区间、同业、目标或正常区间之一 |
| 反证与限制 | 反向指标、样本变化、口径冲突或范围错配材料 |
| 独立交叉验证 | 方向性使用时，至少一个不同来源链或不同生成机制的互补测量 |

取数前先核对：对象、业务时间、定义、单位、版本匹配。

## 4. 优先来源

| 变量 | 首选 | 交叉来源 |
|---|---|---|
| 公司财务／经营 | 法定披露、内部实际值、可回源数据库字段 | 公司 IR、客户或供应商披露 |
| 市场价格 | 交易所、授权行情、指数供应商 | 公司实现价、专业价格源 |
| 行业供需／库存 | 行业数据库、协会统计、专业交易平台 | 代表性公司、上下游或一手调研 |
| 订单／交期／良率 | 一手经营记录、公司披露、客户／供应链反馈 | 同业披露、行业数据 |

## 5. 完备度怎样受限

- 指标未测到目标构念（如名义产能冒充有效供给）：不可用。
- 无业务时间、单位、分母或样本说明：观察或不可用。
- 跨期样本／规格／会计口径改变：标记序列断点，不强行并序列。
- 单点数据：只能作为当前观测材料，不能当作趋势材料。
- 交叉材料来自同一原始数据链：不算独立验证。
- 只有代理指标：按 A09，完备度最高观察或受限。

## 6. 交给 04 什么

```text
目标变量与构念
当前观测材料：数值／状态 + 业务时间 + 单位
比较基准材料
测量范围、误差与交叉／反向材料
证据完备度：充分／受限／观察／不可用
待裁决问题：当前状态应如何表述及其边界（由 04 裁决）
```
