# B00 来源选择与使用边界

来源选择的目标不是找到「最权威的网站」，而是找到最适合证明当前主张、且能够复核的材料。

## 六条原则

1. 优先找最接近事实生产者的来源：规则找发布机构，公司事实找法定披露，行业状态找专业测量，市场预期找带时间戳的共识和行情。
2. 原始事实、独立观测、专业解释、市场预期和发现线索分开；一种来源不能自动替代另一种角色。
3. 新闻、研报、搜索和 AI 可以帮助发现原文、理解观点或寻找竞争解释，不能替代关键原始来源。
4. 来源适用性高于简单层级。公司公告适合确认公司事实，行业数据库更适合测量行业价格；两者不存在跨任务的绝对高低。
5. 多篇材料若来自同一原始数据、同一公司披露或同一转述链，只算一个来源组。
6. 涉及中国政策、公司、贸易或产业时查中国主源；涉及海外规则对中国资产的影响时，同时查海外原文与中国主管部门、公司或交易所披露。

## 来源角色

| 来源角色 | 最适合证明 | 不能单独推出 |
|---|---|---|
| 责任主体原文 | 政策、公告、财务、交易和项目状态 | 实际产业影响、行业趋势、市场预期 |
| 专业直接测量 | 价格、出货、库存、产能、份额、行情 | 未披露公司事实、因果和投资结论 |
| 一手经营／调研 | 订单、交期、渠道、客户和边际变化 | 无样本说明的总体结论、无权限材料的公开事实 |
| 专业解释／研究 | 机制假设、来源发现、竞争解释和观点分歧 | 关键硬事实的唯一证据 |
| 新闻／公开叙事 | 事件线索、时间线、关注点和叙事热度 | 政策、财务、行业状态或趋势的唯一证据 |
| 搜索／AI 摘要 | 关键词、入口和材料整理 | 任何正式证据 |

数据库、网页、MCP 和文件检索是取得通道，不是来源，也不决定证据等级。公司 IR、监管/政府官网等公开原文在完整 provenance（生产者、正文 hash、逐字引用、权限）下可以是一手来源。正式使用时应保留真实生产者、原文或字段定位、业务时间、查询参数、版本和权限。

## 冲突处理

发生冲突时按顺序比较：

```text
对象与产品 → 业务时间 → 指标定义与单位 → 样本与方法
→ 版本与修订 → 是否同源 → 哪项更直接匹配当前主张
```

不同范围的数据分别保留，不强行合并；重大冲突不能消解时保留双方并**降低完备度**，冲突对命题的含义交给 04，不能按来源数量投票或对冲突数值取平均。

## 主源拿不到时怎样降级

| 情况 | 处理 | 对完备度的影响 |
|---|---|---|
| 同一生产者、同一内容，原通道故障 | 换官网／数据库等取得通道 | 通常不改变来源身份，仍检查版本和完整性 |
| 原材料不可得，改用同一生产者的汇总或后续披露 | 记录字段和时间差异 | 可能由充分降为受限 |
| 改用另一独立生产者的相近测量 | 重新检查对象、样本、方法和单位 | 按实际可比性决定受限或观察 |
| 使用经校准代理 | 调用 A09，记录有效／失效条件 | 最高通常为受限；无交叉验证时为观察 |
| 只剩新闻、研报、搜索或 AI | 保留为线索 | 观察或不可用 |

找不到、权限受限、未披露、不适用、结构上不可观测和真实零值必须分开记录。权限受限时不绕过授权；替代来源改变测量对象时，不得静默沿用原结论。

## OPS 准入、复核与从手册拿掉

长期查询手册（OPS）不是来源百科全书。只有同时满足以下条件的来源，才写入长期手册：

1. 高频重复使用；
2. 查询过程不直观；
3. 存在明显口径陷阱；
4. 主源失败时需要固定回退路线；
5. 对完备度有稳定影响。

单次使用的网站、某家公司临时页面、一次性数据入口，留在本次证据归档，不写入长期手册。手册条目必须有唯一查询编号（`QP-*`）、正式入口、口径边界、回退路线和复核日期；入口失效或不再高频使用时，应从手册拿掉或降为归档备注。B01／B02 速查表通过查询编号链到 OPS，不平行维护第二套入口描述。

## 最小来源计划

每张任务卡只需写：主源、独立交叉源、反证来源、主源拿不到时的替代，以及替代造成的口径／完备度限制。详细入口和查询参数见 OPS，不进入默认阅读路径。
