# 04 推理方法知识库

本库保存可复用的判断方法，回答“合格证据怎样形成、削弱、阻断或修改判断”。单次报告、审计格式和 04→05 交接由 [`04_推理输出规范.md`](../04_推理输出规范.md) 规定。

## 1. 库里有什么

| 目录 | 判断对象 | 解决的问题 |
|---|---|---|
| [`A_单项判断裁决`](A_单项判断裁决/A00_A类选择与判断等级规则.md) | 单个关键判断或投资命题 | 状态、趋势、阶段、机制、归因、传导、分化、影响、预期差怎样形成判断，以及投资命题怎样综合裁决 |
| [`B_推理路径验证`](B_推理路径验证/B01_路径成立与逐段验证.md) | 路径、节点和规则 | 逻辑能走到哪里，影响在哪里减弱、延迟或停止 |
| [`C_反证与竞争解释`](C_反证与竞争解释/C01_反证命中与裁决动作.md) | 反证、替代解释和冲突证据 | 应降低强度、缩小范围、停止、改写还是保留争议 |
| [`D_改判与复盘`](D_改判与复盘/D01_改判触发与判断版本.md) | 随时间变化的原判断 | 新证据如何形成新版本，历史结果如何反馈方法 |

行业、产品和报告类型只作为案例或参数，不新增平行推理目录。

## 2. 本库与其他资产的边界

- [`02框架库`](../02框架库/README.md)决定判断什么、路径和变量是什么。
- [`03取证策略库`](../03取证策略库/README.md)决定哪些证据可以使用、最多支持到什么程度。
- 04 推理方法库决定合格证据怎样影响判断。
- 05 只负责把已经审计的判断准确表达为研究报告。

04 不重新设计问题、不增加路径、不补充证据，也不规定最终报告目录。发现问题边界有误退回 01，结构有误退回 02，证据不足或口径有误退回 03。

## 3. 如何使用

1. 确认 01—03 的对象、时间、范围和版本一致。
2. 从 A00 选择一个主要判断方法，并继承 03 给出的最高判断等级。
3. 用 B01 逐段检查决定性路径，确定路径状态、最后一个已验证节点和第一条未通过路径；需要传导结论时，再由 A06 读取该结果形成裁决。
4. 用 C 处理最强反证、竞争解释和未解决冲突。
5. 形成方向、实际等级、置信度、范围、时点和局限。
6. 需要投资观点时，再用 A10 检查研究判断、市场预期、资产定价、时间窗口和下行边界。
7. 用 D 记录上一版判断、证据变化、改判条件和复盘安排。

简单任务不要求使用全部方法。选择范围由本次最难判断、最可能改判的环节决定。

### 常见任务的最小调用组合

“主方法”负责回答本次主问题；前置或辅助方法只在该依赖真实存在时调用。表中组合是最低推荐，不是固定流水线。

| 任务类型 | 主方法 | 常用前置或辅助 |
|---|---|---|
| 判断当前供需是否紧张 | [A01 状态](A_单项判断裁决/A01_状态判断.md) | 必要时 A07 处理结构分化 |
| 判断价格是否进入上涨趋势 | [A02 趋势](A_单项判断裁决/A02_趋势判断.md) | A01 提供当前状态 |
| 判断行业处于周期哪个阶段 | [A03 阶段](A_单项判断裁决/A03_阶段判断.md) | A01、A02 作为阶段条件输入 |
| 判断政策机制是否真实运行 | [A04 机制](A_单项判断裁决/A04_机制判断.md) | B01、B02 |
| 判断某变化主要由什么造成 | [A05 归因](A_单项判断裁决/A05_归因判断.md) | C02 竞争解释 |
| 判断事件影响传到了哪里 | [A06 传导](A_单项判断裁决/A06_传导判断.md) | B01；必要时 B02、B03 |
| 判断哪些公司受益更多 | [A07 分化](A_单项判断裁决/A07_分化判断.md) | A08 检查兑现能力 |
| 判断对公司盈利有什么影响 | [A08 影响](A_单项判断裁决/A08_影响判断.md) | A06；必要时 B02 |
| 判断是否形成预期差 | [A09 预期差](A_单项判断裁决/A09_预期差判断.md) | A08 |
| 判断是否形成投资命题 | [A10 投资命题裁决](A_单项判断裁决/A10_投资命题裁决.md) | A08、A09 及 B/C 已完成结果 |

四条典型链为：

```text
周期判断：A01 → A02 → A03
事件影响：A04 → B01/B02 → A06 → A08
公司分化：A07 → A08
投资命题：A08 → A09 → A10
```

A10 是特殊的综合裁决方法，不与 A01—A09 同粒度。它只消费已完成的基本面判断、预期差、路径和反证结果，不独立生产基本面判断、事前预期基线或资产定价证据。

## 4. 统一执行接口与判断记录

A01—A10 每份方法卡都必须声明“最低输入、必须输出、输出上限与下一方法、强制退回条件”。共同接口是：

| 输入来源 | 最低内容 |
|---|---|
| 01 | 对象、问题、判断时点、时间窗口和范围 |
| 02 | 主判断定义，以及本方法所需的变量、基线、条件或既定路径 |
| 03 | 已准入证据引用、证据权限、最高 J 等级、冲突和缺口 |

缺少共同输入时，不得由 04 自行补造：问题边界返回 01，判断结构返回 02，证据与口径返回 03；若现有信息不足以形成方向，则保留 J0 并写明缺口。

每个重要判断至少记录：

- 待判断命题及对象、时间、范围；
- 03 允许的最高等级；
- 主要判断方法和决定性前提；
- 路径当前能够到达的终点；
- 最强反证和竞争解释；
- 当前结论、实际等级、置信度和限制；
- 上一版到当前版本的证据变化；
- 下一验证点和具体改判动作。

其中“当前判断、实际等级与置信度、适用范围、决定性依据、最强限制、改判条件”是所有 A 方法的固定输出字段。方法卡只增加本方法特有内容，不得另造同义字段。

03 给出的等级是上限，04 可以维持或降低，不能上调。J4 只用于历史事实或当前状态，不用于因果、前瞻和投资命题。完整等级标准见 [`A00`](A_单项判断裁决/A00_A类选择与判断等级规则.md#统一判断等级)。

## 5. 常见处理方式

| 证据影响 | 处理 | 结果 |
|---|---|---|
| 只影响幅度或置信度 | 降级 | 保留方向，降低强度 |
| 只影响部分对象或时间 | 缩小 | 收窄范围或窗口 |
| 命中决定性前提 | 阻断 | 停止相关路径及后续推导 |
| 新解释更能说明事实 | 改写 | 更换主因、路径、阶段或对象表述 |
| 当前证据不能区分 | 保留争议 | 不强行选择，设置区分信号 |

反证不是自动推翻；支持材料多也不是自动增强。处理方式取决于证据命中了判断结构的哪个位置。

## 6. 质量与准入标准

新方法只有满足以下条件，才可进入正式知识库：

1. 解决反复出现的判断问题，不保存单次结论；
2. 现有 A/B/C/D 方法无法完整表达；
3. 至少在两个不同任务中出现并经研究员复核；
4. 说明适用与不适用情形、输入、步骤、反证、输出和常见误判；
5. 不复制 02 的判断结构、03 的证据规则或 05 的写作要求；
6. 单次经验先进入 D02 的复盘候选，验证后再修改稳定方法。


校验器检查 A/B/C/D 方法资产、统一接口、方法等级上限、路径状态值域、标题与链接、重复定义和三库职责边界，不生成或判断研究结论。
