# 04 职责边界与调用规则

## 进入 04 前必须具备什么

- 01 的问题、对象、范围和用途已经冻结；
- 02 已给出判断单元、候选命题、关键变量、主路径和停止条件；
- 03 已冻结事实、观测、反证和证据使用上限；
- 三阶段的任务、对象、业务时间和口径一致。

缺问题边界退回 01，缺判断结构退回 02，缺证据或口径退回 03。04 不改题、不加路径、不补证据、不扩大结论范围。

## 04 的固定动作

1. 复述待裁决命题和 03 使用上限；
2. 按 A00 从 A01—A09 选择一个主裁决动作，并记录 03 给出的 J0—J4 上限；
3. 用 B 检查关键路径可达终点；
4. 用 C 处理反证、竞争解释和冲突；
5. 形成方向、实际等级、置信度、范围、时点和局限；
6. 若 01 要求投资观点或 05 拟形成投资主线，用 A10 执行投资命题裁决；
7. 用 D 记录证据增量、等级更新、跟踪与改判。

## 输出要求

研究员报告回答“当前怎么看、为什么、这条判断是否值得成为投资观点、为什么不能说得更强、下一步看什么、什么情况下改判”。审计记录保存证据引用、路径状态、初始/上一版等级、证据变化、更新等级、投资命题裁决与判断版本，两者结论必须一致。
