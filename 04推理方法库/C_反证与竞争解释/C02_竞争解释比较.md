# C02 竞争解释比较

## 要解决的问题

当多个原因或路径都能解释同一现象时，比较谁的解释力更强，或判断是否应保留共同作用/争议。

## 对称比较表

对每个解释使用同一结构：

| 维度 | 要问的问题 |
|---|---|
| 覆盖 | 能解释哪些核心现象，遗漏什么 |
| 时序 | 原因是否先于结果，时滞是否合理 |
| 中介 | 是否观察到它特有的中间信号 |
| 分化 | 能否解释高/低暴露对象差异 |
| 反事实 | 原因弱或不存在时结果是否仍出现 |
| 假设负担 | 需要多少额外假设才能成立 |
| 证据直接性 | 关键前提是否得到直接、独立支持 |

## 判断处理

- 一种解释在区分信号上明显更强：设为主解释；
- 不同解释分别说明不同对象/阶段：拆分适用范围；
- 多种机制共同作用：说明各自贡献方向，不伪造精确权重；
- 无关键区分证据：保留争议并给出下一观察窗口。
