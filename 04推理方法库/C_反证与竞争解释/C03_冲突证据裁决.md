# C03 冲突证据裁决

## 先判断是真冲突还是表面冲突

依次检查：对象、产品/地区/客户、业务时间与发布日期、单位与分母、计划/实际、总量/结构、初值/修订值、样本和来源独立性。

## 四种处理

| 情况 | 处理 |
|---|---|
| 口径或对象不同 | 缩小各自适用范围，不视为互相推翻 |
| 时间错位 | 按时序解释，保留领先/滞后关系 |
| 方法差异可评估 | 比较样本与方法，按任务适配赋予权重 |
| 无法解释的真实冲突 | 保留双方，降低结论强度并设置区分信号 |

不能删掉“不符合主线”的材料，也不能简单取平均。来源层级较高不保证对当前业务问题更贴近；判断要结合主张性质和任务适配。

## 输出

写明冲突是什么、为何能/不能解释、当前结论因此受限在哪里、下一项最有辨识力的证据是什么。
