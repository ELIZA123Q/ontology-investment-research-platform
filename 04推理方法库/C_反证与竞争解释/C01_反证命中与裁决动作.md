# C01 反证命中与裁决动作

## 反证先定位，再动作

反证不一定推翻主判断。先判断它命中起点事实、决定性前提、中间传导、幅度/持续性、局部对象还是背景解释。

| 命中位置 | 默认动作 |
|---|---|
| 起点事实或决定性前提 | 阻断 |
| 中间传导 | 降级或改为条件判断 |
| 幅度/持续性 | 降低强度或缩短窗口 |
| 局部对象 | 缩小范围并保留分化 |
| 主因解释 | 改写或与竞争解释并列 |
| 尚不能区分 | 保留争议 |

## 五步判断

1. 它反驳的具体命题是什么；
2. 与主证据的对象、时间和口径是否一致；
3. 03 允许它用于什么强度；
4. 它是否命中必要条件，还是只影响程度；
5. 处理后原判断具体改成什么。

“未找到支持”不是反证；真正相反且质量合格的观测才是。反证处理必须进入结论主体，不能全部塞入风险提示。
