# A10 投资命题裁决

## 要判断什么

回答一个已有研究判断在给定资产、时间窗口和风险边界下，是否值得成为投资观点。

```text
研究判断
→ 市场预期差
→ 定价反映程度
→ 上行/下行情景与触发窗口
→ 投资命题裁决
```

A10 判断的是“是否形成投资命题”，不是“基本面判断是否成立”。基本面判断由 A01—A08 完成，预期差和计价程度由 A09 完成。

A10 不是投资建议，不输出买入/卖出、仓位、目标价、确定性收益率或适用于个人的行动指令。

## 综合裁决定位

A10 是 A 类中的特殊综合裁决方法。它只消费前序判断，不独立生产基本面判断、事前预期基线、定价证据、情景数据或资产范围；任何前序输入缺失都不能在 A10 内补造。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 明确资产、投资命题问题、观察窗口、范围和交付边界 |
| 02 | 投资命题结构、上行/基准/下行情景、敏感变量、失效和验证条件 |
| 03 | 上述输入的已准入证据、事前预期与定价材料、最高 J 等级、冲突和缺口 |
| 04 前置 | A08 基本面影响、A09 预期差与计价，以及必要的 B 路径状态和 C 最强反证结果 |

## 进入条件

以下输入缺一时，A10 不得给出“形成投资命题”：

1. 至少一条 A01—A08 研究判断达到 J2，且决定性路径未被阻断；
2. A08 已把基本面变化连接到可识别的经营、盈利、现金流或风险变量；
3. A09 有可追溯的事前预期基线，并对预期修订和价格/估值反应做了判断；要形成正式或条件性投资命题，A09 至少达到 J2；
4. 明确对应资产、观察窗口、上行来源、下行边界和失效条件；
5. 03 对上述输入均已准入，且时点一致。

如果任务只问行业事实、机制或基本面影响，不强制调用 A10。如果 01 明确要求投资观点，或 05 准备将某判断写成投资主线，必须调用 A10。

## 五道判断前提

| 判断前提 | 核心问题 | 最低通过条件 |
|---|---|---|
| G1 研究成立 | 基本面或事件判断是否足够强 | 关键研究判断≥J2，主路径未阻断 |
| G2 预期可比 | 市场原本怎么看，与研究判断差在哪里 | 事前基线、口径、时间尺度和样本可追溯 |
| G3 定价未完全反映 | 盈利修订、价格和估值是否已消化新信息 | 存在未计价或部分计价部分，且不是只凭股价涨跌 |
| G4 收益风险不对称 | 在可比情景下，上行来源是否足以补偿下行暴露 | 基准/上行/下行情景的假设、敏感变量和失效点可比 |
| G5 可验证窗口 | 什么信号会让预期差收敛，在什么时候验证 | 至少一个可观测催化/验证信号及时间窗口 |

G1 失败时退回 A01—A08；G2/G3 失败时退回 A09 或 03；G4/G5 失败时只能保留为研究结论或观察命题，不进入 05 的投资主线。

## 判断步骤

1. 写出一句不含市场表述的研究判断，并引用 A08 及关键路径结果；
2. 写出事前市场预期、新信息改变了哪个定价输入，并引用 A09；
3. 分开检查盈利预期修订、相对价格反应、估值与风险溢价，判断未计价/部分计价/已计价/不可判断；
4. 在同一资产、时间和口径下对比基准、上行和下行情景；能量化时给出区间，不能量化时列出方向、主导变量和不可比限制；
5. 检查催化剂是否可观测、是否在投资窗口内，并区分“基本面终将发生”与“定价可能在窗口内收敛”；
6. 用最强反证重做一次情景检查，判断它是削弱上行、扩大下行、推迟窗口还是直接阻断命题；
7. 给出判断类型、J 等级、置信度、适用范围、改判条件和对 05 的表达上限。

## 判断结果

| 判断类型 | 使用条件 | 对 05 的处理 |
|---|---|---|
| 形成投资命题 | G1—G5 全部通过，且无决定性反证 | 可作为投资主线，必须保留时间、资产、情景和风险边界 |
| 条件性投资命题 | G1—G3 通过，G4 或 G5 依赖明确可观测条件 | 只能以条件观点表达，不得删除前置 |
| 观察命题 | 研究判断成立，但预期、计价、不对称或窗口仍不足 | 作为跟踪项或风险提示，不得写成投资机会 |
| 不形成投资命题 | 已充分计价、上行不足以补偿下行、无可验证窗口，或存在更强反向命题 | 05 可表达研究结论，但不将其列为投资主线 |
| 命题被阻断 | G1 失败或决定性前提/路径被反证命中 | 停止全部下游投资表达 |

A10 属于前瞻综合判断，最高只能达到 J3，不得使用 J4。“形成投资命题”也不等于高置信；判断类型与判断等级必须分开记录。

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 既有研究判断在给定资产、窗口和风险边界下是否形成投资命题 |
| 不能回答 | 独立生产基本面、预期或定价证据；输出买卖建议、仓位、目标价或承诺收益 |
| 最高允许等级 | J3；A10 属于前瞻综合裁决，不得达到 J4 |
| 下一方法 | 无后续 A 方法；只把裁决及表达上限交给 05，并由 D01 持续更新 |

## 必须输出

| 项目 | 内容 |
|---|---|
| 基础研究判断 | 引用 A08 及其 J 等级 |
| 市场预期与时点 | 事前基线、修订路径、分歧度 |
| 预期差与计价 | 引用 A09，标记未计价/部分计价/已计价/不可判断 |
| 情景不对称 | 基准、上行、下行的主要来源与敏感变量 |
| 催化与窗口 | 可观测信号、预期时间、不出现时的处理 |
| 最强反证 | 对上行、下行、窗口或整体命题的影响 |
| 当前判断 | 类型、J 等级、置信度与一句话结论 |
| 适用范围 | 资产、时间、情景、口径及适用对象 |
| 决定性依据 | 使 G1—G5 通过或失败的关键输入 |
| 改判条件 | 升级、降级、阻断或命题过期的信号与动作 |
| 对 05 的上限 | 可否进入投资主线，以及必须保留的前提和禁止表达 |

## 强制退回条件

- 资产、投资问题、观察窗口或范围未固定，返回 01；
- 情景、敏感变量、失效或验证条件未定义，返回 02；
- 事前预期、定价、情景或风险证据未准入/可补，返回 03；
- A08 未形成影响判断时返回 A08；A09 无有效比较时返回 A09；
- G1—G5 不能通过且现有信息不足以形成方向时保留 J0/观察命题，不得以叙事补齐。

## 例与误判

合格：存储价格与库存数据支持周期改善，合同重定价使盈利影响偏正面；事前一致预期对持续时间仍偏低，盈利修订与相对价格反应只部分消化。在下两个验证窗口内，若合同价继续上调且需求未转弱，可判断为“盈利改善尚未完全反映的条件性投资命题”。

误判：

- “周期改善”成立，就直接写“存在投资机会”；
- 股价没涨，就认为未计价；
- 估值低于历史均值，就认为收益风险比有利；
- 只写上行情景和催化剂，不写下行边界与失效条件；
- 把长期基本面正确当成当前定价必然收敛。
