# A02 趋势判断

## 要判断什么

回答变量是否形成持续方向、斜率变化或扩散，而不是判断一次同比/环比波动。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 对象、趋势问题、判断窗口和范围 |
| 02 | 同口径变量、最少连续点数、持续性/斜率/切换门槛、相邻验证变量 |
| 03 | 已准入的可比序列、修订与断点说明、最高 J 等级、反向证据和缺口 |

## 判断步骤

1. 使用 02 预设的窗口、最少连续点数和切换条件；
2. 对齐同口径序列，先排除季节性、基数、修订和样本断点；
3. 区分水平、方向、斜率和扩散度；
4. 用一个相邻机制变量验证，而不是再找同类转述；
5. 检查领先信号、同步确认和滞后结果是否符合预期顺序。

## 判断结果

- 多点持续且互补变量确认：形成趋势判断；
- 方向已变但持续性未确认：只写边际改善/恶化；
- 只有单点或基数效应：退回状态描述；
- 序列断点无法桥接：不比较断点前后。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 方向、持续性、斜率或扩散状态；不能判断时写 J0 |
| 实际等级与置信度 | 不超过 03 上限；区分趋势确认与边际变化 |
| 适用范围 | 对象、序列口径、起止窗口和频率 |
| 决定性依据 | 满足持续性门槛的连续点与相邻变量确认 |
| 最强限制 | 季节性、基数、修订、样本断点或反向信号 |
| 改判条件 | 趋势延续、斜率反转或扩散收窄的可观测门槛 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 已观察序列是否形成方向、斜率变化或扩散 |
| 不能回答 | 单点高低、变化主因、周期阶段或未来必然延续 |
| 最高允许等级 | J4；仅限直接确认的历史/当前趋势，未来延续判断最高 J3 |
| 下一方法 | 只有单点时退回 A01；判断阶段进入 A03；判断原因进入 A05 |

## 强制退回条件

- 对象、窗口或范围未固定，返回 01；
- 连续点数、切换门槛、同口径变量或相邻验证变量未定义，返回 02；
- 序列不可比、修订/断点未说明或关键数据未准入，返回 03；
- 只有单点或持续性不足时保留 J0/J1，并退回状态或边际变化表述。

## 例与误判

合格：价格连续三月上行、库存下降且交期延长，可判断紧张趋势正在形成。

误判：单月同比转正即称需求反转。
