# A00 A 类选择与判断等级规则

## 先选主问题，再选主方法

A01—A10 不是一组必须全部跑完的流程。一个待判断命题只选一个主方法，其他 A 方法只在主命题存在明确依赖时作为前置或辅助判断。

A10 是例外的综合裁决方法：它消费 A08、A09 以及必要的 B/C 结果，判断是否形成投资命题；它不独立生产基本面判断、事前预期基线或定价证据。

| 待回答的主问题 | 主方法 | 不应代替回答的问题 |
|---|---|---|
| 现在是什么状态 | A01 状态 | 是否将持续、为什么发生 |
| 变化是否持续、方向或斜率是否已变 | A02 趋势 | 单点高低、周期位置 |
| 处于哪个周期/发展阶段 | A03 阶段 | 用一个指标代替阶段条件组 |
| 某种作用机制是否在现实中运作 | A04 机制 | 多个原因中谁是主因 |
| 已发生变化主要由什么造成 | A05 归因 | 仅说明某条机制理论可能 |
| 影响如何从起点到达下一环或终点 | A06 传导 | 起点成立后直接推导终点 |
| 谁受益/受损更多，差异为何 | A07 分化 | 在不可比样本中做精确排名 |
| 已验证变化对行业、经营或财务意味着什么 | A08 影响 | 市场是否已经反映 |
| 研究判断相对事前市场预期有何差异、是否已计价 | A09 预期差 | 预期差是否值得成为投资观点 |
| 研究判断是否足以形成有边界的投资命题 | A10 投资命题 | 买卖建议、仓位、目标价或承诺收益 |

## 三组容易混淆的边界

### 状态、趋势、阶段

- 一个时点或窗口的高、低、紧、松：A01。
- 多个可比时点的方向、斜率、扩散度：A02。
- 由多个领先/同步/滞后条件共同定义的位置：A03。

价格上涨可以是 A01 的当前状态；只有连续性和相邻变量确认后才进入 A02；只有同时满足预定义的阶段条件组才进入 A03。

### 机制、归因、传导

- A04 验证“这个机制是否真在运作”。
- A05 比较“哪个原因对已发生变化解释更好”。
- B01 负责逐段验证既定路径并给出每条边的正式状态。
- A06 读取 B01 的路径结果，裁决“影响实际到达哪里、可以形成什么传导结论、哪些后续不得表达”。

三者可以串联，但不能互相代替。例如“美伊冲突对半导体影响”可以以 A08 为主方法，以 A04/A06 作为必要前置；不需把三个都并列为主结论。

### 影响、预期差、投资命题

- A08 到“基本面/盈利影响”为止。
- A09 到“与市场预期的差异及定价反映程度”为止。
- A10 才回答“该差异在给定时间和风险边界下，是否形成投资命题”。

## 统一执行契约

每份 A 方法卡都必须在共同接口基础上声明方法特有要求，不得隐式补齐缺失输入。

### 最低输入

| 输入来源 | 共同必需内容 |
|---|---|
| 01 | 对象、问题、判断时点、时间窗口和范围 |
| 02 | 主判断定义、决定性前提，以及所需变量、基线、条件或既定路径 |
| 03 | 已准入证据引用、证据权限、最高 J 等级、冲突和缺口 |

### 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 一句话结论；J0 时明确写“暂不可判断” |
| 实际等级与置信度 | J0—J4 与独立的置信度记录，不得互相替代 |
| 适用范围 | 对象、时间、地域、产品和口径边界 |
| 决定性依据 | 支持结论的关键条件、证据或已验证路径 |
| 最强限制 | 最强反证、冲突、缺口或未通过节点 |
| 改判条件 | 可观测变量、方向/门槛、窗口及触发后的动作 |

### 强制退回原则

- 对象、问题、时间或范围不清，返回 01；
- 变量、基线、阶段条件、候选解释或路径未定义，返回 02；
- 决定性证据未准入、口径冲突或关键缺口可补，返回 03；
- 当前证据不足以形成方向但结构仍可执行，保留 J0，并写明缺口和下一验证点。

各方法卡必须再声明本方法“可以回答什么、不能回答什么、最高允许等级、何时进入下一方法”。

## 什么时候不能用

| 方法 | 禁用条件 |
|---|---|
| A01 | 对象、时点、口径或比较基线未定义 |
| A02 | 只有单点、不可比序列或无持续性门槛 |
| A03 | 02 未预定义阶段及进入/退出条件 |
| A04 | 只有理论叙事，无行为主体和现实中介 |
| A05 | 候选原因未对称比较，无反事实或区分信号 |
| A06 | 02 无既定路径，或中间关键边未取证 |
| A07 | 比较对象、口径或基准不可比 |
| A08 | 只有概念暴露，无传导、缓冲和结果变量 |
| A09 | 无可追溯的事前预期基线，或只有股价涨跌 |
| A10 | A08 尚未形成判断、A09 无有效比较，或无明确资产/时间窗口/下行边界 |

## 统一判断等级

04 沿用全项目已生效的 J0—J4，不再新增平行的 L 等级。等级表示“当前证据与路径足以把这条判断说到多强”，置信度表示“在该等级下对结论稳健性的信心”，两者不可互换。

| 等级 | 研究含义 | 最低判断要求 |
|---|---|---|
| J0 暂不可判断 | 信息不足，未形成可用判断 | 说明缺口和补证方向，不给方向 |
| J1 观察 | 存在可观察信号，但决定性前提未满足 | 说明信号、噪声和下一验证点 |
| J2 条件/方向支持 | 关键条件已出现，可形成有条件的方向判断 | 至少一项直接支持，条件、范围和失效点明确 |
| J3 高概率 | 多源独立验证，决定性路径基本完整 | 至少两个独立来源组，主要反证已处理 |
| J4 确认 | 关键事实或当前状态已确认 | 仅限历史事实或当前状态；因果、前瞻及投资命题不得达到 J4 |

03 给出每个判断单元的最高等级；04 在该上限内给出实际等级。证据数量增加不会自动升级，只有当新证据命中决定性前提、补齐关键路径或有效排除竞争解释时才可升级。

## 03 证据质量如何限制 04 判断强度

| 03 交付的证据形态 | 04 的默认上限 |
|---|---|
| 一条新闻、一份公告或一个口径模糊的数据，且未补齐关键前提 | J0—J1；只能报告事实或作为观察信号 |
| 关键条件已有直接支持，但独立验证、持续性或中间路径未完整 | J2；只能形成条件/方向判断 |
| 多源独立验证，关键路径基本完整，主要反证已处理 | 可达 J3 |
| 对历史事实或当前状态有直接、高质量且口径一致的确认 | 可达 J4；不得外推到因果、前瞻或投资命题 |

证据上限是硬门槛：推理步骤更完整、叙事更顺或调用更多 A/B/C 方法，都不能把低质量证据“推理成”高等级判断。

## 每次判断必须保留的等级记录

```text
上一版/初始等级
→ 本次新增、变更或失效的证据
→ 证据命中的前提、路径、反证或范围
→ 更新后等级与置信度
→ 等级变化原因，或“为何维持”
→ 下一次升级/降级/阻断信号
```

首次判断时，“上一版”记为 J0；但不得把一次完整取证后的首次形成判断伪装成多次升级。
