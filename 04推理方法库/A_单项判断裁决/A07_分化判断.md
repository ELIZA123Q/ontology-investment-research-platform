# A07 分化判断

## 要判断什么

回答同一驱动下为什么不同对象结果不同，以及差异是否足以支持分组或排序。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 比较问题、对象集合、判断窗口和范围 |
| 02 | 可比口径、排除规则、比较维度、基准、排序/分组规则和稳健性要求 |
| 03 | 各对象对称取证后的暴露、敏感度、兑现能力、约束和实际结果，最高 J 等级及缺口 |

## 判断步骤

1. 固定比较集合、排除规则和统一口径；
2. 分别评价暴露度、敏感度、承接/兑现能力和约束；
3. 区分零值、未知和不适用；
4. 检查改变权重、窗口或基准后排序是否稳定；
5. 用实际结果或历史兑现验证静态暴露判断。

## 判断结果

- 差异变量与实际结果一致且排序稳健：可以排序；
- 只有暴露差异：只做分组，不做精确排序；
- 换合理口径即反转：保留维度化比较；
- 比较基础不一致：不得比较。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 可比对象的分组、稳健排序或不可比较结论 |
| 实际等级与置信度 | 不超过 03 上限；区分暴露分组与兑现排序 |
| 适用范围 | 对象集合、排除项、窗口、口径、基准和权重 |
| 决定性依据 | 导致差异的暴露、敏感度、承接能力或约束 |
| 最强限制 | 不可比项、未知值、权重敏感性或实际兑现缺口 |
| 改判条件 | 排序反转、兑现变化或可比性变化的门槛与窗口 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 同一驱动下对象为何分化，是否足以分组或稳健排序 |
| 不能回答 | 在不可比样本中精确排名，或把概念暴露直接写成盈利受益 |
| 最高允许等级 | J3；分化解释与受益排序不得达到 J4，纯当前事实确认应使用 A01 |
| 下一方法 | 需要验证经营或财务兑现时进入 A08 |

## 强制退回条件

- 比较问题、对象集合、窗口或范围未固定，返回 01；
- 比较维度、基准、排除规则或稳健性要求未定义，返回 02；
- 各对象未对称取证、口径不一致或关键结果可补，返回 03；
- 比较基础不一致时保留 J0，不强制分组或排序。

## 例与误判

合格：两家公司暴露相近，但一家公司有认证产能和客户复购，另一家仍在送样，因此兑现分层不同。

误判：按产业链概念相关度排列受益公司。
