# A03 阶段判断

## 要判断什么

回答对象处于哪一阶段、是否正在切换。阶段是多条件状态组合，不是单指标标签。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 对象、阶段问题、判断时点/窗口和范围 |
| 02 | 预定义阶段、进入/维持/退出条件、领先/同步/滞后变量及分化处理 |
| 03 | 各阶段条件的已准入证据、最高 J 等级、冲突、缺口和时点一致性 |

## 判断步骤

1. 使用 02 已定义的阶段、进入、维持和退出条件；
2. 标明各条件中哪些领先、同步、滞后；
3. 判断当前是“阶段内”“向下一阶段切换”还是“过渡未决”；
4. 检查分项是否同步，若不同步则保留阶段分化；
5. 用退出条件检验当前标签是否仍有效。

## 判断结果

- 进入条件满足且维持信号成立：确认阶段；
- 仅领先条件满足：写“出现切换迹象”；
- 条件相互冲突：写“过渡期/分化期”；
- 退出条件已命中：停止沿原阶段推导。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 阶段内、切换中、过渡未决或暂不可判断 |
| 实际等级与置信度 | 不超过 03 上限；切换迹象与阶段确认分开 |
| 适用范围 | 对象、阶段定义版本、判断时点及分项范围 |
| 决定性依据 | 已满足的进入/维持条件及未命中的退出条件 |
| 最强限制 | 条件冲突、分项不同步、滞后确认或缺失变量 |
| 改判条件 | 下一阶段进入、当前阶段退出或分化收敛的门槛与窗口 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 对象符合哪个预定义阶段，是否处于切换/过渡 |
| 不能回答 | 用单一指标创造阶段、解释阶段成因或保证下一阶段到来 |
| 最高允许等级 | J4；仅限按固定标准确认的历史/当前阶段，切换与前瞻判断最高 J3 |
| 下一方法 | 补充状态/趋势条件用 A01/A02；判断成因用 A05；判断影响用 A08 |

## 强制退回条件

- 对象、时点或阶段问题未固定，返回 01；
- 阶段及进入/维持/退出条件未预定义，返回 02；
- 决定性阶段条件未准入、时点错配或冲突可补，返回 03；
- 条件相互冲突且无法区分时保留 J0/J1，不事后改写阶段标准。

## 例与误判

合格：库存下降、价格止跌且订单改善，但稼动尚未回升，因此判断处于修复早期而非全面扩张。

误判：只凭价格上涨把行业贴为上行周期。
