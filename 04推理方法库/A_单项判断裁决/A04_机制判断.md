# A04 机制判断

## 要判断什么

回答一种作用机制是否在本次对象和窗口中实际运作。机制成立需要现实中介，不只需要理论合理。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 对象、机制问题、判断窗口和范围 |
| 02 | 已定义的起点、行为主体、必要中介、结果、时滞、适用与阻断条件 |
| 03 | 起点、行为和中介的已准入证据，最高 J 等级，替代机制、反证、冲突和缺口 |

## 判断步骤

1. 确认使用的是 02 已定义的机制结构、适用范围和阻断条件；
2. 对必要路径调用 B01；需要判断行为承接、状态承接或合理时滞时调用 B02；
3. 读取路径结果，检查机制特有的主体行为和中介是否按预期顺序出现；
4. 用 C02 对称比较至少一个能够解释相同现象的替代机制；
5. 根据路径、时序、替代解释和阻断结果裁决机制是否实际运作。

## 判断结果

- 中介与时序均有现实承接：机制较成立；
- 只有起点和结果相关：最多写“与该机制一致”；
- 行为未改变或关键中介缺失：机制未验证；
- 替代机制解释力更强：改写机制判断。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 机制实际运作、部分运作、仅与机制一致、未验证或被阻断 |
| 实际等级与置信度 | 不超过 03 上限；理论合理不得提高等级 |
| 适用范围 | 对象、窗口、适用情境和机制版本 |
| 决定性依据 | 机制特有的行为/中介及其 B01/B02 结果 |
| 最强限制 | 替代机制、关键中介缺失、时序异常或阻断条件 |
| 改判条件 | 中介出现/消失、超过时滞窗口或阻断命中的具体动作 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 既定机制是否在本次对象和窗口中实际运作 |
| 不能回答 | 该机制是否为主要原因、影响是否已传到终点、公司盈利是否改善 |
| 最高允许等级 | J3；机制属于因果判断，不得达到 J4 |
| 下一方法 | 比较主因进入 A05；判断到达节点进入 A06；判断经营/财务意义进入 A08 |

## 强制退回条件

- 对象、机制问题、窗口或范围未固定，返回 01；
- 行为主体、必要中介、时滞、适用或阻断条件未定义，返回 02；
- 关键路径证据未准入或现实中介可补证，返回 03；
- 只有理论叙事而无现实中介时保留 J0/J1，不写“机制成立”。

## 例与误判

合格：政策生效后审批收紧、企业采购提前、库存下降并出现交期变化，机制链获得逐段支持。

误判：政策与行业价格同期变化，因此断定政策导致涨价。
