# A05 归因判断

## 要判断什么

回答一个已发生变化主要由什么造成。归因是竞争解释之间的相对判断，不是列举原因。

## 最低输入

| 输入来源 | 本方法必需内容 |
|---|---|
| 01 | 被解释变化、对象、幅度、判断窗口和范围 |
| 02 | 候选原因集，以及各自预期时序、中介、暴露对象、反事实和区分信号 |
| 03 | 每个候选原因的对称证据包、最高 J 等级、共同驱动、反向样本、冲突和缺口 |

## 判断步骤

1. 固定 02 已定义的被解释变化、候选原因和区分信号；
2. 调用或继承 C02，按同一维度对称比较全部候选解释；
3. 检查谁能解释更多现象、分化、时间顺序和反事实；
4. 检查共同驱动、反向样本和低暴露对象；
5. 根据 C02 结果裁决单一主因、共同作用、适用范围拆分或暂不可区分。

## 判断结果

- 主因比竞争解释多解释关键区分信号：可以写“主要由”；
- 多因素各解释不同部分：写共同作用及各自范围；
- 缺反事实或区分信号：写“可能由/与……一致”；
- 低暴露对象同样变化：削弱目标原因。

## 必须输出

| 字段 | 内容 |
|---|---|
| 当前判断 | 主因、共同作用、分范围解释或暂不可区分 |
| 实际等级与置信度 | 不超过 03 上限；“主要由”必须有 C02 对称比较支持 |
| 适用范围 | 被解释变化、对象、幅度、窗口和口径 |
| 决定性依据 | 最有区分力的时序、中介、分化或反事实证据 |
| 最强限制 | 最强竞争解释、共同驱动、低暴露样本或缺失区分信号 |
| 改判条件 | 能区分候选原因的新信号、门槛、窗口和动作 |

## 输出上限与下一方法

| 项目 | 规则 |
|---|---|
| 可以回答 | 多个候选解释中哪个解释力更强，或是否共同作用/不可区分 |
| 不能回答 | 仅凭某机制成立就断言“主要由其造成”，或伪造精确贡献权重 |
| 最高允许等级 | J3；归因属于因果判断，不得达到 J4 |
| 下一方法 | 需验证机制进入 A04；需判断影响到达节点进入 A06；需判断结果意义进入 A08 |

## 强制退回条件

- 被解释变化、对象或窗口未固定，返回 01；
- 候选原因、反事实或区分信号未定义，返回 02；
- 候选解释未对称取证、关键样本缺失或冲突可补，返回 03；
- 无法区分候选解释时保留 J0/J1 或“共同作用待区分”，不得选择新闻中最显眼原因。

## 例与误判

合格：订单回升同时出现在低库存客户而非高库存客户，更支持补库驱动而非全面终端复苏。

误判：选择新闻中最显眼的事件作为唯一原因。
