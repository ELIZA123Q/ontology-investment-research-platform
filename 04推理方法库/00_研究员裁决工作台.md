# 04 研究员判断工作台

## 一句话定位

02 把问题拆成若干关键判断，03 说明证据目前够到哪里，04 负责两层判断：

1. **研究判断：** 这些证据使哪个前提成立到什么程度，逻辑可以走到哪一段，主判断应维持、降低强度、停止还是改写；
2. **投资命题判断：** 已成立的研究判断相对市场预期和资产定价有何差异，在给定窗口和下行边界下是否足以形成投资观点。

04 不再补问题、补路径或补材料。发现结构问题退回 02，发现证据问题退回 03。

## 四类判断对象

| 类别 | 判断对象 | 研究员的问题 | 产物 |
|---|---|---|---|
| A 单项判断方法 | 一个关键判断 | 状态、趋势、阶段、机制等应怎样形成判断 | 有边界的子判断 |
| B 推理路径验证 | 路径、边和规则 | 每一步前提是否成立，影响在哪里减弱或停止 | 路径状态与可达终点 |
| C 反证与竞争解释 | 支持、反证、替代解释之间的关系 | 反证影响哪一层判断，哪种解释更好 | 判断处理与争议状态 |
| D 改判与复盘 | 随时间变化的原判断 | 新信号如何改变原判断，经验应反馈到哪里 | 新版本判断与方法反馈 |

这四类是 04 的固定分类方式。行业、产品和报告类型只作为案例或参数，不新增平行主目录。

## 最短使用顺序

1. 先读 A00，从 A01—A09 选择主要判断方法；
2. 用 B 逐段检查决定性路径，得到“能走到哪里”；
3. 用 C 单独处理最强反证、竞争解释和未解决冲突；
4. 形成“当前判断 + J 等级 + 置信度 + 范围 + 时点 + 局限”；
5. 若任务需要投资观点，用 A10 检查研究判断→市场预期→资产定价→投资命题；
6. 用 D 写下证据变化、等级更新、下一验证点和具体改判动作。

不是每次都要调用所有文件。简单状态判断可能只需 A01 + C01；复杂事件传导可能需要 A06 + B01/B02 + C01/C02 + D01。

## 一张判断记录

| 项目 | 内容 |
|---|---|
| 待判断命题 | 对象、时间、范围、比较基准 |
| 03 允许的最高等级 | J0 / J1 / J2 / J3 / J4 |
| 上一版/初始等级 | 首次判断记 J0；更新时引用上一版 |
| 主要判断方法 | A01—A09；投资观点另加 A10 |
| 决定性前提 | 哪项失败会让后续停止 |
| 路径可达终点 | 当前证据最多支持到哪一环 |
| 最强反证 | 命中事实、机制、幅度、范围还是持续性 |
| 竞争解释 | 哪一解释更强，为什么；或为何暂不能区分 |
| 证据变化 | 新增、变更或失效的证据，以及命中的前提/路径/反证/范围 |
| 当前结论 | 方向、更新后 J 等级、置信度、范围、时间和限制 |
| 等级变化理由 | 为何升级/降级，或新证据为何不足以改变等级 |
| 投资命题判断 | 形成/条件性/观察/不形成/不能继续成立；非投资任务记不适用 |
| 改判条件 | 看什么、何时看、出现后具体怎么改 |

## 统一的 J0—J4 判断等级

等级含义、最低判断要求和禁用条件只在 [A00](A_单项判断裁决/A00_A类选择与判断等级规则.md#统一判断等级) 维护，本工作台不复制等级表。使用时只需记住：03 给出最高可用等级，04 可以维持或降低，不能上调；J4 只用于历史事实或当前状态，不用于因果、前瞻和投资命题。

## 五种常见处理方式

| 发现 | 动作 | 结果 |
|---|---|---|
| 只影响幅度或置信度 | 降级 | 保留方向，降低强度 |
| 只影响部分对象或窗口 | 缩小 | 收窄范围或时间 |
| 命中决定性前提 | 阻断 | 停止相关路径和后续推导 |
| 新解释更能说明事实 | 改写 | 更换主因、路径、阶段或对象表述 |
| 现有证据不能区分 | 保留争议 | 不强行择一，设置区分信号 |

反证不是自动推翻；支持材料多也不是自动增强。动作取决于证据命中了判断结构的哪个位置。

## 结论句的最低结构

> 截至【判断时点】，在【对象/范围】内，现有证据将该判断由【上一版等级】更新为【当前等级】，因为【证据变化及命中位置】；但【反证/竞争解释】限制了【幅度/范围/持续性】。若【具体信号】在【窗口】出现，则应【升级/降级/阻断/改写】。

投资任务追加：

> 基于【研究判断】，相对【事前市场预期】，当前【未计价/部分计价/已计价/不可判断】；在【时间窗口】和【下行边界】下，该投资命题属于【形成/条件性/观察/不形成/不能继续成立】。
