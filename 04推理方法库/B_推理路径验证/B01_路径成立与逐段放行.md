# B01 路径成立与逐段放行

## 目的

判断 02 已冻结的路径可以从起点走到哪里。路径不是“整体成立/不成立”二选一，每一段都要单独放行。

## 每段六问

1. 起点是否在本次对象和窗口真实发生；
2. 作用关系为何适用于本次情形；
3. 预期的主体行为或中间状态是否出现；
4. 当前时点是否已进入合理结果窗口；
5. 削弱、吸收或阻断条件是否命中；
6. 该段证据最多允许传到下一节点还是终点。

## 路径状态

| 状态 | 含义 | 后续动作 |
|---|---|---|
| 成立 | 前提和承接满足 | 放行到下一段 |
| 部分成立 | 方向存在但范围/幅度受限 | 放行并降级 |
| 条件成立 | 结果尚未出现但条件明确 | 只形成条件推导 |
| 存在争议 | 支持和反证未分高下 | 暂停强结论，设置区分信号 |
| 证据不足 | 不能判断是否发生 | 不放行，也不写成没有发生 |
| 被阻断 | 决定性前提失败 | 停止全部下游推导 |
| 不适用 | 不属于本次对象或范围 | 排除该段 |

## 研究员输出

写清“最后一个已验证节点”“第一条未放行的边”和“因此不能推出的后续结果”。不要用弱化措辞绕过缺失中介。
