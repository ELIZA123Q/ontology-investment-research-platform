# D02 历史复盘与方法反馈

## 第一版的定位

复盘先保留轻量框架，不急于沉淀普遍规律。没有足够历史样本时，只记录案例和候选改进，不修改稳定方法。

## 复盘六问

1. 当时基于可见信息预期什么；
2. 后来在哪些对象和时点实际发生什么；
3. 哪个信号有区分力，哪个只是噪声或滞后确认；
4. 错误来自结构、证据、口径、机制、时滞、外推还是竞争解释；
5. 应反馈到 02、03、04、正式本体还是 05；
6. 相同问题是否已在多个独立任务重复。

## 反馈路由

| 问题 | 返回位置 |
|---|---|
| 少了变量、路径或停止条件 | 02 |
| 来源、指标、证据组合或质量门槛有误 | 03 |
| 相同证据被系统性裁决错误 | 04 |
| 稳定对象、关系或正式规则缺失 | 本体候选 |
| 判断正确但表达误导 | 05 |

一次案例只形成候选；至少两个不同任务出现同类裁决问题并通过研究员复核后，才修改稳定规则。
