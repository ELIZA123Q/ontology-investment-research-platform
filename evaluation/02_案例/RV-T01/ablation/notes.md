# RV-T01 消融对照说明（协议试点）

## 评分依据

- **P3**：锚定 `system_artifact.md`、`reasoning_logic.md`、`judgment_brief.md`、`reasoning_audit.yaml`（现行主链产物）。
- **P2**：假设保留分产品周期结构与状态变量口径（本体对象集），但去掉方法路由/证据 Bundle 硬约束——预期术语漂移下降、结构完整度上升，但数字接地与 CE 覆盖仍弱于 P3。
- **P1**：仅分阶段叙述、无本体对象集——易出现 HBM/DRAM/NAND 口径混用与返工定位不清。
- **P0**：单次直答——结构与竞争解释最弱。

## 本体增量

| 指标 | 值 |
|------|-----|
| Δ_ontology = P2 − P1 | **+0.625**（正） |
| Δ_methods = P3 − P2 | **+0.875**（正） |

观察：本体主要抬升「术语/口径」与「返工定位」；方法+证据约束主要抬升「数字来源」「竞争解释」「结论-证据匹配」。

## 最弱项

- P2 的 `numeric_source_error` 仍一般（3）：说明**仅有本体对象集不足以替代证据压缩与数字纪律**。
- `run_stability` 在 P1/P2 未拉开：结构评分无法代替真实重复运行；正式发布前须按 [`06_消融阶梯执行说明.md`](../../../01_协议/06_消融阶梯执行说明.md) 重跑。

## 结论边界

本文件是消融协议的首个案例落盘，证明「可报告本体增量」的交付形态，**不是**已校准的正式评测结果。
