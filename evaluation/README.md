# 研究价值评测

验证"加了这套研究流程后，产出真的比模型一代直接生成更好吗"。

评测不是一次性考试，而是一套持续检查：在冻结证据的前提下，从可靠性、有用性、增量、稳定性四个维度比较工作台产出和同证据直出版本。

## 评什么

| 维度 | 问的是什么 |
|------|-----------|
| **R 可靠性** | 核心判断有没有证据和推理支持，还是凭感觉说的 |
| **U 有用性** | 下游能不能拿来复述、跟踪、更新 |
| **delta 增量** | 比同证据直出/摘要好多少——加流程有没有收益 |
| **S 稳定性** | 换模型、换提示词，结论还稳不稳 |
| **C 可信度** | 评测器本身能不能抓住已知缺陷（评测的评测） |

**注意**：这些指标用来发现问题、比较方案，不能用四题结果宣称"系统研究可靠率为 XX%"。
