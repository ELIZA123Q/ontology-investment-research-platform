## 项目运行（启动服务）
- 启动方式：`cd runtime && export PATH=<managed node 22.22.2>:$PATH && bash scripts/prod-singleton.sh`，用 agent 的 run_in_background 机制直接跑脚本（**不要**再套 nohup/&，也不要走 `npm run prod:singleton` 再 nohup——会双重后台化且 npm 子进程 stdout 块缓冲导致日志看不到进度）。
- 结果：Next.js 16.2.10 ready in 598ms，监听 127.0.0.1:3000，research-worker 同时启动。curl 容器内 HTTP 200，浏览器可正常打开 http://127.0.0.1:3000/。
- 验证监听：`lsof -i TCP:3000 -sTCP:LISTEN`（ps 在沙箱被禁，用 lsof 代替）。

## 研究列表默认排序改为按更新时间
- 需求：/runs（我的研究页）所有研究默认按更新时间排序。
- 改动：`runtime/app/components/run-list.tsx` 默认 `sortMode` 由 `"action_priority"` 改为 `"updated_desc"`（最新在前，降序），并把下拉「按最后更新」选项提到首位。排序逻辑本身已支持（else 分支按 `updated_at` 降序），仅改默认值与下拉顺序。
- 注：草稿/尚未开始的研究仍折叠在「尚未开始的研究」区，区内也按更新时间排序；如要全部摊平进同一列表需另改 forest 拆分逻辑。
