# 研究运行合同

| 文件 | 定义内容 |
|---|---|
| [`evidence.yaml`](evidence.yaml) | 来源、证据、事实和冲突等运行对象 |
| [`reasoning.yaml`](reasoning.yaml) | 假设、判断、反证和审批等对象 |
| [`dynamic_execution.yaml`](dynamic_execution.yaml) | 动态计划、节点执行、双时态与审计约束 |

这些文件约束运行对象的结构；任务步骤和权限由[研究规则](../研究规则/README.md)与[研究能力](../研究能力/README.md)决定，不应在这里另写流程副本。
